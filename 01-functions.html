Функции

Функция — это кусочек кода с именем, который можно запускать снова и снова. Кнопка «Купить», проверка пароля, расчёт суммы в корзине — за каждым таким действием на сайте стоит функция. Сегодня мы научимся их писать, понимать и читать чужие.

  • Объявлять функции двумя способами: Declaration и Expression
  • Писать короткие стрелочные функции
  • Передавать данные через параметры и задавать значения по умолчанию
  • Возвращать результат через return
  • Понимать, где «видна» переменная — область видимости
Как работать с этой страницей

Весь код на тёмном фоне с кнопкой ▶ Запустить — живой. Его можно менять прямо здесь и сразу видеть результат в консоли под ним. Сломали — нажмите ↺ Сброс. Подсказки к задачам спрятаны под замочком 🔒: сначала попробуйте сами, открывайте подсказку, только если застряли.

01 Что такое функция. Function Declaration

Представьте, что вам нужно трижды в разных местах программы поприветствовать пользователя. Без функций код выглядит так:

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в Ilmhona");

// ... какой-то другой код ...

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в Ilmhona");

// ... и ещё раз ...

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в Ilmhona");

Работает, но представьте, что текст нужно поменять. Придётся искать и исправлять его везде — и где-нибудь обязательно забудете. Функция решает эту проблему: мы один раз описываем действие и даём ему имя, а потом просто вызываем его по имени.

function greet() {
  console.log("Ассалому алейкум!");
  console.log("Добро пожаловать в Ilmhona");
}

greet();
greet();
greet();
Аналогия из жизни

Функция — это рецепт. Рецепт оши палав записывают один раз: что взять и в каком порядке готовить. Когда хотим плов — не придумываем его заново, а открываем рецепт и готовим по нему. Записать рецепт — это объявить функцию. Приготовить по рецепту — вызвать функцию. Рецепт можно использовать сколько угодно раз.

Из чего состоит функция

Способ, который мы только что использовали, называется Function Declaration — «объявление функции». Разберём его по частям:

function
Ключевое слово. Говорит JavaScript: «сейчас будет функция».
Имя
Как мы будем обращаться к функции. Обычно это глагол на английском: greet, showMenu, calcTotal.
Параметры
В круглых скобках. Это «входные данные» функции. Скобки пишутся всегда, даже если они пустые.
Тело
Код в фигурных скобках { }. Выполняется каждый раз, когда функцию вызывают.
Вызов
Имя функции и круглые скобки: greet(). Именно скобки заставляют функцию сработать.

Что происходит при вызове — по шагам

function welcome(name) {
  console.log("Хуш омадед, " + name + "!");
}

welcome("Мадина");   // → Хуш омадед, Мадина!
welcome("Фарход");   // → Хуш омадед, Фарход!
  1. JavaScript видит объявление и запоминает: есть функция welcome. Код внутри пока не выполняется — рецепт записан, но готовить ещё не начали.
  2. Встречает вызов welcome("Мадина") и «прыгает» внутрь функции.
  3. Кладёт значение в параметр: name становится равен "Мадина".
  4. Выполняет тело — выводит строку в консоль.
  5. Возвращается туда, откуда функцию вызвали, и идёт дальше — к следующему вызову, где name уже будет "Фарход".

Как называть функции

  • Имя описывает действие: showPrice, checkPassword, sendMessage.
  • Пишем в стиле camelCase: первое слово с маленькой буквы, каждое следующее — с большой.
  • Только латиница. Кириллица технически работает, но в реальных проектах так не пишут.
  • Одна функция — одно действие. Если в имени хочется написать «и» (checkAndSendAndSave), значит, это должно быть несколько функций.
Частая ошибка

Забыть скобки при вызове. greet без скобок — это просто «упоминание» функции, она не сработает. Нужно greet().

function greet() {
  console.log("Салом!");
}

greet;               // ничего не произойдёт — функцию не вызвали
console.log(greet);  // → ƒ greet() — выводится сама функция, а не результат
greet();             // → Салом!

02 Function Expression

В JavaScript функция — это такое же значение, как число или строка. А любое значение можно положить в переменную. Этот способ называется Function Expression — «функциональное выражение».

// Declaration — объявление
function sayHi() {
  console.log("Салом!");
}

// Expression — функция кладётся в переменную
const sayBye = function () {
  console.log("Хайр, то пагох!");
};

sayHi();   // → Салом!
sayBye();  // → Хайр, то пагох!

Посмотрите внимательно на второй вариант:

  • после слова function нет имени — такая функция называется анонимной. Её имя — это имя переменной sayBye;
  • мы используем const, чтобы случайно не перезаписать функцию;
  • в конце стоит точка с запятой ; — потому что это обычное присваивание, как const x = 5;.
Аналогия из жизни

Declaration — это рецепт, напечатанный в книге под заголовком «Оши палав». Expression — тот же рецепт, но записанный на карточке и положенный в коробку с подписью sayBye. Готовить можно по обоим. Разница в том, когда рецепт становится доступен — об этом ниже.

Функция как значение

Раз функция — значение, её можно передать в другую переменную. Обратите внимание: без скобок мы передаём саму функцию, а не вызываем её.

const greet = function (name) {
  console.log(`Салом, ${name}!`);
};

const hello = greet;   // теперь у одной функции два имени
hello("Шахром");       // → Салом, Шахром!
greet("Шахром");       // → Салом, Шахром!

Именно эта идея — «функцию можно передать как значение» — станет главной на следующем уроке, когда мы будем передавать функции в методы массивов map и filter.

Главное отличие: hoisting («поднятие»)

Перед тем как выполнять код, JavaScript быстро просматривает файл и заранее запоминает все функции, объявленные через Declaration. Поэтому их можно вызывать даже выше того места, где они написаны. Это называется hoisting — «поднятие».

showMenu(); // → Меню: самбуса, курутоб, чой — работает, хотя функция ниже!

function showMenu() {
  console.log("Меню: самбуса, курутоб, чой");
}

С Expression так не получится: переменная const появляется только в той строке, где её объявили. До этой строки её просто нет.

showPrices(); // ✖ ошибка: обращаемся к переменной раньше, чем она создана

const showPrices = function () {
  console.log("Самбуса — 5 сомони");
};

Совет

Даже если Declaration позволяет вызывать функцию «до» объявления, лучше так не делать. Код читается сверху вниз: сначала объявили — потом используем. Так его проще понимать и вам, и коллегам, и ИИ-помощнику.

03 Параметры, аргументы и значения по умолчанию

Функция без параметров каждый раз делает одно и то же. Параметры позволяют передавать в неё разные данные — и тогда одна функция работает в разных ситуациях.

Аналогия из жизни

Приложение такси. В нём есть форма с полями «Откуда» и «Куда» — это параметры: место для данных. Когда вы заказываете машину и пишете «Сино» и «Корвон» — это аргументы: конкретные значения, которые попали в эти поля. Форма одна, а поездки каждый раз разные.

Параметр
Имя в скобках при объявлении функции: function orderTaxi(from, to). Внутри функции это обычная переменная.
Аргумент
Конкретное значение при вызове: orderTaxi("Сино", "Корвон").
function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Сино", "Корвон");        // → Такси: Сино → Корвон
orderTaxi("Аэропорт", "Ботсад");    // → Такси: Аэропорт → Ботсад

Порядок имеет значение

Аргументы попадают в параметры строго по порядку: первый — в первый, второй — во второй. Имена переменных при вызове роли не играют.

function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Корвон", "Сино");   // → Такси: Корвон → Сино — поменяли местами, поехали в обратную сторону!

Если аргументов меньше или больше

JavaScript не ругается, если аргументов передали не столько, сколько параметров:

  • не хватает аргумента — параметр получает значение undefined («не определено»);
  • лишние аргументы — просто игнорируются.
function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Сино");                          // → Такси: Сино → undefined
orderTaxi("Сино", "Корвон", "с кондиционером"); // → Такси: Сино → Корвон

Значения по умолчанию

Чтобы вместо undefined было что-то осмысленное, параметру можно задать значение по умолчанию прямо в скобках, через знак =. Оно сработает, только если аргумент не передали.

function greet(name = "гость") {
  console.log(`Салом, ${name}!`);
}

greet("Далер");  // → Салом, Далер!
greet();         // → Салом, гость!

function makeTea(sort = "зелёный", sugar = 0) {
  console.log(`Чой: ${sort}, сахара: ${sugar} ложки`);
}

makeTea();                 // → Чой: зелёный, сахара: 0 ложки
makeTea("чёрный");         // → Чой: чёрный, сахара: 0 ложки
makeTea("чёрный", 2);      // → Чой: чёрный, сахара: 2 ложки
makeTea(undefined, 2);     // → Чой: зелёный, сахара: 2 ложки

Обратите внимание на последнюю строку. Чтобы «пропустить» первый аргумент и задать второй, передают undefined — тогда сработает значение по умолчанию.

Ловушка

Значение по умолчанию срабатывает только для undefined. Если передать 0, "" (пустую строку) или null — будет использовано именно это значение, а не значение по умолчанию.

function setVolume(level = 50) {
  console.log("Громкость:", level);
}

setVolume();          // → Громкость: 50
setVolume(0);         // → Громкость: 0   — ноль это настоящее значение
setVolume(undefined); // → Громкость: 50
Совет

Параметры со значением по умолчанию ставьте в конец списка. Сначала обязательные данные, потом необязательные: function bookTicket(city, seat = "у окна").

04 return — функция возвращает результат

До сих пор наши функции только показывали что-то в консоли. Но чаще функция должна посчитать результат и отдать его нам, чтобы мы могли дальше с ним работать: сложить, сравнить, показать на странице. Для этого есть слово return — «вернуть».

function sum(a, b) {
  return a + b;
}

const result = sum(10, 5);
console.log(result);          // → 15
console.log(sum(2, 3) * 10);  // → 50

Когда функция встречает return, она отдаёт значение туда, где её вызвали. Можно представить, что вызов sum(10, 5) как бы заменяется результатом — числом 15. Поэтому вызов функции можно положить в переменную, подставить в выражение или передать в другую функцию.

Аналогия из жизни

Вы даёте продавцу на Шохмансуре 100 сомони за покупку в 70. Продавец считает и возвращает вам сдачу — 30 сомони. Эти деньги теперь у вас в руках: можно потратить, отложить, пересчитать. Это и есть return. А console.log — это если продавец просто громко скажет «сдача 30!», но денег не даст. Услышали — и всё, использовать нечего.

console.log и return — не одно и то же

Это самая частая путаница у начинающих. Сравните:

Только выводит

Результат показан, но получить его нельзя.

function getChange(paid, price) {
  console.log(paid - price);
}

const change = getChange(100, 70);
// → 30 (вывела сама функция)
console.log("Сдача:", change);
// → Сдача: undefined 😕
Возвращает

Результат можно сохранить и использовать.

function getChange(paid, price) {
  return paid - price;
}

const change = getChange(100, 70);
console.log("Сдача:", change);
// → Сдача: 30 ✓

Правило: если функция что-то считает — пусть возвращает результат через return. А решать, выводить его в консоль или на страницу, будет код, который эту функцию вызвал.

Без return функция возвращает undefined

function doNothing() {
  const x = 5;
}

console.log(doNothing()); // → undefined

return сразу завершает функцию

После return функция прекращает работу. Код ниже него уже не выполнится.

function test() {
  console.log("Шаг 1");
  return "готово";
  console.log("Шаг 2"); // эта строка никогда не выполнится
}

console.log(test());
// → Шаг 1
// → готово

Этим часто пользуются, чтобы выйти из функции пораньше, если что-то не так. Такой приём называют «ранний выход» (guard).

function canEnroll(age) {
  if (age < 14) {
    return "Пока рано: на курс принимают с 14 лет";
  }
  return "Добро пожаловать на курс!";
}

console.log(canEnroll(12)); // → Пока рано: на курс принимают с 14 лет
console.log(canEnroll(17)); // → Добро пожаловать на курс!

Заметьте: else здесь не нужен. Если первое условие сработало, функция уже вышла на первом return и до второго не дойдёт.

Функция может вернуть true или false

Функции-проверки обычно возвращают логическое значение. Их принято называть с is, has или can в начале:

function isAdult(age) {
  return age >= 18;
}

console.log(isAdult(20)); // → true
console.log(isAdult(15)); // → false

if (isAdult(19)) {
  console.log("Можно получить водительские права");
}

Функции работают вместе

Результат одной функции можно сразу передать в другую. Так из маленьких простых функций собирают большие программы.

function getTotal(price, count) {
  return price * count;
}

function addDelivery(total) {
  return total + 10;
}

const order = addDelivery(getTotal(35, 3)); // 3 курутоба по 35 + доставка 10
console.log(`К оплате: ${order} сомони`);  // → К оплате: 115 сомони
Ловушка

Не переносите значение на следующую строку после return. JavaScript сам поставит точку с запятой сразу после слова return, и функция вернёт undefined.

function getCity() {
  return
    "Душанбе";
}

console.log(getCity()); // → undefined — значение «потерялось»

05 Стрелочные функции

Стрелочная функция (arrow function) — это короткая запись Function Expression. Своё название она получила из-за знака =>, похожего на стрелку. В современном коде, в React и в коде, который пишет ИИ, вы будете встречать её постоянно.

Превращаем обычную функцию в стрелочную — по шагам

  1. Исходная функция — Expression 
    const double = function (n) {
  return n * 2;
};
  2. Убираем слово function, после скобок ставим стрелку => 
    const double = (n) => {
  return n * 2;
};
  3. Если в теле только return — убираем фигурные скобки и само слово return. Значение вернётся автоматически. 
    const double = (n) => n * 2;
  4. Если параметр ровно один — можно убрать и круглые скобки 
    const double = n => n * 2;

Все четыре варианта делают одно и то же. Проверьте:

const double = n => n * 2;

console.log(double(5));   // → 10
console.log(double(21));  // → 42

Правила записи

СитуацияКак пишем
Нет параметровconst hi = () => "Салом!"; — скобки обязательны
Один параметрconst double = n => n * 2; — скобки можно опустить
Несколько параметровconst sum = (a, b) => a + b; — скобки обязательны
Одно выражениеБез { } — результат возвращается сам
Несколько строкС { } — и тогда return пишем сами
 
const sayHi = () => "Салом!";
const sum = (a, b) => a + b;
const isEven = n => n % 2 === 0;

// несколько строк — нужны фигурные скобки и return
const getBill = (price, people) => {
  const tip = price * 0.1;
  return (price + tip) / people;
};

console.log(sayHi());          // → Салом!
console.log(sum(7, 8));        // → 15
console.log(isEven(10));       // → true
console.log(getBill(200, 4));  // → 55
Частая ошибка

Поставить фигурные скобки и забыть return. Как только появились { }, автоматический возврат исчезает — функция вернёт undefined.

Ошибка 
const triple = n => { n * 3 };
console.log(triple(4)); // → undefined
Правильно 
const triple = n => n * 3;
console.log(triple(4)); // → 12

Когда какую функцию использовать

  • Стрелочная — для коротких функций и особенно когда функцию передают в другую функцию. На следующем уроке вы увидите, как красиво они смотрятся в методах массивов: prices.map(p => p * 2).
  • Declaration — для крупных, «главных» функций программы, у которых важное имя.
  • У стрелочных функций есть одна особенность, связанная со словом this. Её мы разберём на уроке про объекты, а пока просто запомните, что она существует.
ИИ-подсказка

ИИ почти всегда пишет код на стрелочных функциях. Если видите непонятную стрелку, попросите: «Перепиши эту стрелочную функцию в обычный Function Declaration и объясни разницу». Сравнить два варианта бок о бок — лучший способ понять запись.

06 Область видимости

Область видимости (scope) отвечает на вопрос: в каком месте кода переменная «видна» и её можно использовать. От этого зависит, почему иногда код выдаёт ошибку is not defined, хотя переменная «вот же она, написана».

Аналогия из жизни

Представьте многоэтажный дом. Двор — общий: детскую площадку видят все жильцы. Квартира — личная: находясь в квартире, вы видите и свои вещи, и (из окна) двор. Но соседи со двора не видят, что лежит у вас на столе. Так и в коде: изнутри видно наружу, а снаружи внутрь — нет.

1. Глобальная область

Переменные, объявленные вне всех функций и блоков. Видны везде в программе.

const academy = "Ilmhona";

function showAcademy() {
  console.log(`Учимся в ${academy}`); // функция видит глобальную переменную
}

showAcademy();         // → Учимся в Ilmhona
console.log(academy);  // → Ilmhona

2. Область функции (локальная)

Переменные, объявленные внутри функции, существуют только внутри неё. Параметры функции — тоже локальные переменные. Снаружи их не видно.

function makeOrder() {
  const dish = "оши палав";
  console.log(`Заказ: ${dish}`);
}

makeOrder();       // → Заказ: оши палав
console.log(dish); // ✖ ReferenceError: dish is not defined

Это не баг, а очень полезное свойство. Каждая функция — как отдельная квартира: можно спокойно называть переменные внутри, не боясь, что они «перепутаются» с переменными в другой функции.

function morning() {
  const message = "Субх ба хайр!";
  console.log(message);
}

function evening() {
  const message = "Шаб ба хайр!"; // такое же имя — никакого конфликта
  console.log(message);
}

morning(); // → Субх ба хайр!
evening(); // → Шаб ба хайр!

3. Блочная область

Любые фигурные скобки { } — в if, for, while — тоже создают свою область. Переменные let и const, объявленные в блоке, видны только внутри этого блока.

const score = 92;

if (score >= 86) {
  const grade = 5;
  console.log("Оценка внутри блока:", grade); // → Оценка внутри блока: 5
}

console.log(typeof grade); // → undefined — снаружи блока grade не существует

Затенение: одинаковые имена

Если внутри функции объявить переменную с тем же именем, что и снаружи, внутренняя закроет («затенит») внешнюю. Внешняя при этом не меняется.

const weather = "солнечно";

function showMountainWeather() {
  const weather = "снег"; // своя, локальная переменная
  console.log("В Варзобе:", weather);
}

showMountainWeather();             // → В Варзобе: снег
console.log("В Душанбе:", weather); // → В Душанбе: солнечно

JavaScript ищет переменную изнутри наружу: сначала в текущей области, потом в той, что снаружи, и так до глобальной. Берёт первую найденную. Если не нашёл нигде — ошибка is not defined.

Как достать значение из функции наружу

Правильный способ — return. Функция возвращает значение, а мы сохраняем его в переменную снаружи.

function getDish() {
  const dish = "оши палав";
  return dish;
}

const myDish = getDish();
console.log(myDish); // → оши палав
Важно: а как же var?

В старом коде (и иногда в ответах ИИ) встречается var. Он не подчиняется блочной области — «протекает» за фигурные скобки if и for. Из-за этого возникают трудноуловимые ошибки. В современном коде пишем только const (по умолчанию) и let (если значение будет меняться).

if (true) {
  var oldStyle = "я протёк наружу";
  let newStyle = "я остался внутри";
}

console.log(oldStyle);        // → я протёк наружу
console.log(typeof newStyle); // → undefined
Совет

Объявляйте переменную в самой маленькой области, где она нужна. Глобальные переменные может случайно изменить любая функция в программе — и потом очень трудно найти, кто это сделал. Чем меньше глобальных переменных, тем спокойнее жизнь.

1) Прочитайте условие дважды. 2) Выпишите, что функция получает (параметры) и что возвращает. 3) Решите на конкретном примере в уме или на бумаге. 4) Только потом пишите код — и проверяйте его кнопкой «Запустить» после каждого шага.

ЗАДАЧА 7.1

Счёт в чайхоне

средняя

Компания друзей поужинала в чайхоне. Напишите функцию splitBill(total, people, tipPercent), которая возвращает, сколько должен заплатить каждый с учётом чаевых. Чаевые по умолчанию — 10%. Результат округлите до целого числа с помощью Math.round().

// function splitBill(...) { ... }

console.log(splitBill(360, 4));
console.log(splitBill(250, 3, 15));
console.log(splitBill(500, 5, 0));
Ожидаемый результат
99
96
100
Подсказка 1

Порядок действий: посчитать чаевые → прибавить к сумме → разделить на количество людей → округлить.

Подсказка 2

Сумма с чаевыми: total + total * tipPercent / 100. Обратите внимание на третий вызов: 0 — это настоящее значение, значение по умолчанию тут не сработает (и не должно).

ЗАДАЧА 7.2

Погода в Душанбе

средняя

Напишите две функции. Стрелочная toFahrenheit(c) переводит градусы Цельсия в Фаренгейты по формуле c × 9 / 5 + 32. Функция describeWeather(c) использует первую и возвращает строку: от 30 °C и выше — жарко, от 15 — тепло, ниже — прохладно. Используйте ранний return.

// const toFahrenheit = ...
// function describeWeather(c) { ... }

console.log(describeWeather(38));
console.log(describeWeather(22));
console.log(describeWeather(5));
Ожидаемый результат
38°C (100.4°F) — жарко
22°C (71.6°F) — тепло
5°C (41°F) — прохладно
Подсказка 1

Сначала посчитайте Фаренгейты в переменную внутри describeWeather, чтобы не вызывать функцию несколько раз.

Подсказка 2

Проверки идут от большей температуры к меньшей: if (c >= 30) return ...; затем if (c >= 15) return ...;, а последний return — для всех остальных случаев.

ЗАДАЧА 7.3

Ведомость экзамена

сложная

Преподаватель переводит баллы (от 0 до 100) в оценки: 86 и выше — 5, от 71 — 4, от 56 — 3, ниже — 2. Напишите:

  • getGrade(score) — возвращает оценку числом;
  • isPassed(score) — стрелочная, возвращает true, если оценка 3 и выше (используйте getGrade внутри);
  • report(name, score) — возвращает строку для ведомости, используя обе функции.
// function getGrade(score) { ... }
// const isPassed = ...
// function report(name, score) { ... }

console.log(report("Рустам", 87));
console.log(report("Зарина", 72));
console.log(report("Шахром", 56));
console.log(report("Далер", 50));
Ожидаемый результат
Рустам: 87 баллов, оценка 5 — сдал
Зарина: 72 баллов, оценка 4 — сдал
Шахром: 56 баллов, оценка 3 — сдал
Далер: 50 баллов, оценка 2 — пересдача
Подсказка 1

Начните с getGrade и проверьте её отдельно: console.log(getGrade(90)). Только когда она работает — переходите к следующей функции. Так строят программы из маленьких надёжных кирпичиков.

Подсказка 2

isPassed в одну строку: score => getGrade(score) >= 3. В report слово «сдал» или «пересдача» удобно выбрать тернарным оператором: isPassed(score) ? "сдал" : "пересдача".

✓ Шпаргалка урока

  • Функция — именованный кусок кода. Объявили один раз — вызываем сколько угодно: greet().
  • Declaration: function greet() {} — можно вызвать до объявления (hoisting).
  • Expression: const greet = function () {}; — функция как значение в переменной, доступна только после объявления.
  • Стрелочная: const double = n => n * 2; — без { } результат возвращается сам; с { } нужен return.
  • Параметры — имена при объявлении, аргументы — значения при вызове. Передаются по порядку. Не передали — undefined.
  • По умолчанию: function f(x = 10) — срабатывает только для undefined.
  • return отдаёт результат и сразу завершает функцию. Без него функция возвращает undefined. Считаем — возвращаем, а не выводим.
  • Область видимости: изнутри видно наружу, снаружи внутрь — нет. let/const живут в своих { }. var не используем.
