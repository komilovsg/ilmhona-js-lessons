# HOME-SPEC — course board on the home page

Status: approved by owner 2026-10-27 (all 7 blocks). Implement AFTER the three-course architecture (frontend, vibe-coding, react-next) is merged. Read `docs/course/vibe-coding/ARCH-SPEC.md` and `docs/course/react-next/ARCH-SPEC.md` first; their "Must NOT change" rules still apply (lesson URLs, progress keys/store, lesson pages, mentor prompts).

## Routing
- `/{ru,tj}` → NEW course board (this spec).
- Frontend + ИИ roadmap moves from `/{locale}` to `/{locale}/frontend-ai`: `Course.base` for frontend becomes `'/frontend-ai'` for the ROADMAP only. Lesson URLs stay `/{locale}/lessons/<slug>` (do NOT change — progress links, SEO, shared links). So split the concept: `courseHome(c)` = roadmap URL (`/frontend-ai`, `/vibe-coding`, `/react-next`); `lessonHref` for frontend keeps `/lessons/<slug>`. `courseFromPath`: `/lessons/*` and `/frontend-ai` → frontend.
- Old roadmap page content: move `app/[locale]/page.tsx` (frontend roadmap + its JSON-LD Course) to `app/[locale]/frontend-ai/page.tsx` unchanged in output (only canonical/sub path changes). Add OG/twitter images there (copy existing home ones for frontend).
- Header: logo → board `/{locale}`; «Карта курса» → current course roadmap (`courseHome`); on the board itself the map link is hidden (no current course) and lesson switcher/XP badge show nothing course-specific (XP badge may show total XP — keep it simple: hide course-specific parts on the board).
- Sitemap: add `/{l}/frontend-ai`; keep `/{l}`.
- No redirect needed: `/ru` still exists (board). Old bookmarks to `/ru` land on the board — fine.

## Board page `app/[locale]/page.tsx` → `components/home/*`
Visual language: existing design system only (tokens, fonts, radii, card styles from `app/globals.css`, roadmap hero look). Light/dark. Mobile-first, 375px no overflow. Animations: existing stack (GSAP via @gsap/react is installed; CSS preferred for simple things). Respect `prefers-reduced-motion`. Texts ru + tg in `messages/*` (new `home` section; TypeScript enforces parity).

1. **Hero with stairs animation — two variants by theme (owner decision):** LIGHT theme shows Variant A (isometric stairs + walking figure that celebrates on the summit, `<scratchpad>/steps-anim-v2/a.html`), DARK theme shows Variant B (logo stair line drawing itself with glowing dot and course cards, `b.html`). Render both, switch with CSS on the site's theme (`[data-theme]` + `prefers-color-scheme` exactly like the rest of globals.css) so there is no hydration mismatch; run the GSAP timeline only for the visible one (check `getComputedStyle(el).display` / matchMedia + theme change listener) and kill the other. Port into `components/home/StepsHero.tsx` (A) and `components/home/StepsLine.tsx` (B) (inline SVG + CSS module or globals block; CSS vars from the site theme, so it follows `data-theme`). Step labels = the three course names from `COURSES` (localised). Next to it: kicker «MakeFirstStep», h1 «Сделай первый шаг» (tg «Қадами аввалро гузор»), lead (1–2 sentences: learn programming and AI step by step, with auto-checked practice and a mentor), primary button «Выбрать курс» (scrolls to #courses), secondary link «Не знаю, с чего начать» (scrolls to #quiz).
2. **Continue where you left off** (client, only if progress exists). Derive from the store, no new storage: take the most recent `solvedAt` across all keys → course by key prefix (`ownsKey`) → lesson. If that lesson has unsolved tasks → continue it; else → next available lesson in that course (if none → that course roadmap). Card: course chip, «Урок N · Title», solved/total, progress bar, button «Продолжить →». Hydration-safe (render after mount / `useSyncExternalStore` server snapshot = empty).
3. **Course board** `#courses`: one card per course in ladder order: Vibe Coding (badge «С нуля»), Frontend + ИИ («Уровень 2»), React Pro + Next.js («Уровень 3»). Card content from course `texts` (add to frontend's texts in the registry layer if missing — do NOT edit `content/course.ts`; put frontend texts in `lib/courses.ts` or a new `content/frontend-texts.ts`): name, level badge, for whom (1 line), lessons count / weeks (24 · 8 недель), «Что получится» (1 line), available lessons count («доступно N из 24»), personal progress % (client) and CTA «Начать» / «Продолжить» → course roadmap. Visual ladder: on desktop cards are offset upward step by step (subtle, CSS transform/margin), connected by a stair line in the logo style; on mobile a simple vertical list.
4. **Course picker quiz** `#quiz`: 3 single-choice questions (ru+tg): (a) Программировали раньше? нет / немного / да; (b) Знаете HTML/CSS и JavaScript? нет / HTML/CSS / и JS тоже / и React; (c) Чего хотите? быстро собирать продукты с ИИ / стать фронтенд-разработчиком / профессиональный React и Next.js. Deterministic rule (document it in code): React known or (JS known and goal=pro) → react-next; JS or HTML known and goal=frontend → frontend; otherwise goal=products or no experience → vibe-coding; ties → the lower level. Result: highlights the matching card (scroll + accent outline) and shows a one-line reason + CTA. Pure client, no storage needed (optional: remember last answer in `mfs:` key — skip).
5. **How learning works**: 3 steps in a row (stairs motif numbers 1-2-3): «Теория и видео» → «Задачи с автопроверкой» → «XP, уровни и достижения», plus a 4th small note about the AI mentor («подсказывает, но не решает за вас»). Icons: reuse `components/roadmap/icons.tsx` or simple inline SVG.
6. **Mini leaderboard**: top-5 via the existing `leaderboard` RPC (signed-in only, as on /leaderboard — reuse its fetching code; extract a small shared hook if needed rather than duplicate). Anonymous: a card «Войдите, чтобы попасть в рейтинг» with the existing sign-in action. Respect `show_on_leaderboard`/pseudonyms exactly as the full page. Link «Весь рейтинг →». All-time (no weekly — would need a migration).
7. **Your stats** (client, only if progress exists): total XP and level (`lib/game.ts` on full progress), streak, achievements count across all courses, per-course XP mini row. No new calculations beyond existing game helpers.

SEO/meta for `/`: title «MakeFirstStep — курсы программирования и ИИ шаг за шагом» (tg equivalent), description, JSON-LD `ItemList` of the three `Course`s (url = course roadmaps). OG image: new board variant in `lib/og.tsx` (heading «Сделай первый шаг», stairs), keep frontend OG at `/frontend-ai`.
