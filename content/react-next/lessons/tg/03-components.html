01 JSX ва унсурҳо: компонент воқеан чӣ бармегардонад

JSX — на HTML ва на қолаб аст. Ин синтаксиси JavaScript аст, ки ҳангоми ҷамъкунӣ ба даъвати функсияҳо табдил меёбад. Vite инро худкор мекунад: <h1>Navruz</h1>-и шумо ба даъвати jsx('h1', …) аз бастаи react/jsx-runtime табдил меёбад. Натиҷаи даъват — унсури React: объекти оддӣ, ки тавсиф мекунад, чиро нишон додан лозим. Ин на пораи DOM аст ва на HTML-и тайёр.

const element = <h1 className="title">Navruz</h1>

// после сборки это вызов jsx('h1', { className: 'title', children: 'Navruz' }),
// а в итоге обычный объект примерно такого вида:
const sameElement = {
  type: 'h1',
  props: { className: 'title', children: 'Navruz' },
}

Унсурро арзон сохтан мумкин аст ва онро тағйир додан намешавад: барои нишон додани чизи дигар, компонент танҳо объекти нав бармегардонад. Аз чунин объектҳо дарахт сохта мешавад, ки React онро баъд бо пештара муқоиса мекунад ва фарқиятҳоро ба DOM интиқол медиҳад (бахши 4).

Намоиши шартӣ ва он чизе, ки React намекашад

Се роҳи нишон додани чизе аз рӯи шарт: оператори сегона ({open ? <Open /> : <Closed />}), оператори && ({open && <Badge />}) ва return null-и барвақтӣ дар аввали компонент. Қиматҳои null, undefined, true ва false-ро React фурӯ мегузорад, сатр ва рақамҳоро ҳамчун матн мекашад. Объектро кашидан мумкин нест: React бо хато қатъ мешавад.

Унсури React — варақаи фармоиш дар чойхона аст: дар он навишта шудааст «палав, чой, ду самбӯса». Варақа хӯрок нест, онро зуд навиштан ва партофтан мумкин аст. Шумо варақаи кӯҳнаро тағйир намедиҳед, балки нав менависед, ва ошпаз (React) онҳоро муқоиса карда, ҳал мекунад, ки чиро ба дастархон бурдан лозим.

ВАЗИФАИ 1.1

Худро санҷед: JSX

осон

Компоненти function Card() { return <h1>Navruz</h1> } чӣ бармегардонад?

  1. Сатр бо коди HTML "<h1>Navruz</h1>"
  2. Унсури DOM-и тайёр, ки ба саҳифа гузошта шудааст
  3. Унсури React: объекти оддӣ, ки тавсиф мекунад, чиро нишон додан лозим
  4. Ҳеҷ чиз: компонент танҳо саҳифаро тағйир медиҳад

Компонент худаш чизеро ба саҳифа намегузорад. Он тавсиф (унсур) бармегардонад, ва DOM-ро дар қадами коммит React нав мекунад.

Компонент reviews = 0 гирифт ва <p>{reviews && <b>есть отзывы</b>}</p>-ро баргардонд. Дар саҳифа чӣ пайдо мешавад?

  1. Сархати холӣ
  2. Сархат бо рақами 0
  3. Хато: истифодаи && мумкин нест
  4. Сархат бо матни «есть отзывы»

Ифодаи 0 && … ба 0 баробар аст, ва рақамро React мекашад. Натиҷаи холиро танҳо null, undefined, false медиҳанд. Дуруст: reviews > 0 && ….

Кадом сатрҳои JSX хато доранд? Ду варианти ҷавобро интихоб кунед.

  1. <label class="field">Имя</label>
  2. <img src="a.png" alt="" />
  3. <div style={{ color: 'red' }}>Привет</div>
  4. <input type="text">

Дар сатри аввал class бояд className бошад, дар сатри чорум теги input баста нашудааст: бояд <input type="text" /> бошад. Боқиро дуруст навиштаанд.

02 Компонентҳо, props, children ва композитсия

Компоненти функсионалӣ — функсияи оддӣ, ки як объекти props-ро қабул мекунад ва JSX (ё агар нишон додан чизе набошад, null) бармегардонад. Он ду қоидаи сахт дорад: ном бо ҳарфи калон ва даъват танҳо тавассути нишонагузорӣ (<Card />, на Card()). Ҳарфи хурд маънои «ин теги HTML аст»-ро дорад.

src/Bad.tsx(9,10): error TS2339: Property 'restaurantCard' does not exist on type 'JSX.IntrinsicElements'.
<restaurantCard /> is using incorrect casing. Use PascalCase for React components, or lowercase for HTML elements.

Сатри якум — хатои TypeScript, сатри дуюм — огоҳии React дар консоли браузер. Props танҳо хонда мешаванд: қиматҳои пешфарзро дар параметрҳо месупоранд, ва тағйир додани props мумкин нест (бахши 5).

type RatingProps = {
  value: number
  max?: number // необязательный prop
}

export default function Rating({ value, max = 5 }: RatingProps) {
  return (
    <span>
      ★ {value.toFixed(1)} / {max}
    </span>
  )
}

children ва композитсия

children — ҳама он чизест, ки байни тегҳои кушодашаванда ва пӯшидашавандаи компонент гузоштаед. Ҳамин тавр «печонакҳо» месозанд: Layout, Card, Modal, ки медонанд, чӣ тавр намоён шаванд, аммо намедонанд, дар дохил чӣ ҳаст. Навъи children — ReactNode (онро дар дарси 2 омӯхтед): ҳама чизеро, ки React нишон дода метавонад, қабул мекунад. Аз сабаби парчами verbatimModuleSyntax (дарси 1) онро ҳамчун навъ ворид кунед.

import type { ReactNode } from 'react'

type LayoutProps = {
  header: ReactNode // слот: любой JSX
  children: ReactNode // основное содержимое
  footer?: ReactNode
}

export default function Layout({ header, children, footer }: LayoutProps) {
  return (
    <div>
      <header>{header}</header>
      <main>{children}</main>
      {footer && <footer>{footer}</footer>}
    </div>
  )
}

// использование:
// <Layout header={<Logo />} footer={<Contacts />}>
//   <RestaurantList />
// </Layout>

Композитсия аз «танзимот» беҳтар аст: ба ҷои компонент бо даҳ парчами prop (showHeader, showLogo, isCompact…) ба он слотҳо медиҳед, ва худи саҳифа ҳал мекунад, чиро нишон диҳад. Ин усули асосии React ба ҷои мерос аст.

Компонентро дар дохили компонент эълон накунед

Агар function Counter()-ро бевосита дар бадани App нависед, ҳангоми ҳар аз нав кашидани App функсияи нави Counter сохта мешавад. Барои React ин аллакай компоненти дигар аст: кӯҳна бо ҳолати худ нест мешавад, нав аз сифр сохта мешавад. Аломат: «ҳолат вақте барқарор мешавад, ки чизе дар беруна тағйир меёбад». Компонентҳоро дар сатҳи боло дар файл эълон кунед, беҳтараш дар файли алоҳида: як компонент — як файл, номи файл бо номи компонент мувофиқ аст.

Хатоҳои маъмул

1. Компонентро ҳамчун функсия даъват кардан ({Rating({ value: 4 })}) ба ҷои <Rating value={4} />: ҳукҳо ва ҳолат ин тавр кор намекунанд. 2. Компонент дар дохили компонент (дар боло бинед). 3. Ба children маълумоти нолозим додан: объект ба ҷои JSX хатои «Objects are not valid as a React child» медиҳад. 4. Компоненти «комбайн» дар 400 сатр сохтан: ҳудуди компонентро дар бахши 7 таҳлил мекунем. 5. Дар як файл компонент ва собитҳо ё функсияҳои оддиро гузоштан: қоидаи Oxlint react/only-export-components огоҳ мекунад, ки Fast Refresh (ивазкунии гарм) метавонад кор карданро бас кунад.

Ролик бо забони русӣ (октябри 2025, 21 дақиқа): props, интиқоли маълумот ва children. Муаллиф JavaScript нишон медиҳад, шумо ҳамин усулҳоро бо навъҳо (ReactNode) доред.

Монанд аз ҳаёт

Layout — дастархон аст: суфра, болиштҳо, чойник дар миёна. Он барои ҳар зиёфат якхела аст. Имрӯз ба он чӣ меоранд (палав ё самбӯса), соҳибхона ҳал мекунад, ва ин children аст. Слотҳои header ва footer — ҷойҳо барои «оғоз» ва «анҷоми» зиёфат: чой дар аввал ва ширинӣ дар охир.

осон

Чаро компоненти function badge()-ро бо ҳарфи хурд ҳамчун <badge /> истифода бурдан мумкин нест?

  1. Зеро дар JavaScript функсияҳоро бо ҳарфи хурд номидан мумкин нест
  2. Зеро JSX тегҳои бо ҳарфи хурдро унсурҳои HTML мешуморад, на компонент
  3. Зеро React 19 калимаи badge-ро манъ кардааст
  4. Зеро компонент бояд ҳатман функсияи тирдор бошад

Номи бо ҳарфи хурдро JSX ба сатри 'badge' (теги HTML) табдил медиҳад, ва бо ҳарфи калонро — ба истинод ба функсияи шумо. Барои ҳамин Badge.

Дар навишти <Card title="Плов"><p>28 сомони</p></Card> ба children-и компонент чӣ мефарояд?

  1. Сатри «Плов»
  2. Тамоми компоненти Card

04 Кай ва чӣ тавр React компонентро аз нав мекашад

«Рендер» — калимаи аз ҳама зиёд сарбор дар React аст. Биёед онро ба се қадам ҷудо кунем. Триггер: чизе намоишро талаб кард (оғози аввал тавассути createRoot().render() ё тағйирёбии ҳолат тавассути setState). Рендер: React функсияҳои компонентҳои шуморо даъват мекунад ва дарахти нави унсурҳоро мегирад. Ин танҳо ҳисобкунӣ аст, экран ҳоло ламс нашудааст. Коммит: React дарахти навро бо пештара муқоиса мекунад ва ба DOM танҳо фарқиятҳоро ворид мекунад. Агар чизе фарқ накунад, DOM умуман ламс намешавад.

Ролик бо забони русӣ (соли 2023, 10 дақиқа): марҳилаҳои render ва commit дар мисолҳо. Ғоя дар React 19 тағйир наёфтааст.

Ҳолат — ин акс аст

Ҳар рендер қиматҳои худи props ва ҳолатро мебинад: онҳо дар лаҳзаи даъвати функсия «яхкарда» мешаванд. setQty(qty + 1) тағйирёбандаи qty-ро ҳамин лаҳза иваз намекунад, балки аз React хоҳиш мекунад, ки рендери нав бо қимати нав иҷро кунад. Барои ҳамин се даъвати пай дар пай як qty-ро мегиранд.

const [qty, setQty] = useState(0)

function addThree() {
  setQty(qty + 1) // qty здесь равно 0 → попросили 1
  setQty(qty + 1) // qty всё ещё 0 → попросили 1
  setQty(qty + 1) // и снова 1
}
// после клика на экране 1, а не 3

function addThreeRight() {
  setQty((q) => q + 1) // функция получает последнее значение из очереди
  setQty((q) => q + 1)
  setQty((q) => q + 1)
}
// после клика на экране 3

Чӣ аз нав кашида мешавад

Компонент аз нав рендер мешавад, вақте ки ҳолати худаш тағйир ёфт ё волидаш аз нав кашида шуд. Банди дуюм муҳим аст: ба таври пешфарз React ҳамаи авлоди компонентеро, ки ҳолаташ тағйир ёфтааст, аз нав мекашад, ҳатто агар props-и онҳо ҳамон монда бошанд. Ин даҳшатнок нест: рендер — даъвати арзони функсия аст, ва коммит ба ҳар ҳол танҳо фарқиятҳои воқеиро ламс мекунад. Аксар вақт чизеро беҳтар кардан лозим нест. Агар компоненти вазнин бе зарурат ба ҳар клик рендер шавад, доруи аввал аз ҳама оддӣ аст — ҳолатро поёнтар фуроварда: он қисматеро, ки ба ҳолат ниёз дорад, ба компоненти хурди алоҳида баред. Абзорҳо чун React.memo, Profiler ва React Compiler-ро дар дарсҳои 6 ва 12 таҳлил мекунем.

Боз се далел дар бораи рендер. 1. Агар setQty-ро бо ҳамон қимат даъват кунед (муқоиса тавассути Object.is), React аз нав кашиданро мегузаронад. Массиви нав ё объект бо ҳамон мундариҷа аллакай қимати нав аст. 2. Дар реҷаи dev бо StrictMode (он дар main.tsx-и шумо ҳаст) React ҳар компонентро ду маротиба даъват мекунад, то функсияҳои ғайритозаро ошкор кунад (бахши 5). Барои ҳамин console.log дар компонент ду маротиба чоп мешавад (агар React DevTools насб шуда бошад, даъвати дуюм хокистарӣ нишон дода мешавад). Дар созмони барои истифодабарандагон даъвати дугона нест. 3. Тағйир додани ҳолат бе setState (масалан, items.push(x)) рендерро умуман оғоз намекунад: React аз тағйирёбӣ огоҳ намешавад. Дар бораи навсозии дурусти объектҳо ва массивҳо дар дарси 4 сухан меравем.

Пешхизмат он чиро, ки аллакай рӯи миз аст, муқоиса мекунад ва танҳо навро меорад: ин коммит. Ошпаз метавонад таомро ду бор тайёр кунад (StrictMode), аммо меҳмон як бор мегирад.

Тасаввуроти хато

1. «Рендер — вақте ки экран нав мешавад». Не, экранро коммит нав мекунад, ва танҳо агар фарқият бошад. 2. «setState тағйирёбандаро фавран иваз мекунад». На ҳатман. 5. «console.log-и дугона — хато». Не, ин StrictMode дар dev аст.

ВАЗИФАИ 4.1

Худро санҷед: модели рендер

миёна

Дар қадами «рендер» чӣ рӯй медиҳад?

  1. React унсурҳои навро ба DOM-и браузер мегузорад
  2. Браузер пикселҳоро дар экран мекашад
  3. React функсияҳои компонентҳоро даъват мекунад ва дарахти унсурҳоро мегирад, DOM дар ин ҳангом тағйир намеёбад

Ҳудуди компонент дар куҷо мегузарад

  1. Такрор мешавад. Агар порчаи экран бисёр маротиба нишон дода шавад (корт, нишон), ин компонент аст: он як маротиба навишта мешавад, ва маълумот тавассути props меравад.
  2. Ном ва як масъулият дорад. Шумо метавонед онро бо як калима ном баред ва бигӯед, ки вай чӣ мекунад, бе «ва». «Корти тарабхона» — ҳа, «корт ва филтр ва сабад» — не.
  3. Ба наздикӣ ҳолати худро мегирад. Дар дарси 4 дар феҳрист филтрҳо пайдо мешаванд, ва корт «писандидашуда» мегирад: чунин порча useState-и худро дорад, ва беҳтар аст фавран ба он ҳудуд диҳед («ҳолатро поёнтар фуроред»-ро аз бахши 4 ба ёд оред).
  4. Сохтори маълумот сохтори компонентҳоро нишон медиҳад. Массиви тарабхонаҳо — ин RestaurantList аст, як объект — RestaurantCard.
  5. Барои ҷудокунӣ ҷудо накунед. Компоненти якхатта бе такрор ва бе маънои худ танҳо хонданро мушкил мекунад. Аломати аз ҳад гузаштан: 6–7 props, ки танҳо ба поён интиқол дода мешаванд.
Формулаи промпт: контекст → вазифа → маҳдудиятҳо → формат → санҷиш

Ду дархостро муқоиса кунед. Хубаш ошкоро хоҳиш мекунад, ки аввал танҳо дарахт, бе код, ва агентро водор мекунад, ки ҳар ҳудудро асоснок кунад. Ин агентро ба рақиб табдил медиҳад, ки бо вай баҳс кардан мумкин аст.

Бо агент баҳс мекунем

Баъди гирифтани дарахт, ба навбат се саволро диҳед ва ҷавобҳоро баҳо диҳед. 1. «Чаро Rating ва Badge компонентҳои алоҳида ҳастанд, на қисми корт?» Ҷавоби хуб ба истифодаи такрорӣ ва экранҳои оянда (меню, сабад) ишора мекунад, бад — «ин тавр қабул шудааст». 2. «Агар RestaurantList ва RestaurantCard-ро ба як компонент муттаҳид кунем, чӣ мешавад?» Ҷавоб бояд дарозӣ, имконнопазирии додани ҳолати худ ба корт ва мушкилоти key-ро зикр кунад. 3. «Layout кадом props-ро мегирад ва чаро children?» Агар агент тавассути Layout маълумоти тарабхонаҳоро интиқол диҳад, вай печонакро бо контейнери маълумот омехта кардааст.

Коди компонентҳои аз агент гирифташударо чӣ тавр санҷидан лозим

  1. key. Дар ҳар map key аз id гузошта шудааст, на аз индекс. Oxlint гузаронидашударо мегӯяд.
  2. Компонент дар дохили компонент. Дар бадани функсия-компоненти дигар function X() нест.
  3. Тағйирдиҳӣ. .sort(), .push(), .reverse() бе нусха дар props ва ҳолат нест.
  4. Навъҳо. any нест, props бо навъ тавсиф шудааст, ReactNode ва навъҳои дигар тавассути import type ворид шудаанд.
  5. Синфҳои Tailwind. Номҳои аз порчаҳо ҷамъшуда (`bg-${x}-600`) нестанд, ду усули услубгузории як хосият нест.
  6. Андоза. Компонент аз 80–100 сатр дарозтар ё бо шаш ва зиёд props: сабаб барои бозгашт ба ҳудудҳо.
  7. Изофа. useState-и нав, useEffect, бастаҳои нав ва React.memo, ки хоҳиш накардаед, нестанд: дар ин дарс мо экранро танҳо ба компонентҳо ҷудо мекунем.

✓ Шпаргалкаи дарс

  • JSX ба даъвати функсияҳо табдил меёбад ва унсурҳо медиҳад: объектҳои-тавсифи оддӣ. Қоидаҳо: як реша (Fragment <>), ҳамаи тегҳо баста, className, style — объект, дар {} танҳо ифодаҳо, номи компонент бо ҳарфи калон.
  • Намоиши шартӣ: оператори сегона, &&, return null. {n && …} ҳангоми n = 0 «0»-ро мебарорад: нависед n > 0 && …. null, undefined, true, false кашида намешаванд, объект — хато.
  • Компонент — функсияест, ки props мегирад ва JSX бармегардонад. children: ReactNode — мундариҷаи байни тегҳо; слотҳо — props бо JSX. Композитсия ба ҷои даҳ парчам. Компонентро дар дохили компонент эълон намекунанд: ҳолат барқарор мешавад.
  • Рӯйхатҳо: filter + map, key аз id дар унсури дохили map, дар байни ҳамсояҳо ягона. Индекс — танҳо барои рӯйхатҳои статикӣ, Math.random() дар калид — ҳеҷ гоҳ. Рӯйхати холиро алоҳида коркард мекунанд.
  • Рендер: триггер (оғози аввал ё setState) → рендер (даъвати функсияҳо) → коммит (фарқиятҳо дар DOM). Ҳолат — акс аст: барои силсилаи навсозиҳо setQty((q) => q + 1). Авлод бо волид аз нав кашида мешавад; корҳои нолозимро аввал бо поёнтар фуровардани ҳолат дур мекунанд. StrictMode дар dev компонентҳоро ду бор даъват мекунад.
  • Тозагӣ: ҳамон props ва ҳолат ҳамон JSX медиҳанд, ҳангоми рендер ба чизи берунӣ даст намезанем. На items.sort(), балки [...items].sort(). Таъсироти иловагӣ — дар коркарди ҳодисаҳо ва дар useEffect (дарси 5).
  • CSS Modules: Ном.module.css, import styles from …, синфҳо маҳаллианд; хатои имло дар styles.x бо навъҳо гирифта намешавад. Tailwind 4: tailwindcss ва @tailwindcss/vite, @import 'tailwindcss', мавзӯъ дар @theme, mobile first (sm:, lg:), синфҳоро пурра менависанд.
  • Ҳудуди компонент: такрор мешавад, як масъулияти номдор, ба наздикӣ ҳолат мегирад, ба сохтори маълумот мувофиқ аст; барои ҷудокунӣ ҷудо накунед. Бо агент: аввал танҳо дарахт, баъд баҳс, баъд код.
  • Лоиҳаи 1 «Дастархон»: 11 компонент: App, Layout, Header, Footer, SearchBox, CuisineFilter, Section, RestaurantList, RestaurantCard, Badge, Rating. Минбаъд: саралакунӣ ва сабад бо useReducer (дарси 4).
ВАЗИФАИ 10.1

Ман мавзӯъро воқеан фаҳмидам

осон

Танҳо он чизеро қайд кунед, ки бе маслиҳат иҷро карда метавонед.

  • Метавонам шарҳ диҳам, ки унсури React чист ва компонент чӣ бармегардонад
  • Метавонам қоидаҳои JSX-ро номбар кунам ва хатогиҳои TS2657 ва TS17008-ро аз рӯи матн ислоҳ намоям
  • Метавонам печонакро бо children ва слотҳо нависам, онро тавассути ReactNode навъбандӣ кунам
  • Метавонам шарҳ диҳам, ки чаро компонентро дар дохили компонент эълон кардан мумкин нест
  • Метавонам рӯйхатро бо key-и дуруст нишон диҳам ва шарҳ диҳам, ки индекс чаро бад аст
  • Метавонам се қадами рендерро тасвир кунам ва пешгӯӣ намоям, ки кадом компонентҳо аз нав кашида мешаванд
  • Метавонам компоненти тоза ва ғайритозаро фарқ кунам ва тағйирдиҳии props-ро ислоҳ намоям
  • Метавонам Tailwind 4-ро ба Vite пайваст кунам ва байни он ва CSS Modules интихоб намоям
  • Метавонам макетро ба дарахти компонентҳо ҷудо кунам ва ҳар ҳудудро асоснок намоям
