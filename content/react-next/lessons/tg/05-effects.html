Дарси 5 · Ҳукҳо, формаҳо, услубҳо

Эффектҳо, ref-ҳо ва боркунии маълумот

Дар охири дарс феҳристи «Дастархон» тарабхонаҳоро на аз файл, балки аз API-и маҳаллии воқеӣ мегирад: бо скелетони боркунӣ, хатои фаҳмо ва тугмаи «Такрор», бо бекоркунии дархостҳои нолозим, бо фокус ба ҷустуҷӯ аз рӯи тугмаи «/» ва ҳаракати саҳифа ба менюи тарабхонаи интихобшуда. Шумо мефаҳмед, ки барои чӣ дар лоиҳа ҳар як useEffect лозим аст, ва он эффектеро, ки лозим нест, хориҷ карда метавонед.

  • Эффектро ҳамчун ҳамоҳангсозӣ бо системаи беруна шарҳ диҳед ва вобастагиҳоро аз рӯи ишораи линтер ҷойгир кунед, бе хомӯш кардани он
  • Тозакунӣ (cleanup)-ро барои таймерҳо, обунаҳо ва дархостҳо нависед ва шарҳ диҳед, ки чаро дар реҷаи таҳия эффект ду маротиба оғоз мешавад
  • Эффектҳои нолозимро ёбед ва хориҷ кунед: маълумоти ҳосилшуда, барқарорсозии ҳолат тавассути key, вокуниш ба клик
  • useRef-ро барои DOM (фокус, ҳаракати саҳифа) ва барои қиматҳое, ки набояд аз нав кашидан ба вуҷуд оранд, истифода баред
  • Маълумотро тавассути fetch ва AbortController бо ҳолатҳои loading, error ва success, ки бо навъи union тавсиф шудаанд, бор кунед
  • Ҷавоби API-ро тавассути unknown ва type guard навъбандӣ кунед, хаторо дар catch танг кунед ва any-ро истифода набаред
Ин дарсро чӣ тавр гузаштан лозим аст

Лозим аст: лоиҳаи dastarkhon баъд аз дарсҳои 3 ва 4 (дарахти 11 компонент бо Tailwind ва CSS Modules, ҷустуҷӯ ва филтр аз рӯи ошхона, сабад ва ҷудосозӣ бо useReducer), терминал, муҳаррир, ду тирезаи терминал ва тақрибан 3,5 соат. Бахшҳои 1–5 — назария бо майдончаҳои зинда: коди дар замина торик навишташударо тағйир додан ва иҷро кардан мумкин аст, ва дар вазифаҳо бояд тавре кунед, ки баромад бо «Натиҷаи интизоршаванда» мувофиқ ояд. Бахши 6 — дар бораи агенти ЗС, бахши 7 — машқ дар лоиҳа, бахши 8 — вазифаи хонагӣ.

Фарз мешавад, ки шумо JavaScript, fetch ва асосҳои useEffect-ро медонед (худсанҷии дарси 1 онро такрор мекунад), инчунин навъҳо ва union-ро аз дарси 2 ва модели рендерро аз дарси 3. Дар ин ҷо эффектҳоро амиқтар мебинем: чӣ тавр сохта шудаанд, кай лозим нестанд ва вақте ки маълумот тавассути шабака меояд, чӣ бояд кард.

01 useEffect: ҳамоҳангсозӣ бо ҷаҳони беруна ва вобастагиҳо

Компонент ҳангоми рендер танҳо JSX-ро ҳисоб мекунад (дарси 3: функсияи тоза). Аммо барнома ба корҳои «лой» низ ниёз дорад: сарлавҳаи варақаро гузоштан, маълумотро тавассути шабака дархост кардан, ба клавиатура обуна шудан, таймерро оғоз кардан. Ҳамаи инро эффектҳо меноманд: кор, ки аз ҳудуди ҳисоб кардани нишонагузорӣ берун мебарояд. Ҳуки useEffect ба React мегӯяд: «баъд аз он ки экранро нишон додӣ, ин функсияро иҷро кун».

Эффектро ҳамчун «рӯйдоди давраи ҳаёт» (componentDidMount аз дастурҳои кӯҳна) тасаввур накунед. Модели дуруст: эффект компонентро бо системаи беруна (шабака, таймер, DOM, API-и браузер) аз рӯи қиматҳои ҷории props ва ҳолат ҳамоҳанг мекунад. Агар қиматҳо тағйир ёфта бошанд, ҳамоҳангсозиро бояд такрор кард. Кадом қиматҳо ба эффект лозиманд, массиви вобастагиҳо мегӯяд.

import { useEffect } from 'react'

type PageTitleProps = { city: string }

export default function PageTitle({ city }: PageTitleProps) {
  useEffect(() => {
    document.title = `Дастархон · ${city}` // внешняя система: вкладка браузера
  }, [city]) // повторять, когда city изменился

  return null
}

Ҳар як қимати «реактивӣ» (prop, ҳолат, тағйирёбанда ё функсия, ки дар бадани компонент сохта шудааст), ки дар дохили эффект хонда мешавад, бояд дар массив бошад. Фаромӯш кардани он маънои эффектеро дорад, ки бо қимати «кӯҳна» кор мекунад. Инро линтер месанҷад: Oxlint аз дарси 1 қоидаи react-hooks/exhaustive-deps-ро дорад.

Ин огоҳиро бо шарҳи // eslint-disable хомӯш накунед: он қариб ҳамеша ба хатои воқеӣ ишора мекунад. Ба ҷои ин кодро тағйир диҳед. Чор роҳи стандартӣ ҳаст:

  1. Қимат ба эффект лозим аст — онро ба вобастагиҳо илова кунед. Эффект такроран оғоз мешавад ва ин дуруст аст: маълумот тағйир ёфтааст.
  2. Қимат тағйир намеёбад (собит, функсия бе замкунӣ) — онро аз ҳудуди компонент бароред ва он ба вобастагиҳо намеафтад.
  3. Эффект танҳо «ҳолати пештара»-ро талаб мекунад — навсозии функсионалӣ setCount((c) => c + 1)-ро истифода баред: худи count-ро хондан лозим намешавад.
  4. Эффект бояд қимати тозаро бихонад, вале бо сабаби он аз нав оғоз нашавад — «рӯйдод»-ро аз эффект тавассути useEffectEvent ҷудо кунед (дар поён).

Объектҳо ва функсияҳо дар вобастагиҳо

Объекте, ки дар бадани компонент сохта шудааст, дар ҳар рендер нав аст, ҳатто агар майдонҳо яканд. Агар чунин объект дар вобастагиҳо бошад, эффект баъд аз ҳар рендер оғоз мешавад. Объектро дар дохили эффект созед ва аз қиматҳои оддӣ вобаста шавед.

type Options = { city: string; onlyOpen: boolean }

function Catalog({ city, onlyOpen }: Options) {
  const options = { city, onlyOpen } // новый объект при каждом рендере

  // Плохо: options каждый раз другой, эффект запускается после каждого рендера
  useEffect(() => {
    load(options)
  }, [options])

  // Хорошо: объект собирается внутри, зависимости — простые значения
  useEffect(() => {
    load({ city, onlyOpen })
  }, [city, onlyOpen])
}

Замкунии кӯҳнашуда (stale closure)

Ҳар рендер нусхаи худи функсияҳо ва қиматҳоро месозад (дарси 3: ҳолат — акс). Эффект бо массиви холӣ қиматҳои рендери аввалро барои ҳамеша «ба ёд мегирад». Доми классикӣ: ҳисобкунак дар setInterval.

import { useEffect, useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const id = setInterval(() => {
      setCount(count + 1); // count здесь всегда 0: замыкание первого рендера
    }, 200);
    return () => clearInterval(id);
  }, []);

  return <p>Секунд: {count}</p>;
}

Ҳисоб то 1 мерасад ва ях мекунад: ҳар тик setCount(0 + 1)-ро иҷро мекунад. Бо навсозии функсионалӣ ислоҳ мешавад: setCount((c) => c + 1) қимати ҷориро аз React мегирад ва вобастагӣ аз count лозим нест.

useEffectEvent: рӯйдод дар дохили эффект

Баъзан эффект бояд қимати тозаро бихонад, аммо ҳангоми тағйири он аз нав оғоз нашавад. Мисол: ҳангоми пайвастшавӣ ба чат огоҳиро бо мавзӯи ҷории тарроҳӣ нишон медиҳем. Тағйири мавзӯъ набояд чатро аз нав пайваст кунад. Аз React 19.2 барои ин useEffectEvent ҳаст: функсияе, ки дар дохили эффект ҳамеша props ва ҳолати тозаро мебинад, аммо худаш вобастагӣ ҳисоб намешавад.

import { useEffect, useEffectEvent } from 'react'

type ChatProps = { roomId: string; theme: 'light' | 'dark' }

export default function Chat({ roomId, theme }: ChatProps) {
  // свежая theme внутри, но в зависимости её добавлять не нужно
  const onConnected = useEffectEvent(() => {
    showToast('Подключено', theme)
  })

  useEffect(() => {
    const connection = createConnection(roomId)
    connection.on('connected', onConnected)
    connection.connect()
    return () => connection.disconnect()
  }, [roomId]) // перезапуск только при смене комнаты

  return null
}

Чунин функсияро танҳо аз дохили эффектҳо даъват кардан мумкин аст, ва онро ба компонентҳои дигар додан мумкин нест. Агар шубҳа дошта бошед, аввал яке аз се ҳалли болоиро кӯшиш кунед: useEffectEvent кам лозим мешавад.

Монанд аз ҳаёт

Эффект — ин маршруткаи бо лавҳаи «Рӯдакӣ — Сино». Лавҳа (вобастагӣ) мегӯяд, ки бо кадом хат мераванд. Хат иваз шуд — ронанда мегардад ва бо хати нав меравад. Массиви холии вобастагиҳо — монанди маршруткаест, ки ҳамеша бо лавҳаи кӯҳна мондааст: мусофирон кайҳо ба ҷои дигар мераванд, ва вай ҳамоно бо хати пештара мебарад.

Хатоҳои маъмул

1. []-и холӣ «то ки такрор нашавад», ҳол он ки эффект props-ро мехонад: маълумоти кӯҳна мегиред. 2. Шарҳи хомӯшкунандаи линтер ба ҷои ислоҳи код. 3. Объект ё функсия аз бадани компонент дар вобастагиҳо: эффект баъд аз ҳар рендер оғоз мешавад. 4. Эффект умуман бе массив ва setState дар дохил: давраи беохири рендерҳо, дар консол Maximum update depth exceeded ё ях кардани варақа. 5. Эффектро «коркардкунандаи рӯйдод» ҳисобидан: вокуниш ба клик бояд дар onClick навишта шавад (бахши 3).

ВАЗИФАИ 1.1

Худро санҷед: эффектҳо ва вобастагиҳо

миёна

Эффект prop-и city ва ҳолати onlyOpen-ро мехонад. Кадом массиви вобастагиҳо дуруст аст?

  1. []: то ки эффект як маротиба кор кунад
  2. [city, onlyOpen]: ҳамаи қиматҳои реактивӣ, ки эффект мехонад
  3. [city]: ҳолатро нишон надодан мумкин аст
  4. Бе массив: ин боэътимодтар аст

Вобастагиҳоро коди эффект муайян мекунад, на хоҳиши «камтар оғоз кардан». Бо массиви холӣ эффект қиматҳои рендери аввалро барои ҳамеша ба ёд мегирад, бе массив баъд аз ҳар рендер оғоз мешавад.

Эффект бо [options], ки дар он const options = { city } дар бадани компонент эълон шудааст, баъд аз ҳар рендер оғоз мешавад. Кадом ислоҳҳо кӯмак мекунанд? Ду вариантро интихоб кунед.

  1. Объектро дар дохили эффект сохтан ва вобастагии [city]-ро нишон додан
  2. Шарҳи хомӯшкунии линтерро илова кардан
  3. Массиви вобастагиҳоро ба [options, options] иваз кардан
  4. Ба вобастагиҳо танҳо қимати оддии city-ро додан, на объектро

Объект дар бадани компонент ҳар дафъа нав аст, барои Object.is ин қимати дигар аст. Ё бояд онро дар дохили эффект сохт, ё аз қиматҳои ибтидоӣ вобаста шуд.

setCount((c) => c + 1) дар эффект бо интервал дар муқобили setCount(count + 1) чӣ мекунад?

  1. Ҳеҷ чиз, ин танҳо навишти дигар аст
  2. Тезтар иҷро мешавад
  3. Қимати ҷориро аз React мегирад, бинобар ин count-ро хондан ва ба вобастагиҳо илова кардан лозим нест
  4. Дар эффектҳо манъ аст

Навсозии функсионалӣ ҳолати охиринро аз React мегирад, на аз замкунӣ. Бо ин ҳам қимати кӯҳна, ҳам вобастагии нолозим нест мешавад.

осон

Компоненти PageTitle бояд ҳангоми ҳар тағйири тарабхона сарлавҳаи варақаро гузорад. Ҳоло дар консол танҳо қимати аввал аст: эффект массиви холии вобастагиҳо дорад, ҳол он ки name-ро мехонад. Ислоҳ кунед. Стенд тарабхонаро ду маротиба иваз мекунад.

import { useEffect, useState } from "react";

function useScript(steps) {
  useEffect(() => {
    const ids = steps.map(([ms, fn]) => setTimeout(fn, ms));
    return () => ids.forEach(clearTimeout);
  }, []);
}

// стенд: вместо document.title печатаем в консоль
function setTitle(text) {
  console.log("заголовок:", text);
}

function PageTitle({ name }) {

    setTitle(name);
  }, []);
  return <h1>{name}</h1>;
}

export default function App() {
  const [name, setName] = useState("Navruz");
  useScript([
    [50, () => setName("Rohat")],

02 Тозакунии эффект ва оғози дукарата дар StrictMode

Эффект аксар вақт чизеро «фаъол» мекунад: таймер, обуна, пайвастшавӣ, дархост. Функсияе, ки эффект бармегардонад, тозакунӣ аст: он ончиро, ки эффект фаъол кардааст, «хомӯш» мекунад. React онро дар ду ҳолат даъват мекунад: пеш аз оғози навбатии эффект (ҳангоми тағйири вобастагиҳо) ва ҳангоми хориҷ шудани компонент. Тартиб ҳангоми тағйири вобастагиҳо ҳамеша чунин аст: тозакунӣ бо қиматҳои кӯҳна, баъд эффекти нав бо қиматҳои нав.

useEffect(() => {
  function handleResize() {
    setWidth(window.innerWidth)
  }
  window.addEventListener('resize', handleResize) // включили
  return () => window.removeEventListener('resize', handleResize) // выключили
}, [])

Тозакунии хуб — оинаи танзим аст: addEventListener ва removeEventListener, setInterval ва clearInterval, connect ва disconnect, fetch ва abort (бахши 5). Бе тозакунӣ обунаҳо ҷамъ мешаванд: баъд аз даҳ маротиба нишон додани компонент ба ҳар рӯйдод даҳ коркардкунанда амал мекунад.

Чаро эффект ду маротиба оғоз мешавад

Лоиҳа аз қолаби Vite сохта шудааст, ва дар main.tsx барнома дар StrictMode печонида шудааст (дарси 3: он компонентҳоро ду маротиба даъват мекунад). Он як чизи дигар низ мекунад: дар реҷаи таҳия баъд аз нишон додани аввалини компонент фавран тозакуниро иҷро мекунад ва эффектро аз нав оғоз менамояд. Ин санҷиши устуворӣ аст: React «рафтем ва баргаштем»-ро тақлид мекунад ва мебинад, ки чизе вайрон намешавад. Дар ҷамъбасти истеҳсолӣ оғози дукарата нест.

  2. Ки дар лоиҳа ягон эффект нест

Ролик бо забони русӣ (19 дақиқа, ноябри 2025): useRef ва кор бо DOM. Қисмати дар бораи компонентҳои идоранашавандаро ҳоло гузаронидан мумкин аст: формаҳоро дар дарси 7 мебинем.

Монанд аз ҳаёт

Ҳолат — ин менюи дар девори чойхона: тағйир ёфт, ва ҳама ҷадиди онро мебинанд. Ref — дафтарчаи пешхизмат дар киса: вай навиштааст, ки ба кадом миз чӣ бояд бурд, вале деворро тағйир додан лозим нест. Чизи нишондодашаванда бояд дар ҳолат бошад. 2. inputRef.current.focus() бе ?.: хатои TS18047, ва ҳангоми нишон додан пеш аз пайдо шудани унсур — вайроншавии воқеии Cannot read properties of null. 3. Боркунии маълумотро тавассути шабака шумо дар курси «Frontend + ИИ» аллакай иҷро кардаед: useEffect, fetch, ҳолатҳои «боркунӣ / хатогӣ / маълумот». Ба ҷои се useState-и алоҳида (loading, error, data) як ҳолат бо нишони status эълон кунед. Он гоҳ омезишҳои имконнопазир («боркунӣ ва хатогӣ якҷоя») содда тасвир намешаванд, ва компилятор намегузорад, ки то санҷидани статус data-ро хонед.

Қолаби дархост дар эффект

Дархост — системаи беруна аст, бинобар ин эффект дар ин ҷо мувофиқ аст. Қолаб аз панҷ банд:

  1. AbortController дар дохили эффект сохта мешавад, signal-и он ба fetch дода мешавад.
  2. response.ok ҳамеша месанҷад: fetch promise-ро танҳо ҳангоми хатои шабака рад мекунад, ва ҷавобҳои 404 ва 500 барои он «муваффақият» мебошанд.
  3. Ҷавоб дар unknown хонда мешавад ва бо функсияи санҷишӣ (дар поён) месанҷад, танҳо баъд ба навъи лозимӣ табдил меёбад.
  4. Хато дар catch — ин unknown аст; бекоркуниро (AbortError) нодида мегиранд, боқиро нишон медиҳанд.
  5. Тозакунии эффект controller.abort()-ро даъват мекунад: агар вобастагӣ иваз шуда бошад ё компонентро хориҷ карда бошанд, дархости кӯҳна бекор мешавад.

Агар const list: Restaurant[] = await response.json() нависед, хатои навъ пайдо намешавад, вале агар сервер чизи дигар фиристад, барнома дар ҷои дури аз дархост меафтад. Бехатартар аст, ки ҷавобро ҳамчун unknown («чизе, ки ҳанӯз санҷида нашудааст») қабул кунед ва ба компилятор шакли қиматро исбот намоед.

  return (
    isRecord(value) &&
    typeof value.id === 'number' &&
    typeof value.title === 'string' &&
    typeof value.price === 'number'

Монанд аз ҳаёт

1. response.ok-ро нашиносидан: ҷавоби 500 бо бадани {"message": …} ҳамчун «маълумот» ба ҳолат меафтад. 2. const data = await response.json() ва баъд data.map: any ҳама чизро хомӯшона мегузаронад. 3. AbortError-ро ҳамчун хато ба корбар нишон додан: бекоркунӣ — рӯйдоди муқаррарӣ. 4. async бевосита дар useEffect(async () => …): эффект бояд функсияи тозакунӣ ё ҳеҷ чизро баргардонад, на promise. Функсияи async-ро берун аз эффект эълон кунед (мисли fetchRestaurants) ва даъват кунед. 5. «Боркунӣ»-ро дар худи эффект тавассути setLoad(…) барқарор кардан: ин setState-и синхронӣ дар эффект аст. Онро дар коркардкунанда (тугмаи «Такрор») ё тавассути key барқарор кунед. 6. Навъро тавассути as Restaurant[] овардан: ин ваъда ба компилятор бе санҷиш аст.

ВАЗИФАИ 5.1

Худро санҷед: дархостҳо ва навъҳо

миёна

Сервер бо рамзи 500 ҷавоб дод. await fetch(url) чӣ мекунад?

  1. Хатоеро мепартояд, ки catch онро мегирад
  2. response-ро бо ok === false бармегардонад: санҷиш бояд аз тарафи шумо бошад
  3. null бармегардонад
  4. Дархостро худкор такрор мекунад

fetch танҳо ҳангоми хатои шабака рад мешавад. Барои хатогиҳои HTTP шумо response.ok-ро месанҷед ва худатон хато меандозед.

Чаро натиҷаи response.json()-ро ҳамчун unknown қабул мекунанд, на ҳамчун навъи лозимӣ?

  1. То ки компилятор шакли ҷавобро то истифода санҷиданро талаб кунад: сервер метавонад чизи дигареро фиристад, на он чизе, ки интизорем
  2. То ки код зудтар иҷро шавад
  3. Зеро json() маълумот бармегардонад
  4. То ки await нанависем

Навишти const x: Restaurant[] = await response.json() бе санҷиш тартиб дода мешавад: any ба ҳар навъ мувофиқ аст. Бо unknown бе type guard навъро додан мумкин нест.

Ба catch (error) аз сабаби даъвати controller.abort() дар cleanup AbortError афтод. Чӣ бояд кард?

  1. Ба корбар паёми хатогӣ нишон додан
  2. Дархостро такрор кардан
  3. Нодида гирифтан: бекоркунӣ — қарори худи мо аст, на вайроншавӣ
  4. AbortController-ро хориҷ кардан

Бекоркунӣ вақте рух медиҳад, ки дархост лозим намемонад (вобастагӣ иваз шуд ё компонентро хориҷ карданд). Онро ҳамчун хато нишон додан — яъне корбарро бесабаб тарсондан.

ВАЗИФАИ 5.2

  await readFile(new URL('./menu.json', import.meta.url), 'utf8'),

const server = createServer(async (req, res) => {
  const url = new URL(req.url ?? '/', 'http://localhost')
  // ?delay=2000 замедляет ответ, ?fail=1 отвечает ошибкой 500
  const delay = Number(url.searchParams.get('delay') ?? 600)
  await new Promise((resolve) => setTimeout(resolve, delay))

  const send = (status, body) => {
    res.writeHead(status, {
      'Content-Type': 'application/json; charset=utf-8',
    })
    res.end(JSON.stringify(body))
  }

  if (url.searchParams.get('fail') === '1') {
    return send(500, { message: 'Сервер временно недоступен' })
  }

  const path = url.pathname
  if (path === '/api/restaurants') {
    return send(200, restaurants)
  }
  const menuMatch = path.match(/^\/api\/restaurants\/(\d+)\/menu$/)
  if (menuMatch) {
    const id = Number(menuMatch[1])
    if (!restaurants.some((r) => r.id === id)) {
      return send(404, { message: 'Ресторан не найден' })
    }
    return send(
      200,
      menu.filter((item) => item.restaurantId === id),
    )
  }
  send(404, { message: 'Такого адреса нет' })
})

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null
}

function isRestaurant(value: unknown): value is Restaurant {
  return (
    isRecord(value) &&
    typeof value.id === 'number' &&
    typeof value.name === 'string' &&
    typeof value.cuisine === 'string' &&
    (CUISINES as readonly string[]).includes(value.cuisine) &&

    typeof value.emoji === 'string' &&
    typeof value.deliveryMin === 'number' &&

}

export async function fetchRestaurants(
  signal: AbortSignal,
): Promise<Restaurant[]> {
  const response = await fetch('/api/restaurants', { signal })
  if (!response.ok) {
    throw new Error(`Сервер ответил ${response.status}`)

    throw new Error('Сервер прислал данные в неожиданном формате')
  }
  return data
}
