01 Майдонҳои идорашаванда ва идоранашаванда

Ҳар як майдони воридкунӣ қимат дорад, ва касе бояд соҳиби он бошад. Ду роҳ ҳаст.

  • Майдони идорашаванда (controlled): қиматро React дар ҳолат нигоҳ медорад. Дар майдон шумо value={name} ва onChange менависед, ки қимати навро ба setName мегузорад. Ҳар як аломат аз React мегузарад: метавон фавран санҷид, форматбандӣ кард ё манъ кард.
  • Майдони идоранашаванда (uncontrolled): қиматро худи браузер (DOM) нигоҳ медорад. React чизеро намедонад, то шумо напурсед: ҳангоми фиристодани шакл (FormData) ё тавассути ref. Қимати ибтидоиро defaultValue медиҳад.
import { useState, type ChangeEvent } from 'react'

export default function NameField() {
  const [name, setName] = useState('')

  function handleChange(event: ChangeEvent<HTMLInputElement>) {
    setName(event.target.value)
  }

  return (
    <label>
      Имя
      <input value={name} onChange={handleChange} />
    </label>
  )
}

import type { FormEvent } from 'react'

export default function QuickOrder({ onOrder }: { onOrder: (phone: string) => void }) {
  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault() // без этого браузер перезагрузит страницу
    const data = new FormData(event.currentTarget)
    onOrder(String(data.get('phone')))
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="phone" defaultValue="+992" />
      <button>Перезвоните мне</button>
    </form>
  )
}

Диққат диҳед: data.get('phone') FormDataEntryValue | null-ро бармегардонад (сатр, файл ё null), бинобар ин онро бояд ба сатр табдил дод ё санҷид. Қиматҳои майдонҳо ҳамеша сатранд: рақам аз type="number" низ ҳамчун сатр меояд, ва онро бояд табдил дод (Number(value)).

Нишона, фиристодан ва тугмаҳо

  • Ҳар як майдон <label> дорад: майдонро бо он печонед ё htmlFor-ро бо id пайваст кунед. Барои id-ҳои беназир дар компоненте, ки борҳо кашида мешавад, ҳуки useId()-ро истифода баред. Ишора дар placeholder нишона нест: он ҳангоми воридкунӣ нопадид мешавад.
  • Тугма дар дохили <form> бе type ба таври пешфарз шаклро мефиристад. Тугмаи «Закрыть» дар дохили шакл ба type="button" ниёз дорад.
  • Байрақчаро аз checked мехонанд, на аз value; барои select қимат — event.target.value аст.
  • Дар React 19 <form> prop-и action-ро барои функсияҳои сервер дорад: мо онро дар дарси 18 (Next.js) меомӯзем. Дар SPA, мисли «Дастархон», шаклро onSubmit коркард мекунад.
Монанд аз ҳаёт

Майдони идорашаванда — фурӯшандаи бозор аст, ки ҳар як калимаи шуморо дар дафтар менависад ва фавран бо овози баланд ба шумо бармехонад. Идоранашаванда — варақаи фармоиш аст: шумо онро худатон пур мекунед, ва фурӯшанда онро як бор мехонад, вақте ки шумо онро аз болои пештахта дароз кардед.

Хатоҳои маъмул

1. value бе onChange: майдон «чоп намекунад». Дар консоли реҷаи таҳия:

You provided a `value` prop to a form field without an `onChange` handler. This will render a read-only field. If the field should be mutable use `defaultValue`. Otherwise, set either `onChange` or `readOnly`.

2. Қимати ибтидоӣ undefined, баъд сатр: майдон аз идоранашаванда ба идорашаванда «мекӯчад». Аз сатр оғоз кунед: useState('').

A component is changing an uncontrolled input to be controlled. This is likely caused by the value changing from undefined to a defined value, which should not happen. Decide between using a controlled or uncontrolled input element for the lifetime of the component. More info: https://react.dev/link/controlled-components

3. event.preventDefault() дар onSubmit нест: саҳифа аз нав бор мешавад ва ҳолат нест мешавад. 4. Ҳамзамон value ва defaultValue дар як майдон. 5. Рақами майдонро ҳамчун сатр ҷамъ мекунанд: "2" + "3" "23" медиҳад.

02 Санҷиш: аз санҷиши дастӣ то схемаи Zod

Санҷиши шакл ба ду савол ҷавоб медиҳад: чиро дуруст ҳисоб кардан ва кай хаторо нишон додан. Аз он оғоз мекунем, ки ин бе китобхонаҳо чӣ гуна менамояд.

type OrderValues = {
  name: string
  phone: string
  address: string
}

type Errors = Partial<Record<keyof OrderValues, string>>

function validate(values: OrderValues): Errors {
  const errors: Errors = {}
  if (values.name.trim().length < 2) {
    errors.name = 'Введите имя: не меньше 2 букв'
  }
  if (!/^\+992\d{9}$/.test(values.phone)) {
    errors.phone = 'Телефон в формате +992901234567'
  }
  if (values.address.trim().length < 5) {
    errors.address = 'Укажите улицу и дом'
  }
  return errors
}

Ин кор мекунад, аммо ду нуқсон мебинем. Аввалан, навъ ва қоидаҳо алоҳида зиндагӣ мекунанд: майдонро ба навъ илова кардед, дар validate фаромӯш кардед, ва TypeScript хомӯш мемонад. Дувум, ҳама чизи боқимонда (кай санҷидан, кадом майдонҳо «ламс шудаанд», чӣ тавр ба майдони аввалини хатогӣ фокус додан, чӣ тавр фиристодан) бояд худатон нависед. Қисми дуюмро React Hook Form (бахши 3) мегирад, қисми аввалро — схема.

Кай хаторо нишон додан

  • Ҳангоми фиристодан: оромтарин вариант ва қимати пешфарз. Корбар то охир нарасида сурхиро намебинад.
  • Баъд аз рафтан аз майдон (onBlur, дар React Hook Form реҷаи onTouched): хато вақте пайдо мешавад, ки майдон «ламс шуд», ва баъд ҳангоми ислоҳ фавран нопадид мешавад.
  • Барои ҳар аломат: танҳо дар ҷое, ки ин кумак мекунад (қувваи парол, ҳисобкунаки аломатҳо). Хатои сурх дар ҳарфи аввали ном озор медиҳад.

Схема ҳамчун сарчашмаи ягонаи ҳақиқат

Zod — китобхонаест, ки дар он қоидаҳо як маротиба дар намуди схема тавсиф мешаванд. Схема се корро метавонад: қиматро дар вақти кори барнома санҷад, хатоҳои фаҳморо диҳад ва ба TypeScript навъи маълумоти санҷидашударо диҳад. Навъҳои TypeScript ҳангоми сохт нопадид мешаванд, ва схема ҳамчун код мемонад ва маълумоти воқеиро, ки аз шакл ё аз сервер омадааст, месанҷад.

import { z } from 'zod'

export const PAYMENTS = ['cash', 'card'] as const

export const orderSchema = z.object({
  name: z.string().trim().min(2, 'Введите имя: не меньше 2 букв'),
  phone: z.string().regex(/^\+992\d{9}$/, 'Телефон в формате +992901234567'),
  address: z.string().trim().min(5, 'Укажите улицу и дом'),
  comment: z.string().max(200, 'Не больше 200 символов'),
  payment: z.enum(PAYMENTS, { error: 'Выберите способ оплаты' }),
})

// тип получаем из схемы: второй раз его не пишем
export type OrderForm = z.infer<typeof orderSchema>

OrderForm — ин айнан { name: string; phone: string; address: string; comment: string; payment: 'cash' | 'card' } аст. Қоидаро дар схема тағйир додед, ва навъ худаш тағйир ёфт. Инро чунин хонед: «навъи қиматҳое, ки кафолат дода шудааст, ки аз схема гузаштаанд».

Zod ба маълумоти бад чӣ тавр ҷавоб медиҳад

schema.parse(data) маълумотро бармегардонад ё хато мепартояд, ва schema.safeParse(data) чизеро намепартояд ва объектро бо майдони success бармегардонад. Шаклҳо ба варианти дуюм ниёз доранд: хатоҳо вазъияти маъмулӣ мебошанд, на истисно.

if (!result.success) {

Шакли натиҷаро дар хотир доред: номи майдон → рӯйхати паёмҳо. React Hook Form хатоҳоро ҳамин тавр ҷойгир мекунад, ва ба шумо танҳо нишон додани errors.name?.message мемонад. Агар майдон тамоман нагузашта бошад, Zod бо матни стандартии Invalid input: expected string, received undefined шикоят мекунад: ин матн ба корбар чизе намегӯяд, бинобар ин дар шакл ҳар як майдон қимати пешфарз дорад.

Якчанд усули Zod

  • z.string().trim().min(2, 'матн'): занҷири санҷишҳо, паём ҳамчун далели дуюм. trim() боз дар натиҷа фосилаҳоро мебуррад.
  • z.email('матн'): санҷиши суроға (дар Zod 4 ин навишти кӯтоҳ аст; z.string().email()-и пештара кор мекунад, аммо кӯҳна ҳисоб мешавад, мисли параметри message ба ҷои error).
  • z.enum([...] as const): яке аз қиматҳо, навъ ҳамчун union аз дарси 2 ба даст меояд.
  • .refine(санҷиш, { path: ['confirm'], error: '...' }): қоидае, ки ба якчанд майдон якбора менигарад (парол ва такрори парол). Шумо онро дар вазифаи хонагӣ истифода мебаред.
  • Майдони матнии ихтиёрӣ: майдони холии шакл '' аст, на undefined, бинобар ин онро ҳамчун z.string() бе ҳадди ақал тавсиф мекунанд, мисли comment дар боло.

TypeScript: навъ аз як сарчашма

Усули «навъ аз қимат гирифта мешавад» бе Zod низ кор мекунад: as const ва typeof-ро шумо дар дарси 2 дар мисоли CUISINES дидед. z.infer — ҳамон чиз, танҳо қимат схема аст. Дар вазифаҳои поён дар мисоли оддӣ машқ кунед.

Монанд аз ҳаёт

Схема — қабулкунандаи анбор дар Душанбе аст: як нафар бо як рӯйхати қоидаҳо. Ӯ ҳар як мошинро (қимат) месанҷад, далелномаи рад бо сабабҳо (паёмҳо) менависад ва мӯҳри «қабул шуд» (навъ) мемонад. Агар қоидаҳоро ҳам ронанда, ҳам анбордор ва ҳам ҳисобдор дар ёд нигоҳ медоштанд, онҳо дер ё зуд аз ҳам ҷудо мешуданд.

Хатоҳои маъмул

1. Навъи шакл бо даст дар паҳлӯи схема навишта шудааст: ҳангоми ислоҳи схема навъ «қафо мемонад». z.infer-ро гиред. 2. Санҷиш танҳо дар клиент: шаклро бо дархости бевосита давр мезананд, сервер вазифадор аст ҳамаро аз нав санҷад (дарси 18). 3. Рақамҳо аз майдонҳо: схема сатр мегирад, на рақам; барои рақамҳо табдил лозим аст, ва он гоҳ навъи воридот ва баромади схема гуногун мешавад. Ҳоло майдонҳоро сатр гузоред. 4. Паёмҳо бо забони англисӣ ба таври пешфарз: паёмҳои худро нависед, зеро Invalid input: expected string, received undefined ба корбар чизе намегӯяд. 5. Майдони ҳатмӣ ҳамчун z.string() тавсиф шудааст: сатри холӣ мегузарад. .min(1, 'матн') ё қоидаи дақиқтарро илова кунед.

ВАЗИФАИ 2.1

миёна

Барои чӣ навъро тавассути z.infer гирифтан лозим аст, на ин ки type OrderForm = { … }-ро дар паҳлӯи схема нависем?

  2. Қоидаҳо ва навъро аз ҳам ҷудо кардан мумкин нест: схема тағйир меёбад, навъ низ тағйир меёбад

  4. Навъи дастинавишро дар компонент истифода бурдан мумкин нест

Ду тавсифи як чиз дер ё зуд аз ҳам ҷудо мешаванд. Схема — сарчашмаи ягона: аз он ҳам санҷиш, ҳам навъ.

Чаро навъи OrderForm худ аз худ аз маълумоти нодурусти корбар муҳофизат намекунад?

  1. Навъҳои TypeScript танҳо ҳангоми сохт мавҷуданд: дар вақти кор танҳо схема месанҷад
  2. Чунки TypeScript хато мекунад
  3. Чунки навъро ворид кардан мумкин нест
  4. Чунки навъ танҳо барои рақамҳо кор мекунад

Дар браузер аз навъҳо JavaScript-и оддӣ мемонад. Маълумоти шакл ё шабакаро код месанҷад: схемаи Zod ё дастӣ.

Дар шакли фармоиши оддӣ хаторо кай беҳтар аст нишон диҳем?

  1. Барои ҳар аломати воридшуда, то одам фавран мушкилро бинад
  2. Танҳо баъд аз аз нав боркунии саҳифа

  4. Ҳеҷ гоҳ: як навиштаи умумии «Шакл нодуруст пур шудааст» кифоя аст

Сурх дар ҳарфи аввал метарсонад, ва навиштаи умумӣ намегӯяд, ки чиро ислоҳ кардан лозим аст. Хато ҳангоми фиристодан ё баъд аз рафтан аз майдон — варианти ором ва фаҳмо аст.

03 React Hook Form: шакл бе кори дастии такрорӣ

Агар шаклро бо даст нависед, барои ҳар майдон useState, onChange, onBlur, байрақчаҳои «ламс шуд», ҷамъоварии хатоҳо ва гузаронидани фокус лозим аст. React Hook Form (RHF) инро ба ҷои шумо мекунад ва бо ин ҳам шаклро барои ҳар ҳарф аз нав намекашад: майдонҳо идоранашаванда мемонанд, ва китобхона онҳоро тавассути ref мехонад. Он якҷоя бо Zod ба лоиҳа насб мешавад:

npm install react-hook-form zod @hookform/resolvers

Дар лаҳзаи дарс ин react-hook-form 7.91, zod 4.6 ва @hookform/resolvers 6.0 аст. Бастаи @hookform/resolvers — пул байни RHF ва схема: функсияи zodResolver(schema) ба шакл мегӯяд «қиматҳоро бо ин схема санҷ».

import { zodResolver } from '@hookform/resolvers/zod'
import { useForm } from 'react-hook-form'
import { orderSchema, type OrderForm } from './orderSchema'

export default function MiniForm() {
  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm<OrderForm>({
    resolver: zodResolver(orderSchema),
    defaultValues: { name: '', phone: '+992', address: '', comment: '', payment: 'cash' },
  })

  async function onSubmit(values: OrderForm) {
    // сюда попадают только значения, прошедшие схему
    console.log(values)
  }

  return (
    <form noValidate onSubmit={handleSubmit(onSubmit)}>
      <input {...register('name')} />
      {errors.name && <p role="alert">{errors.name.message}</p>}
      <button disabled={isSubmitting}>Отправить</button>
    </form>
  )
}

Бо watch() эҳтиёт шавед: он компонентро ба қиматҳо обуна мекунад ва боз барои ҳар ҳарф аз нав кашидан мекунад. Агар қимат танҳо ҳангоми фиристодан лозим бошад, он аллакай дар onSubmit ҳаст. Сабаби дуюми эҳтиёткорӣ низ ҳаст: watch() ҳолати пинҳони тағйирёбандаро нигоҳ медорад, бинобар ин React Compiler (дарси 6) чунин компонентҳоро мегузаронад, ва қоидаи линтери react-hooks/incompatible-library дар бораи онҳо огоҳ мекунад. Агар қиматро дар экран нишон додан лозим бошад, ҳуки useWatch-ро гиред. Ин яке аз сабабҳост, ки дар лоиҳаи асосии курс компилятор фаъол нест.

TypeScript болои номҳои майдонҳо назорат мекунад

Азбаски навъи шакл аз схема гирифта шудааст, хатои имло дар номи майдон дигар хомӯш намемонад. Компилятор чӣ мегӯяд, агар register('nmae') нависед ё фаромӯш кунед, ки хато метавонад набошад:

src/MiniForm.tsx(12,30): error TS2345: Argument of type '"nmae"' is not assignable to parameter of type '"address" | "comment" | "name" | "payment" | "phone"'.
src/MiniForm.tsx(13,24): error TS18048: 'errors.name' is possibly 'undefined'.

Хатои дуюм муфид аст: errors.name танҳо вақте ҳаст, ки майдон нодуруст аст, бинобар ин errors.name?.message-ро хонед ё мавҷудиятро санҷед, чунон ки дар мисоли боло.

Хатои сервер ва шакли «хомӯш»

Схема шаклро дар клиент месанҷад, аммо сервер бештар медонад (тарабхона баста аст, рақам масдуд аст). Хатои серверро дар try/catch гирифта, тавассути setError('root.server', …) ба шакл мегузоранд. Мушкили маъмули дуюм: дар схема майдон ҳаст, аммо дар аломатгузорӣ нест (ё бо номи дигар аст). Он гоҳ handleSubmit onSubmit-ро даъват намекунад, ва хаторо нишон додан ба кас нест: шакл «хомӯш» аст. Барои ёфтани ин, ҳамчун далели дуюм коркардкунандаи фиристодани нодурустро диҳед: handleSubmit(onSubmit, (errors) => console.log(errors)). Шумо инро дар машқ иҷро мекунед.

Ролик бо забони англисӣ: пайвастагии RHF ва Zod, ҳолати шакл ва Controller. Номҳои функсияҳоро бо ҳуҷҷатгузории расмӣ муқоиса кунед: версияҳои китобхонаҳо зуд-зуд баромад мекунанд.

Монанд аз ҳаёт

RHF — маъмури қабулгоҳи клиника аст. Шумо корти беморро дар варақаҳо пур мекунед (майдонҳо), ӯ то даме ки менависед, ҳар ҳарфро намехонад. Вақте ки шумо картро дароз кардед, ӯ онро бо қоидаҳо (схема) муқоиса мекунад, ва агар чизе нодуруст бошад, шуморо хомӯшона ба майдони аввалини нодуруст мебарад ва нишон медиҳад, ки чиро ислоҳ кардан лозим аст.

Хатоҳои маъмул

1. defaultValues нест: майдонҳо бо undefined оғоз мешаванд, ва схема сатр интизор аст. 2. register('name') бе кушодан: {...register('name')} нависед. 3. onChange-и худи майдони register RHF-ро мепӯшонад: онро ба дохили register('name', { onChange }) диҳед. 4. Майдон дар схема ҳаст, дар шакл нест: шакл хомӯш мемонад, чунон ки дар боло навишта шуд. 5. Мисолҳои кӯҳна бо ref={register} (RHF версияи 6) дар ҷавобҳои ЗС: дар версияи 7 ин кор намекунад. 6. onSubmit = (data: any)-и навъбандишуда: навъро аз схема гиред.

04 Равзанаҳои модалӣ ва порталҳо

Равзанаи модалӣ — блоке дар болои саҳифа, ки ҷавоб металабад: то даме ки он кушода аст, боқимондаи саҳифа «яхкарда» мешавад. Онро дар ҷое кашидан, ки шумо эълон кардаед (дар дохили корт ё сабад), хатарнок аст: волидайн баъзан overflow: hidden, transform ё z-index-и худро доранд, ва равзана бурида мешавад ё дар зери қабати дигар мемонад. Бинобар ин равзанаро ба охири <body> мебароранд. Дар React барои ин портал ҳаст.

import { createPortal } from 'react-dom'

function Hint({ children }: { children: ReactNode }) {
  return createPortal(
    <div className="fixed inset-0 z-50">{children}</div>,
    document.body,
  )
}

Далели аввал — чиро кашидан, дуюм — унсури воқеии DOM, ки онро ба он ҷо мегузоранд. Компонент дар ҳамон ҷое мемонад, ки шумо навиштаед: дар дарахти React он насли волидайни худ аст, ва дар DOM аломатгузории он дар document.body меистад.

Рӯйдодҳо ва контекст аз рӯи дарахти React мераванд

Ғайричашмдоштарин чиз дар порталҳо: рӯйдод аз портал аз рӯи дарахти React боло меравад, на аз рӯи DOM. Агар корт onClick дошта бошад, ва равзанаи портал дар дохили он бошад, клик ба тугмаи равзана ба onClick-и корт мерасад, ҳарчанд дар DOM равзана дар body меистад. Агар ин ба волидайн халал расонад, боло рафтанро дар равзана қатъ кунед: event.stopPropagation(). Контекст (дарси 8) низ тавассути портал мегузарад.

Аз ҳама осонтар — document.body: он ҳамеша ҳаст. Метавон дар index.html контейнери <div id="modal-root">-ро гузошт, аммо он гоҳ document.getElementById HTMLElement | null-ро бармегардонад, ва портал танҳо Element ё DocumentFragment қабул мекунад:

src/Hint.tsx(3,33): error TS2345: Argument of type 'HTMLElement | null' is not assignable to parameter of type 'DocumentFragment | Element'.
  Type 'null' is not assignable to type 'DocumentFragment | Element'.

Ва агар дар id хатои имло кунед ва компиляторро тавассути as HTMLElement давр занед, дар браузер ҳангоми кор хато мешавад:

Uncaught Error: Target container is not a DOM element.

Дар SPA бо Vite document ҳамеша ҳаст. Дар Next.js компонентҳо аввал дар сервер кашида мешаванд, ки дар он ҷо document нест: он ҷо порталҳоро баъд аз насбшавӣ пайваст мекунанд (ба ин дар дарси 16 бармегардем). Диалоги худӣ ё <dialog>-и дарунсохт

Дар браузерҳо барчаспи <dialog> бо усули showModal() ҳаст: он худаш қабатро дар болои саҳифа, бастан бо Esc, торикшавии ::backdrop ва манъи фокус ба саҳифаи зери худро медиҳад. Барои лоиҳаҳои нав ин варианти олӣ аст, ва донистани он арзанда аст. Дар курс мо равзанаро тавассути портал менависем: ба ин тартиб маълум мешавад, ки дастрасӣ (бахши 5) аз чӣ иборат аст, ва портал барои ишораҳо, менюҳои афтанда ва огоҳиҳо низ лозим аст. Минбаъд китобхонаҳои интерфейс (Radix, Headless UI) ҳамин мушкилотро бо компонентҳои тайёр ҳал мекунанд.

Ролик бо забони русӣ: портал чӣ тавр сохта шудааст ва бо он равзанаро чӣ тавр ҷамъ кардан мумкин. Фокус ва дастрасӣ дар он суст ёдовар шудаанд: мо онҳоро дар бахши 5 илова мекунем.

Монанд аз ҳаёт

Портал — мисли эълон дар девори чойхона аст. Фармоишро шумо дар назди мизи худ қабул кардед (ҷой дар дарахти React), аммо лавҳаи «Миз банд аст»-ро ба девори асосӣ дар назди даромадгоҳ мезананд (body), то ҳама онро бубинанд ва ягон миз онро напӯшонад. Агар меҳмон ба лавҳа пахш кунад, савол ба ҳар ҳол ба мизи шумо мерасад: рӯйдод аз рӯи дарахти React меравад.

Хатоҳои маъмул

1. Равзана дар дохили корт бо overflow: hidden: бурида шудааст. 2. Клик дар равзана дар корти зери он кор мекунад (боло рафтан аз рӯи дарахти React). 3. Бастан бо клик ба замина аз клики дар дохили равзана низ кор мекунад: event.target === event.currentTarget-ро муқоиса кунед. 4. document.getElementById('modal-root') бе санҷиши null. 5. Равзана ҳамеша насб шудааст ва бо услуб пинҳон аст: шакл дар дохил ҳолати кӯҳнаро нигоҳ медорад. {open && <Modal />}-ро кашед: ҳангоми бастан ҳолат тоза мешавад, ва фокус бармегардад (бахши 5).

05 Дастрасии асосӣ: фокус, Esc ва aria

На ҳамаи корбарон бо муш кор мекунанд ва ба экран менигаранд. Касе бо клавишаи Tab мегузарад, касе саҳифаро бо хонандаи экран (VoiceOver, NVDA, TalkBack) гӯш мекунад, касе танҳо дар даст чой дорад ва Esc-ро барои бастани равзана пахш мекунад. Хабари хуш: дастрасии асосӣ — ин панҷ одат аст, ва онҳо шаклро барои ҳама қулайтар мекунанд.

Одати 1. Ҳар як майдон нишона дорад

Хонанда «Ном, майдони воридкунӣ»-ро танҳо дар сурате мехонад, ки майдон бо <label> пайваст бошад. Пайвастро htmlFor + id ё печонидан месозад. Дар компоненти такроршаванда id-ро аз useId() мегиранд, то ду майдон як id нагиранд.

Одати 2. Хато бо майдон пайваст аст

  • aria-invalid="true" дар майдони нодуруст: хонанда мегӯяд «қимати нораво»;
  • aria-describedby="id-и-хато": хонанда матни хаторо якҷоя бо майдон мехонад;
  • role="alert" дар блоки хато, ки баъд аз амал пайдо мешавад: хонанда онро фавран, бе гузаштан ба он, садо медиҳад. Барои матне, ки ҳамеша дар саҳифа меистад, нақш лозим нест;
  • ранг ягона аломат нест: дар паҳлӯи чаҳорчӯбаи сурх матн ҳаст.
const id = useId()
const errorId = `${id}-error`

<label htmlFor={id}>Имя</label>
<input
  id={id}
  aria-invalid={error ? true : undefined}
  aria-describedby={error ? errorId : undefined}
/>
{error && <p id={errorId} role="alert">{error}</p>}

Одати 3. Равзана худро диалог эълон мекунад

Дар панели равзана role="dialog", aria-modal="true" ва aria-labelledby-ро бо истинод ба сарлавҳаи равзана менависанд. Он гоҳ хонанда мегӯяд «Оформление заказа, диалог», ва мазмуни саҳифа дар зери он барои ӯ хомӯш мешавад.

Одати 4. Фокус: ба дарун, давр задан, бозгашт

  1. Ба дарун. Ҳангоми кушодан фокусро ба равзана гузаронед (ба панел бо tabIndex={-1} ё ба майдони аввал). Вагарна корбари клавиатура «дар паси» равзана мемонад ва Tab-ро дар саҳифаи нонамоён мепахшад.
  2. Давр задан. Tab аз унсури охирини равзана ба аввал мебарад, Shift+Tab аз аввал — ба охирин (доми фокус, focus trap). Алтернативаи муосир — атрибути inert дар боқимондаи саҳифа: браузер худаш фокусро ба зери равзана намегузорад.
  3. Бозгашт. Ҳангоми бастан фокусро ба тугмае баргардонед, ки равзанаро кушод. Агар тугма аллакай нест (сабад баъд аз фармоиш тоза шуд), фокусро ба ҷойи бомаъно диҳед, масалан ба майдони ҷустуҷӯ.

Одати 5. Бастан бе муш ва бе ҳаракати замина

Esc равзанаро мебандад, равзана тугмаи «Закрыть»-и намоён ва садодиҳандашаванда дорад (aria-label, агар дар он танҳо «×» бошад), ва то даме ки равзана кушода аст, замина ҳаракат намекунад (document.body.style.overflow = 'hidden' ва бозгашт ҳангоми бастан: ин системаи беруни воқеӣ аст, ва дар ин ҷо эффект бо тозакунӣ мувофиқ аст, мисли дарси 5).

useEffect(() => {
  const opener =
    document.activeElement instanceof HTMLElement ? document.activeElement : null
  dialogRef.current?.focus()
  document.body.style.overflow = 'hidden'
  return () => {
    document.body.style.overflow = ''
    if (opener?.isConnected) {
      opener.focus()
    }
  }
}, [])

Массиви холии вобастагиҳо дар ин ҷо ҳалол аст: эффект чизи реактивиро намехонад. opener-ро бояд дар худи аввал дар хотир нигоҳ дошт: баъд activeElement аллакай дар дохили равзана мешавад. Санҷиши isConnected — барои ҳолате, ки тугма дар саҳифа аллакай нест.

TypeScript: ref ба унсур

useRef<HTMLDivElement>(null) ref медиҳад, ки current-и он — унсур ё null аст (дар React 19 навъҳо инро инъикос мекунанд: RefObject<HTMLDivElement | null>). Барои <dialog> навъ HTMLDialogElement, барои <form> — HTMLFormElement аст. Ҷустуҷӯ дар дохили контейнер низ навъбандӣ мешавад: container.querySelectorAll<HTMLElement>(selector). Ҳар дафъае ки current метавонад null бошад, TypeScript шуморо водор мекунад инро санҷед: dialogRef.current?.focus().

Чӣ тавр бе асбобҳо санҷидан

  • Мушро канор гузоред. Шаклро бо клавишаҳои Tab, Shift+Tab, Enter, Фосила, Esc гузаред: фокус ҳамеша намоён аст, равзана онро гум намекунад, Esc мебандад.
  • Хонандаро фаъол кунед (дар Mac — VoiceOver, Cmd+F5) ва гӯш кунед, ки майдон бо хато чӣ тавр хонда мешавад.
  • Дар Chrome DevTools: варақаи Accessibility ном ва нақши унсури интихобшударо нишон медиҳад, ва санҷиши Lighthouse (категорияи Accessibility) майдонҳои бе нишона ва контрасти сустро меёбад.
Монанд аз ҳаёт

Равзанаи модалӣ — мизи алоҳида дар чойхона аст, ки шуморо ба он нишонданд. То даме ки шумо дар паси он ҳастед, шумо дар толор намедавед (доми фокус). Шумо даромадед — пешхизмат фавран маҳз ба назди шумо омад (фокус ба дарун). Шумо хестед — ба ҷойи худ баргаштед, на ин ки дар толор гум шавед (фокус бозгашт). Ва ҳамеша метавон гуфт «ташаккур, бас аст» (Esc).

Хатоҳои маъмул

1. Нишона-«placeholder»: баъд аз воридкунӣ намоён нест, ва хонанда нишонаро нишона ҳисоб намекунад. 2. outline: none бе ивазкунӣ: корбари клавиатура намебинад, ки фокус дар куҷост. 3. Тугмаи «×» бе aria-label: хонанда «тугма, зарб» мехонад. 4. Равзана кушода аст, ва фокус дар тугмаи зери он мондааст: Tab ба замина меравад. 5. Ҳангоми бастан фокус ба аввали саҳифа гум шуд. 6. div бо onClick ба ҷои button: ба он бо клавишаи Tab расидан мумкин нест. 7. role="alert" дар ҳама матнҳо паси ҳам: хонанда бе таваққуф мегӯяд.

  onClose: () => void
  children: ReactNode
}

const FOCUSABLE =
  'a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled])'

export default function Modal({ title, onClose, children }: ModalProps) {
  const titleId = useId()
  const dialogRef = useRef<HTMLDivElement>(null)

  // Внешняя система — DOM: запоминаем, откуда открыли, фокус внутрь и запрет прокрутки фона
  useEffect(() => {
    const opener =
      document.activeElement instanceof HTMLElement
        ? document.activeElement
        : null
    dialogRef.current?.focus()
    document.body.style.overflow = 'hidden'
    return () => {
      document.body.style.overflow = ''
      if (opener?.isConnected) {
        opener.focus()
      }
    }
  }, [])

  function handleKeyDown(event: KeyboardEvent<HTMLDivElement>) {
    if (event.key === 'Escape') {
      onClose()
      return
    }
    if (event.key !== 'Tab' || dialogRef.current === null) {
      return
    }
    const items = dialogRef.current.querySelectorAll<HTMLElement>(FOCUSABLE)
    const first = items[0]
    const last = items[items.length - 1]
    if (first === undefined || last === undefined) {
      return
    }
    if (event.shiftKey && document.activeElement === first) {
      event.preventDefault()
      last.focus()
    } else if (!event.shiftKey && document.activeElement === last) {
      event.preventDefault()
      first.focus()
    }
  }

  function handleBackdropClick(event: MouseEvent<HTMLDivElement>) {
    if (event.target === event.currentTarget) {
      onClose()
    }
  }

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex items-center justify-center bg-black/50 p-4"
      onClick={handleBackdropClick}
      onKeyDown={handleKeyDown}
    >
      <div
        ref={dialogRef}
        role="dialog"
        aria-modal="true"
        aria-labelledby={titleId}
        tabIndex={-1}
        className="max-h-full w-full max-w-md overflow-y-auto rounded-2xl bg-white p-5 shadow-xl outline-none"
      >
        <div className="mb-3 flex items-start justify-between gap-3">
          <h2 id={titleId} className="text-xl font-bold">
            {title}
          </h2>
          <button
            className="h-8 w-8 rounded-full border border-stone-300 font-bold hover:bg-brand-50"
            aria-label="Закрыть окно"
            onClick={onClose}
          >
            ×
          </button>
        </div>
        {children}
      </div>
    </div>,
    document.body,
  )
}

Тугма дар ин ҳол нопадид мешавад, бинобар ин фокусро баргардонидан ҷое нест: инро мисли машқ ҳал кунед ва интихоби худро дар docs/forms.md шарҳ диҳед.
  5. Расондан ё худ гирифтан. Ба orderSchema майдони delivery-ро илова кунед ('courier' ё 'pickup') ва суроғаро танҳо барои курер ҳатмӣ кунед: дар объект address танҳо z.string().trim() мешавад, ва қоидаи «на камтар аз 5 аломат» ба .refine((value) => value.delivery === 'pickup' || value.address.length >= 5, { path: ['address'], error: 'Укажите улицу и дом' }) мегузарад. Дар CheckoutForm гурӯҳи радиотугмаҳои «Получение»-ро илова кунед (fieldset ва legend), ба таври пешфарз courier. Майдони суроғаро ҳангоми худ гирифтан нишон надиҳед (watch('delivery') дар ин ҷо ҷоиз аст: ба интихоб вокуниш лозим аст).
  6. Ном аз профил ва сервер. Агар корбар бақайдгирифта шуда бошад, name дар шакли фармоиш бо номи ӯ пур карда мешавад (defaultValues: prop-и нави ихтиёрии defaultName?: string). Серверро низ нав кунед: он delivery-ро қабул мекунад ва суроғаро танҳо ҳангоми courier талаб мекунад; қимати delivery берун аз ду ҷоиз бо ҷавоби 400 рад карда мешавад. Ин қоидаи «ба клиент бовар намекунем» аст: бо дархости curl бо "delivery":"pickup" бе суроға (бояд 201 бошад) ва бо "delivery":"teleport" (400) санҷед.
  7. Аудити дастрасӣ. Коди Modal, TextField, CheckoutForm ва SignupForm-ро бо промпти санҷиши дастрасӣ аз бахши 6 ба агент фиристед. Баъд ҳамаро худатон санҷед: гузаштани шакл танҳо бо клавиатура, Lighthouse (категорияи Accessibility) барои саҳифа бо равзанаи кушода. Дар docs/forms.md ҷадвали «эзоҳ → қабул ё рад → чаро» созед ва ба панҷ саволи поён бо суханони худ ҷавоб диҳед.
  8. Санҷишҳо ва коммитҳо. npm run format:check, npm run typecheck, npm run lint, npm run build мегузаранд. Дар шоха на камтар аз се коммити бомаъно, шоха ба GitHub фиристода шудааст.
