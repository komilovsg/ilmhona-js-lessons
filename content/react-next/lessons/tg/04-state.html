Ҳолат: useState ва useReducer

Дар охири дарс шумо «Дастархон»-и интерактивӣ хоҳед дошт: дар паҳлӯи феҳристи тарабхонаҳо менюи тарабхонаи интихобшуда ва сабади фармоиш пайдо мешавад, ки онро редюсер бо useReducer ва амалҳои навъбандишуда идора мекунад. Шумо мефаҳмед, ки чиро дар ҳолат нигоҳ доштан лозим ва чиро ҳисоб кардан, массивҳо ва объектҳоро чӣ тавр бе вайрон кардани React навсозӣ кардан мумкин аст ва чаро ҳукҳоро ба ҳар ҷое даъват кардан мумкин нест.

  • Ҳолатро аз props ва аз тағйирёбандаи оддӣ фарқ кунед ва ҳал намоед, ки маълумот ҳолати худро лозим дорад ё не
  • Массивҳо ва объектҳоро дар ҳолат бе тағйирдиҳии ҷой (map, filter, spread) навсозӣ кунед ва шарҳ диҳед, ки чаро React истинодҳоро муқоиса мекунад
  • Ҳолатро ба наздиктарин волидайни умумӣ бардоред ва ба фарзандон қимат ва колбэкро интиқол диҳед
  • Маълумоти ҳосилшударо пайдо кунед ва онҳоро дар ҳолат такрор накунед
  • Редюсери тозаро нависед ва онро тавассути dispatch даъват кунед, байни useState ва useReducer интихоб намоед
  • Ҳолат ва амалҳоро тавассути discriminated union навъбандӣ кунед ва пуррагии switch-ро бо ёрии never санҷед
  • Қоидаҳои ҳукҳоро номбар кунед, сабаби онҳоро шарҳ диҳед ва хатоҳоеро, ки ҳангоми вайрон кардан пайдо мешаванд, бихонед

01 Ҳолат ва props: кадом маълумот аз они кист

Компонент ду манбаи маълумот дорад. Props — он чизест, ки волидайн ба он додааст: компонент онҳоро танҳо мехонад, мисли аргументҳои функсия. Чаро тағйирёбандаи оддӣ не

Шояд фикр кунед: «useState барои чӣ, ахир let qty = 1 ҳаст». Тағйирёбандаи оддӣ ду мушкил дорад. Якум, таъинкунии он рендерро ба кор намеандозад: React намедонад, ки экранро нав кардан лозим аст. Дуюм, ҳангоми рендери навбатӣ функсияи компонент аз аввал иҷро мешавад, ва let qty = 1 боз якум мешавад. useState ҳарду мушкилро ҳал мекунад: React қиматро берун аз функсия нигоҳ медорад, дар ҳар рендер онро бармегардонад, ва даъвати setQty рендери навро оғоз мекунад.

Оё маълумот ҳолат лозим дорад: чор савол

  1. Он бо мурури замон тағйир меёбад? Агар не, ин собит ё prop аст.
  2. Онро волидайн тавассути props додааст? Пас он аз они шумо нест: онро ба ҳолати худ нусха накунед, prop-ро хонед.
  3. Онро аз ҳолати дигар ё props ҳисоб кардан мумкин аст? Пас ин ҳолат нест, балки маълумоти ҳосилшуда (бахши 4).
  4. Он ба он чизе, ки дар экран намоён аст, таъсир мерасонад? Агар не (масалан, рақами таймер), ҷойи он дар ҳолат нест (баъдтар барои чунин қиматҳо useRef мешавад, дарси 5).

Ҳолати ҳар нусха аз они худаш

Ду компоненти якхела дар саҳифа ҳолатро тақсим намекунанд: ҳар даъвати <Portions /> «ҳуҷайраи» хотираи худро мегирад. Ҳолат ба ҷойи компонент дар дарахт пайваст аст: то даме ки компонент дар ҳамон ҷо истодааст, React онро дар хотир дорад, ва вақте ки компонент аз нишонагузорӣ нопадид мешавад, ҳолат партофта мешавад (вазифаи key ва «компонент дар дохили компонент»-ро аз дарси 3 ба ёд оред).

Монанд аз ҳаёт

Пешхизмат дар чойхона ба ду миз як-як чойник овард. Чойник дар миз — ҳолат аст: он ба миз тааллуқ дорад, ва ки дар он чӣ қадар чой ҳаст, танҳо дар сари ҳамон миз медонанд. Агар ҷамъомадро ба миззи дигар гузаронанд, чойник дар ҷои пештара мемонад: ҳамин тавр компонент, ки дар дарахт ба ҷои дигар гузаштааст, барои React нав аст ва бо хотираи холӣ оғоз мекунад.

Санҷед: ҳар корт ҳолати худро дорад

Дар назди палав ва чой «+»-ро пахш кунед, баъд «Сбросить плов»-ро пахш кунед. Диққат диҳед, ки initial (prop) танҳо қимати оғозӣ-ро медиҳад, ва баъд ҳолат худаш зиндагӣ мекунад.

import { useState } from "react";

function Portions({ name, initial }: { name: string; initial: number }) {
  const [qty, setQty] = useState(initial);
  return (
    <p>
      {name}: <button onClick={() => setQty(qty - 1)}>−</button>{" "}
      <b>{qty}</b> <button onClick={() => setQty(qty + 1)}>+</button>{" "}
      <button onClick={() => setQty(initial)}>Сбросить {name.toLowerCase()}</button>
    </p>
  );
}

export default function App() {
  return (
    <div>
      <Portions name="Плов" initial={1} />
      <Portions name="Чай" initial={2} />
    </div>
  );
}
Хатоҳои маъмул

1. Prop-ро «бо эҳтиёт» ба ҳолат нусха кардан: useState(props.restaurant) қиматро танҳо дар рендери аввал ба ёд мегирад, баъд props-и нав нодида гирифта мешавад, ва маълумот кӯҳна мешавад. 2. Он чиро, ки ҳисоб кардан мумкин аст, дар ҳолат нигоҳ доштан (бахши 4). 3. Тағйир додани prop дар дохили компонент: props танҳо барои хондан аст. 4. Интизор шудан, ки setQty qty-ро ҳамин лаҳза дар ҳамин функсия тағйир медиҳад: қимати нав дар рендери навбатӣ намоён мешавад (бахши 4-и дарси 3). 5. Як пораи ҳолатро дар ду ҷой эълон кардан «барои қулайӣ»: баъд онҳо аз ҳам ҷудо мешаванд.

Ролик бо забони русӣ (16 дақиқа, соли 2025): useState дар амал, иловакунӣ ва навсозии маълумот. Муаллиф бо JavaScript менависад, шумо ҳамин усулҳоро бо навъҳо истифода мебаред.

02 Навсозии тағйирнопазир: тағйир не, балки иваз кардан

Вақте ки шумо setCart(newCart)-ро даъват мекунед, React қимати навро бо қадимӣ аз рӯи истинод муқоиса мекунад (мисли Object.is). Агар истинод яктост, React ҳисоб мекунад, ки чизе тағйир наёфтааст, ва рендерро гузаронда мегузарад. Бинобар ин ҳолати дорои массив ё объектро «дар ҷо» тағйир додан мумкин нест: бояд массиви ё объекти нав сохта, ба set… дод. Ин навсозии тағйирнопазир (иммутабелӣ) номида мешавад. Қимати кӯҳнаро акси яхкардашуда ҳисоб кунед.

Чӣ дар ҷой тағйир медиҳад, ва чӣ нусха месозад

Ҳамаи амалиётҳо бо сабад бо ин чор усул ифода мешаванд. Дар ин ҷо CartItem — навъ аз дарси 2 ({ item: MenuItem; qty: number }):

// добавить в конец
setCart([...cart, { item, qty: 1 }])

// убрать по id
setCart(cart.filter((entry) => entry.item.id !== itemId))

// изменить одну запись: у остальных вернуть тот же объект
setCart(
  cart.map((entry) =>
    entry.item.id === itemId ? { ...entry, qty: entry.qty + 1 } : entry,
  ),
)

// вставить в начало
setCart([{ item, qty: 1 }, ...cart])

// отсортировать: сначала копия, потом sort
setCart([...cart].sort((a, b) => a.item.price - b.item.price))

Нусха сатҳӣ аст: { ...entry, qty: 5 } объекти нави сабт месозад, вале объекти дохилии entry.item ҳамон мемонад. Ин муқаррарӣ аст, агар шумо танҳо сатҳи болоиро тағйир диҳед. Агар лозим бошад, ки майдони объекти дохилиро тағйир диҳед, ҳар сатҳро дар роҳи ба он нусха кунед:

// поменять цену блюда внутри записи корзины
setCart(
  cart.map((entry) =>
    entry.item.id === itemId
      ? { ...entry, item: { ...entry.item, price: 50 } }
      : entry,
  ),
)

Дохилшавии амиқ зуд номувофиқ мешавад. Аз ин рӯ дар ҳолат кӯшиш мекунанд, ки маълумотро ҳамвор нигоҳ доранд, ва барои ҳолатҳои мураккаб китобхонаи Immer ҳаст: он имкон медиҳад, ки «гӯё бо тағйирдиҳии ҷой» навишта шавад, ва дар асл нусха месозад. Шумо онро дар Redux Toolkit мебинед (дарси 9). Ҳоло map, filter ва spread басанд.

Навъҳо кӯмак мекунанд: readonly

TypeScript метавонад тағйирдиҳии ҷойро манъ кунад. Навъи readonly CartItem[] (ё ReadonlyArray<CartItem>) аз массив методҳои тағйирдиҳандаро мегирад ва таъинкуниро аз рӯи индекс манъ мекунад. Агар параметри функсияро ҳамин тавр эълон кунед, компилятор намегузорад, ки массиви омадаро тасодуфан тағйир диҳед:

src/ro.ts(3,9): error TS2339: Property 'push' does not exist on type 'readonly CartItem[]'.
src/ro.ts(4,3): error TS2542: Index signature in type 'readonly CartItem[]' only permits reading.

readonly — муҳофизати вақти компилятсия аст, дар барномаи кунунӣ массив оддӣ мемонад. Майдони объект чунин муҳофизат мешавад: readonly qty: number. Навъи Readonly<T> ҳамаи майдонҳои объекти T-ро танҳо барои хондан мегардонад (навъҳои ёрирасон муфассалтар — дарси 9).

Монанд аз ҳаёт

Менюи чойхонаро дар як варақ чоп мекунанд. Агар дар он бо қалам хӯрокеро хат занед, маъмуре, ки варақҳоро аз рӯи рақами партия муқоиса мекунад, ислоҳро намебинад: рақам ҳамон аст. Бинобар ин барои менюи нав варақи нав бо рақами нав чоп мекунанд. Варақ — массив, рақами партия — истинод, ва чопи типографӣ — spread ва map аст.

Хатоҳои маъмул

1. cart.push(item); setCart(cart): истинод пештара, рендер нест. 2. entry.qty += 1; setCart([...cart]): массив нав аст, вале объектҳои дохилаш дар ҷо тағйир ёфтаанд, яъне «акси кӯҳна» низ вайрон шуд. Қисмҳои дигари барнома, ки истинод ба сабтро доранд, тағйироти бегонаро мебинанд. 3. const sorted = cart.sort(…): sort худи массивро тағйир медиҳад ва ҳамонро бармегардонад. 4. setUser(user.name = 'Алишер'): таъинкунӣ — ибора аст, он сатрро бармегардонад, на объектро. 5. Нусха кардани массив тавассути const copy = cart: ин истиноди дигар ба ҳамон массив аст, на нусха.

ВАЗИФАИ 2.1

Худро санҷед: тағйирнопазирӣ

миёна

Барномасоз cart.push(item); setCart(cart); навишт ва шикоят мекунад, ки экран тағйир намеёбад. Чаро?

  1. Методи push бо массиви объектҳо кор намекунад
  2. Ду маротиба паси ҳам setCart-ро даъват кардан мумкин нест
  3. Истинод ба массив пештара монд, React истинодҳоро муқоиса мекунад ва тағйиротро намебинад
  4. Бояд forceUpdate-ро даъват кард

React рендер лозим аст ё не, бо муқоисаи қимати нав бо кӯҳна аз рӯи истинод ҳал мекунад. Массиви навро диҳед: setCart([...cart, item]).

Кадом навиштаҳо ҳолатро дуруст навсозӣ мекунанд? Ду варианти ҷавобро интихоб кунед.

  1. cart[0].qty = 5; setCart(cart)
  2. setCart(cart.map((e) => (e.item.id === 1 ? { ...e, qty: 5 } : e)))
  3. setCart(cart.sort((a, b) => a.qty - b.qty))
  4. setCart([...cart].sort((a, b) => a.qty - b.qty))

Дар варианти якум тағйирдиҳии ҷой аст, дар сеюм sort массиви аслиро тағйир медиҳад ва ҳамон истинодро бармегардонад. Дар дуюм ва чорум қиматҳои нав сохта мешаванд.

Дар коди setCart(cart.map((e) => { e.qty += 1; return e; })) массив нав аст. Чӣ нодуруст аст?

  1. Объектҳои дохилӣ дар ҷо тағйир ёфтаанд: акси кӯҳна вайрон шуд, истинодҳои дигар ба ин объектҳо тағйироти бегонаро мебинанд
  2. Ҳеҷ чиз: массив нав аст, яъне ҳама дуруст аст
  3. map-ро бо ҳолат истифода бурдан мумкин нест
  4. Бояд массив баргардонд, на объект

Массиви нав тағйирдиҳии объектҳои дохилашро бекор намекунад. Барои сабт объекти нав лозим аст: { ...e, qty: e.qty + 1 }.

03 Боло бурдани ҳолат: як манбаи ҳақиқат

Ҳолате мешавад, ки ба ду компонент як маълумот лозим аст. Дар «Дастархон» меню хӯрокҳоро ба сабад меандозад, ва сабад онҳоро нишон медиҳад. То даме ки ҳар кадомаш ҳолати худро дорад, онҳо ҳамоҳанг намешаванд: меню «намедонад», ки дар сабад чӣ ҳаст. Ҳал боло бурдани ҳолат (lifting state up) номида мешавад: ҳолатро ба наздиктарин волидайни умумӣ гузаронед, ва ба фарзандон қиматро тавассути props ва функсияи коркардкунандаро тавассути колбэк диҳед.

Алгоритм аз чор қадам: 1) ҳамаи компонентҳоеро, ки ба ин маълумот ниёз доранд, ёбед; 2) наздиктарин волидайни умумии онҳоро ёбед; 3) ҳолатро дар он ҷо эълон кунед; 4) қиматро тавассути props ба поён диҳед, ва тағйиротро тавассути функсия (onAdd, onChange). Компоненти фарзанд нусха нигоҳ намедорад, он чиро, ки гирифтааст, нишон медиҳад ва дар бораи рӯйдод хабар медиҳад.

function PortionControl({ qty, onChange }: { qty: number; onChange: (qty: number) => void }) {
  return (
    <div>
      <button onClick={() => onChange(qty - 1)}>−</button> {qty}{' '}
      <button onClick={() => onChange(qty + 1)}>+</button>
    </div>
  )
}

function OrderTotal({ qty, price }: { qty: number; price: number }) {
  return <p>Итого: {qty * price} сомони</p>
}

export default function App() {
  const [qty, setQty] = useState(1) // состояние живёт у родителя

    <>
      <PortionControl qty={qty} onChange={setQty} />

Ҳолатро аз зарурат баландтар набаред. Агар маълумот танҳо ба як компонент лозим бошад, бигзор дар он зиндагӣ кунад. Ифрати дигар: ҳолат ба боми боло бардошта шудааст, ва бояд онро аз панҷ сатҳи компонентҳое, ки ба он лозим нестанд, гузаронд. Ин prop drilling номида мешавад. Барои он Context ҳаст (дарси 8), вале аввал санҷед, ки масъаларо бо композитсия ҳал кардан мумкин нест: JSX-и тайёрро тавассути children интиқол диҳед (дарси 3).

Монанд аз ҳаёт

Дар тӯйи Душанбе ду ошпаз палав ва самбӯса мепазанд ва ҳарду рӯйхати меҳмононро алоҳида доранд. Яке 120 нафар навишт, дигаре 150: хӯрок гоҳ аз ҳад зиёд, гоҳ намерасад. Як рӯйхат назди тақсимкунанда (волидайни умумӣ) лозим аст. Ошпазон аз ӯ рақамро мегиранд ва ба ӯ «меҳмон илова шуд» хабар медиҳанд.

ВАЗИФАИ 3.1

  2. Дар ҳарду компонент ва дастӣ ҳамоҳанг кардан
  3. Дар наздиктарин волидайни умумӣ, ки маълумотро тавассути props ба поён медиҳад, ва рӯйдодро тавассути колбэк мегирад
  4. Дар тағйирёбандаи глобалӣ берун аз компонентҳо

  3. setState-и волидайнро бевосита аз рӯи истинод даъват мекунад
  4. Ҳеҷ чиз: фарзандон наметавонанд ба волидайн дар бораи рӯйдод хабар диҳанд

Маълумот ба поён меравад, рӯйдодҳо ба боло: фарзанд функсияи додашударо даъват мекунад, волидайн ҳолатро навсозӣ мекунад ва ҳамаро, ки онро истифода мебаранд, аз нав мекашад.

import { useReducer } from "react";

function reducer(state, action) {
  switch (action.type) {
    case "add":
      return [...state, action.title];
    case "removeLast":
      return state.slice(0, -1);
    case "clear":
      return [];
    default:
      throw new Error("Неизвестное действие: " + action.type);

}

Редюсер бе навъҳо — ин switch аз рӯи сатр аст, ки дар он хатои имлоии 'add' бесадо кор намекунад. Бо навъҳо компилятор ҳар амал ва ҳар шоҳаро месанҷад. Усули асосӣ — discriminated union (иттиҳоди нишондодашуда, шумо онро дар дарси 2 дидаед): маҷмӯи навъҳои объектӣ бо майдони умумии нишонаи type, ки ҳар навъ сатри литерали худ ва майдонҳои иловагии худро дорад.

import { assertNever } from './assertNever'
import type { CartItem, MenuItem } from './types'

export type CartAction =
  | { type: 'add'; item: MenuItem }
  | { type: 'remove'; itemId: number }
  | { type: 'setQty'; itemId: number; qty: number }
  | { type: 'clear' }

export function cartReducer(state: CartItem[], action: CartAction): CartItem[] {
  switch (action.type) {
    case 'add': {
      const exists = state.some((entry) => entry.item.id === action.item.id)
      if (!exists) {
        return [...state, { item: action.item, qty: 1 }]
      }
      return state.map((entry) =>
        entry.item.id === action.item.id
          ? { ...entry, qty: entry.qty + 1 }
          : entry,
      )
    }
    case 'remove':
      return state.filter((entry) => entry.item.id !== action.itemId)
    case 'setQty': {
      if (action.qty <= 0) {
        return state.filter((entry) => entry.item.id !== action.itemId)
      }
      return state.map((entry) =>
        entry.item.id === action.itemId ? { ...entry, qty: action.qty } : entry,
      )
    }
    case 'clear':
      return []
    default:
      return assertNever(action)
  }
}

  3. Барои такмил баргардондан: массив нав аст, вале объекти сабт дар ҷо тағйир ёфтааст, яъне ин тағйирдиҳии ҷой аст; map бо нусхаи сабт лозим аст

function reducer(state, action) {
  switch (action.type) {
    case "add": {
      const exists = state.some((e) => e.id === action.id);
      if (!exists) return [...state, { id: action.id, qty: 1 }];
      return state.map((e) => (e.id === action.id ? { ...e, qty: e.qty + 1 } : e));

      const entry = state.find((e) => e.id === action.id);
      if (entry) entry.qty = action.qty;
      return [...state];
    }
    default:
      throw new Error("Неизвестное действие: " + action.type);
  }
}

export function cartReducer(state: CartItem[], action: CartAction): CartItem[] {
  switch (action.type) {
    case 'add': {
      const exists = state.some((entry) => entry.item.id === action.item.id)
      if (!exists) {
        return [...state, { item: action.item, qty: 1 }]
      }
      return state.map((entry) =>
        entry.item.id === action.item.id
          ? { ...entry, qty: entry.qty + 1 }
          : entry,
      )
    }
    case 'remove':
      return state.filter((entry) => entry.item.id !== action.itemId)
    case 'setQty': {
      if (action.qty <= 0) {
        return state.filter((entry) => entry.item.id !== action.itemId)
      }
      return state.map((entry) =>
        entry.item.id === action.itemId ? { ...entry, qty: action.qty } : entry,
      )
    }
    case 'clear':
      return []
    default:
      return assertNever(action)
  }
}

  • Метавонам фарқи ҳолат, props ва тағйирёбандаи оддиро шарҳ диҳам ва ҳал кунам, ки маълумот ҳолат лозим дорад ё не
  • Метавонам массив ва объекти дохилиро дар ҳолат бе тағйирдиҳии ҷой навсозӣ кунам ва шарҳ диҳам, ки чаро React истинодҳоро муқоиса мекунад
  • Метавонам ҳолатро ба волидайни умумӣ боло бурда, ба поён қиммат ва колбэк диҳам
  • Метавонам дар компонент маълумоти ҳосилшударо ёфта, онро аз ҳолат хориҷ кунам
  • Метавонам редюсери тозаи сабадро навишта, онро тавассути dispatch даъват кунам
  • Метавонам амалҳоро ҳамчун иттиҳоди нишондодашуда навъбандӣ карда, пуррагии switch-ро тавассути never санҷам
  • Метавонам қоидаҳои ҳукҳоро номбар карда, сабаби онҳоро шарҳ диҳам ва паёми линтерро бихонам
  • Метавонам коди агентро аз рӯи тағйирдиҳии ҷой ва таъсирҳои иловагӣ дар редюсер санҷам
