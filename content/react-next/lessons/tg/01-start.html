01 React чист ва барои чӣ лозим аст

Вақте интерфейсро бо дасти худ менависед, ба браузер қадам ба қадам фармон медиҳед: «унсурро ёб, матнро иваз кун, синф илова намо, блоки навро гузор». Экран калон шавад, чунин фармонҳо бисёртар мешаванд ва фаромӯш кардани яке аз онҳо осонтар мешавад. Экран ва маълумот аз ҳам ҷудо мешаванд ва хатоҳое пайдо мешаванд, монанди «дар сабад 3 мол аст, аммо дар нишона 2 навишта шудааст».

React равишро иваз мекунад. Шумо тасвир мекунед, ки экран бо маълумоти додашуда чӣ гуна менамояд: «агар молҳо 3 бошанд, се сатр ва рақами 3-ро нишон деҳ». Баъд React худаш натиҷаи навро бо кӯҳна муқоиса мекунад ва DOM-ро нуқтавӣ нав менамояд. Формулаи кӯтоҳе, ки бояд дар хотир дошт: UI = функсия(ҳолат).

Монанд аз ҳаёт

Дар чойхона шумо ба пешхизмат мегӯед: «Палав ва чой мехоҳам». Шумо шарҳ намедиҳед, ки сабзиро чӣ тавр бурида, биринҷро чанд вақт пазед. Ин равиши декларативӣ аст ва React ҳам ҳамин тавр кор мекунад: шумо натиҷаро фармоиш медиҳед («экран бо се хӯрок»), роҳи расидан ба онро ошхона ҳал мекунад. DOM-и дастӣ ба худатон пухтан монанд аст: ҳар қадам ба зиммаи шумост.

Санҷед: ҳамин интерфейс дар React

Ин қуттии регии зинда аст. Тугмаҳоро пахш кунед, баъд матнро тағйир диҳед ва аз нав иҷро намоед. Дукуктаҳо баъди номҳо дар код (name: string) навъҳои TypeScript мебошанд. Ҳоло кифоя аст онҳоро шинохтан ва хондан, навъҳоро муфассал дар дарси 2 мебинем.

import { useState } from "react";

type CardProps = { name: string; cuisine: string };

function Card({ name, cuisine }: CardProps) {

      <button onClick={() => setLiked(!liked)}>{liked ? "♥" : "♡"}</button>
    </li>
  );
}

React — китобхона аст, на фреймворк

React танҳо барои як чиз масъул аст: интерфейс чӣ гуна менамояд бо маълумоти додашуда. Саҳифаҳо ва суроғаҳо, ҳолати умумӣ, дархостҳо ба сервер, шаклҳо ва санҷишҳо дар React дохил нестанд: барои ҳар кадом абзори алоҳида ҳаст. Барои ҳамин курс чунин сохта шудааст: аввал худи React ва TypeScript, баъд якбаякин лозимаро пайваст мекунем (шаклҳо, Redux Toolkit, RTK Query, React Router, санҷишҳо) ва дар дарсҳои 15–24 ба Next.js мегузарем, ки дар он бисёр чиз аллакай ба як ҷамъ омадааст.

Тасаввуроти хато

1. «React фреймворк аст». Не, ин китобхона барои интерфейс аст; роутинг ва маълумотро худатон интихоб мекунед. 2. «React худаш сайтро тез мекунад». Не, ӯ барои нигоҳдории интерфейсҳои калон қулай аст, суръат аз коди шумо вобаста аст. 3. «React ва Next.js як чиз аст». Next.js фреймворкест, ки дар асоси React сохта шудааст. 4. «Бояд тамоми JavaScript-ро пеш аз React омӯхт». Асос аз курсҳои пештара кифоя аст, боқиро дар роҳ меомӯзед.

03 Node.js-ро месанҷем ва лоиҳа эҷод мекунем

Ҳамаи абзорҳои курс (Vite, TypeScript, Prettier, баъдтар Next.js) дар Node.js кор мекунанд. Vite 8 Node.js 20.19+ ё 22.12+-ро талаб мекунад. Дар 28 октябри соли 2026 хати 22 ва 24 дастгирии дарозмӯҳлат (LTS) доранд, LTS-и навро аз nodejs.org гиред.

  1. Версияҳоро санҷед. Терминалро кушоед (дар Cursor: Ctrl + `) ва иҷро кунед: 
    node -v
npm -v
git --version
    Бояд v22.12 ва болотар (ё v24.x), версияи npm ва версияи Git намоён шавад. Агар версияи Node поёнтар бошад ё фармон ёфт нашавад, LTS-ро аз nodejs.org насб кунед ва терминалро аз нав оғоз намоед.
  2. Папкаро барои лоиҳаҳо интихоб кунед. Роҳ бе кириллитса ва фосила, на дар дохили OneDrive ё iCloud. Ба он бо фармони cd гузаред.
  3. Лоиҳаро эҷод кунед. 
    npm create vite@latest dastarkhon -- --template react-ts
    Агар устод савол диҳад: ба «Which linter to use?» Oxlint-ро интихоб кунед (чаро — дар бахши 5 шарҳ медиҳем), ба «Install with npm and start now?» No ҷавоб диҳед: насбро худамон мекунем.
  4. Вобастагиҳоро насб ва оғоз кунед. 
    cd dastarkhon
npm install
npm run dev
    Дар терминал суроғаи http://localhost:5173/ пайдо мешавад. Онро дар браузер кушоед: саҳифаи оғозии Vite-ро бо ҳисобкунак мебинед. Тугмаро пахш кунед, баъд ягон матнро дар src/App.tsx иваз кунед ва захира намоед: саҳифа бе аз нав боркунӣ нав мешавад (ин HMR аст). Сервер: қатъ кардан Ctrl + C.
  5. Лоиҳаро дар муҳаррир кушоед: cursor . ё «File → Open Folder».

Please upgrade your Node.js version.» Версияи Node хеле кӯҳна аст: LTS-ро насб кунед ва терминалро аз нав оғоз намоед. «npm: command not found»: Node.js насб нашудааст ё терминал аз нав оғоз нашудааст. 04 Сохтори лоиҳа: файл ба файл

Лоиҳаро кушоед ва ин файлҳоро ёбед. Ҳар яки онро ё бояд ламс кунед, ё ҳадди аққал фаҳмед.

Аз React 19 чӣ фавран ба чашм мерасад

ref — prop-и оддӣ. Пештар компонентеро, ки ref мегирад, бояд бо forwardRef печонданд. Ҳоло кифоя аст, ки ref-ро аз props гиред:

function SearchInput({ placeholder, ref }) {
  return <input placeholder={placeholder} ref={ref} />;
}

export default function App() {
  const inputRef = useRef(null);
  return (
    <div>
      <SearchInput placeholder="Найти ресторан" ref={inputRef} />
      <button onClick={() => inputRef.current?.focus()}>В поиск</button>
    </div>
  );
}

Context бе .Provider. Ба ҷои <ThemeContext.Provider value="dark"> менависем <ThemeContext value="dark">. Навишти кӯҳна ҳоло кор мекунад, аммо мансух эълон хоҳад шуд. Тафсилот дар дарси 8.

Агар зеҳни сунъӣ ё дастури кӯҳна чунин код пешниҳод кунад, ин ишорат аст: мисол кӯҳна шудааст.

TypeScript ва React 19. useRef ҳоло ҳамеша қимати аввалиро талаб мекунад (useRef(null)), ва ref-callback набояд қиматро ғайриошкоро баргардонад: менависем ref={(el) => { node = el }}, на ref={(el) => (node = el)}. Матнҳои хатоҳо дар чунин ҳолатҳо худашон ислоҳро мегӯянд.
