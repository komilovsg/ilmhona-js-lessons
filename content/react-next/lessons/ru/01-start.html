02 TypeScript: проверка типов

Блок с data-lang="ts" проверяется настоящим компилятором TypeScript, затем запускается как обычный JavaScript.

interface User {
  name: string;
  age: number;
}

const user: User = { name: "Зарина", age: 20 };
const greet = (u: User): string => `Привет, ${u.name}!`;
console.log(greet(user));

const price: number = "100";
console.log(price * 2);
ЗАДАЧА 2.1

Исправь ошибку типов

лёгкая

Код выводит сумму заказа, но компилятор TypeScript ругается. Исправьте ошибку типов, не меняя вывод.

function total(price: number, qty: number): number {
  return price * qty;
}

console.log(total("250", 3));
Ожидаемый результат
750
Подсказка 1

Функция ждёт число, а получила строку в кавычках. Уберите кавычки у 250.
