Дарси 6 · Муҳити корӣ: Cursor

Cursor ба ҳадди аксар: Agent, қоидаҳои лоиҳа, MCP

То охири дарс шумо низоми худии кор бо агенти AI-ро дошта мешавед: файли қоидаҳои лоиҳа (AGENTS.md), одати «аввал нақша, баъд код», браузери пайвастшуда, ки агент худаш саҳифаи шуморо мекушояд ва натиҷаро месанҷад, ва суғуртае, ки имкон медиҳад ҳар хатои ӯро бе дарди сар баргардонед. Лендинги дарси 5-ро бо як промпти калон беҳтар мекунед ва хатои воқеии терминалро якҷоя бо AI ислоҳ менамоед.

  • Промпти бад («сайт созед») ва хубро (нақш, стек, талабот, санҷиш) фарқ кардан ва промптҳои заифро аз нав навиштан
  • Реҷаи чатро интихоб кардан: Agent, Ask ё Plan, ва аз рӯи нақшаи «аввал нақша, баъд код» кор кардан
  • Контекстро тавассути @ пайваст кардан ва қоидаҳои лоиҳаро дар файлҳои .cursor/rules ва AGENTS.md ба агент фаҳмондан
  • JSON-и оддиро (ҷуфтҳои «калид — қимат») хондан ва таҳрир кардан ва ба Cursor сервери MCP бо браузер пайваст кардан
  • Тағйироти агентро бо се роҳ баргардондан: checkpoint дар Cursor, «Discard Changes» дар Source Control ва commit пеш аз вазифаи калон
  • Хатои терминалро бо AI таҳлил кардан ва дар чати гурӯҳ чунон кӯмак пурсидан, ки бори аввал ҷавоб диҳанд
Ин дарсро чӣ тавр гузаштан лозим

Лозим мешавад: лоиҳаи dental-landing аз дарси 5 (он дар Cursor кушода мешавад, дар GitHub нигоҳ дошта мешавад ва дар Vercel нашр шудааст), Node.js, интернет ва тақрибан 2,5 соат. Дарсро дар як нимаи экран ва Cursor-ро дар нимаи дигар кушоед. Назарияро (бахшҳои 1–7) қисм-қисм хонед, амалиётро (бахши 8) якбора иҷро кунед. Дар охир: «Дуэли промптҳо» ва вазифаи хонагӣ.

Агар лоиҳаи дарси 5 нагирифта бошад, ба рӯйхатҳои санҷиши он баргардед: дар ин ҷо ба он бе такрор такя мекунем.

01 Реҷаҳои чат: аввал нақша, баъд код

Дар дарси 5 агент саҳифаро аз рӯи як промпт менавишт. Ин то замоне кор мекунад, ки вазифа хурд бошад. Дар вазифаи калон («лендингро аз нав кун») агент метавонад якбора ба самти нодуруст код навишта равад ва шумо барои баргардонидан вақт сарф мекунед. Аз ин сабаб барномасозони боэътимод кори худро ду қадам тақсим мекунанд: аввал нақша, баъд код. Cursor инро бо реҷаи дарунсохт дастгирӣ мекунад.

Agent
Реҷаи асосӣ: агент худаш файлҳои лоиҳаро мехонад, таҳрир мекунад ва фармонҳоро дар терминал иҷро мекунад. Шумо дар дарси 5 маҳз ҳамин реҷаро истифода бурдед.
Plan
Реҷаи нақшакашӣ: агент саволҳои возеҳкунанда медиҳад, лоиҳаро меомӯзад ва нақшаи кор тартиб медиҳад. Код танҳо баъд аз он тағйир меёбад, ки шумо нақшаро санҷидед ва тугмаи оғозро пахш кардед (тибқи ҳуҷҷатҳои Cursor — «сохтани нақша»). Бо гузариши реҷаҳо ё бо пахши Shift+Tab дар майдони воридкунии чат фаъол мешавад.
Ask
Реҷаи саволҳо: коди ягонаро шарҳ додан, ғоя пешниҳод кардан, бе тағйири файлҳо. Вақте мувофиқ аст, ки фаҳмидан лозим аст, на кардан. Рӯйхати реҷаҳо аз версия вобаста аст: дар рӯйхат метавонанд реҷаҳои дигар низ бошанд (масалан, Debug барои ёфтани сабаби хатогӣ).

Видеои кӯтоҳ бо забони англисӣ (2 дақиқа, зернависро фаъол кунед): реҷаи Plan дар муҳаррир чӣ тавр менамояд. Интерфейс тағйир меёбад, аммо тартиби «саволҳо → нақша → оғоз» мемонад.

Пеш аз код нақша кашидан ба таъмири хона дар Душанбе монанд аст. Устое, ки якбора девор шикастанро сар кард, метавонад девори борбардорро шиканад. Устои хуб аввал хонаро давр мезанад, савол медиҳад («ошхонаро куҷо мегузорем? розеткаҳо куҷоянд?»), нақша мекашад ва танҳо баъд аз «ҳа»-и шумо болға мегирад. Реҷаи Plan ҳамин гуна уст аст.

Хатогиҳои маъмули навомӯзон

1. Тугмаи «оғоз»-ро бе хондани нақша пахш кардан: маънои реҷа дар санҷиш аст. 2. Plan-ро барои ислоҳи як калима фаъол кардан: дақиқаҳои беҳуда. 3. Ба саволҳои агент «чӣ хел хоҳӣ» ҷавоб додан: ҷавоби «чӣ хел хоҳӣ» саҳифаи миёна медиҳад, на аз они шумо. 4. Нақшаро ислоҳ накардан, вақте ки дар он чизи зиёдатӣ ҳаст: навиштан мумкин аст «қадами 4-ро хориҷ кун, он лозим нест» ва нақша нав мешавад.

  3. Нест карда, аз нав сохта мешаванд
  4. Ба GitHub фиристода мешаванд

Нақша — матни пешниҳодист. Танҳо баъд аз он ки шумо онро санҷида оғоз кардед, агент файлҳоро таҳрир мекунад.

02 Промпти бад ва хуб, @-контекст

Агент фикрро намехонад: вай матни шумо ва он файлҳоро мебинад, ки худаш ёфтааст ё шумо нишон додаед. Ҳар қадар дархост дақиқтар бошад, ислоҳҳо камтар мешаванд. Дар дарси 2 шумо формулаи «контекст → мақсад → маҳдудиятҳо → мисолҳо → санҷиш»-ро омӯхтед. Барои агент дар лоиҳа онро ба чор қисм ҷудо кардан қулай аст: нақш, стек, талабот, санҷиш.

Промпти бад

@-контекст: ба агент чизи лозимаро нишон додан

Агент худаш дар лоиҳа ҷустуҷӯ мекунад, аммо баъзан файли нодурустро мегирад. Дар майдони чат аломати @-ро ворид кунед: рӯйхати он чизе, ки ба паём замима кардан мумкин аст, пайдо мешавад. Тибқи ҳуҷҷатҳои Cursor ин файлҳо ва ҷузвдонҳо (масалан, @page.tsx ё @app/components/), баромади терминал (@Terminals), чатҳои пешина (@Chats), тағйирот дар Git (@Commit ва @Branch) ва браузери дарунсохт (@Browser) мебошанд. Тасвирро, масалан скриншоти хатогӣ ё макетро, ба майдони чат кашида андозед ё аз буфери мубодила гузоред.

Қоидаҳои кор бо агент

1. Вазифаи калон — аввал Plan. 2. Файли таҳрири лозимиро тавассути @ замима кунед. 3. Санҷиши натиҷаро хоҳиш кунед: npm run build ва тавсифи тағйирот. 4. Кодеро, ки шарҳ дода наметавонед, қабул накунед: аз агент шарҳ пурсед. 5. Розҳо (калидҳои дастрасӣ)-ро ҳеҷ гоҳ дар промптҳо нанависед ва файлҳои .env-ро замима накунед. 6. Агар ҷавоб он набошад, дар ҳамон чат возеҳ кунед.

Монандӣ аз ҳаёт

Промпти «сайт созед» ба фармоиши таксӣ бо суханони «баро ба ягон ҷо» монанд аст. Промпти хуб — «аз Рӯдакӣ то фурудгоҳ, ду ҷомадон, оромона». Ва файлҳои @ — мисли нишон додани суроға дар харита ба ронанда: имкони ба ҷои дигар рафтан камтар.

Хатогиҳои маъмули навомӯзон

1. Тавассути @ тамоми ҷузвдони лоиҳаро «барои эҳтиёт» замима кардан: садои зиёдатӣ ба агент халал мерасонад. 2. Дар як паём якчанд вазифаи бо ҳам алоқамандро нанавишта нависед. 3. Ба агент ҷанҷол кардан ба ҷои возеҳ намудан: ибораи «ту ҳамаро вайрон кардӣ» чизеро шарҳ намедиҳад, аммо «бахши хидматҳо нопадид шуд, онро баргардон, боқиро нигоҳ дор» шарҳ медиҳад. 4. Стекро номнагирифтан: он гоҳ китобхонаи дигар пайдо шуданаш мумкин.

03 Қоидаҳои лоиҳа: .cursor/rules ва AGENTS.md

Агент ҳар чатти навро «аз саҳифаи холӣ» оғоз мекунад: вай намедонад, ки шумо дирӯз чӣ хоҳиш кардед. То ки як гапро такрор накунед («бо русӣ нависед», «танҳо Tailwind», «build-ро иҷро кун»), ин созишҳоро дар файли қоидаҳо менависанд ва Cursor онро ба ҳар дархост илова мекунад. Ин мисли дастурамал барои кормандест, ки ҳар рӯз аз нав меояд.

AGENTS.md
Файли матнии оддӣ дар решаи лоиҳа (формати Markdown, бе майдонҳои хизматӣ). Cursor онро мехонад ва агентҳои дигари AI низ: ин «стандарти» умумӣ аст. Файлҳои дохили AGENTS.md дар зерҷузвдонҳо дар дохили ҳамон ҷузвдонҳо амал мекунанд ва файли мушаххастар муҳимтар аст. Аз ҳамин файл оғоз кунед: он аз ҳама содда аст.
.cursor/rules
Ҷузвдони қоидаҳои Cursor. Ҳар қоида — файли алоҳида бо тамдиди .mdc (тибқи ҳуҷҷатҳо, .md-и оддӣ дар ин ҷузвдон кор намекунад). Дар аввали файл майдонҳои хизматӣ ҷойгиранд: description (тавсиф), globs (барои кадом файлҳо, масалан app/**/*.tsx) ва alwaysApply (ҳамеша татбиқ шавад ё не). Навъи қоидаро дар танзимот интихоб мекунанд: ҳамеша, аз рӯи маъно, барои файлҳои муайян ё дастӣ.
.cursorrules
Роҳи кӯҳна: як файл дар реша. Он ҳанӯз дар мақолаҳои қадима вомехӯрад, аммо кӯҳна ҳисоб меёбад: аз он оғоз накунед.

Қоидаро чӣ тавр сохтан

Роҳи аз ҳама содда — худи агентро хоҳиш кардан: дар чат /create-rule-ро ворид кунед ва қоидаро бо суханон тасвир намоед. Ё танзимоти Cursor-ро кушоед (бахши «Customize», банди «Rules») ва қоидаро бо тугмаи «Add Rule» илова кунед. Ва AGENTS.md — танҳо файл аст: онро дар решаи лоиҳа созед ва қоидаҳоро бо бандҳои оддӣ нависед.

# Проект: лендинг стоматологии «Улыбка»

## Стек
- Next.js (App Router, TypeScript) и Tailwind CSS. Другие библиотеки не добавлять без вопроса.

## Стиль
- Стили только классами Tailwind, без отдельных CSS-файлов.
- Секции страницы лежат в app/components, по одному компоненту на файл.
- Тексты на сайте на русском, данные вымышленные.

## Безопасность
- Никаких ключей и паролей в коде. Секреты только в .env, а .env не коммитить.

## Проверка
- После правок запускай npm run build и исправляй ошибки.
- В конце коротко перечисли изменённые файлы.

Намунаи AGENTS.md бо русӣ боқӣ мемонад: агент онро бо ҳамин забон хонда, аз рӯи он кор мекунад. Файли худро метавонед бо забони дилхоҳ нависед.

Видео бо забони русӣ: порча дар бораи қоидаҳо (Rules) дар Cursor. Аз ҷои қайдшуда 6–8 дақиқа тамошо кунед; тамоми видео хеле дароз аст (тақрибан 2,5 соат) ва пурра лозим нест.

Файли қоидаҳо — мисли ёддошт дар назди дари чойхона барои пешхидмати нав: «чойро аввал медиҳем», «фармоишро бо овози баланд такрор мекунем», «бе фармоиш ба ошхона намедароем». Пешхидмат метавонад ҳар рӯз нав бошад, аммо тартиб мемонад.

04 JSON бо ангуштон: калид ва қимат

Танзимоти MCP дар Cursor дар файли формати JSON нигоҳ дошта мешавад. Тарсидан лозим нест: ин «анкета»-и ҷуфтҳои калид — қимат аст. Шумо чунин чизро дар package.json дидаед. Инак як одам дар шакли JSON:

{
  "name": "Madina",
  "age": 22,
  "city": "Dushanbe",
  "student": true,
  "languages": ["tg", "ru", "en"],
  "contacts": { "telegram": "@madina_example" }
}
  • Қавсҳои ҷингилагӣ { } — «қуттӣ» бо ҷуфтҳо. Дар дохил ҷуфтҳои "калид": қимат бо вергул ҷудо шудаанд.
  • Калид — ҳамеша дар нохунакҳои дучанд: "name". Ин номи майдон аст.
  • Қимат — сатр дар нохунакҳои дучанд ("Madina"), адад (22), true ё false, рӯйхат дар қавсҳои мураббаъ [ ] ё қуттии дигар { } дар дохил.
  • Вергул байни ҷуфтҳо лозим аст, ва баъд аз ҷуфти охирин он нест. Нохунакҳои ягона ва шарҳҳо дар JSON манъ аст.

Худатон кӯшиш кунед. Дар поён — барномаи хурде, ки JSON-ро мехонад. Онро иҷро кунед, баъд дар матн ном иваз кунед, ба рӯйхати args як калимаи дигар илова намоед ва аз нав иҷро кунед. Баъд JSON-ро қасдан вайрон кунед (масалан, нохунаки калидро хориҷ кунед) ва ба хабари хатогӣ нигоҳ кунед.

// матн дар формати JSON: танзимоти сервер, мисли дар mcp.json
const text = `{
  "name": "playwright",
  "command": "npx",
  "args": ["@playwright/mcp@latest"]
}`;

try {
  const cfg = JSON.parse(text);          // матнро ба объект табдил медиҳем
  console.log("Имя:", cfg.name);          // қимат аз рӯи калиди name
  console.log("Команда:", cfg.command);
  console.log("Слов в args:", cfg.args.length);
} catch (e) {
  console.log("Ошибка в JSON:", e.message); // ба ин ҷо меафтем, агар JSON вайрон бошад
}
Дар JSON чӣ тавр хато накардан

Муҳаррир вергул ё нохунакҳои зиёдатӣ ё нопайдоро бо сурх зери хат мегирад. Агар файл кор накунад, онро ба чат нусха кунед ва хоҳиш намоед: «хатогиро дар ин JSON ёб ва варианти ислоҳшударо нишон деҳ». Агент инро фавран иҷро мекунад.

Монандӣ аз ҳаёт

JSON — мисли анкета барои гузарномаи вуруд: «Насаб: Раҳимова», «Синну сол: 22», «Забонҳо: тоҷикӣ, русӣ». Дар чап номи сутун (калид), дар рост ҷавоб (қимат). Рӯйхати забонҳо — сутуне, ки якчанд ҷавоб дорад, ва тамосҳо — анкета дар дохили анкета.

Хатогиҳои маъмули навомӯзон

1. Вергул баъд аз ҷуфти охирин: "b": 2, пеш аз қавси бастанда. 2. Нохунакҳои ягона 'name' ба ҷои дучанд. 3. Калид бе нохунак: name: "Madina". 4. Шарҳҳои // дар дохили JSON: онҳо дар он вуҷуд надоранд. 5. Қавси бастандаро фаромӯш кардан: барои ҳар { бояд } бошад.

05 MCP: ба агент браузер ва ҳуҷҷатҳо медиҳем

Бе абзорҳои иловагӣ агент «нобино» аст: вай файлҳоро мехонад ва менависад, аммо намебинад, ки саҳифа дар браузер чӣ гуна менамояд, ва ҳуҷҷатҳоро танҳо «аз хотир» медонад, ки метавонад кӯҳна шуда бошад. MCP (Model Context Protocol) — стандарти умумӣ, ки тавассути он ба агенти AI абзорҳои беруна пайваст мекунанд. Як сервери MCP-и пайвастшуда — як маҷмуи имкониятҳо: «саҳифаро дар браузер кушодан», «ҳуҷҷатҳои навбатии китобхонаро ёфтан», «вазифаро дар трекер хондан».

Дар ду қадам пайваст мекунем

Танзимоти MCP дар файли JSON ҷойгир аст (бахши 4 муфид шуд). Тибқи ҳуҷҷатҳои Cursor ду ҷой ҳаст:

  • .cursor/mcp.json дар ҷузвдони лоиҳа — абзорҳо танҳо барои ҳамин лоиҳа;
  • ~/.cursor/mcp.json дар ҷузвдони хонагӣ — абзорҳо барои ҳамаи лоиҳаҳо.

Дар дохили файл калиди болоӣ — mcpServers аст ва дар он ҳар сервер таҳти номи худ меистад. Барои браузер сервери Playwright-и Microsoft-ро истифода мебаранд (Node.js 18 ё нав лозим аст; он аз дарси 4 дар шумо ҳаст):

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Баъд аз захира кардани файл танзимоти Cursor-ро кушоед: дар версияҳо бо саҳифаи «Customize» сервер дар ҳамон ҷо намоён аст, дар дигарҳо — дар танзимот дар бахши MCP. Калимаи MCP-ро ҷустуҷӯ кунед: дар сервер гузарондак фаъол бошад ва хатои сурх нагирад. Агар сервер пайдо нашавад, Cursor-ро пурра аз нав оғоз кунед. Серверҳоро аз феҳрист (Marketplace) бо як клик ҳам илова кардан мумкин аст, аммо роҳи дастӣ як бартарӣ дорад: шумо мебинед, ки дар компютери шумо маҳз чӣ оғоз мешавад.

Видео бо забони англисӣ, зернависро фаъол кунед (4 дақиқа): пайваст кардани Playwright MCP дар Cursor дар мисоли зинда. Агар равзанаҳо фарқ кунанд, ба файли mcp.json дар боло такя кунед.

Боз чӣ пайваст кардан мумкин аст

Дар Cursor имрӯз абзори дарунсохти «Browser» низ ҳаст: агент метавонад саҳифаҳоро кушояд, пахш кунад, скриншот гирад ва хатогиҳои консолро бихонад бе танзим. Агар пайвасти Playwright нагирифта бошад, аз агент хоҳиш кунед, ки саҳифаро «дар браузери дарунсохт» санҷад. Ва барои он ки AI коди кӯҳнаро намеандешад, сервери ҳуҷҷатҳо пайваст мекунанд, масалан Context7. Ба он калиди ройгон лозим аст (тибқи тавсифи лоиҳа, калид барои маҳдудиятҳо тавсия мешавад), барои ҳамин он ба файли шахсии ~/.cursor/mcp.json меравад, на ба лоиҳа. Баъд аз пайвастшавӣ ба промпт калимаҳои «use context7»-ро илова мекунанд.

Бехатарии MCP

1. Сервери MCP — барномаест, ки дар компютери шумо оғоз мешавад ё аз номи шумо ба хидматҳо дастрасӣ мегирад. Танҳо серверҳоро аз манбаъҳои боэътимод насб кунед: анбори расмии таҳиягар ё феҳристи Cursor. 2. Калидҳои дастрасиро дар файл дар дохили лоиҳа нанависед: он ба GitHub меравад. Агар калид лозим бошад, файлро дар ҷузвдони хонагӣ мегузоранд (~/.cursor/mcp.json). 3. Cursor ба таври пешфарз барои истифодаи абзор иҷозат мепурсад. Ба тири назди ном пахш кунед, хонед, ки агент чӣ кор карданист, ва танҳо баъд иҷозат диҳед. 4. Оғози худкори ҳамаро фаъол накунед: аввал хондани дархостҳоро ёд гиред.

Монандӣ аз ҳаёт

Агент бе MCP — мисли корманде, ки дар хона бо компютер қуфл аст: доно, аммо аз берун чизе намебинад. MCP — тирезаи ҳавлӣ ва телефон: агент ба браузер менигарад («дар саҳифа чӣ ҳаст?») ва ба хадамоти маълумот занг мезанад («дар ин версия чӣ тавр дуруст аст?»). Ва иҷозати шумо — мисли посбон: қарор медиҳад, ки кӣ ворид мешавад.

06 Тағйироти агентро чӣ тавр баргардондан

Агент хато мекунад ва ин муқаррарӣ аст. Хатарнок хато кардан нест, балки баргашта натавонистан аст. Се сатҳи суғурта ҳаст, аз зуд то боэътимод.

1. Checkpoint дар Cursor

Пеш аз тағйироти назаррас агент худкор checkpoint месозад: акси файлҳои тағйирёбанда. Тибқи ҳуҷҷатҳои Cursor, ба дархост дар таърихи чат пахш кунед (ё ба тугмаи «Restore Checkpoint» назди паёми пешина) ва бозгаштро тасдиқ намоед: файлҳо ба он ҳолат бармегарданд. Паёмҳои чат дар ин ҳол нест намешаванд. Қайди муҳим аз ҳуҷҷатҳо: checkpoint ба таври маҳаллӣ, ҷудо аз Git нигоҳ дошта мешавад ва танҳо барои бекор кардани таҳрири агент мувофиқ аст. Таърихи доимӣ — ин Git аст.

2. «Discard Changes» дар Source Control

Source Control-ро кушоед (Ctrl+Shift+G; дар macOS — Control+Shift+G), чунон ки дар дарси 4. Дар рӯйхати «Changes» курсорро ба файл бибаред ва ба нишони бекоркунӣ (тири ба қафо) — «Discard Changes» пахш кунед. Файл ба commit-и охирин бармегардад. Муҳаррир тасдиқ мепурсад: таҳрирҳои бекоршударо баргардонида намешавад. Файли нав (ҳарфи U) ҳангоми бекор кардан нест мешавад.

3. Commit пеш аз вазифаи калон

Пеш аз ба агент додани вазифаи калон, Source Control-ро кушоед ва commit бо хабари фаҳмо кунед, масалан before agent refactor. Он гоҳ «commit-и охирин» — версияи корист ва Discard шуморо маҳз ба он бармегардонад. Агар натиҷаи агент ба шумо маъқул шуд, commit-и навбатӣ кунед; агар не — бекор кунед. Ин тавр Git аз «барномаи тарсонанда» ба тугмаи «Бекор кардан» барои тамоми лоиҳа табдил меёбад.

Чиро интихоб кунед

Агент дар як ҷавоб «каме аз ҳад гузашт» — Restore Checkpoint. Як файл вайрон шуд — Discard Changes назди файл. Ҳамааш ба ҷои нодуруст рафт ва баъд аз commit-и охирин тағйирот бисёр аст — Discard-и ҳамаи тағйирот. Мисоли кӯҳнаи дарси 5 (git restore .) ҳамин корро аз терминал мекунад.

Монандӣ аз ҳаёт

Commit — мисли акс гирифтани хона пеш аз ҷобаҷогузории мебел. Агар баъд аз ҷобаҷогузорӣ нокулай шуд, акс нишон медиҳад, ки чӣ тавр буд, ва ҳама чизро ба ҷояш мегузоранд. Бе акс ба ёд овардан мемонад. Checkpoint — ёддошти «ҷевон дар чап буд», ва акс — боэътимодтар.

Хатогиҳои маъмули навомӯзон

1. Пеш аз вазифаи калон commit накардан: баъд ба ҷое баргардидан нест. 2. «Discard All»-ро пахш кардан ва ҳайрон шудан, ки таҳрирҳои хуб низ нопадид шуданд: бекоркунӣ ҳамаи тағйиротро баъд аз commit-и охирин мегирад. 3. Ба checkpoint ҳамчун ба таърихи «воқеӣ» умед бастан: он маҳаллӣ аст ва Git-ро иваз намекунад. 4. Кодро баргардондан, аммо фаромӯш кардан, ки агент метавонист китобхона насб кунад: package.json-ро санҷед ва дар зарурат аз агент хоҳиш кунед, ки зиёдатиро хориҷ кунад.

ВАЗИФАИ 6.1

Худро санҷед: баргардонидан

осон

Агент саҳифаро вайрон кард, commit-и охирин пеш аз вазифа буд. Чӣ ҳамаи файлҳоро ба версияи корӣ бармегардонад?

  1. Discard-и ҳамаи тағйирот дар Source Control (ё Restore Checkpoint дар чат)
  2. Аз нав оғоз кардани компютер
  3. Нест кардани ҷузвдони node_modules
  4. Commit-и нав бо версияи вайроншуда

Баргардонидан файлҳоро ба ҳолати захирашуда бармегардонад. Аз нав оғоз кардан ва нест кардани node_modules файлҳои саҳифаро тағйир намедиҳанд, ва commit вайронкуниро мустаҳкам мекунад.

Пеш аз додани вазифаи калон ба агент чӣ кор кардан лозим аст?

  1. Cursor-ро бастан
  2. AGENTS.md-ро нест кардан
  3. Бо версияи корӣ commit кардан: ин нуқтаи бозгашт аст
  4. Ҳеҷ чиз: checkpoint Git-ро иваз мекунад

Рӯйхати санҷиши сифати лендинг

  • Сохтор: бахшҳо ба компонентҳои алоҳида дар app/components бароварда шудаанд (ақалан се файл); app/page.tsx ба «ҷамъкунии» кӯтоҳи компонентҳо табдил ёфтааст.

  • Аниматсияҳо: ақалан ду эффект (пайдошавии корточкаҳо, эффект ҳангоми нишонгирӣ, тағйири ҳамвори ранги тугма) танҳо бо воситаҳои Tailwind.
  • Дастрасӣ: майдонҳои форма тавсиф доранд, тасвирҳо тавсиф доранд, матн дар замина хонда мешавад.
  • Санҷиши браузер: агент тавассути MCP (ё браузери дарунсохти Cursor) саҳифаро дар ду паҳноӣ санҷид; ҳисоботи агентро нигоҳ доред ва дар санҷиш нишон диҳед.
  • Ҷамъоварӣ: npm run build бе хатогиҳо мегузарад.

Файли қоидаҳои лоиҳа AGENTS.md

Ин қисми асосии вазифа аст. Файл дар решаи репозиторий ҷойгир аст ва ақалан 7 қоидаи мушаххас-ро дар бахшҳои зерин дорад:

  • Лоиҳа ва стек: лоиҳа чист, кадом технологияҳо иҷозат дорад.
  • Услуб: компонентҳо дар куҷо ҷойгиранд, файлҳо чӣ ном доранд, матнҳо бо кадом забон.
  • Бехатарӣ: розҳо танҳо дар .env, commit намекунанд; дар код калидҳо нест.
  • Санҷиш: баъд аз таҳрир кадом фармонҳо иҷро мешаванд.
  • Рафтори агент: масалан, «тағйиротро кӯтоҳ шарҳ деҳ», «файлҳоеро, ки нахостаам, тағйир надеҳ», «барои вазифаҳои калон аввал нақша».

Ихтиёрӣ: қоидаеро ба .cursor/rules бо тамдиди .mdc илова кунед, масалан барои файлҳои app/components/**/*.tsx.

  4. Санҷед npm run build ва саҳифаро дар ду паҳноӣ.
  5. Commit ва push кунед, нав шудани Vercel-ро интизор шавед ва сайтро дар телефон санҷед.
  6. Ду истинодро дар майдонҳои поён супоред.
Хатогиҳои маъмул дар вазифаи хонагӣ

1. AGENTS.md-и стандартии create-next-app-ро бе қоидаҳои худ гузоштан. 2. Қоидаҳои норавшан мисли «хуб нависед». 3. Калидҳо ё паролҳо дар файли қоидаҳо ё дар mcp.json дар дохили лоиҳа. 4. Push-и фаромӯшшуда: дар Vercel версияи кӯҳна. 5. Истинод ба localhost ба ҷои vercel.app. 6. Репозиторийи хусусӣ, ки санҷанда онро намекушояд.
