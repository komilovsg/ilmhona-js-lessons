01 App Router: ҷузвдон — ин суроға аст

Дар дарси 7 шумо аз AI хостед, ки app/cafe/page.tsx-ро созад ва суроғаи /cafe-ро гирифтед. Имрӯз мефаҳмем, ки чаро ин кор мекунад. Дар Next.js роутинги файлӣ амал мекунад: суроғаи саҳифа аз сохтори ҷузвдонҳо муайян мешавад. Рӯйхати масирҳоро дар код навиштан ва чизеро сабт кардан лозим нест: ҷузвдон ва файл сохтед — саҳифа пайдо шуд.

Сегмент
Як қисми суроға дар байни слэшҳо. Дар /services/web ду сегмент ҳаст: services ва web. Ба ҳар сегмент як ҷузвдон мувофиқ аст.
page.tsx
Файле, ки суроғаро кушодашаванда мекунад. Дар дохили он — компонент бо export default. Бе ин файл ҷузвдон танҳо ҷузвдон аст, суроға пайдо намешавад.
layout.tsx
«Чорчӯби» умумии саҳифаҳо: сарлавҳа, поён, замина. Дар боби 2 шарҳ медиҳем.
Сегменти динамикӣ
Ҷузвдон дар қавсҳои чоркунҷа, масалан [slug]: як файл суроғаҳои зиёдро хизмат мекунад (/cases/bank, /cases/cafe).

Саҳифа ва суроғаи динамикӣ чӣ гуна менамоянд

export default function ServicesPage() {
  return (
    <main>
      <h1>Услуги</h1>
    </main>
  );
}

export default async function CasePage({
  params,
}: {
  params: Promise<{ slug: string }>;
}) {
  const { slug } = await params;
  return <h1>Кейс: {slug}</h1>;

Саҳифа — ин компоненти оддии дарси 7 аст, танҳо бо номи файли page.tsx. Дар саҳифаи динамикӣ суроғаи /cases/bank slug = "bank"-ро мефиристад. Дар Next.js 16 params ҳамчун «ваъда» (Promise) меояд, бинобар ин пеш аз истифода онро бо калимаи await «интизор шудан» лозим аст: AI инро худаш мекунад, танҳо await-ро нест накунед.

Монандӣ аз ҳаёт

Қатори дӯконҳо дар бозор. Ҳар дар дар қатор — ҷузвдон аст, лавҳаи «Кушода» дар дар бошад — файли page.tsx. Дари бе лавҳа ҳаст, аммо харидорро намегузоранд: 404 мегиред. Қавсҳои чоркунҷа ба дӯкони «Ҳама чиз бо фармоиш» монанд аст: як дӯкон ҳар номи молро қабул мекунад ва чизи лозимиро медиҳад.

Хатогиҳои маъмули навомӯзон

1. Файлро ба ҷои page.tsx бо номи Services.tsx ё index.tsx номидан: саҳифа намешавад. 2. Ҷузвдонро на дар дохили app, балки паҳлӯи он гузоштан: Next.js онро намебинад. 3. Аз рӯи дастурҳои кӯҳна pages/about.tsx навиштан: ин тавр Pages Router-и пештара кор мекард, дар лоиҳаи мо он лозим нест. 4. export default-ро дар page.tsx фаромӯш кардан.

02 Layout-и умумӣ: сарлавҳа ва поён як маротиба

Агар сарлавҳаро ба ҳар як аз панҷ саҳифа нусха кунед, ҳангоми аввалин ислоҳи меню панҷ файлро иваз кардан лозим мешавад. Барои ин layout ҳаст: компонент-«чорчӯба», ки Next.js саҳифаи лозимиро ба дарунаш мегузорад. Шумо файли app/layout.tsx-ро дар лоиҳаи нав аллакай дидаед — ин layout-и реша аст. Он ҳатмист ва бояд тегҳои <html> ва <body>-ро дошта бошад.

import "./globals.css";
import Header from "@/components/Header";
import Footer from "@/components/Footer";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="ru">
      <body>
        <Header />
        <main>{children}</main>
        <Footer />
      </body>
    </html>
  );
}

Калимаи асосӣ дар ин ҷо — children (prop аз дарси 7). Ин «чизест, ки ба дарун гузоштанд»: дар суроғаи /services дар он ҷо app/services/page.tsx мешавад, дар /cases — app/cases/page.tsx. Сарлавҳа ва поён ҳамон мемонанд.

Layout аз нав бор намешавад ва дарунҷо шуда метавонад

Ҳангоми гузариш байни саҳифаҳо Next.js танҳо мундариҷаи children-ро иваз мекунад, layout бошад дар ҷояш мемонад: он аз нав кашида намешавад ва ҳолати худро гум намекунад (масалан, менюи кушода ё матн дар майдони ҷустуҷӯ дар сарлавҳа). Layout-ро дарунҷо кардан мумкин аст: файли app/cases/layout.tsx танҳо саҳифаҳои бахши /cases-ро печонида мегирад, layout-и реша бошад — ҳамаро якбора.

Видео бо забони англисӣ, 4,5 дақиқа, субтитрҳоро фаъол кунед: layout.tsx чӣ тавр кор мекунад ва дарунҷогӣ. Дар видео версияи Next.js 15 аст, аммо барои layout қоидаҳо ҳамонанд, ки дар 16.

Монандӣ аз ҳаёт

Маршрутка. Бадана, ронанда ва лавҳаи масир — layout аст: онҳо тамоми роҳ мераванд. Танҳо мусофирон дар курсиҳо иваз мешаванд — инҳо children мебошанд. Дар ҳар истгоҳ (саҳифа) салонро аз нав ранг намекунанд, балки танҳо одамонро ҷо ба ҷо мекунанд.

Хатогиҳои маъмули навомӯзон

1. Сарлавҳаро ба ҷои як layout.tsx ба ҳар саҳифа нусха кардан. 2. {children}-ро дар layout фаромӯш кардан: саҳифаҳо умуман пайдо намешаванд. 3. Дар layout-и дарунҷо <html> ё <body>-и дуюмро илова кардан — онҳо танҳо дар layout-и реша лозиманд. 4. Дар сайти русӣ lang="en" гузоштан: муҳаррикҳои ҷустуҷӯ ва экранхонҳо гумон мекунанд, ки забон дигар аст.

03 Навигатсия: Link ба ҷои истиноди оддӣ

Байни саҳифаҳои сайт бо компоненти Link аз next/link мегузаранд. Он ба истиноди оддии <a> монанд аст ва ҳатто дар HTML ба он табдил меёбад, аммо ду ҳила медонад: гузариш бе аз нав бор кардани тамоми саҳифа (танҳо children иваз мешавад, layout мемонад) ва пешборкунии саҳифа, ҳангоме ки истинод дар экран намоён аст. Барои он ки боздидкунанда бифаҳмад, ки дар куҷост, бандҳои менюи саҳифаи ҷориро ҷудо мекунанд. Суроғаро ҳуки usePathname аз next/navigation медиҳад. Ин ҳук аст, ва ҳукҳо (мисли useState дар дарси 8) танҳо дар компонентҳои мизоҷӣ кор мекунанд, бинобар ин файли меню бо "use client" оғоз мешавад. Худи саҳифаҳо ва layout бошанд серверӣ мемонанд: Metadata API аз боби 5 маҳз дар онҳо кор мекунад.

"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";

const items = [
  { href: "/", label: "Главная" },
  { href: "/services", label: "Услуги" },
  { href: "/cases", label: "Кейсы" },
  { href: "/about", label: "О компании" },
  { href: "/contacts", label: "Контакты" },
];

function isActive(pathname: string, href: string) {
  if (href === "/") return pathname === "/";
  return pathname === href || pathname.startsWith(href + "/");
}

export default function Nav() {
  const pathname = usePathname();
  return (
    <nav className="flex gap-4">
      {items.map((item) => (
        <Link
          key={item.href}
          href={item.href}
          aria-current={isActive(pathname, item.href) ? "page" : undefined}
          className={isActive(pathname, item.href) ? "font-bold text-brand-600" : "text-slate-600"}
        >
          {item.label}
        </Link>
      ))}
    </nav>
  );
}

Ҳама чиз дар ин файл ба шумо ошност: массив ва map (дарси 7), шарт дар класс (дарси 8). Нав танҳо usePathname ва функсияи isActive аст. Чаро дар он ду шарт ҳаст? Суроғаи / — ибтидои ҳар суроға аст, бинобар ин барои саҳифаи асосӣ сахт муқоиса мекунем. Бахши /services бояд дар саҳифаи дарунҷои /services/web низ «фаъол» монад, аммо на дар /servicesX: барои ҳамин href + "/"-ро месанҷем.

Дар мантиқи «тоза» тамрин кунед. Дар Next.js суроғаро usePathname медиҳад, дар ин ҷо бошад он ҳамчун prop меояд ва ба ҷои Link истиноди оддӣ истодааст (компоненти Link дар браузери дарс дастнорас аст).

Нишондиҳандаҳо дар метро. Тири ба хатти лозимӣ равшан аст, боқӣ хира, ва мусофир фавран мебинад, ки дар куҷост. Гузариш (Link) бошад бе баромадан ба кӯча ва аз нав даромадан мегузарад: шумо дар истгоҳ мемонед, танҳо қатор иваз мешавад.

Хатогиҳои маъмули навомӯзон

1. Барои саҳифаҳои худ <a href="/services"> навиштан: саҳифа пурра аз нав бор мешавад, пешборкунӣ нест. 2. "use client"-ро дар файли бо usePathname фаромӯш кардан: Next.js ҷамъоварӣро бо матне монанди «You're importing a component that needs usePathname. This React Hook only works in a Client Component» қатъ мекунад. 3. Барои саҳифаи асосӣ pathname.startsWith("/")-ро муқоиса кардан: ҳамаи бандҳо ҷудо мешаванд. 4. "use client"-ро «ҳамроҳ» ба layout.tsx гузоштан: он гоҳ тамоми сайт мизоҷӣ мешавад. Танҳо менюро ба файли хурди алоҳида баред.

Худро санҷед: Link ва меню

осон

  1. Гузариш бе аз нав бор кардани пурраи саҳифа ва пешборкунии саҳифа дар ҷамъоварии ҷангӣ
  2. Истинод худкор зеботар мешавад
  3. Бе интернет кор мекунад
  4. Ҳеҷ чиз: Link танҳо дар сайтҳои англисӣ лозим аст

Link танҳо children-ро иваз мекунад ва саҳифаи оянда ро пешакӣ бор мекунад. Намуди берунӣро бо классҳо, мисли ҳар истинод, медиҳанд.

Дар файли меню шумо usePathname()-ро истифода мебаред. Дар ибтидои файл ҳатман чӣ бояд истад?

  1. "use server"
  2. "use client"
  3. export const metadata
  4. Ҳеҷ чиз: ҳукҳо дар ҳар файл кор мекунанд

Ҳукҳо танҳо дар компонентҳои мизоҷӣ кор мекунанд, бинобар ин директиваи "use client" лозим аст (дарси 8). metadata, баръакс, аз файлҳои серверӣ содир мешавад.

  1. <Link href="t.me/saru_studio"> бе https
  2. <Link href="/https://t.me/saru_studio">
  3. Бо <a href="https://t.me/saru_studio" target="_blank" rel="noopener">-и оддӣ
  4. Файли app/t.me/page.tsx-ро гузоштан

04 Расмҳо: next/image

<img>-и оддӣ файлро «ҳамон тавр» боргирӣ мекунад: сурати телефон дар 4 МБ ҳам дар ноутбук, ҳам дар смартфон бо интернети суст бор мешавад. Компоненти Image аз next/image инро ба дӯш мегирад: андозаи мувофиқ ва формати муосирро медиҳад, боргирии расмҳои берун аз экранро ба таъхир меандозад ва ҷойро захира мекунад, то матн ҳангоми боршавии расм «напарад».

import Image from "next/image";

export default function Examples() {
  return (
    <>
      {/* 1. Андоза маълум: width ва height ҳатмианд */}
      <Image src="/images/team.webp" alt="Команда студии за работой" width={800} height={533} />

      {/* 2. Расм блокро пур мекунад: падар бояд position: relative дошта бошад */}
      <div className="relative h-64 w-full">
        <Image src="/images/office.webp" alt="Офис студии" fill sizes="(max-width: 768px) 100vw, 50vw" className="object-cover" />
      </div>
    </>
  );
}
PropЧӣ мекунад
srcРоҳ ба файл: /images/team.webp маънои файли public/images/team.webp-ро дорад (калимаи public-ро дар роҳ намениванд)
altТавсиф барои экранхонҳо ва муҳаррикҳои ҷустуҷӯ; ҳатмист. Барои расми танҳо ороишӣ — сатри холӣ alt=""
width, heightАндозаи ҳақиқии файл бо пиксел: браузер барои захираи ҷой ба он эҳтиёҷ дорад. Андозаи намоишшавандаро бо классҳои CSS медиҳанд
fillБа ҷои width ва height: расм падарро пур мекунад. Падар бояд position: relative (дар Tailwind — класси relative) ва андоза дошта бошад; буриданро object-cover медиҳад
sizesИшора, ки расм кадом қисми экранро мегирад: браузер файли андозаи лозимиро мегирад, на калонтаринро
preloadРасмро пешакӣ бор кардан: танҳо барои аввалин расми экран. Дар мисолҳои кӯҳна ба ҷои он priority вомехӯрад: аз Next.js 16 ин ном кӯҳна шудааст
Расмҳоро аз куҷо гирифтан

Суратҳои худӣ ё расмҳо аз стокҳои ройгон, ки истифода иҷозат аст (литсензияро санҷед). Ба public/images гузоред, формат .webp ё .jpg, то 300 КБ барои як файл — калонҳоро фишурда кунед. Барои логотипҳо ва аломатҳо .svg мувофиқ аст: Next.js худаш онро оптимизатсия намекунад (SVG худ сабук аст). Расмҳои аз суроғаи бегона (https://…) аввал бояд дар next.config.ts дар танзими images.remotePatterns иҷозат дода шаванд, вагарна хато мешавад: ин ҳифзи аз суиистифодаи бегонагон аст. Барои сайти таълимӣ гузоштани файлҳо ба public осонтар аст.

Монандӣ аз ҳаёт

Суратгир дар тӯй суратҳоро фавран дар се андоза меорад: хурд барои телефон, миёна барои планшет ва калон барои чоп. Меҳмон бо телефон нусхаи сабукро мегирад ва интизор намешавад. next/image чунин суратгир аст: худаш андоза ва форматро барои дастгоҳ тайёр мекунад.

Хатогиҳои маъмули навомӯзон

1. alt-ро нанависед ё «расм» / «image1» нависед. Нависед, ки дар сурат чӣ ҳаст, кӯтоҳ ва ба маврид. 2. Роҳи /public/images/team.webp-ро навиштан: файлҳо аз public аз реша сайт дастрасанд. 3. fill-ро бе relative дар падар истифода бурдан: расм мепарад ё ба тамоми экран кашида мешавад. 4. width ва height-ро «ба тасодуф» дар таносуби дигар аз файл нишон додан: то даме ки CSS андоза надиҳад, расм таҳриф мешавад. 5. Расмро аз сайти бегона бе remotePatterns ҷойгир кардан: хатои намуди Invalid src prop … hostname "…" is not configured under images in your next.config.js. 6. preload-ро ба ҳамаи расмҳо гузоштан: фоида аз байн меравад.

  4. Image-ро ба Link иваз кардан

Суроғаҳои берунӣ барои оптимизатсия бояд ошкоро иҷозат дода шаванд. Барои лоиҳаи таълимӣ гузоштани расм ба public осонтар аст.

05 Метатегҳо ва SEO-и асосӣ

SEO — ин усулҳоест, ки ба муҳаррикҳои ҷустуҷӯ кӯмак мекунанд, то бифаҳманд, ки саҳифаи шумо дар бораи чӣ аст, ва онро ба одамони лозимӣ нишон диҳанд. Ҳама чиз аз ду сатр оғоз мешавад, ки дар натиҷаҳои ҷустуҷӯ намоёнанд: title (сарлавҳаи кабуд) ва description (тавсифи хокистарӣ дар зери он). Дар Next.js онҳоро тавассути Metadata API медиҳанд: дар файли layout.tsx ё page.tsx объекти metadata содир мешавад, Next.js бошад худаш тегҳоро дар <head>-и саҳифа месозад.

import type { Metadata } from "next";

export const metadata: Metadata = {
  title: {
    default: "Студия «Сарв» — сайты и приложения в Душанбе",
    template: "%s | Студия «Сарв»",
  },
  description: "Делаем сайты и приложения для бизнеса в Душанбе. Фиксированная цена в сомони.",
  openGraph: {
    title: "Студия «Сарв»",
    description: "Сайты и приложения для бизнеса в Душанбе.",
    type: "website",
    locale: "ru_RU",
  },
};

import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Услуги",
  description: "Сайты, приложения и поддержка: что входит и сколько стоит в сомони.",
};

export default function ServicesPage() {
  return <h1>Услуги</h1>;
}

Қолаби "%s | Студия «Сарв»" аз layout-и реша ба ҷои %s номи саҳифаро мегузорад: дар <title> «Услуги | Студия «Сарв»» мешавад. Барои саҳифаи асосӣ default гирифта мешавад. Майдони openGraph сарлавҳа ва тавсифро барои корт ҳангоми фиристодани истинод дар Telegram ва шабакаҳои иҷтимоӣ медиҳад (расми кортро ба app/opengraph-image.png гузоштан мумкин — Next.js худаш онро пайваст мекунад).

Қоидаи муҳими якҷоякунӣ

Агар саҳифа openGraph-и худро диҳад, он пурра ивазкунандаи умумии аз layout мешавад, на пурракунандаи он. Бинобар ин барои саҳифаҳое, ки ба онҳо маълумоти махсус барои шабакаҳои иҷтимоӣ лозим аст, ҳамаи майдонҳои лозимиро аз нав нависед, расми умумиро бошад ба файли opengraph-image баред.

Видео бо забони англисӣ, 8 дақиқа, субтитрҳоро фаъол кунед: метаданҳои статикӣ, қолаби сарлавҳа, generateMetadata. Барои ин дарс 5 дақиқаи аввал муҳиманд.

SEO-и асосӣ: рӯйхати санҷиш барои ҳар саҳифа

  • title ва description-и худӣ дар ҳар саҳифа: дар «Хизматҳо» ва «Тамос» онҳо набояд мувофиқ оянд. Сарлавҳа — кӯтоҳ (тақрибан 50–60 аломат), тавсиф — 1–2 ҷумла (тақрибан 150 аломат), ба маврид ва бе «беҳтарин дар ҷаҳон».
  • Як <h1> дар саҳифа: фикри асосии саҳифа. Зерсарлавҳаҳо — <h2>.
  • Суроғаҳои бомаъно: /services, на /page2. Онҳо ба боздидкунанда низ кӯмак мекунанд, то бифаҳмад, ки дар куҷост.
  • alt дар ҳар расми мундариҷадор.
  • Забон: <html lang="ru"> дар layout-и реша.
  • Версияи мобилӣ: сайт бояд дар телефон хуб намояд (дарси 3 ва Tailwind).
  • Файлҳои robots.ts ва sitemap.ts дар ҷузвдони app: Next.js онҳоро ба /robots.txt ва /sitemap.xml табдил медиҳад — харитаи сайт барои муҳаррикҳои ҷустуҷӯ. Барои сайти аввал хоҳиш аз AI барои тавлиди онҳо кофист.
Рост дар бораи SEO

Метатегҳо мавқеъро кафолат намедиҳанд: ба он мундариҷа, суръат, истинодҳо ба сайт ва бисёр чизҳои дигар таъсир мерасонанд. Метатегҳо — асосанд, ки бе онҳо боқӣ кор намекунад. Ва боз як чиз: дар сайт матни пинҳон ё «қолини» калимаҳои калидиро ҷойгир накунед — муҳаррикҳои ҷустуҷӯ барои ин ҷазо медиҳанд.

Монандӣ аз ҳаёт

Лавҳа ва меню дар назди дари чойхона. Лавҳа (title) ба роҳгузар мегӯяд, ки дар дарун чӣ ҳаст; сатри зери он (description) — бо чӣ мепазанд. Агар дар ҳар панҷ дар лавҳаи якхонаи «Дӯкон» бошад, касе намефаҳмад, ки ба куҷо равад. Лавҳаи хуб навбатро кафолат намедиҳад, аммо бе он навбат ҳатман нест.

Хатогиҳои маъмули навомӯзон

1. export const metadata-ро ба файли бо "use client" гузоштан: ҷамъоварӣ бо хабаре қатъ мешавад, ки содироти metadata аз компоненти мизоҷӣ манъ аст. Метаданҳо дар page.tsx ва layout.tsx-и серверӣ зиндагӣ мекунанд. 2. Дар layout.tsx нусхаи «Create Next App»-ро гузоштан: он дар Telegram ва ҷустуҷӯ пайдо мешавад. 3. Бо қолаби тайёр дар саҳифа title: "Услуги | Студия «Сарв»" навиштан: «Услуги | Студия «Сарв» | Студия «Сарв»» мешавад. 4. description-ро дар ҳамаи саҳифаҳо якхела гузоштан. 5. Суроғаи нисбии расмро дар openGraph.images нишон додан ва metadataBase-ро надодан: ҷамъоварӣ хато медиҳад, суроғаи пурраи сайт лозим аст.

ВАЗИФАИ 5.1

Худро санҷед: metadata ва SEO

миёна

Дар layout.tsx-и реша қолаби title: { template: "%s | Сарв", default: "Сарв" } гузошта шудааст, дар app/about/page.tsx — title: "О компании". <title>-и саҳифаи /about кадом аст?

  2. О компании | Сарв
  3. %s | Сарв
  4. Сарв | О компании

Чӣ ба SEO-и асосии саҳифа тааллуқ дорад? (ҳамаи ҷавобҳои дурустро интихоб кунед)

  1. title ва description-и беназир
  2. Тавсифи якхела дар ҳамаи саҳифаҳо — боэътимодтар аст
  3. Як <h1> ва alt-и бомаъно дар расмҳо

06 Системаи дизайн дар Tailwind: рангҳо ва қоидаҳо дар як ҷой

Вақте ки сайт аз панҷ саҳифа иборат аст ва ранги тугмаи «Тамос» дар бист ҷой ҳамчун bg-[#0e7a55] навишта шудааст, иваз кардани бренд ба ҷустуҷӯ дар тамоми лоиҳа табдил меёбад. Системаи дизайн — ин мувофиқа аст: рангҳо, шрифтҳо, гирдкуниҳо ва фосилаҳо як маротиба муайян шудаанд, саҳифаҳо бошанд танҳо онҳоро истифода мебаранд. Он аз ду қабат иборат аст.

Токенҳо дар Tailwind 4

Tailwind CSS 4 бевосита дар файли app/globals.css бо блоки @theme танзим мешавад. Ҳар тағйирёбандаи аз «фазо»-и --color-*, --font-*, --radius-* ба классҳо табдил меёбад:

@import "tailwindcss";

@theme {
  --color-brand-50: #ecfdf5;
  --color-brand-600: #0e7a55;
  --color-brand-700: #0b6045;
  --color-ink: #0f172a;
  --radius-card: 16px;
}

Акнун классҳои bg-brand-600, text-brand-700, bg-brand-50, text-ink ва rounded-card дастрасанд. Барои иваз кардани палитра шумо се сатрро дар як файл ислоҳ мекунед. Дар лоиҳаи нав дар globals.css аллакай тағйирёбандаҳо ва блоки @theme inline барои шрифтҳо будан мумкин аст: онҳоро нест накунед, блоки худии @theme-ро дар паҳлӯ илова кунед.

Қоидаи дарси 7 эътибор дорад

Tailwind дар код танҳо номҳои пурраи классҳоро меёбад. Нишон додани bg-${color}-600 мумкин нест: услуб пайдо намешавад. Агар ранг ҳамчун prop ояд, номи пурраи классро фиристед, масалан accent="bg-brand-600".

Ғояро дар CSS-и тоза санҷед

Принсипи «як қиммат — ҷойҳои зиёд» ҳам дар Tailwind (@theme), ҳам дар CSS-и оддӣ (тағйирёбандаи var(--brand)) якхела аст. Дар Tailwind шумо аллакай классҳои тайёрро истифода мебаред, дар ин ҷо бошад худи ғояро тамрин кунед: се унсур бояд ранги худро аз як тағйирёбанда гиранд.

ВАЗИФАИ 6.1

Як токен ба ҷои се ранг

миёна

Дар CSS ранги #0e7a55 дар се қоида ба таври дастӣ навишта шудааст. Онро дар ҳар кадом ба var(--brand) иваз кунед (тағйирёбандаи --brand дар боло аллакай эълон шудааст). Санҷиш --brand-ро ба сурх иваз мекунад ва мебинад, ки ҳар се унсур рангин шуданд ё не. Блоки «САНҶИШ»-ро нагиред.

<header class="bar">
  <a class="link" href="#">Services</a>
  <span class="badge">New</span>
  <button class="btn">Contact us</button>
</header>

:root { --brand: #0e7a55; }

body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; background: #f8fafc; }
.bar { display: flex; align-items: center; gap: 14px; }
.link { color: #0e7a55; font-weight: 700; }
.badge { background: #0e7a55; color: #fff; padding: 2px 10px; border-radius: 999px; font-size: 13px; }
.btn { background: #0e7a55; color: #fff; border: 0; padding: 10px 18px; border-radius: 10px; font-weight: 700; }

// САНҶИШ — ин кодро нагиред. Танҳо ҷадвали CSS-ро ислоҳ кунед.

const ok = (name, cond) => console.log((cond ? '✓ ' : '✗ ') + name);

Ишора 1

Дар ҳар яке аз се қоида қиммати #0e7a55-ро ба var(--brand) иваз кунед. Дар :root ҳамон тавр гузоред: ин ягона ҷоест, ки ранг бо рақамҳо навишта мешавад.

Ишора 2

Бояд масалан чунин шавад: .btn { background: var(--brand); … }. Ба нуқтаю вергул пас аз қиммат диққат диҳед.

Монандӣ аз ҳаёт

Либоси мактабӣ. Мактаб як маротиба қарор медиҳад: ранг — кабуди баданд, галстук — сабз. Синфҳо ҳар рӯз дар бораи рангҳо баҳс намекунанд, ва ҳар хонандаи нав фавран «дар услуб» аст. Хостед либосро навсозӣ кунед — дар утоқи директор (@theme) қарор медиҳед, на ҳар хонандаро гашта мебароед.

Хатогиҳои маъмули навомӯзон

1. 12 тобиши «барои эҳтиёт» сохтан: бренд (2–3 тон), хокистарии нейтралӣ ва акцент кофист. 2. Рангро бевосита ба компонент навиштан (bg-[#0e7a55]), чунки «зудтар»: услуби ягона дар саҳифаи дуюм вайрон мешавад. 3. Ба ҳар саҳифа тугмаҳои худиро бо гирдкуниҳои гуногун навиштан: як Button созед. 4. Фаромӯш кардани он, ки мавзӯи торик (дарси 8) маҷмӯаи дигари қиматҳои токенҳост, на нусхаи компонентҳо.

ВАЗИФАИ 6.2

Худро санҷед: системаи дизайн

миёна

Шумо мехоҳед, ки дар лоиҳа классҳои bg-brand-600 ва text-brand-600 кор кунанд. Дар Tailwind 4 чӣ кор кардан лозим?

  1. Файли brand.tsx-ро бо ранг сохтан
  2. Ба @theme дар globals.css тағйирёбандаи --color-brand-600: …-ро илова кардан
  3. Бе танзим className="bg-brand-600" навиштан: Tailwind худаш мефаҳмад
  4. Бастаи brand-colors-ро насб кардан

Тағйирёбандаҳо дар @theme аз фазои --color-* худкор ба классҳои ранг табдил меёбанд.

Сабаби асосии ба токенҳо баровардани рангҳо ва гирдкуниҳо:

  1. Услуби сайтро бо ислоҳ дар як ҷой иваз кардан мумкин аст ва дар ҳамаи саҳифаҳо ягона мемонад
  2. Сайт даҳ маротиба тезтар кор мекунад
  3. Tailwind бо рангҳо кор карданро қатъ мекунад
  4. Истифодаи компонентҳо лозим нест

Токенҳо услуби ягона ва ислоҳҳои арзонро медиҳанд. Суръати сайт аз онҳо бевосита вобаста нест, компонентҳо бошанд ҳамоно лозиманд: токенҳо — қиматҳо, компонентҳо — «хишт»-ҳои тайёр аз онҳо.

07 Блоки AI: сайти бисёрсаҳифагиро чӣ тавр хостан

Қоидаҳо барои сайти бисёрсаҳифагӣ

Сделай сайт компании на next js с несколькими страницами
Контекст: проект Next.js 16 (App Router, TypeScript, Tailwind CSS 4, без папки src), создан через create-next-app. Нужен корпоративный сайт вымышленной студии «Сарв» из Душанбе: веб-разработка для бизнеса. Правила проекта лежат в AGENTS.md. Цель: многостраничный сайт из 5 страниц: Главная (/), Услуги (/services), Кейсы (/cases), О компании (/about), Контакты (/contacts). У всех страниц общая шапка с меню и подвал, всё в одном стиле. Ограничения: общий layout в app/layout.tsx (lang="ru"); меню в components/Nav.tsx с подсветкой текущей страницы через usePathname (только этот файл с "use client"); ссылки внутри сайта только через Link; картинки только через next/image из public/images, у каждой alt и размеры; на каждой странице свой title и description через metadata, шаблон заголовка в корневом layout; цвета, шрифты и скругления только через @theme в app/globals.css и классы bg-brand-600 и т. п.; общие кирпичи Container, Section, Button в components/ui; без новых библиотек; адаптивно для телефона. Примеры: тексты короткие и по делу на русском, цены в сомони, вымышленные контакты. Проверка: после изменений запусти npm run build, исправь ошибки и в конце перечисли созданные файлы и адреса.

Ба ҷои як промпти азим бо қадамҳо тақсим кардани кор қулайтар аст (дар амалиёт онҳо аллакай навишта шудаанд). Агар AI «ба ҷои нодуруст рафт», аз нав оғоз накунед: қадамро тавассути Checkpoint ё Discard Changes (дарси 6) баргардонед ва ислоҳи нуқтавӣ диҳед.

08 Амалиёт: сайти корпоративии панҷсаҳифагӣ

Сайти студияи хаёлии «Сарв»-ро (сарв — рамзи устуворӣ) месозем. Студия, бренд ва рангҳои худро худатон интихоб кунед: сайт аз они шумо мешавад. Нақша чунин аст: лоиҳаи нав → қоидаҳо → системаи дизайн → layout ва меню → панҷ саҳифа → расмҳо ва метатегҳо → санҷиш → нашр.

Қадами 0. Омодагӣ

  • Cursor, Node.js, Git ва аккаунтҳои GitHub ва Vercel аз дарсҳои 4–5 тайёранд.
  • Қарор диҳед: номи студия, ба чӣ машғул аст, 3 хизмат бо нархҳо бо сомонӣ, 3 кейс (хаёлӣ), 2–3 «одами даста». Барои расмҳо 3–4 файлро омода кунед (суратҳои худӣ, тавлидшуда ё аз стокҳо бо литсензияи иҷозатдодашуда), ҳар кадом то 300 КБ.
  • Тамосҳо дар сайт — танҳо хаёлӣ ё онҳое, ки омодаед ба ҳама нишон диҳед.

Қадам ба қадам

  1. Лоиҳаро созед. Дар терминал аз ҷузвдоне, ки лоиҳаҳоятон нигоҳ дошта мешаванд: npx create-next-app@latest saru-site, ҷавобҳо ба таври пешфарз (танзимоти тавсияшуда, мисли дарси 5: TypeScript, ESLint, Tailwind, App Router, бе src). Ҷузвдонро дар Cursor кушоед, npm run dev-ро оғоз кунед ва боварӣ ҳосил кунед, ки саҳифа дар localhost:3000 кушода мешавад. Коммити аввалро кунед.
  2. Қоидаҳои лоиҳа. Аз агент дар реҷаи «Нақша» хоҳиш кунед, ки AGENTS.md-ро бо қоидаҳои кӯтоҳ созад ё пурра кунад (дарси 6). Мисол: «Саҳифаҳо — дар app/<суроға>/page.tsx. Истинодҳо дар дохили сайт — танҳо Link. Расмҳо — танҳо next/image аз public/images, ҳамеша alt, width ва height. Рангҳо ва шрифтҳо — танҳо токенҳо аз @theme. "use client" — танҳо дар Nav ва шакл. Ҳар саҳифа title ва description-и худро дорад». Санҷед, ки қоидаҳо аз 10 зиёд нестанд ва мушаххасанд.
  3. Системаи дизайн. Ба агент вазифа диҳед: «Дар app/globals.css @theme-ро бо токенҳо илова кун: brand-50, brand-600, brand-700, ink, radius-card (ранги акценти ман: […]). components/ui/Container.tsx, Section.tsx, Button.tsx-ро бисоз, ки танҳо ин токенҳоро истифода баранд. Button ду намуд дорад: пуршуда ва контурӣ; барои истиноди дохилӣ дар дохили худ Link-ро истифода мебарад». npm run build-ро иҷро кунед, коммит кунед.
  4. Layout ва меню. Хоҳиш кунед: «components/Header.tsx бо логотип ва Nav, components/Nav.tsx (танҳо он бо "use client", usePathname, ҷудокунии саҳифаи ҷорӣ, мисли дарси 9), components/Footer.tsx; онҳоро дар app/layout.tsx пайваст кун, lang="ru", metadata-и умумӣ бо қолаби сарлавҳа. Менюи бургер дар телефон (дарси 8)». Сайтро кушоед, боварӣ ҳосил кунед, ки сарлавҳа намоён аст, ва меню ба суроғаҳо мебарад (онҳо ҳоло 404 медиҳанд).
  5. Панҷ саҳифа. Як-як: app/page.tsx (hero, 3 хизмат, тугма ба тамос), app/services/page.tsx, app/cases/page.tsx (кортҳои кейсҳо аз массив), app/about/page.tsx (даста, таърих), app/contacts/page.tsx (тамосҳо ва шакли дархост аз дарси 8: хоҳиш кунед, ки шакли аз dental-landing-ро мутобиқ кунад, он дар файли алоҳида компоненти мизоҷӣ мемонад). Ҳар саҳифаро дар браузер санҷед ва коммит кунед.
  6. Расмҳо. Файлҳоро ба public/images гузоред. Хоҳиш кунед: «Расмҳоро тавассути next/image пайваст кун: hero дар саҳифаи асосӣ бо preload, сурати даста дар саҳифаи Дар бораи ширкат бо fill ва object-cover, дар ҳар кадом alt, sizes нишон дода шудааст». Дар тирезаи танг санҷед, ки тарҳбандӣ «намепарад».
  7. Метатегҳо. Хоҳиш кунед: «Барои ҳар саҳифа title ва description-и худро тавассути metadata бидеҳ. Ҷадвали «саҳифа → title → description»-ро дар ҷавоб нишон бидеҳ». Саҳифаро кушоед, тугмаи рости мушро пахш кунед → «Намоиши рамзи саҳифа» (View Page Source) ва <title> ва <meta name="description">-ро пайдо кунед. Бонус: app/robots.ts ва app/sitemap.ts.
  8. Саҳифаи 404. app/not-found.tsx-ро дар услуби сайт бо истиноди «Ба саҳифаи асосӣ» хоҳиш кунед. Бо кушодани суроғаи вуҷуд надошта, масалан /zzz, санҷед.
  9. Санҷиш. npm run build-ро иҷро кунед: хатоҳо набояд бошанд. Тавассути меню гузаред, ҷудокуниро санҷед, сайтро дар паҳнои телефон кушоед (дарси 3), бубинед, ки рангҳо ҳама ҷо аз токенҳоянд. Аз агент пурсед: «рангҳои дастнавис сабтшударо пайдо кун» (ниг. промптҳои боло).
  10. GitHub ва Vercel. Репозиторияро дар GitHub созед, кодро фиристед (коммит ва push, дарси 4), дар Vercel репозиторияро воридот кунед (дарси 5) ва деплойро интизор шавед. Истиноди …vercel.app-ро кушоед, аз ҳама саҳифаҳо гузаред.
  11. Шарҳ. Аз AI пурсед, ки дар сайт кадом суроғаҳо ҳастанд ва чаро Nav.tsx мизоҷӣ аст, саҳифаҳо бошанд не. Ҷавобро бо суханони худ бигӯед — ин қадами «аз натиҷа ба фаҳмиш» аст.
Агар вайрон шуд

404 дар суроғае, ки шумо сохтед. Файл на page.tsx номида шудааст (масалан, services.tsx), берун аз ҷузвдони app мехобад ё дар номи ҷузвдон хато ҳаст. Номҳоро муқоиса кунед: суроға = номи ҷузвдон.

Хато дар бораи usePathname ва Client Component. Дар файли меню сатри аввал "use client" нест. Илова кунед ё аз AI хоҳиш кунед.

Хато дар бораи metadata ва "use client". Содироти metadata дар файли мизоҷӣ афтодааст. Саҳифаро ба серверӣ баргардонед, қисми мизоҷиро бошад ба компоненти алоҳида баред.

Хатои Invalid src prop … hostname "…" is not configured under images in your next.config.js. Расм аз суроғаи бегона: файлро ба public/images гузоред ё суроғаро ба images.remotePatterns илова кунед (матни хато дар версияи шумо метавонад каме фарқ кунад).

Расм «парид» ё ба тамоми экран кашида шуд. Дар Image бо fill падар бе relative ва баландӣ. Классҳоро монанди relative h-64 диҳед.

Услубҳои токенҳо татбиқ намешаванд (bg-brand-600 бе ранг). Санҷед, ки тағйирёбанда --color-brand-600 (бо пешванди --color-) номида шудааст ва дар дохили @theme мехобад; пас аз ислоҳ, агар саҳифа навсозӣ нашуд, npm run dev-ро аз нав оғоз кунед.

Меню дар ҳамаи саҳифаҳо ҷудо шудааст. Барои саҳифаи асосӣ startsWith("/") муқоиса мешавад. Муқоисаи дақиқро барои / баргардонед (ниг. вазифаи 3.1).

Vercel чизи дигар ҷамъ кард, на он ки дар компютер аст. git push-ро фаромӯш кардед ё файлҳоро коммит накардед (хусусан public/images). Файл бо ҳарфи калон дар ном дар Windows ва macOS кор мекунад, дар Vercel (Linux) бошад вайрон шуданаш мумкин: ҳарфҳои калону хурдро дар воридотҳо муқоиса кунед.

09 Фишкаи дарс: баррасии ҳамдигарии код

Дастаҳои касбӣ коде, ки одами дуюм ба он нигоҳ накардааст, нашр намекунанд. Ин код-ревью (баррасии код) ном дорад. Имрӯз шумо худро дар ду нақш месанҷед: муаллиф ва баррасикунанда. Дар ҷуфтҳо кор мекунед, сайти бегонаро аз рӯи рӯйхати санҷиш месанҷед ва шарҳҳои судманд менависед. Блок барои муаллим пешбинӣ шудааст ва дар синф ё онлайн гузаронида мешавад.

Қоидаҳо

1. Ҷуфтҳоро муаллим таъин мекунад (ё қуръа). Ҳар кас сайти ҳамсояро месанҷад ва баррасиро ба сайти худ мегирад. 2. Баррасикунанда ду ҷадвал дорад: сайти зинда дар Vercel ва репозитория дар GitHub. 3. Қатъиян аз рӯи рӯйхати санҷиши зер мегузарем, дар коди бегона чизеро ислоҳ намекунем: танҳо шарҳ. 4. Шарҳ бояд мушаххас бошад: дар куҷо (файл ё саҳифа), чӣ нодуруст аст, чаро ин муҳим аст, чӣ тавр ислоҳ кардан. Бе «бад» ва «ба ман маъқул нест». 5. Ба ҳар мулоҳиза дараҷа дода мешавад: монеа (сайт вайрон мешавад ё талабот иҷро нашудааст), муҳим (бояд ислоҳ шавад), беҳбудӣ (ба ихтиёр). 6. Ҳадди ақал як мулоҳиза ҳатмист ва ҳадди ақал як таърифи чизи хуб. 7. Муаллиф ба ҳар мулоҳиза ҷавоб медиҳад: «ислоҳ шуд» ё «розӣ нестам, зеро…».
