Telegram-бот ва худкорсозӣ

То охири дарс лоиҳаи хатмии шумо интерфейси дуюм пайдо мекунад: Telegram-бот. Аризаҳои нав ё фармоишҳо ба соҳиб дар Telegram меоянд, бот ба фармонҳое монанди /status ҷавоб медиҳад, ва одамони бегона на дархостро ба бот дурӯғ карда метавонанд, на фармонҳои маъмуриро иҷро кунанд. Илова бар ин, шумо як худкорсозиро дар n8n (ё дар Make) бе як сатр код месозед.

  • Ботро тавассути BotFather эҷод кунед, токенро танҳо дар тағйирёбандаҳои муҳит нигоҳ доред ва шарҳ диҳед, ки ҳангоми ошкор шудани он чаро хатарнок аст
  • Объекти JSON-и навсозиро (Update) аз Telegram хонед ва аз он рақами чат, матн ва фармонро ҷудо кунед
  • Вебхукро ба route handler-и Next.js пайваст кунед, сарлавҳаи secret_token-ро санҷед ва ба фармонҳо ҷавоб диҳед
  • Ҳангоми аризаи нав ба Telegram огоҳинома фиристед ва фармонҳои маъмуриро бо рӯйхати chat id-ҳои иҷозатдода ва ҳадди дархостҳо ҳифз кунед
  • Вебхукро дар суроғаи ҷамъиятии HTTPS санҷед: дар Vercel ё тавассути туннел (ngrok, cloudflared)
  • Худкорсозиро дар n8n ё Make созед ва шарҳ диҳед, кай конструктор кифоя аст ва кай код лозим
Ин дарсро чӣ тавр гузаштан лозим

01 Чаро маҳсулот бот лозим дорад: Telegram ҳамчун интерфейси дуюм

Фармоиши воқеиро дар фриланс тасаввур кунед. Соҳиби чойхонаи душанбегӣ мегӯяд: «Аризаҳо барои мизҳо ба сайт меоянд, вале ман дар ошхона нишастаам ва сайтро намекушоям. Мехоҳам, ки ба Telegram хабар расад: кӣ, барои чанд нафар, ба кадом вақт. Ва ман ба бот /status нависам ва донам, имрӯз чанд ариза ҳаст». Ин фармоиши хеле маъмулист: дар Тоҷикистон Telegram паёмрасони асосии муштариён, таъминкунандагон ва кормандон аст. Одамон «боз як барнома»-и мағозаи шуморо насб намекунанд, вале Telegram барояшон ҳамеша кушода аст.

Бот ҳамчун интерфейси дуюм-и ҳамон маҳсулот кор мекунад. Сайт ҷои асосӣ мемонад, ки маълумот дар он сохта ва нигоҳ дошта мешавад (Supabase, дарси 11). Бот сайтро иваз намекунад, балки роҳи дигари гуфтугӯ бо ҳамон маълумотро медиҳад:

Дар фармоишҳои воқеӣ аз бот одатан чиро мепурсанд:

  • Огоҳиномаҳо: ариза нав, фармоиши нав, пардохт гузашт, боқимондаи мол тамом шуд. Як паём ба соҳиб.

Монандӣ аз ҳаёт

Фаромӯш кардан, ки огоҳинома набояд амали асосиро вайрон кунад: агар Telegram дастнорас бошад, аризаи муштарӣ ба ҳар ҳол бояд сабт шавад.

02 Telegram Bot API: BotFather, токен, Update

Telegram ба ботҳо HTTP API-и оддӣ медиҳад, яъне ҳамон чизе, ки шумо аз дарси 10 медонед: дархост ба суроға, JSON ба он ҷо, JSON ба ин ҷо. «Барномасозии бот»-и ҳақиқӣ лозим нест: бот — ин сервери шумост, ки ба дархостҳои Telegram ҷавоб медиҳад ва худаш усулҳои Telegram-ро мехонад.

Қадами 1. Ботро дар BotFather сабт мекунем

Ягона роҳи расмии эҷоди бот: ба @BotFather дар худи Telegram навиштан (дар паҳлӯи ном аломати кабуд ҳаст; бо номи монанд қалбакиҳо бисёранд). Мукотиба чунин менамояд:

  1. @BotFather-ро кушоед ва /newbot фиристед.
  2. Ном-ро ворид кунед (одамон онро мебинанд, бо русӣ ҳам мешавад: «Чойхона Рудаки») ва username (нодир, бо ҳарфҳои лотинӣ, ҳатман бо bot тамом мешавад, масалан choyxona_rudaki_bot).
  3. BotFather токен мефиристад: сатри намуди рақамҳо:ҳарфу-рақамҳо. Ин калиди бот аст.
  4. Токенро фавран ба .env.local ҳамчун TELEGRAM_BOT_TOKEN нусха кунед ва дигар ҷое нишон надиҳед.
Токен — ин пароли бот аст

Касе ки токенро медонад, метавонад аз номи бот паём фиристад, он чиро, ки ба бот менависанд, бихонад ва вебхукро иваз кунад. Қоидаҳо ҳамон, ки барои калиди Gemini дар дарси 13: танҳо .env.local ва тағйирёбандаҳои Vercel, бе префикси NEXT_PUBLIC_, на дар код, на дар чат бо AI, на дар скриншот, на дар логҳо. Агар токен ошкор шуд, дар BotFather боти худро кушоед (фармони /mybots) ва токенро аз нав содир кунед (дар менюи API Token бандӣ барои бекор кардани токени ҷорӣ ҳаст), баъд .env.local ва Vercel-ро нав кунед. Номҳои дақиқи бандҳо метавонанд тағйир ёбанд.

Қадами 2. Дархост ба API чӣ гуна менамояд

Ҳамаи усулҳо аз рӯи як қолаб даъват мешаванд: https://api.telegram.org/bot<ТОКЕН>/<УСУЛ>. Диққат диҳед: токен ба суроға дохил аст. Барои ҳамин суроғаи дархост ё хатогиеро, ки онро дар бар мегирад, ба лог чоп кардан мумкин нест. Ҷавоб ҳамеша JSON аст: {"ok": true, "result": …} ҳангоми муваффақият ё {"ok": false, "description": "…"} ҳангоми хатогӣ.

curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getMe"

Ҷавоби getMe ном ва username-и ботро нишон медиҳад: бо ҳамин санҷида мешавад, ки токен корист. Се усуле, ки дар ин дарс лозиманд:

Қадами 3. Аз Telegram чӣ меояд: объекти Update

Вақте одам ба бот менависад, Telegram объекти JSON-и Update («навсозӣ») месозад. Он рақами update_id ва дақиқан як майдони-рӯйдод дорад. Барои паёми матнӣ ин майдони message аст: дар дохилаш chat (чате, ки паём дар он омад, бо id-и рақамӣ), from (кӣ навишт), text ва, агар ин фармон бошад, массиви entities бо сабти намуди bot_command. Дар чати шахсӣ chat.id бо рақами корбар мувофиқат мекунад; дар гурӯҳ ин рақами алоҳида (манфӣ) аст.

{
  "update_id": 900001,
  "message": {
    "message_id": 17,
    "from": { "id": 555111, "is_bot": false, "first_name": "Фарзона" },
    "chat": { "id": 555111, "type": "private", "first_name": "Фарзона" },
    "date": 1767225600,
    "text": "/status",
    "entities": [{ "offset": 0, "length": 7, "type": "bot_command" }]
  }
}

Ҳар навсозӣ паём нест: паёмҳои таҳриршуда, пахшҳои тугмаҳо, илова шудани бот ба гурӯҳ низ ҳастанд. Барои ҳамин код ҳамеша бо саволи «оё дар ин ҷо message.text ҳаст?» оғоз мешавад. Фармон дар гурӯҳ метавонад бо номи бот ояд: /status@choyxona_rudaki_bot, инро низ бояд тавонист таҳлил кард.

Хатогиҳои маъмули навомӯзон

1. update.text-ро ба ҷои update.message.text гирифтан: дар сатҳи боло танҳо update_id ва намуди рӯйдод ҳаст. 2. Бо навсозии бе message (масалан, edited_message) афтидан: сервер хатогӣ бармегардонад, ва Telegram ҳамон навсозиро аз нав мефиристад. 3. chat.id-ро ҳамчун сатр нигоҳ доштан ва бо рақам муқоиса кардан: "555111" === 555111 false медиҳад. 4. Намунаи Update-ро бо токени воқеӣ ё рақами телефони бегона ба чат бо AI гузоштан.

миёна

Ҳамаи изҳороти дурустро интихоб кунед.

03 Вебхук дар route handler-и Next.js ва суроғаи ҷамъиятӣ

Бот аз куҷо мефаҳмад, ки ба ӯ навиштанд? Ду роҳ ҳаст ва онҳо ҳамдигарро истисно мекунанд: ё бот худаш пайваста аз Telegram мепурсад «чӣ нав?» (усули getUpdates, «пурсиш»), ё шумо як маротиба ба Telegram мегӯед «хабарҳоро ба ин суроға фирист» (setWebhook, «вебхук»). То вақте ки вебхук насб аст, getUpdates кор намекунад. Барои сайт дар Vercel вебхук мувофиқ аст: шумо барномаи доимо корандае надоред, ки пурсиш кунад, вале route handler (дарси 10) доред, ки бо дархост бедор мешавад.

Талаботи Telegram ба суроғаи вебхук

  • Танҳо HTTPS бо сертификати воқеӣ. Портҳо мувофиқи ҳуҷҷат: 443, 80, 88 ё 8443.
  • Суроға бояд ҷамъиятӣ бошад: серверҳои Telegram аз интернет мезананд. http://localhost:3000 барои онҳо вуҷуд надорад.
  • Редиректҳо дастгирӣ намешаванд: суроға бояд худаш ҷавоб диҳад, на ин ки роҳнамоӣ кунад.
  • Telegram дархостро бо усули POST бо бадани JSON мефиристад. Агар ҷавоб 2xx набошад, Telegram фиристодани такрориро чанд маротиба иҷро мекунад ва дар охир бас мекунад, пас ҷавоби 500 «ҳар эҳтимол» такрорҳо ва нусхаҳои дубораро меорад.
«Вебхук дар localhost кор намекунад» — ва бо ин чӣ кор кардан

Се роҳ ҳаст. 1. Продакшн дар Vercel: роутро ҷойгир кунед ва вебхукро ба https://лоиҳаи-шумо.vercel.app/api/telegram гузоред. Ин роҳи аз ҳама соддатарин аст ва он барои боти воқеӣ ба ҳар ҳол лозим аст. 2. Preview дар Vercel: шохаҳо суроғаҳои худро доранд, вале Vercel бо пешфарз суроғаҳои preview-ро бо муҳофизат мепӯшонад (Deployment Protection: Standard Protection ҳамаи суроғаҳоро, ба истиснои доменҳои продакшн, мепӯшонад). const TOKEN = process.env.TELEGRAM_BOT_TOKEN;
const SECRET = process.env.TELEGRAM_WEBHOOK_SECRET;

type Update = {
  update_id: number;
  message?: { chat: { id: number; type: string }; from?: { id: number }; text?: string };
};

async function sendMessage(chatId: number, text: string) {
  const res = await fetch(`https://api.telegram.org/bot${TOKEN}/sendMessage`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ chat_id: chatId, text }),
  });
  // Ба лог танҳо статус, ҳеҷ гоҳ суроғаи дархост: дар он токен ҳаст
  if (!res.ok) console.error("telegram sendMessage failed", res.status);
}

export async function POST(req: Request) {
  // 1. Дархост дар ҳақиқат аз Telegram аст?
  if (!SECRET || req.headers.get("x-telegram-bot-api-secret-token") !== SECRET) {
    return new Response("unauthorized", { status: 401 });
  }

  // 2. Таҳлили навсозӣ
  const update = (await req.json()) as Update;
  const msg = update.message;
  if (!msg?.text) return Response.json({ ok: true }); // матн нест: хомӯшона қабул мекунем

  // 3. Фармонҳо
  if (msg.text.startsWith("/start")) {
    await sendMessage(msg.chat.id, "Салом! Я бот чойхоны. Команда /help покажет, что я умею.");
  }

  return Response.json({ ok: true }); // ҳамеша 200-и зуд
}

Дар ин ҷо чӣ муҳим аст. Сарлавҳаи x-telegram-bot-api-secret-token-ро Telegram ба ҳар дархост илова мекунад, агар шумо ҳангоми setWebhook secret_token-ро нишон дода бошед (1–256 аломат: ҳарфҳои лотинӣ, рақамҳо, _ ва -, мувофиқи ҳуҷҷати Bot API). Агар сарлавҳа мувофиқат накунад — ин Telegram нест, балки шахси бегонае аст, ки суроғаи роутро фаҳмидааст. Асрорро худатон меандешед ва ба TELEGRAM_WEBHOOK_SECRET мегузоред: масалан, 32 аломати тасодуфӣ аз генератори паролҳо.

Огоҳинома: сайт ба Telegram менависад

Барои огоҳинома вебхук умуман лозим нест: сайт кифоя аст, ки sendMessage-ро даъват кунад. Ду қимат лозим аст: токен ва chat id-и соҳиб (TELEGRAM_ADMIN_CHAT_ID). Chat id-и худро чӣ тавр донистан: ба бот /start нависед, ва дар Update аз вазифаи боло рақами message.chat.id — ҳамон аст. Аз ҳама осон аст, ки msg.chat.id-ро муваққатан ба логи роут чоп кунед (худи id асрор нест, вале нашр кардани он маъное надорад).

export async function notifyOwner(text: string) {
  const token = process.env.TELEGRAM_BOT_TOKEN;
  const chatId = process.env.TELEGRAM_ADMIN_CHAT_ID;
  if (!token || !chatId) return; // бот танзим нашудааст: ба кори асосӣ халал намерасонем
  try {
    const res = await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ chat_id: Number(chatId), text, parse_mode: "HTML" }),

Паёмро чӣ тавр оро додан

Барои матн parse_mode: "HTML"-ро фаъол кардан мумкин аст: он гоҳ тегҳои <b>, <i>, <code> кор мекунанд. Аммо ҳар чизе, ки муштарӣ ворид кардааст (ном, шарҳ), бояд экранировка шавад: &, <, >-ро иваз кунед, вагарна муштарӣ ба ном теги вайронкунанда мегузорад, паёмро вайрон мекунад (Telegram бо хатогии 400 ҷавоб медиҳад) ё истиноди қалбакӣ мечаспонад. 05 Амнияти бот: асрор, санҷиш, ҳадҳо

Суроғаи ҷамъиятии вебхук ва username-и ҷамъиятии бот — ин дари кушода аст, ва боти шуморо ҳамаи корбарони Telegram мебинанд: онро бо ном ёфтан мумкин аст. Аз дарси 19 шумо медонед, ки AI коде менависад, ки «кор мекунад», вале ҳифз намекунад. Барои бот ҳифз аз панҷ қоида иборат аст:

1. Токен ва асрор — танҳо дар муҳит
TELEGRAM_BOT_TOKEN ва TELEGRAM_WEBHOOK_SECRET дар .env.local ва дар тағйирёбандаҳои Vercel мехобанд, бе NEXT_PUBLIC_; дар репозиторий танҳо .env.example бе қиматҳо. Ин ҳамон аудит аст, ки дар дарси 19 (git grep аз рӯи қолаби токен: рақамҳо, дунуқта, сатри дароз).
2. Токен ба логҳо намеафтад
Дар суроғаи дархостҳо ба API токен ҳаст. Барои ҳамин дар console.log на суроғаи дархостро чоп мекунанд, на тамоми объекти хатогии fetch-ро, на пурра сарлавҳаҳои дархостро (дар онҳо асрори вебхук аст). Статуси ҷавоб ва тавсифи умумӣ чоп мешавад.
3. Санҷиши сарлавҳаи махфӣ
Сатри якуми роут — муқоисаи X-Telegram-Bot-Api-Secret-Token бо асрори шумо. Мувофиқ набуд: 401 ва тамом. Ин санҷиш пеш аз хондани бадани дархост меистад.
4. Фармонҳои маъмурӣ — танҳо барои иҷозатдодагон
Ботро ҳар кас меёбад. Фармонҳое, ки маълумоти муштариёнро нишон медиҳанд ё чизеро тағйир медиҳанд, chat.id-ро аз рӯи рӯйхат месанҷанд (TELEGRAM_ADMIN_IDS дар муҳит, бо вергул). «Фармонҳои махфӣ», ки танҳо худиҳо медонанд, нестанд: номи фармон ҳифз нест.
5. Ҳади дархостҳо
Як корбаре, ки ба бот садҳо паём мефиристад, сервер ва пойгоҳи шуморо бор мекунад. Соддатарин ҳад: на зиёда аз N паём аз як chat.id дар як дақиқа; боқимонда хомӯшона нодида гирифта мешавад (ҷавоби 200 ба ҳар ҳол лозим аст, вагарна Telegram такрор мекунад).
const ADMIN_IDS = (process.env.TELEGRAM_ADMIN_IDS ?? "")
  .split(",")
  .map((s) => Number(s.trim()))
  .filter((n) => Number.isInteger(n) && n !== 0);

const hits = new Map<number, { count: number; resetAt: number }>();

// На зиёда аз 10 паём дар як дақиқа аз як чат.
// Хотира то зиндагии нусхаи функсия мемонад: барои омӯзиш кифоя аст,
// барои маҳсулоти воқеӣ ҳадро дар пойгоҳи умумӣ нигоҳ медоранд (масалан, Upstash Redis ё ҷадвал дар Supabase).
function tooMany(chatId: number): boolean {
  const now = Date.now();
  const h = hits.get(chatId);
  if (!h || h.resetAt < now) {
    hits.set(chatId, { count: 1, resetAt: now + 60_000 });
    return false;
  }
  h.count += 1;
  return h.count > 10;
}

  return msg.chat.type === "private" && ADMIN_IDS.includes(msg.chat.id);
}

Workflow-и «Хулосаи субҳ»-ро ҷамъ кунед: ҳар рӯз соати 9:00 бот ба соҳиб шумораи аризаҳои нави як шабонарӯзро мефиристад (нақша дар бахши 6). Он танҳо мефиристад, барои ҳамин дар n8n-и маҳаллӣ низ кор мекунад.

  2. Триггер. Гиреҳи Schedule Trigger-ро илова кунед: як маротиба дар як рӯз соати 09:00. Барои санҷиш тугмаи оғози дастӣ ҳаст (Execute workflow), субҳро интизор шудан лозим нест.
  3. Додаҳо. Гиреҳи Supabase-ро илова кунед (сатрҳои ҷадвали аризаҳоро бо шарти «сохташуда дар 24 соати охир» гиред) ва маълумоти воридшавӣ: суроғаи лоиҳа ва калид аз панели Supabase. Барои прототип калиди махфӣ мешавад, вале дар хотир доред, ки он RLS-ро убур мекунад; онро танҳо дар маълумоти воридшавии n8n нигоҳ доред ва содироти workflow-ро нашр накунед. Агар гиреҳи Supabase танзим нашавад, гиреҳи HTTP Request ва суроғаи REST API-и лоиҳаи худро гиред (аз AI хоҳиш кунед, ки дархостро аз рӯи ҳуҷҷати Supabase ҷамъ кунад).
  4. Шарт. Гиреҳи If: шумораи сатрҳо аз 0 зиёд. Вагарна паём фиристода намешавад.
  5. Telegram. Гиреҳи Telegram, амали «Send Message»: маълумоти воридшавӣ бо токени бот, chat_id-и соҳиб, матни «Аризаҳои нави як шабонарӯз: …» бо рақам аз гиреҳи қаблӣ.
  6. Санҷиш. Дастӣ оғоз кунед: паём омад. Workflow-ро фаъол кунед (калиди Active), то аз рӯи ҷадвал кор кунад.
Агар вайрон шуд

Қоидаҳои RLS калиди намуди publishable-ро намегузоранд: калидро бо ҳуқуқҳо барои сервер гиред ва хатарро дар хотир доред, ё маълумотро дар тарафи API-и худ филтр кунед. Ҷадвал кор намекунад. Интерфейсҳои n8n ва Make навсозӣ мешаванд: гиреҳро бо ном дар ҷустуҷӯ ҷӯед ва скриншоти экранро бе калидҳо ба AI фиристед.

  • Update: update_id ва як майдони-рӯйдод; матн: message.text, чат: message.chat.id, фармон: entities бо bot_command; дар гурӯҳ фармон метавонад /cmd@номи_бот бошад. message нест — нодида гиред.
  • Вебхук: HTTPS-и ҷамъиятӣ (портҳои 443, 80, 88, 8443), бе редиректҳо; getUpdates ва вебхук ҳамдигарро истисно мекунанд; на-2xx ба такрорҳо мебарад. Дар localhost кор намекунад: Vercel (продакшн) ё туннел (cloudflared tunnel --url …, ngrok http …); preview дар Vercel бо пешфарз бо муҳофизат пӯшида аст.
  • secret_token: 1–256 аломат (A-Z a-z 0-9 _ -), дар сарлавҳаи X-Telegram-Bot-Api-Secret-Token меояд; мувофиқ набуд: 401.
  • Ҳифз: асрор, рӯйхати маъмурон аз рӯи chat.id аз муҳит, ҳад барои чат, логҳои тоза, 200 ба ҳама чизи дигар, экранировкаи матни корбар барои HTML, нусхаҳои дубора аз рӯи update_id.
  • Ҳадҳои Telegram: тақрибан 1 паём дар як сония ба чат, то 20 дар як дақиқа ба гурӯҳ, тақрибан 30 дар як сония ҳамагӣ; баъд хатогии 429.
  • n8n ва Make: конструкторҳои занҷирҳо (триггер → амал → шарт). n8n: абр (давраи санҷишӣ) ё npx n8n → localhost:5678; Make: тарифи ройгон бо ҳади кредитҳо. Триггерҳои воридотӣ дар маҳал суроғаи ҷамъиятиро талаб мекунанд; ҷадвал бе он кор мекунад. Тарифҳоро дар сайтҳо санҷед.
  • AI: версияҳо ва файлҳоро номбар кунед, санҷишҳои амниятро рӯйхат кунед, токенро нагузоред, усулҳоро бо ҳуҷҷат муқоиса кунед, хатогиҳоро бо getWebhookInfo фиристед.

Ман мавзӯъро воқеан фаҳмидам

осон

Танҳо он чиро аломат гузоред, ки бе ишора карда метавонед.

  • Метавонам ба фармоишгар шарҳ диҳам, ки бот аз сайт чӣ фарқ дорад ва чаро ҳамчун интерфейси дуюм лозим аст
  • Метавонам дар BotFather бот эҷод кунам, токенро санҷам ва медонам, ки ҳангоми ошкор шудани он чӣ кор кардан лозим
  • Метавонам Update-ро хонам ва аз он chat id, матн ва фармонро ҷудо кунам
  • Метавонам route handler-и вебхукро нависам ва вебхукро бо фармони setWebhook гузорам
  • Медонам, ки вебхук чаро дар localhost кор намекунад, ва метавонам онро дар Vercel ё тавассути туннел санҷам
  • Метавонам огоҳиномаро дар бораи ариза нав фиристам ва матни корбарро экранировка кунам
  • Метавонам ботро ҳифз кунам: сарлавҳаи махфӣ, рӯйхати маъмурон, ҳад, логҳои тоза
  • Метавонам худкорсозии оддиро дар n8n ё Make ҷамъ кунам ва бигӯям, кай код беҳтар аст
