01 Чаро «дар ман кор мекунад» ҳисоб намешавад

Шумо тугмаро пахш кардед, форма фиристода шуд, сабт пайдо гашт. Кор мекунад? Шумо як роҳро санҷидед: бо ҳисоби худ, бо маълумоти дуруст, дар як браузер, як бор. Корбарони воқеӣ тамоман дигар амал мекунанд: майдони холиро пур мекунанд, бо нақши дигар медароянд, «Бозгашт»-ро пахш мекунанд, сайтро аз телефон мекушоянд. Ва муҳимтар аз ҳама: код ҳар рӯз тағйир меёбад. Дирӯз ҳама чиз кор мекард, имрӯз агент «каме ислоҳ кард» файли ҳамсояро, ва воридшавӣ вайрон шуд. Пас аз ҳар ислоҳ ҳама чизро бо дасти худ санҷидан номумкин аст: шумо аллакай дар санҷиши сеюм хаста мешавед.

Бо коди AI ин махсусан муҳим аст. Агент боварибахш ва кӯтоҳ менависад «тайёр аст, ҳама чиз кор мекунад». Аммо ӯ на ҳамеша код-ро ба кор андохтааст, ва агар андохта бошад ҳам, шояд чизи нодурустро санҷида бошад. Шабакаи нейронӣ метавонад ҷавоби ба ҳақиқат монандро дар бораи натиҷае нависад, ки набуд. Бинобар ин дар вайбкодинг қоида амал мекунад: кор мекунад он чизе, ки иҷро тасдиқ кардааст, на суханони агент. Санҷиши натиҷа маҳорати асосии инсон дар ҷуфт бо AI аст.

Ошпаз дар чойхона палавро бо қошуқ аз лаби дег мечашад: бомазза. Аммо меҳмонон қисмеро мегиранд, ки аз таги дег аст ва сӯхтааст. Автотест — санҷиш аз рӯи рӯйхат пеш аз пешниҳод: биринҷ, гӯшт, сабзӣ, намак, ҳарорат. Ҳар дафъа якхела, ҳатто агар ошпаз хаста ё шитобон бошад.

Хатогиҳои маъмули навомӯзон

1. Ба сатри «ман ҳама чизро санҷидам» аз агент бе иҷро бовар кардан. 2. Танҳо ҷойеро санҷидан, ки ислоҳ шуд. 3. Танҳо зери администратор тест кардан. 4. Тестҳоро «кори зиёдатӣ барои баъд» ҳисоб кардан: маҳз пас аз ислоҳи сеюм онҳо наҷот медиҳанд. 5. Аз агент хостан «тестҳоро гузарон» ва баромадро накушодан: ӯ метавонад тестро ба коди вайроншуда мувофиқ кунад.

ВАЗИФАИ 1.1

Худро санҷед: чӣ санҷиш ҳисоб мешавад

осон

Шумо аз агент хостед, ки ба формаи фармоиш майдони «шарҳ» илова кунад. Ӯ ҷавоб дод: «Тайёр аст, форма кор мекунад». Чиро далел ҳисоб кардан лозим?

  1. Худи ҷавоби агент: ӯ код-ро дид, пас медонад, ки ҳама чиз дуруст аст
  2. Иҷрои сенария («ворид шудан, фармоиш сохтан, онро дар рӯйхат дидан») ва натиҷаи сабзе, ки шумо худатон мебинед
  3. Он, ки файл дар муҳаррир бе хатҳои сурх кушода мешавад
  4. Набудани шикоят дар рӯзи аввал

Суханони агент фарзия аст, иҷро бошад санҷиш. Хатҳои зери сурх дар муҳаррир кам аст: код метавонад аз ҷиҳати синтаксис дуруст бошад ва бо ин ҳама сенарияро вайрон кунад. Интизор шудани шикоятҳо маънои санҷиш бар корбаронро дорад.

Кадоме аз ин хатогиҳо бо даст одатан намоён нест, то ки махсус санҷида нашавад? Ҳамаи вариантҳои дурустро интихоб кунед.

  1. Корбари оддӣ /admin-ро мекушояд ва саҳифаро мебинад
  2. Дар сарлавҳаи саҳифаи асосӣ хатои имлоӣ ҳаст, ва шумо ҳар рӯз ба он менигаред
  3. Формаи холӣ сабтро бе ном месозад
  4. Тугмаи «Войти» пахш намешавад, ва ин фавран намоён аст

Намоён он чизест, ки ба он менигаред. Санҷишҳо зери нақши дигар ва бо маълумоти нодуруст намоён нестанд: касе онҳоро «дар баробари кори дигар» намекунад.

02 Тести сенарияӣ бо даст: аввал мефаҳмем, ки чиро месанҷем

Автотестро то он даме навиштан мумкин нест, ки худатон надонед, ки чӣ бояд рӯй диҳад. Бинобар ин аввал сенарияро бо даст мегузаронанд ва менависанд. Сенария — роҳи инсон тавассути маҳсулот барои як мақсад: «харидор маҳсулотро интихоб мекунад ва фармоиш медиҳад», «мизоҷ барои қабул навбат мегирад», «менеҷер мизоҷро ба CRM илова мекунад». Сенарияи асосии лоиҳаи хатмии худро шумо дар ТВ (дарси 16) тасвир кардед ва дар спринти 2 (дарси 18) сохтед.

Онро бо ҷадвали се сутун нависед: қадам (инсон чӣ мекунад), интизорӣ (чӣ бояд бинад) ва воқеият (воқеан чӣ диданд; ҳоло холӣ). Таърифҳоро чунон нависед, ки инсон мебинад: на «POST кор кард», балки «дар рӯйхат сатр бо ном пайдо шуд».

03 Автотести сенарияи асосӣ: Playwright

Playwright — абзори ройгон, ки браузери воқеиро мекушояд ва ҳамон корро мекунад, ки шумо мекардед: ба саҳифа медарояд, матн ворид мекунад, тугмаҳоро пахш мекунад ва месанҷад, ки дар экран чизи лозимӣ пайдо шуд. Чунин тестҳоро e2e (end-to-end, «аз канор то канор») меноманд: онҳо тамоми роҳро аз браузер то базаи маълумот мегузаранд. Шумо як фармон иҷро мекунед, браузер барои чанд сония кушода ва баста мешавад, ва дар терминал рӯйхат намоён аст: чӣ гузашт, чӣ не.

Насб дар лоиҳаи Next.js

Роҳи расмӣ аз ҳуҷҷатҳои Next.js: npm init playwright@latest дар решаи лоиҳа. Фармон саволҳо медиҳад: забон (TypeScript-ро интихоб кунед), папкаи тестҳо (tests), оё файли GitHub Actions лозим аст (ҳоло не, дар бонус бармегардем) ва оё браузерҳо зеркашӣ шаванд (ҳа). Ҷавобҳо аз рӯи тартиб: TypeScript, папкаи tests, GitHub Actions: не, браузерҳо: ҳа. Фармон Playwright-ро ба package.json илова мекунад, playwright.config.ts ва намунаи tests/example.spec.ts-ро месозад. Браузерҳо садҳо мегабайт вазн доранд, зеркашӣ чанд дақиқа мегирад.

npm init playwright@latest
npx playwright test

Конфиг: сайтро худамон оғоз мекунем

Барои ин ки терминали дуюм кушода нашавад, дар конфиг блоки webServer ҳаст: Playwright фармонро иҷро мекунад, интизор мешавад, ки суроға ҷавоб диҳад, ва танҳо баъд тестҳоро оғоз мекунад. baseURL имкон медиҳад, ки дар тестҳо суроғаҳои кӯтоҳ, ба монанди /login, нависед. Файли тавлидшударо чунин ислоҳ кунед (боқимондаи тавлидшударо мемонед):

import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  // як браузер: тезтар ва хондани натиҷа осонтар
  projects: [{ name: 'chromium', use: { ...devices['Desktop Chrome'] } }],
  use: {
    baseURL: 'http://localhost:3000',
    trace: 'on-first-retry',
  },
  webServer: {
    command: 'npm run dev',
    url: 'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
    timeout: 120 * 1000,
  },
});

Ҳуҷҷатҳои Next.js тавсия медиҳанд, ки тестҳоро дар версияи ҷамъшуда (npm run build ва npm run start) иҷро кунед, зеро он ба версияи ҷангӣ наздиктар аст. Барои дарс npm run dev кофист: соддатар. Агар дар dev тестҳо баъзан аз сабаби вақт меафтанд, зеро саҳифаҳо ҳангоми кушодани аввал ҷамъ мешаванд, фармонро ба npm run build && npm run start иваз кунед.

Тест чӣ гуна менамояд

Тест — функсия бо ном аст, ки дар дарунаш қадамҳои корбар ва санҷишҳо мебошанд. Қадамҳо: goto (кушодани суроға), fill (ворид кардани матн), click (пахш кардан). Санҷишҳо: expect(...) бо toBeVisible() («дар саҳифа намоён аст») ё toHaveURL() («суроға чунин аст»). Унсурҳоро чунон меҷӯянд, ки инсон онҳоро мебинад: getByRole('button', { name: '...' }) («тугма бо чунин ном»), getByLabel('...') («майдон бо чунин навишт»), getByText('...'). Дар ҳуҷҷатҳои Playwright маҳз getByRole дар аввали рӯйхати тавсияҳост, ва селекторҳои CSS ва XPath барои ҳолати охирин мондаанд. Санҷишҳои expect интизор шуда метавонанд: агар унсур баъди як сония пайдо шавад, тест интизор мешавад, на фавран меафтад.

import { test, expect } from '@playwright/test';

// тести 1: меҳмон дар саҳифаи пӯшида ба воридшавӣ мегузарад
test('guest is redirected to login', async ({ page }) => {
  await page.goto('/dashboard');
  await expect(page).toHaveURL(/\/login/);
});

// тести 2: воридшавӣ ва сохтани сабт (сенарияи асосӣ)
test('user signs in and creates an item', async ({ page }) => {
  const title = 'e2e-item-' + Date.now(); // номи беназир, то тестҳо ба ҳам халал нарасонанд
  await page.goto('/login');
  await page.getByLabel('Email').fill(process.env.E2E_EMAIL!);
  await page.getByLabel('Password').fill(process.env.E2E_PASSWORD!);
  await page.getByRole('button', { name: 'Sign in' }).click();
  await expect(page).toHaveURL(/\/dashboard/);

  await page.getByRole('button', { name: 'New item' }).click();
  await page.getByLabel('Title').fill(title);
  await page.getByRole('button', { name: 'Save' }).click();
  await expect(page.getByText(title)).toBeVisible();
});

Навиштаҳо дар нохунакҳо («Sign in», «New item») дар мисол англисианд: лоиҳаи шумо навиштаҳои худро дорад, масалан «Войти». Тест бояд он чизеро ҷӯяд, ки дар экрани сайти шумо навишта шудааст. Почта ва пароли корбари санҷишӣ аз process.env гирифта мешавад, яъне аз файли .env.test (он дар .gitignore ҳамон тавр баста шудааст, ки .env.local), на аз код: ин ҳамон қоидаи асрор аз дарси 19 аст.

Иҷро, ҳисобот ва таҳлили афтодан

  • npx playwright test ҳамаи тестҳоро дар реҷаи хомӯш (бе равзанаи браузер) иҷро мекунад.
  • npx playwright test --ui равзанаеро мекушояд, ки дар он ҳар қадами тест ва акси саҳифа дар он намоён аст: роҳи беҳтарин барои фаҳмидани рӯйдод.
  • npx playwright test --headed равзанаи воқеии браузерро нишон медиҳад.
  • npx playwright show-report ҳисоботи HTML-ро мекушояд: рӯйхати тестҳо, сабаби афтодан, акс ва қадамҳо.

Натиҷаи сурхро чӣ тавр хондан

  1. Номи тест. Аз рӯи он маълум мешавад, ки кадом қадами сенария вайрон шудааст.
  2. Сатри хато. Масалан, expect(locator).toBeVisible() failed ва Timeout 5000ms exceeded: интизор шуд-шуд ва интизор нашуд.
  3. Чиро меҷӯянд. Сатри Locator: нишон медиҳад, ки кадом унсур. Агар матн дар сайт тағйир ёфта бошад, тест тугмаро наёфт.
  4. Қарор: хато ё тести кӯҳнашуда? Агар сайт вайрон бошад, код-ро ислоҳ кунед. Агар матнро бошуурона тағйир додед, тестро нав кунед. Тестро «ислоҳ» накунед, ки сабз шавад, бе фаҳмидан.

Codegen: сабти қадамҳо бо муш

Агар навиштани қадамҳо намехоҳед, Playwright метавонад онҳоро сабт кунад: фармони npx playwright codegen http://localhost:3000 браузер ва равзанаи Playwright Inspector-ро мекушояд. Шумо дар сайт клик мекунед, ва кликҳо ба коде табдил меёбанд, ки нусха бардоштан мумкин аст. Дар панел тугмаҳои санҷишҳо ҳастанд (намоёнӣ, матн, қиммат): ҳамин тавр expect илова мекунед. Сабт эскиз медиҳад; онро бихонед ва тестро бо номи фаҳмо иваз кунед.

Видео бо забони англисӣ (субтитрҳоро фаъол кунед), тақрибан 6 дақиқа: насби Playwright ва оғози аввал. Тамошо кунед, то раванд намоён шавад; кор карданро дар лоиҳаи худ мекунед. Муқаддимаи кӯтоҳ «барои чӣ тестҳои e2e лозиманд» — Episode 1 аз ҳамон плейлист (тақрибан як дақиқа).

Чаро тест «флакает мекунад»

Мешавад, ки тест гоҳ сабз, гоҳ сурх мешавад бе тағйири код. Чунин тестро ноустувор (flaky) меноманд, ва он аз набудани тест бадтар аст: ба он бовар карданро бас мекунанд. Сабабҳои маъмул:

  • Таваққуфи сахт ба ҷои интизорӣ: waitForTimeout(2000). Имрӯз ду сония кифоя аст, пагоҳ сервер сусттар. Дуруст он аст, ки чизи мушаххасро интизор шавед: await expect(...).toBeVisible().
  • Маълумоти умумӣ: ду тест сабт бо як ном месозанд ё маълумоти ҳамдигарро нест мекунанд. Бо номҳои беназир (Date.now()) ва тестҳои новобаста табобат мешавад.
  • Ҷустуҷӯи нозук: «тугмаи сеюм дар саҳифа» (nth) ё занҷири дарози синфҳои CSS. Тугма илова шуд, ва тест тугмаи дигарро ёфт. Беҳтар аст getByRole бо ном.
  • Оғози суст-и сервери коркард: саҳифа ҳангоми дохили аввал ҷамъ мешавад. Бо зиёд кардани timeout ё иҷро дар версияи ҷамъшуда табобат мешавад.
  • Вобастагӣ аз тартиб: тести 2 танҳо вақте кор мекунад, ки то он тести 1 гузашта бошад.
Монандӣ аз ҳаёт

Тарозуи бозор. Агар онҳо барои як маҳсулот гоҳ 1 кг, гоҳ 1,2 кг нишон диҳанд, шумо ба онҳо бовар намекунед ва ба тир нигоҳ карданро бас мекунед. Тести ноустувор ҳамин гуна тарозуст: даста одат мекунад «аз нав оғоз мекунем, шояд сабз шавад» ва вайроншавии воқеиро аз даст медиҳад.

Хатогиҳои маъмули навомӯзон

1. Тест бе expect: он «мегузарад», зеро ҳеҷ чизро намесанҷад. 2. Парол ё калид бевосита дар тест ва дар репозиторий. 3. Тест бар зидди базаи ҷангӣ бо маълумоти воқеӣ: партов сохтед ё бегонаро нест кардед. 4. Тесте, ки матни тугмаро месанҷад, на натиҷаро («тугма ҳаст» ба ҷои «сабт пайдо шуд»). 5. Аз нав оғоз кардан, то сабз шавад, бе фаҳмидани сабаб.

ВАЗИФАИ 3.1

Мини-раннери тестҳо: функсияро ислоҳ кунед, то ҳамаи санҷишҳо гузаранд

миёна

Ин версияи бозичаи он чизест, ки Playwright мекунад: функсияи test санҷишро иҷро мекунад ва PASS ё FAIL-ро бо сабаб чоп мекунад. Функсияи applyDiscount(price, percent) бояд нархро бо тахфиф бо фоиз ҳисоб кунад ва то адади бутун доира кунад. Ҳоло он хато мекунад: тест нишон медиҳад, ки маҳз дар куҷо. Танҳо функсияро (сатрҳои аввал) ислоҳ кунед, ба тестҳои поён даст нарасонед.

function applyDiscount(price, percent) {
  // TODO: percent фоиз аст (10 маънои 10%), натиҷаро то адади бутун доира кунед
  return price - price * percent;
}

let passed = 0;
let total = 0;
function test(name, fn) {
  total++;
  try {
    fn();
    passed++;
    console.log("PASS " + name);
  } catch (e) {
    console.log("FAIL " + name + " -> " + e.message);
  }
}
function expectEqual(actual, expected) {
  if (actual !== expected) {
    throw new Error("expected " + expected + ", got " + actual);
  }
}

test("10% off 200", () => expectEqual(applyDiscount(200, 10), 180));
test("0% changes nothing", () => expectEqual(applyDiscount(200, 0), 200));
test("100% gives 0", () => expectEqual(applyDiscount(50, 100), 0));
test("rounds to whole somoni", () => expectEqual(applyDiscount(99, 15), 84));

console.log("passed: " + passed + " of " + total);
Натиҷаи интизоршаванда

PASS 0% changes nothing
PASS 100% gives 0
PASS rounds to whole somoni
passed: 4 of 4
Ишораи 1

Бо ҳамин ҳолат иҷро кунед ва сатрҳои FAIL-ро бихонед: дар онҳо навишта шудааст, ки чӣ интизор буд ва чӣ гирифта шуд. Фоизро бояд ба 100 тақсим кард.

Ишораи 2

Сатри дуруст: return Math.round(price - price * percent / 100);. Math.round то наздиктарин адади бутун доира мекунад.

ВАЗИФАИ 3.2

Ин тест чиро месанҷад

миёна

Тестеро бихонед, ки агент барои формаи фармоиш навиштааст.

import { test, expect } from '@playwright/test';

test('order form works', async ({ page }) => {
  await page.goto('/orders/new');
  await page.getByLabel('Title').fill('Test order');
  await page.getByRole('button', { name: 'Save' }).click();
  await page.waitForTimeout(2000);
});

Ин тест воқеан чиро месанҷад?

  1. Он, ки фармоиш сохта мешавад ва дар рӯйхат пайдо мегардад
  2. Он, ки пас аз пахши «Save» саҳифаи рӯйхати фармоишҳо кушода мешавад
  3. Қариб ҳеҷ чиз: ӯ танҳо боварӣ ҳосил мекунад, ки саҳифа кушода мешавад, майдон ёфт мешавад ва тугма пахш мешавад. Натиҷа санҷида нашудааст, бинобар ин ҳатто ҳангоми вайроншавии нигоҳдорӣ низ сабз аст
  4. Он, ки сервер дар давоми ду сония ҷавоб медиҳад

Дар тест пас аз пахш ягон expect нест. Таваққуфи 2 сония ҳеҷ чизро намесанҷад, танҳо вақтро сарф мекунад. Ислоҳ: таваққуфро хориҷ кунед ва await expect(page.getByText('Test order')).toBeVisible();-ро илова кунед.

Шумо аз агент мехоҳед: «Ба ин тест санҷиш илова кун». Кадом таъриф санҷиши хубро медиҳад?

  1. «Тест сабз шавад»
  2. «Пас аз пахши Save санҷ, ки дар саҳифа матни фармоиш намоён аст; таваққуф лозим нест, пайдошавии матнро интизор шав»
  3. «Ба эҳтимоли зарурат бештар санҷишҳо илова кун»
  4. «Санҷ, ки ҳама чиз кор мекунад»

Дархости хуб мегӯяд, ки маҳз чӣ бояд дар экран пайдо шавад, ва таваққуфҳоро манъ мекунад. «Сабз кун» агентро ба мувофиқ кардани тест ба натиҷа даъват мекунад, ва «ҳамаро санҷ» намегӯяд, ки чиро муваффақият ҳисоб кардан.

ВАЗИФАИ 3.3

Чаро тест ноустувор аст

душвор

Тест фармоишро бо номи 'Test order' месозад ва онро дар рӯйхат тавассути getByText('Test order') меҷӯяд. Аз оғози аввал сабз, дар дуюм ва сеюм сурх: Playwright менависад «strict mode violation: resolved to 3 elements». Сабаб дар чист?

  1. Ҳар иҷро сабтеро бо ҳамон ном мегузорад; дар рӯйхат аллакай якчанд якхела ҳаст, ва ҷустуҷӯ беш аз як унсурро меёбад. Барои ҳар иҷро номи беназир ('e2e-' + Date.now()) ва тоза кардани сабтҳои санҷишӣ лозим
  2. Иҷозатномаи Playwright тамом шудааст
  3. Браузери Chromium кӯҳна шудааст
  4. Агент калимаи test-ро нодуруст навиштааст

Ин хатои классикии маълумоти умумӣ аст: иҷрои аввал гузашт, ва иҷроҳои баъдӣ изҳои пештараро мебинанд. Бо номи беназир ва нест кардани сохташуда (дар охири тест ё бо қадами алоҳидаи тозакунӣ) табобат мешавад.

Тест «Save»-ро пахш мекунад ва фавран toBeVisible()-и матнро дар рӯйхат месанҷад. Дар компютери тез сабз, дар сусташ гоҳо сурх. Агент пешниҳод мекунад, ки пеш аз санҷиш waitForTimeout(3000) гузорад. Чӣ дурусттар аст?

  1. Таваққуфи 10 сония гузоштан: ҳар чӣ зиёдтар, ҳамон қадар боэътимодтар
  2. Тестро панҷ маротиба иҷро кардан ва ҳадди ақал як сабзро муваффақият ҳисоб кардан
  3. Тестро нест кардан: ӯ хеле серхархаша аст
  4. Таваққуф нагузоред, ба ҷои он аломати мушаххасро интизор шавед: санҷиши expect(...).toBeVisible() худаш пайдошавиро интизор мешавад, бинобар ин бояд санҷид, ки фиристодан воқеан анҷом ёфт (масалан, паёми муваффақиятро интизор шавед), ва ҳангоми сервери суст timeout-ро зиёд кунед

Таваққуфи собит ё хеле кӯтоҳ аст, ё вақтро беҳуда мегирад. Санҷишҳои Playwright то timeout такрор мешаванд, пас кифоя аст рӯйдоди мушаххасро интизор шавед. «Яке сабз аз панҷ» вайроншавиро пинҳон мекунад.

Бештар хонед: Next.js: Playwright, Playwright: насб, Playwright: локаторҳо, Playwright: webServer, Playwright: Codegen (бо забони англисӣ).

04 Логҳо ва хатогиҳо дар продакшн: Vercel Logs

Тестҳо вайроншавиро пеш аз релиз мегиранд. Аммо баъзан сайт дар Vercel дигар хел рафтор мекунад, на мисли дар компютери шумо: тағйирёбандаи муҳит нест, версияи дигари маълумот, воридоти ғайричашмдошт. Корбар «Something went wrong»-ро мебинад, ва шумо ҳеҷ чиз намебинед. Дар ин ҷо логҳо лозиманд: рӯзномаи сервер, ки дар он сервер менависад, чӣ рӯй дод. Ин дафтари рӯзмараи сервер аст: вақт, суроға, рамзи ҷавоб ва паёмҳое, ки шумо худатон тавассути console.log ва console.error баровардед.

Дар Vercel дар куҷо нигоҳ кардан

  1. Панели Vercel-ро кушоед, лоиҳаро интихоб кунед.
  2. Дар менюи канории лоиҳа Logs-ро кушоед. Инҷо Runtime Logs аст: рӯзномаи даъвати функсияҳои серверӣ (route.ts-ҳои шумо, амалҳои серверӣ, саҳифаҳо бо тасвир дар сервер) дар версияи ҷангӣ ва пешнамоишӣ.
  3. Дар тарафи чап филтрҳо: вақт, сатҳ (Error, Warning), роут (Route), роҳи дархост, рамзи ҷавоб (Status Code), муҳит (production ё preview). Ҷустуҷӯ аз рӯи матни паёмҳо ва реҷаи Live mode ҳаст: сабтҳо пеши чашм пайдо мешаванд.
  4. Ба сатр пахш кунед: дар тарафи рост тафсилот (усул, роҳ, рамз, минтақа, номи функсия) ва дар поён Log Messages кушода мешавад: console.log ва console.error-и шумо.

Рамзҳоро чӣ тавр хондан: 2xx муваффақият, 4xx хатои дархост (401 «ворид нашудаед», 403 «мумкин нест», 404 «чунин нест»; Vercel онҳоро ҳамчун огоҳӣ ҷудо мекунад), 5xx хатои сервер (ҳамчун хато ҷудо шудааст; ин қариб ҳамеша хато дар шумост). Сатри console.error(...) бо сатҳи error қайд шудааст, ва console.log(...) бо сатҳи info.

Дар тарифи ройгон логҳо кӯтоҳмуддат мемонанд

Мувофиқи ҳуҷҷатҳои Vercel, дар тарифи Hobby Runtime Logs 1 соат нигоҳ дошта мешаванд, дар Pro — 1 рӯз. Бинобар ин одат чунин аст: хато рӯй дод, логҳоро фавран кушоед, на «пагоҳ менигарам». Барои такрор кардани хато худатон дар сайти ҷангӣ ҳамон дархостро иҷро кунед ва фавран онро дар Logs ёбед.

Чиро дар логҳо навиштан, то баъд сабабро ёфтан

export async function POST(request: Request) {
  try {
    // ... санҷиши воридшавӣ, хондани маълумот, навишт дар Supabase
    return Response.json({ ok: true });
  } catch (error) {
    // нишонаи фаҳмо + паём; бе паролҳо, токенҳо ва объектҳои пурраи корбар
    console.error('orders.create failed:', error instanceof Error ? error.message : error);
    return Response.json({ error: 'Something went wrong' }, { status: 500 });
  }
}
  • Нишонаи ҷой дар аввал: orders.create failed дар ҷустуҷӯ осон ёфт мешавад.
  • Паёми хато, на танҳо «хато».
  • Асрор наменависед: парол, токен, калид, почтаи пурра ва маълумоти мизоҷон ба лог намеафтанд. Логҳоро ҳар касе мебинад, ки ба лоиҳа дастрасӣ дорад.
  • Хомӯш набошед: блоки холии catch {} хаторо аз худи шумо пинҳон мекунад.

Логҳо аз терминал ва якҷоя бо агент

Vercel барномаи консолӣ дорад (Vercel CLI). Дар папкаи лоиҳаи пайвастшуда фармони vercel logs сабтҳои охиринро нишон медиҳад (ба таври пешфарз барои 30 дақиқа), ва парчамҳо ҷустуҷӯро танг мекунанд. Мисол аз ҳуҷҷатҳои Vercel: vercel logs --environment production --query 'level:error' --since 1h. Баромадро ба агент нишон додан мумкин: «инҳо логҳо, сабабро дар код ёб». Аммо худи ёфтаро санҷед: агент тахмин мекунад, лог бошад далелро нишон медиҳад.

Хатогиҳои маъмули навомӯзон

1. Хатои сервериро дар консоли браузер ҷустан ва баръакс. 2. Логҳоро баъди як шабонарӯз дар Hobby кушодан: сабтҳо аллакай нестанд. 3. Паролро «барои ислоҳ» ба лог навиштан. 4. Бо «500 дар логҳо» маҳдуд шудан ва матни Log Messages-ро нахондан. 5. Код-ро тасодуфӣ ислоҳ кардан бе такрори дархост.

08 Хусусияти дарс: «Тугмаи сурх»

Ғоя: на код-ро, балки тестҳоро санҷидан. Агар омӯзгор лоиҳаро қасдан вайрон кунад, тестҳои шумо ҳатман бояд сурх шаванд. Агар сабз монданд, онҳо хеле кам чизро месанҷанд. Вақт: 20–30 дақиқа, ҷуфт-ҷуфт ё дастаҳои 3–4 нафар бозӣ мекунанд.

Баъди бозӣ шоха нест карда мешавад: git switch tests (ё main), баъд git branch -D red-button. Push-и маҷбурӣ истифода намешавад.

осон

Танҳо он чизеро қайд кунед, ки бе ишора карда метавонед.

  • Шарҳ дода метавонам, ки чаро «дар ман кор мекунад» далел нест, ва се вайроншавии маъмулро, ки бо даст намоён нестанд, меорам
  • Сенарияи асосиро бо ҷадвали «қадам, интизорӣ, воқеият» навишта метавонам ва дар он роҳи хушбахт, воридоти хато ва санҷиши дастрасиро ҷудо мекунам
  • Playwright-ро ба лоиҳаи Next.js насб карда, baseURL ва webServer-ро танзим карда ва тестҳоро иҷро карда метавонам
  • Тестро хонда ва гуфта метавонам, ки чиро месанҷад, ва тестеро, ки ҳеҷ чизро намесанҷад, дида метавонам
  • Сабабҳои тести ноустувор ва роҳҳои табобатро номбар карда метавонам
  • Натиҷаи сурхро хонда ва қарор дода метавонам, ки хато дар барнома аст ё тести кӯҳна
  • Дархостро дар Runtime Logs дар Vercel аз рӯи роут ва рамзи ҷавоб ёфта ва паёмҳоро хонда метавонам
