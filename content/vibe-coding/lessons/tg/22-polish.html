01 «Мисли тиҷоратӣ» чӣ маъно дорад ва чек-лист барои чӣ

Лоиҳа кор мекунад: воридшавӣ, сабт, рӯйхат. Аммо шахсе, ки онро бори аввал мебинад, чизи дигарро мебинад. Экрани сафед як сония ҳангоми боркунӣ. Рӯйхати холӣ бе як калима. Тугмаи «OK», ки маълум нест ба чӣ. Дар телефон саҳифа ба паҳлу мегурезад. Истинод ба Telegram бо суроғаи луч меояд. Ҳар хурдакакӣ алоҳида тоқатпазир аст, аммо якҷоя ҳисси «кори донишҷӯӣ» медиҳанд. Фарқи байни «кор мекунад» ва «истифодааш гуворо» — сайқалдиҳӣ аст.

Сайқалдиҳӣ функсияҳои нав талаб намекунад. Он рӯйхат ва интизом талаб мекунад: халабонҳо ҳавопайморо аз рӯи чек-лист месанҷанд на аз он ки фаромӯшкоранд, балки аз он ки банди сархӯрда гарон меистад. Шумо аз рӯи 30 банд дар се гурӯҳ мегузаред ва ҳар бандро танҳо пас аз санҷиш бо чашм ва даст қайд мекунед, на пас аз суханони агент.

Сайқал додан дар шаби охири пеш аз супориш.

Чӣ тавр бо чашми навомӯз ба экран нигарист

Дар зер макети таълимии экран бо панҷ мушкил. Пеш аз хондани тавзеҳ худатон онҳоро ёбед, баъд бо рақамҳо муқоиса кунед.

ВАЗИФАИ 1.1

Худро санҷед: бо ин экран чӣ хатост

осон

Ба макети боло нигаред.

Кадом мушкилоти макет ба дастрасӣ тааллуқ доранд? Ҳамаи дурустҳоро интихоб кунед.

  1. Майдонҳои воридкунӣ ном надоранд, танҳо ишора дар дохили майдон ҳаст
  2. Экран мавзӯи торик надорад
  3. Матни хокистарии равшан дар замина сафед: контраст аз меъёр паст аст
  4. Дар рӯйхат ягон заказ нест

Ишора дар дохили майдон (placeholder) ҳангоми воридкунӣ нест мешавад ва барномаи хондани экран онро бад мехонад, бинобар ин номи воқеии <label> лозим аст. Хокистарӣ дар сафед контрасти тақрибан 2:1 медиҳад, дар ҳоле ки меъёр 4.5:1 аст. Мавзӯи торик иловаи хуш аст, аммо талаби дастрасӣ нест. Рӯйхати холӣ масъалаи ҳолатҳост, на дастрасӣ.

Бо рӯйхати холии заказҳо чӣ кор кардан лозим?

  1. Ҳеҷ чиз: агар заказ нест, нишон додан лозим нест
  2. Матни кӯтоҳи «Ҳоло заказ нест» ва тугмаи амали «Аввалин заказро эҷод кунед» нишон диҳед
  3. Заказ-намунаи пинҳониро нишон диҳед, то рӯйхат холӣ набошад
  4. Ҷойро бо тасвири бе матн пур кунед

Ҳолати холӣ — имконияти ишора кардан ба қадами навбатӣ аст. Инсон бояд бифаҳмад, ки экран вайрон нест ва минбаъд чӣ кор кардан лозим. Закази сохта ба иштибоҳ меандозад, ва тасвири бе калима ҳеҷ чизро шарҳ намедиҳад.

Ба ҷои «Error: 500 Internal Server» кадом матн беҳтар аст?

  1. «Хато»
  2. «Чизе нодуруст шуд»
  3. «Server error 500: TypeError, ба администратор муроҷиат кунед»
  4. «Заказҳо бор нашуданд. Интернетро санҷед ва боз кӯшиш кунед» ва тугмаи «Такрор»

Хатои хуб мегӯяд, ки чӣ шуд, чӣ кор кардан лозим ва тугмаи амал медиҳад. «Хато» ва «Чизе нодуруст шуд» ҳеҷ чизро шарҳ намедиҳанд. Матни техникӣ метарсонад ва барои инсон бефоида аст; ҷойи он дар логҳост (дарси 20).

Бештар хонед: web.dev: курси дастрасӣ (бо забони англисӣ).

02 Боркунӣ, холӣ, хато ва матнҳои интерфейс

Ҳар экране, ки маълумот нишон медиҳад, як ҳолат надорад, балки ақаллан чор ҳолат дорад. Навомӯзон танҳо чоруминро месозанд («маълумот омад»), ва се ҳолати дигар экрани сафед мемонанд. Маҳз аз рӯи онҳо инсон мебарорад, ки маҳсулот «воқеӣ» аст ё не.

Дар Next.js чӣ тавр сохта мешавад

  • Боркунӣ. Файли loading.tsx дар паҳлуи саҳифа: Next.js худаш саҳифаро ба <Suspense> мепечонад ва ин компонентро то омода шудани маълумот нишон медиҳад. Барои блоки алоҳида атрофи он <Suspense fallback={...}> истифода баред.
  • Холӣ. Шарти оддӣ дар компонент: orders.length === 0 матн ва тугмаро нишон медиҳад.
  • Хато. Файли error.tsx (ҳатман компоненти клиентӣ, сатри аввал 'use client') хатоҳои нагирифташудаи сегментро мегирад. Дар ҳуҷҷатҳои Next.js 16 ӯ хосиятҳои error ва retry-ро мегирад; тугмаи «Такрор» retry()-ро даъват мекунад. Дар нусхаҳои пештараи Next.js 16 ба ҷои он reset ва unstable_retry буданд: бубинед, муҳаррир барои нусхаи шумо кадом хосиятҳоро пешниҳод мекунад.
  • 404. Файли not-found.tsx бо матни инсонӣ ва истинод ба саҳифаи асосӣ.
export default function Loading() {
  return (
    <div aria-busy="true" aria-live="polite">
      <p className="sr-only">Загружаем заказы…</p>
      <div className="skeleton h-12" />
      <div className="skeleton h-12" />
      <div className="skeleton h-12" />
    </div>
  );
}

Синфи skeleton (росткунҷаи хокистарӣ бо анимацияи нарм) ва sr-only (матн танҳо барои барномаҳои хондани экран; дар Tailwind аз қутти боз ҳаст) агент бо хоҳиши шумо месозад, агар онҳо ҳанӯз набошанд. Матни дохили кодро бетағйир мемонем: дар код сатрҳои русӣ шарҳ дода нашудаанд, шумо матни худро менависед.

Хатогиҳои маъмули навомӯзон

1. То боркунии маълумот экрани холиро нишон додан. 2. Ба корбар матни истисноро бо «undefined» баровардан. 3. Нишондиҳандаи беохири боркунӣ бе хато аз рӯи тайм-аут. 4. Ҳангоми дархост тугмаро фаъол мондан, ва заказ ду маротиба эҷод мешавад. 5. «Хато!» навиштан бе сабаб.

миёна

Шакли номнависӣ ба сартарошхона. Кадом навиштаи тугмаи асосӣ беҳтарин аст?

  1. OK
  2. Фиристед
  3. Ба сартарошхона номнавис шавед
  4. Инҷо пахш кунед

Навишти хуб амал ва объектро номбар мекунад: «Ба сартарошхона номнавис шавед». «OK» ва «Фиристед» намегӯянд, ки чӣ мешавад, ва «Инҷо пахш кунед» танҳо дар бораи худи пахш мегӯяд.

Инсон «Нигоҳ доштан»-ро пахш кард, сервер 3 сония ҷавоб медиҳад. Бо тугма чӣ кор кардан лозим?

  1. Ҳеҷ чиз: бигзор боз пахш кунад, агар боварӣ надошта бошад
  2. Барои вақти дархост манъ кунед ва «Нигоҳ медорем…» нишон диҳед, баъд натиҷаро нишон диҳед: «Заказ нигоҳ дошта шуд» ё сабаби радкуниро
  3. Тугмаро абадӣ пинҳон кунед
  4. Барои эҳтиёт тирезаи бо матни «Хато!» нишон диҳед

Бе манъкунӣ пахши такрорӣ закази дубора месозад. Бе паём инсон намедонад, ки муваффақ шуд ё не. Ин яке аз «хомӯш»-тарин мушкилоти маъмул дар лоиҳаҳои дорои коди AI аст.

Саҳифаи рӯйхат ҳангоми боркунии маълумот 2 сония экрани сафедро нишон медиҳад, баъд сатрҳо пайдо мешаванд. Кадом файли Next.js ҳолати фаврии боркуниро илова мекунад?

  1. loading.tsx дар паҳлуи page.tsx
  2. wait.tsx дар решаи лоиҳа
  3. error.tsx: он ҳамеша то охири боркунӣ нишон дода мешавад
  4. robots.txt

loading.tsx саҳифаро ба Suspense мепечонад ва компоненти шуморо то омода шудани он нишон медиҳад. error.tsx танҳо барои ҳолати хато лозим, ва robots.txt дар бораи роботҳои ҷустуҷӯӣ аст.

Бештар хонед: Next.js: loading.js, Next.js: error.js (бо забони англисӣ).

03 Таҷрибаи мобилӣ: ангушт, на муш

Аксарияти корбарони шумо сайтро аз телефон мекушоянд: ҷаласаро бо истинод аз Telegram қариб ҳамеша смартфон оғоз мекунад. Санҷиши мобилӣ — на «тирезаи браузерро ҷунбондан», балки чанд чизи мушаххас аст.

  • Ғелонидани уфуқӣ нест. Сабаб қариб ҳамеша унсури бо бари собит (width: 600px) ё сатри дарози бе интиқол аст. Табобат: max-width: 100%, flex-wrap, overflow-wrap: anywhere барои калимаҳои дароз. Санҷиш: бари 360 px, саҳифа ба паҳлу намеравад.
  • Ангушт аз курсор калонтар аст. Минтақаи пахши тугмаҳо ва истинодҳоро на хурдтар аз 44×44 px созед ва фосилаҳо гузоред. Нуқтаҳои ҳидоят: 44 px дар Apple, 48 px дар Material Design.
  • Андозаи матн аз 16 px. Матни хурд хонданаш душвор аст, ва дар браузери iPhone майдони воридкунӣ бо ҳарфи хурдтар аз 16 px ҳангоми фокус саҳифаро калон мекунад ва ороишро вайрон мекунад.
  • Навъи дурусти майдон. type="tel" клавиатураи рақамиро мекушояд, type="email" клавиатураро бо «@», inputmode="numeric" барои рамзҳо, ва autocomplete имкон медиҳад ном ва телефонро бо як ламс ҷойгир кунед.
  • Мета-теги viewport. Дастӣ илова кардани он дар Next.js лозим нест: тибқи ҳуҷҷатҳо <meta name="viewport" content="width=device-width, initial-scale=1"> ба таври пешфарз илова мешавад. Агар набошад, телефон «сайти компютерии хурдкардашуда»-ро нишон медиҳад.
  • Меню ва ҷадвалҳо. Менюи дароз ба тугма печида мешавад, ҷадвали васеъ дар дохили блоки худ ғелонидан мегирад, на ки тамоми саҳифаро ғелонад.

Чӣ тавр санҷид: аз DevTools то телефони воқеӣ

  1. Дар Chrome сайтро кушоед, F12-ро пахш кунед ва реҷаи дастгоҳро фаъол кунед (аломати телефон ва планшет дар тарафи чапи боло дар панели DevTools; инчунин Ctrl+Shift+M ё Cmd+Shift+M). iPhone SE ё андозаи 360×800-ро интихоб кунед.
  2. Тамоми сенарияи асосиро гузаронед. Диққат диҳед: оё навори уфуқӣ ҳаст, оё бо ангушт ба тугмаҳо мерасед, оё чизе шаклро намепӯшонад.
  3. DevTools телефони воқииро иваз намекунад: клавиатура, сатри суроға, имову ишораҳо дигар хел кор мекунанд. Суроғаи ҷангиро дар телефони худ кушоед.
  4. Самти амудӣ ва уфуқиро санҷед.

Хатогиҳои маъмули навомӯзон

Худро санҷед: нусхаи мобилӣ

Дар телефон саҳифа ба паҳлу ғелонида мешавад. Кадом сабаб эҳтимолтарин аст?

  1. Экрани телефон хеле хурд аст, коре кардан намешавад
  2. Ягон унсур аз экран васеътар аст, масалан блок бо width: 600px ё ҷадвали васеъ

Кадом майдон ба инсон барои воридкунии телефон клавиатураи рақамиро медиҳад?

  1. <input type="text">
  2. <input type="password">
  3. <input type="color">
  4. <input type="tel" autocomplete="tel">

04 Дастрасӣ: alt, контраст, номҳо, клавиатура

Дастрасӣ (accessibility, мухтасар a11y) — ин вақте аст, ки ҳама метавонанд аз сайт истифода баранд: одамони босири суст, онҳое ки саҳифаро бо барномаи хондани экран мешунаванд, онҳое ки бо мушак кор карда наметавонанд, ва оддӣ шахс зери офтоб бо экрани хира. Барои шумо ин ҳамчунин тезтарин иловаи Lighthouse аст: баҳои Accessibility қариб пурра аз санҷишҳо иборат аст, ки дар як соат ислоҳ мешаванд.

05 Lighthouse: суръат ва сифатро чен мекунем

Lighthouse — абзори ройгони Google, ки ба Chrome дарунсохта шудааст. Он саҳифаро мекушояд, ченак мекунад ва ҳисобот бо баҳоҳо аз 0 то 100 ва рӯйхати эродҳои мушаххас медиҳад. Ин дилхоҳӣ нест: рақамҳо ва ишораҳо барои ҳама якхелаанд, бинобар ин бо онҳо мусобиқа кардан ва кор супоридан осон аст.

Чӣ тавр оғоз кардан

  1. Chrome DevTools. Сайтро кушоед, F12-ро пахш кунед, ба варақаи Lighthouse гузаред, категорияҳоро фаъол монед ва Analyze page load-ро пахш кунед (тибқи ҳуҷҷатҳо ҳисобот 30–60 сония омода мешавад). Дастгоҳро «Mobile» интихоб кунед: баҳо барои телефон одатан сахттар аст, ва маҳз онро аввал назар мекунанд.
  2. PageSpeed Insights. pagespeed.web.dev-ро кушоед, суроғаро гузоред ва Analyze-ро пахш кунед. Танҳо барои саҳифаҳои оммавӣ, ки бе воридшавӣ кушода мешаванд, мувофиқ аст.
  3. Саҳифаҳои паси воридшавӣ дар DevTools санҷед, дар ҳоле ки аллакай дохил шудаед: тибқи ҳуҷҷатҳо васеъкунии Chrome бо саҳифаҳои маҳаллӣ ва пӯшида кор намекунад.

Performance аз чӣ иборат аст

Тибқи ҳуҷҷатҳои Lighthouse (барои нусхае, ки ҳоло дар он тасвир шудааст) баҳои суръат аз панҷ ченак ҷамъ мешавад: Total Blocking Time (саҳифа ҳангоми боркунӣ то чӣ андоза «овезон» мешавад, тақрибан 30 %), Largest Contentful Paint (калонтарин унсур кай пайдо шуд, тақрибан 25 %), Cumulative Layout Shift (оё ороиш ҳангоми боркунӣ ҷаҳида меравад, тақрибан 25 %), First Contentful Paint ва Speed Index (ҳар кадом 10 %). Вазнҳо аз нусха ба нусха иваз мешаванд, бинобар ин рақамҳоро ба ёд гирифтан лозим нест, аммо номҳоро донистан фоидаовар аст: маҳз онҳоро шумо дар ҳисобот мебинед.

Дар лоиҳаҳои Next.js чӣ чиз баҳоро бештар паст мекунад

  • Тасвирҳои калон. Компоненти next/image-ро истифода баред: ӯ худаш андозаи лозимӣ ва формати муосирро медиҳад. Ҳамеша alt, инчунин width ва height (ё fill)-ро нишон диҳед, то ороиш ҷаҳида наравад. Тасвири асосиро болои хати қатшавӣ фавран бор кунед: дар Next.js 16 хосияти priority кӯҳна шудааст, ҳуҷҷатҳо loading="eager" ё fetchPriority="high"-ро маслиҳат медиҳанд (ва preload камтар лозим мешавад).
  • Шрифтҳо. Ба воситаи next/font пайваст кунед: файлҳои шрифт дар сайти шумо ҷойгир мешаванд, дархости барзиёд ба серверҳои сеюм нест. Аз ду оилаи шрифт зиёд нагиред.
  • JavaScript-и зиёд. Директиваи 'use client'-ро танҳо дар ҷое гузоред, ки интерактивӣ лозим аст. Китобхонаҳои вазнинро барои як диаграмма танбалона бор кунед (next/dynamic).
  • Скриптҳои сеюм. Аналитика, виджетҳо, чатҳо: ҳар кадом саҳифаро суст мекунанд. Танҳо он чизеро пайваст кунед, ки лозим аст.
  • Ороиши ҷаҳанда. Тасвирҳо бе андоза, шрифтҳо бе эҳтиёт, блокҳое ки пас аз боркунии маълумот васеъ мешаванд (бинобар ин скелетон аз бахши 2 барои баҳои CLS фоиданок аст).

Мини-ҳисобот: баҳоҳо ва чек-листро ҳисоб кунед

миёна

Ин нусхаи бозичавии Lighthouse аст: се функсия баҳои миёна, ранги баҳо ва фоизи иҷрои чек-листро аз рӯи гурӯҳҳо ҳисоб мекунанд. Дар онҳо се хато ҳаст; бо ҳамин ҳолат иҷро кунед, натиҷаро бихонед ва танҳо функсияҳоро (сатрҳои аввал) ислоҳ кунед, блоки «САНҶИШ»-и поёнро нагардонед.

function average(list) {
  // ТАЗКИР: миёнаи арифметикӣ, то адади бутун мудаввар карда шавад; барои рӯйхати холӣ 0
  let sum = 0;
  for (const n of list) sum += n;
  return sum;
}

function color(score) {
  // ТАЗКИР: 90–100 green, 50–89 orange, 0–49 red
  if (score > 90) return "green";
  if (score > 50) return "orange";
  return "red";
}

const checklist = [
  { group: "UX", done: true }, { group: "UX", done: true }, { group: "UX", done: true }, { group: "UX", done: false },
  { group: "Mobile", done: true }, { group: "Mobile", done: false }, { group: "Mobile", done: false }, { group: "Mobile", done: false },
  { group: "Speed", done: true }, { group: "Speed", done: true }, { group: "Speed", done: true }, { group: "Speed", done: true },
];

function groupScore(items, group) {
  // ТАЗКИР: фоизи бандҳои иҷрошуда танҳо дар дохили гурӯҳ, то адади бутун мудаввар кунед
  const done = items.filter((i) => i.done).length;
  return Math.round((done / items.length) * 100);
}

Баҳо аз тасвирҳои вазнин, JavaScript-и барзиёд ва скриптҳои сеюм паст мешавад. Директиваи 'use client' дар ҳама ҷо ба браузер коди бештар мефиристад, ва виджетҳо дархостҳо илова мекунанд.

Метатегҳо: муҳаррики ҷустуҷӯ ва мессенҷер шуморо чӣ тавр мебинанд

Вақте истинод ба сайтро ба Telegram мегузоранд ё дар Google меҷӯянд, саҳифаи зебои шуморо нахонда, метамаълумот-ро дар <head> мехонанд: сарлавҳа (title), тавсиф (description) ва тасвир барои пешнамоиш (og:image). Дар Next.js App Router ҳамаи инҳо бе HTML-и дастӣ муқаррар мешаванд: бо содирот кардани объекти metadata аз layout.tsx ё page.tsx ё бо функсияи generateMetadata барои саҳифаҳое, ки маълумот аз суроға вобаста аст (масалан, саҳифаи заказ).

import type { Metadata } from 'next';

export const metadata: Metadata = {
  metadataBase: new URL('https://my-project.vercel.app'),
  title: { default: 'Бахор: заказ плова на дом', template: '%s · Бахор' },
  description: 'Заказывайте плов и лагман с доставкой по Душанбе за час.',

};

Суроғаро дар metadataBase ба суроғаи ҷангии худ иваз кунед. Он лозим аст, то истинодҳои нисбӣ ба тасвирҳо ба истинодҳои пурра табдил ёбанд.

Тасвир барои пешнамоиш

Роҳи аз ҳама соддатар: файли opengraph-image.png (ё .jpg)-ро ба папкаи app/ гузоред, ва Next.js худаш теғҳои лозимиро илова мекунад. Андоза: 1200×630. Барои саҳифаҳои бо маълумот тасвирро бо код сохтан мумкин: файли opengraph-image.tsx бо ImageResponse аз next/og (танҳо қисми CSS дастгирӣ мешавад: flexbox ҳаст, display: grid нест). Нишонаи сайт: файли favicon.ico дар папкаи app/. Файлҳои robots.txt ва sitemap.xml дар app/ низ аз рӯи созишномаи Next.js кор мекунанд.

Пешнамоишро чӣ тавр санҷид

Рамзи сарчашмаи саҳифаи ҷангиро кушоед (Ctrl+U) ва дар <head> теғҳои og:title, og:image-ро ёбед. Баъд истинодро ба худатон дар «Избранное»-и Telegram фиристед: корт бояд бо тасвир пайдо шавад. Агар мессенҷер корти кӯҳнаро нишон диҳад, ӯ нусхаи пештараро ба хотир гирифтааст: барои санҷиш ба суроға ?v=2 илова кунед.

Барои қисми пӯшидаи лоиҳа (кабинет паси воридшавӣ) тасвирҳо ва тавсифҳо лозим нестанд: нишон додани онро ба муҳаррикҳои ҷустуҷӯ лозим нест. Дар metadata-и ин саҳифаҳо robots: { index: false } кифоя аст.
