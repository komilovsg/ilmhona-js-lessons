01 Хостинг, домен ва URL чист

То ҳол саҳифаҳои шумо танҳо дар компютери шумо зиндагӣ мекарданд: файли index.html ё суроғаи localhost, ки ба ҷуз шумо барои касе кушода намешавад. Барои он ки дигарон саҳифаро бибинанд, онро бояд ба компютере гузошт, ки ҳамеша фаъол ва ба интернет пайваст аст. Чунин компютерҳоро сервер меноманд, хидматро «файлҳои худро дар сервери бегона ҷойгир кардан» бошад — хостинг.

Хостинг
Ҷой дар сервер, ки сайти шумо дар он нигоҳ дошта мешавад ва аз он ба ҳамаи хоҳишмандон дода мешавад. Монанди пештахтаи иҷорагирифта дар бозор: мол аз они шумо, ҷой ва посбонӣ аз они дигарон.
Домен
Номи хондашавандаи сайт, масалан vercel.app ё example.tj. Компютерҳо ҳамдигарро аз рӯи суроғаҳои рақамӣ (IP) меёбанд, ном бошад барои одамон лозим аст. «Китоби телефон»-и махсуси интернет (DNS) номро ба суроғаи сервер табдил медиҳад.
URL
Суроғаи пурраи саҳифаи мушаххас: протокол, домен ва роҳ. Домен — қисми URL аст, на муродифи он.

URL аз чӣ иборат аст

Видеои кӯтоҳ бо забони русӣ (2,5 дақиқа): ҳамин мафҳумҳо дар мисоли дигар. Видео кайҳо сабт шудааст, аммо ғоя кӯҳна нашудааст.

Монандӣ аз ҳаёт

Дӯкони худро дар бозори Душанбе тасаввур кунед. Хостинг — пештахтаи шумо: ҷое, ки мол мехобад ва харидорон меоянд. Домен — лавҳа ва номест, ки бо он шуморо меёбанд: «Табассум, қатори 5». URL — роҳи пурра «қатори 5, пештахтаи 12, рафи чап»: он на танҳо ба бозор, балки ба мақсади мушаххас мебарад. localhost бошад — молест, ки дар ошхонаи хонаи шумо паҳн шудааст: барои санҷиш қулай, вале харидорон онро намебинанд.

Хатогиҳои маъмули навомӯзон

1. Ба дӯст истиноди http://localhost:3000-ро фиристодан: он танҳо дар компютери шумо кор мекунад. 2. Фикр кардан, ки бе харидани домен сайт «нест». Суроғаи …vercel.app ба ҳамаи дунё дастрас аст. 3. «Хостинг» ва «домен»-ро омехта кардан: домен харидан ва хостинг надоштан мумкин аст ва баръакс. 4. Бо сайт маълумоти шахсиро нашр кардан: сайти дар интернет буда ба ҳама намоён аст.

02 create-next-app: лоиҳа аз як фармон

Next.js — фреймворки маъруф дар асоси React: маҷмааи қоидаҳо ва абзорҳои тайёр, ки аз онҳо сайтҳо ва барномаҳои муосир месозанд. Дар дарси 1 шумо як файли index.html сохта будед. Барои лоиҳаи воқеӣ даҳҳо файл лозим аст (саҳифаҳо, услубҳо, танзимот, китобхонаҳо), барои ҳамин на аз ҷузвдони холӣ, балки аз қолаби тайёр оғоз мекунанд. Онро фармони расмӣ месозад:

npx create-next-app@latest dental-landing

npx барномаи сохтани лоиҳаро аз интернет мегирад ва иҷро мекунад (барои ҳамин интернет лозим аст), create-next-app — худи барнома, @latest — «нусхаи нактарин», dental-landing — номи ҷузвдон бо лоиҳаи нав. Агар терминал пурсад, ки бастаи create-next-app-ро насб кардан мумкин аст ё не, ҷавоби y диҳед.

Устои насб чӣ мепурсад

Саволҳо аз нусха вобастаанд, барои ҳамин онҳоро аз ёд накунед. Тибқи ҳуҷҷатҳои Next.js ҳоло саволи якум — номи лоиҳа, дуюм — оё танзимоти тавсияшударо истифода баред. Ба шумо варианти якум («Yes, use recommended defaults») лозим аст: онро бо тирчаҳо интихоб кунед ва Enter пахш намоед.

Танзимоти тавсияшуда ҳама чизеро, ки курс лозим дорад, дар бар мегирад: TypeScript, ESLint (санҷиши услуби код), Tailwind CSS, App Router (низоми муосири саҳифаҳо), ҷузвдони лоиҳа бе src ва инчунин файли AGENTS.md бо маслиҳатҳо барои ёрдамчиёни AI. Пас аз ҷавоб барнома ҷузвдонро месозад ва китобхонаҳоро насб мекунад: ин аз як то якчанд дақиқа вақт мегирад.

Роҳи тез бе саволҳо

Ҳамон қолаб бо як фармон: npx create-next-app@latest dental-landing --yes. Парчами --yes саволҳоро гузаронида, танзимоти захирашуда ё стандартиро мегирад. Ин усулро он вақт интихоб кунед, ки танзимот аллакай шиносанд.

Дар ҷузвдони лоиҳа package.json ҷойгир аст: дар он китобхонаҳо ва «тугмаҳо» — фармонҳои кӯтоҳ барои кор номбар шудаанд. Се фармони асосӣ:

Файлҳои .tsx — инҳо чианд?

Саҳифа дар page.tsx ҷойгир аст. Васеъшавии .tsx маънои TypeScript + JSX-ро дорад: ин забони React (қисмҳое, ки аз онҳо интерфейс сохта мешавад) бо санҷиши навъҳо мебошад. React, JSX ва компонентҳоро дар дарси 7 муфассал месанҷед, TypeScript баъдтар вомехӯрад. Ҳоло ду қоида кифоя аст: 1) кодро дар чунин файлҳо AI менависад, шумо онро иҷро мекунед ва бо чашм месанҷед; 2) агар дар терминал ё логи ҷамъоварӣ «хатои навъҳо» (type error) пайдо шавад, онро пурра нусха карда ба AI фиристед — мо ҳамин тавр ҳал мекунем.

Монандӣ аз ҳаёт

Лоиҳаро бо create-next-app сохтан — монанди иҷораи кофеи тайёр ба ҷои сохтмон: девор, ошхона, симкашӣ ва лавҳа аллакай ҳаст. Шумо танҳо менюи худро (page.tsx) меоред ва деворҳоро ранг мекунед (Tailwind). Бунёдро аз нав сохтан лозим нест.

Хатогиҳои маъмули навомӯзон

1. Лоиҳаро дар дохили репозиторийи дигари Git (масалан, дар ҷузвдони дарси гузашта) сохтан: он гоҳ репозиторийи Git-и қолаб сохта намешавад ва баъдтар ошуфтагӣ пайдо мешавад. Лоиҳаро дар ҷузвдони одӣ, масалан дар мизи кор созед. 2. Терминалро пӯшидан ва тааҷҷуб кардан, ки localhost:3000 кушода намешавад: сервери dev қатъ шудааст. 3. Дар Cursor ҷузвдони аз лоиҳа болотарро кушодан: маҳз dental-landing-ро кушоед. 4. Ба node_modules даромада, чизеро ислоҳ кардан.

03 Tailwind CSS: услубҳо бевосита дар нишонагузорӣ

Дар дарси 3 шумо CSS-ро мехондед: қоидаҳо дар файли алоҳида, ки селектор ва маҷмуи хосиятҳо дорад. Tailwind CSS дигар хел сохта шудааст: синфҳои кӯтоҳи тайёр — «хиштҳо»-ро бевосита дар унсур менависед. Як синф барои як хурдакорӣ ҷавобгар аст: px-8 — фосила аз паҳлӯҳо, bg-sky-600 — заминаи кабуд, font-semibold — ҳарфи нимғафс.

Чаро AI Tailwind-ро дӯст медорад

  • Ҳама чиз дар як ҷо. Барои тағйири тугма AI як сатрро ислоҳ мекунад ва қоидаро дар файли дигар намеҷӯяд, унсурҳои ҳамсояро вайрон намекунад.
  • Луғати пешгӯишаванда. Синфҳо стандартианд ва аз рӯи онҳо дар дастрасии кушод кодҳои бисёр навишта шудаанд: модел онҳоро аз ёд медонад.
  • Хатогиҳои камтар. Задухӯрди номҳо ва «каскад»-и дарси гузашта нест, ки дар он як қоида ногаҳон дигареро бекор мекунад.
  • Мутобиқшавӣ бо як усул. Пешванди sm: ё md: маънои «аз чунин васеъии экран сар карда»-ро дорад: grid sm:grid-cols-3 — дар телефон як сутун ва дар экрани калонтар се сутун.

Лоиҳаи нав аллакай танзим шудааст: Tailwind дар файли app/globals.css бо як сатри @import "tailwindcss"; пайваст аст. Чизеро насб ва танзим кардан лозим нест, танҳо синфҳоро нависед.

Видео бо забони русӣ (2 дақиқа): ғояи Tailwind дар шакли хеле фишурда. Tailwind-ро аз рӯи видео пайваст кардан лозим нест: дар лоиҳаи шумо он аллакай пайваст аст.

Монандӣ аз ҳаёт

CSS-и одӣ — монанди фармоиши костюми инфиродӣ: ба дӯзанда ҳар андозаро бо мактуби алоҳида шарҳ медиҳанд. Tailwind — монанди конструктор аз қисмҳои тайёр дар бозори матоъ: «остин кӯтоҳ, гиребон рост, ранг кабуд». Қисмҳо кам, номҳо барои ҳама якхела ва ҳар ёрдамчӣ фавран мефаҳмад, ки шумо чӣ мехоҳед.

Хатогиҳои маъмули навомӯзон

1. Аз сатри дарози синфҳо тарсидан: онро аз чап ба рост калима ба калима, мисли ҷумла хонед. 2. Ба синфҳо калимаҳои ихтироъшуда ба монанди big-blue-button навиштан: чунин синф нест ва услуб татбиқ намешавад. Аз AI хоҳиш кунед, ки танҳо синфҳои стандартии Tailwind-ро истифода барад. 3. Видеоҳои нусхаҳои кӯҳнаи Tailwind-ро пайравӣ карда, онро аз нав «пайваст кардан»: дар лоиҳаи шумо ҳама чиз тайёр аст. 4. Ҳарду усулро бетартиб омехта кардан: бо AI шарт кунед, ки услубҳо танҳо бо Tailwind бошанд.

Синфҳои Tailwind аз луғати стандартӣ ҷамъ мешаванд: bg-… — замина, px-… — фосилаҳои уфуқӣ, py-… — амудӣ. Вариантҳои дигар — калимаҳои ихтироъшуда ё CSS-и одӣ мебошанд.

Бештар хонед: Tailwind: услубгузорӣ бо синфҳои utility ва тарҳи мутобиқшаванда (бо забони англисӣ).

04 Деплой: аз GitHub ба Vercel

Деплой (deploy) — гузоштани лоиҳа дар сервер, то ҳама онро бубинанд. Vercel — хостинге, ки дастаи Next.js сохтааст; барои лоиҳаҳои таълимӣ тарифи ройгони Hobby кифоя аст (он барои лоиҳаҳои шахсӣ ва ғайритиҷоратӣ пешбинӣ шудааст; шартҳоро дар сайти хидмат бинед). Нақша оддӣ: код дар GitHub меистад, Vercel репозиторийро мушоҳида мекунад ва бо ҳар тағйирот сайтро худаш ҷамъ карда нашр мекунад.

Репозиторийро чӣ тавр пайваст кардан (тибқи ҳуҷҷатҳои Vercel)

  1. Дар vercel.com/signup сабти ном кунед бо тугмаи воридшавӣ тавассути GitHub: ин тавр аккаунтҳо фавран пайваст мешаванд. Варианти ройгони шахсиро (Hobby) интихоб кунед.
  2. «Add New…» → «Project»-ро пахш кунед (ё тугмаи лоиҳаи навро дар панели асосӣ). Рӯйхати репозиторийҳои GitHub-и шумо пайдо мешавад. Агар репозиторий дар рӯйхат набошад, дар танзимоти GitHub ба Vercel дастрасиро ба он иҷозат диҳед (тугмаи танзими дастрасӣ дар ҳамин экран).
  3. Дар назди репозиторий «Import»-ро пахш кунед. Саҳифаи танзим кушода мешавад: Vercel худаш фреймворкро муайян мекунад (Framework Preset: Next.js), ҷузвдони решаро ./ гузоред. Тағйирёбандаҳои муҳит ва танзимоти ҷамъоваришро нагиред: онҳо баъдтар лозим мешаванд.
  4. «Deploy»-ро пахш кунед. Ҷамъоварӣ мегузарад, пас аз он табрик ва тасвири хурди сайт пайдо мешавад. Тугмаи «Visit» сайти шуморо мекушояд, суроғаи намуди ном.vercel.app-ро ба ҳар кас фиристодан мумкин аст.
  5. Минбаъд — танҳо git push. Ҳар push ба шохаи асосӣ (main) сайтро навсозӣ мекунад, push ба шохаҳои дигар суроғаи озмоишии алоҳида (preview) месозад. Нашри дастӣ дигар лозим нест.

Видео бо забони англисӣ, зернависро фаъол кунед: ҳамин қадамҳо дар мисоли зинда (4,5 дақиқа). Агар интерфейс аз нақшаи боло фарқ кунад, ба номи тугмаҳои «Import» ва «Deploy» такя кунед.

Агар деплой афтад, логи ҷамъоварӣ чӣ тавр хонда мешавад

Мешавад, ки дар компютери шумо ҳама чиз кор мекунад, дар Vercel бошад назди лоиҳа ҳолати сурхи Error аст. Ин муқаррарӣ аст: сервер лоиҳаро аз сервери dev сахттар ҷамъ мекунад. Сабаб ҳамеша дар логи ҷамъоварӣ (build log) — сабти муфассали он ки сервер қадам ба қадам чӣ кор кардааст, навишта мешавад.

  1. Лоиҳаро дар Vercel кушоед → варақаи «Deployments» ва деплойро бо ҳолати сурх пахш кунед.
  2. Дар блоки «Deployment Details» «Building»-ро кушоед — логи ҷамъоварӣ дар ҳамон ҷост.
  3. То сатрҳои сурх бо калимаи «Error» поён равед. Аз сатри охирини монанди «Command "npm run build" exited with 1» натарсед: он танҳо мегӯяд «ҷамъоварӣ нашуд». Сабаби асосӣ одатан якчанд сатр болотар аст: номи файл, рақами сатр ва матни хато.
  4. Ин порчаро пурра нусха кунед (бо номи файл) ва ба AI дар Cursor фиристед: «Деплой дар Vercel афтод, хато аз лог ин аст. Сабабро шарҳ деҳ ва ислоҳ кун, боқиро тағйир надеҳ».
  5. Ислоҳро дар худатон санҷед: дар терминал npm run build-ро иҷро кунед. Агар дар компютери шумо ҷамъоварӣ мегузарад, commit ва push кунед — Vercel аз нав ҷамъ мекунад.

  • Фармонҳо: npm run dev — коркард дар localhost:3000, npm run build — санҷиши ҷамъоварии ҷангӣ, Ctrl+C — қатъ кардан.
  • .tsx — TypeScript + JSX (React): муфассал дар дарси 7; хатогиҳои навъҳоро пурра нусха карда ба AI мефиристем.
  • Tailwind: синфҳои тайёр бевосита дар унсур (px-8 bg-sky-600 rounded-full); sm: ва hover: — мутобиқшавӣ ва ҳолатҳо. AI луғати онро медонад ва як сатрро бе таъсири иловагӣ ислоҳ мекунад.
  • Деплой: код дар GitHub → воридкунии репозиторий ба Vercel → Deploy → истиноди ….vercel.app; минбаъд ҳар git push сайтро худаш навсозӣ мекунад.
  • Агар деплой афтад: лоиҳа дар Vercel → Deployments → деплой → Building → сатрҳои сурхи «Error» → блокро пурра нусха кардан → ба AI фиристодан → npm run build-ро санҷидан → commit ва push.
  • Бехатарӣ: розҳо ва калидҳоро ба код ва репозиторий намегузорем, маълумоти шахсиро нашр намекунем; нигоҳдории дурусти калидҳо — дар дарси 10.
