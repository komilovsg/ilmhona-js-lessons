То охири дарс дар компютери шумо муҳити корӣ комилан омода хоҳад буд: муҳаррири Cursor, терминал, Node.js, Git ва аккаунти GitHub. Шумо саҳифаи худро аз терминал бо суроғаи localhost оғоз мекунед, аввалин коммитро иҷро мекунед ва онро ба GitHub мефиристед: корҳои 1–3-и шумо дар репозиторийи ҳақиқӣ ҷойгир мешаванд ва истинод ба он супориши хонагии шумо мегардад.

  • Шарҳ додан, ки ҳар як абзор барои чӣ лозим аст: муҳаррири код, терминал, Node.js, npm, Git, GitHub
  • Байни Cursor ва VS Code интихоб карда тавонистан ва вариантҳои эҳтиётиро донистан, агар лимитҳои тарифи ройгон тамом шаванд
  • Иҷрои 10 фармони асосии терминал ва натарсидан аз равзанаи сиёҳ
  • Оғоз кардани лоиҳа дар localhost ва шарҳ додани он, ки порт чист
  • Танзими Git (user.name, user.email), коммит бо тугмаи Source Control ва фиристодани он ба GitHub
  • Таҳлили хатогиҳои маъмули насбкунӣ дар Windows ва macOS
Ин дарсро чӣ тавр гузаштан лозим

Лозим аст: компютер (Windows ё Mac) бо ҳуқуқи насб кардани барномаҳо, интернет ва тақрибан 2,5 соат. Бахши 1-ро дар хона то дарс иҷро кунед: насби Node.js ва Git 20–30 дақиқа вақт мегирад ва дар дарс ин вақт барои амалиёт лозим аст. Дарсро дар як тарафи экран кушоед, Cursor ва терминалро — дар тарафи дигар.

Ин «техникитарин» дарси курс аст: баъзе калимаҳо ношинос хоҳанд буд ва ин муқаррарӣ аст. Муҳимаш — қадамҳоро такрор кардан ва натиҷаро бо расмҳо муқоиса кардан. Агар чизе наояд, худро айбдор накунед: матни хатогиро нусха карда, ба AI ё муаллим нишон диҳед (бахши 7).

01 То дарс: насби Node.js ва Git дар хона

Шумо бояд ду барномаро насб кунед: Node.js (бо он npm низ меояд) ва Git. Барои чӣ лозиманд — аз назария мефаҳмед; ҳоло муҳим аст, ки онҳоро насб карда, санҷед. Барномаҳоро танҳо аз сайтҳои расмии ин рӯйхат зеркашӣ кунед: версияҳои «шикастаи» барнома ва насбкунандаҳо аз сайтҳои бегона метавонанд вирус дошта бошанд.

Фармонҳои санҷишро куҷо ворид кардан лозим

Windows: тугмаи «Пуск»-ро пахш кунед, PowerShell нависед ва «Windows PowerShell»-ро кушоед (ва «Терминал» низ мувофиқ аст). macOS: Cmd+Фосила-ро пахш кунед, Terminal нависед ва Enter-ро пахш кунед. Равзана бо курсори милтиқзананда мекушояд: ин терминал аст, муфассалтар — дар бахши 4.

Windows

  1. Node.js. nodejs.org/en/download-ро кушоед, версияи LTS-ро (Long Term Support, «дастгирии дарозмуддат» — устувортарин) интихоб кунед ва насбкунандаро барои Windows зеркашӣ намоед. Онро иҷро карда, «Next»-ро пахш кунед ва танзимоти пешфарзро нигоҳ доред. Агар насбкунанда пешниҳод кунад, ки «necessary tools» (абзорҳои иловагӣ) насб шаванд — аломат гузоштан лозим нест, барои курс насби оддӣ кифоя аст.
  2. Git. git-scm.com/install/windows-ро кушоед, насбкунандаи Git-…-64-bit.exe-ро (барои компютерҳои бо протсессори ARM — версияи arm64) зеркашӣ карда, иҷро кунед. Дар ҳамаи равзанаҳои устод «Next»-ро пахш кунед: танзимоти пешфарз барои курс мувофиқанд. Алтернатива барои онҳое, ки терминалро дӯст медоранд: winget install --id Git.Git -e --source winget.
  3. PowerShell-ро аз нав оғоз кунед: равзанаро пӯшед ва нав кушоед. Ин муҳим аст: равзанаи кӯҳна дар бораи барномаҳои навмонтажшуда хабар надорад.
  4. Версияҳоро санҷед бо се фармони блоки поён. Агар ҳар кадом рақами версияро чоп кард — ҳама чиз омода аст.

macOS

  1. Node.js. nodejs.org/en/download-ро кушоед, версияи LTS-ро интихоб кунед, насбкунандаро барои macOS (файли .pkg) зеркашӣ карда, кушоед ва ҳамаи қадамҳоро бо танзимоти пешфарз гузаред.
  2. Git. Дар терминал git --version-ро ворид кунед. Агар Git аллакай бошад, рақами версия пайдо мешавад. Агар набошад, macOS равзанаеро нишон медиҳад бо пешниҳоди насби «command line developer tools» (абзорҳои сатри фармон): «Насб кардан» («Install»)-ро пахш карда, интизор шавед — ин метавонад 5–15 дақиқа вақт гирад. Бо онҳо Git низ меояд. Агар шумо Homebrew истифода баред, метавонед brew install git-ро иҷро кунед.
  3. Терминалро пӯшида, аз нав кушоед, то он барномаҳои навро бинад.
  4. Версияҳоро санҷед бо се фармони блоки поён.

1. Омехта кардани Git ва GitHub: Git — барнома дар компютери шумо, GitHub — сайт, ки нусха ба он фиристода мешавад. Git бе GitHub низ кор мекунад. 2. Омехта кардани Node.js бо JavaScript дар браузер: Node.js — барномаи алоҳида, браузер ба он ниёз надорад. 3. Омехта кардани VS Code бо Visual Studio — инҳо барномаҳои гуногунанд. 4. Гумон кардан, ки терминал компютерро «вайрон мекунад»: фармонҳои безарари дарс чизеро нест намекунанд.

05 Node.js, npm, localhost ва порт

Node.js — барномаест, ки JavaScript-ро бевосита дар компютер иҷро мекунад. То ҳол саҳифаҳои шумо бо дучанд зер кардан мекушоданд ва дар сатри суроға роҳи намуди file:///… буд. Лоиҳаҳои касбӣ дигар хел кушода мешаванд: барномаи махсус («сервер») дар компютери шумо оғоз мешавад ва саҳифаро ба браузер бо суроғаи localhost «тақсим мекунад». Ин тавр саҳифа ба сайти воқеӣ дар интернет наздиктар кор мекунад ва Next.js ва дигар лоиҳаҳои курс низ ҳамин тавр оғоз мешаванд.

localhost чӣ маъно дорад

localhost — «худи ҳамин компютер». Суроғаи http://localhost:3000 маънои онро дорад: «ба ҳамин компютер, ба дарвозаи рақами 3000 дароед». Саҳифаро бо чунин суроға танҳо шумо мебинед: одамони дигар онро кушода наметавонанд, то даме ки сайтро нашр накунед (дарси 5).

Монандӣ аз ҳаёт

Бинои бисёрошёна дар Душанбе. Суроғаи бино — ин localhost: «ин хона, шумо дар дохил ҳастед». Рақами порт — рақами даромадгоҳ ё хонаи истиқоматӣ: дар як бино оилаҳои зиёд зиндагӣ мекунанд ва ҳар кадом ба занги худ ҷавоб медиҳад. Дар порти 3000 саҳифаи шумо метавонад зиндагӣ кунад, дар порти 3001 — лоиҳаи дигар. Агар даромадгоҳ банд бошад, ба даромадгоҳи дигар занг задан лозим аст.

Порт ва паёми маъмули «порт банд аст»

Порт — адад аз 0 то 65535, «рақами дарвоза» барои барномаҳо дар компютер. Як портро танҳо як барнома гирифта метавонад. Агар шумо ду лоиҳаро дар порти 3000 оғоз кунед, дуюм хабар медиҳад: address already in use («суроға аллакай истифода мешавад»). Ҳал — лоиҳаи аввалро қатъ кунед (Ctrl+C) ё дуюмро дар порти дигар оғоз намоед.

06 Git ҳамчун тугмаи «захира кардан»: commit ва push

Шумо албатта файлро баъди ислоҳи ноком гум карда будед ё ҳуҷҷатҳоро ниҳоӣ, ниҳоӣ2, ниҳоӣ-ҳатман-охирин меномидед. Git ин мушкилро ҳал мекунад: он ҳолати тамоми ҷузвдони лоиҳаро дар лаҳзаҳои зарурӣ ба хотир мегирад ва ба ҳар кадоме аз ин «акс»-ҳо баргаштан мумкин аст. Барои кор бо AI ин махсусан муҳим аст: агар ислоҳи навбатӣ саҳифаро вайрон кунад, шумо ба охирин акси корбарор бармегардед, на ки ҷустуҷӯ кунед, ки маҳз чӣ тағйир ёфтааст.

Репозиторий (repo)
Ҷузвдони лоиҳа, ки Git аз паи он назорат мекунад. Дар дохили он ҷузвдони пинҳонии .git бо таърих пайдо мешавад. Онро нест кардан ва бо даст ислоҳ кардан мумкин нест.
Commit
Як «акс»-и лоиҳа бо имзои кӯтоҳ: шумо чӣ кор кардед. Мисли захира кардан дар бозӣ: баргаштан мумкин аст.
Push
Коммитҳои худро ба GitHub фиристодан. То push накунед, нусха дар интернет вуҷуд надорад.
Шоха (branch)
Хати таърих. Ҳоло як шоха кифоя аст, номаш main аст.
Монандӣ аз ҳаёт

Савдогар дар бозор ҳар рӯз ба дафтар менависад: «12 октябр — 20 кг мавиз фурӯхта шуд, 840 сомонӣ гирифта шуд». Ҳар сабт — ин commit: кӯтоҳ ва бо сана. Агар сабт гум шавад ё дар рақамҳо хато шавад, ёфтан мумкин аст, ки ин кай рӯй дод. Push — вақте ки савдогар як бор дар як рӯз саҳифаҳоро аксбардорӣ карда, ба бародараш мефиристад. Агар дӯкон бисӯзад, дафтар назди бародар мемонад. GitHub — «бародар» аст, ки нусхаи дафтари шумо назди ӯ нигоҳ дошта мешавад.

Танзими Git: ном ва почта (як бор)

Дар ҳар коммит Git муаллифро имзо мекунад. То ки ӯ донад, ки шумо кистед, як бор ду фармонро ворид кунед (номи худро бо ҳарфҳои лотинӣ ва почтаро ҷойгузин кунед):

git config --global user.name "Madina Rakhimova"
git config --global user.email "madina@example.com"

Санҷиш: git config --global user.name номи захирашударо чоп мекунад. Агар танзим накунед, дар коммити аввал Git бо Author identity unknown ҷавоб медиҳад ва хоҳиш мекунад, ки худро муаррифӣ кунед. Почтаро беҳтар аст ҳамонеро нишон диҳед, ки GitHub-ро бо он сабти ном мекунед: ин тавр коммитҳо ба профили шумо вобаста мешаванд. Агар намехоҳед почтаи воқеиро нишон диҳед, дар танзимоти GitHub («Settings → Emails») метавонед онро пинҳон карда, суроғаи махсуси намуди …@users.noreply.github.com-ро гиред: онро дар user.email нишон диҳед.

Воридшавӣ ба GitHub аз муҳаррир: парол мувофиқ нест

GitHub муддати дароз аст, ки пароли оддии аккаунтро барои кор бо Git қабул намекунад: дар ҳуҷҷатҳо мустақиман навишта шудааст, ки «password-based authentication for Git has been removed». Аммо чизеро ворид кардан лозим нест. Вақте ки шумо бори аввал лоиҳаро аз Cursor ё VS Code ба GitHub мефиристед, муҳаррир худаш воридшавиро пешниҳод мекунад: браузер бо саҳифаи GitHub мекушояд, шумо «Authorize» («Иҷозат додан»)-ро пахш мекунед ва браузер шуморо ба муҳаррир бармегардонад. Агар бозгашт рӯй надод, дар сатри ҳолат дар поён банди «Signing in to github.com…» ҳаст: онро пахш кунед ва рамзро аз браузер ворид намоед.

Чиро ба GitHub фиристодан лозим нест

Репозиторийро ҷамъиятӣ (ҳама мебинанд) ё пӯшида кардан мумкин аст. Барои вазифаҳои хонагӣ он бояд ҷамъиятӣ бошад, барои ҳамин ҳеҷ гоҳ дар он паролҳо, калидҳои API, файлҳои .env ва ҳуҷҷатҳои бо маълумоти шахсӣ нагузоред. Қоидаро дар ёд доред: сирҳоро дар файли .env нигоҳ медоранд, ки ба Git намеафтад (дарси Supabase нишон медиҳад, ки чӣ тавр). Агар сир тасодуфан ба репозиторий афтад, онро фош шуда ҳисоб кунед ва бо нав иваз намоед.

Видео бо забони русӣ (14 дақиқа): Git чӣ тавр сохта шудааст, коммитҳо ва фиристодан ба GitHub. Агар вақт набошад, 7 дақиқаи аввал кифоя аст. Дар видео асосан ба фармонҳо таваҷҷӯҳ шудааст; дар дарс шумо ҳамин корро бо тугмаҳои Source Control мекунед.

Хатогиҳои маъмули навомӯзон

1. Дар охири ҳафта як коммити азим сохтан: қоидаи курс «ҳар қадам = коммит». 2. Паёмҳои намуди «asdf» ё «ислоҳҳо» навиштан: баъди як ҳафта шумо нахоҳед фаҳмид, ки ин чӣ буд. Кӯтоҳ ва ба мавзӯъ нависед (add my-site, fix header color). 3. Push-ро фаромӯш кардан: коммит дар компютер ҳаст, дар GitHub холӣ аст. 4. Пароли GitHub-ро дар терминал ворид кардан — он мувофиқ нест. 5. Репозиторийро дар дохили репозиторийи дигар ё дар дохили ҷузвдоне сохтан, ки бо абр ҳамоҳанг мешавад (OneDrive, iCloud): лоиҳаҳоро дар ҷузвдони оддии диск нигоҳ доред.

Шумо commit кардед, аммо дар GitHub чизе пайдо нашуд. Чаро?

  1. GitHub дар кишвари шумо баста шудааст
  2. Commit аксро танҳо дар компютери шумо захира мекунад; барои он ки ба GitHub равад, push лозим аст (Publish Branch / Sync Changes)
  3. Як шабонарӯз интизор шудан лозим аст
  4. Ҷузвдони .git-ро нест кардан лозим аст

Commit — захираи маҳаллӣ. Нусха дар интернет танҳо баъди push пайдо мешавад.

Чӣ кор кардан лозим, то Git бо Author identity unknown шикоят накунад?

  1. Як бор git config --global user.name "…" ва git config --global user.email "…"-ро иҷро кардан
  2. Муҳаррирро аз нав насб кардан
  3. Пароли GitHub-ро дар терминал ворид кардан
  4. Аккаунти нави GitHub сохтан

Git бояд донад, ки муаллифи коммитҳо кист. Танзим як бор барои компютер анҷом дода мешавад.

Вақте ки муҳаррир ҳангоми push-и аввал воридшавиро талаб мекунад, чӣ тавр дуруст ворид шудан лозим?

  1. Пароли аккаунти GitHub-ро дар терминал ворид кардан
  2. Паролро ба муаллим фиристодан
  3. Воридшавиро тавассути браузер, ки муҳаррир мекушояд, гузашта, «Authorize»-ро пахш кардан
  4. Репозиторийро бе воридшавӣ сохтан: ин тавр низ мешавад

Барои Git дар GitHub пароли аккаунт мувофиқ нест. Муҳаррир браузерро мекушояд, шумо дастрасиро иҷозат медиҳед ва воридшавӣ бе ворид кардани парол дар терминал анҷом меёбад.

Чиро ба репозиторийи ҷамъиятӣ гузоштан мумкин нест? (ҳамаи вариантҳои дурустро интихоб кунед)

  1. Файли .env бо калидҳои API
  2. Саҳифаи index.html бо визиткаи таълимӣ
  3. Файли README.md бо тавсифи лоиҳа
  4. Ҳуҷҷат бо маълумоти шиноснома

Сирҳо ва ҳуҷҷатҳои шахсиро нашр намекунанд. Саҳифаҳои таълимӣ ва README, баръакс, репозиторийро фаҳмо мекунанд.

Барои мутолиаи муфассалтар: GitHub Docs: Hello World, VS Code: Source Control, GitHub: сохтани аккаунт.

ВАЗИФАИ 8.1

Рӯйхати санҷиш: муҳаррир ва аккаунтҳо

осон
  • Ҷузвдони vibe-course сохта шудааст, корҳои дарсҳои 1–3 ба он нусха шудаанд
  • Cursor насб шудааст, оғоз мешавад, ба аккаунт ворид шудаам (ё варианти эҳтиётӣ насб шудааст: VS Code)
  • Аккаунти GitHub сохта шудааст, почта тасдиқ шудааст, номи корбар дар ёд дошта ё навишта шудааст
  • Ҳимояи дуомилаии GitHub фаъол шудааст (тавсия дода мешавад)

Қадами 2. Ҷузвдон ва терминалро кушоед

  1. Дар Cursor «File → Open Folder…»-ро интихоб карда, ҷузвдони vibe-course-ро нишон диҳед. Ба саволи «Trust the authors?» («Ба муаллифон боварӣ доред?») бо «Yes, I trust the authors» ҷавоб диҳед: ин ҷузвдони шумост.
  2. Терминалро кушоед: «Terminal → New Terminal» ё Ctrl+` (дар macOS — Control+`). Дар поён панели терминал пайдо мешавад ва он аллакай дар ҷузвдони лоиҳа меистад. Бо фармони pwd санҷед.
  3. Абзорҳоро бо фармонҳои node -v, npm -v, git --version санҷед. Агар хатогӣ пайдо шуд — «Агар вайрон шуд»-ро дар поён бинед.

Қадами 3. Ба Git муаррифӣ шавед

  1. Дар терминал ду фармони бахши 6-ро ворид кунед, номи худро бо ҳарфҳои лотинӣ ва почтаеро, ки GitHub ба он сабти ном шудааст, ҷойгузин намоед (ё суроғаи …@users.noreply.github.com-ро аз танзимоти GitHub).
  2. Санҷед: git config --global user.name ва git config --global user.email бояд он чиро, ки шумо ворид кардед, чоп кунанд.

Қадами 4. Лоиҳаро дар localhost оғоз кунед

  1. Ба ҷузвдон дароед: cd my-site. Санҷед, ки ls index.html-ро нишон медиҳад.
  2. Серверро оғоз кунед: npx serve. Агар терминал бипурсад Ok to proceed? (y), y ворид кунед ва Enter-ро пахш намоед.
  3. Сатри суроғаи http://localhost:…-ро интизор шавед ва онро дар браузер кушоед (дар терминали Cursor метавонед бо Ctrl ё Cmd-и зермонда ба суроға зер кунед). Шумо саҳифаи худро мебинед.
  4. Скриншот барои вазифаи хонагӣ гиред: равзанаи браузер бо суроғаи localhost:… дар сатри суроға ва дар паҳлӯяш терминал бо сервери оғозшуда.
  5. Серверро қатъ кунед: дар терминал Ctrl+C-ро пахш кунед, баъд бо фармони cd .. аз ҷузвдон бароед.

Қадами 5. Коммити аввал бо тугмаи Source Control

  1. Дар решаи vibe-course файли README.md-ро созед (аломати «New File» дар панели файлҳо) ва дар он ду сатр нависед: сарлавҳаи # vibe-course ва рӯйхати корҳо (my-site, coffee, fitness). Файлро захира кунед (Ctrl+S / Cmd+S).
  2. Дар панели канории чап аломати Source Control-ро (се давра, ки бо хатҳо пайваст шудаанд) ё Ctrl+Shift+G-ро пахш кунед (дар macOS — Control+Shift+G). Агар ҷузвдон ҳоло зери Git набошад, тугмаи Initialize Repository пайдо мешавад: онро пахш кунед. Ҳамин корро фармони git init мекунад.
  3. Дар рӯйхати «Changes» ҳамаи файлҳои шумо бо ҳарфи U (untracked — «нав, Git ҳоло ӯро надидааст») хоҳанд буд. Дар майдони «Message» паёмро нависед: add my-site, coffee, fitness ва Commit-ро пахш кунед. Агар муҳаррир бипурсад, ки ҳамаи тағйиротро ба коммит илова кунед («stage all changes»), розӣ шавед.
  4. Баъди коммит тугма ба Publish Branch табдил меёбад. Онро пахш кунед: муҳаррир пешниҳод мекунад, ки дар GitHub репозиторий созед. public (ҷамъиятӣ)-ро интихоб карда, тасдиқ кунед. Бори аввал браузер мекушояд: ба GitHub ворид шавед ва «Authorize» («Иҷозат додан»)-ро пахш кунед, баъд ба муҳаррир баргардед. Парол дар ҳеҷ ҷо ворид кардан лозим нест.
  5. Вақте ки муҳаррир огоҳии муваффақиятро нишон дод, репозиторийро дар сайт кушоед: github.com/логини-шумо/vibe-course. Шумо бояд ҷузвдонҳо ва файли README-и худро бинед.

Қадами 6. Коммити дуюм: одати «ҳар қадам = коммит»

  1. README.md-ро кушоед ва сатри номи худ ва як ҷумларо дар бораи он, ки имрӯз чӣ омӯхтед, илова кунед. Захира кунед.
  2. Дар Source Control файл бо ҳарфи M (modified, «тағйир ёфт») пайдо мешавад. Паёми update readme-ро нависед ва Commit-ро пахш кунед.
  3. Sync Changes-ро пахш кунед: коммит ба GitHub меравад. Саҳифаи репозиторийро дар браузер нав кунед: дар рӯйхати коммитҳо камаш ду коммит бояд бошад.
Аз ин дарс: ҳар қадам = коммит

Баъди ҳар қадами назаррас (саҳифа кор кард, блок илова шуд, хатогӣ ислоҳ шуд) бо паёми фаҳмо коммит кунед ва дар охири кор — push. Агар ислоҳи навбатии AI лоиҳаро вайрон кунад, шумо ба коммити қаблӣ бармегардед. Вазифаҳои хонагӣ акнун бо истинод ба GitHub супорида мешаванд.

Агар вайрон шуд

PowerShell: «иҷрои сценарияҳо хомӯш карда шудааст» (Windows)

Ҳангоми оғози npx ё npm дар Windows PowerShell метавонад матни сурхи намуди зерин пайдо шавад: npx : File C:\Program Files\nodejs\npx.ps1 cannot be loaded because running scripts is disabled on this system (дар Windows-и русӣ: «…так как выполнение сценариев отключено в этой системе»). Ин ҳимояи PowerShell аст: то даме ки сиёсати иҷро («execution policy») сценарияҳоро манъ мекунад, npx.ps1 оғоз намешавад. Оғози сценарияҳои маҳаллиро танҳо барои корбари худ иҷозат диҳед:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Ба саволи тағйири сиёсат бо Y (ё «Д») ҷавоб диҳед, баъд терминалро пӯшед ва аз нав кушоед. Сиёсати RemoteSigned сценарияҳои маҳаллии шуморо иҷозат медиҳад, аммо барои сценарияҳои аз интернет боргиришуда имзо талаб мекунад. Агар фармон нависад, ки параметр бо сиёсати гурӯҳӣ танзим шудааст (компютери корӣ ё мактабӣ), дар рӯйхати кушодашаванда дар паҳлӯи «+» дар панели терминал профили Command Prompt-ро интихоб кунед: дар он ин ҳимоя амал намекунад.

macOS: дархости насби Command Line Tools

Агар Git насб нашуда бошад, аввалин фармони git равзанаеро бо матни тахминан «The “git” command requires the command line developer tools. Would you like to install the tools now?» мекушояд. «Install» («Насб кардан»)-ро пахш кунед, шартҳоро қабул намоед ва анҷомро интизор шавед (5–15 дақиқа). Фармони дуюми терминал, ки ҳангоми насб оғоз шудааст, равзанаро аз нав мекушояд: танҳо интизор шавед. Вақте равзана пӯшида шуд, фармонро такрор кунед. Агар равзана пайдо нашуд, дар терминал xcode-select --install-ро иҷро кунед. Баъд терминалро пӯшед ва аз нав кушоед.

ВАЗИФАИ 8.3

Агар вайрон шуд: сабабро ёбед

миёна

Дар Windows PowerShell фармони npx serve матни сурхро нишон дод: «npx.ps1 cannot be loaded because running scripts is disabled on this system». Чӣ кор кардан лозим?

  1. Windows-ро аз нав насб кардан
  2. Set-ExecutionPolicy -Scope CurrentUser RemoteSigned-ро иҷро карда, тасдиқ намудан ва терминалро аз нав кушодан
  3. Node.js-ро нест кардан
  4. npx.ps1-ро аз сайти дигар зеркашӣ кардан

PowerShell бо пешфарз иҷрои сценарияҳоро манъ мекунад, ва npx дар он сценария аст. Фармон сценарияҳои маҳаллиро барои корбари шумо бе ҳуқуқи администратор иҷозат медиҳад.

Ҳангоми push терминал менависад «Support for password authentication was removed». Кадом ҷавоб дуруст аст?

  1. Паролро боз ворид кардан лозим аст, аз рӯи диққат бештар
  2. Паролро ба дарозтар иваз кардан лозим аст
  3. Пароли GitHub барои Git мувофиқ нест: тавассути браузер ворид шавед, бо тугмаҳои Publish Branch ё Sync Changes
  4. Аккаунти нав сохтан лозим аст

GitHub пароли аккаунтро барои Git қабул намекунад. Муҳаррир браузерро мекушояд ва иҷозатро бе парол дар терминал мегирад.

Дар macOS баъди git --version равзанаи «The “git” command requires the command line developer tools» пайдо шуд. Чиро пахш кардан лозим?

  1. «Install» («Насб кардан») ва анҷомро интизор шуда, баъд фармонро такрор кардан
  2. «Cancel» ва дигар аз Git истифода набурдан
  3. Терминалро пӯшида, Git-ро аз сайти номаълум зеркашӣ кардан
  4. Mac-ро бе пахш кардани чизе аз нав бор кардан

Ин роҳи муқаррарии гирифтани Git дар macOS аст: бо абзорҳои сатри фармон Git низ меояд.

Барои мутолиаи муфассалтар: Microsoft: сиёсатҳои иҷрои PowerShell (бо забони англисӣ), GitHub: репозиторийҳои дурдаст ва воридшавӣ.

10 Вазифаи хонагӣ: скриншоти localhost ва истинод ба репозиторий

ВХ-4 тасдиқ мекунад, ки занҷираи пурраи шумо кор мекунад: лоиҳа дар localhost оғоз мешавад, корҳо дар репозиторийи ҷамъиятии GitHub бо таърихи коммитҳо ҷойгиранд. Аз ин дарс сар карда вазифаҳои хонагӣ бо истинод ба GitHub супорида мешаванд.

Чӣ кор кардан лозим

  1. Скриншоти муҳит. npx serve-ро дар ягон корҳои худ (my-site, coffee ё fitness) оғоз кунед ва як скриншот гиред: браузер бо суроғаи localhost:… ва терминал бо сервери оғозшуда. Скриншотро ба чати гурӯҳ фиристед.
  2. Репозиторий. Боварӣ ҳосил кунед, ки vibe-course дар GitHub ҳамчун public нашр шудааст ва дар он my-site, coffee, fitness (ҳамаи онҳое, ки доред) ва README.md намоён аст.
  3. Таърих. Дар репозиторий камаш ду коммит бо паёмҳои фаҳмо (масалан, add my-site, coffee, fitness ва update readme).
  4. Санҷиши истинод. Истинодро дар равзанаи инкогнито кушоед: саҳифа бояд бе воридшавӣ кушода шавад. Агар воридшавӣ талаб кунад, репозиторий пӯшида (private) аст: «Settings»-и онро дар GitHub кушоед ва намоёнро ба Public иваз намоед.
  5. Истинодро супоред дар майдони поён: суроғаи намуди https://github.com/логини-шумо/vibe-course.
Хатогиҳои маъмул дар вазифаи хонагӣ

1. Истинод ба репозиторийи пӯшида: санҷишгар онро кушода наметавонад. 2. Скриншот бе суроғаи localhost дар сатри суроға ё бо суроғаи file:///…: ин localhost нест. 3. Репозиторий холӣ аст: commit сохта шудааст, аммо push нест. 4. Истинод на ба репозиторий, балки ба профил ё ба як файл. 5. Дар репозиторий паролҳо, калидҳо ё ҳуҷҷатҳои шахсӣ ҳастанд. 6. Ҳамаи файлҳо дар як коммити «update» — одати «ҳар қадам = коммит»-ро машқ кунед.

Санҷишгар чӣ тавр баҳо медиҳад

  • Истинод бе воридшавӣ кушода мешавад ва маҳз ба репозиторий мебарад.
  • Ҷузвдонҳои корҳои 1–3 ва README.md бо номи шумо намоёнанд.
  • Дар таърих камаш ду коммит ҳаст, муаллиф бо ном имзо шудааст (на «unknown»).
  • Дар скриншот суроғаи localhost бо порт ва сервери оғозшуда намоён аст.
  • Сирҳо ва файлҳои .env нестанд.
