React бе тарс: компонентҳо ва props

То охири дарс шумо лендинге хоҳед дошт, ки на аз як саҳифаи дароз, балки аз «хиштҳо» ҷамъ шудааст: компонентҳои Header, Hero, Services, Pricing ва Footer ва як корти универсалӣ, ки худаш ба маълумот мутобиқ мешавад. Барои иваз кардани нарх, ном ё як блоки том ба шумо танҳо як ислоҳ дар як ҷой кофист, на дар даҳ ҷой. Дар роҳ шумо ҳадди ақали JavaScript-ро, ки барои хондани чунин код лозим аст, меомӯзед: тағйирёбандаҳо, массивҳо, объектҳо, функсияҳо ва импорт. Саволи маъмултарин баъди дарси 5 — .tsx чӣ маъно дорад — ҷавоби мустақим мегирад.

  • Шарҳ додан, ки React барои чӣ лозим аст ва компонент чист, ва «хишт»-ҳоро дар ҳар сайт нишон додан
  • JavaScript-и асосиро хондан: const, сатрҳо ва рақамҳо, массивҳо, объектҳо, функсияҳо, функсияҳои тирдор, import ва export
  • JSX-ро хондан ва ислоҳ кардан: қоидаҳои нишонагузорӣ, воридкуниҳои {…}, компонентҳои дарунҷо
  • Додаҳоро тавассути props фиристодан ва як корти универсалӣ ба ҷои се нусха сохтан
  • Рӯйхати кортҳоро аз массив бо map баровардан ва фаҳмидан, ки key барои чӣ лозим аст
  • Лендингро ба компонентҳо дар ҷузвдони components тақсим кардан ва онҳоро дар app/page.tsx пайваст кардан
Ин дарсро чӣ тавр гузаштан лозим

Муҳаррирҳои React дар саҳифа React-ро аз интернет боргирӣ мекунанд, бинобар ин пайвастшавӣ ба шабака лозим аст. Амалиётро (боби 8) як нишаст иҷро кунед. Агар дарси 5-ро гузаронда бошед ё лоиҳа оғоз нашавад, аввал ба он баргардед: дар ин ҷо мо бидуни такрор ба он такя мекунем.

01 React барои чӣ лозим аст ва компонент чист

Файли app/page.tsx-и лендинги худро аз дарси 5 кушоед. Эҳтимол, ин як саҳифаи дарози 200–400 сатрӣ аст: сарлавҳа, hero, се корти хизмат, се табиб, шарҳҳо ва шакл. Акнун дархостҳои маъмули муштариро тасаввур кунед: «рангҳои тугмаҳоро иваз кунед», «хидмати чорумро илова кунед», «барои додарам, ки қаҳвахона дорад, айнан чунин сайт созед». Дар файли дароз як корти якхела якчанд маротиба нусха шудааст ва ислоҳ ба ҷустуҷӯи матн табдил меёбад: нусхаеро аз қафо мондан осон аст ва сайте мегиред, ки дар он се тугма кабуд аст, чорумӣ бошад сабз монд. AI низ дар чунин файл бештар саргум мешавад.

React инро чунин ҳал мекунад: интерфейс аз компонентҳо ҷамъ мешавад — «хишт»-ҳои хурди мустақил, ки ҳар кадомаш барои пораи худии экран масъул аст. Кортро як маротиба тавсиф мекунед ва баъд ба қадри лозим истифода мебаред, маълумоти гуногунро ҷойгир карда. React дар Meta (Facebook) сохта шудааст ва имрӯз маъмултарин китобхона барои интерфейсҳо боқӣ мемонад, барои ҳамин AI дар он беҳтар менависад. Next.js, ки дар дарси 5 бо он кор кардед, фреймворк дар заминаи React аст: саҳифаҳо, масирҳо ва нашрро илова мекунад, хиштҳои интерфейс дар он ҳамон компонентҳои React мебошанд.

Видео бо забони англисӣ, зернависро фаъол кунед (тақрибан 2 дақиқа): ғояи React ва компонентҳо дар шакли фишурда. Тафсилоти ҳолат ва хукҳоро аз видео то дараҷае гузаред: ба онҳо дар дарси 8 бармегардем.

Монандӣ аз ҳаёт

Компонент — қолаби кулчаҳои ошхона аст. Қолаб як аст, кулчаро ба қадри дилхоҳ сохтан мумкин, ва ҳар кулча дарунаш гуногун аст. Хостед ба рӯйи қолаб ситорача илова кунед — қолабро як бор ислоҳ кардед ва ҳамаи кулчаҳои баъдӣ аллакай бо ситорача мебароянд. Бе қолаб шумо ҳар кулчаро бо даст месозед ва ҳар кадом каме гуногун мебарояд.

Файлҳои .tsx: ҷавобе, ки дар дарси 5 ваъда шуда буд

Дар номи page.tsx ду қисм ҳаст. JSX — роҳи навиштани нишонагузорӣ бевосита дар дохили код (дар боби 3 шарҳ медиҳем). TS — TypeScript: ба JavaScript «имзоҳо» ба додаҳо илова шудаанд, то муҳаррир ва ҷамъоварӣ хатогиҳоро пешакӣ бигиранд. Ҳоло ба шумо танҳо шинохтани онҳо дар код лозим аст. Инак сатри маъмуле, ки AI менависад:

export default function Card({ title, price }: { title: string; price: number }) {
  // ...
}

Қисми баъд аз дунуқта — тавсифи навъҳо: «ба ин корт ном (матн) ва нарх (адад) меояд». Онро ҳамчун навишта рӯйи қуттӣ хонед: дарунаш чӣ бояд бошад. Агар нархро бо калима диҳед, ҷамъоварӣ қатъ мешавад ва хатои навъҳоро менависад — онро, мисли дарси 5, пурра нусха карда ба AI мефиристанд. Дар машқҳои ин саҳифа навъҳо нест: мо React-и «тоза»-ро бо JavaScript менависем, дар лоиҳаи Cursor AI имзоҳоро худаш илова мекунад.

Хатогиҳои маъмули навомӯзон

1. React ва Next.js-ро омехта кардан: React хиштҳо месозад, Next.js аз онҳо сайт бо саҳифаҳо ва нашр месозад. 2. Фикр кардан, ки пеш аз оғоз бояд тамоми JavaScript-ро омӯхт: барои хондани код маҷмӯи хурди боби 2 кофист. 3. «Компонент»-ро саҳифаи том ҳисобидан. Компонент метавонад ҳам бахши том ва ҳам тугмаи хурд бошад. 4. Як кортро се маротиба нусха кардан ба ҷои як компонент: аз ин «саҳифаи дароз» пайдо мешавад, ки мо аз он дур мешавем.

02 Ҳадди ақали JavaScript: барои хондани коди компонентҳо

Компонентҳои React — JavaScript-и оддӣ плюс нишонагузорӣ мебошанд. Онро AI менависад, аммо хондан-ро худатон бояд кунед: санҷед, ки AI чӣ кардааст, ёбед, ки нарх дар куҷост, ва ислоҳҳоро бо суханони дақиқ хоҳиш кунед. Барои ин тамоми забон лозим нест: шаш мафҳум кофист. Ҳар кадом — мисоли кӯтоҳ, ки онро бо тугмаи «Иҷро кардан» дар худи ҳамин ҷо оғоз кардан мумкин, ва вазифа. Баъди ин боб массивҳо ва объектҳо дар код дигар ба рамз монанд нахоҳанд буд.

Мисолҳо чӣ тавр кор мекунанд

Дар блокҳои бо тугмаи «Иҷро кардан» код дар браузер иҷро мешавад ва натиҷа дар консол дар зери он пайдо мешавад. console.log(…) — «қимматро дар консол чоп кун». Рақамҳо ва калимаҳоро иваз кунед ва аз нав иҷро кунед: вайрон кардан имконнопазир аст.

1. Тағйирёбанда: const

Тағйирёбанда — қуттии имзошуда, ки қиммат дар он гузошта мешавад, то баъд бо ном ба сўяш баргардед. Калимаи const (аз constant, «доимӣ») чунин қуттӣ месозад; қимматро баъди аломати = як бор дар он мегузоранд ва минбаъд аз нав таъин намекунанд. Дар коди AI боз let-ро мебинед — қуттӣ, ки онро аз нав таъин кардан мумкин аст, аммо дар ин дарс const кофист.

const city = "Душанбе";
const price = 200;

console.log(city);
console.log(price);

2. Сатр ва адад

Сатр — матн дар байни нохунакҳо: "Чистка зубов". Адад — бе нохунак: 200. Фарқ муҳим аст: ададҳоро ҷамъ ва тарҳ кардан мумкин, сатрҳоро бошад — часпонидан. Барои часпонидан сатри шаблонӣ дар нохунакҳои баръакс қулайтар аст: ба дохили он тавассути ${…} тағйирёбандаҳо ва ҳатто ҳисобкуниҳоро мегузоранд. Дар коди React имзоҳоро ба монанди «Чистка зубов: 150 сомони» ҳамин тавр месозанд.

const title = "Пломба";
const price = 350;
const discount = 50;

console.log(price - discount);              // адад: 300
console.log("Услуга: " + title);            // часпонидан: Услуга: Пломба
console.log(`${title} стоит ${price - discount} сомони`);   // сатри шаблонӣ
console.log("350" + 50);                    // сатр + адад = сатр: 35050

Ишора 2

console.log(`${title}: ${price - discount} сомони`); — сатри шаблонӣ дар нохунакҳои баръакс, дар дохили ${…} тағйирёбандаҳо ва тарҳ меистанд.

3. Массив: рӯйхати қиматҳо

Массив — рӯйхати тартибдор дар қавсҳои чоркунҷа: [120, 200, 350]. Ҳар унсур шумора (индекс) дорад ва ҳисобкуниро бояд аз сифр оғоз кард: унсури аввал — prices[0]. Дарозии рӯйхат — prices.length. Вақте дар лендинг якчанд хизмат, табиб ё шарҳ ҳаст, дар код онҳо маҳз дар массив мехобанд.

4. Объект: корт аз ҷуфтҳои «калид: қиммат»

Объект — маҷмӯи қиматҳои имзошуда дар қавсҳои фигурӣ: { name: "Зарина", experience: 7 }. Қиматро бо калид тавассути нуқта мегиранд: doctor.name. Агар шумо аллакай JSON дидаед, ин хеле монанд аст, танҳо калидҳо одатан бе нохунак мебошанд. Дар React аксар вақт массивҳои объектҳо вомехӯранд: рӯйхате, ки ҳар унсураш корт бо якчанд майдон аст.

const doctor = { name: "Зарина", role: "терапевт", experience: 7 };
const prices = [120, 200, 350];

console.log(doctor.name);          // Зарина
console.log(prices[0]);            // 120 — ҳисоб аз сифр
console.log(prices.length);        // 3

// деструктуризатсия: якбора якчанд майдонро аз объект мегирем
const { name, role } = doctor;
console.log(`${name} — ${role}`);

Сатри const { name, role } = doctor; деструктуризатсия номида мешавад: «аз объект майдонҳои name ва role-ро гир ва аз онҳо тағйирёбанда бисоз». Онро дар хотир нигоҳ доред: компонентҳо додаҳоро дар боби 4 маҳз ҳамин тавр қабул мекунанд.

5. Функсия ва функсияи тирдор

Функсия — маҷмӯи амалҳои номдор: қиматҳоро ба воридот (параметрҳо) мегирад, коре мекунад ва натиҷаро тавассути return бармегардонад. Муҳим аст, ки омехта накунед: console.log қиматро танҳо чоп мекунад, return бошад онро ба касе, ки функсияро даъват кардааст, бармегардонад. Функсияи тирдор — навишти кӯтоҳи ҳамон чиз бо тир =>. Агар баъд аз тир як ифода бошад, return-ро навиштан лозим нест.

function formatPrice(value) {
  return value + " сомони";
}

const formatPrice2 = (value) => value + " сомони";    // ҳамон чиз кӯтоҳтар

console.log(formatPrice(120));
console.log(formatPrice2(200));

Ҳар як компоненти React низ функсия аст: дар воридот додаҳо мегирад ва нишонагузорӣ бармегардонад. Барои ҳамин фаҳмидани функсияҳо — хишти асосии ин боб аст.

6. import ва export: файлҳо чӣ тавр ҳамдигарро меёбанд

Лоиҳа аз файлҳои зиёд иборат аст ва файлҳо бояд аз ҳамдигар пораҳои кодро гиранд. export — «ба берун баровардан»-и он чизе, ки файл омодаи додан аст, import — «гирифтан»-и он дар файли дигар. Бе онҳо компонент, ки дар components/Hero.tsx ҷойгир аст, дар саҳифа нишон дода намешавад.

// экспорти асосии файл: номро дар импорт ихтиёрӣ интихоб кардан мумкин
import Hero from "@/components/Hero";

// экспорти номдор: ном дар қавсҳо бояд бо номи export мувофиқ бошад
import { services } from "@/data/services";

Функсияро навиштан, вале даъват накардан: бе қавсҳо formatPrice(120) ҳеҷ чиз рӯй намедиҳад. 6. console.log-ро дар ҷое истифода бурдан, ки return лозим аст: натиҷа чоп шудааст, вале ба пеш дода нашудааст.

03 JSX ва компонент: функсияе, ки нишонагузорӣ бармегардонад

Компонент дар React — функсияи оддӣ аст, ки номаш бо ҳарфи калон оғоз мешавад ва нишонагузорӣ бармегардонад. Ин нишонагузорӣ дар намуди JSX навишта мешавад: он ба HTML монанд аст, вале бевосита дар дохили JavaScript зиндагӣ мекунад. Компоненти тайёрро мисли теги HTML-и худӣ даъват мекунанд: <Hero />.

Поёнтар «Иҷро кардан»-ро пахш кунед: дар ин ҷо ду компонент ҳаст ва функсияи сеюм — App онҳоро якҷоя ҷамъ мекунад. Шаҳр ё солро дар Hero иваз кунед ва аз нав иҷро кунед.

Компонент бояд дар куҷо зиндагӣ кунад

Ҳар компонентро дар «сатҳи боло»-и файл эълон кунед, на дар дохили компоненти дигар: React огоҳ мекунад, ки эълони дарунҷо суст кор мекунад ва ба хатогиҳои аҷиб оварда мерасонад. Агар AI функсия-компонентро дар дохили функсия-компоненти дигар навишта бошад, хоҳиш кунед, ки онро ба берун барорад.

Монандӣ аз ҳаёт

Компонент — мисли хишт аз як қолаб дар корхонаи хиштпазӣ дар наздикии Душанбе: ҳама якхела андоза доранд, барои ҳамин аз онҳо ҳар девореро сохтан мумкин. Саҳифа — девор аст, <Hero /> бошад — калима дар нақша «ин ҷо хишти Hero гузор». Нақша кӯтоҳ аст ва дар як дақиқа хонда мешавад, мураккабӣ дар дохили хиштҳо пинҳон шудааст.

Хатогиҳои маъмули навомӯзон

1. Аз компонент ду теги ҳамсояро бе печонаки умумӣ баргардондан (хатои «Adjacent JSX elements must be wrapped…»). 2. Слешро дар <input>, <img>, <br> фаромӯш кардан. 3. class-ро ба ҷои className навиштан: React дар консоли браузер огоҳӣ нишон медиҳад, ва ҳангоми ҷамъоварии лоиҳа линтери сахт метавонад нашрро қатъ кунад. 4. Компонентро бо ҳарфи хурд номидан ё файлро hero.tsx номидан, вале Hero.tsx-ро импорт кардан: дар сервери Vercel ҳарфҳои калон ва хурд дар номи файлҳо аҳамият доранд. 5. {city}-ро бе қавсҳо навиштан ё баръакс, қавсҳоро гирду атрофи матни оддӣ гузоштан.

04 Props: як корт чӣ тавр додаҳои гуногунро нишон медиҳад

То ҳол компонентҳои шумо ҳамеша як матни якхеларо нишон медиҳанд. Барои он ки як корт ҳам «Тозакунии дандон бо 200», ҳам «Пломба бо 350» бошад, ба он бояд додаҳо фиристод. Ин додаҳо props (аз properties, «хосиятҳо») номида мешаванд. Онҳоро мисли атрибутҳои теги HTML мефиристанд, дар дохили компонент бошад онҳо ҳамчун параметрҳои воридоти функсия меоянд — хондани онҳоро аз боби 2 медонед.

Дар код чӣ тавр менамояд

function Card({ title, price }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <p>{price} сомони</p>
    </div>
  );
}

<Card title="Чистка зубов" price={200} />
  • Сатрро дар нохунак мефиристанд: title="Пломба". Адад, массив, объект, функсияро — дар қавсҳои фигурӣ: price={200}. Агар price="200" нависед, ба ҷои адад сатр меояд.
  • { title, price } дар қавсҳои функсия — ҳамон деструктуризатсияи боби 2: «аз объекти воридшуда ин ду майдонро гир».
  • Қимати пешфарзро бо аломати баробар таъин мекунанд: { title, price = 0 }. Он дар сурате кор мекунад, ки prop дода нашудааст.
  • Props-ро танҳо мехонанд. Дар дохили компонент онҳоро иваз кардан мумкин нест: додаҳо ба падар тааллуқ доранд. (Додаҳоро чӣ тавр иваз кардан — дар дарси 8 меомӯзем.)

Монандӣ аз ҳаёт

Props — мисли варақаи фармоиш дар чойхона. Варақа якхела аст: «таом», «миқдор», «миз». Пешхизмат онро барои ҳар меҳмон гуногун пур мекунад, ошпаз бошад ҳамон як форматро мехонад ва таоми лозимиро мепазад. Ошпаз фармоиши бегонаро хат намекунад ва аз нав наменависад: ӯ онро танҳо мехонад, ва барои ҳамин дар ошхона бетартибӣ нест. Props низ чунин: падар пур мекунад, компонент мехонад.

Хатогиҳои маъмули навомӯзон

1. Хатои имло дар номи prop: titel фиристодед, вале title-ро мехонед, ҷои холӣ мегиред, чунки қимат undefined аст. 2. Қавсҳои фигурӣ дар параметрҳо фаромӯш шуданд: function Card(title, price) ба ҷои function Card({ title, price }). 3. Адад бо сатр фиристода шуд: price="200". 4. Кӯшиши иваз кардани prop дар дохили компонент. 5. Объекти томро фиристода, мехоҳед онро ҳамчун матн намоиш диҳед: React «Objects are not valid as a React child» ҷавоб медиҳад. Майдонро баровардан лозим аст: {service.title}. 6. Кортро се маротиба нусха мекунед ба ҷои як компонент бо props-и гуногун.

05 Додаҳо дар массив ва map: кортҳо худ аз рӯйхат пайдо мешаванд

Ҳатто бо props се даъвати <ServiceCard … /> такрор менамояд. Агар хизматҳо даҳ бошанд ва фардо — дувоздаҳ шаванд-чӣ? Додаҳо алоҳида, нишонагузорӣ алоҳида: барои илова кардани хизмат шумо як сатр ба массив илова мекунед, ва саҳифа худаш нав мешавад. Маҳз ҳамин форматро AI ба таври пешфарз интихоб мекунад, ва маҳз онро вазифаи хонагӣ талаб мекунад.

Абзори лозимӣ — усули массиви map. Он ҳар унсури рӯйхатро мегирад, бо ёрии функсияи тирдори шумо онро ба чизи нав табдил медиҳад ва натиҷаҳоро ба массиви нави ҳамон дарозӣ ҷамъ мекунад. Аввал бо сатрҳои оддӣ кӯшиш мекунем.

Дар React map сатрҳоро не, балки JSX бармегардонад: ба ҳар унсури додаҳо — як компонент. Натиҷаро дар қавсҳои фигурӣ бевосита дар нишонагузорӣ мегузоранд. Ба ҳар унсури рӯйхат бояд prop-и key-ро илова кард: «нишона»-и ягона, ки бо он React мефаҳмад, кадом корт кадом аст, вақте рӯйхат иваз мешавад.

const services = [
  { id: 1, title: "Чистка зубов", price: 200 },
  { id: 2, title: "Пломба", price: 350 },
];

export default function Services() {
  return (
    <div className="grid">
      {services.map((service) => (
        <ServiceCard key={service.id} title={service.title} price={service.price} />
      ))}
    </div>
  );
}

  • key-ро ба унсури берунӣ дар дохили map мегузоранд, яъне ба худи <ServiceCard />. Ба дохили компонент он намеравад, ин нишонаи хизматӣ барои React аст.
  • Калид бояд дар байни ҳамсояҳо ягона ва устувор бошад: идентификатор аз додаҳо (id) мувофиқ аст; Math.random() — не. Рақами унсур (index) танҳо барои рӯйхате мувофиқ аст, ки ҳеҷ гоҳ ҷобаҷо ва ё нест карда намешавад.
  • Бе key React дар консоли браузер огоҳии «Each child in a list should have a unique "key" prop»-ро мебарорад. Саҳифа метавонад кор кунад, вале огоҳиро намонед: он аз мушкили воқеӣ бо тартиби унсурҳо хабар медиҳад.

06 Сохтори лоиҳа: чӣ дар куҷо мехобад

Акнун ҳар компонент файли худро хоҳад дошт. Барои он ки дар лоиҳа тӯдаи бетартиб набошад, ба қоидаҳои оддӣ розӣ мешавем. Next.js схемаи сахтро ҷорӣ намекунад (дар ҳуҷҷатгузорӣ мустақиман гуфта шудааст, ки файлҳоро ҳам дар дохили app ва ҳам дар берун аз он нигоҳ доштан мумкин), аммо барои курс мо фаҳмотаринашро интихоб мекунем: хиштҳои умумӣ дар ҷузвдони components дар паҳлуи app мехобанд.

Ду қайд барои оянда

1. Имрӯз ҳамаи компонентҳои мо танҳо додаҳоро нишон медиҳанд. Баробари пайдо шудани рафтори «зинда» (пахши тугма, воридкунӣ ба майдон), дар сатри болои файл директиваи "use client" лозим мешавад. Агар AI онро аллакай ба файли шакл гузошта бошад, ҳамон тавр бигзоред: барои чӣ лозим аст, дар дарси 8 шарҳ медиҳем. 2. Аз файлҳо дар app саҳифаҳои алоҳидаи сайт (/about, /prices) чӣ тавр ҳосил мешаванд, дар дарси 9 шарҳ медиҳем. Ҳоло тамоми кори мо — дар дохили як саҳифаи app/page.tsx аст.

Монандӣ аз ҳаёт

Лоиҳа — мисли анбор дар бозори яклухт. Дар раф «Хиштҳо» қисмҳои тайёр мехобанд (components), дар раф «Ҳуҷҷатҳо» — рӯйхати молҳо ва нархҳо (data), ва дар утоқи роҳбар (app/page.tsx) як нақша: чӣ ва бо кадом тартиб гузошта мешавад. Агар ҳамаро ба як тӯда резед, касе чизи лозимиро намеёбад, AI бошад ним соат барои ҷустуҷӯ сарф мекунад.

Хатогиҳои маъмули навомӯзон

1. Компонентро ба ҷузвдони нодуруст гузоштан ва дар импорт роҳи дигар навиштан: Module not found: Can't resolve '@/components/Hero'. Роҳ ва ҳарфҳои калону хурди номи файлро санҷед. 2. export default-ро дар файли компонент фаромӯш кардан. Он вақт React ҷавоб медиҳад: «Element type is invalid… You likely forgot to export your component from the file it's defined in, or you might have mixed up default and named imports». 3. Импортро фаромӯш кардан: Hero is not defined. 4. Ҳар як хурдакориро дар панҷ файл тақсим кардан: компонент вақте лозим аст, ки порча такрор мешавад ё мантиқан ҷудо аст. 5. Файлро дар node_modules ба ҷои компоненти худ ислоҳ кардан.

ВАЗИФАИ 6.1

Худро санҷед: props, рӯйхат, сохтор

миёна

Шумо <Card titel="Пломба" price={350} />-ро даъват кардед, вале компонент ҳамчун function Card({ title, price }) эълон шудааст. Дар саҳифа чӣ мебинед?

  1. Корт пайдо мешавад, вале ном холӣ мемонад, чунки prop-и title фиристода нашудааст: номи бо хатои имло мувофиқ наомад
  2. React худаш хатои имлоро ислоҳ мекунад
  3. Калимаи «Пломба» пайдо мешавад, аммо бе нарх
  4. Саҳифа пурра бе паём нопадид мешавад

Props-ро бо ном мефиристанд. Prop-и titel-ро компонент намехонад, title бошад наомадааст, бинобар ин қимат undefined аст ва React чизе намебарорад. Дар лоиҳа бо TypeScript хаторо ҷамъоварӣ мебинад: мегӯяд, ки prop-и ҳатмӣ дода нашудааст.

Шумо кортҳоро тавассути services.map(…) мебароред. Кадом key беҳтар аст?

  1. Math.random()
  2. Калимаи якхелаи «card» барои ҳама
  3. service.id-и ягона аз додаҳо
  4. Калид тамоман лозим нест

Калид бояд дар байни ҳамсояҳо ягона ва дар байни рендерҳо устувор бошад. Идентификатор аз додаҳо мувофиқ аст; адади тасодуфӣ ҳар дафъа нав аст, калимаи якхела кортҳоро фарқ намекунад, ва бе key React аз хатогӣ огоҳ мекунад.

Нархҳои хизматҳо дар ду компоненти гуногун лозим шуданд. Онҳоро дар куҷо нигоҳ доштан беҳтар аст?

  1. Нархҳоро ба ҳар ду компонент нусха кардан
  2. Дар як массив дар файли алоҳида (масалан, data/services.ts) ва аз он ҷо импорт кардан
  3. Дар файли package.json
  4. Дар ҷузвдони node_modules

Як манбаи додаҳо: нархро дар массив иваз кардед — он дар ҳама ҷое, ки нишон дода мешавад, иваз шуд. Нусхаҳои нархҳо дер ё зуд аз ҳам ҷудо мешаванд.

Саҳифа бо паёми «Element type is invalid: expected a string … but got: undefined. You likely forgot to export your component» меафтад. Аввал чиро санҷидан лозим аст?

  1. Домени нав харидан
  2. Ҷузвдони .next-ро нест кардан ва умедвор шудан
  3. Cursor-ро аз нав насб кардан
  4. Оё дар файли компонент export default ҳаст ва оё усули импорт мувофиқ аст (бе қавсҳо барои default, бо қавсҳо барои номдор)

Паём сабабро мустақиман нишон медиҳад: компонент экспорт нашудааст ё импорт ба экспорт мувофиқат намекунад. Ин маъмултарин хатогӣ баъди тақсими код ба файлҳо мебошад.

Бештар хонед: Next.js: сохтори лоиҳа ва ташкили файлҳо ва React: импорт ва экспорти компонентҳо (бо забони англисӣ).

07 Блоки AI: кодро ба компонентҳо тақсим кардан чӣ тавр хоҳиш карда мешавад

Қоидаҳои рефакторинг бо AI

1. Аввал нусхаи корро захира кунед (commit), чунки AI якбора бисёр файлҳоро иваз мекунад. 2. Хоҳиш кунед, ки намуди зоҳирӣ нигоҳ дошта шавад: «рефакторинг» маънои иваз кардани сохтори код аст, на тасвир. 3. Компонентҳо ва ҷузвдонҳоро худатон номгузорӣ кунед: он гоҳ AI чизи нолозим намеандешад. 4. Агар вазифа калон бошад, аввал нақша, баъд код хоҳиш кунед. 5. Баъди ислоҳ натиҷаро дар браузер кушоед ва npm run build-ро иҷро кунед. 6. Кодеро, ки ҳадди ақал дар хатҳои асосӣ шарҳ дода наметавонед, қабул накунед: шарҳ хоҳиш кунед. 7. Дар ҳамон чат ислоҳ мекунем, на аз сар оғоз мекунем.

Формулаи промпт ҳамон: контекст → мақсад → маҳдудиятҳо → мисолҳо → санҷиш.

разбей код на компоненты
Контекст: проект Next.js (App Router, TypeScript) с Tailwind CSS. Весь лендинг стоматологии «Улыбка» лежит в app/page.tsx, и страница уже работает. Цель: разбить страницу на компоненты, не меняя внешний вид и тексты. Создай в папке components/ файлы Header.tsx, Hero.tsx, Services.tsx, Pricing.tsx, Footer.tsx (если секции Pricing ещё нет, добавь её: 3 тарифа «Базовый», «Стандарт», «Премиум» с ценами в сомони). Универсальную карточку вынеси в components/Card.tsx: она принимает props title, price (число) и необязательный description. Services и Pricing должны использовать именно её. Данные услуг и тарифов вынеси в массивы в data/services.ts и data/pricing.ts (поля id, title, price) и выводи карточки через map с key=id. Ограничения: один файл — один компонент, export default; импорты только через алиас @/; только Tailwind-классы, без новых библиотек; app/page.tsx должен только импортировать компоненты и расставлять их по порядку. Если в форме заявки есть обработчик события, оставь там первую строку "use client" и не добавляй её в остальные файлы. Проверка: запусти npm run build и исправь ошибки. В конце перечисли созданные файлы и коротко (по одной строке) скажи, что в каждом лежит.

Промпти қавӣ чӣ барартарӣ дорад: файлҳо ва ҷузвдонҳо номбар шудаанд, props ва формати додаҳо нишон дода шудаанд, мустаҳкам шудааст, ки намуди зоҳириро иваз кардан мумкин нест, ва санҷиши ҷамъоварӣ экспортҳо ва импортҳои фаромӯшшударо мегирад.

Промптҳоро бо русӣ нигоҳ медорем: модел бо онҳо беҳтар кор мекунад. Дар чати Cursor онҳоро бетағйир нусха кунед.

Ислоҳҳо ва саволҳо: кӯтоҳ, яке-яке

Сначала только план: какие компоненты и файлы ты создашь и какие props будет принимать каждый. Код пока не пиши и ничего не меняй. Я отвечу «ок» или поправлю план.

Объясни простыми словами, как для новичка: как components/Services.tsx получает массив services, как работает services.map и зачем нужен key. Код не переписывай.
В консоли браузера предупреждение: Each child in a list should have a unique "key" prop. Найди, где это, и исправь. Остальное не меняй.
Дар ҷавобҳои AI ба чӣ эътибор додан лозим аст

1. Тақсими аз ҳад майда: бист файл аз се сатрӣ. Бигӯед: «ҳар чизеро, ки як бор истифода мешавад, баргардон ва муттаҳид кун». 2. Компонентҳое, ки дар дохили компонентҳои дигар эълон шудаанд: хоҳиш кунед, ки ба сатҳи боло бароварда шаванд. 3. Китобхонаҳои нолозим дар package.json. 4. Навъи any дар имзоҳо: он санҷишро хомӯш мекунад. Агар дидед, хоҳиш кунед, ки навъҳоро дақиқтар тавсиф кунад. 5. Тарҳи «дар баробари ин» аз нав навишташуда: шумо сохторро хоҳиш кардед, на рангҳои нав.

Дар «Конструктори компонентӣ» иштирокчиён дар як шом се лендинги гуногун месозанд (масалан, стоматология, қаҳвахона ва курсҳои забони англисӣ) ва дар ин ҳол ягон компонентро нусха намекунанд: фақат додаҳо ва якчанд props фарқ мекунанд. Блок барои муаллим пешбинӣ шудааст ва барои шоми мустақилона низ мувофиқ аст.

Қоидаҳо

1. Хиштҳои аввалия — Header, Hero, Services, Pricing, Footer ва Card-и шумо аз амалиёт. 2. Се лендинг дар се суроға дар як лоиҳа лозим аст: саҳифаи асосии / ва ду саҳифаи нав. Фақат props метавонанд иваз шаванд: сарлавҳа, ранги таъкид, рӯйхати хизматҳо. 4. Компонентро нусха карда, аз нав номидан мумкин нест. Агар ба хишт чизе намерасад, ба он prop илова кунед. 5. Кодро бо даст наменависед: вазифаро ба AI тавсиф мекунед ва натиҷаро месанҷед. 6. Натиҷа — як истиноди зинда ба Vercel бо се суроға.

✓ Хулосаи дарс

  • React: интерфейс аз компонентҳо-«хишт» ҷамъ мешавад; Next.js — фреймворк дар заминаи React. .tsx = JSX + навъҳои TypeScript; хатогиҳои навъҳоро пурра нусха карда ба AI мефиристем.
  • Ҳадди ақали JS: const x = 5; — тағйирёбанда; "матн" ва 5 — сатр ва адад; `${a} и ${b}` — сатри шаблонӣ; [1, 2] — массив (ҳисоб аз сифр, .length); { key: value } — объект, майдон бо нуқта; const { a, b } = obj; — деструктуризатсия.
  • Функсияҳо: function f(x) { return … } ва const f = (x) => …; return қиматро бармегардонад, console.log танҳо чоп мекунад.
  • import / export: export default → import Name from "…" (бе қавсҳо); export const x → import { x } from "…"; @/ — аз решаи лоиҳа.
  • JSX: як реша (ё <>…</>), ҳамаи тегҳо баста, className ба ҷои class, қиматҳо аз JS — дар {…}.
  • Компонент: функсия бо ҳарфи калон, JSX бармегардонад; ҳамчун теги <Card /> даъват мешавад; дар сатҳи боло дар файл эълон мешавад.
  • Props: параметрҳои компонент: function Card({ title, price }); сатрҳо дар нохунак, боқӣ дар {…}; танҳо мехонем; prop-и махсуси children.
  • Рӯйхатҳо: додаҳо дар массиви объектҳо + {items.map((item) => <Card key={item.id} … />)}; key — ягона ва устувор (id).
  • Сохтор: app/page.tsx танҳо ҷамъ мекунад; components/ — хиштҳо (як файл — як компонент, ном бо ҳарфи калон); data/ — массивҳои додаҳо.
  • Хатогиҳои маъмул: export default нест («Element type is invalid»), ҳарфи нодуруст дар роҳ, key нест, объект ба ҷои майдон («Objects are not valid as a React child»).
  • Бо AI: commit пеш аз рефакторинг, номгузории файлҳо ва props, «намуди зоҳирӣ иваз нашавад», санҷиши npm run build, шарҳ хоҳиш кардани нофаҳмо.
ВАЗИФАИ 11.1

Ман мавзӯъро воқеан фаҳмидам

осон

Танҳо он чизеро қайд кунед, ки бе маслиҳат иҷро карда метавонед.

  • Метавонам шарҳ диҳам, ки React барои чӣ лозим аст ва компонент чист, ва дар ҳар сайт мисол орам
  • Метавонам кодро бо const, массивҳо, объектҳо, функсияҳои тирдор ва импортҳо хонам ва бигӯям, ки он чӣ мекунад
  • Метавонам шарҳ диҳам, ки васеъшавии .tsx чӣ маъно дорад ва имзои навъҳоро дар props чӣ тавр хондан мумкин аст
  • Метавонам компонентеро нависам, ки props мегирад, ва онро бо додаҳои гуногун даъват кунам
  • Метавонам рӯйхати кортҳоро аз массив тавассути map барорам ва шарҳ диҳам, ки key барои чӣ лозим аст
  • Метавонам саҳифаро ба компонентҳо дар ҷузвдони components тақсим кунам ва онҳоро дар app/page.tsx пайваст намоям
  • Метавонам сабаби хатогиҳои «Module not found» ва «Element type is invalid»-ро ёбам ва онҳоро ба AI фиристам
