Ин дарсро чӣ тавр гузаштан лозим

Лозим мешаванд: браузери Chrome ё Edge, VS Code аз дарси аввал ва чат бо AI. Вақт — тақрибан 2,5 соат. Назарияро (бахшҳои 1–6) қисм-қисм хондан мумкин, амалиётро (бахши 7) беҳтар аст дар як нишаст иҷро кунед. Дар матн бисёр майдончаҳои зинда ҳастанд: дар тарафи чап код, дар тарафи рост натиҷа. Кодро иваз кунед ва «Запустить»-ро пахш кунед; масъалаҳое, ки блоки «Натиҷаи интизорӣ» доранд, худкор санҷида мешаванд.

Шумо дар як дарс верстальщик намешавед ва ин лозим ҳам нест. Мақсад дигар аст: то ки AI барои шумо «қуттии сиёҳ» набошад. Агар код ақаллан дар хатҳои умумӣ фаҳмо бошад, шумо хаторо мебинед, чизи хурдро дар якчанд сония ислоҳ мекунед ва ба AI дақиқтар мегӯед, ки чиро иваз кунад.

01 Сохтори саҳифа: тегҳое, ки ҳама чиз аз онҳо сохта шудааст

Саҳифа — ин дарахт-и блокҳои дарунҳам аст. Берунитаринаш — <html>; дар дохили он ду қисм: <head> («сар» бо маълумоти хизматӣ: сарлавҳаи варақа, рамзгузорӣ, услубҳо) ва <body> («тан»: ҳар чизе ки дар экран намоён аст). Дар дохили <body> сарлавҳаи саҳифа, қисми асосӣ ва поёни саҳифа ҷойгиранд, дар дохили онҳо — сарлавҳаҳо, бандҳо, тугмаҳо ва тасвирҳо. Тегеро, ки дар дохили дигаре ҷойгир аст, фарзанд, берунӣ — волид меноманд.

Як тег чӣ тавр сохта шудааст

Ин сатрро ҷудо мекунем: <a …> — теги кушоянда, </a> — теги пӯшанда, href="…" ва class="…" — атрибутҳо (ҷуфти «ном = қимат дар нохунак»), ва матни байни тегҳо — он чизе, ки одам мебинад.

Атрибутҳо — «танзимот»-и тег: href, src, alt, class, id, type, placeholder. Онҳо дар дохили теги кушоянда навишта мешаванд, қимат — дар нохунак. Аксари тегҳо ҷуфтанд (кушоянда ва пӯшанда доранд); танҳоҳо — <img>, <input>, <br>.

Монандӣ аз ҳаёт

Саҳифа ба қатори бозор монанд аст. <section> — дӯкони алоҳида («Мева», «Седона»), <div> — қуттӣ дар болои пештахта, дар дохили қуттӣ мол ҳаст: <h3> — лавҳачаи ном, <p> — нархнома, <img> — акс, <a> — тире «ба он дӯкон гузаред», <button> — занги «фурӯшандаро даъват кунед». Қуттии холӣ арзише надорад ва дӯкони бе қуттӣ ҷои холист.

Худатон санҷед

Дар зер — корти қаҳвахона. Дар нусхаи шумо чор унсур намерасад. Шарҳҳоро дар HTML хонед, тегҳоро илова кунед ва «Запустить»-ро пахш кунед. Тасвире бо суроғаи photo.jpg дар майдонча нест, бинобар ин шумо аломати тасвири «шикаста»-ро якҷоя бо матни alt мебинед — ин муқаррарӣ аст ва нишон медиҳад, ки alt барои чӣ лозим аст.

  3. <div class="…">

  4. То ки тасвир зудтар бор шавад

  2. <img>
  3. <input>

02 Синф ва услуб: саҳифа ороишро чӣ тавр мегирад

HTML мегӯяд, ки дар саҳифа чӣ ҳаст. CSS мегӯяд, ки он чӣ тавр менамояд. Онҳоро синф мепайвандад — барчаспе, ки шумо ба тег мечаспонед: <button class="btn">. Дар CSS барои ин барчасп қоида менависанд.

.btn {                     /* селектор: «ҳамаи унсурҳои бо class="btn"» */
  background: #0e7a55;     /* хосият: қимат; — нуқтавергул ҳатмӣ аст */
  color: #fff;
  padding: 10px 18px;
}
Селектор чӣ тавр навишта шудаастКӣ-ро интихоб мекунад
h1ҳамаи тегҳои <h1> (номи тег)
.btnҳамаи унсурҳои бо class="btn" (нуқта = синф)
#menuяк унсури бо id="menu" (панҷара = id; он дар саҳифа якто аст)
.dish pбандҳои <p> дар дохили унсурҳои синфи dish

Тег метавонад якчанд синф дошта бошад, бо фосила: class="btn big". Онҳо ҷамъ мешаванд. Ва боз услубро бевосита ба тег навиштан мумкин: <p style="color: red">. Ин тавр барои санҷиши зуд мекунанд, вале синфҳо қулайтаранд: қоида дар як ҷо ҳамаи унсурҳоро идора мекунад.

Чор хосияте, ки шумо аксар вақт иваз мекунед

  • Ранг: color — ранги матн, background — замина. Қиматҳо: #0e7a55, rgb(14, 122, 85), white.
  • Матн: font-size (андоза), font-weight (ғафсӣ), text-align (тақсимот).
  • Фосилаҳо: padding — дар дохили блок, margin — дар беруни блок.
  • Чаҳорчӯба ва кунҷҳо: border, border-radius.
Монандӣ аз ҳаёт

Қуттии палав барои расонидан. Палав дар дохил — content. Дастмолҳо байни палав ва девори қуттӣ — padding. Девори қуттӣ — border. Масофа байни қуттиҳо дар раф, то ки ба ҳам напечанд, — margin. Мехоҳед палав «нафас кашад» — padding илова кунед; мехоҳед қуттиро аз ҳамсоя дур кунед — margin.

ВАЗИФАИ 2.2

Худро санҷед: CSS

осон

Қоидаи .btn { color: white; } чӣ маъно дорад?

  1. Ҳамаи тегҳои <btn> сафед мешаванд
  2. Ҳамаи унсурҳои бо class="btn" ранги сафеди матн мегиранд
  3. Танҳо як унсури бо id="btn" ранги сафед мегирад
  4. Заминаи саҳифа сафед мешавад

Нуқта пеш аз ном маънои «синф»-ро дорад. color — ранги матн, на замина (замина — background аст).

padding аз margin чӣ фарқ дорад?

  1. padding — фосилаи дохили блок (байни мӯҳтаво ва чаҳорчӯба), margin — фосилаи берунӣ (аз блокҳои ҳамсоя)
  2. padding — фосилаи берунӣ, margin — дохилӣ
  3. Ин як чиз аст
  4. padding рангро иваз мекунад, margin — андозаи ҳарфро

Тартиби қабатҳо аз берун ба дарун: margin → border → padding → content.

Дар CSS навишта шудааст colour: red;. Браузер чӣ мекунад?

  1. Паёми хатои сурх нишон медиҳад
  2. Тамоми саҳифаро вайрон мекунад
  3. Ин сатрро хомӯшона мегузаронад, ранг иваз намешавад
  4. Хатои имлоро худаш ислоҳ мекунад

Браузер аз хосиятҳои номаълум шикоят намекунад, онҳоро нодида мегирад. Барои ҳамин хатоҳои имлоӣ дар CSS пайдо кардан душвор аст: саҳифа танҳо «гӯш намекунад». Дар DevTools чунин сатр бо огоҳӣ қайд мешавад, дар ин бора — дар бахши 5.

03 Flexbox ва Grid бо ангушт: блокҳо чӣ тавр ба ҷояшон меоянд

Одатан блокҳо яке дар зери дигаре меоянд, ба монанди сатрҳои дафтар. Барои он ки блокҳоро дар як қатор гузоред, сутунҳо ё галерея созед, ду абзор истифода мебаранд. Ҳарду бо як хосият дар волид фаъол мешаванд, баъд блокҳои фарзанд худашон мувофиқи қоидаҳо ҷойгир мешаванд.

Flexbox: як хат

Дар волид фаъол мешавад: display: flex. Фарзандон дар як қатор мерасанд. Се хосият қариб ҳар он чизеро, ки вомехӯред, фаро мегирад:

ХосиятЧӣ мекунадҚиматҳо
gapмасофа байни фарзандон16px
justify-contentблокҳоро дар баробари хат чӣ тавр тақсим карданflex-start, center, space-between, space-around
align-itemsблокҳоро аз болои хат (аз рӯи баландӣ) чӣ тавр тарозу карданstretch, flex-start, center, flex-end
flex-directionсамт: қатор ё сутунrow (пешфарз), column

Видео бо забони русӣ (6,5 дақиқа): ҳамаи хосиятҳои Flexbox дар мисолҳои зинда. Ҳамаи онҳоро ба ёд гирифтан лозим нест, фаҳмидани ғояи «як тир, блокҳо навбат ба навбат» кифоя аст.

ВАЗИФАИ 3.1

Қатори кортҳо тавассути Flexbox

миёна

Се таом яке дар зери дигаре меистанд. Дар қоидаи .row нависед: display: flex, gap: 16px, justify-content: space-between ва align-items: center. Корти сеюм аз боқӣ баландтар аст — ин тавр хуб дида мешавад, ки align-items чӣ мекунад.

<div class="row">
  <div class="box">Плов</div>
  <div class="box">Шашлык</div>
  <div class="box tall">Лагман<br>с лепёшкой<br>и зеленью</div>
</div>

body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.row {
  /* ба ин ҷо: display, gap, justify-content, align-items */
}
.box { padding: 16px 20px; background: #e7f3ee; border: 2px solid #0e7a55; border-radius: 10px; font-weight: 700; }

// САНҶИШ — ин кодро тағйир надиҳед. Танҳо варақаҳои HTML ва CSS-ро ислоҳ кунед.
const $ = (s) => { try { return document.querySelector(s); } catch { return null; } };
const $$ = (s) => [...document.querySelectorAll(s)];
const css = (el, p) => (el ? getComputedStyle(el)[p] : '');
const ok = (name, cond) => console.log((cond ? '✓ ' : '✗ ') + name);

const row = $('.row');
ok('ряд включён (display: flex)', css(row, 'display') === 'flex');
ok('промежуток между карточками 16px', css(row, 'columnGap') === '16px');
ok('карточки разнесены по краям (space-between)', css(row, 'justifyContent') === 'space-between');
ok('карточки выровнены по центру высоты', css(row, 'alignItems') === 'center');
Натиҷаи интизорӣ
✓ ряд включён (display: flex)
✓ промежуток между карточками 16px
✓ карточки разнесены по краям (space-between)
✓ карточки выровнены по центру высоты
Маслиҳат 1

Ҳар чор хосият дар дохили ақсодҳои як қоидаи .row навишта мешаванд, дар волид, на дар кортҳои .box.

Маслиҳат 2

.row { display: flex; gap: 16px; justify-content: space-between; align-items: center; }

Grid: тӯр

Вақте ки ҳам сатрҳо, ҳам сутунҳо лозиманд (каталог, галерея, тарифҳо), Grid мегиранд: display: grid. Хосияти асосӣ — grid-template-columns, тавсифи сутунҳо. Навишти repeat(3, 1fr) чунин хонда мешавад: «се сутуни паҳнои баробар» (fr — «ҳиссаи ҷои холӣ»). Сатрҳо худашон илова мешаванд, вақте хонаҳо тамом мешаванд. Барои он ки унсур ду сутунро гирад: grid-column: span 2.

Видео бо забони русӣ (13 дақиқа), агар хоҳед амиқтар фаҳмед. Барои дарс матни боло ва вазифаи поён кифоя аст.

ВАЗИФАИ 3.2

Галереяи шаш лавҳа тавассути Grid

миёна

Аз .gallery тӯре аз се сутуни паҳнои баробар бо масофаи 12px созед. Баъд ба лавҳаи якум (.tile:first-child) иҷозат диҳед, ки ду сутунро гирад.

<div class="gallery">
  <div class="tile">1</div>
  <div class="tile">2</div>
  <div class="tile">3</div>
  <div class="tile">4</div>
  <div class="tile">5</div>
  <div class="tile">6</div>
</div>

body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.gallery {
  /* ба ин ҷо: display, grid-template-columns, gap */
}
.tile { padding: 20px; background: #fdf0e6; border: 2px solid #c2410c; border-radius: 10px; font-weight: 700; text-align: center; }

/* қоида барои лавҳаи якум дар ин ҷо навишта мешавад */

const $$ = (s) => [...document.querySelectorAll(s)];

ok('промежуток между плитками 12px', css(g, 'columnGap') === '12px' && css(g, 'rowGap') === '12px');

Маслиҳат 1

Дар .gallery: display: grid;, grid-template-columns: repeat(3, 1fr); ва gap: 12px;.

Маслиҳат 2

Қоидаи алоҳида: .tile:first-child { grid-column: span 2; } — «лавҳаи якум ду хонаро аз рӯи паҳноӣ мегирад».

Монандӣ аз ҳаёт

Flexbox — ин одамоне ҳастанд, ки дар маршрутка дар як қатор нишастаанд: касе ба канор часпидааст, касе баробар дур шудааст, ҳама ба як тараф менигаранд. Grid — ин мизҳои чойхона дар хонаҳои толор: ҳар миз сатр ва сутуни худро дорад ва ду мизро барои гурӯҳи калон ба ҳам овардан мумкин аст (span 2).

Чиро интихоб кунед

Як хат (меню дар сарлавҳа, қатори тугмаҳо, дар марказ гузоштани чизе) — Flexbox. Тӯр (каталог, кортҳо, галерея) — Grid. AI аксар вақт ҳарду дар як саҳифа истифода мебарад: Grid барои тарҳи умумӣ, Flexbox дар дохили кортҳо. Ин муқаррарӣ аст.

Хатогиҳои маъмули навомӯзон

1. display: flex-ро дар фарзандон навиштан, на дар волид: чизе рӯй намедиҳад. 2. justify-content (дар баробари хат) ва align-items (аз болои хат)-ро омехта кардан. 3. Дар бораи gap фаромӯш кардан ва ба ҳар корт ҷудо фосила гузоштан. 4. Аз Flexbox тӯр интизор шудан: агар ҳам сатрҳо, ҳам сутунҳо лозим бошанд, Grid гиред.

04 Коде, ки AI додааст, чӣ тавр хонда мешавад

Файли 200 сатра, то даме ки намедонед ба куҷо нигаред, даҳшатнок менамояд. Акнун шумо харита доред: ҳар файли HTML аз AI аз ҳамон қисмҳо иборат аст.

Панҷ усули хондан

  1. Аз рӯи фосилаҳо хонед. Дарунмонӣ аз ҷойивазкунӣ ба рост намоён аст: ҳар чизе ки амиқтар ҷойгир аст, дар дохили теги қаблӣ мехобад. Агар фосилаҳо «ба тарафи дигар рафта бошанд», форматкуниро иҷро кунед: дар VS Code ин Shift+Alt+F (Windows) ё Shift+Option+F (macOS) аст.
  2. Блокҳоро печонед. Дар паҳлӯи рақамҳои сатр дар VS Code тирчаҳо ҳастанд: пахш кунед ва тег печонида мешавад. Ҳамаи изофаро печонед ва скелетро монед.
  3. Аз рӯи матн ҷустуҷӯ кунед. Дар саҳифа калимаи «Заказать»-ро мебинед — Ctrl+F (Cmd+F)-ро пахш кунед, онро ворид кунед ва ба тугма дар код меафтед.
  4. Аз синф — ба қоида. class="btn"-ро ёфтед — боз Ctrl+F, .btn-ро ворид кунед ва ана қоида бо ранг ва фосилаҳо. Агар тег якчанд синф дошта бошад, ҳар якро ҷӯед.
  5. Аз AI дар бораи чизи мушаххас пурсед. На «ҳамаро шарҳ деҳ», балки «сатри 42 чӣ мекунад» ё «gap дар ин ҷо барои чӣ».
Монандӣ аз ҳаёт

Шаҳри ношиносро шумо аз рӯи ҳар кӯча наомӯзед: ба харита менигаред, майдон, кӯчаи асосӣ ва ноҳияи худро меёбед. Код низ ҳамин тавр хонда мешавад: аввал скелет (тегҳои header, main, section), баъд ноҳияи лозимӣ, баъд хонаи мушаххас (сатр).

Қоидаи суғурта

Пеш аз ҳар ислоҳ нусхаи файлро нигоҳ доред: index.html → index-v1.html (дар VS Code: тугмаи рости муш бар файл дар панели чап → «Copy», баъд «Paste» ва ном иваз кунед). Агар чизе вайрон шавад, ба нусхаи корӣ дар як сония бармегардед. Аз дарси 4 ин нақшро Git мегирад.

Хатогиҳои маъмули навомӯзон

1. Кӯшиши фаҳмидани ҳамаи 200 сатр пай дар пай. «Аз рӯи дархост» хонед: ба шумо ҷое лозим аст, ки мехоҳед иваз кунед. 2. Чизеро, ки нафаҳмидаед, бе нусхаи файл ислоҳ кардан. 3. Ороишро дар HTML ҷустан: рангҳо ва фосилаҳо дар CSS (<style>) меистанд, дар HTML танҳо синфҳо. 4. Сатрҳои «нофаҳмо»-ро дар <head> нест кардан: аз ҷумла <meta charset="UTF-8">, бе он матни русӣ ба «ҳарфҳои вайронкардашуда» табдил меёбад.

ВАЗИФАИ 4.1

Худро санҷед: хондани код

осон

Шумо дар саҳифа тугмаи «Заказать звонок»-ро мебинед. Чӣ тавр зудтар онро дар код ёфтан мумкин?

  1. Дар муҳаррир Ctrl+F (Cmd+F)-ро пахш карда, калимаҳои «Заказать звонок»-ро ворид кардан
  2. Файлро аз сатри аввал то охир хондан
  3. Файлро нест карда, аз AI хоҳиш кардан, ки аз нав нависад
  4. Дар блоки <head> ҷустан, ҳамаи тугмаҳо дар он ҷо мехобанд

Ҷустуҷӯ аз рӯи матни намоён бевосита ба ҷои даркорӣ мебарад. Тугмаҳо дар <body> ҷойгиранд, <head> — қисми хизматӣ ва услубҳост.

Дар тугмаи бо class="btn big" рангро иваз кардан лозим аст. Онро дар куҷо ҷустан?

  1. Дар теги <title>
  2. Дар CSS (дар <style>) дар қоидаҳои .btn ва .big
  3. Дар теги пӯшандаи тугма
  4. Дар номи файл

Синф дар HTML танҳо барчасп аст. Ороиш дар қоидаҳои CSS бо нуқта ва номи синф меистад; барои ду синф метавонад ду қоида бошад ва онҳо ҷамъ мешаванд.

Пеш аз ислоҳ дар файле, ки онро то охир нафаҳмидаед, чӣ кор кардан лозим?

  1. Ҳеҷ чиз, AI худаш ҳамаро ислоҳ мекунад
  2. Сатрҳои нофаҳморо нест кардан
  3. Нусхаи файлро нигоҳ доштан, то ки баргаштан имконпазир бошад
  4. Компютерро аз нав бор кардан

Нусха — соддатарин суғурта аст. Баъдтар онро Git иваз мекунад, вале одати «аввал корӣ-ро нигоҳ дор» то абад мемонад.

Бештар хонед: VS Code: асосҳои таҳрир (ҷустуҷӯ, печондан, форматкунӣ) (бо забони англисӣ).

05 DevTools дар 10 дақиқа: рентгени саҳифа

DevTools («абзорҳои барномасоз») дар Chrome ва Edge сохта шудаанд, насб кардан лозим нест. Онҳо нишон медиҳанд, ки ҳар саҳифа аз чӣ сохта шудааст, имкон медиҳанд онро муваққатан иваз кунед ва хатоҳоро доштаанд. Ин ёвари асосии шумост: вақте ки AI «чизи нодуруст» сохт, DevTools нишон медиҳанд, ки дақиқан чӣ шуд.

Чӣ тавр кушодан

  • Тугмаи рости муш бар ҷои даркории саҳифа → банди «Inspect» (дар интерфейси русӣ — «Просмотреть код» дар Chrome, дар Edge ном метавонад фарқ кунад). Панел бо унсури аллакай интихобшуда кушода мешавад.
  • Тугмаҳо: F12 ё Ctrl+Shift+I (Windows), Cmd+Option+I (Mac).
  • Бевосита Console: Ctrl+Shift+J (Windows), Cmd+Option+J (Mac).
  • Ҳолати «унсурро бо муш интихоб кун»: Ctrl+Shift+C (Windows), Cmd+Shift+C (Mac).

1. Elements: дидан ва муваққатан иваз кардан

  1. Унсурро интихоб кунед. Аломати «тир дар мураббаъ» (1) ё Ctrl+Shift+C-ро пахш кунед ва курсорро ба саҳифа баред: блокҳо равшан мешаванд. Ба блоки даркорӣ клик кунед ва он дар дарахти тегҳо (5) ҷудо мешавад.
  2. Услубҳоро бинед. Дар минтақаи Styles (6) ҳамаи қоидаҳои CSS-ро мебинед, ки ба унсур амал мекунанд, ва файл бо сатре, ки онҳо аз он ҷо омадаанд. Сатр бо хато дар номи хосият бо аломати огоҳӣ қайд шудааст.
  3. Иваз кунед. Ба қимат (масалан, ранг) клик кунед ва дигареро ворид намоед, Enter-ро пахш кунед. Саҳифа дарҳол тағйир меёбад. Байрақча дар тарафи чапи сатр қоидаро муваққатан хомӯш мекунад: барои санҷидани «агар он набошад, чӣ мешавад» қулай аст.
  4. Ёфтаро нусха кунед. Қимати писандшударо ба файли худ дар VS Code гузаронед ва захира кунед.
Асосӣ дар бораи DevTools

Ислоҳҳо дар DevTools муваққатӣ мебошанд: онҳо танҳо нусхаи саҳифаро дар браузери шумо иваз мекунанд. Саҳифаро нав кунед — ҳама чиз мисли пештара мегардад, ва файли шумо дар VS Code умуман тағйир наёфтааст. Агар қимати хубро ёфтед, онро бо даст ба код гузаронед.

2. Ҳолати дастгоҳ: саҳифа бо чашми телефон

Аломати «телефон ва планшет» (2) ё Ctrl+Shift+M (дар Mac Cmd+Shift+M)-ро пахш кунед. Саҳифа то андозаи экрани телефон танг мешавад. Дар боло метавон модели тайёрро интихоб кард ё сарҳадро кашида, паҳноиро иваз намуд. Бо ин роҳ шумо ҳамон чизро месанҷед, ки дар дарси 2 ҳарф мезадем: оё матн аз канор набаромадааст, оё блокҳо ба ҳам напечидаанд, оё тугмаҳо ҷо мешаванд. Ин тақрибӣ аст: телефони воқеиро ҳам кушодан фоидаовар аст.

3. Console: хатоҳои сурх

Варақаи Console (4) — «рӯзнома»-и саҳифа аст. Агар дар код хато дар JavaScript бошад (дар дарсҳои 7–8 он дар лоиҳаҳо пайдо мешавад), браузер онро дар ин ҷо бо рангӣ сурх менависад. Хато содда хонда мешавад: чӣ шуд, дар кадом файл ва кадом сатр. Айнан ҳамин матнро бояд ҳамроҳи код ба AI нусха кард.

Uncaught ReferenceError: nosuchthing is not defined
    at <anonymous>:1:1

Тарҷума мекунем: «истинод ба номи вуҷуд надошта nosuchthing». Худатон кӯшиш кунед: Console-ро кушоед, nosuchthing()-ро ворид кунед ва Enter-ро пахш намоед. Сатри сурх — муқаррарӣ аст, аксари хатоҳо ҳамин тавр менамоянд. Хатоҳои имлоӣ дар HTML ва CSS ба Console намеафтанд: онҳоро дар варақаи Elements ҷустан лозим, ба дарахт ва сатрҳои Styles нигариста. Сатрҳои зард — огоҳиҳо ҳастанд, онҳо муҳим нестанд.

Видео бо забони русӣ (тақрибан 21 дақиқа): шарҳи DevTools. Қисмҳои оид ба Elements, Styles ва Console-ро тамошо кунед, боқиро гузаронидан мумкин. Номи тугмаҳо дар версияҳои нави Chrome метавонад андаке фарқ кунад — ба маъно такя кунед.

Монандӣ аз ҳаёт

DevTools — ҳам рентген, ҳам ҳуҷраи андозагирӣ. Рентген нишон медиҳад, ки саҳифа аз кадом устухонҳо (тегҳо) сохта шудааст. Ҳуҷраи андозагирӣ имкон медиҳад ранг ва фосилаи дигарро санҷед, бе харидани матоъ, яъне бе даст задан ба файл. Мувофиқ наомад — баромадед ва ҳама чиз ба ҷои худ баргашт.

Хатогиҳои маъмули навомӯзон

1. Дар DevTools таҳрир кардан ва ислоҳро ба файл гузарондан фаромӯш кардан. 2. Гумон кардан, ки сатрҳои сурх дар Console «ҳеҷ гоҳ набояд бошанд»: саҳифаи таълимӣ бе JavaScript умуман ба Console чизе наменависад, хато дар ҳар саҳифаи зинда мешавад. 09 Вазифаи хонагӣ: лендинги клуби фитнес ва 5 ислоҳи дастӣ

Лендинги клуби фитнесро бо ёрии AI созед, баъд 5 ислоҳро бо дастон, бе AI иҷро кунед. Ба ин восита шумо ба худатон (ва санҷишгар) исбот мекунед, ки хондан ва ислоҳ кардани кодро медонед, на танҳо дархости онро.

Чӣ кор кардан лозим

  1. Ҷузвдони fitness-ро созед ва дар он файли index.html (дар паҳлӯи my-site аз дарси 1).
  2. Лендингро тавассути AI созед. Формулаи промптро аз дарси 2 истифода баред. Дар саҳифа бояд бошанд: сарлавҳа бо номи клуб ва меню, экрани асосӣ бо тугмаи сабт, блоки «Программы» (3 корт), блоки «Тренеры» (3 корт), блоки «Цены» (3 тариф) ва тамосҳо. Як файл, услубҳо дар дохил, бе тасвирҳо аз интернет. Қолаби промпт дар зер.
  3. Нусхаро нигоҳ доред index-ai.html — ин нусхаи «чунон ки AI дод».
  4. Айнан 5 ислоҳро бо дастон иҷро кунед, бе AI. Шумо худатон онҳоро аз рӯйхати поён интихоб мекунед. Ҳар ислоҳро дар index.html иҷро кунед ва дар браузер санҷед.
  5. Ислоҳҳоро қайд кунед дар файли матнии changes.txt: рақам, чӣ иваз кардед, дар кадом ҷо (тег ё қоидаи CSS), чӣ тавр санҷидед. Мисол: «1. Ранги тугма аз сабз ба норанҷӣ. Қоидаи CSS .btn, хосияти background. Саҳифаро дар браузер нав кардам».
  6. Санҷед саҳифаро дар ҳолати дастгоҳ (DevTools) ва ду скриншот гиред: оддӣ ва телефонӣ.
  7. Ҷузвдони fitness-ро ба бойгонӣ ҷамъ кунед (мисли дарси 1) ва ба чати гурӯҳ фиристед: бойгонӣ, ду скриншот ва changes.txt.

Блоки «Программы» — 3 корт (ном, 1–2 ҷумла, давомнокӣ). Блоки «Тренеры» — 3 корт (ном, ихтисос, матни кӯтоҳ; ба ҷои акс доираи рангин бо ҳарфҳои аввал). Блоки «Цены» — 3 тариф. Тамосҳо: суроға, телефони пуркунанда, тугмаи «Позвонить». Маҳдудиятҳо: як файли index.html, CSS дар дохил дар блоки style, бе китобхонаҳои беруна ва тасвирҳо. Синфҳои бо номҳои фаҳмо (card, btn, section), тағйирёбандаҳои CSS барои рангҳо ва Flexbox/Grid барои тарҳбандӣ истифода шаванд. Дар телефон хуб намоён бошад (сутунҳо ба як сутун мубаддал шаванд). Матнҳоро худат пеша кун, забони русӣ. Шакли ҷавоб: файли пурра дар як блок, баъд 5 шарҳи кӯтоҳ: кадом қисмҳои файл барои чӣ масъуланд. Санҷиш: боварӣ ҳосил кун, ки ҳамаи истинодҳо href доранд, ҳамаи тасвирҳо (агар бошанд) alt доранд, ва дар аввали файл <meta charset="UTF-8"> ҳаст.

  • сарлавҳа ва зерсарлавҳаи экрани асосиро аз нав навиштан;
  • ду блокро иваз кардан (масалан, «Тренеры» ва «Цены»);
  • фосилаҳоро байни блокҳо ё дар дохили кортҳо иваз кардан;

Скриншотҳо паҳнои телефонро нишон намедиҳанд. 5. Ба ҷои пуркунандаҳо дар тамосҳо маълумоти шахсӣ.

ВАЗИФАИ 9.2

Бонус: лендингро дар интернет нашр кунед

душвор

Ихтиёрӣ: app.netlify.com/drop-ро кушоед, ҷузвдони fitness-ро ба тиреза кашед ва истинодро дар зер гузоред. Агар хизмат аккаунти ройгон пешниҳод кунад, то ки сайт нест нашавад, розӣ шавед. Нашри пурраро дар дарси 5 таҳлил мекунем.

✓ Хулосаи дарс

  • Саҳифа — дарахти тегҳо: html → head ва body → header, main, footer → блокҳо ва унсурҳо.
  • Тегҳо: div ва section — қуттиҳо, button — тугма, input — майдон (type), img — тасвир (src + alt), a — истинод (href). img ва input бе теги пӯшанда.
  • Синф — барчасп дар теги; дар CSS ба он қоида бо нуқта мувофиқ меояд: .btn { … }. #id дар саҳифа якто аст.
  • Қуттӣ: margin (беруна) → border → padding (дарун) → content.
  • Хосиятҳои маъмул: color, background, font-size, padding, margin, border-radius.
  • Flexbox — як хат: display: flex, gap, justify-content, align-items. Grid — тӯр: display: grid, grid-template-columns: repeat(3, 1fr), gap.
  • Хондани коди AI: ба фосилаҳо нигаристан, блокҳоро печондан, аз рӯи матн ҷустан (Ctrl+F), аз синф ба қоида рафтан, пеш аз ислоҳ нусхаи файл гирифтан.
  • DevTools: F12 ё Cmd+Option+I; Elements — дидан ва муваққатан иваз кардани услуб; ҳолати дастгоҳ — телефон; Console — хатоҳои сурх. Ислоҳҳо муваққатианд: онҳоро ба файл гузаронед.
  • Хатоҳои маъмул: теги пӯшида нашуда, хатои имлоӣ дар синф ё хосият, нуқта ё ;-и гузашта, ранги матн ва замина якхела, тасвир бе alt, ҳарфи майда, тартиби нодурусти блокҳо.
  • Промпт барои ислоҳ: аломат → интизорӣ → «ислоҳи ҳадди ақал, боқиро нагир» → рӯйхати тағйирот («буд → шуд → чаро») ва файли пурра.
ВАЗИФАИ 10.1

Ман мавзӯъро воқеан фаҳмидам

осон

Танҳо он чизеро қайд кунед, ки бе маслиҳат иҷро карда метавонед.

  • Метавонам шарҳ диҳам, ки div, section, button, input, img ва a аз ҳам чӣ фарқ доранд
  • Метавонам аз рӯи код бифаҳмам, ки унсур кадом синф дорад, ва қоидаи CSS-и онро ёбам
  • Метавонам ранг, фосила ва тартиби блокҳоро бо дастон иваз кунам
  • Мефаҳмам, ки display: flex ва display: grid чӣ тавр кор мекунанд, ва метавонам онҳоро фаъол кунам
  • Метавонам DevTools-ро кушоям, унсурро бубинам, услубро муваққатан иваз кунам ва саҳифаро дар ҳолати телефон санҷам
  • Метавонам хатои сурхро дар Console бихонам ва мефаҳмам, ки бо он чӣ кор кардан лозим
  • Метавонам промпт барои ислоҳи код тартиб диҳам ва санҷам, ки AI дақиқан чиро иваз кард
