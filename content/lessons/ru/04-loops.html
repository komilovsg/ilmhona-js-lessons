01 Зачем нужны циклы. Цикл while

Представьте, что вы встречаете пятерых гостей на пороге Ilmhona. Без циклов код выглядит так:

console.log("Гость №1, добро пожаловать!");
console.log("Гость №2, добро пожаловать!");
console.log("Гость №3, добро пожаловать!");
console.log("Гость №4, добро пожаловать!");
console.log("Гость №5, добро пожаловать!");

Пять строк — ещё терпимо. А если гостей 500? А если их число заранее неизвестно? Здесь и приходит на помощь цикл — конструкция, которая повторяет блок кода, пока выполняется условие. Самый простой цикл — while («пока»):

let i = 1;                 // 1. старт: счётчик начинается с 1
while (i <= 5) {           // 2. условие: повторяем, пока оно true
  console.log(`Гость №${i}, добро пожаловать!`);
  i++;                     // 3. шаг: меняем счётчик
}
console.log("Все гости встречены");
Аналогия из жизни

Вы раздаёте оши палав на свадьбе. Правило простое: пока в казане есть плов — накладываем ещё одну тарелку. Перед каждой тарелкой вы заглядываете в казан (проверяете условие). Плов есть — накладываете (выполняете тело). Казан пуст — закончили. Сколько будет тарелок, вы заранее не знаете: это зависит от казана.

Как работает while — по шагам

  1. Проверка условия. JavaScript вычисляет выражение в скобках после while. Это то же самое выражение, что и в if: true или false.
  2. Если true — выполняется всё, что в фигурных скобках. Это тело цикла.
  3. Возврат к шагу 1. Дошли до закрывающей скобки — снова проверяем условие.
  4. Если false — цикл заканчивается, программа идёт дальше, к строке после }.

Напоминание: короткие записи

i++ — то же самое, что i = i + 1. i-- — уменьшить на 1. i += 2 — прибавить 2, money -= 6 — вычесть 6. Эти записи мы будем встречать в каждом цикле.

while, когда число кругов заранее неизвестно

Главная сила while — ситуации «делай, пока не случится что-то». Например, пока хватает денег на чай:

let money = 20;          // сомони в кошельке
const teaPrice = 6;      // цена чайника чая

while (money >= teaPrice) {
  money -= teaPrice;
  console.log(`Выпили чай. Осталось: ${money} сомони`);
}
console.log("Денег на чай больше нет");

Сколько чайников получится — заранее не видно, цикл сам посчитал. Если же число повторений известно сразу («ровно 5 гостей»), удобнее другая запись — for, о ней в следующем разделе.

Частые ошибки

1. Если условие ложно с самого начала, тело не выполнится ни разу — и это нормально, просто ничего не выведется. 2. Если забыть изменить счётчик (i++), условие навсегда останется истинным и цикл будет вращаться вечно — это бесконечный цикл. Мы разберём его отдельно в разделе 08, не пугайтесь.

let n = 10;
while (n < 5) {
  console.log("Сюда мы не попадём");
  n++;
}
console.log("Конец, n =", n);   // → Конец, n = 10

02 Цикл for

В цикле while три важные части — старт, условие и шаг — разбросаны по коду: старт выше цикла, шаг в конце тела. Легко что-то забыть. Цикл for собирает всё это в одну строку:

for (let i = 1; i <= 5; i++) {
  console.log(`Гость №${i}, добро пожаловать!`);
}

Результат тот же, что у while в прошлом разделе, но кода меньше и все три части видны сразу.

Аналогия из жизни

Маршрутка №8 едет по остановкам. Заголовок for — это ответ на три вопроса: на какой остановке сел (let i = 1), до какой едешь (i <= 5) и как едешь — по одной остановке или через одну (i++). Тело цикла — то, что ты делаешь на каждой остановке: смотришь в окно, выходишь, оплачиваешь.

В каком порядке всё выполняется

  1. Старт let i = 1 выполняется один раз, самым первым.
  2. Условие i <= 5 проверяется перед каждым кругом. false — выход из цикла.
  3. Тело выполняется целиком.
  4. Шаг i++ выполняется после тела. Затем снова шаг 2.

Разные варианты заголовка

Меняя три части, можно считать как угодно: с нуля, с шагом, назад.

Совет: while или for?

Знаете заранее, сколько кругов («5 гостей», «от 1 до 100») — берите for. Крутиться нужно «пока не случится что-то» (хватает денег, не закончился ввод) — берите while. Любой for можно переписать на while и наоборот: это вопрос удобства.

Ловушка: на единицу ошибся

Самая частая ошибка в циклах — «ошибка на единицу» (off-by-one). Разница между i < 5 и i <= 5 — это целый лишний круг. Если считаете с нуля, пишите <; если с единицы — <=. И всегда проверяйте первое и последнее значение.

for (let i = 1; i < 5; i++) {
  console.log(`Урок ${i}`);   // 5-й урок потерялся!
}

Переменная цикла живёт только внутри

for (let i = 1; i <= 3; i++) {
  console.log(i);
}
console.log(i);   // ✖ i не существует вне цикла

Это нормально и даже удобно: каждый цикл имеет собственную i, и циклы друг другу не мешают. Если значение нужно после цикла, объявляйте переменную до него. Почему так устроено — расскажем на уроке про функции.

03 Цикл do..while

У while есть брат-близнец: do..while («делай, пока»). Разница одна, но важная: условие проверяется после тела, поэтому тело выполнится минимум один раз, даже если условие ложно с самого начала.

let attempt = 0;

do {
  attempt++;
  console.log(`Попытка входа №${attempt}`);
} while (attempt < 3);

Обратите внимание на точку с запятой после while (…) — в do..while она нужна. Теперь сравните оба цикла, когда условие ложно сразу:

let cups = 0;

while (cups > 0) {
  console.log("while: тело выполнилось");
}

do {
  console.log("do..while: тело выполнилось");
} while (cups > 0);
Аналогия из жизни

В чайхане чайник с чаем приносят сразу, не спрашивая, а потом интересуются: «Ещё?». Это do..while: сначала действие, потом вопрос. В другом заведении сперва спросят: «Принести чай?» — и только после «да» принесут. Это while: сначала проверка, потом действие.

04 break и continue

Иногда цикл нужно прервать раньше срока или пропустить один круг. Для этого есть два слова.

  • break — выйти из цикла совсем. Программа продолжается со строки после цикла.
  • continue — пропустить остаток текущего круга и перейти к следующему.
for (let i = 1; i <= 10; i++) {
  if (i === 4) {
    console.log("Нашли нужную остановку! Выходим");
    break;
  }
  console.log(`Проезжаем остановку №${i}`);
}
console.log("Цикл закончился");
Аналогия из жизни

Вы ищете свободный стол в чайхане и идёте вдоль рядов. Нашли — break: дальше не ищете, садитесь. А continue — это «этот стол занят, не останавливаюсь, иду к следующему». Поиск продолжается, но один стол вы просто пропустили.

Остаток от деления: оператор %

Для примера с continue нам понадобится оператор % — остаток от деления. 7 % 3 — это остаток от деления 7 на 3, то есть 1. Число чётное, если остаток от деления на 2 равен нулю.

console.log(7 % 3);    // → 1   (7 = 3 + 3 + остаток 1)
console.log(10 % 5);   // → 0   (делится нацело)
console.log(9 % 2);    // → 1   (нечётное)
console.log(8 % 2);    // → 0   (чётное)

for (let i = 1; i <= 8; i++) {
  if (i % 2 === 0) {
    continue;           // чётные пропускаем
  }
  console.log(`Нечётное число: ${i}`);
}

Приём: while (true) и break

Бывает, что заранее непонятно, когда остановиться. Тогда пишут условие true (цикл «навсегда») и выходят через break, когда пришло время. Это единственный случай, когда «вечный» цикл — осознанный, потому что выход у него предусмотрен.

let n = 1;
while (true) {
  n *= 2;               // удваиваем
  console.log(n);
  if (n > 50) {
    break;              // выход предусмотрен
  }
}
console.log("Остановились на", n);
Ловушка: continue в while

В for шаг i++ выполняется сам. А в while он стоит в теле — и если continue сработает раньше него, счётчик не изменится, условие останется истинным, цикл зависнет. Этот код запускать не нужно:

let i = 0;
while (i < 5) {

05 Перебор строки: for..of

Цикл можно запускать не только по числам, но и по буквам строки. Для этого есть удобная форма for..of («для каждого … из …»):

for (const letter of "Душанбе") {
  console.log(letter);
}

На каждом круге в переменную letter попадает следующая буква. Не нужно ни счётчика, ни условия, ни шага — JavaScript сам дойдёт до конца строки. Пишем const, потому что на каждом круге создаётся новая переменная, а внутри круга мы её не меняем.

Аналогия из жизни

Тасбех (чётки): вы перебираете бусины по одной, от первой до последней. for..of — «для каждой бусины делай то-то». Вам не важно, какая она по номеру, вы просто берёте следующую, пока нить не закончится.

Тот же перебор через обычный for

Каждая буква в строке имеет номер — индекс. Нумерация начинается с нуля. Получить букву по номеру можно через квадратные скобки: city[0]. Количество букв хранится в city.length. Поэтому последний индекс — length - 1.

const city = "Хорог";
console.log(city.length);   // → 5
console.log(city[0]);       // → Х
console.log(city[4]);       // → г

for (let i = 0; i < city.length; i++) {
  console.log(`${i}: ${city[i]}`);
}

Когда нужен только сам символ — берём for..of, это проще. Когда нужен ещё и номер (например, сравнить первую и последнюю букву) — берём обычный for с индексом.

Типичные задачи на строки

Посчитать, сколько раз встречается буква:

const word = "самбуса";
let count = 0;
for (const ch of word) {
  if (ch === "с") {
    count++;
  }
}
console.log(`Букв «с»: ${count}`);   // → Букв «с»: 2

Собрать новую строку — например, перевернуть слово. Каждую новую букву приписываем слева к уже собранному:

let reversed = "";
for (const ch of "оши") {
  reversed = ch + reversed;
  console.log(`взяли «${ch}» → ${reversed}`);
}
console.log(reversed);   // → ишо

А что с массивами? Маленький взгляд вперёд

Точно так же for..of умеет перебирать список значений — он называется массив и записывается в квадратных скобках. Массивам посвящён весь следующий урок, а пока просто посмотрите — форма цикла та же:

for (const dish of ["плов", "самбуса", "курутоб"]) {
  console.log(`В меню: ${dish}`);
}

06 Счётчики и накопители

Почти любой цикл в реальной программе что-то накапливает: общую сумму чека, число подходящих товаров, самую высокую цену, итоговую строку. Для этого есть универсальный приём:

  1. До цикла заводим переменную с начальным значением (накопитель).
  2. В теле цикла обновляем её на каждом круге.
  3. После цикла используем итог.
Аналогия из жизни

Касса в магазине на Зелёном базаре. Утром в ней 0 сомони — это старт. Каждый покупатель кладёт деньги — это тело цикла. Вечером кассир подсчитывает итог — это код после цикла. Касса не обнуляется после каждого покупателя: иначе вечером вы увидели бы только деньги последнего.

Произведение

Для умножения старт — единица: ноль «съест» всё произведение. Факториал числа (4! = 1 · 2 · 3 · 4) — классика:

Ловушки накопителей

1. Накопитель объявлен внутри цикла — на каждом круге он обнуляется. 2. Неверный старт: для суммы 0, для произведения 1. 3. Накопитель выводится внутри цикла, а нужен только итог — тогда строк на экране слишком много.

07 Вложенные циклы

Внутри цикла может быть другой цикл. Это называется вложенными циклами. Они нужны везде, где есть «двойной» перебор: дни и пары в расписании, строки и столбцы в таблице, ряды и места в зале.

for (let day = 1; day <= 2; day++) {
  for (let lesson = 1; lesson <= 3; lesson++) {
    console.log(`День ${day}, пара ${lesson}`);
  }
}
Аналогия из жизни

Часы. Часовая стрелка делает один шаг, а минутная за это время обходит весь циферблат — 60 шагов. Внешний цикл — часовая стрелка, внутренний — минутная. Пока внешний делает один круг, внутренний успевает пройти все свои круги от начала до конца.

Как это выполняется

  1. Внешний цикл начинает круг: day = 1.
  2. Внутренний цикл запускается с самого начала и проходит все свои круги: lesson = 1, 2, 3.
  3. Внутренний закончился. Внешний делает шаг: day = 2.
  4. Внутренний снова запускается с нуля и снова проходит все круги.

Всего тело внутреннего цикла выполнилось 2 × 3 = 6 раз. Правило: число выполнений тела = круги внешнего × круги внутреннего.

Рисуем фигуры

console.log всегда переводит строку, поэтому нарисовать ряд символов в одной строке напрямую нельзя. Решение — собрать всю строку в накопитель внутренним циклом, а вывести её после внутреннего цикла:

for (let row = 1; row <= 3; row++) {
  let line = "";                       // новая пустая строка для каждой строки
  for (let col = 1; col <= 5; col++) {
    line += "*";
  }
  console.log(line);                   // выводим готовую строку
}

Чтобы получить треугольник, достаточно, чтобы внутренний цикл зависел от внешнего: в строке номер row — ровно row символов.

for (let row = 1; row <= 4; row++) {
  let line = "";
  for (let col = 1; col <= row; col++) {
    line += "#";
  }
  console.log(line);
}

И, наконец, таблица умножения: в клетке стоит произведение номера строки и номера столбца.

for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 3; col++) {
    line += row * col + " ";
  }
  console.log(line);
}
Ловушки вложенных циклов

1. Накопитель строки нужно обнулять для каждой строки — то есть объявлять между внешним и внутренним циклом, как let line = "" выше. 2. Не называйте обе переменные одинаково: используйте i и j или понятные row и col. 3. break выходит только из внутреннего цикла — внешний продолжает работать.

for (let day = 1; day <= 3; day++) {
  for (let lesson = 1; lesson <= 3; lesson++) {
    if (day === 2 && lesson === 2) {
      break;            // прервали только пары второго дня
    }
    console.log(`День ${day}, пара ${lesson}`);
  }
}
Совет: сколько это работает

Вложенный цикл 1000 × 1000 — это миллион выполнений тела, компьютер справляется за долю секунды. Но тройной цикл на 10 000 × 10 000 × 10 000 уже может «подвесить» страницу. Чем глубже вложенность, тем осторожнее нужно быть.

08 Бесконечный цикл: как не зависнуть

Цикл остановится, только если его условие когда-нибудь станет false. Если условие всегда истинно, цикл не закончится никогда. Это бесконечный цикл, и это самая известная ошибка начинающих (и не только) программистов. Страница с таким циклом «зависает»: кнопки не нажимаются, вкладка не отвечает.

Аналогия из жизни

Таксист включил счётчик и забыл его выключить. Пассажир давно вышел, а цифры продолжают расти — и так, пока кто-то не остановит машину. Цикл без изменяемого счётчика — такое же «забытое» такси.

Как это выглядит на нашей странице

Раннер на этой странице защищён: если код «молчит» дольше нескольких секунд, он принудительно останавливается и пишет красное сообщение. Нажмите ▶ Запустить и подождите примерно три секунды:

let i = 1;
while (i <= 5) {
  // забыли написать i++ — условие всегда true
}
console.log("Эта строка никогда не выполнится");

Вы увидите сообщение ⏱ Код выполняется слишком долго (возможен бесконечный цикл). Это страховка только нашей страницы. В обычной программе или на реальном сайте такой подстраховки нет, и всё просто зависнет.

Откуда берутся бесконечные циклы

Три вопроса перед запуском цикла

  1. Что меняется на каждом круге? Должна меняться переменная из условия.
  2. В какую сторону она меняется? К границе условия, а не от неё.
  3. Может ли условие стать false? Подставьте 2–3 значения и проверьте руками.

Предохранитель: цикл, который не может зависнуть

Когда пишете цикл с нетривиальным условием, добавьте счётчик кругов и ограничьте его. Если что-то пойдёт не так — цикл сам выйдет, и вы увидите это в консоли, а не получите зависшую страницу:

let money = 18;
let rounds = 0;

while (money > 0) {
  rounds++;
  if (rounds > 100) {          // предохранитель
    console.log("Аварийная остановка: слишком много кругов");
    break;
  }
  money -= 6;                  // уменьшаем деньги на 6
}
console.log(`Кругов: ${rounds}, денег: ${money}`);
Что делать, если зависло

В браузере: закройте вкладку (иногда браузер сам предлагает остановить страницу). В терминале при запуске node: нажмите Ctrl + C. В обоих случаях — найдите цикл и ответьте на три вопроса выше.

09 ИИ-блок: объяснить чужой код построчно

В работе вы почти никогда не пишете код с нуля: чаще читаете то, что написал коллега, нашли в интернете или выдал ИИ. Умение разобрать чужой цикл — один из главных навыков. ИИ здесь отличный помощник, если просить правильно: не «реши», а «объясни, как новичку».

Правила курса про ИИ — напоминаем

1) Сначала 15 минут пробуете разобраться сами: выпишите, чему равны переменные на первых трёх кругах. 2) Не вставляете код, который не можете объяснить строчка за строчкой. 3) В промпте всегда: контекст → задача → ограничения → формат ответа → проверка.

Возьмём чужой код

Допустим, коллега прислал такую программу. Что она делает?

let total = 0;

  if (n % 2 === 0) continue;
  total += n;
}
console.log(total);

Слабый и сильный запрос

объясни код
Контекст: я новичок в JavaScript. Знаю переменные, типы, условия if и циклы for/while. Функций и массивов пока не знаю. Задача: объясни, как новичку, что делает этот код: [код] Ограничения: не переписывай код. Если встретится незнакомое слово, объясни его простыми словами в одну строку. Формат ответа: таблица «строка кода → что делает». Потом — значения переменных после каждого из первых трёх кругов цикла. В конце одно предложение: что делает вся программа. Проверка: назови одно изменение, которое поменяет результат, и скажи, что получится.

Как проверить объяснение ИИ

ИИ может объяснять уверенно — и ошибаться. Поэтому ответ всегда проверяется по трём шагам:

  1. Запустите код и запишите настоящий вывод в консоли.
  2. Сравните с тем, что «сказал» ИИ. Не совпало — ИИ ошибся, верьте консоли.
  3. Добавьте трассировку: console.log внутри цикла, который печатает счётчик и накопитель на каждом круге. Так вы видите весь путь, а не только результат.

Ещё два шаблона для тренировки

Из библиотеки промптов курса: попросить объяснить построчно без переписывания и попросить задачи без готовых решений.

Вот код: [код]. Объясни построчно, что происходит и почему результат такой. Не переписывай код — только объясни.

Проверка ответа: убедитесь, что задачи по теме и в ответе нет готового кода решения. Решения вы ищете сами.

Напоминание

✓ Шпаргалка урока

  • Цикл повторяет блок кода. Один проход — итерация. Условие проверяется перед каждым кругом.
  • while: while (условие) { … } — когда число кругов неизвестно. Счётчик нужно менять в теле.
  • for: for (старт; условие; шаг) { … } — когда число кругов известно. Порядок: старт (один раз) → условие → тело → шаг → условие…
  • do..while: do { … } while (условие); — тело выполнится минимум один раз, условие проверяется после.
  • break выходит из цикла совсем, continue пропускает остаток круга. Внутри вложенных циклов break выходит только из внутреннего.
  • for..of по строке: for (const ch of "текст"). Нужен номер буквы — for с text[i] и text.length. Индексы с нуля, последний — length - 1. Строку «по месту» не изменить — собираем новую.
  • Накопители: сумма — старт 0, произведение — старт 1, счётчик — count++ по условию, максимум — if (x > best), строка — line += …. Объявляем до цикла.
  • Вложенные циклы: тело внутреннего выполняется «круги внешнего × круги внутреннего» раз. Строку для рисунка собираем внутренним циклом и выводим после него. Накопитель строки — внутри внешнего цикла.
  • Остаток от деления %: x % 2 === 0 — чётное, x % 3 === 0 — кратно 3.
  • Бесконечный цикл: условие всегда true. Причины — забыли менять счётчик, меняем не в ту сторону, continue до шага, нет break у while (true). Три вопроса перед запуском: что меняется, в какую сторону, может ли условие стать false. Помогает предохранитель — счётчик кругов с break.
  • С ИИ: чужой код — «объясни как новичку, построчно, покажи значения на первых кругах, не переписывай». Ответ всегда проверяйте запуском и трассировкой console.log.
