React: барои чӣ лозим аст. Vite, JSX ва компоненти аввал

Дар дарси 11 Шумо render(state)-ро навиштед, ки экранро аз рӯи маълумот аз нав мекашад. Ин ғояи дуруст аст, аммо кодҳои гирду атрофи он бисёранд: унсурро ёфтан, эҷод кардан, пур кардан, ҷойгир кардан, нав карданро фаромӯш накардан. React ин корро ба зимма мегирад: Шумо тавсиф мекунед, ки дар экран чӣ бояд бошад, ва он чӣ тавр расидан ба инро худаш ҳал мекунад. Имрӯз Шумо мебинед, ки чаро сайтҳои калон ин тавр мекунанд, лоиҳаро дар Vite месозед ва саҳифаро аз компонентҳо ҷамъ мекунед.

  • Номбар кардан, ки DOM-и дастӣ чӣ тавр ба рушди барнома халал мерасонад, ва як интерфейси ҳамонро бо JS-и тоза ва бо React муқоиса кардан
  • Саҳифаро ба компонентҳо тақсим кардан ва ба онҳо номҳои дуруст додан
  • Лоиҳаро бо фармони npm create vite@latest -- --template react сохтан ва сохтори онро хондан
  • JSX навиштан ва донистан, ки он аз HTML чӣ фарқ дорад: className, htmlFor, тегҳои пӯшида, як реша, {…}, style={{…}}
  • Компонентҳоро эълон кардан, содир (export) кардан ва дар App.jsx ворид (import) кардан
  • Аз ЗС хостан, ки блоки шиноси JS-ро ба React аз нав нависад, ва ҷавобро сатр ба сатр таҳлил кардан
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Мисолҳои React дар қуттии регӣ бо пешнамоиш кушода мешаванд: ҷадвали App.jsx бо код, дар зери он — саҳифаи тайёр ва консол. Кодро тағйир диҳед ва ▶ Иҷро кардан (ё Ctrl + Enter)-ро пахш кунед. React аз интернет бор мешавад, бинобар ин дастрасӣ ба шабака лозим аст. Дар қуттии регӣ як файл ҳаст — компонентҳо дар паҳлуи якдигар ҷойгиранд; дар лоиҳаи воқеии Vite ҳар кадом дар файли алоҳида мешавад. Сатри setTimeout(() => console.log(…), 100) дар поёни мисолҳо — санҷиши худкори хидматӣ аст: он HTML-ро, ки React сохтааст, ба консол чоп мекунад, то вазифаро санҷидан мумкин бошад. Дар вазифаҳо онро нест накунед; дар лоиҳаи оддӣ он лозим нест. Блокҳо бо сарлавҳаи «Терминал» ва номи файл — ин фармонҳо ва файлҳо барои компютери Шумо ҳастанд, онҳо тугмаи оғоз надоранд.

01 Барои чӣ React: DOM-и дастӣ аз куҷо халал мерасонад

Ҳар чизе, ки Шумо то ҳол бо экран мекардед, — ин равиши императивӣ аст: Шумо ба браузер қадам ба қадам фармон медиҳед. «Ин унсурро ёб. Нав эҷод кун. Матнро ба он сабт кун. Ин ҷо ҷойгир кун». Барои корт бо сарлавҳа ин чунин менамояд:

Дар консоли ҳарду қуттии регӣ — як аломатгузории ҳамонанд. Фарқ дар он аст, ки Шумо ба он чӣ тавр расидед: дар ҳолати аввал 12 сатри фармон, дар дуюм — «тасвир»-и он чӣ лозим аст.

Монанд аз ҳаёт

Чойхона. DOM-и дастӣ — ин вақте аст, ки Шумо худатон ба ошхона меравед ва ба ошпаз мегӯед: «Қазонро гир. Равғанро резон. Пиёзро андоз. Пас аз панҷ дақиқа сабзиро илова кун…» Барои ҳар палав — тамоми дастур аз нав. React — ин вақте аст, ки Шумо ба пешхизмат мегӯед: «Палав ва чой барои ду нафар». Дар ошхона чӣ ва бо кадом тартиб кардан — ташвиши муассиса аст. Шумо натиҷа-ро тавсиф мекунед (ин чунин номида мешавад — равиши декларативӣ), на қадамҳоро.

Чор дарди DOM-и дастӣ

1. Аломатгузорӣ намоён нест
Сохтори саҳифа дар паси даҳҳо createElement ва append пинҳон аст. Барои фаҳмидани он ки чӣ мешавад, бояд кодро дар зеҳн «иҷро» кард.
2. Нав кардан осон фаромӯш мешавад
Як маълумот дар якчанд ҷой нишон дода мешавад. Дар як ҷо тағйир додед — дар ҷои дигар кӯҳна монд, ва экран дурӯғ мегӯяд.
3. «Тегҳои худӣ» нестанд
Корти курс дар даҳ ҷо лозим аст — функсияҳои корхона навиштан ва бо даст пайваст кардан лозим мешавад. Роҳи ягона барои гуфтан «ин блоки ман аст, онро мисли теги оддӣ истифода бар» нест.
4. Ҳолат ва экран аз ҳам мераванд
Дар дарси 11 Шумо инро бо функсияи render() ҳал кардед, ки экранро пурра аз нав месозад. Кор мекунад, аммо ҳангоми ҳар тағйирот браузер ҳама чизро аз нав эҷод мекунад — ва фокус дар майдони воридот, прокрутка ва интихоб гум мешаванд.

Дарди дуюмро зинда бинед. Нархи курс дар ду ҷой нишон дода шудааст, аммо танҳо дар як ҷо нав шудааст:

document.body.innerHTML = `
  <p>Курс: <b id="price-top">500</b> сомони</p>
  <p>Итого: <b id="price-total">500</b> сомони</p>`;

let price = 500;
price = 450; // тахфиф кардем

document.querySelector("#price-top").textContent = price;
// дар бораи #price-total фаромӯш кардем

console.log(document.querySelector("#price-top").textContent);
console.log(document.querySelector("#price-total").textContent);

Дар боло 450, дар «Итого» ҳанӯз 500. Дар саҳифаи хурд ин фавран намоён аст, дар барномаи калон бо сад экран — не. React чунин сохта шудааст, ки экран ҳамеша аз маълумот ҳисоб карда мешавад, ва «фаромӯш кардан»-и нав кардани ҷой чизе надорад.

React чист

React — китобхонаи сохтани интерфейсҳо аст, онро ширкати Meta (Facebook-и пешина) офаридааст, ва ҳоло он шояд маъмултарин дар ҷаҳон барои сайтҳо ва барномаҳо бошад. Ғояи асосӣ: интерфейс — функсия аз маълумот аст. Маълумот тағйир ёфт — React худаш «буд» ва «шуд»-ро муқоиса мекунад ва дар DOM танҳо он чизеро, ки лозим аст, иваз мекунад. Ҳама чизи дигар (масиррӯбиҳо, рендери серверӣ) алоҳида пайваст мешавад: дар сатҳи оянда Шумо бо Next.js вомехӯред — ин фреймворк дар асоси React аст.

React на ҳамеша лозим аст

Лендинг аз панҷ блок ва ду тугма бо HTML, CSS ва JS-и тоза хуб зиндагӣ мекунад — ва зудтар бор мешавад. React дар ҷое сарфа мекунад, ки экранҳои интерактивии зиёд ҳастанд, блокҳои якхела такрор мешаванд, ва маълумот зуд тағйир меёбад: кабинетҳои шахсӣ, мағозаҳо, дашбордҳо, чатҳо. Мо React-ро на ба ҷои JS, балки болои он меомӯзем: ҳар чизе, ки Шумо дар бораи функсияҳо, массивҳо ва объектҳо медонед, дар ҳар сатр муфид мешавад.

02 Бо компонентҳо фикр мекунем

Ҳар сайтеро кушоед ва дар зеҳн «хиштҳо»-ро бо чорчӯба иҳота кунед: сарлавҳа, меню, корти мол, тугма, поёнӣ. Ин худи компонентҳо ҳастанд. Компонент — функсияест, ки порчаи интерфейсро бармегардонад. Азбаски ин функсия аст, Шумо аллакай бо он муомила карда метавонед: як маротиба эълон кунед, ба қадри лозим даъват намоед.

Монанд аз ҳаёт

Конструктор ё маҷмӯи қолабҳо барои самбӯса. Як қолабро як маротиба сохтед — ва бо он ҳатто сад дона шаклдиҳӣ мекунед. Саҳифаи сайт як нони калон нест, балки маҷмӯи қисмҳои тайёр аст: сарлавҳа, рӯйхати курсҳо, поёнӣ. Лозим шуд, ки поёниро тағйир диҳед — дар як ҷо тағйир медиҳед, ва он дар ҳамаи саҳифаҳо нав мешавад.

Саҳифа — дарахт аст

Компонентҳо дар якдигар мисли қуттиҳои дарунгузашта ҷойгир мешаванд. Берунитарин — App, компоненти асосии барнома. Дар дохили он боқӣ ҷойгиранд:

App ├─ Header │ ├─ Logo │ └─ Nav ├─ Courses └─ Footer

Ҳудуди компонентҳоро чӣ тавр ёфтан

  • Блок такрор мешавад (корти курс, банди меню) — қариб ҳамеша ин компоненти алоҳида аст.
  • Блок вазифаи худро дорад («сарлавҳаро нишон деҳ», «поёниро нишон деҳ») — компоненти алоҳида, мисли функсияи алоҳида дар дарси 5.
  • Файл калон шуд, ва дар он чизи лозимиро ёфтан мушкил аст — ба қисмҳо мебурем.
  • То заррачаҳо бурида накунед. Теги <h2>-ро компонент кардан лозим нест. Қоидаи хуб: агар барои блок номи фаҳмо ихтироъ кардан мумкин бошад, он барои компонент ҳам мебарояд.

Компоненти аввал

Компонент мисли функсияи дарси 5 менамояд, танҳо он на рақам, балки аломатгузориро бармегардонад. Ду қоида: ном бо ҳарфи калон оғоз мешавад ва онро мисли теги истифода бурдан лозим аст:

function Header() {
  return (
    <header className="top">
      <h1>MakeFirstStep</h1>
    </header>
  );
}

function Footer() {
  return <footer>© MakeFirstStep, Душанбе</footer>;
}

export default function App() {
  return (
    <div className="page">
      <Header />
      <main>Здесь будут курсы</main>
      <Footer />
    </div>
  );
}

Ба се чиз диққат диҳед. <Header /> бо ҳарфи калон — ин компоненти мо аст: React функсияи Header-ро даъват мекунад ва натиҷаро ҷойгир менамояд. <main> бо ҳарфи хурд — теги оддии HTML. App ҳам компонент аст, танҳо аз ҳама асосӣ. Онро мо ҳамчун export default function App() менависем: маҳз онро қуттии регӣ (ва лоиҳаи Vite) дар саҳифа нишон медиҳад.

Хатои маъмул: ном бо ҳарфи хурд

React тегҳо ва компонентҳоро аз рӯи ҳарфи аввал фарқ мекунад. <header /> — ин теги HTML аст, ва <Header /> — функсияи Шумо. Агар компонентро header ё menu ном дода бошед, React функсияро намеёбад ва тегҳои холиро мекашад (ва <menu> умуман теги ҳақиқии HTML аст). Хато нест — танҳо холигӣ дар экран, ва ин аз ҳама нохушоянд аст.

04 JSX: ба HTML монанд, аммо HTML нест

JSX — ин роҳи навиштани аломатгузорӣ бевосита дар дохили JavaScript аст. Браузер JSX-ро намефаҳмад: Vite (ва дар қуттии регии мо — компилятори дарунсохт) ҳар тегро ба даъвати функсия табдил медиҳад. Барои Шумо ин маънои яктоиро дорад: JSX — ин JavaScript аст, пас қоидаҳояш аз HTML сахттаранд.

// Шумо менависед:

Монанд аз ҳаёт

JSX — аризаи расмӣ: ҳар таг пӯшида, ҳуҷҷат як сарлавҳа дорад, ҳамаи калимаҳо дар шакли лозимӣ. Аммо ариза худкор санҷида мешавад. Бинобар ин JSX дар бораи ғалатии имло фавран шикоят мекунад, ва браузер хомӯшона «тахмин мекунад».

05 App.jsx: содир ва ворид кардани компонентҳо

То ҳол компонентҳо дар як файл меистоданд. Дар лоиҳаи воқеӣ ин тавр намекунанд: як компонент — як файл. Ин ҳамон модулҳои дарси 17 аст: як файл функсияро содир мекунад, файли дигар онро ворид мекунад. Барои компонентҳо export default маъмул аст.

Сохтори лоиҳа бо компонентҳо

src/ ├─ main.jsx ├─ App.jsx саҳифаро аз компонентҳо ҷамъ мекунад └─ components/ ├─ Header.jsx export default function Header() ├─ CourseCard.jsx export default function CourseCard() └─ Footer.jsx export default function Footer()
  • Номи файл = номи компонент, бо ҳарфи калон: Header.jsx, CourseCard.jsx.
  • Пасванди .jsx — нишонаи он аст, ки дар дохил JSX ҳаст. Vite онро барои файлҳои дорои аломатгузорӣ талаб мекунад.
  • Папкаи components — танҳо мувофиқа аст, то ҳама чизро дар src/ нарезем.

Ин дар файлҳо чӣ тавр менамояд

export default function Header() {
  return (
    <header className="top">
      <h1>MakeFirstStep</h1>
    </header>
  )

Сатри import Header from './components/Header.jsx' чунин хонда мешавад: «он чизеро, ки Header.jsx бо пешфарз содир мекунад, гир ва Header ном бигузор». Роҳ бо ./ оғоз мешавад (дар паҳлуи ин файл), пасванди .jsx-ро пурра менависем — чунон ки дар дарси 17 мувофиқа кардем. Агар export default намебуд — ворид кардан чизе намебуд.

Монанд аз ҳаёт

Ошхонаи тарабхонаи калон. Салатҳоро бахши сард мекунад, хӯроки гармро бахши гарм, ширинӣро қаннодӣ. Ҳар бахш дар ҳуҷраи худ (файл) кор мекунад ва хӯроки тайёрро медиҳад (содир кардан). Пешхизмати ҷамъкунанда (App.jsx) чизе намепазад: ӯ хӯрокҳоро аз бахшҳо мегирад (ворид кардан) ва аз онҳо фармоишро дар рӯи миз ташкил медиҳад. Бахшҳоро омехта кардан мумкин нест, ва ошпази нав ба бахши мушаххас меояд, на ба тамоми ошхона якбора.

Содири номдор низ кор мекунад

// 1) бо пешфарз — як компонент дар як файл (интихоби мо)
export default function Header() { … }
import Header from './components/Header.jsx'

// 2) номдор — якчанд донаро аз як файл содир кардан мумкин аст
export function Header() { … }
import { Header } from './components/Header.jsx'

Асосӣ — он аст, ки содир ва ворид аз рӯи сабк мувофиқ бошанд: дар export default воридот бе қавс аст, дар номдор — бо қавс. Дар ин курс компонентҳоро бо пешфарз содир мекунем.

Се хатои маъмули воридот

1) export default-ро фаромӯш кардаед — хатои «does not provide an export named 'default'». 2) Бе ./ ворид кардаед: import Header from 'components/Header.jsx' — Vite чунин бастаро дар node_modules меҷӯяд ва намеёбад. 3) Компонентро дар воридот бо ҳарфи хурд ном додаед: import header from … — таг мешавад, на компоненти Шумо (нигаред ба бахши 02).

Дар React аз нав кун

Чаро бад аст: ЗС намедонад, ки Шумо дар куҷо меомӯзед, кадом абзорҳо доред, ва «ҳама чизро якбора» медиҳад — бо ҳолат, эффектҳо ва китобхонаҳои тарафи сеюм, ки мо ҳанӯз нагузаштаем. Ва Шумо шарҳҳо намегиред.

Контекст: ман навомӯзам, моҳи дуюм JavaScript меомӯзам, имрӯз бори аввал React-ро дидам. Лоиҳа дар Vite, қолаби React, JavaScript (на TypeScript), бе китобхонаҳои иловагӣ. Вазифа: инак коди JS-и тоза: [блоки болоро гузоред]. Онро ҳамчун як компоненти React-и App аз нав навис. Маҳдудиятҳо: танҳо аломатгузорӣ ва маълумот. Бе useState, useEffect ва коркардкунандаҳои ҳодиса. Бе document.querySelector ва createElement. Ҳеҷ бастаи нав. Формати ҷавоб: 1) коди компонент; 2) ҷадвали «сатр дар JS — чӣ ба ҷои он дар React омад» — барои ҳар сатри коди аслӣ як сатр; 3) се фарқи JSX аз HTML, ки дар ин мисол вомехӯранд. Санҷиш: бигӯ, ки навомӯзон ҳангоми чунин тарҷума кадом хатоҳоро бештар мекунанд.

Ин варианти густурдаи қолаби шпаргалкаи курс аст: «Инак коди JS-и тоза: [код]. Ҳамчун компоненти React аз нав навис ва сатр ба сатр шарҳ деҳ, ки чӣ ба ҷои querySelector ва addEventListener омад». Мо контекст, маҳдудиятҳо ва формат илова кардем — ва ҳодисаҳоро, ки дар дарси 23 пайдо мешаванд, хориҷ кардем.

  2. Ба ҳар кадом компоненти худро аз қуттии регӣ интиқол диҳед ва export default-ро илова кунед.
  3. Дар ҷое, ки компонент компоненти дигарро истифода мебарад, import илова кунед (Header Nav-ро ворид мекунад).
  4. Дар App.jsx Header, Courses, Footer-ро ворид кунед ва саҳифаро ҷамъ намоед.
  5. Услубҳоро аз ҷадвали style.css ба src/App.css интиқол диҳед ва боварӣ ҳосил кунед, ки App.jsx онро ворид мекунад: import './App.css'.

✓ Шпаргалкаи дарс

  • DOM-и дастӣ — императив: «ёб, эҷод кун, ҷойгир кун, нав кун». Кодҳои бисёр, нав карданро фаромӯш кардан осон, аломатгузорӣ намоён нест. React — декларатив: тавсиф мекунем, ки дар экран чӣ бояд бошад, ва React худаш DOM-ро тағйир медиҳад.
  • Компонент — функсияест, ки JSX бармегардонад. Ном бо ҳарфи калон, истифода мисли таг: <Header />. Ном бо ҳарфи хурд — ин теги оддии HTML аст.
  • Саҳифа = дарахти компонентҳо. Аз рӯи маъно мебурем: блоки такроршаванда, блоки дорои вазифаи худ. Як компонент — як файл.
  • Лоиҳа: npm create vite@latest my-app -- --template react → cd my-app → npm install → npm run dev.
  • Занҷираи оғоз: index.html (<div id="root">) → src/main.jsx (createRoot(…).render(<App />)) → src/App.jsx (компоненти асосӣ).
  • JSX ≠ HTML: className, htmlFor, ҳамаи тегҳо пӯшида (<br />, <input />), як реша ё фрагменти <>…</>, {ифода}, style={{ backgroundColor: "gold" }}, шарҳ {/* … */}.
  • Дар {…} — танҳо ифодаҳо: тағйирёбандаҳо, арифметика, даъватҳо, ? :, &&. Кашида намешаванд true, false, null, undefined; 0 кашида мешавад — шарти n && …-ро чун n > 0 && … нависед.
  • Содир ва ворид: export default function Header() {…} → import Header from './components/Header.jsx'. Роҳ бо ./, пасванди .jsx пурра.
  • StrictMode дар реҷаи таҳия компонентҳоро дукарата даъват мекунад — console.log дар компонент ду маротиба чоп мешавад. Дар сайти ҷамъшуда чунин намешавад.
  • ЗС: аввал худатон 15 дақиқа; дар промпт — контекст, «бе useState ва ҳодисаҳо», формати «ҷадвали сатр → сатр». Месанҷем: номҳо, className, як реша, объекти style, китобхонаҳои зиёдатӣ, оғоз.
  • Минбаъд (дарси 23): props — параметрҳои компонент, useState — хотираи он, рӯйхатҳо ва key.
