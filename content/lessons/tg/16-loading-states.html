Дарси 16 · Async ва API

Ҳолатҳои боркунӣ, хато, debounce

Шумо аллакай маълумотро аз сервери воқеӣ гирифта метавонед. Аммо дар сайти воқеӣ интернет гоҳо суст аст, сервер — дастнорас, корбар бошад — бетоқат: вай дар сатри ҷустуҷӯ тезтар менависад, нисбат ба он ки ҷавобҳо меоянд. Имрӯз мо ба барнома меомӯзонем, ки дар ҳар кадом аз ин вазъиятҳо шоиста рафтор кунад: боркуниро нишон диҳад, хаторо шарҳ диҳад, серверро бо дархостҳо пур накунад ва нолозимро бекор кунад.

  • Чор ҳолати экранро фарқ кардан: боркунӣ, хато, холӣ, маълумот — ва ҳар якро кашидан
  • response.ok-ро санҷидан ва «сервер бо хато ҷавоб дод»-ро бо «шабака нест» омехта накардан
  • Skeleton сохтан — ҷойгузинҳои хокистарӣ дар ҷои мазмуни ояндаи — бо CSS-и пок
  • debounce-ро аз сифр навиштан ва шарҳ додан, ки он тавассути closure ва таймер чӣ тавр кор мекунад
  • Дархостро тавассути AbortController бекор кардан ва ҷавобҳои кӯҳнашударо нишон надодан
  • Тағйиротеро, ки агенти ЗС (Cursor) якбора ба якчанд файл ворид мекунад, хондан ва санҷидан
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди дар заминаи торик бо тугмаи ▶ Иҷро кардан зинда аст: онро тағйир диҳед ва натиҷаро дар консол бинед. Дар ин дарс «сервер» дар мисолҳо атайин суст аст ва рост дар код сохта шудааст (тавассути Promise ва setTimeout), барои ҳамин натиҷа ҳамеша якхела аст ва аз интернети шумо вобаста нест; баъд аз иҷро як сония интизор шавед — сатрҳо дар консол ба навбат пайдо мешаванд. Мисолҳо бо API-и воқеӣ низ ҳастанд, аммо вазифаҳои санҷидашаванда бе шабака кор мекунанд. Дар ҷое ки равзанаи пешнамоиш ҳаст — ин саҳифаи хурд аст: дар тарафи чап код, дар тарафи рост натиҷа. Ишораҳо зери қулфак 🔒 пинҳонанд: аввал худатон кӯшиш кунед.

01 Чор ҳолати экран

Тасаввур кунед, ки шумо барномаи таксиро кушодед ва «Фармоиш додан»-ро пахш кардед. Чӣ мебинед? Чархаки «мошин меҷӯем». Агар дар наздикӣ мошин набошад — паёми «Мошини холӣ нест, баъдтар кӯшиш кунед». Агар интернет гум шавад — «Пайвастшавӣ нест» ва тугмаи «Такрор кардан». Ва танҳо агар ҳама чиз хуб бошад — корти ронанда. Як экран, чор тасвири гуногун — вобаста ба он ки ҳоло бо маълумот чӣ мегузарад.

Навомӯзон одатан танҳо тасвири охиринро мекашанд — «маълумот омад». Се тасвири дигарро фаромӯш мекунанд. Дар натиҷа бо интернети суст корбар ба саҳифаи холӣ менигарад ва гумон мекунад, ки сайт вайрон шудааст. Касбӣ ҳар чорро фикр мекунад:

Қиёс аз ҳаёт

Шумо ба чойхона омада, курутоб фармоиш додед. Пешхизмати хуб хомӯшона намеистад: «Тайёр мекунем, тақрибан даҳ дақиқа» (loading); «Курутоб тамом шуд» (error — фармоиш додан мумкин нест); «Мутаассифона, чунин хӯрок дар меню нест» (empty — ҷустем, аммо наёфтем); ва ниҳоят — табақро меорад (success). Пешхизмати бад оддӣ ғайб мезанад, шумо бошед менишинед ва тахмин мекунед: фармоиш қабул шуд ё не?

Ҳолатро дар куҷо нигоҳ доштан

Аз дарси ҳолат (дарси 11) шумо қоидаи асосиро медонед: маълумот ҳаст — функсияе ҳаст, ки аз рӯи он экранро мекашад. Дар ин ҷо ҳам ҳамин тавр. Як объекти state бо се майдон ва як функсияи view (ё render) месозем, ки қарор медиҳад, чиро нишон диҳад.

// status: "idle" | "loading" | "success" | "error"
function view(state) {
  if (state.status === "idle") return "Введите название блюда";
  if (state.status === "loading") return "Загрузка…";
  if (state.status === "error") return `Ошибка: ${state.error}`;
  // минбаъд status === "success"
  if (state.data.length === 0) return "Ничего не найдено";
  return `Нашли: ${state.data.join(", ")}`;
}

console.log(view({ status: "idle", data: [], error: null }));
console.log(view({ status: "loading", data: [], error: null }));
console.log(view({ status: "error", data: [], error: "Нет сети" }));
console.log(view({ status: "success", data: [], error: null }));
console.log(view({ status: "success", data: ["Курутоб"], error: null }));

Диққат диҳед: «empty» — ин статуси алоҳидаи сервер нест, балки ҳолати хоси муваффақият аст: дархост гузашт, аммо рӯйхат холӣ баромад. Хоҳед — онро бо статуси алоҳидаи "empty" ҷудо кунед (дар тамға қулайтар мешавад), хоҳед — data.length-ро санҷед. Асосӣ — корбар матни гуногунро бинад.

Тартиби санҷишҳо муҳим аст

Хатои маъмултарин — аввал «холӣ?»-ро санҷидан. То даме ки маълумот бор мешавад, рӯйхат ҳам холӣ аст ва корбар ба ҷои «Загрузка…» «Ничего не найдено»-ро мебинад. Аввал мепурсем: «бо дархост чӣ шуд?» (loading, error), ва танҳо баъд — «дар дохили ҷавоб чӣ ҳаст?» (холӣ ё не).

Хатои маъмул

Ба ҷои чор ҳолат — як булии isLoading ва «баъд мебинем». Он гоҳ ба осонӣ омезишҳои имконнопазир ҳосил мешаванд: isLoading: true ва дар ҳамон вақт error: "Нет сети". Як status бо қиматҳои фаҳмо чунин чизро намепазирад: дар ҳар лаҳза вай ба якто аз онҳо баробар аст.

Гузариш байни ҳолатҳо

Ҳолатҳо бо сенарияи оддӣ ҷойи ҳамдигарро мегиранд. Онро дар хотир доред — вай дар ҳар барномае, ки менависед, хоҳад буд:

  1. Корбар коре кард (саҳифаро кушод, «Ёфтан»-ро пахш кард) → status: "loading"-ро мемонем ва экранро аз нав мекашем.
  2. Сервер ҷавоб дод → status: "success"-ро (ё "empty") мемонем ва маълумотро мегузорем.
  3. Чизе вайрон шуд → status: "error"-ро мемонем ва матни фаҳмои хаторо мегузорем.
  4. Корбар «Такрор кардан»-ро пахш кард → боз қадами 1.
Маслиҳат

Ҳангоми дархости нав судманд аст, ки маълумоти кӯҳнаро то боркунӣ нест накунед, ҳангоми хато — рӯйхати аллакай нишондодаро гум накунед. Он гоҳ болои рӯйхати пештара «Навсозӣ муяссар нашуд»-ро кашидан мумкин аст, на ин ки корбарро бо экрани холӣ гузоштан. Имрӯз мо дар ҷое ки қулай аст, ҳамин тавр мекунем.

ВАЗИФАИ 1.1

Экран чӣ нишон медиҳад

осон

Чопро пешгӯӣ кунед, бе иҷрои код: label барои ҳар кадом аз чор ҳолат чӣ чоп мекунад? Сатрҳоро ба prediction ворид кунед ва иҷро намоед. Ба ҳолати дуюм диққат диҳед: статуси «success», аммо маълумот нест.

const states = [

function label(s) {
  if (s.status === "loading") return "Загрузка…";

ВАЗИФАИ 1.4

Гузариш байни ҳолатҳо

миёна

Функсияи next(state, event)-ро нависед: вай ҳолати ҷорӣ ва ҳодисаро мегирад ва ҳолати навро бармегардонад (объекти кӯҳнаро тағйир намедиҳем). Ҳодисаҳо: start → status: "loading", error: null, маълумоти пештара мемонад; done → status: "success", дар data — event.data, хато нест; fail → status: "error", дар error — event.error, маълумоти пештара мемонад.

// function next(state, event) { ... }

let s = { status: "idle", data: [], error: null };

  { type: "start" },
  { type: "fail", error: "Нет сети" },
];
for (const e of events) {
  s = next(s, e);
  console.log(e.type, "→", s.status, s.data.length, s.error);
}

Барои done нусха кардани ҳолати кӯҳна лозим нест — ҳар се майдон аз нав муайян мешавад: { status: "success", data: event.data, error: null }.

02 Дархост, хатоҳо ва «сервери суст»

Акнун боркунии воқеиро пайваст мекунем. Аз дарсҳои гузашта схемаро медонед: функсияи async, await fetch(...), try / catch. Ба он ҳолатҳоро илова мекунем: пеш аз дархост loading-ро мемонем, баъд аз — success ё error, finally бошад дар ин ҷо қариб лозим нест: ҳар ҳолат ошкоро гузошта мешавад.

async function searchProducts(query) {
  console.log("loading");
  try {
    const res = await fetch(`https://dummyjson.com/products/search?q=${query}&limit=3`);
    const data = await res.json();
    console.log(`success: ${data.products.length} из ${data.total}`);
  } catch (err) {
    console.log(`error: ${err.message}`);
  }
}

searchProducts("phone");

Ду хатои гуногун — ва fetch онҳоро на ҳамон тавр фарқ мекунад, ки шумо гумон мекунед

Ин доме аст, ки қариб ҳар навомӯз ба он меафтад. Дархост ду навъи гуногуни ноком дорад:

Шабака нест
Интернет гум шуд, сервер ёфт нашуд, дархост нарасид. Он гоҳ fetch промисро рад мекунад — идоракунӣ ба catch меравад.
Сервер гуфт «не»
Дархост расид, аммо сервер рамзи 404 («ёфт нашуд») ё 500 («назди мо ҳама чиз вайрон шуд») баргардонд. Барои fetch ин муваффақият аст: ҷавоб гирифта шуд! Промис иҷро мешавад, ба catch намеафтем.

Барои ҳамин баъд аз fetch ҳамеша хусусияти res.ok-ро санҷед — вай барои рамзҳои 200–299 ба true баробар аст. Агар не — хаторо худатон бипартоед:

async function loadProduct(id) {
  try {
    const res = await fetch(`https://dummyjson.com/products/${id}`);
    console.log("status:", res.status, "ok:", res.ok);
    if (!res.ok) throw new Error(`Сервер ответил кодом ${res.status}`);
    const product = await res.json();
    console.log("success:", product.title);
  } catch (err) {
    console.log("error:", err.message);
  }
}

loadProduct(999999);

Кӯшиш кунед 999999-ро бо 1 иваз кунед: рамз 200 мешавад ва шумо номи молро мебинед.

Қиёс аз ҳаёт

Шумо курйерро ба мағоза дар Бозори Сабз фиристодед. Агар роҳро банданд ва курйер нарасид — ин «шабака нест» аст (catch). Агар курйер расид ва бо гуфтаи «ин мол дар фурӯш нест» баргашт — вай бомуваффақият баргашт, аммо натиҷа бад аст. Маҳз ҳамин тавр fetch фикр мекунад: курйер баргашт — пас муваффақият. Санҷидани он ки вай дақиқан чӣ овард, кори шумост.

«Сервери суст» дар коди мо

API-и воқеӣ гоҳ тез, гоҳ суст ҷавоб медиҳад, гоҳ умуман ҷавоб намедиҳад. Барои он ки дарсҳо ва вазифаҳо софдилона ва барои ҳама якхела бошанд, мо ба худамон сервери «қалбакӣ» месозем — функсияи fakeSearch. Вай хӯрокро дар массиви хурд меҷӯяд, баъд аз вақти додашуда ҷавоб медиҳад ва аз рӯи дархости «ошибка» вайрон шуда метавонад. Касбиён ҳам ҳамин тавр мекунанд: то даме ки сервери воқеӣ нест (ё ноустувор аст), интерфейсро бо ҷойгузин месанҷанд.

Ҷойгузинро таҳлил мекунем

Онро пурра хондан ҳатмӣ нест, аммо се ҷои муҳим ҳаст. setTimeout таъхири шабакаро тақлид мекунад (ms миллисония). Агар дархост бо номи "ошибка" фиристода шавад — промис рад мешавад, мисли ҳангоми қатъи шабака. Параметри signal барои бекор кардан лозим аст — дар бораи он дар қисми 5; ҳоло онро нодида гирифтан мумкин аст. Дар ҳамаи мисолҳои поён блоки «сервер» як хел аст — онро оддӣ пурра нусха кунед.

// ↓ «сервер»: ҷустуҷӯи суст дар меню — тағйир надиҳед
const DISHES = ["Оши палав", "Самбуса с мясом", "Самбуса с тыквой", "Курутоб", "Шакароб", "Нон"];

function fakeSearch(query, { signal, ms = 200 } = {}) {
  return new Promise((resolve, reject) => {
    if (signal && signal.aborted) return reject(signal.reason);
    const timer = setTimeout(() => {
      if (query === "ошибка") return reject(new Error("Нет соединения с сервером"));
      resolve(DISHES.filter((d) => d.toLowerCase().includes(query.toLowerCase())));
    }, ms);
    if (signal) {
      signal.addEventListener("abort", () => {
        clearTimeout(timer);

03 Skeleton: ҷойгузинҳои хокистарӣ ба ҷои холигӣ

Оддитарин ҳолати боркунӣ — навиштаи «Загрузка…» ё чархак. Аммо вай камбудӣ дорад: саҳифа «ҷаст мезанад». Аввал дар экран навиштаи хурд, баъд ногаҳон рӯйхати дароз пайдо мешавад ва тамоми мазмун ба поён мекӯчад. Роҳи ҳал — skeleton («скелет»): дар ҷои кортҳои оянда росткунҷаҳои хокистарии ҳамон андоза нишон медиҳем. Корбар пешакӣ мебинад, ки саҳифа чӣ гуна хоҳад буд, вақте маълумот меояд — ҷойгузинҳо оддӣ бо кортҳои воқеӣ дар ҳамон ҷойҳо иваз мешаванд.

Қиёс аз ҳаёт

Шумо ба тӯй дар чойхона омадед, аммо дастурхон ҳанӯз чида нашудааст. Аммо ғилофи миз аллакай густурда шудааст ва болои он табақҳои холӣ — ба шумораи меҳмонон — гузошта шудаанд. Шумо фавран мебинед, ки дар куҷо менишинед ва чанд ҷой ҳаст. Баъд пешхизматон оддӣ хӯрокро ба табақҳои тайёр мегузоранд — миз аз нав чида намешавад. Skeleton — ҳамон табақҳои холӣ аст.

Skeleton бо CSS-и пок

JavaScript дар ин ҷо танҳо барои як чиз лозим аст: шумораи лозимаи блокҳоро ба саҳифа гузоштан. Тамоми «намуд»-ро CSS месозад. Сирри милликунӣ — градиент, ки бо ёрии аниматсия аз чап ба рост «меҳазад»:

.skeleton {
  /* замини хокистарии равшан бо рахи равшантар дар мобайн */
  background: linear-gradient(90deg, #e6e9ef 25%, #f4f6fa 37%, #e6e9ef 63%);
  background-size: 400% 100%;      /* градиент 4 маротиба аз блок васеътар */
  animation: shimmer 1.2s ease infinite;
  border-radius: 8px;
  color: transparent;              /* барои ҳолате, ки дар дохил матн пайдо шавад */
}

@keyframes shimmer {
  0%   { background-position: 100% 0; }
  100% { background-position: 0 0; }
}

  .skeleton { animation: none; }
}
  1. Градиент аз блок васеътар. background-size: 400% заминро чор маротиба аз худи блок васеътар мекунад — танҳо порчаи он намоён аст.
  2. Аниматсия заминро ҳаракат медиҳад. @keyframes shimmer background-position-ро тағйир медиҳад — «рахи равшан» оҳиста аз болои блок мегузарад.
  3. Андозаҳоро корт муайян мекунад. Ҷойгузин бояд ҳамон баландӣ ва бари корти воқеӣ дошта бошад — вагарна саҳифа ба ҳар ҳол «ҷаст мезанад».
  4. Дар бораи дастрасӣ фаромӯш накунед. Ба контейнер aria-busy="true"-ро то боркунӣ мемонем ва "false" — вақте тамом шуд: хонандаҳои экран мефаҳманд, ки мазмун навсозӣ мешавад.

Кай skeleton, кай чархак

Skeleton хуб аст, вақте медонед, ки натиҷа чӣ гуна менамояд: рӯйхати кортҳо, ҷадвал, профил. Чархак (спиннер) ё «Загрузка…»-и кӯтоҳ — вақте натиҷа номуайян ё хурд аст (масалан, тугмаи «Захира кардан»). Бо skeleton кор карда, ҳамон қадар ҷойгузин нишон диҳед, ки одатан кортҳо дар экран ҷо мешаванд, — зиёд не.

Skeleton — ягона ҳолати «зебо» нест

Ҳолатҳои дигарро низ бояд оро дод, на ин ки матни «луч» гузошт:

  • Холӣ (empty): ибораи кӯтоҳ ва ишора, ки чӣ кор кардан лозим: «Ничего не найдено. Номи дигарро кӯшиш кунед».
  • Хато (error): сабаби фаҳмо ва тугмаи «Такрор кардан». Ранги сурх — ҳатмӣ нест, асосӣ — равшан бошад, ки минбаъд чӣ кор кардан мумкин аст.
  • Оғоз (idle): даъват ба амал: «Номи хӯрокро ворид кунед».
Хатои маъмул

Нест кардани ҷойгузинҳоро фаромӯш кардан. Агар ҳангоми ҷавоби сервер кортҳоро тавассути append илова кунед, на ин ки мазмунро тавассути replaceChildren иваз кунед, блокҳои хокистарӣ дар саҳифа мемонанд, кортҳои воқеӣ бошанд дар зери онҳо пайдо мешаванд. Ҳамеша мазмунро пурра иваз кунед.

04 Debounce: функсияро ба ҳар атса насозед

Сатри ҷустуҷӯи «дар парвоз»: корбар «плов»-ро менависад ва натиҷаҳо аллакай дар ҷараён тағйир меёбанд. Оддитарин роҳи ҳал — ба ҳодисаи input гӯш додан ва барои ҳар ҳарф дархост фиристодан. Аммо одам зуд менависад: «п», «пл», «пло», «плов» — ин чор дархост дар як сония аст, ки аз онҳо танҳо охирин лозим аст. Сервер сарбор мешавад, трафик сарф мешавад, ҷавобҳо бошанд омехта меоянд (дар бораи ин — дар қисми 5).

Роҳи ҳал debounce — «пахшкунии ларзиш» ном дорад: функсияро танҳо вақте иҷро мекунем, ки корбар барои вақти додашуда онро кашидан гузошт. Ҳар даъвати нав интизориро аз нав оғоз мекунад. То даме ки одам менависад — ҳеҷ чиз намешавад; 300 мс истод — дархост меравад.

Қиёс аз ҳаёт

Маршрутка дар истгоҳ. Ронанда ҳамин ки мусофири аввал даромад, намеравад. Вай интизор мешавад: дуюм даромад — боз интизор, сеюм даромад — боз интизор. Ва танҳо вақте чанд сония ҳеҷ кас намедарояд, ҳаракат мекунад. Ҳар мусофири нав таймери интизориро аз нав оғоз мекунад. Debounce — ин ронандаест, ки танҳо баъд аз танаффус ҳаракат мекунад.

Debounce-ро аз сифр менависем

Дар дохил ҳамагӣ се ғояи аллакай маълум ҳаст: функсия функсия бармегардонад, closure таймерро байни даъватҳо нигоҳ медорад, clearTimeout бошад интизории қаблиро бекор мекунад.

function debounce(fn, wait) {
  let timer;                         // як таймер барои ҳамаи даъватҳо — дар closure зиндагӣ мекунад
  return function (...args) {
    clearTimeout(timer);             // даъвати нав: интизории гузаштаро бекор мекунем
    timer = setTimeout(() => {
      fn(...args);                   // танаффус дида шуд — функсияи воқеиро иҷро мекунем
    }, wait);
  };
}
  1. Мо функсияи fn ва танаффуси wait-ро мегирем ва функсияи нав бармегардонем — онро ба ҳодиса мепайвандем.
  2. Тағйирёбандаи timer дар берун аз функсияи баргардонидашаванда эълон шудааст. Барои ҳамин ҳамаи даъватҳо як тағйирёбандаи ягонаро мебинанд (closure, дарси 5).
  3. Ҳангоми ҳар даъват аввал clearTimeout(timer) интизории даъвати гузаштаро нест мекунад, баъд setTimeout интизории нав месозад.
  4. Танҳо интизории охирин кор мекунад — он, ки дар давоми wait миллисония касе барқарор накард.
  5. ...args ҳамаи аргументҳоро ба массив ҷамъ мекунад, fn(...args) бошад баргашта паҳн мекунад — ба ин тартиб debounce ба функсия бо ҳар шумораи параметрҳо мувофиқ аст.

Дар «менависандаи» одам месанҷем

Барои он ки натиҷа аз суръати навиштани шумо вобаста набошад, мо пахши тугмаҳоро аз рӯи ҷадвал ба нақша мегирем тавассути setTimeout. Ҷадвал: «п» дар 0 мс, «пл» дар 40 мс, «пло» дар 80 мс (зуд менависад), баъд танаффус ва «плов» дар 300 мс. Танаффуси debounce — 100 мс. Дар консол дида мешавад, ки воқеан чӣ кор кард.

function debounce(fn, wait) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), wait);
  };
}

Хатои маъмул

let timer-ро дар дохили функсияи баргардонидашаванда эълон кардан. Он гоҳ ҳар даъват timer-и худии ҷудогона мегирад, clearTimeout бошад холигиро бекор мекунад — ҳеҷ чиз барқарор намешавад ва ҳамаи даъватҳо кор мекунанд, фақат бо таъхир. Тағйирёбандаи таймер бояд дар берун, дар closure зиндагӣ кунад.

Debounce танаффусро интизор мешавад ва як маротиба баъд аз силсилаи даъватҳо кор мекунад (ҷустуҷӯ, худкор захира кардан). Throttle («дроссел») на зиёдтар аз як маротиба дар N мс ҳангоми силсила кор мекунад (варақ задани саҳифа, тағйири андозаи тиреза). Дар ҷустуҷӯ ба мо маҳз debounce лозим аст.

Кай debounce лозим нест

Барои амалҳо бо тугма («Ёфтан», «Фиристодан») танаффус лозим нест: одам бошуурона ва як маротиба пахш мекунад. Debounce — дору аз ҷараёни ҳодисаҳост: input, scroll, resize, mousemove.

Даъвати ба таъхир гузоштаро бекор кардан: cancel

Мешавад, ки на танҳо ба таъхир гузоштан, балки интизорро бекор кардан лозим мешавад: корбар майдонро тоза кард ё аз саҳифа баромад. Функсияҳо дар JavaScript низ объект мебошанд, ба онҳо хусусиятро «часпондан» мумкин аст. Усули cancel-ро илова мекунем:

function debounce(fn, wait) {
  let timer;
  function debounced(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), wait);
  }
  debounced.cancel = () => clearTimeout(timer);   // усул дар функсия
  return debounced;
}

05 AbortController: бекор кардани дархост

Debounce шумораи дархостҳоро кам мекунад, аммо мушкили асосиро бартараф намекунад: дархосте, ки аллакай рафтааст, «фаромӯш» кардан мумкин нест. Вай ба сервер мерасад ва бо ҷавоб бармегардад, ҳатто агар ин ҷавоб ба корбар аллакай лозим набошад. Ва ин ба ду нохушӣ меорад.

Мушкили 1. Кори зиёдатӣ

Корбар саҳифаи каталогро кушод ва фавран ба саҳифаи дигар рафт. Дархост барои 100 мол ба ҳар ҳол зеркашӣ ва таҷзия мешавад — трафик ва батарея беҳуда сарф мешавад (дар интернети мобилӣ дар маршрутка ин эҳсос мешавад).

Мушкили 2. Мусобиқаи дархостҳо (race condition)

Корбар «с»-ро навишт — дархости №1 рафт. Баъд аз 50 мс «са»-ро анҷом дод — дархости №2 рафт. Сервер дархостҳоро бо вақти гуногун коркард мекунад: ҷавоб ба якум (натиҷаҳояш бисёр) баъд аз 400 мс омад, ба дуюм — баъд аз 100 мс. Дар экран чӣ мешавад?

// ↓ «сервер»: ҷустуҷӯи суст дар меню — тағйир надиҳед
const DISHES = ["Оши палав", "Самбуса с мясом", "Самбуса с тыквой", "Курутоб", "Шакароб", "Нон"];

function fakeSearch(query, { signal, ms = 200 } = {}) {
  return new Promise((resolve, reject) => {
    if (signal && signal.aborted) return reject(signal.reason);
    const timer = setTimeout(() => {
      if (query === "ошибка") return reject(new Error("Нет соединения с сервером"));
      resolve(DISHES.filter((d) => d.toLowerCase().includes(query.toLowerCase())));
    }, ms);
    if (signal) {
      signal.addEventListener("abort", () => {
        clearTimeout(timer);
        reject(signal.reason);
      });
    }
  });
}

let shown = "";

function onType(query, ms) {
  fakeSearch(query, { ms }).then(() => {

Қиёс аз ҳаёт

Шумо палав фармоиш додед, баъд аз як дақиқа фикратон гашт ва занг задед: «Беҳтараш самбуса». Агар дар чойхона фармоиши аввалро бекор накунанд, ба назди шумо ҳарду курйер меоянд — ва палав, шояд, пештар ё дертар аз самбуса. Дуруст — занг задан ва фармоиши аввалро бекор кардан. Маҳз инро AbortController мекунад: вай ба дархост «занг мезанад» ва мегӯяд «истед».

Чӣ тавр кор мекунад: controller ва signal

AbortController
«Пулт»: объекте, ки тугмаи abort() дорад. Чунин сохта мешавад: new AbortController().
controller.signal
«Симча»-и пулт: сигнале, ки ба дархост медиҳем. Дархост онро гӯш мекунад ва вақте тугма пахш шуд, истод.
controller.abort()
Тугма пахш шуд — дархост бекор шуд, промиси он бо хатои бо номи AbortError рад мешавад.
// ↓ «сервер»: ҷустуҷӯи суст дар меню — тағйир надиҳед
const DISHES = ["Оши палав", "Самбуса с мясом", "Самбуса с тыквой", "Курутоб", "Шакароб", "Нон"];

function fakeSearch(query, { signal, ms = 200 } = {}) {
  return new Promise((resolve, reject) => {
    if (signal && signal.aborted) return reject(signal.reason);
    const timer = setTimeout(() => {
      if (query === "ошибка") return reject(new Error("Нет соединения с сервером"));
      resolve(DISHES.filter((d) => d.toLowerCase().includes(query.toLowerCase())));
    }, ms);
    if (signal) {
      signal.addEventListener("abort", () => {
        clearTimeout(timer);
        reject(signal.reason);
      });
    }
  });
}

const controller = new AbortController();

// дархост барои 500 мс, ба он «пулт» пайваст аст
fakeSearch("самбуса", { signal: controller.signal, ms: 500 })
  .then((items) => console.log("получили", items.length))
  .catch((err) => console.log("ошибка:", err.name));

// баъд аз 100 мс корбар «Бекор»-ро пахш кард
setTimeout(() => {
  console.log("нажали abort()");
  controller.abort();
}, 100);

Дархосте, ки бояд 500 мс мерафт, баъд аз 100 истод. Ҷавоб наомад — ба ҷои он catch бо err.name === "AbortError" кор кард.

fetch-и воқеӣ signal-ро мефаҳмад

Ҷойгузини мо мисли fetch-и воқеӣ сохта шудааст: сигнал ҳамчун аргументи дуюм, дар объекти танзимот дода мешавад. Агар abort()-ро фавран даъват кунем, дархост ҳатто зеркаширо оғоз намекунад:

const controller = new AbortController();

const request = fetch("https://dummyjson.com/products?limit=100", {
  signal: controller.signal,
});

controller.abort();   // фавран бекор мекунем

request.catch((err) => console.log("fetch отменён:", err.name));

Дарозтар тоб намеорад — таймаут бо як сатр

Аксар вақт на бекор кардани дастӣ, балки интизор шудани на дарозтар аз N миллисония лозим мешавад. Барои ин функсияи тайёри AbortSignal.timeout(мс) ҳаст: вай худаш баъд аз вақти додашуда «abort»-ро пахш мекунад. Хато ҳангоми ин AbortError не, балки TimeoutError ном дорад — ба ин тартиб шумо «мо бекор кардем»-ро аз «интизор нашудем» фарқ мекунед.

fetch("https://dummyjson.com/products?limit=100", { signal: AbortSignal.timeout(1) })
  .then(() => console.log("успели"))
  .catch((err) => console.log("ошибка:", err.name));

Намуна: «ҳар дархости нав дархости гузаштаро бекор мекунад»

Маҳз ҳамин тавр мусобиқаи аввали қисмро ислоҳ кардан мумкин аст. Контроллерро дар тағйирёбандаи берун аз функсия нигоҳ медорем; пеш аз дархости нав кӯҳнаро бекор мекунем ва контроллери нав месозем.

  2. Дар кӯҳна abort()-ро даъват мекунем пеш аз сохтани нав — дар ҳамин лаҳза дархости кӯҳна ҳанӯз дар роҳ буда метавонад.
  3. Дар catch AbortError-ро хомӯшона мегузаронем. Бекор кардан — хатои сервер нест, ва ба корбар бо матни сурхи «Хато!» бо сабаби он ки ҳарфе илова кард, тарс додан мумкин нест.
Хатои маъмул

AbortError-ро коркард накардан. Дархости бекоршуда промисро рад мекунад ва агар дар catch оддӣ «хаторо нишон деҳ» навишта шуда бошад — дар экран як лаҳза «Ошибка: The user aborted a request» милтик мезанад. Ҳамеша err.name-ро санҷед ва барои "AbortError" хомӯшона бароед.

Роҳи дуюм ҳам ҳаст

Дархостро бекор накарда, оддӣ ҷавоби кӯҳнашударо нодида гирифтан мумкин аст: ҳисобкунаки requestId сохтан, рақами дархости худро ба ёд гирифтан ва ҳангоми ҷавоб санҷидан, ки вай ҳанӯз охирин аст. Ин оддитар аст, аммо дархост ба ҳар ҳол ба сервер мерасад ва трафик сарф мекунад. AbortController — роҳи «софдилона»: дархост воқеан қатъ мешавад.

Сенарияи намоиш

Муаллим барномаи хурдро аз дарсҳои гузашта — ҷустуҷӯ аз рӯи API бо рӯйхат ва пагинатсия — бар якчанд файл тақсимшуда мегирад: index.html, style.css, api.js (дархостҳо), ui.js (кашидан) ва main.js (ҳодисаҳо). Вазифа — маҳз ҳамон аст, ки имрӯз бо даст ҳал мекунем: ҳолатҳои боркунӣ, холигӣ ва хато, debounce ва бекор кардани дархостҳоро илова кардан.

  1. Нусхаро нигоҳ медорем. Пеш аз демо ҷузвдони лоиҳаро нусха мекунанд (Git-ро дар дарси 19 меомӯзем, ҳоло — нусхаи оддӣ). Агар агент вайрон кунад, ҳамеша баргаштан мумкин аст.
  2. Вазифаро аз рӯи формула мегузорем. Промпт бо овози баланд хонда мешавад (вай дар поён аст) — ҳар порчаи он барои қисми худи формула масъул аст.
  3. Мебинем, ки агент чиро мехонад. Агент «тахмин» намекунад: вай файлҳои лоиҳаро мекушояд. Диққат диҳед, кадом файлҳоро кушод — оё лозимаро гузаронд.
  4. Нақшаро мехонем — пеш аз ислоҳҳо. Аз агент хоҳиш мекунем, ки аввал нақша нависад: кадом файлҳо ва чиро тағйир медиҳад. Аллакай дар ин қадам дида мешавад, ки вазифаро фаҳмид ё не.
  5. Ислоҳҳоро файл ба файл баррасӣ мекунем. Дар муҳаррир фарқ дида мешавад: чӣ илова шуд, чӣ нест шуд. Қабул мекунем яктоӣ-яктоӣ, на «ҳама якбора».
  6. Иҷро мекунем ва кӯшиш мекунем вайрон кунем. Дар ҷустуҷӯ зуд менависем; дар DevTools дар ҷадвали Network шабакаи сустро ва ҳолати Offline-ро фаъол мекунем; дархостеро меҷӯем, ки дар API нест.
  7. Фаромӯшшударо меёбем. Қариб ҳамеша чизе мемонад: саҳифаро ба аввал барқарор карданро ҳангоми дархости нав фаромӯш карданд, AbortError-ро гузарониданд, console.log-ро монданд. Инро промпти навбатӣ ё бо даст ислоҳ мекунанд.

Промпт барои демо

Диққат диҳед, вай чӣ тавр сохта шудааст: аввал контекст, баъд вазифа, баъд маҳдудиятҳо, сипас чиро нишон додан ва чӣ тавр санҷидан. Бо варианти «бад» муқоиса кунед:

ба лоиҳаи ман боркунӣ ва ҷустуҷӯро бо таъхир илова кун
Контекст: барномаи таълимӣ бо JS-и пок бе китобхонаҳо — ҷустуҷӯи хӯрокҳо аз рӯи API бо пагинатсия. Файлҳо: index.html, style.css, api.js (fetch), ui.js (рӯйхатро мекашад), main.js (ҳодисаҳо). Вазифа: 1) се ҳолатро илова кун — боркунӣ (skeleton аз се блоки хокистарӣ), холӣ («Ничего не найдено») ва хато (матни фаҳмо ва тугмаи «Повторить»); 2) debounce 400 мс ба вурудот дар сатри ҷустуҷӯ илова кун; 3) ҳангоми дархости нав қаблиро тавассути AbortController бекор кун ва AbortError-ро хомӯшона нодида гир; 4) ҳангоми дархости ҷустуҷӯи нав саҳифаро ба аввал барқарор кун. Маҳдудиятҳо: мантиқи пагинатсия ва номи синфҳои CSS-и мавҷударо ламс накун, китобхона илова накун, файлҳоеро, ки барои ин вазифа лозим нестанд, тағйир надеҳ. Формат: аввал нақша нависед — кадом файлҳоро ва барои чӣ тағйир медиҳӣ; баъд ислоҳҳоро ворид кун ва файлҳои тағйирёфтаро номбар кун. Санҷиш: бинвис, ки ман чӣ тавр ҳар яке аз чор тағйиротро дастӣ санҷам.

Дар вақти намоиш ба чӣ нигоҳ кардан лозим

Ин саволҳоро дар хотир доред, ҳангоме ки ба экран менигаред, — ва онҳоро бо овози баланд диҳед:

  • Чанд файл тағйир ёфтааст ва оё ҳамаи онҳо лозиманд? Ислоҳ дар style.css бамаврид аст (skeleton). Аммо тағйирот дар функсияҳои бегона, ки мо ламс кардани онҳоро нахостем, — сабаби истодан аст.
  • Оё тамоми diff хонда шудааст? Сурх — нест шуд. Оё мантиқи корӣ (масалан, пагинатсия) дар «рефакторинг» нопадид нашуд?
  • Оё чизи ихтироъшуда нест? Майдони JSON, ки дар ҷавоби воқеии API нест, ё функсияе, ки дар браузер нест. Бо ҷавоби воқеӣ дар ҷадвали Network муқоиса мекунем.
  • Оё ҳар чор ҳолат коркард шудаанд? Махсусан омехтагии «холӣ» ва «хато» — ЗС онҳоро зуд-зуд омехта мекунад.
  • Оё AbortError дар catch ҳаст? Бе он дар экран «хато» бо ҳар ҳарфи нав милтик мезанад.
  • Оё ман метавонам ҳар сатрро шарҳ диҳам? Агар не — кодро қабул намекунем (қоидаи курс №3).

Хавфҳо: чӣ метавонад хато равад

Одатҳои хатарнок
  • «Ҳамаро қабул кун»-ро бе хондани ислоҳҳо пахш кардан
  • Бе маҳдудият «ҳамаро ислоҳ кун» хоҳиш кардан: агент он чиро, ки кор мекард, аз нав менависад
  • Бовар кардан, ки «агент худаш санҷид» — иҷро ва санҷиш бар души шумо мемонанд
  • Ба агент сирҳо додан: калидҳои API, паролҳо, файлҳо бо маълумоти шахсӣ (.env)
  • Хондани кодро бас кардан — бо мурури замон малака гум мешавад
Одатҳои солим
  • Вазифаи хурд — ислоҳҳои хурд — санҷиш
  • Ҳамеша пеш аз ислоҳҳо нақша ва баъд аз онҳо рӯйхати файлҳои тағйирёфтаро хоҳиш кардан
  • Равшан навиштан, ки чиро ламс кардан мумкин нест
  • То оғози кори агент нусхаи лоиҳаро нигоҳ доштан (баъдтар — коммит дар Git)
  • Дар браузер санҷидан: зуд, суст, офлайн, холӣ
Махфият

Коде, ки шумо ба агент нишон медиҳед, ба сервери хидмати ЗС фиристода мешавад. Барои лоиҳаҳои таълимӣ ин муқаррарӣ аст, аммо коди корӣ-и фармоишгар, паролҳо ва калидҳоро бе иҷозат ба он ҷо фиристодан мумкин нест. Одат кунед, ки дар ин бора пешакӣ фикр кунед: дар амал ин масъалаи эътимод ва гоҳо — қонун аст.

Ва шумо — тавассути чати ЗС: ҳуҷҷатгузории API-ро таҳлил мекунем

Ҳамин ҳозир шумо метавонед ЗС-ро дар ҷое истифода баред, ки вай махсусан судманд аст: барои фаҳмидани ҳуҷҷатгузории бегона. Формула ҳамон:

чӣ тавр аз ин api маълумот гирифтан
Инак ҳуҷҷатгузории API-и ҷустуҷӯи мол: [матн ё истинодро гузоред]. Ба ман лозим аст 5 натиҷаи аввалро аз рӯи дархост аз майдони вуруд гирам ва ҳолатеро, ки чизе ёфт нашуд, коркард кунам. Кадом эндпойнт, кадом параметрҳо, кадом мисоли дархост бо fetch? JS-и пок, бе китобхонаҳо. Чунин ҷавоб деҳ: 1) ҷадвали параметрҳо; 2) мисоли код; 3) дар ҷавоби воқеӣ чиро санҷидан лозим, то боварӣ ҳосил шавад, ки майдонҳо дуруст номгузорӣ шудаанд.
Санҷиши ҷавоби ЗС: бо API-и воқеӣ муқоиса мекунем

Суроғаи дархостро рост дар браузер кушоед (масалан, https://dummyjson.com/products/search?q=phone&limit=5) ё ҷавобро дар ҷадвали Network бинед. Оё номи майдонҳо (products, total) бо навиштаи ЗС мувофиқат мекунанд? Агар не — ЗС ихтироъ кардааст ё омехта кардааст; мо танҳо ба ҷавоби воқеии сервер бовар мекунем.

Амал: баррасии кори «агент»

Дар поён — код, чунон ки агент аз рӯи промпти мо навишта метавонист. Мо дар кори воқеӣ ҳамин тавр мекунем: аз сифр намеорем, балки кори бегонаро месанҷем ва ислоҳ мекунем.

ВАЗИФАИ 6.1

Баррасии коди агент: се хато

душвор

Дар коди поён се хато ҳаст; аз сабаби онҳо ҷустуҷӯ дархостҳои зиёдатӣ мегирад ва ҳолатҳои нодурустро нишон медиҳад. Ҷадвали «пахшҳо» дар охир: «к», «ку», «кур» — силсилаи зуд; баъд «самбуса», ҳангоме ки дархости қаблӣ ҳанӯз меравад; баъд «борщ» (дар меню чунин нест). Кодро иҷро кунед, ба бесарусомонӣ дар консол нигаред, хатоҳоро ёбед ва ислоҳ кунед. Баъд аз ислоҳ ҳолатҳо бояд маҳз бо ин тартиб раванд: боркунӣ, боркунӣ, муваффақият, боркунӣ, холӣ.

const DISHES = ["Оши палав", "Самбуса с мясом", "Самбуса с тыквой", "Курутоб", "Шакароб", "Нон"];

function fakeSearch(query, { signal, ms = 200 } = {}) {
  return new Promise((resolve, reject) => {
    if (signal && signal.aborted) return reject(signal.reason);
    const timer = setTimeout(() => {
      if (query === "ошибка") return reject(new Error("Нет соединения с сервером"));
      resolve(DISHES.filter((d) => d.toLowerCase().includes(query.toLowerCase())));
    }, ms);
    if (signal) {
      signal.addEventListener("abort", () => {
        clearTimeout(timer);
        reject(signal.reason);
      });
    }
  });
}

07 Амал дар дарс: се ҳолат ва debounce

Ҳамаро дар барномаи хурди «Менюи чойхона» ҷамъ мекунем: сатри ҷустуҷӯ ва рӯйхати хӯрокҳо. Ба ҷои API-и воқеӣ дар ин ҷо ҷойгузини шиноси fakeSearch ҳаст, то ҳама чиз барои ҳама якхела ва бе интернет кор кунад. Шумо дар ду марҳила кор мекунед: аввал ҳолатҳо, баъд debounce ва бекор кардан.

  1. Марҳилаи 1. Ҳолатҳо. Як объекти state ва функсияи render, ки аз рӯи state.status мекашад: ишора, skeleton, кортҳо, «холӣ» ё хато бо тугмаи «Такрор кардан». Функсияи load статусро мегузаронад: loading → success / empty / error.
  2. Марҳилаи 2. Debounce. debounce-ро менависем, ба input мепайвандем: дархост танҳо баъд аз танаффус меравад.
  3. Марҳилаи 3. Бекор кардан. Пеш аз дархости нав кӯҳнаро бекор мекунем, AbortError-ро хомӯшона мегузаронем.
  4. Марҳилаи 4. Дар барномаи худ. Ҳамонро ба лоиҳаи дарсҳои 14–15 мегузаронем — дар поён нақша ҳаст.

Амал: менюи чойхона

Сатрҳои санҷишии консол тасдиқ мекунанд, ки ҳар марҳила кор мекунад. Онҳо худашон «тугмаҳо»-ро пахш мекунанд, барои ҳамин натиҷа барои ҳама якхела аст.

Марҳилаи 4. Ба барномаи худ мегузаронем

Барномаи шумо аз дарсҳои 14–15 аллакай ҷустуҷӯ ва варақ задани саҳифаҳоро медонад. Ҳамонро қадам ба қадам ба он илова мекунем. Баъд аз ҳар қадам иҷро кунед ва санҷед:

  1. state-ро созед бо майдонҳои status, items, error (ва page, агар пагинатсия дошта бошед).
  2. Кашидани ҳамаро ба як функсияи render() баред, ки аз рӯи state.status тасвири лозимаро нишон медиҳад. Дар ҷои дигар DOM-ро ламс накунед.
  3. Дархостро бипечонед: аввал loading, баъд success / empty / error. if (!res.ok) throw ...-ро фаромӯш накунед.
  4. Skeleton: CSS-ро аз қисми 3 нусха кунед, шумораи лозимаи ҷойгузинҳоро дар ҳолати loading илова кунед.
  5. Debounce: debounce-ро нусха кунед, коркардкунандаи input-ро бипечонед — танаффус 300–400 мс.
  6. AbortController: signal-ро ба fetch-и худ диҳед, дархости гузаштаро бекор кунед, AbortError-ро гузаронед.
  7. Дар DevTools санҷед (ҷадвали Network): шабакаи сустро (Slow 4G) ва ҳолати Offline-ро фаъол кунед — ҳар се ҳолат бояд зинда дида шавад.

Агар дар барнома саҳифаҳо бошанд, ҳангоми дархости ҷустуҷӯи нав ба саҳифаи аввал баргардед. Ҳангоми боркунӣ — тугмаҳои «Ба қафо» ва «Ба пеш»-ро ғайрифаъол кунед (disabled), вагарна корбар метавонад онҳоро якчанд бор пай дар пай пахш кунад.

08 Вазифаи хонагӣ

UX-и барномаро такмил диҳед: боркунӣ, натиҷаи холӣ, хатои шабака. Барномаи худро аз дарсҳои 14–15 (рӯйхат ё ҷустуҷӯ аз рӯи API-и воқеӣ) мегиред ва онро ба корбар мулоим мекунед.

Чӣ кор кардан лозим

  1. Боркунӣ. То даме ки дархост меравад, skeleton нишон дода мешавад (3–6 ҷойгузин бо шакли лозимӣ). Дар контейнер — aria-busy.
  2. Холӣ. Агар чизе ёфт нашуд — матни фаҳмо («Ничего не найдено по запросу «…»») ва ишора, ки чӣ кор кардан лозим.
  3. Хато. Санҷиши res.ok; паёми инсонӣ (на «Failed to fetch») ва тугмаи «Такрор кардан», ки ҳамон дархостро такрор мекунад.
  4. Debounce. Ҷустуҷӯи «дар парвоз» бо debounce 300–500 мс, ки шумо навиштаед (на аз китобхона).
  5. Бекор кардан. Дархости нав қаблиро тавассути AbortController бекор мекунад; AbortError ҳамчун хато нишон дода намешавад.
  6. Санҷиш дар DevTools. Се скриншот гиред: боркунӣ дар шабакаи суст, ҳолати Offline бо хато, натиҷаи холӣ.
  7. (Бонус.) Ҳангоми дархости нав саҳифа ба аввал барқарор мешавад; тугмаҳои пагинатсия барои вақти боркунӣ ғайрифаъол мешаванд.

  • Истинод ба репозиторий дар GitHub (ё ҷузвдони лоиҳа — чунон ки бо муаллим мувофиқа кунед).

✓ Лавҳаи ёддошти дарс

  • Чор ҳолат: loading (бор мекунем), error (вайрон шуд + «Такрор кардан»), empty (ҷавоб холӣ аст), success (маълумот). Плюс idle — оғоз. Як status ба ҷои бисёр булиҳо.
  • Тартиби санҷишҳо: аввал loading ва error, баъд «холӣ ё не». Вагарна ҳангоми боркунӣ «Ничего не найдено» нишон дода мешавад.
  • fetch ва хатоҳо: шабака нест → промис рад шуд (catch); сервер 404/500 ҷавоб дод → барои fetch муваффақият. Ҳамеша if (!res.ok) throw new Error(...).
  • Ба корбар — матни фаҳмо ва «Такрор кардан»; ҷузъиёти техникӣ — дар console.error.
  • Skeleton: блокҳои хокистарӣ бо ҳамон шакл + background-size: 400% ва аниматсияи background-position; aria-busy; prefers-reduced-motion; мазмунро пурра иваз кардан (replaceChildren).
  • debounce(fn, wait): let timer дар берун, дар дохил clearTimeout(timer); timer = setTimeout(() => fn(...args), wait). Танаффус барои ҷустуҷӯ — 300–500 мс. Debounce — барои ҷараёни ҳодисаҳост, на барои тугмаҳо.
  • AbortController: const c = new AbortController(); fetch(url, { signal: c.signal }); c.abort(); — промис бо AbortError рад мешавад. Контроллер якдафъаина аст; барои дархости нав — нав.
  • Мусобиқаи дархостҳо: дархости нав гузаштаро бекор мекунад; AbortError-ро дар catch хомӯшона мегузаронем. AbortSignal.timeout(мс) — таймаут (TimeoutError).
  • Агенти ЗС (Cursor): тамоми лоиҳаро мебинад, якчанд файлро ислоҳ мекунад. Пеш аз ислоҳҳо нақша мепурсем, diff-ро файл ба файл мехонем, «ҳамаро қабул кун»-ро намепахшем, дар браузер месанҷем (зуд, суст, офлайн, холӣ); сирҳоро ба агент намедиҳем.
