Лоиҳаи хурд: барнома дар API-и оммавӣ

Лоиҳаи дуюм барои портфолио — аллакай «калонсолона»: он барои маълумот ба интернет мераванд, боркуниро нишон медиҳад, аз хатоҳои шабака мегузарад, бо ҳар ҳарф сервер-ро бо дархостҳо пур намекунад ва тавассути Vite ба ҷамъбасти тайёр ҷамъ мешавад. Маҳз ҳамин тавр виҷетҳои обуҳаво, ҷустуҷӯи маҳсулот ва лентаҳои хабарҳо сохта шудаанд. Имрӯз шумо лоиҳаро ҳимоя мекунед, коди ҳамдигарро месанҷед ва Кори назоратии №2-ро бе ЗС менависед.

  • Варианти барномаро дар API-и оммавӣ интихоб кардан ва онро якҷоя бо ЗС ба қадамҳо тақсим намудан
  • Ҳолатҳои loading / error / empty / success-ро нишон додан ва ҷавобҳои кӯҳнаро нишон надодан
  • Дархостҳоро тавассути debounce маҳдуд кардан ва кодро ба модулҳо тақсим намудан
  • Лоиҳаро тавассути Vite ҷамъ кардан (npm run build) ва ба репозиторий бор намудан
  • Лоиҳаро дар 5 дақиқа ҳимоя кардан ва code review-ро дар ҷуфт гузаронидан
  • Кори назоратии №2-ро дар 30 дақиқа навиштан: объектҳо, async/await, fetch, коркарди хатоҳо
  • Ростқавлона таҳлил кардан, ки ЗС дар куҷо вақтро сарфа кард ва дар куҷо аз роҳ бурд
Бо ин саҳифа чӣ тавр кор кардан лозим

Имрӯз ду блок аст. Якум — лоиҳаи хурд: вазифа, меъёрҳои баҳодиҳӣ (0–100), нақша бо ЗС, ду гармкунӣ оид ба ҳолатҳо ва дархостҳо, қолаби ибтидоӣ дар майдончаи озмоишӣ, ревью дар ҷуфтҳо ва ҳимоя. Дуюм — Кори назоратии №2: дар қисми 11 версияи пурраи озмоишӣ бе ишораҳо ҷойгир аст. Барои гармкуниҳо мо ба шабакаи ҳақиқӣ намеравем: ба ҷои fetch «сервери сохта»-ро аз Promise ва setTimeout истифода мебарем — ҳамин тавр натиҷа ҳамеша яксон аст ва онро худкор санҷидан мумкин аст. Лоиҳаи худро шумо дар VS Code-и худ ҷамъ мекунед.

01 Вазифа: вариантро интихоб кунед

Лоиҳа аз он чизе ҷамъ мешавад, ки дар дарсҳои 13–17 гузаштед: ғайримуттаҳидӣ (async), fetch, ҳолатҳои боркунӣ, debounce, модулҳо ва ҷамъбасти Vite. Яке аз се вариантро интихоб кунед. Ҳамаи онҳо бо як меъёр баҳо дода мешаванд, API-ҳо ҳама кушода ҳастанд ва калид талаб намекунанд.

Варианти А. Ҷустуҷӯи маҳсулот

Майдони ҷустуҷӯ, дар зери он — кортаҳои маҳсулот. Дархост бо таъхир (debounce) мерасад, то боркунӣ меравад — нишондиҳанда, агар чизе наёфтанд — паёми фаҳмо.

API: dummyjson.com/products/search?q=phone&limit=10

Варианти Б. Обуҳаво дар шаҳрҳо

Рӯйхати шаҳрҳо (Душанбе, Хуҷанд, Бохтар, Кӯлоб ва шаҳрҳои худатон). Шаҳрро интихоб мекунед — ҳарорат ва шамолро мебинед. Хатои шабакаро бо тугма такрор кардан мумкин аст.

API: api.open-meteo.com/v1/forecast бо параметрҳои latitude, longitude, current=temperature_2m,wind_speed_10m

Варианти В. Одамон ва постҳои онҳо

Ҷустуҷӯи корбар аз рӯи ном, ҳангоми интихоб — постҳои ӯ. Ду дархости вобаста: аввал одам, баъд сабтҳои ӯ.

API: jsonplaceholder.typicode.com: /users ва /posts?userId=1

Мураккабӣ тақрибан баробар аст: дар маҳсулот мантиқи ҷустуҷӯ бештар аст, дар обуҳаво — таҳлили ҷавоби дарунҷойгир, дар корбарон — дархостҳои вобаста. Ғояи худро дар API-и кушодаи дигар пешниҳод кардан мумкин аст, агар он калид надошта бошад, аз браузер (CORS) кор кунад ва ҳаҷмаш ҳамон қадар бошад — инро бо муаллим пеш аз оғози кор мувофиқа кунед.

Монандӣ аз ҳаёт

Шумо дар чойхона тавассути пешхизмат палав фармоиш медиҳед. То он замон, ки мепазад — «фармоиш қабул шуд»-ро мебинед (loading). Агар палав нест — пешхизмат ростқавлона мегӯяд «тамом шуд» (empty), ва агар дар ошхона хатогӣ рух дод — «бубахшед, боз кӯшиш кунед» (error). Пешхизмати бад хомӯш аст ва умуман ҷавоб намедиҳад — ва шумо намедонед, интизор шавед ё равед. Барномаи шумо бояд мисли пешхизмати хуб рафтор кунад.

Дар охир чиро нишон медиҳед

  1. Барномаи корӣ — бе хато дар консол кушода мешавад, ҳангоми хомӯш будани шабака хатои ботартибро нишон медиҳад.
  2. Репозиторий дар GitHub бо коди Vite, README ва скриншот; фармони npm run build бе хато мегузарад.
  3. Ҳимояи 5-дақиқагӣ — намоиш, шарҳи код ва ҷавоб ба саволҳо.
  4. Таҳлили кӯтоҳи «ЗС дар лоиҳа» — қисми 12: ЗС дар куҷо кумак кард, дар куҷо аз роҳ бурд.
Қоидаҳои курс дар ин ҷо ҳам амал мекунанд

ЗС-ро истифода бурдан мумкин аст, аммо: аввал 15 дақиқа худатон кӯшиш мекунед, кодеро, ки сатр ба сатр фаҳмонида наметавонед, намегузоред, ва дар ҳимоя муаллим ҳақ дорад, ки хоҳиш кунад ҳар кадом сатрро фаҳмонед. Натавонистед — холҳои ин қисм кам карда мешаванд. Аммо дар Кори назоратии №2 ЗС комилан хомӯш аст.

02 Талабот: MVP ва бонусҳо

MVP — версияи ҳадди ақал, ки аллакай аз аввал то охир кор мекунад. Аввал онро пурра месозем, ва танҳо баъд оро медиҳем. Лоиҳа бе MVP баҳои баланд намегирад, ҳар қадар бонус дар он бошад ҳам.

MVP — барои ҳамаи вариантҳо ҳатмист

№ТалаботЧӣ тавр месанҷем
1Маълумот аз API-и оммавӣ тавассути fetch ва async/await меояддар ҷадвали Network дархост намоён аст, дар код маълумоти «холӣ»-и ҷойгузин нест
2Санҷиши response.ok: ҷавоби 404 ё 500 хато ҳисоб мешавад, на маълумотдар код if (!response.ok) throw … ҳаст
3Ҳолати loading: то дархост меравад — нишондиҳанда, майдон ё тугма иҷозат намедиҳанд дархости дукарата фиристода шавадSlow 3G-ро дар DevTools фаъол мекунем

5Ҳолати empty: «Ҳеҷ чиз ёфт нашуд» ба ҷои экрани холӣдархости бемаъно ворид мекунем
6Ҷустуҷӯ ё интихоб (аз рӯи вариант) бо debounce ё тугмаи возеҳ; дархости холӣ ба сервер намеравадзуд менависем: дар Network на зиёда аз як дархост
7Ҷавоби кӯҳна ҷавоби тозаро намепӯшонад (ҳисобкунаки дархостҳо ё AbortController)дархостро зуд иваз мекунем — дар экран охирин аст, на пеш аз охирин
8Код ба модулҳои ES тақсим шудааст: api.js, ui.js (ё render.js), main.jsсохтори папкаи src/

Бонусҳо — пас аз MVP

  • Скелетонҳо ба ҷои калимаи «Боркунӣ…» (блокҳои хокистарӣ дар зери кортаҳо).
  • Кэш-и дархостҳои охирин: ҳамон дархост бори дуюм ба шабака намеравад.
  • Таймаути дархост тавассути Promise.race ё AbortController бо паёми худӣ.
  • Таърихи ҷустуҷӯ ё интихобшудаҳо дар localStorage.
  • Такрори худкор ҳангоми хато: то се кӯшиш бо таваққуф.
  • Мавзӯи торик бо нигоҳ доштани интихоб.
  • Саҳифабандӣ ё тугмаи «Бештар нишон додан» (limit ва skip дар dummyjson).
Маслиҳат

Бонус танҳо дар сурате қадр карда мешавад, ки шумо ҳар сатри онро фаҳмонда тавонед. Як кэши оддӣ, ки шумо мефаҳмед, аз се порчаи «сеҳрноки» чати ЗС беҳтар аст.

Чӣ холҳоро кам мекунад

  • Коди худро фаҳмонда наметавонед — дар меъёре, ки қисми нофаҳмо ба он тааллуқ дорад, холҳоро гум мекунед.
  • Маълумот «сахт дар код навишта шудааст» ба ҷои дархости ҳақиқӣ — меъёри «fetch ва async/await» 0 мегирад.
  • Дар муҳлат супурда нашуд — то −10 хол, бо мувофиқа бо муаллим.
  • Код пурра аз донишҷӯи дигар ё аз чат бе фаҳмиш нусха шудааст — 0 барои лоиҳа. Ба якдигар кумак кардан мумкин ва лозим аст, аммо ҳар кас аз они худро менависад ва мефаҳмад.

04 Таҷзия: лоиҳаро якҷоя бо ЗС ба қисмҳо тақсим мекунем

Лоиҳа бо API аз якумӣ хатарноктар аст: шабака, интизорӣ ва хатоҳо пайдо шуданд, ки «бо фармоиш» такрор намешаванд. Барои ҳамин нақша махсусан муҳим аст. Ғоя ҳамон аст, ки дар дарси 12: аввал қадамҳо, баъд код, ва ҳар қадам натиҷаи намоён дорад. Аммо акнун дар нақша бояд қадамҳои алоҳида барои ҳар ҳолат (loading, error, empty) ва барои ҷойҳои «хатарнок» бошад: дархости аввал, рақобати ҷавобҳо, ҷамъбаст.

Монандӣ аз ҳаёт

Сафар бо маршрутка аз Душанбе ба Хуҷанд: бояд пешакӣ истгоҳҳо, вақти роҳ ва варианти эҳтиётиро донист, агар роҳро бандад. «Ба ягон тарз меравам» — роҳ ба ҳеҷ ҷо. Нақша бо варианти эҳтиётӣ — ин ҳолатҳои error ва «Такрор»-и шумост.

Блоки ЗС: вазифаи калон — маълум нест аз куҷо оғоз кардан

ЗС рӯйхати қадамҳоро хуб пешниҳод мекунад, аммо тартиб, зиёдатӣ ва баҳодиҳии вақтро шумо месанҷед. Дархостро аз рӯи формулаи курс тартиб диҳед: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш.

бо JS барномаи обуҳаво бисоз
Контекст: ман донишҷӯи курси JavaScript ҳастам, лоиҳаи таълимии «обуҳаво дар шаҳрҳои Тоҷикистон»-ро бо JS-и тоза + Vite месозам, бе фреймворкҳо. API: open-meteo (бе калид). Аллакай медонам: fetch, async/await, try/catch, ҳолатҳои loading/error/empty, debounce, модулҳои ES. Вазифа: лоиҳаро ба 10–14 қадам, ҳар кадом 20–40 дақиқа, бо тартиби иҷро тақсим кун. Маҳдудиятҳо: бе китобхонаҳо; модулҳои api.js, ui.js, main.js; дар MVP — интихоби шаҳр, дархост, се ҳолат, тугмаи «Такрор», муҳофизат аз ҷавобҳои кӯҳна. Бонусҳо — рӯйхати алоҳида дар охир. Код нанавис. Формати ҷавоб: рӯйхати рақамгузорӣшуда. Барои ҳар қадам: ном, пас аз он чӣ бояд кор кунад, баҳои вақт бо дақиқа. Санҷиш: пас аз рӯйхат 3 ҷойро номбар кун, ки навомӯз дар кор бо fetch бештар хато мекунад, ва чӣ тавр онҳоро пай бурдан мумкин аст.

Дархости аввал маҷмӯи тасодуфии калимаҳо ё фавран тамоми кодеро медиҳад, ки шумо фаҳмонида наметавонед. Дуюм — нақшае, ки бо он кор кардан мумкин аст. Аммо ин танҳо нусхаи пешакӣ аст. Мисоли нақша пас аз таҳрири шумо:

06 Гармкунии 2. Debounce, кэш ва таймаут

Агар барои ҳар ҳарфи пахшшуда дархост фиристем, сервер даҳҳо муроҷиати зиёдатӣ мегирад, ва экран милт-милт мекунад. Debounce инро ҳал мекунад: функсия танҳо вақте кор мекунад, ки корбар барои вақти додашуда хомӯш шуд. Ҳар даъвати нав таймерро аз сифр мекунад ва навашро оғоз менамояд.

function debounce(fn, ms) {
  let timer;
  return (...args) => {
    clearTimeout(timer);                           // таймери гузаштаро бекор кардем
    timer = setTimeout(() => fn(...args), ms);     // навашро оғоз кардем
  };
}

const search = debounce((q) => console.log("запрос:", q), 30);
search("п");
search("пл");
search("плов");      // танҳо ҳамин даъват кор мекунад, пас аз 30 мс

08 Қолаби ибтидоӣ: ҷустуҷӯ бо ҳолатҳо

Дар зер — скелети барнома бо ҷустуҷӯ дар майдончаи озмоишӣ. То ки натиҷа ҳамеша яксон бошад, ба ҷои сервери ҳақиқӣ дар он «сохта» (fakeSearch) истифода шудааст; ва дар паҳлӯ realSearch бо fetch-и ҳақиқӣ меистад — дар лоиҳаи худ шумо онро бо як сатр ҷойгузин мекунед. Код ба блокҳо бо ҳамон тартибе тақсим шудааст, ки шарҳ додани он дар ҳимоя қулай аст: «сервер» → ҳолат → DOM ва тасвир → ҷустуҷӯ → ҳодисаҳо.

  1. «Сервер». Маълумот ва функсияҳое, ки промис бармегардонанд: сохта ва ҳақиқӣ.
  2. Ҳолат. Як объекти { status, items, error } ва ҳисобкунаки дархостҳои latestId.
  3. Тасвир. render() интерфейсро аз state месозад. Дигар касе ба DOM даст намезанад.
  4. Ҷустуҷӯ. search(query): loading → success ё error, ҷавобҳои кӯҳна нодида гирифта мешаванд.
  5. Ҳодисаҳо. Майдони ворид бо debounce.

▶ Иҷро кардан-ро пахш кунед: худсанҷии поён чоп мекунад, ки ҳоло чӣ кор намекунад. Вазифаи шумо — чор қайди TODO.

Саволҳои маъмул ва дар бораи чӣ гуфтан лозим

async/await чист ва аз then чӣ фарқ дорад?
Ин ҳамон Promise аст, аммо код аз боло ба поён хонда мешавад. await функсияро то ҷавоб «таваққуф мекунад», бе қуфл кардани саҳифа.
Барои чӣ response.ok лозим аст? Магар fetch дар 404 намеафтад?
Не: fetch танҳо ҳангоми мушкили шабака рад мекунад. Ҷавоби 404/500 — «муваффақ» аст, зеро сервер ҷавоб дод. Статусро худатон бояд санҷед.
Барои чӣ await response.json(), ин ахир аллакай ҷавоб аст?
Сарлавҳаҳо омаданд, аммо баданаи ҷавоб алоҳида ва ҳамчунин ғайримуттаҳид хонда мешавад.
Debounce чист ва барои чӣ дар ин ҷо лозим аст?
Функсия пас аз таваққуф кор мекунад. Бе он ҳар ҳарф — дархост: сарбории зиёдатӣ ва экрани «милтилдеанда».
Рақобати ҷавобҳо чист ва шумо онро чӣ тавр ҳал кардед?
Ҷавоб ба дархости кӯҳна метавонад дертар аз ҷавоб ба дархости нав расад ва онро бипӯшонад. Ҳал: рақами дархост (танҳо тозаро татбиқ мекунем) ё AbortController.
Ҳолатҳои шумо чӣ тавр сохта шудаанд?
Як объекти state бо status, items, error; render аз он тасвир мекунад. Маҷмӯи парчамҳое нест, ки метавонанд бо якдигар зиддият кунанд.
Дар api.js чӣ ҳаст, дар ui.js чӣ, ва барои чӣ ин тавр?
Дар api.js танҳо шабака, дар ui.js танҳо DOM, main.js пайваст мекунад. Ҳамин тавр ҳар қисмро алоҳида тағйир додан ва санҷидан мумкин аст.
npm run build чӣ кор мекунад ва дар dist чӣ меистад?
Vite модулҳоро ба файлҳои барои хостинг тайёр ҷамъ мекунад. dist-ро ба Git намегузоранд: онро аз нав ҷамъ кардан мумкин аст.
ЗС-ро дар куҷо истифода кардед? Ин сатрро шарҳ диҳед.
Ростқавлона бигӯед, барои чӣ (нақша, шарҳи хато, ревью) ва дар куҷо ӯ хато кард — қисми 12. Ҳар сатрро бояд бо суханони худатон шарҳ диҳед.

Маслиҳатҳо барои омодагӣ

  • Намоишро бо овози баланд бо секундомер такрор кунед. Offline дар DevTools → Network → «No throttling» → Offline фаъол мешавад.
  • Файлҳои даркориро пешакӣ кушоед, ҳуруфро калон кунед: гурӯҳ бояд кодро бубинад.
  • Зиёдатиро хориҷ кунед: console.log, коди шарҳшуда.
  • Узр наовардед («натавонистам»). Беҳтараш: «ин нест, зеро… инак ман онро чӣ тавр илова мекардам».

12 Таҳлил: ЗС дар куҷо вақтро сарфа кард ва дар куҷо аз роҳ бурд

Ин блоки ЗС-и дарс аст: пас аз ду лоиҳа муҳим аст, ки на танҳо «ЗС-ро истифода баред», балки қимати ҳақиқии онро донед. Аксар вақт ба назар мерасад, ки ЗС корро тезонд, баъд шумо як соат хатоиро дар коди бегона ва нофаҳмо меҷустед. Баръакс низ мешавад: ЗС дар се дақиқа он чизро шарҳ дод, ки шумо як шом сарф мекардед. Барои фарқ кардани якдигар на эҳсосот, балки сабтҳо лозиманд.

Қоидаҳои курс, ки ҳоло месанҷем

№1: аввал 15 дақиқа худам, баъд ЗС. №2: кодеро, ки сатр ба сатр фаҳмонида наметавонӣ, намегузорем. №5: ЗС нусхаи пешакӣ менависад — ту мантиқ, номҳо ва ҳолатҳои канориро месанҷӣ. Таҳлил нишон медиҳад, ки ин қоидаҳоро дар куҷо риоя кардед ва дар куҷо не.

Монандӣ аз ҳаёт

Навигатор дар мошин. Дар шоҳроҳи ношинос дар вилояти Суғд ӯ соатҳоро сарфа мекунад. Аммо агар кӯркӯрона ба ҳар ҷое ки ӯ мегӯяд равед, метавонед ба роҳи баста расед. Ронандаи хуб медонад, ки ба куҷо рафтан мехоҳад, ва ишораҳоро бо аломатҳо муқоиса мекунад. ЗС низ навигатор аст: ҳадаф ва санҷиш бар дӯши шумо мемонад.

✓ Варақаи кӯмакии дарс

  • Лоиҳа: барнома дар API-и оммавӣ (маҳсулот, обуҳаво ё корбарон) дар Vite. Баҳо 0–100: MVP 20, fetch ва async/await 20, ҳолатҳо 15, debounce ва назорати дархостҳо 10, модулҳо 10, ҷамъбаст ва репозиторий 5, интерфейс 5, ҳимоя 15; бонус то +5.
  • fetch: await fetch(url) → if (!response.ok) throw … → await response.json(). fetch танҳо ҳангоми нокомии шабака меафтад, 404 ва 500 — ҷавобҳои «муваффақ».
  • Ҳолатҳо: як объекти { status, items, error }, status: idle / loading / success / error; success-и холӣ — ин empty аст. Иваз шудани статус майдонҳои зиёдатиро тоза мекунад.
  • try/catch/finally: catch ба корбар паёми фаҳмо нишон медиҳад, на хомӯш мемонад; finally ҳамеша иҷро мешавад.
  • Мувозӣ ё пай дар пай: дархостҳои мустақил — Promise.all, вобастаҳо — await пай дар пай. Promise.race — барои таймаут.
  • debounce: таймерро ҳангоми ҳар даъват аз сифр мекунем; пас аз таваққуф кор мекунад. Дархости холиро ба сервер намефиристем.
  • Рақобати ҷавобҳо: рақами дархост (myId !== latestId → нодида) ё AbortController.
  • Модулҳо: api.js — шабака, ui.js — DOM, main.js — пайвандак; пеш аз ҳимоя npm run build + preview; dist ва node_modules дар Git нестанд.
  • Ревью: иҷро (Offline, Slow 3G, партов) → хондан аз рӯи чек-лист → мулоҳиза = дар куҷо, чӣ мебинам, чаро, пешниҳод.
  • Кори назоратии №2: 30 дақиқа, бе ЗС, мавзӯъҳо — объектҳо, async/await, fetch, хатоҳо; 10 вазифа бо санҷиши худкор.
  • ЗС дар лоиҳа: эпизодҳоро сабт кунед (чӣ пурсидам → чӣ гирифтам → натиҷа → ± дақиқа → чӣ тавр санҷидам). ЗС аксар вақт ok-ро фаромӯш мекунад, хатоҳоро фурӯ мебарад ва майдонҳои API-ро меандешад — санҷиш бар дӯши шумо мемонад.
