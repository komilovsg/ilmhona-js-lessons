Дарси 8 · DOM

DOM: ҷустуҷӯ ва тағйири унсурҳо

То ҳол JavaScript дар консол зиндагӣ мекард: мо ҳисоб мекардем, филтр мекардем ва матн мебароридем. Имрӯз вай ба саҳифа мебарояд. Феҳристи молҳо, сабад, рӯйхати вазифаҳо, баҳоҳо дар кабинети шахсӣ — ҳамаи инро дар сайтҳои воқеӣ JavaScript мекашад, ки ҷойи лозимиро дар саҳифа меёбад ва онро тағйир медиҳад. Имрӯз шумо саҳифаеро месозед, ки тамоми мундариҷааш аз массив эҷод мешавад.

  • Шарҳ додан, ки DOM чист ва аз файли HTML чӣ фарқ дорад
  • Унсурҳоро тавассути querySelector ва querySelectorAll ёфтан
  • Матн, ҳамбандӣ (разметка), классҳо, атрибутҳо ва data-*-ро тағйир додан
  • Унсурҳоро тавассути createElement эҷод кардан, ҷойгир кардан ва нест кардан
  • Рӯйхати кортҳоро аз массиви объектҳо кашидан ва тоза кардан
  • Кори худро бо ЗС тақсим кардан: ӯ ҳамбандӣ ва услубҳоро менависад, шумо — мантиқро
Бо ин саҳифа чӣ тавр кор кардан лозим

Дар ин дарс қуттиҳои реги (песочница) бисёранд. Дар ҳар кадом се ҷадвалча: index.html (ҳамбандӣ), style.css (услубҳо, агар бошанд) ва script.js (коди шумо). ▶ Иҷро ё Ctrl + Enter-ро пахш кунед — дар поён саҳифаи зинда пайдо мешавад, ва дар зери он — консол. Вазифаҳо аз рӯи он санҷида мешаванд, ки шумо тавассути console.log чиро баровардед, бинобар ин сатрҳои баромадро дар ҷояшон гузоред. Ишораҳо пинҳонанд: аввал худатон кӯшиш кунед.

Як қоидаи қуттии реги: ҳамбандии шумо дар <body> танҳо нест — пас аз он браузер <script>-ҳои хидматиро илова мекунад. Бинобар ин мо мундариҷаро ҳамеша ба як печонак мегузорем ё унсурҳоро бо селектор меҷӯем, на ин ки кӯдакони body-ро ҳисоб кунем.

01 DOM чист

Шумо HTML менависед — ин матни оддӣ дар файл аст. Вақте браузер саҳифаро мекушояд, ин матнро мехонад ва аз он дарахти объектҳо-ро месозад. Ин дарахт DOM — Document Object Model, «модели объектии ҳуҷҷат» ном дорад. Ҳар тег ба объект табдил меёбад, ки хосиятҳо (матн, классҳо, андозаҳо) ва методҳо дорад. Маҳз бо ҳамин объектҳо JavaScript кор мекунад.

Монандӣ аз ҳаёт

Файли HTML — менюи чопшуда дар ҷузвдон аст. DOM — дастурхони густурда дар чойхона аст, ки аз рӯи ин меню сохта мешавад. Пешхизмат (JavaScript) метавонад ба дастурхон боз як самбуса гузорад, косаи холиро бардорад ё чойро иваз кунад. Менюи чопшуда дар ҷузвдон аз ин тағйир намеёбад. Саҳифаро навсозӣ кардед — дастурхон аз нав аз рӯи меню густурда мешавад.

Инак саҳифаи оддӣ ва дарахте, ки аз он ҳосил мешавад:

<body>
  <h1>Меню</h1>
  <ul class="menu">
    <li>Самбуса</li>
    <li>Курутоб</li>
  </ul>
</body>
document
Решаи тамоми дарахт ва «дари даромад» ба саҳифа. Тавассути он шумо унсурҳоро меҷӯед: document.querySelector(...).
Унсур
Объекти мувофиқ ба тег: <h1>, <li>, <div>. Маҳз онҳоро мо меҷӯем, тағйир медиҳем, эҷод мекунем ва нест мекунем.
Волидайн ва кӯдакон
<ul> — волидайни ду <li>. Ду <li> — ҳамсоя (siblings).
Гиреҳи матнӣ
Порчаи матн дар дохили унсур. Фосилаҳо ва гузаришҳои сатр байни тегҳо — низ гиреҳҳои матнианд.

DOM-ро бо чашми худ чӣ тавр дидан

Ягон сайтро кушоед, F12-ро пахш кунед ва ба ҷадвалчаи Elements гузаред. Ин маҳз DOM-и зинда аст: шумо дарахтро мебинед, ба унсурҳо клик карда метавонед, матнро бо ду клик тағйир диҳед, тегҳоро кашед — ва саҳифа фавран вокуниш нишон медиҳад. Худи файл ҳангоми ин тағйир намеёбад. Унсури дар Elements интихобшуда дар консол чун $0 дастрас аст.

Дар дарахт мегардем

Ҳар унсур «тирҳо» ба гиреҳҳои ҳамсоя дорад. Онҳо вақте ба кор меоянд, ки як унсур ёфт шуд ва ба ҳамсояҳо расидан лозим аст:

// body.firstElementChild — унсури аввали ҳамбандии мо, яъне <ul>
const menu = document.body.firstElementChild;

console.log(menu.tagName);                      // UL
console.log(menu.children.length);              // 3
console.log(menu.firstElementChild.textContent); // Самбуса
console.log(menu.lastElementChild.textContent);  // Шакароб

const second = menu.children[1];                 // кӯдакон мисли массив меистанд: 0, 1, 2
console.log(second.textContent);                 // Курутоб
console.log(second.previousElementSibling.textContent); // Самбуса
console.log(second.parentElement.tagName);       // UL

textContent — матни дохили унсур. Муфассалтар дар бораи он — дар бахши сеюм, ҳоло танҳо истифода баред.

Хатои маъмул: childNodes ба ҷойи children

Хосияти монанди childNodes ҳаст. Он ҳамаи гиреҳҳоро, аз ҷумла фосилаҳо ва гузаришҳои сатр байни тегҳоро бармегардонад. Бинобар ин «кӯдакон» аз он ки бо чашм мебинед, бештар мебароянд. Барои кор бо унсурҳо children ва оилаи ...ElementChild, ...ElementSibling-ро истифода баред.

const box = document.createElement("div");
box.innerHTML = `
  <p>Один</p>
  <p>Два</p>
`;

console.log(box.children.length);    // → 2 — ду банд
console.log(box.childNodes.length);  // → 5 — ду банд ва се гиреҳи матнии «холӣ»

02 Ҷустуҷӯи унсурҳо: querySelector

Барои чизеро дар саҳифа тағйир додан, аввал бояд ин «чиз»-ро ёфт. Барои ҷустуҷӯ дар JavaScript-и муосир қариб ҳамеша ду метод кофист. Асосӣ: дар онҳо шумо селектори оддии CSS-ро менависед — ҳамон, ки дар файли услубҳо ҳаст. Забони нав омӯхтан лозим нест.

document.querySelector(селектор)
Аввалин унсури мувофиқро бармегардонад. Агар чизе ёфт нашавад — null.
document.querySelectorAll(селектор)
Рӯйхати ҳамаи унсурҳои мувофиқро (NodeList) бармегардонад. Агар чизе набошад — рӯйхати холӣ, на null.
<h1 id="title">Чайхона «Сомон»</h1>
<ul class="menu">
  <li class="item">Курутоб</li>
  <li class="item">Оши палав</li>
  <li class="item hot">Шакароб</li>
</ul>

const title = document.querySelector("#title");        // аз рӯи id
const first = document.querySelector(".item");         // аз рӯи класс — аввалини се
const hot = document.querySelector(".item.hot");       // ду класс якбора
const all = document.querySelectorAll(".item");        // ҳар се

console.log(title.textContent);   // Чайхона «Сомон»
console.log(first.textContent);   // Курутоб
console.log(hot.textContent);     // Шакароб
console.log(all.length);          // 3

Шумо дар Бозори Сабз истодаед ва мегӯед: «Барои ман аввалин чодари зардолуи хушкро ёбед» — ин querySelector аст. Ва «Ба ман ҳамаи чодарҳои зардолуи хушкро нишон диҳед» — ин querySelectorAll аст. Селектор — ин тавсифи шумо аз чодар аст: аз рӯи рақам (#id), аз рӯи лавҳа (.class) ё аз рӯи навъ (li).

NodeList: ба массив монанд аст, аммо массив нест

querySelectorAll NodeList бармегардонад. Он .length дорад, ба унсурҳо бо индекс муроҷиат кардан мумкин аст, онро тавассути for...of ва forEach гузаштан мумкин аст. Аммо методҳои map, filter ва reduce надорад. Агар лозим бошанд — ба массиви воқеӣ табдил медиҳем:

const box = document.createElement("div");
box.innerHTML = `<p class="n">10</p><p class="n">20</p><p class="n">30</p>`;

const nodes = box.querySelectorAll(".n");

console.log(nodes.length);         // → 3
console.log(nodes[1].textContent); // → 20

nodes.forEach(p => console.log("p:", p.textContent));   // forEach ҳаст

const numbers = Array.from(nodes).map(p => Number(p.textContent)); // map — танҳо дар массив
// ҳамон чиз: [...nodes].map(...)
console.log(numbers);              // → [10, 20, 30]

На дар тамоми саҳифа, балки дар дохили унсур меҷӯем

Методи querySelector на танҳо дар document, балки дар ҳар унсур ҳам ҳаст. Он гоҳ ҷустуҷӯ танҳо дар дохили он мегузарад. Ин вақте муҳим аст, ки дар саҳифа кортҳои якхелаи бисёр ҳастанд ва нархро маҳз аз ҳамин корт гирифтан лозим аст:

<div class="card"><span class="name">Шапка</span> — <span class="price">60</span></div>
<div class="card"><span class="name">Шарф</span> — <span class="price">45</span></div>

const cards = document.querySelectorAll(".card");

for (const card of cards) {
  const name = card.querySelector(".name").textContent;   // танҳо дар дохили card меҷӯем
  const price = card.querySelector(".price").textContent;
  console.log(name + ": " + price);
}

Методҳои кӯҳна низ ҳастанд: getElementById("title"), getElementsByClassName, getElementsByTagName. Онҳо кор мекунанд, ва шумо онҳоро дар коди бегона вомехӯред, аммо querySelector универсалтар аст — як усулро дар хотир доштан кифоя аст.

Хатои маъмул: унсур ёфт нашуд (null)

Агар querySelector чизеро наёфта бошад, null бармегардонад. Ва null на textContent дорад, на хосиятҳои дигар — машҳуртарин хатои DOM-ро мегирем. Сабабҳо одатан се ҳастанд: хатои имлоӣ дар селектор, нуқта ё решёткаи фаромӯшшуда ("item" ба ҷойи ".item"), ё скрипт пештар аз пайдо шудани унсур дар саҳифа оғоз шуд.

const price = document.querySelector(".price"); // дар саҳифа чунин унсур нест → null
console.log(price);                              // → null
console.log(price.textContent);                  // ✖ TypeError: Cannot read properties of null

Дар бораи сабаби сеюм: дар лоиҳаи воқеӣ скриптро бо атрибути defer пайваст кунед — он гоҳ он пас аз он иҷро мешавад, ки браузер тамоми дарахтро сохт. Дар қуттиҳои реги дарс ин аллакай барои шумо анҷом дода шудааст.

<body>
  <ul id="list"></ul>
  <script src="script.js" defer></script>
</body>
Одат барои тамоми умр

Унсурҳои ёфтшударо ба тағйирёбандаҳо як бор дар оғози скрипт гузоред: const list = document.querySelector("#list");. Як унсури якхеларо даҳ бор наҷӯед — код кӯтоҳтар мешавад, ва браузер зудтар.

03 Мундариҷаро тағйир медиҳем: textContent ва innerHTML

Унсур ёфт шуд. Акнун он чиро, ки дар дохили он аст, хондан ва иваз кардан мумкин аст. Барои ин ҳар унсур ду хосияти асосӣ дорад. Онҳо монанданд, аммо корҳои гуногун мекунанд — ва фарқ на танҳо барои зебоӣ, балки барои бехатарӣ низ муҳим аст.

textContent — танҳо матн

Матни оддӣ-ро мехонад ва менависад. Ҳар гуна < ва > оддӣ аломат ҳисоб мешаванд, тегҳо эҷод намешаванд. Зуд ва бехатар.

innerHTML — матн ва ҳамбандӣ

Сатри HTML-ро мехонад ва менависад. Тегҳои дохилӣ ба унсурҳои воқеӣ табдил меёбанд. Қудратманд, аммо хатарнок аст, агар дар сатр матни бегона бошад.

<h2 id="dish">Загрузка…</h2>
<div id="box">Старое содержимое</div>

const dish = document.querySelector("#dish");
const box = document.querySelector("#box");

dish.textContent = "Оши палав";            // матнро иваз кардем
console.log(dish.textContent);              // Оши палав

box.innerHTML = "<b>Цена:</b> 35 сомони";   // теги <b> унсури воқеӣ мешавад
console.log(box.children.length);           // 1 — дар дохил <b> пайдо шуд
console.log(box.innerHTML);                 // <b>Цена:</b> 35 сомони
console.log(box.textContent);               // Цена: 35 сомони — танҳо матн, бе тегҳо
Монандӣ аз ҳаёт

Тасаввур кунед, ки шумо торт бо навишта фармоиш медиҳед. textContent — вақте ки қаннод дар торт маҳз он чиро, ки шумо гуфтед менависад, ҳатто агар аломатҳои аҷибро гуфта бошед. innerHTML — вақте ки шумо ба қаннод дастур медиҳед: «дар ин ҷо ороиш гузор, ва дар ин ҷо навиштаи ғафс кун». Вай дастурро айнан иҷро мекунад. Агар дастурро шахси бегона навишта бошад — вай метавонад қанноддро водор кунад, ки ҳар чизро кунад.

Мехонем ва менависем

  • el.textContent — тамоми матни дохили унсурро хондан (аз ҷумла тегҳои дарунравӣ, аммо бе худи тегҳо).
  • el.textContent = "матни нав" — тамоми мундариҷаро бо як матн иваз кардан.
  • el.innerHTML — мундариҷаро якҷоя бо тегҳо чун сатр хондан.
  • el.innerHTML = "<b>ғафс</b>" — мундариҷаро иваз кардан, сатрро чун HTML таҳлил карда.

Боз innerText ҳаст: вай CSS-ро ба назар мегирад ва матни пинҳонро нишон намедиҳад. Барои кори оддӣ textContent-ро гиред — вай соддатар ва пешбинишавандатар аст.

Чаро innerHTML хатарнок аст

Фарз мекунем, дар сайти шумо корбар шарҳ менависад, ва шумо онро тавассути innerHTML ба саҳифа ҷойгир мекунед. Агар ба ҷойи «Курси аъло!» ӯ теги махсус омодакардаи <img>-ро бо коди пинҳонӣ нависад — браузер ин унсурро эҷод мекунад ва коди бегонаро дар саҳифаҳои дигар боздидкунандагон иҷро мекунад. Чунин ҳамла XSS номида мешавад ва аз маъмултарин ҳамлаҳо дар веб мебошад.

Қоидаи бехатарӣ

Ҳар чизе, ки аз корбар, аз шакл, аз сатри суроға ё аз API-и берунӣ омад, тавассути textContent ҷойгир кунед. innerHTML — танҳо барои ҳамбандие, ки худатон навиштаед (ё ЗС, ва шумо онро санҷидед). Бинед, фарқ чӣ гуна менамояд:

const safe = document.createElement("div");
safe.textContent = comment;          // матн матн монд
console.log(safe.children.length);   // → 0 — ягон теги нав пайдо нашуд

const risky = document.createElement("div");
risky.innerHTML = comment;           // сатр чун HTML таҳлил шуд
console.log(risky.children.length);  // → 1 — теги воқеии <b> пайдо шуд

Қапқон: += барои innerHTML

Навишти list.innerHTML += "<li>…</li>" чун «ба охир илова кардан» менамояд, аммо дар асл браузер тамоми рӯйхатро хароб мекунад ва аз нав ҷамъ мекунад. Ҳамаи унсурҳои қаблан ёфтшуда дар тағйирёбандаҳои шумо пайванд бо саҳифаро гум мекунанд.

const list = document.createElement("ul");
list.innerHTML = "<li>Нон</li>";

const first = list.firstElementChild;     // банди аввалро дар хотир гирифтем
list.innerHTML += "<li>Чой</li>";         // «илова кардем» дуюмро

console.log(list.children.length);             // → 2
console.log(first === list.firstElementChild); // → false — ин аллакай унсури дигар, нав аст!
console.log(list.contains(first));             // → false — банди кӯҳна партофта шуд

Дар бахши 5 шумо мефаҳмед, ки унсурҳоро бе чунин таъсири иловагӣ чӣ тавр илова кардан мумкин — тавассути createElement ва append.

Рӯйхатро бо сатр ҷамъ мекунем

Агар ҳамбандиро худатон менависед, ва додаҳо бехатаранд (массиви шумо, на воридоти корбар), қулай аст, ки HTML-ро бо сатрҳои қолабӣ ва методҳои массив, ки шумо аллакай медонед, ҷамъ кунед:

console.log(html);   // → <li>Самбуса</li><li>Курутоб</li><li>Шакароб</li>

const menu = document.createElement("ul");
menu.innerHTML = html;
console.log(menu.children.length); // → 3

04 Классҳо, услубҳо ва атрибутҳо

Намуди зоҳирии унсур қариб ҳамеша дар CSS муайян мешавад. JavaScript набояд саҳифаро худаш ранг кунад, кори он — ба кор андохтан ва хомӯш кардани классҳои тайёр аст. Шумо дар CSS менависед, ки .hot чӣ гуна менамояд, ва дар JS танҳо қарор медиҳед, ки кай онро ба унсур диҳед. Ҳамин тавр код тоза мемонад, ва тарроҳӣ дар як ҷой тағйир меёбад.

Монандӣ аз ҳаёт

Класс — ин нишони шахсӣ дар курс аст: бейҷи «омӯзгор», «донишҷӯ», «меҳмон». Бейҷро як бор ихтироъ карданд, тарроҳиро тасдиқ карданд. Посбон (JS) ба ҳар кас бейҷи нав намекашад, балки танҳо тайёрро медиҳад ё мегирад. Додан — add, гирифтан — remove, ба муқобил иваз кардан — toggle.

classList: классҳоро идора мекунем

МетодЧӣ мекунад
el.classList.add("hot")классро илова мекунад (агар аллакай бошад — чизе рӯй намедиҳад)
el.classList.remove("old")классро мебарорад
el.classList.toggle("open")бошад — мебарорад, набошад — илова мекунад
el.classList.contains("hot")true ё false бармегардонад
el.classList.replace("old", "new")як классро бо дигаре иваз мекунад

Хатои маъмул: className = "…" ҳамаи классҳоро пок мекунад

Хосияти className тамоми сатри классҳоро нигоҳ медорад. Агар ба он қимати нав нависед, ҳамаи классҳои пешина нест мешаванд. Барои илова ва нест кардан classList-ро истифода баред.

const el = document.createElement("div");
el.className = "card sale";

el.className = "hot";                 // «card» ва «sale»-ро пок кардем!
console.log(el.className);            // → hot

el.className = "card sale";
el.classList.add("hot");              // дуруст: ба мавҷудҳо илова кардем
console.log(el.className);            // → card sale hot

style: усули зуд, аммо дағал

Тавассути el.style.хосият услубро мустақиман барои унсур додан мумкин аст. Номҳои хосиятҳо бо camelCase навишта мешаванд: background-color ба backgroundColor табдил меёбад, ва қиматҳо — ҳамеша сатрҳо:

<p id="note">Скидка до конца недели</p>

const note = document.querySelector("#note");

note.style.color = "white";
note.style.backgroundColor = "tomato";   // camelCase!
note.style.padding = "8px 12px";
note.style.borderRadius = "8px";

console.log(note.style.color);           // white

Қоида: агар услуб муддати дароз ё барои якчанд унсур лозим бошад — класс эҷод кунед. style-ро барои қиматҳое монед, ки дар код ҳисоб карда мешаванд (бари навори боркунӣ, мавқеъ). Ҳамин тавр JS бо тарроҳӣ омехта намешавад, ва ёрдамчии ЗС ба шумо осонтар кумак мекунад.

Атрибутҳо: getAttribute, setAttribute ва хосиятҳо

Атрибутҳо — он чизе ҳастанд, ки дар теги кушоянда навишта мешавад: href, src, alt, disabled, data-id. Онҳоро бо ду усул хондан ва тағйир додан мумкин аст:

Мехоҳед ба унсур додаҳои худро «пайваст» кунед — масалан, id-и мол ё нархи онро? Барои ин атрибутҳое ихтироъ шудаанд, ки бо data- оғоз мешаванд. Дар JS онҳо тавассути el.dataset дастраванд, ва ном пас аз data- ба хосият табдил меёбад:

console.log(buy.getAttribute("data-price")); // 40 — атрибут дар ҳамбандӣ тағйир ёфт

buy.disabled = true;                    // хосияти disabled — тугма хокистарӣ ва ғайрифаъол аст
console.log(buy.hasAttribute("disabled")); // true

dataset.price "35"-ро бармегардонад, на 35-ро. Чунин қиматҳоро ҷамъ кардан хатарнок аст: "35" + "5" "355" медиҳад. Пеш аз ҳисобҳо ҳамеша тавассути Number(...) ба адад табдил диҳед.

05 Унсурҳоро эҷод ва нест мекунем

То ҳол мо танҳо он чиро меёфтем ва тағйир медодем, ки дар HTML навишта шудааст. Аммо дар сайти воқеӣ, масалан мағозаи интернетӣ, рӯйхати молҳо аз додаҳо меояд, ва ҳамбандӣ барои он пешакӣ навишта намешавад. Унсурҳоро бояд аз код эҷод кард. Ин се қадам аст:

06 Рендер: аз массив ба кортҳо

Акнун ҳар чизеро, ки медонед, ҳамроҳ мекунем. Дар дарсҳои 6 ва 7 шумо бо массивҳои объектҳо кор кардед — феҳристҳои молҳо, донишҷӯён, фармоишҳо. Акнун ин додаҳоро кашидан мумкин аст. Калимаи рендер (render) маҳз маънои «аз додаҳо он чиро, ки дар экран намоён аст, сохтан»-ро дорад. Тарҳ ҳамеша як аст:

  1. Додаҳо — массиви объектҳо: const products = [{ title: "Нон", price: 4 }, …]. Ин сарчашмаи асосии ҳақиқат аст.
  2. Функсияи-фабрика createCard(product) — як объектро мегирад ва унсури тайёрро бармегардонад.
  3. Функсияи рендер render(items) — контейнерро тоза мекунад ва ба он кортҳоро барои тамоми массив ҷойгир мекунад.
  4. Даъват render(products) — саҳифа кашида шуд. Массивро тағйир додед — боз render-ро даъват кардед.
Монандӣ аз ҳаёт

Оши палав дар тӯй. Дастур ва рӯйхати меҳмонон — ин додаҳо мебошанд. Ошпаз — функсияи-фабрика: дар вуруд биринҷ ва гӯшт, дар хуруҷ як пурсон. Ва пешхизмат — render: аз тамоми рӯйхати меҳмонон мегузарад, пеши ҳар кас пурсон мегузорад. Меҳмони нав омад — дастурро тағйир додан лозим нест, танҳо боз як пурсон аз рӯи ҳамон дастур.

Маълумоти кӯтоҳ: BEM — номҳои классҳо бе бесаранҷомӣ

Вақте ки ЗС ҳамбандӣ мекунад, хоҳиш кунед, ки классҳоро аз рӯи BEM ном гузорад. Ин мувофиқа дар бораи номҳост, то аз рӯи класс фавран маълум шавад, ки ин чист:

Блок
Ҷузъи мустақил: product-card.
Унсур
Қисми блок, бо ду зерхат: product-card__title, product-card__price.
Модификатор
Варианти блок, бо ду тире: product-card--out («дар мавҷуд нест»). Дар JS онро тавассути classList фаъол ва хомӯш мекунанд — ҳамон гуфтугӯ дар бораи бейҷҳо аз бахши 4.

Промпт барои қолаби HTML

Ду дархости ба ЗС-ро муқоиса кунед. Якум — чунон ки навомӯзон мекунанд. Дуюм — аз рӯи формулаи курс: замина → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш.

корти молро бисоз
Замина: ман JavaScript меомӯзам, мағозаи таълимии интернетиро бо HTML/CSS/JS-и тоза бе китобхонаҳо месозам. Ба ман танҳо ҳамбандӣ лозим аст — JavaScript-ро худам менависам. Вазифа: қолаби HTML-и як корти молро (ном, нарх, тугмаи «В корзину») ва CSS барои он, илова CSS барои тӯри мутобиқшавандаи чунин кортҳо (grid) бисоз. Маҳдудиятҳо: классҳо аз рӯи BEM (product-card, product-card__title, product-card__price, product-card__btn, модификатори product-card--out барои моле, ки дар мавҷуд нест). Бе JavaScript, бе услубҳои inline, бе onclick, бе тасвирҳо ва ҳарфҳои берунӣ. Мавзӯи равшан, кунҷҳои мудаввар. Формати ҷавоб: ду блоки код — HTML ва CSS. Пас аз онҳо — рӯйхати классҳо ва маънои ҳар кадом, дар се то панҷ сатр. Санҷиш: нависед, ки кадом унсурҳои қолабро ман бояд аз JavaScript пур кунам.

ЗС аз промпти дуюм чӣ мегирад? Стек, сатҳ, ҳудудҳо («JavaScript нанавис»), номҳои мушаххаси классҳо, формати ҷавоб ва хоҳиши худро санҷидан. Ва ба шумо мантиқ мемонад — ва шумо дақиқ медонед, ки он ба кадом классҳо такя мекунад.

Ҷавоби ЗС-ро месанҷем: феҳристи санҷиш

  • Оё дар ҷавоб <script>, onclick="…", услубҳои inline style="…" ҳастанд? Шумо бе онҳо хоҳиш карда будед — яъне мебарорем.
  • Оё номҳои классҳо бо онҳое, ки шумо дар JS истифода мебаред, мувофиқ меоянд? Як ҳарфи изофӣ — ва querySelector null бармегардонад.
  • Оё тегҳо мувофиқанд: article барои корт, h3 барои ном, button барои тугма (на div бо клик)?
  • Оё тасвирҳо ва ҳарфҳои берунӣ нестанд, ки бор намешаванд?

Чӣ кор кардан лозим

  • ☐ Додаҳо. Массиви на камтар аз 10 объект дар мавзӯи интихоби шумо: мағоза, менюи чойхона, курсҳои MakeFirstStep, маршруткаҳои Душанбе, филмҳо. Ҳар объект на камтар аз 4 майдон дорад, ки дар байни онҳо title ва майдони мантиқӣ (масалан, inStock) ҳаст.
  • ☐ Ҳамбандӣ аз ЗС. Қолаби HTML ва CSS аз рӯи промпт бо формулаи курс гирифта шудааст. Промпт дар файли prompt.txt нигоҳ дошта шудааст. Классҳо — аз рӯи BEM.
  • ☐ createCard(item). Функсияи алоҳида, ки тавассути createElement кортро ҷамъ мекунад ва онро бармегардонад. Тамоми матн — тавассути textContent.
  • ☐ render(items). Функсияи алоҳида: контейнерро тавассути replaceChildren тоза мекунад ва кортҳоро ҷойгир мекунад. Барои массиви холӣ «Ҳеҷ чиз ёфт нашуд»-ро нишон медиҳад.
  • ☐ Тугмаи тоза кардан. Тугмаи «Тоза кардан» ҳамаи кортҳоро мебарорад (тавассути onclick, чун дар дарс). Бонус: тугмаи «Ҳамаро нишон деҳ» онҳоро бармегардонад.
  • ☐ Ҳисобкунак. Матни «Нишон дода шуд: N» дар дохили render навсозӣ мешавад.
  • ☐ Модификатор. Кортҳое, ки майдони мантиқӣ барояшон дурӯғ аст, класси иловагӣ (--out, --sold ва ғ.) тавассути classList мегиранд, ва CSS онҳоро ҷудо мекунад.
  • ☐ Бонус. render-ро бо массиви филтршуда (масалан, танҳо арзонҳо) даъват кунед — оддӣ бо сатр дар код, бе тугмаҳо. Тугмаҳои-филтр дар дарси оянда мешаванд.

✓ Хулосаи дарс

  • DOM — дарахти зиндаи объектҳо, ки браузер аз HTML месозад. JavaScript бо он тавассути document кор мекунад. Файли HTML ҳангоми ин тағйир намеёбад.
  • Ҳаракат: parentElement, children, firstElementChild, lastElementChild, nextElementSibling, previousElementSibling. childNodes фосилаҳоро низ ҳисоб мекунад.
  • Ҷустуҷӯ: querySelector(sel) — унсури аввал ё null; querySelectorAll(sel) — NodeList (барои map — Array.from). Дар дохили унсур ҷустан мумкин аст: card.querySelector(".price").
  • Матн ва ҳамбандӣ: textContent — матни бехатар; innerHTML — ҳамбандӣ, танҳо барои додаҳои худӣ. Матни бегона — ҳамеша textContent. += барои innerHTML истинодҳои кӯҳнаро вайрон мекунад.
  • Классҳо: classList.add / remove / toggle / contains. className = ҳамаро пок мекунад. Тарроҳӣ — дар классҳои CSS, на дар el.style.
  • Атрибутҳо: getAttribute / setAttribute / removeAttribute / hasAttribute; хосиятҳои value, disabled, hidden; додаҳои худӣ — data-* ва el.dataset.name (ҳамеша сатр).
  • Эҷод: createElement → танзим кардан → append / prepend / before / after. Нест кардан — el.remove(), тоза кардан — parent.replaceChildren(), нусха — cloneNode(true). Унсур нусха намешавад, балки кӯч мебандад.
  • Рендер: додаҳо (массив) → createCard(item) унсурро бармегардонад → render(items) replaceChildren(...items.map(createCard))-ро иҷро мекунад. Ҳамеша массиви холиро коркард кунед.
  • Бо ЗС: ЗС HTML ва CSS менависад (BEM, бе JS ва услубҳои inline), шумо — мантиқро. Номҳои классҳо, бехатарии ҷойгиркунӣ ва методҳои ихтироъшударо санҷед. Кодеро, ки шарҳ дода наметавонед, ҷойгир накунед.
