Ҳодисаҳо

Саҳифае, ки танҳо маълумотро нишон медиҳад, плакат аст. Сайти зинда ҷавоб медиҳад: тугмаи «В корзину» маҳсулотро илова мекунад, майдони ҷустуҷӯ рӯйхатро фавран филтр мекунад, шакли дархост саҳифаро аз нав бор намекунад. Паси ҳар як чунин вокуниш ҳодиса истодааст. Имрӯз шумо «шунидани» кликҳо, воридкунӣ ва ирсоли шаклҳоро меомӯзед — ва рӯйхати воқеан интерактивӣ месозед, мисли барномаҳое, ки ҳар рӯз истифода мебаред.

  • Ба ҳодисаҳо тавассути addEventListener обуна шудан ва тавассути removeEventListener обунаро бекор кардан
  • Объекти ҳодисаро хондан: type, target, currentTarget, key, value
  • Амали пешфарзии браузерро тавассути preventDefault боздоштан (истинодҳо, шаклҳо, клавишаҳои тез)
  • Болоравӣ (bubbling) ва фурӯравиро (capturing) фаҳмидан ва идора кардан
  • Як коркардкунандаро барои бисёр элементҳо навиштан — вакилкунии ҳодисаҳо бо closest ва data-*
  • Хаторо барои ЗС чунон тавсиф кардан, ки ӯ аз бори аввал кӯмак расонад
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди дар заминаи торик бо тугмаи ▶ Запустить — зинда аст: онро тағйир диҳед ва натиҷаро дар консол бубинед. Блокҳо бо ҷадвалҳои index.html / style.css / script.js — саҳифаҳои хурданд: дар зери код пешнамоиш пайдо мешавад, ки дар он воқеан клик кардан ва чоп кардан мумкин аст. Ишораҳои вазифаҳо пинҳон шудаанд — аввал 15 дақиқа худатон кӯшиш кунед.

Муҳим дар бораи вазифаҳо. Корбар бо муш клик мекунад, аммо санҷиши вазифаҳо худкор аст ва бояд ҳар дафъа як натиҷаи якхела диҳад. Бинобар ин дар вазифаҳо кликҳо ва воридкуниро худи код «иҷро мекунад»: button.click(), input.dispatchEvent(...). Барои коркардкунандаи шумо ин аз клики воқеӣ фарқ надорад.

01 Ҳодиса чист ва addEventListener

То даме ки шумо кодро аз боло ба поён менависед, он як маротиба иҷро мешавад ва тамом мегардад. Аммо корбар чизеро баъдтар ва ғайричашмдошт анҷом медиҳад: клик мекунад, тугмаро мезанад, матн ворид мекунад, саҳифаро варақ мезанад. Браузер ҳар як чунин амалро мушоҳида мекунад ва ҳодиса месозад — сигнали «чизе рӯй дод». Вазифаи мо — пешакӣ гуфтан: «агар чунин ҳодиса дар чунин элемент рӯй диҳад — ин функсияро иҷро кун».

Муқоиса аз ҳаёт

Дар болои дари чойхона зангӯлача овезон аст. То даме ки касе намедарояд — хомӯшӣ, пешхизмат ба кори худ банд аст. Аммо ҳамин ки дарро кушоянд — зангӯлача садо медиҳад ва пешхизмат барои истиқболи меҳмон меравад. Шумо пешакӣ мувофиқа кардед: «садо дод — ба сӯи дар рав». Ҳодиса — садои зангӯлача, коркардкунанда — амалҳои пешхизмат, ва addEventListener — худи мувофиқа.

Ҳодиса
Сигнал аз браузер: click, input, submit, keydown… Ҳар ҳодиса навъ дорад — сатр бо ном.
Коркардкунанда
Функсияе, ки ҳангоми рӯй додани ҳодиса иҷро мешавад. Инчунин handler ё listener («шунаванда») мегӯянд.
Обуна
Пайвасти «элемент + навъи ҳодиса + функсия». Як маротиба анҷом дода мешавад, аммо ҳар қадар маротиба кор мекунад.

Обуна чӣ тавр менамояд

Бигзор бо мисоли зинда бубинем. Мо тугма месозем, ба клик обуна мешавем ва тугмаро аз код бо ду даъвати click() «мезанем»:

document.body.innerHTML = `<button id="buy">Купить</button>`;
const buy = document.querySelector("#buy");

function onBuy() {
  console.log("Спасибо за покупку!");
}

buy.addEventListener("click", onBuy);
console.log("Обработчик навешен, клика ещё не было");

buy.click();   // клики барномавӣ — гӯё бо муш зананд
buy.click();

Диққат диҳед: коркардкунанда дар лаҳзаи addEventListener иҷро намешавад. Он танҳо ба ёд гирифта мешавад ва интизор мешавад. Ҳар клик онро аз нав даъват мекунад.

Хатои маъмул: қавсҳо баъди номи функсия

Ба addEventListener худи функсия дода мешавад, на натиҷаи даъвати он. Қавсҳои () функсияро худи ҳозир даъват мекунанд — ва коркардкунанда он чизе мегардад, ки функсия баргардонд (одатан undefined).

document.body.innerHTML = `<button id="b">Кнопка</button>`;
const b = document.querySelector("#b");

function hello() {
  console.log("Салом!");
}

b.addEventListener("click", hello());   // ✖ қавсҳо: «Салом!» фавран, як маротиба чоп мешавад
console.log("Клика ещё не было, а салом уже прозвучал");
b.click();   // аммо ба клик касе ҷавоб намедиҳад

Агар лозим бошад, ки маълумоти худро ба коркардкунанда диҳед, даъватро ба функсияи тирчадор печонед: b.addEventListener("click", () => hello("Мадина")).

Гирифтани коркардкунанда ва як маротиба кор кардан

Обунаро бекор кардан мумкин аст: removeEventListener бо ҳамон параметрҳо. Бинобар ин функсияро дар тағйирёбанда нигоҳ доштан лозим аст — тирчаи беном-ро гирифтан намешавад, зеро он функсияи «дигар» мебошад.

document.body.innerHTML = `<button id="b">Талон</button>`;
const b = document.querySelector("#b");

function takeTicket() {
  console.log("Ваш талон выдан");
  b.removeEventListener("click", takeTicket);   // ҳамон элемент, навъ ва функсия
}

b.addEventListener("click", takeTicket);
b.click();
b.click();   // хомӯшӣ — коркардкунанда гирифта шуд
console.log("Второй клик ничего не сделал");

Барои ҳолати «як маротиба кор кардан» роҳи кӯтоҳ ҳаст — аргументи сеюм бо танзимот. Браузер худаш коркардкунандаро баъди аввалин кор кардан мегирад:

document.body.innerHTML = `<button id="b">Приз</button>`;
const b = document.querySelector("#b");

b.addEventListener("click", () => console.log("Вы получили приз!"), { once: true });

b.click();
b.click();
b.click();

02 Объекти ҳодиса

Вақте браузер коркардкунандаи шуморо даъват мекунад, ба он як аргумент — объекти ҳодисаро медиҳад. Одатан онро event, evt ё мухтасар e меноманд. Дар он ҳама чизе, ки дар бораи рӯйдод маълум аст, ҷой дорад: аз кадом навъ аст, дар кадом элемент рӯй дод, муш дар куҷо буд, кадом клавиша зада шуд.

Муқоиса аз ҳаёт

Диспетчери маршрутка дар журнал сабт мекунад: «чӣ шуд (савор шудан), дар куҷо (бекати «Шохмансур»), соати чанд, кӣ савор шуд». Объекти ҳодиса — ҳамин гуна варақаи журнал аст. Агар хоҳед тафсилотро бидонед — ба он нигоҳ кунед.

document.body.innerHTML = `<button id="pay" class="btn">Оплатить</button>`;
const pay = document.querySelector("#pay");

pay.addEventListener("click", (event) => {
  console.log("Тип события:", event.type);
  console.log("Элемент:", event.target.id);
  console.log("Тег:", event.target.tagName);
  console.log("Это Event?", event instanceof Event);
});

pay.click();

Муш ва клавиатура

«Тугмаро задан»-ро аз код чӣ тавр иҷро кардан мумкин? Ҳодисаро дастӣ месозем ва бо усули dispatchEvent ба элемент мефиристем. Мо дар вазифаҳо ҳамин тавр амал мекунем — барои коркардкунандаи шумо ин ба задани воқеӣ монанд аст.

document.body.innerHTML = `<input id="field" placeholder="Введите имя">`;
const field = document.querySelector("#field");

field.addEventListener("keydown", (e) => {
  console.log("Нажата клавиша:", e.key);
});

field.dispatchEvent(new KeyboardEvent("keydown", { key: "Enter" }));
field.dispatchEvent(new KeyboardEvent("keydown", { key: "a" }));

document.body.innerHTML = `<div id="map" style="width:300px;height:200px">Карта</div>`;
const map = document.querySelector("#map");

map.addEventListener("click", (e) => {

map.dispatchEvent(new MouseEvent("click", { clientX: 120, clientY: 45 }));

target ва currentTarget: кӣ кор кард ва кӣ мешунавад

Ин ду хосияти гуногун аст ва омехтакунии онҳо яке аз маъмултарин хатоҳост. Бигзор дар дохили тугма нишонаи <b> бошад. Агар ба нишона клик кунанд, пас:

target
Элементи аз ҳама чуқур, ки ба он воқеан клик карданд: нишонаи <b>.
currentTarget
Элементе, ки барои он коркардкунанда даъват шудааст: тугма. Ҳамеша ҳамон, ки шумо барояш addEventListener навиштаед.
document.body.innerHTML = `<button id="cart"><b id="icon">🛒</b> Корзина</button>`;
const cart = document.querySelector("#cart");
const icon = document.querySelector("#icon");

cart.addEventListener("click", (e) => {
  console.log("target:", e.target.tagName);
  console.log("currentTarget:", e.currentTarget.tagName);
});

icon.click();   // ба нишона дар дохили тугма клик карданд
cart.click();   // ба худи тугма клик карданд

То даме ки элемент як аст, онҳо мувофиқат мекунанд. Аммо ҳамин ки дар дохил элементҳои дарунмонда ҳастанд, target метавонад «чуқуртар» шавад. Ин муҳим аст: дар бахши 06 мо дар ин асос як техникаи томро месозем.

Аммо this чист?

Дар функсияи оддии коркардкунанда this низ ба элементе ишора мекунад, ки коркардкунанда дар он овезон аст — ҳамон ки currentTarget. Дар функсияи тирчадор this дигар аст. Барои ҳадс назадан, ҳамеша event.currentTarget-ро истифода баред — он дар ҳама ҷо яксон кор мекунад.

Хатои маъмул: хосият на аз ҳамон ҳодиса

Маҷмӯи хосиятҳо аз навъи ҳодиса вобаста аст. Клик клавиша надорад, зеро пахши клавиша координатаҳои муш надорад. JavaScript хафа намешавад — он танҳо undefined бармегардонад ва шумо ним соат барои ҷустуҷӯи «хато» сарф мекунед.

document.body.innerHTML = `<button id="b">Кнопка</button>`;
const b = document.querySelector("#b");

b.addEventListener("click", (e) => {
  console.log(e.key);        // undefined — клик клавиша надорад
  console.log(e.clientX);    // аммо координатаҳо ҳастанд (0, зеро клик барномавӣ аст)

04 Амали пешфарз: preventDefault

Барои бисёр ҳодисаҳо браузер амали пешфарзии худро дорад. Он баъд аз коркардкунандаҳои шумо иҷро мешавад, агар онро боз надоред:

  • клик ба истинод <a href> — гузариш ба саҳифаи дигар;
  • ирсоли шакл — аз нав бор шудани саҳифа бо маълумот;
  • клики тугмаи рости муш — менюи контекстӣ;
  • Ctrl + S — тирезаи «Захира кардани саҳифа»;
  • фосила дар саҳифа — варақ задан ба поён.

Усули event.preventDefault() ба браузер мегӯяд: «Лозим нест, минбаъд худам». Коди шумо дар ин ҳол мисли пештара кор карда истодааст.

Муқоиса аз ҳаёт

Шумо ба турникети истгоҳ наздик мешавед ва назоратчӣ мегӯяд: «Истед, аввал чиптаро нишон диҳед». Шумо мехостед гузаред (амали пешфарз), аммо шуморо боздоштанд — ва акнун шумо қарор медиҳед, ки иҷозат диҳед ё не. preventDefault — дасти боло кардаи назоратчӣ: гузариш бекор шуд, аммо боқии корҳо дар толор ба тартиби худ идома меёбанд.

document.body.innerHTML = `<a id="promo" href="https://example.com/promo">Акция недели</a>`;
const promo = document.querySelector("#promo");

promo.addEventListener("click", (e) => {
  e.preventDefault();                       // дар саҳифа мемонем
  console.log("Переход отменён:", e.defaultPrevented);
});

promo.click();

Ҳолати асосӣ: шакл

Ирсоли шакл ба таври пешфарз саҳифаро аз нав бор мекунад: ҳар чизе ки JavaScript кашида буд, нест мешавад. Бинобар ин қариб ҳар шакл дар сайти муосир чунин коркард мешавад: submit-и шаклро мешунавем (на click-и тугмаро!), preventDefault()-ро иҷро мекунем ва бо маълумот худамон кор мекунем.

Чаро маҳз submit, на клик ба тугма? Шаклро бо клавишаи Enter дар майдон фиристодан мумкин аст — клик ба тугма дар ин ҳолат рух намедиҳад, аммо submit ҳамеша кор мекунад. Дар вазифаҳои мо шаклро код «мефиристад»: он ҳодисаи submit-ро бо фармони form.dispatchEvent(new Event("submit", { cancelable: true })) дастӣ пеш мебарад. Коркардкунанда фарқиятро намебинад, ва саҳифа аз нав бор намешавад.

    <input id="who" value="Мадина">
    <button>Заказать</button>
  </form>`;
const order = document.querySelector("#order");

05 Болоравӣ ва фурӯравӣ

Агар тугма дар дохили корточка бошад, корточка дар дохили рӯйхат, ва дар ҳар як аз онҳо коркардкунандаи клики худӣ овезон бошад, чӣ мешавад? Ҳар се кор мекунанд — ва бо тартиби хеле муайян. Ҳодиса дар элементе, ки ба он клик карданд, «намеистад»: он дар занҷири падарон сайр мекунад.

Муқоиса аз ҳаёт

Ҳубобчаи ҳаво дар стакани чой аз таги он ба рӯи об боло меравад ва аз ҳамаи қабатҳо мегузарад. Клик ба тугма низ ҳамин тавр «боло меравад»: аввал ба тугма хабар медиҳад, баъд ба корточка, баъд ба рӯйхат, баъд ба body, document. Ва боз ин ба идораи Душанбе монанд аст: корманд хабарро ба сардори шӯъба мерасонад, ӯ — ба директор, ӯ — ба соҳиб.

  1. Фурӯравӣ (capturing). Ҳодиса аз document ба ҳадаф мефурояд. Коркардкунандаҳо дар ин ҷо танҳо дар сурате кор мекунанд, ки шумо махсус хоҳиш карда бошед: { capture: true }. Кам лозим мешавад.
  2. Ҳадаф (target). Ҳодиса ба элементе мерасад, ки ба он клик карданд.
  3. Болоравӣ (bubbling). Ҳодиса боз ба боло то худи document мебарояд. Дар ин марҳила ҳамаи коркардкунандаҳои оддӣ кор мекунанд.
document.body.innerHTML = `

    <li id="card"><button id="btn">В корзину</button></li>
  </ul>`;

for (const id of ["btn", "card", "list"]) {
  document.getElementById(id).addEventListener("click", (e) => {
    console.log(`сработал ${e.currentTarget.id}, а кликнули по ${e.target.id}`);
  });
}

stopPropagation: роҳро қатъ кардан

event.stopPropagation() болоравиро қатъ мекунад: падарон ҳодисаро намегиранд. Ҷолиб менамояд, аммо эҳтиёткорона истифода баред. Ҳодисаи қатъшуда ба коди бегона низ намерасад — масалан, ба ҳисобкунаки аналитика дар document, ва шумо муддати дароз мекобед, ки чаро он кликҳоро «гузашта мегузорад». Одатан беҳтар аст дар коркардкунандаи падар санҷид, ки маҳз ба куҷо клик карданд: event.target === event.currentTarget.

Фурӯравӣ: { capture: true }

Агар ҳамчун аргументи сеюм true ё { capture: true } диҳед, коркардкунанда дар марҳилаи фурӯравӣ кор мекунад — пештар аз худи ҳадаф. Ҳамин тавр ҳодисаро то расидан ба поён «пешвоз гирифтан» мумкин аст.

06 Вакилкунии ҳодисаҳо

Фарз кунем, шумо рӯйхати 50 кор доред ва ҳар кадом тугмаи «Удалить» дорад. Фикри аввал: бо давра гузашта, ба ҳар тугма коркардкунанда овехтан. Ин кор мекунад, аммо се мушкилот ҳаст:

  • Коркардкунандаҳои зиёд. 50 тугма — 50 шунаванда дар хотира. Агар сатрҳо 5000 бошанд-чӣ?
  • Элементҳои нав «кар» мешаванд. Корбар кор илова кард — тугмаи нав коркардкунанда надорад, зеро давра пештар кор карда буд.
  • Кори изофӣ. Ҳар як элементро бояд обуна кард ва ҳангоми нест кардан — обунаро бекор кард.

Ҳал аз болоравии бахши гузашта истифода мебарад. Клик ба ҳар тугма ба ҳар ҳол боло мебарояд то падари умумӣ — рӯйхат. Пас, як коркардкунанда дар падар кифоя аст: он мефаҳмад, ки маҳз кӣ ҳадаф буд, ва қарор медиҳад, ки чӣ кор кунад. Ин вакилкунӣ номида мешавад — падар ҳодисаҳоро «бо вакилнома» аз номи ҳамаи фарзандон қабул мекунад.

Бо вакилкунӣ низ ҳамин тавр: як «маъмур» (падар) ҳамаро хизмат мерасонад, аз ҷумла онҳое, ки баъдтар пайдо мешаванд.

Барои ин усули element.closest(selector) ҳаст: он худи элементро месанҷад, баъд падарро, баъд падари падарро — ва аввалин мувофиқро аз рӯи селектори CSS бармегардонад. Агар чунин набошад — null.

Боз як абзор: атрибутҳои data

Чӣ тавр фаҳмидан мумкин аст, ки маҳз кадом тугмаро заданд — «нест кардан» ё «ба интихобшуда»? Ва дар кадом сатр? Аз рӯи матни тугма ҳадс заданӣ нестем-ку. Барои чунин нишонаҳо дар HTML атрибутҳои data-* ҳастанд: шумо худатон ном меандешед, ва дар JS тавассути element.dataset мехонед.

console.log(li.dataset.userName);    // data-user-name → userName (camelCase)
console.log(btn.dataset.action);     // "remove"
console.log(Number(li.dataset.id) + 1);   // 43 — адад худамон месозем

Қолаби вакилкунӣ

  1. Як коркардкунанда дар падари умумӣ — рӯйхат, ҷадвал, меню.
  2. Элементи лозимиро ёбед: const btn = event.target.closest("button[data-action]");
  3. Чизе наёфтем — мебароем: if (!btn) return; (клик ба ҷое, ки тугма нест).
  4. Санҷед, ки тугма дар дохили рӯйхати шумост: if (!list.contains(btn)) return; Вақте лозим аст, ки рӯйхатҳо дар якдигар ҷойгиранд.
  5. Ба сатр боло равед: const li = btn.closest("li");
  6. Аз рӯи dataset қарор диҳед: if (btn.dataset.action === "remove") li.remove();

07 Блоки ЗС: хаторо чӣ тавр тавсиф кардан

«Тугма кор намекунад» — ибораи аз ҳама маъмули барномасозони навомӯз. Ва аз ҳама бефоида: на одам, на ЗС намефаҳмад, ки чӣ маҳз вайрон шуд. Тавсифи чунин хаторо ёд гиред — ва аз ЗС ҷавоби дақиқ мегиред, ва аксар вақт худатон сабабро меёбед, ҳангоми навиштани тавсиф.

Қоидаҳои курс дар бораи ЗС — ёдрас мекунем

1) Аввал 15 дақиқа худатон кӯшиш мекунед. 2) Коде, ки сатр ба сатр шарҳ дода наметавонед, ворид намекунед — ҳангоми санҷиши вазифаи хонагӣ омӯзгор ҳақ дорад дар бораи ҳар сатр бипурсад. 3) Дар промпт ҳамеша: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш.

09 Вазифаи хонагӣ: рӯйхати интерактивӣ

«Компоненти интерактивӣ»-и худро ба итмом расонед: рӯйхат бо илова, нест кардан ва филтр бо тугмаҳо. Мавзӯъро худатон интихоб кунед: харидҳо, корҳои ҳафта, филмҳо барои тамошо, ҷойҳои дӯстдоштаи Душанбе. Натиҷаи ин вазифаи хонагӣ дар лоиҳаи хурд дар дарси 12 лозим мешавад.

Чӣ бояд ҳосил шавад

  • Шакли илова. Майдон ва тугма; банд ҳам бо клик, ҳам бо Enter илова мешавад (ҳодисаи submit, preventDefault). Баъди илова майдон тоза мешавад.
  • Санҷишҳо. Номи холӣ (баъди trim()) ва такроркунӣ (бе ҳисоби регистр) илова намешаванд.
  • Тугмаҳо дар ҳар сатр: ♥ — ба интихобшуда (синфи fav), ✕ — нест кардан. Ҳама тавассути як коркардкунанда дар рӯйхат: closest + data-action.
  • Филтр. Ду тугмаи «Все» ва «Избранные» (низ бо вакилкунӣ дар контейнери тугмаҳо). Тугмаи интихобшуда равшан шудааст. Филтр баъди илова, нест кардан ва иваз кардани ♥ кор карданро давом медиҳад.
  • Ҳисобкунаки «Всего: N, избранных: M».
  • Тозагӣ. Дар HTML onclick="…" нест. Ба ҳар li обуна нест. Матни корбар тавассути textContent ворид мешавад, на innerHTML.

Дар зер — тайёрии оғозии қуттии санҷиш бо автотест: он санҷишҳои маъмулиро такрор мекунад (илова, воридкунии холӣ, такроркунӣ, интихобшуда, филтр, нест кардан). Вақте дар консол ҳама мувофиқат кард — нусхаи худро бо мавзӯъ ва услубҳои зебо супоред.

Ёдрасӣ

Ҳангоми санҷиши вазифаи хонагӣ омӯзгор метавонад хоҳиш кунад, ки ҳар сатрро шарҳ диҳед. Агар шарҳ дода наметавонед, ки клик ба ✕ чӣ тавр ба коркардкунанда дар рӯйхат мерасад, — пеш аз супурдан бахшҳои 05 ва 06-ро аз нав хонед.

Ёддошти дарс

  • Ҳодиса — сигнал аз браузер. Коркардкунанда — функсияе, ки мо медиҳем (бе қавс!): el.addEventListener("click", handler).
  • Коркардкунандаҳо метавонанд бисёр бошанд, онҳо бо тартиби илова шудан кор мекунанд. Гирифтан: removeEventListener (ҳамон функсия лозим аст). Як маротиба: { once: true }. Хосияти onclick танҳо як коркардкунандаро нигоҳ медорад — истифода намебарем.
  • Коркардкунанда event мегирад: type, target (дар куҷо рух дод), currentTarget (дар куҷо коркардкунанда овезон аст), key, clientX/Y, target.value.
  • Ҳодисаҳои маъмул: click, input (ҳар ҳарф), change (қимат собит шуд), keydown, submit, DOMContentLoaded. Дар байрақча checked-ро мехонем, дар майдон ва рӯйхат — value (сатр).
  • Аз код: el.click(), el.dispatchEvent(new Event("input", { bubbles: true })), form.dispatchEvent(new Event("submit", { cancelable: true })). Ҳодисаҳои дастӣ ба таври пешфарз боло намераванд.
  • event.preventDefault() амали браузерро бекор мекунад: гузариш аз истинод, аз нав бор шудан ҳангоми submit, Ctrl + S. Шаклҳоро аз рӯи submit мешунавем, на аз рӯи клик ба тугма.
  • Болоравӣ: ҳодиса аз ҳадаф ба боло аз болои падарон меравад (button → li → ul → body). target тағйир намеёбад, currentTarget тағйир меёбад. Фурӯравӣ — { capture: true }, кам лозим аст.
  • stopPropagation() болоравиро қатъ мекунад — эҳтиёткорона истифода баред; бештар санҷидани event.target === event.currentTarget кифоя аст.
  • Вакилкунӣ: як коркардкунанда дар падар + event.target.closest("селектор") + if (!el) return. Барои элементҳои баъдтар иловашуда кор мекунад. Нишонаҳо дар HTML — data-action, data-id, мехонем el.dataset.action.
  • Боло намераванд: focus, blur, mouseenter, mouseleave — дар падар focusin, focusout, mouseover, mouseout-ро бишнавед.
  • Матни корбар дар DOM — тавассути textContent, на тавассути innerHTML.
  • Бо ЗС: гузориши хато = интизор будам / гирифтам (хато айнан) / коди ҳадди аққал (то 20 сатр) / чӣ кӯшиш кардам / формати ҷавоб. Фарзияҳоро як-як санҷед.
