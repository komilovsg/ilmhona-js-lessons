Массивҳо ва методҳои онҳо

Ассалому алейкум! Ягон сайтро кушоед: рӯйхати молҳо дар мағозаи интернетӣ, лентаи паёмҳо дар чат, кортҳои тарабхонаҳо дар хизмати расонидан, ҷадвали автобусҳо. Ҳамаи ин — рӯйхатҳоанд, ва дар JavaScript рӯйхат массив номида мешавад. Додаҳо аз сервер қариб ҳамеша дар шакли массивҳо меоянд, ва кори барномасози фронтенд — ин массивро ба он чизе табдил додан аст, ки одам дар экран мебинад: филтр кардан, мураттаб кардан, натиҷаро ҳисоб кардан. Имрӯз мо меомӯзем, ки инро боварона анҷом диҳем.

  • Массивҳо эҷод кардан, унсурҳоро аз рӯи индекс хондан ва тағйир додан
  • Унсурҳоро илова ва нест кардан: push, pop, shift, unshift, splice
  • Қисмҳои массивро тавассути slice нусха бардоштан ва онро бо splice омехта накардан
  • Callback-ҳоро фаҳмидан ва map, filter, find, some, every-ро истифода бурдан
  • Натиҷаро тавассути reduce ҳисоб кардан ва тавассути sort дуруст мураттаб кардан
  • Методҳоро ба занҷир пайваст кардан, ҳамонанди фронтенд-барномасозони воқеӣ

01 Массив чист

То ҳол ҳар тағйирёбанда як қиматро нигоҳ медошт: як ном, як нарх, як баҳо. Аммо дар зиндагӣ додаҳо бештар бо рӯйхат меоянд: рӯйхати харидҳо дар Шоҳмансур, ҷадвали дарсҳои ҳафта, баҳоҳои тамоми гурӯҳ барои имтиҳон. Тағйирёбандаҳои item1, item2, item3… эҷод кардан нокулай аст: агар харидҳо сад бошанд-чӣ?

Массив — ин як тағйирёбанда аст, ки дар он рӯйхати мураттаби қиматҳо нигоҳ дошта мешавад. «Мураттаб» маънои онро дорад, ки ҳар қимат ҷойи худро дорад: якум, дуюм, сеюм ва ҳамин тавр минбаъд.

Монандӣ аз ҳаёт

Қатори Душанбе–Хуҷандро тасаввур кунед. Қатор — массив аст, вагонҳо — унсурҳои он. Вагонҳо қатъиян бо тартиб меистанд, ва ҳар кадом рақам дорад. Танҳо дар JavaScript рақамгузорӣ на аз 1, балки аз 0 оғоз мешавад: аввалин вагон — сифрум аст.

Тасвири дигар — ҳуҷайраҳои анбори ашёи шахсӣ дар вокзал: қатори ҳуҷайраҳои якхела, дар ҳар кадом рақам, дар ҳар кадом чизе мемонад. Рақамро медонед — фавран ҳуҷайраи лозимиро мекушоед.

Массивро чӣ тавр эҷод кардан

Қавсайни мураббаъро менависем, дар дохил — қиматҳо бо вергул. Қавсайни холии [] — массиви холӣ аст, ки баъдан ба он чизе илова кардан мумкин аст.

const shopping = ["нон", "чой", "шакар", "зардолу"];
const scores = [78, 92, 65];
const empty = [];

console.log(shopping); // → ["нон", "чой", "шакар", "зардолу"]
console.log(scores);   // → [78, 92, 65]
console.log(empty);    // → []

Чаро индексҳо аз сифр оғоз мешаванд

Индекс — на «рақами тартибӣ», балки тафовут (смещение) аст: аз оғози массив чанд қадам лозим аст, то ба унсур расем. То унсури аввал рафтан лозим нест — сифр қадам, бинобар ин индекси он 0 аст. То дуюм — як қадам, индекс 1. Хотираи компютер ҳамин тавр сохта шудааст, ва қариб ҳамаи забонҳои барномасозӣ ҳамин тавр ҳисоб мекунанд.

Аз ин ҷо қоидаи содда: индекси унсури охирин = дарозӣ − 1. Дар массиви 4 унсура индекси охирин — 3 аст.

Унсурҳоро мехонем: индекс, length, at

const wagons = ["локомотив", "вагон-ресторан", "купе", "плацкарт"];

console.log(wagons.length);             // → 4
console.log(wagons[0]);                 // → локомотив
console.log(wagons[2]);                 // → купе
console.log(wagons[wagons.length - 1]); // → плацкарт
console.log(wagons.at(-1));             // → плацкарт
console.log(wagons.at(-2));             // → купе

wagons[wagons.length - 1] — усули классикии гирифтани унсури охирин: дарозӣ 4, яъне индекси охирин 3. Усули муосир кӯтоҳтар аст: wagons.at(-1). Методи at ададҳои манфиро мефаҳмад: −1 — охирин, −2 — пеш аз охирин.

Унсурро аз рӯи индекс тағйир медиҳем

Ба ҳуҷайра аз рӯи индекс муроҷиат карда, қимати навро таъин мекунем — қимати кӯҳна оддӣ иваз мешавад.

const schedule = ["HTML", "CSS", "JavaScript"];
schedule[1] = "Figma";

console.log(schedule);     // → ["HTML", "Figma", "JavaScript"]
console.log(schedule[5]);  // → undefined
console.log(schedule[-1]); // → undefined

Агар ба индексе муроҷиат кунед, ки вуҷуд надорад, JavaScript хато намедиҳад, балки undefined — «дар ин ҷо чизе нест» — бармегардонад. Диққат диҳед: schedule[-1] низ undefined аст. Индексҳои манфӣ дар қавсайни мураббаъ кор намекунанд — барои ин at(-1) ҳаст.

Намудҳои гуногун дар як массив

const student = ["Мадина", 19, true, null];
console.log(student);        // → ["Мадина", 19, true, null]
console.log(student.length); // → 4

Ин тавр навиштан мумкин аст, аммо дар амал дар як массив одатан додаҳои якнамуд нигоҳ медоранд: танҳо нархҳо, танҳо номҳо, танҳо баҳоҳо. Бо чунин массив кор кардан осонтар аст — ҳамаи унсурҳоро якхела коркард кардан мумкин аст.

const-массивро ба ҳар ҳол тағйир додан мумкин аст

Ин қариб ҳамаро ҳайрон мекунад. const аз нав таъин кардани тағйирёбанда-ро, яъне ба он массиви дигар гузоштанро манъ мекунад. Аммо мазмуни ҳамон массивро тағйир додан мумкин аст.

const cart = ["нон"];
cart[1] = "чой";
console.log(cart); // → ["нон", "чой"]

const cart = ["нон"];
cart = ["самбуса"]; // кӯшиш мекунем ба тағйирёбанда массиви дигар гузорем
Монандӣ аз ҳаёт

Ба анбори ашёи шахсӣ бармегардем. Тағйирёбанда худи чизҳоро не, балки калиди ҳуҷайра-ро (барномасозон «истинод» мегӯянд) нигоҳ медорад. const маънои онро дорад: калидро иваз кардан мумкин нест, он ҳамеша аз ҳамин ҳуҷайра аст. Аммо ҳуҷайраро кушода, чизҳоро дар дохил ҷобаҷо кардан — марҳамат.

Гузариш аз массив бо давра

Бештар вақт бо массив бояд барои ҳар як унсур коре кард. Давраи for-ро шумо аллакай медонед — вақте ки индекс лозим аст, он хеле мувофиқ аст.

const grades = [5, 4, 5, 3];

for (let i = 0; i < grades.length; i++) {
  console.log(`Оценка №${i + 1}: ${grades[i]}`);
}
// Мебарорад:
// Оценка №1: 5
// Оценка №2: 4
// Оценка №3: 5
// Оценка №4: 3

Агар индекс лозим набошад, for...of қулайтар аст: дар ҳар қадам ба тағйирёбанда унсури навбатӣ меафтад.

const fruits = ["зардолу", "гранат", "черешня"];

for (const fruit of fruits) {
  console.log(`Купить: ${fruit}`);
}
// Мебарорад:
// Купить: зардолу
// Купить: гранат
// Купить: черешня

Оё унсур дар массив ҳаст: includes ва indexOf

Ду методи хурд, вале хеле фоиданок. includes(қимат) бо «ҳа/не» ҷавоб медиҳад, ва indexOf(қимат) индекси мувофиқати аввалро ё -1-ро, агар чизе ёфт нашавад, бармегардонад.

const menu = ["оши палав", "самбуса", "курутоб"];

console.log(menu.includes("самбуса")); // → true
console.log(menu.includes("манту"));   // → false
console.log(menu.indexOf("курутоб"));  // → 2
console.log(menu.indexOf("манту"));    // → -1
Хатогиҳои маъмул

1. Аз сарҳад баромадан. arr[arr.length] — ин аллакай пас аз унсури охирин аст, undefined мегирем. Охирин — arr[arr.length - 1].

2. Қадами изофӣ дар давра. Шарти i <= arr.length як қадам зиёдтар мекунад, ва баромади охирин undefined мешавад. Дуруст: i < arr.length.

3. Қавсайн пас аз length. length — хосият аст, на функсия. arr.length() хатои «is not a function» медиҳад. Бе қавсайн менависем: arr.length.

Пеш аз методҳо: мутатсиякунанда ва ғайримутатсиякунанда

Минбаъд дар дарс методҳо бисёр мешаванд — функсияҳои дарунсохт, ки ҳар массив дорад ва тавассути нуқта даъват мешаванд: arr.push(...). Ҳамаи онҳо ба ду гурӯҳ тақсим мешаванд, ва ин тақсимотро ҳамеша дар хотир доштан лозим аст.

Муҳим

Методҳои мутатсиякунанда массиви аслиро тағйир медиҳанд («мутатсия» — тағйирот). Пас аз даъват массиви кӯҳна дар шакли пештара дигар вуҷуд надорад.

Методҳои ғайримутатсиякунанда массиви аслиро даст намезананд: онҳо қимати нав бармегардонанд, ва асл чун пештара мемонад. Дар фронтенд (масалан, дар React) ин махсусан муҳим аст: додаҳо дар экран танҳо он гоҳ дуруст навсозӣ мешаванд, ки мо массиви аслиро вайрон накарда, массиви нав эҷод кунем.

02 push ва pop: дар охир илова кардан ва гирифтан

Амалҳои аз ҳама маъмули рӯйхат — чизеро ба охир гузоштан ва охиринро гирифтан. Корбар молро ба сабад илова кард — push. «Амали охиринро бекор кун»-ро пахш кард — pop.

Монандӣ аз ҳаёт

Дастаи нонҳои гарм дар нонвойхона. Нонвой нони навро боло мегузорад — ин push аст. Харидор низ аз боло мегирад — охирин гузошташударо. Ин pop аст. Охири массив — боло-и даста аст.

push — ба охир илова кардан

arr.push(унсури1, унсури2, …)Бармегардонад: дарозии навроМассиви аслиро тағйир медиҳад
const stack = ["нон", "нон"];
const newLength = stack.push("нон с кунжутом");

console.log(newLength); // → 3
console.log(stack);     // → ["нон", "нон", "нон с кунжутом"]

stack.push("патыр", "фатир"); // якбора якчандро илова кардан мумкин аст
console.log(stack.length);    // → 5

pop — охиринро гирифтан

arr.pop()Бармегардонад: унсури ҳазфшудароМассиви аслиро тағйир медиҳад
const orders = ["самбуса", "курутоб", "шакароб"];
const last = orders.pop();

console.log(last);   // → шакароб
console.log(orders); // → ["самбуса", "курутоб"]

const empty = [];
console.log(empty.pop()); // → undefined

Аз массиви холӣ pop() undefined бармегардонад — хато намешавад, танҳо гирифтан чизе нест.

Хатои маъмул

Гумон кардан, ки push массивро бармегардонад. Он адад — дарозии навро бармегардонад. Бинобар ин ин тавр навиштан мумкин нест:

Ин бад аст

Дар cart адад мемонад, на массив.

let cart = ["нон"];
cart = cart.push("чой");
console.log(cart); // 2 — массив гум шуд!
Ин хуб аст

Оддӣ методро даъват мекунем — массив худ тағйир меёбад.

const cart = ["нон"];
cart.push("чой");
console.log(cart); // ["нон", "чой"]
Маслиҳат: shift ва unshift — ҳамон чиз, аммо дар оғоз

Агар даста — push/pop бошад, пас навбат — кор бо оғоз аст. Дар навбати бонк ё маршрутка аввал касеро хизмат мекунанд, ки аввал омадааст: shift() унсури аввалро мебарорад ва онро бармегардонад. Ва unshift(унсур) унсурро ба худи оғоз мегузорад (масалан, шахси солхӯрдаро пеш мегузаронем) ва дарозии навро бармегардонад.

arr.shift()Бармегардонад: аввалини ҳазфшудароМассиви аслиро тағйир медиҳад
arr.unshift(унсур)Бармегардонад: дарозии навроМассиви аслиро тағйир медиҳад
const queue = ["Фарход", "Мадина", "Рустам"];

const first = queue.shift();
console.log(first); // → Фарход
console.log(queue); // → ["Мадина", "Рустам"]

const len = queue.unshift("Абдулло-ака");
console.log(len);   // → 3
console.log(queue); // → ["Абдулло-ака", "Мадина", "Рустам"]

Пас аз shift ва unshift индекси ҳамаи унсурҳои боқимонда тағйир меёбад: ҳар кадом як ҷой мегузарад. Инро дар хотир доред, агар индексро пешакӣ ба тағйирёбанда нигоҳ дошта бошед.

03 splice: дар миёна нест кардан, ҷобаҷо кардан, иваз кардан

push ва pop танҳо бо охир кор мекунанд. Пас агар бояд истгоҳро аз миёнаи маршрут бардорем ё дарси навро байни ду дарси дигар гузорем-чӣ? Барои ин методи универсалии splice — «корди швейтсарӣ»-и массивҳо ҳаст.

Монандӣ аз ҳаёт

Қатор дар истгоҳ истодааст. Коргар дар ҳар ҷои таркиб метавонад якчанд вагонро ҷудо кунад ва ба ҷойи онҳо навҳоро пайваст намояд. Ба ӯ се чизро гуфтан лозим аст: аз кадом вагон оғоз кунад, чандторо ҷудо кунад ва кадом вагонҳоро ба ҷойи онҳо пайваст кунад. Маҳз ҳамин се чизро splice мегирад.

arr.splice(start, deleteCount, ...items)Бармегардонад: массиви ҳазфшудагонроМассиви аслиро тағйир медиҳад

1. Нест кардан

  3. Чизе ҷобаҷо кардан лозим нест — аргументи сеюм нест. Унсурҳои боқимонда ба чап мегузаранд.
  4. Массиви ҳазфшудагон бармегардад — онро нигоҳ доштан ё оддӣ истифода набурдан мумкин аст.

04 slice: як қисми массивро нусха бардоштан

slice («бурида, порча») як қисми массивро мегирад ва онро ҳамчун массиви нав бармегардонад. Массиви аслӣ дар ин ҳолат тамоман тағйир намеёбад. Ин яке аз бехатартарин методҳост.

Монандӣ аз ҳаёт

Ба шумо се саҳифа аз китоби дарсӣ лозиманд. Шумо онҳоро намекашед, балки нусхабардорӣ (ксерокс) мекунед. Дар дасти шумо варақҳои нав ҳастанд, ва китоби дарсӣ бутун мондааст. slice — нусхабардорӣ аст, ва splice аз мавзӯи гузашта — қайчӣ.

arr.slice(start, end)Бармегардонад: массиви навАслиро тағйир намедиҳад

Охир дохил намешавад

Муҳимтарин қоида: унсури дорои индекси end ба натиҷа намеафтад. slice(1, 4) индексҳои 1, 2 ва 3-ро мегирад — «аз 1 то 4, аммо 4-ро даст намезанем».

const days = ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб"];

console.log(days.slice(1, 4)); // → ["Вт", "Ср", "Чт"]
console.log(days.slice(3));    // → ["Чт", "Пт", "Сб"]
console.log(days.slice(-2));   // → ["Пт", "Сб"]
console.log(days.slice(0, -1)); // → ["Пн", "Вт", "Ср", "Чт", "Пт"]
console.log(days);             // → ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб"]
  1. slice(3) — бе end ҳамаро аз индекси 3 то охир мегирем.
  2. slice(-2) — индекси манфӣ аз охир ҳисоб мешавад: ду унсури охирин.
  3. slice(0, -1) — ҳама ғайр аз охирин: хати истгоҳ дар унсури охирин.
  4. Сатри охирин нишон медиҳад, ки days мисли пештара монд.

Нусхаи пурра: slice() бе аргументҳо

Баъзан нусхаи пурраи массив лозим аст, то онро тағйир диҳем ва аслро даст назанем. Барои ин — slice() бе аргументҳо ё навишти [...arr] (се нуқта унсурҳоро ба қавсайни нав «паҳн мекунанд»).

const original = ["нон", "чой"];
const copy1 = original.slice();
const copy2 = [...original];

copy1.push("самбуса");
copy2.push("курутоб");

console.log(original); // → ["нон", "чой"]
console.log(copy1);    // → ["нон", "чой", "самбуса"]
console.log(copy2);    // → ["нон", "чой", "курутоб"]
Хатои маъмул: ин нусха нест

const copy = original; массиви нав эҷод намекунад. Шумо танҳо калиди дуюми ҳамон ҳуҷайраи анбори ашёи шахсӣ сохтед. copy-ро тағйир медиҳед — original низ тағйир меёбад.

const original = ["Фарход", "Мадина"];
const notCopy = original; // ин ҳамон истинод аст
notCopy.push("Рустам");

console.log(original); // → ["Фарход", "Мадина", "Рустам"]

Номҳо ба як ҳарф фарқ мекунанд, ва рафтор — тамоман. Дар хотир доред: дар splice «sp» ҳаст — мисли калимаи spoil (вайрон кардан): аслро вайрон мекунад.

Callback чист

Callback (аз англисии callback — «даъвати баръакс») — функсияест, ки мо онро ба метод медиҳем, ва он худаш онро барои ҳар унсур даъват мекунад. Мо давра наменависем — давра аллакай дар дохили метод пинҳон аст. Мо танҳо шарҳ медиҳем, ки бо як унсур чӣ кор кардан лозим.

Монандӣ аз ҳаёт

Шумо ба бофандаи корхонаи Хуҷанд халтаи пахта ва дастур медиҳед: «аз ҳар тӯда ришта кун». Шумо дар паҳлӯяш намеистед ва ҳар ҳаракатро фармон намедиҳед — ӯ худаш тӯдаҳоро як-як мегирад ва барои ҳар кадом дастури шуморо иҷро мекунад. Дастур — callback аст, бофанда — метод.

То ки callback ҷодугарӣ ба назар нарасад, «метод»-и хурди худамонро бо давраи шинос менависем. Маҳз ҳамин тавр map дар дохил сохта шудааст:

function myMap(list, callback) {
  const result = [];
  for (const item of list) {
    result.push(callback(item)); // функсияи ШУМОРО барои ҳар унсур даъват мекунем
  }
  return result;
}

const double = (n) => n * 2;
console.log(myMap([4, 7, 10], double)); // → [8, 14, 20]

Қайд кунед: мо double-ро бе қавсайн додем. Бо қавсайни double() мо худамон функсияро даъват карда, натиҷаашро медодем. Ва ба мо худи функсияро додан лозим аст, то метод онро даъват кунад.

map — усули дарунсохт

map («акс кардан, мувофиқ гузоштан») аз болои ҳар унсур мегузарад, callback-ро даъват мекунад ва он чиро, ки callback баргардонд, ба массиви нав мегузорад. Унсурҳо чӣ қадар буданд — ҳамон қадар мемонанд.

const pricesKg = [18, 25, 12];

console.log(pricesTwoKg); // → [36, 50, 24]

Параметрҳои callback: element, index, array

Метод ба callback на танҳо унсурро медиҳад. Ҳамчун аргументи дуюм индекс, ҳамчун сеюм — тамоми массив меояд. Одатан танҳо якум лозим аст, баъзан — якум ва дуюм. Номҳоро ҳар гуна додан мумкин аст, тартиб муҳим аст.

const guests = ["Нилуфар", "Далер", "Сабрина"];
const numbered = guests.map((name, index) => `${index + 1}. ${name}`);

console.log(numbered); // → ["1. Нилуфар", "2. Далер", "3. Сабрина"]

const cities = ["душанбе", "худжанд", "хорог"];
const titles = cities.map((city) => city[0].toUpperCase() + city.slice(1));

console.log(titles); // → ["Душанбе", "Худжанд", "Хорог"]

Дар мисоли дуюм callback ҳарфи аввалро мегирад (city[0]), онро калон мекунад (toUpperCase()) ва боқимондаи сатрро мечаспонад (slice(1) дар сатрҳо низ кор мекунад). Ин вазифаи маъмули фронтенд аст: додаҳоро пеш аз нишон додан ба шакли зебо овардан.

Хатои маъмул: return дар қавсайни фигурӣ фаромӯш шуд

Функсияи тирдор бе қавсайни фигурӣ натиҷаро худаш бармегардонад. Аммо бо қавсайни фигурӣ бояд return-ро ошкоро навишт — вагарна функсия undefined бармегардонад, ва тамоми массиви нав аз undefined иборат мешавад.

const prices = [10, 20, 30];

const wrong = prices.map((p) => { p * 2 });
console.log(wrong); // → [undefined, undefined, undefined]

const right = prices.map((p) => { return p * 2; });
console.log(right); // → [20, 40, 60]

const short = prices.map((p) => p * 2);
console.log(short); // → [20, 40, 60]
Хатои маъмул: map барои амалҳои иловагӣ

06 filter: танҳо мувофиқҳоро мондан

filter («филтр, элак») аз болои массив мегузарад ва танҳо он унсурҳоро мемонад, ки callback барояшон true ҷавоб дод. Дар фронтенд ин ҷустуҷӯ, филтрҳо дар феҳрист, ҷадвалчаҳои «Ҳама / Нахондашуда» аст.

Монандӣ аз ҳаёт

Шумо пеш аз фурӯш гелосро ҷудо мекунед: ҳар донаро мебинед ва қарор медиҳед — «ба қуттӣ» ё «не». Қарори шумо «ҳа/не» — callback аст. Қуттии бо донаҳои интихобшуда — массиви нав. Тӯдаи аслии гелос ҷое нарафтааст.

arr.filter((element, index, array) => true ё false)Бармегардонад: массиви нав (метавонад холӣ бошад)Аслиро тағйир намедиҳад

console.log(cheap);  // → [12, 8, 30]
console.log(prices); // → [12, 45, 8, 120, 30]

Бар хилофи map, дарозии натиҷа метавонад ҳар чӣ бошад: аз сифр то дарозии массиви аслӣ. Худи унсурҳоро filter тағйир намедиҳад — танҳо қарор медиҳад, ки онҳоро монад ё не.

Натиҷаи холӣ ва ҳисоб тавассути length

Сатрҳоро филтр мекунем

Мини-пешнамоиш: объект

Дар додаҳои воқеӣ мол на танҳо нарх, балки маҷмӯаи маълумот аст: ном, нарх, мавҷудият. Барои ин дар JavaScript объект ҳаст — қавсайни фигурӣ бо ҷуфтҳои «калид: қимат», масалан { name: "Нон", price: 4 }. Барои гирифтани қимат номи объект, нуқта ва калидро менависанд: агар item чунин объект бошад, пас item.price ба 4 баробар аст, ва item.name — "Нон".

Объектҳоро мо дар дарси оянда муфассал ҷудо мекунем, ҳоло ин барои хондани мисолҳои зер кифоя аст.

1. return дар қавсайни фигурӣ фаромӯш шуд. Callback undefined бармегардонад, ва ин «не» ҳисоб мешавад — натиҷа холии [] мешавад.

2. Як унсурро интизоранд, ва массив мегиранд. filter ҳамеша массив бармегардонад, ҳатто агар як унсур мувофиқ омада бошад: ["Хорог"], на "Хорог". Агар як унсур лозим бошад — find ҳаст, дар бораи он дар мавзӯи оянда.

07 find ва findIndex: аввалин мувофиқро ёфтан

Аксар вақт на рӯйхат, балки як унсури мушаххас лозим аст: мол бо номи лозимӣ, донишҷӯ бо номи лозимӣ, аввалин рӯзи гарм. Барои ин find ҳаст.

Монандӣ аз ҳаёт

Шумо дар истгоҳи таксӣ мошинеро меҷӯед, ки ба Варзоб меравад. Шумо дар паҳлӯи қатор қадам зада, аз ронандагон навбат ба навбат мепурсед. Ҳамин ки аввалин мувофиқро ёфтед — менишинед ва минбаъд намепурсед. Ва агар касе намеравад — бе чизе мераве. Ин маҳз find аст: аввалин ёфтшуда ё undefined.

arr.find((element, index, array) => true ё false)Бармегардонад: аввалин унсури мувофиқ ё undefinedАслиро тағйир намедиҳад
const temps = [36, 38, 41, 43, 39];

console.log(temps.find((t) => t > 40)); // → 41
console.log(temps.find((t) => t > 50)); // → undefined

Ҳам 41 ва ҳам 43 мувофиқанд, аммо find дар мувофиқати аввал истода, худи унсурро бармегардонад — на массив.

console.log(temps.findIndex((t) => t > 50));     // → -1

findIndex аз indexOf чӣ фарқ дорад? indexOf қимати мушаххас-ро меҷӯяд (indexOf(41)), ва findIndex — унсурро аз рӯи шарт («аввалин аз 40 зиёд»).

09 every: оё ҳама мувофиқанд?

every («ҳар як») — бародари some аст. Он ба ин савол ҷавоб медиҳад: «оё ҳамаи унсурҳо ба шарт мувофиқанд?». Оё ҳамаи молҳо мавҷуданд? Оё ҳамаи донишҷӯён супориданд? Оё ҳамаи майдонҳои шакл дурустанд?

Монандӣ аз ҳаёт

Ронандаи маршрутка пеш аз сафар ба Искандаркӯл месанҷад: оё ҳамаи мусофирон камарбандро бастаанд? Ӯ аз салон мегузарад, ва ҳамин ки аввалин бастанашударо мебинад — ҷавоб «не», минбаъд нигоҳ кардан лозим нест. Ҷавоби «ҳа» танҳо дар сурате мешавад, ки ҳамаи мусофирон бе истисно бастаанд.

every дар аввалин «не» меистад, ҳамон тавр ки some дар аввалин «ҳа» меистад. Дар даъвати дуюм санҷиш дар 60 анҷом ёфт.

Массиви холӣ → true. Чаро?

Ин аҷиб менамояд, аммо мантиқ чунин аст: every вайронкунанда — унсурро, ки мувофиқ нест, меҷӯяд. Дар массиви холӣ вайронкунанда нест, пас «ҳама мувофиқанд». Мисли ронандаи маршрутка: агар дар салон касе набошад, пас касе бастанашуда ҳам нишаста нест.

Қапқон

Бинобар ин қоида every дар массиви холӣ осон фиреб медиҳад. Санҷиши «ҳамаи молҳои сабад мавҷуданд» дар сабади холӣ true медиҳад — ва тугмаи «Фармоиш додан» фаъол мешавад. Агар массиви холӣ барои шумо ҳолати махсус бошад, онро алоҳида санҷед: arr.length === 0.

10 reduce: массивро ба як қимат овардан

reduce («гирд овардан, кӯтоҳ кардан») — қудратмандтарин ва нофамилтарин методи дарс аст. Он аз болои массив мегузарад ва аз ҳамаи унсурҳо як қимат ҷамъ мекунад: ҷамъ, ҳадди аксар, сатри ниҳоӣ, ҳисоб. Шитоб накунед: онро оҳиста ҷудо мекунем.

Монандӣ аз ҳаёт

Хазинаи чойхона. Ширкат палав, самбуса, хӯриш ва чой фармуд. Хазинадор аз сифр дар экрани калкулятор оғоз мекунад. Таоми якумро мегирад — нархашро илова мекунад, дар экран ҷамъи нави миёнагӣ. Таоми навбатиро мегирад — ба он чӣ дар экран аст, илова мекунад. Ва ҳамин тавр то таоми охирин. Он чи дар охир дар экран аст — ҷамъи чек аст.

Одат кунед: ҳамеша қимати оғозиро нависед. Барои ҷамъ — 0, барои сатр — "", барои ҳисоб — {}. Ин фавран нишон медиҳад, ки натиҷа кадом навъ мешавад.

Ҳадди аксар

const temps = [36, 41, 38, 43, 39];
const max = temps.reduce((acc, t) => (t > acc ? t : acc), temps[0]);

console.log(max); // → 43

Дар ин ҷо дар acc «калонтарин то ин лаҳза» нигоҳ дошта мешавад. Дар ҳар қадам муқоиса мекунем: агар ҷорӣ калонтар бошад — он ҳадди аксари нав мешавад, вагарна кӯҳнаро мемонем. Аз унсури аввал оғоз мекунем, на аз 0: мабодо ҳамаи ҳароратҳо манфӣ бошанд (зимистон дар Хоруғ −20 низ мешавад).

Барои ҳадди аксари оддӣ роҳи кӯтоҳ низ ҳаст — Math.max(...temps). Аммо онро тавассути reduce ҷудо кардан муфид аст: ҳамин тавр вазифаҳое ҳал мешаванд, ки функсияи тайёр надоранд.

Ҳисоби такрорҳо (шиносоии сабук бо объект)

Қимати оғозӣ метавонад объекти холии {} бошад. Дар ҳар қадам ба он «ҳисобкунак» барои калимаи ҷорӣ илова мекунем.

const orders = ["чой", "самбуса", "чой", "нон", "чой"];

const count = orders.reduce((acc, item) => {
  acc[item] = (acc[item] || 0) + 1;
  return acc;
}, {});
console.log(count); // → { чой: 3, самбуса: 1, нон: 1 }

Сатри acc[item] = (acc[item] || 0) + 1 чунин хонда мешавад: «ҳисоби ҷории ин таомро бигир, ва агар он ҳоло нест — 0 бигир, 1 илова кун ва баргардон навис». Қавсайни мураббаъи acc[item] — роҳи муроҷиат ба калидест, ки номаш дар тағйирёбанда мебошад. Муфассалтар — дар дарс дар бораи объектҳо.

Сатрро мепайвандем

const fruits = ["зардолу", "гранат", "дыня"];

const text = fruits.reduce((acc, fruit, i) => acc + (i === 0 ? "" : ", ") + fruit, "");
console.log(text); // → зардолу, гранат, дыня

console.log(fruits.join(", ")); // → зардолу, гранат, дыня

Барои пайвастан методи тайёри join(ҷудокунанда) ҳаст — он сатрро аз ҳамаи унсурҳо бармегардонад. Онро вақте истифода баред, ки танҳо пайвастан лозим аст. Ва reduce вақте ба кор меояд, ки пайвастан мураккабтар аст: бо шартҳо, бо рақамгузорӣ, бо ҳисоб дар ҷараён.

Хатогиҳои маъмул

1. return-ро фаромӯш карданд дар callback бо қавсайни фигурӣ — дар қадами дуюм acc undefined мешавад, ва натиҷа — NaN («адад нест»).

2. Тартиби параметрҳоро омехтанд. Якум ҳамеша аккумулятор меояд, дуюм — унсури ҷорӣ: (acc, current).

3. Қимати оғозиро надоданд — ду ҳолати болоро бинед.

Ишораи ЗС

reduce-ро беҳтар аз ҳама тавассути ҷадвал мефаҳманд. Хоҳиш кунед: «Барои reduce-и ман ҷадвали қадамҳо бисоз: сутунҳои acc, current, callback чӣ баргардонд» — ва коди худ ва додаҳоро гузоред.

Амалия: мустаҳкам мекунем

Пеш аз навиштани reduce ба ду савол ҷавоб диҳед: аз чӣ оғоз мекунем (қимати оғозӣ) ва аз ҷамъи кӯҳна ва унсури ҷорӣ чӣ тавр ҷамъи нав гирем.

11 sort: мураттабкунӣ

Мураттабкунӣ ҳама ҷо лозим аст: молҳо «аввал арзонҳо», донишҷӯён аз рӯи алифбо, бозиҳо аз рӯи сана. Методи sort унсурҳои массивро мураттаб мекунад. Аммо он ду хусусият дорад, ки қариб ҳама дар онҳо пешпо мехӯранд. Ҳардуро ҷудо мекунем.

arr.sort((a, b) => адад)Бармегардонад: ҳамон массив, аллакай мураттабМассиви аслиро тағйир медиҳад

Хусусияти 1: бе callback sort ҳамчун сатр муқоиса мекунад

const prices = [5, 100, 25, 1];
prices.sort();

console.log(prices); // → [1, 100, 25, 5]

Чаро 100 пештар аз 25 шуд? Бе callback sort ҳар унсурро ба сатр табдил медиҳад ва сатрҳоро аз рӯи аломатҳо муқоиса мекунад, мисли калимаҳо дар луғат: "1", "100", "25", "5". Сатри "100" бо «1» оғоз мешавад, бинобар ин пеш аз "25", ки бо «2» оғоз мешавад, меистад. Ҳамон тавр ки дар луғат «ананас» пеш аз «банан» меистад, новобаста аз дарозӣ.

Callback-муқоисакунанда: (a, b) => a - b

Барои дуруст мураттаб кардани ададҳо функсияи муқоиса (компаратор) медиҳем. sort худаш борҳо ҷуфтҳои унсурҳои a ва b-ро мегирад ва аз callback мепурсад: «кадоме аз онҳо бояд пештар истад?». Callback бо адад ҷавоб медиҳад:

Callback баргардондИн барои sort чӣ маъно дорад
адади манфӣ (масалан, −3)a-ро пеш аз b мемонем
адади мусбат (масалан, 7)b-ро пеш аз a мемонем
0тартиб байни онҳо муҳим нест, чун ҳаст мемонем

Акнун бинед, чаро a - b мураттабкуниро аз рӯи афзуншавӣ медиҳад. Бигзор a = 5, b = 25: 5 − 25 = −20, манфӣ — яъне 5 пеш аз 25. Бигзор a = 100, b = 25: 100 − 25 = 75, мусбат — яъне 25 пеш аз 100. Ададҳои хурдтар ба пеш мераванд. Ва b - a ҳама чизро баръакс мекунад — аз рӯи камшавӣ.

const prices = [5, 100, 25, 1];

prices.sort((a, b) => a - b);
console.log(prices); // → [1, 5, 25, 100]

prices.sort((a, b) => b - a);
console.log(prices); // → [100, 25, 5, 1]
Маслиҳат: чӣ тавр дар хотир нигоҳ доштан

a - b — «аввал a, баъд b», аз рӯи алифбо, аз рӯи афзуншавӣ: аз хурд ба калон. b - a — баръакс, аз калон ба хурд.

Мураттабкунии сатрҳо: localeCompare

Барои сатрҳо тарҳ кор намекунад ("Абдулло" - "Далер" — ин NaN аст). sort()-ро бе callback даъват кардан мумкин аст, аммо барои номҳои бо кириллица он хато мекунад: ҳарфҳои калон дар он пеш аз хурдҳо меоянд, ва ҳарфи «Ё» умуман ба оғоз мепарад.

const names = ["манижа", "Фарход", "Абдулло"];
console.log([...names].sort()); // → ["Абдулло", "Фарход", "манижа"]
console.log([...names].sort((a, b) => a.localeCompare(b))); // → ["Абдулло", "манижа", "Фарход"]

const team = ["Жасур", "Ёдгор", "Евгений"];
console.log([...team].sort()); // → ["Ёдгор", "Евгений", "Жасур"]
console.log([...team].sort((a, b) => a.localeCompare(b))); // → ["Евгений", "Ёдгор", "Жасур"]

a.localeCompare(b) — методи сатр, ки онро бо сатри дигар «ба тарзи инсонӣ», бо риояи қоидаҳои забон муқоиса мекунад. Он худаш адади манфӣ, мусбат ё 0 бармегардонад — маҳз он чи ба sort лозим аст. Барои мураттабкунии «аз Я то А» ҷой иваз кунед: b.localeCompare(a).

Мураттабкунии объектҳо

Callback ду объектро мегирад, ва мо майдони лозимаи онҳоро муқоиса мекунем.

const products = [
  { name: "Курутоб", price: 35 },
  { name: "Самбуса", price: 6 },
  { name: "Оши палав", price: 30 },
];

products.sort((a, b) => a.price - b.price);
console.log(products[0].name);    // → Самбуса
console.log(products.at(-1).name); // → Курутоб

Хусусияти 2: sort массиви аслиро тағйир медиҳад

sort массиви нав эҷод намекунад — он унсурҳоро мустақиман дар массиви аслӣ ҷойгузин мекунад. Агар тартиби аслӣ ҳанӯз лозим бошад (масалан, тартибе, ки додаҳо аз сервер омаданд), аввал нусха созед.

const scores = [70, 95, 82];

const sorted1 = [...scores].sort((a, b) => b - a);
const sorted2 = scores.slice().sort((a, b) => b - a);
const sorted3 = scores.toSorted((a, b) => b - a);

console.log(sorted1); // → [95, 82, 70]
console.log(sorted2); // → [95, 82, 70]
console.log(sorted3); // → [95, 82, 70]
console.log(scores);  // → [70, 95, 82]

Усули сеюм — методи муосири toSorted. Он ҳамон корро мекунад, ки sort, аммо массиви нав бармегардонад ва аслро даст намезанад. Он дар JavaScript ба наздикӣ (соли 2023) пайдо шуд ва дар ҳамаи браузерҳои муосир кор мекунад.

Хатогиҳои маъмул

1. Мураттабкунии ададҳо бе callback: [5, 100, 25].sort() → [100, 25, 5]. Барои ададҳо ҳамеша (a, b) => a - b нависед.

2. Callback true/false бармегардонад ба ҷойи адад: (a, b) => a > b. Чунин callback ғайримунтазир кор мекунад. Маҳз адад лозим аст: a - b.

3. Фаромӯш карданд, ки sort мутатсия мекунад ва додаҳои аслиро «вайрон карданд». Аввал нусха — баъд мураттабкунӣ.

Амалия: мустаҳкам мекунем

Саволи асосӣ дар ҳар вазифа: ададҳо ё сатрҳо, аз рӯи афзуншавӣ ё камшавӣ, ва оё асл лозим аст.

12 Занҷири методҳо

Шумо аллакай дидед: map, filter ва slice массиви нав бармегардонанд. Ва массиви нав низ ҳамаи методҳоро дорад. Яъне фавран методи навбатиро тавассути нуқта даъват кардан мумкин аст — занҷир ҳосил мешавад. Қариб ҳар коди воқеии коркарди додаҳо дар фронтенд ҳамин тавр менамояд.

Монандӣ аз ҳаёт

Конвейер дар корхонаи шарбат дар Истаравшан. Дар участкаи якум зардолуҳои пӯсидаро ҷудо мекунанд (filter), дар дуюм онҳоро мешӯянд ва мебуранд (map), дар сеюм ҳама чиз ба як бочкаи шарбат рехта мешавад (reduce). Ҳар участка натиҷаи пештараро мегирад. Занҷирро ҳамин тавр мехонем — аз боло ба поён, участка ба участка.

Вазифа: дар мағоза дар Корвон молҳои аз 100 сомонӣ гаронтарро гирифта, ба онҳо 10% тахфиф кардан ва ҷамъро ҳисоб кардан. Аввал қадам ба қадам, бо тағйирёбандаҳои миёнагӣ:

const prices = [450, 60, 380, 15, 220];

const expensive = prices.filter((p) => p > 100);
console.log(expensive);  // → [450, 380, 220]

const discounted = expensive.map((p) => p * 0.9);
console.log(discounted); // → [405, 342, 198]

const total = discounted.reduce((acc, p) => acc + p, 0);
console.log(total);      // → 945

Ва акнун ҳамин чизро бо як занҷир. Ҳар методро аз сатри нав, аз нуқта оғоз карда менависем — ин тавр занҷирро хондан осон аст:

const prices = [450, 60, 380, 15, 220];

const total = prices
  .filter((p) => p > 100)       // [450, 380, 220]
  .map((p) => p * 0.9)          // [405, 342, 198]
  .reduce((acc, p) => acc + p, 0); // 945

console.log(`К оплате: ${total} сомони`); // → К оплате: 945 сомони
  1. prices — додаҳои аслӣ, 5 нарх.
  2. .filter(...) — 3 мол гарон мемонад. Массиви нав бармегардад.
  3. .map(...) — ба массиви нав тахфиф татбиқ мешавад. Боз массиви нав бо ҳамон дарозӣ.
  4. .reduce(...) — массив ба як адад печонида мешавад. Занҷир анҷом меёбад: адад аллакай методҳои массив надорад.

Занҷир бо объектҳо ва мураттабкунӣ

const students = [
  { name: "Рустам", score: 54 },
  { name: "Мадина", score: 95 },
  { name: "Фарход", score: 88 },
  { name: "Нилуфар", score: 43 },
];

const honorBoard = students
  .filter((s) => s.score >= 60)
  .sort((a, b) => b.score - a.score)
  .map((s) => `${s.name} (${s.score})`)
  .join(", ");

console.log(honorBoard); // → Мадина (95), Фарход (88)

Дар ин ҷо sort пас аз filter меистад — ва ин бехатар аст: filter аллакай массиви нав баргардонд, бинобар ин мураттабкунӣ онро тағйир медиҳад, на students-и аслиро.

Хатогиҳои маъмул дар занҷирҳо

1. reduce дар миёна. Пас аз reduce одатан адад ё сатр ҳосил мешавад, ва бар он .map-ро даъват кардан мумкин нест — хатои «is not a function» мешавад.

2. sort дар аввали занҷир массиви аслиро вайрон мекунад. Онро пас аз filter/map/slice гузоред ё toSorted-ро истифода баред.

3. Занҷири аз ҳад дароз, ки кор намекунад. Тахмин накунед — онро ба тағйирёбандаҳои миёнагӣ ҷудо кунед ва ҳар якро тавассути console.log баровед, чун дар мисоли якум. Ин тавр шумо фавран мебинед, ки мушкил дар кадом участкаи конвейер аст.

Амалия: мустаҳкам мекунем

Ин вазифаҳо ба кори воқеии фронтенд-барномасоз монанданд. Аввал вазифаро бо калимаҳо ба участкаҳои конвейер ҷудо кунед, баъд код нависед.

Ишора 1

Ҳар сатр — методи худ: рӯзи гарм — reduce, ки дар он acc — тамоми объекти рӯз; миёна — reduce барои ҷамъ ва toFixed(1); рӯйхат — filter + map + join; саволи охирин — some.

Ишора 2

Гарм: days.reduce((acc, d) => (d.temp > acc.temp ? ___ : ___), days[0]). Рӯйхат: days.filter((d) => d.temp > ___).map((d) => d.___).join(", "). Дар хотир доред: 38 — ин «гармтар аз 38» нест.

✓ Хулоса: хулосаи массивҳо

  • [] — массив; индексҳо аз 0; охирин — arr[arr.length - 1] ё arr.at(-1); индекси ғайримавҷуд → undefined.
  • Массиви const-ро дар дохил тағйир додан мумкин аст, аммо аз нав таъин кардан мумкин нест.
  • includes(x) → оё қимат ҳаст; indexOf(x) → индекс ё -1.
  • push(x) / pop() — охири массив; unshift(x) / shift() — оғоз. Мутатсия мекунанд.
  • splice(start, deleteCount, ...items) — дар миёна нест кардан/ҷобаҷо кардан/иваз кардан; ҳазфшудагонро бармегардонад. Мутатсия мекунад.
  • slice(start, end) — нусхаи қисм, end дохил намешавад; slice() ва [...arr] — нусхаи пурра.
  • Callback — функсияест, ки метод худаш онро барои ҳар унсур даъват мекунад: (element, index, array).
  • map — ҳар якро табдил додан, дарозӣ ҳамон. return-ро дар қавсайни фигурӣ фаромӯш накунед.
  • filter — мувофиқҳоро мондан, натиҷа метавонад [] бошад.
  • find / findIndex — аввалин мувофиқ ё undefined / -1. «Ёфт нашуд»-ро санҷед.
  • some — ҳадди аққал яке? (холӣ → false); every — ҳама? (холӣ → true).
  • reduce((acc, cur) => ..., оғоз) — ба як қимат овардан. Қимати оғозӣ — ҳамеша.
  • sort((a, b) => a - b) — ададҳо аз рӯи афзуншавӣ; сатрҳо — a.localeCompare(b). Мутатсия мекунад: нусха кунед ё toSorted гиред.
  • join(", ") — массивро ба сатр пайвастан.
  • Занҷир: filter → map → reduce, аз боло ба поён мехонем, чун конвейер.
Чӣ тавр дар бораи массивҳо аз ЗС хоҳиш кардан

1. Методро ном баред. Агар шумо медонед, ки кадом метод лозим аст, инро бигӯед: «тавассути filter ва map ҳал кун, бе давраҳо». Вагарна ЗС метавонад ҳалле диҳад, ки усулҳояш барои шумо нофаҳмост.

2. Мисоли додаҳо ва натиҷаи интизориро диҳед. «Инак массиви [450, 60, 380], мехоҳам [405, 342]-ро гирам» — ин тавр ЗС вазифаро дақиқ мефаҳмад ва тахмин намекунад.

3. Хоҳиш кунед, ки ҳар қадамро шарҳ диҳад. На танҳо «код нависед», балки «шарҳ деҳ, ки дар ҳар қадам чӣ рӯй медиҳад, ва қиматҳои миёнагиро нишон деҳ». Коде, ки шумо мефаҳмед, — аз они шумост; коде, ки оддӣ нусха кардед, — не.

ба тарзе кун, ки нархҳо ҳисоб шаванд
Ман массиви молҳо дорам: [{ name: "Куртка", price: 450 }, { name: "Шапка", price: 60 }]. Мехоҳам ҷамъи нархи молҳои аз 100 сомонӣ гаронтарро бо тахфифи 10% гирам. Бо занҷири filter → map → reduce ҳал кун, бе давраҳо. Пас аз код ҳар қадамро шарҳ деҳ ва нишон деҳ, ки пас аз ҳар метод кадом массив ҳосил мешавад.
