Функсияҳо

Функсия — як пораи кодест, ки ном дорад ва онро борҳо ва борҳо иҷро кардан мумкин аст. Тугмаи «Харидан», санҷиши парол, ҳисоби маблағи сабад — паси ҳар чунин амал дар сайт функсия меистад. Имрӯз мо фаро мегирем, ки онҳоро чӣ тавр нависем, фаҳмем ва кодҳои дигаронро хонем.

  • Функсияҳоро бо ду усул эълон кардан: Declaration ва Expression
  • Функсияҳои тирдори кӯтоҳ навиштан
  • Тавассути параметрҳо додаҳо фиристодан ва қиматҳои пешфарзро муайян кардан
  • Натиҷаро тавассути return баргардондан
  • Фаҳмидани он, ки тағйирёбанда дар куҷо «намоён» аст — доираи намоёнӣ
Бо ин саҳифа чӣ тавр кор кардан лозим

Тамоми кодҳо дар заминаи торик бо тугмаи ▶ Иҷро — зинда мебошанд. Онҳоро худи ҳамин ҷо тағйир додан ва натиҷаро фавран дар консол, дар зери код, дидан мумкин аст. Агар вайрон кардед — ↺ Аз нав-ро пахш кунед. Ишораҳо ба вазифаҳо дар зери қулф 🔒 пинҳон шудаанд: аввал худатон кӯшиш кунед, ишораро танҳо дар сурати печидан кушоед.

01 Функсия чист. Function Declaration

Тасаввур кунед, ки шумо бояд се маротиба дар ҷойҳои гуногуни барнома корбарро салом диҳед. Бе функсияҳо код чунин менамояд:

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в MakeFirstStep");

// ... ягон коди дигар ...

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в MakeFirstStep");

// ... ва боз як бор ...

console.log("Ассалому алейкум!");
console.log("Добро пожаловать в MakeFirstStep");

Кор мекунад, аммо тасаввур кунед, ки матнро бояд иваз кард. Шумо бояд онро дар ҳама ҷо ёфта ислоҳ кунед — ва дар ягон ҷо ҳатман фаромӯш мекунед. Функсия ин мушкилро ҳал мекунад: мо амалро як бор тавсиф карда, ба он ном медиҳем, баъд онро танҳо бо ном даъват мекунем.

function greet() {
  console.log("Ассалому алейкум!");
  console.log("Добро пожаловать в MakeFirstStep");
}

greet();
greet();
greet();
Монандӣ аз ҳаёт

Функсия — ин дастур (рецепт) аст. Дастури оши палавро як бор менависанд: чиро гирифтан ва бо кадом тартиб пухтан. Вақте палав мехоҳем — онро аз нав ихтироъ намекунем, балки дастурро мекушоем ва аз рӯи он мепазем. Навиштани дастур — ин эълон кардани функсия аст. Аз рӯи дастур пухтан — даъват кардани функсия. Дастурро ҳар қадар бор истифода бурдан мумкин аст.

Функсия аз чӣ иборат аст

Усуле, ки мо ҳозир истифода бурдем, Function Declaration — «эълони функсия» ном дорад. Онро аз рӯи қисмҳо ҷудо мекунем:

function
Калимаи калидӣ. Ба JavaScript мегӯяд: «ҳозир функсия меояд».
Ном
Бо кадом ном ба функсия муроҷиат мекунем. Одатан ин феъл бо забони англисӣ аст: greet, showMenu, calcTotal.
Параметрҳо
Дар қавсайни доира. Ин «додаҳои вурудии» функсия мебошанд. Қавсайн ҳамеша навишта мешаванд, ҳатто агар холӣ бошанд.
Бадан
Код дар қавсайни фигурӣ { }. Ҳар дафъае, ки функсияро даъват мекунанд, иҷро мешавад.
Даъват
Номи функсия ва қавсайни доира: greet(). Маҳз қавсайн функсияро ба кор медароранд.

Ҳангоми даъват чӣ рӯй медиҳад — қадам ба қадам

function welcome(name) {
  console.log("Хуш омадед, " + name + "!");
}

welcome("Мадина");   // → Хуш омадед, Мадина!
welcome("Фарход");   // → Хуш омадед, Фарход!
  1. JavaScript эълонро мебинад ва ба ёд мегирад: функсияи welcome мавҷуд аст. Коди дохили он ҳоло иҷро намешавад — дастур навишта шудааст, аммо пухтан ҳоло оғоз нашудааст.
  2. Даъватро вомехӯрад — welcome("Мадина") — ва ба дохили функсия «ҷаҳида медарояд».
  3. Қиматро ба параметр мемонад: name ба "Мадина" баробар мешавад.
  4. Баданро иҷро мекунад — сатрро ба консол мебарорад.
  5. Бармегардад ба он ҷое, ки аз он функсияро даъват карда буданд, ва минбаъд — ба даъвати навбатӣ мегузарад, ки дар он name аллакай "Фарход" мешавад.

Функсияҳоро чӣ тавр ном гузорем

  • Ном амал-ро тавсиф мекунад: showPrice, checkPassword, sendMessage.
  • Бо услуби camelCase менависем: калимаи аввал бо ҳарфи хурд, ҳар як калимаи баъдӣ — бо ҳарфи калон.
  • Танҳо ҳарфҳои лотинӣ. Кириллица аз ҷиҳати техникӣ кор мекунад, аммо дар лоиҳаҳои воқеӣ чунин намениванд.
  • Як функсия — як амал. Агар дар ном мехоҳед «ва» нависед (checkAndSendAndSave), пас ин бояд якчанд функсия бошад.
Хатои маъмул

Қавсайнро ҳангоми даъват фаромӯш кардан. greet бе қавсайн — танҳо «зикр»-и функсия аст, он кор намекунад. Бояд greet() навишт.

function greet() {
  console.log("Салом!");
}

greet;               // ҳеҷ чиз рӯй намедиҳад — функсия даъват нашудааст
console.log(greet);  // → ƒ greet() — худи функсия баромад мекунад, на натиҷаи он
greet();             // → Салом!

02 Function Expression

Дар JavaScript функсия — ҳамон қимат-и монанди адад ё сатр аст. Ва ҳар қимате ро ба тағйирёбанда гузоштан мумкин аст. Ин усул Function Expression — «ифодаи функсионалӣ» ном дорад.

// Declaration — эълон
function sayHi() {
  console.log("Салом!");
}

// Expression — функсия ба тағйирёбанда гузошта мешавад
const sayBye = function () {
  console.log("Хайр, то пагох!");
};

sayHi();   // → Салом!
sayBye();  // → Хайр, то пагох!

Ба варианти дуюм бодиққат нигаред:

  • пас аз калимаи function ном нест — чунин функсия беном (аноним) номида мешавад. Номи он — номи тағйирёбандаи sayBye аст;
  • мо const-ро истифода мебарем, то функсияро тасодуфан аз нав сабт накунем;
  • дар охир нуқтавергул ; меистад — чунки ин ҷойгиркунии оддӣ аст, мисли const x = 5;.
Монандӣ аз ҳаёт

Declaration — дастурест, ки дар китоб дар зери сарлавҳаи «Оши палав» чоп шудааст. Expression — ҳамон дастур, аммо дар корт навишта ва ба қуттӣ бо номи sayBye гузошташуда. Аз рӯи ҳарду пухтан мумкин аст. Фарқ дар он аст, ки дастур кай дастрас мешавад — дар бораи ин дар поён.

Функсия ҳамчун қимат

Азбаски функсия — қимат аст, онро ба тағйирёбандаи дигар додан мумкин аст. Диққат диҳед: бе қавсайн мо худи функсия-ро медиҳем, на ин ки онро даъват мекунем.

const greet = function (name) {
  console.log(`Салом, ${name}!`);
};

const hello = greet;   // акнун як функсия ду ном дорад
hello("Шахром");       // → Салом, Шахром!
greet("Шахром");       // → Салом, Шахром!

Маҳз ҳамин ғоя — «функсияро ҳамчун қимат додан мумкин аст» — дар дарси оянда асосӣ мешавад, вақте ки мо функсияҳоро ба методҳои массиви map ва filter медиҳем.

Фарқи асосӣ: hoisting («боло бардорӣ»)

Пеш аз иҷрои код, JavaScript файлро зуд аз назар мегузаронад ва ҳамаи функсияҳоеро, ки тавассути Declaration эълон шудаанд, пешакӣ ба ёд мегирад. Бинобар ин онҳоро ҳатто болотар аз ҷое, ки навишта шудаанд, даъват кардан мумкин аст. Инро hoisting — «боло бардорӣ» меноманд.

showMenu(); // → Меню: самбуса, курутоб, чой — кор мекунад, ҳарчанд функсия поёнтар аст!

function showMenu() {
  console.log("Меню: самбуса, курутоб, чой");
}

Бо Expression ин тавр намебарояд: тағйирёбандаи const танҳо дар ҳамон сатре пайдо мешавад, ки онро эълон кардаанд. То ин сатр он танҳо вуҷуд надорад.

showPrices(); // ✖ хато: ба тағйирёбанда пеш аз эҷод шуданаш муроҷиат мекунем

const showPrices = function () {
  console.log("Самбуса — 5 сомони");
};

Амалия: мустаҳкам мекунем

ВАЗИФАИ 2.1

Ба Expression аз нав нависед

осон

Дар зер функсия дар шакли Declaration аст. Онро ба шакли Function Expression бо ҳамон ном аз нав нависед ва даъват кунед. Натиҷа набояд тағйир ёбад.

// Function Expression-и шумо бо номи showAddress

Ишора 1

Номи функсия ба номи тағйирёбанда табдил меёбад: const showAddress = ...

Ишора 2

Пас аз аломати = function () { ... } бе ном навишта мешавад, ва дар охири охир — нуқтавергул.

ВАЗИФАИ 2.2

миёна

Бе иҷрои код, шифоҳӣ ё дар дафтар ҷавоб диҳед: сатри аввал чиро мебарорад? Дар сатри сеюм чӣ рӯй медиҳад? Баъд иҷро кунед ва худро санҷед. Пас аз ин кодро ислоҳ кунед, то ҳарду функсия кор кунанд, ва ифодаи hi Expression боқӣ бимонад.

03 Параметрҳо, аргументҳо ва қиматҳои пешфарз

Функсия бе параметрҳо ҳар дафъа як чизро иҷро мекунад. Параметрҳо имкон медиҳанд, ки ба он додаҳои гуногун диҳем — ва он гоҳ як функсия дар ҳолатҳои гуногун кор мекунад.

Монандӣ аз ҳаёт

Барномаи таксӣ. Дар он шакле ҳаст бо майдонҳои «Аз куҷо» ва «То куҷо» — ин параметрҳо мебошанд: ҷой барои додаҳо. Вақте шумо мошин мефармоед ва «Сино» ва «Корвон»-ро менависед — ин аргументҳо мебошанд: қиматҳои мушаххасе, ки ба ин майдонҳо афтоданд. Шакл як аст, аммо сафарҳо ҳар дафъа гуногунанд.

Параметр
Ном дар қавсайн ҳангоми эълон-и функсия: function orderTaxi(from, to). Дар дохили функсия ин тағйирёбандаи оддӣ аст.
Аргумент
Қимати мушаххас ҳангоми даъват: orderTaxi("Сино", "Корвон").
function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Сино", "Корвон");        // → Такси: Сино → Корвон
orderTaxi("Аэропорт", "Ботсад");    // → Такси: Аэропорт → Ботсад

Тартиб муҳим аст

Аргументҳо ба параметрҳо қатъиян бо тартиб меафтанд: якум — ба якум, дуюм — ба дуюм. Номҳои тағйирёбандаҳо ҳангоми даъват нақш намебозанд.

function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Корвон", "Сино");   // → Такси: Корвон → Сино — ҷой иваз карда шуд, ба самти муқобил рафтанд!

Агар аргументҳо камтар ё бештар бошанд

JavaScript эътироз намекунад, агар аргументҳо на ба қадари параметрҳо дода шаванд:

  • аргумент намерасад — параметр қимати undefined («номуайян») мегирад;
  • аргументҳои изофӣ — оддӣ нодида гирифта мешаванд.
function orderTaxi(from, to) {
  console.log(`Такси: ${from} → ${to}`);
}

orderTaxi("Сино");                          // → Такси: Сино → undefined
orderTaxi("Сино", "Корвон", "с кондиционером"); // → Такси: Сино → Корвон

Қиматҳои пешфарз

То ба ҷои undefined чизи мантиқӣ бошад, ба параметр қимати пешфарз-ро мустақиман дар қавсайн, тавассути аломати = муайян кардан мумкин аст. Он танҳо дар сурате кор мекунад, ки аргумент дода нашуда бошад.

function greet(name = "гость") {
  console.log(`Салом, ${name}!`);
}

greet("Далер");  // → Салом, Далер!
greet();         // → Салом, гость!

function makeTea(sort = "зелёный", sugar = 0) {
  console.log(`Чой: ${sort}, сахара: ${sugar} ложки`);
}

makeTea();                 // → Чой: зелёный, сахара: 0 ложки
makeTea("чёрный");         // → Чой: чёрный, сахара: 0 ложки
makeTea("чёрный", 2);      // → Чой: чёрный, сахара: 2 ложки

Қапқон

Параметрҳои дорои қимати пешфарзро дар охир-и рӯйхат гузоред. Аввал додаҳои ҳатмӣ, баъд ғайриҳатмӣ: function bookTicket(city, seat = "у окна").

04 return — функсия натиҷаро бармегардонад

То ҳол функсияҳои мо танҳо чизеро дар консол нишон медоданд. Аммо бештар функсия бояд натиҷаро ҳисоб кунад ва онро ба мо супорад, то мо минбаъд бо он кор карда тавонем: ҷамъ кунем, муқоиса намоем, дар саҳифа нишон диҳем. Барои ин калимаи return — «бозгардондан» ҳаст.

function sum(a, b) {
  return a + b;
}

const result = sum(10, 5);
console.log(result);          // → 15
console.log(sum(2, 3) * 10);  // → 50

Вақте функсия return-ро вомехӯрад, ӯ қиматро медиҳад ба ҷое, ки аз он даъват шуда буд. Тасаввур кардан мумкин аст, ки даъвати sum(10, 5) гӯё бо натиҷа — адади 15 иваз мешавад. Бинобар ин даъвати функсияро ба тағйирёбанда гузоштан, ба ифода ҷойгир кардан ё ба функсияи дигар додан мумкин аст.

Монандӣ аз ҳаёт

Шумо ба фурӯшанда дар Шоҳмансур барои хариди 70 сомонӣ 100 сомонӣ медиҳед. Фурӯшанда ҳисоб мекунад ва ба шумо бақияро бармегардонад — 30 сомонӣ. Ин пул акнун дар дасти шумост: сарф кардан, гузоштан, аз нав шумурдан мумкин аст. Ин маҳз return аст. Ва console.log — ин ҳамон вақт аст, ки фурӯшанда танҳо баланд мегӯяд «бақия 30!», вале пул намедиҳад. Шунидед — вассалом, чизе барои истифода нест.

console.log ва return — як чиз нестанд

Ин серталабтарин иштибоҳи навомӯзон аст. Муқоиса кунед:

Танҳо мебарорад

Натиҷа нишон дода шудааст, аммо онро гирифтан мумкин нест.

function getChange(paid, price) {
  console.log(paid - price);
}

const change = getChange(100, 70);
// → 30 (худи функсия баровард)
console.log("Сдача:", change);
// → Сдача: undefined 😕
Бармегардонад

Натиҷаро нигоҳ доштан ва истифода бурдан мумкин аст.

function getChange(paid, price) {
  return paid - price;
}

const change = getChange(100, 70);
console.log("Сдача:", change);
// → Сдача: 30 ✓

Қоида: агар функсия чизеро ҳисоб кунад — бигзор натиҷаро тавассути return баргардонад. Аммо ин ки онро ба консол ё саҳифа баровардан, коде ҳал мекунад, ки ин функсияро даъват кардааст.

Бе return функсия undefined бармегардонад

function doNothing() {
  const x = 5;
}

console.log(doNothing()); // → undefined

return функсияро фавран анҷом медиҳад

Пас аз return функсия кор карданро қатъ мекунад. Коди поёнтар аз он аллакай иҷро намешавад.

function test() {
  console.log("Шаг 1");
  return "готово";
  console.log("Шаг 2"); // ин сатр ҳеҷ гоҳ иҷро намешавад
}

console.log(test());
// → Шаг 1
// → готово

Аксар вақт аз ин истифода мебаранд, то дар сурати нодуруст будани чизе аз функсия барвақттар баромад. Чунин усулро «баромади барвақт» (guard) меноманд.

function canEnroll(age) {
  if (age < 14) {
    return "Пока рано: на курс принимают с 14 лет";
  }
  return "Добро пожаловать на курс!";
}

console.log(canEnroll(12)); // → Пока рано: на курс принимают с 14 лет
console.log(canEnroll(17)); // → Добро пожаловать на курс!

Қайд кунед: else дар ин ҷо лозим нест. Агар шарти аввал кор карда бошад, функсия аллакай дар return-и якум баромадааст ва ба дуюм намерасад.

Функсия метавонад true ё false баргардонад

Функсияҳои санҷишӣ одатан қимати мантиқӣ бармегардонанд. Онҳоро одатан бо is, has ё can дар аввал ном мегузоранд:

function isAdult(age) {
  return age >= 18;
}

console.log(isAdult(20)); // → true
console.log(isAdult(15)); // → false

if (isAdult(19)) {
  console.log("Можно получить водительские права");
}

Функсияҳо якҷоя кор мекунанд

Натиҷаи як функсияро фавран ба дигаре додан мумкин аст. Ин тавр аз функсияҳои хурди содда барномаҳои калон месозанд.

function getTotal(price, count) {
  return price * count;
}

function addDelivery(total) {
  return total + 10;
}

const order = addDelivery(getTotal(35, 3)); // 3 курутоб ба нархи 35 + расонидан 10
console.log(`К оплате: ${order} сомони`);  // → К оплате: 115 сомони
Қапқон

Қимати баргардониданиро пас аз return ба сатри дигар нагузаронед. JavaScript худаш пас аз калимаи return фавран нуқтавергул мемонад, ва функсия undefined бармегардонад.

function getCity() {
  return
    "Душанбе";
}

console.log(getCity()); // → undefined — қимат «гум шуд»

05 Функсияҳои тирдор

Функсияи тирдор (arrow function) — навишти кӯтоҳ-и Function Expression аст. Номи худро аз аломати =>, ки ба тир монанд аст, гирифтааст. Дар коди муосир, дар React ва дар коде, ки ЗС менависад, шумо онро пайваста вомехӯред.

Функсияи оддиро ба тирдор табдил медиҳем — қадам ба қадам

  1. Функсияи аслӣ — Expression 
    const double = function (n) {
  return n * 2;
};
  2. Калимаи function-ро мебарорем, пас аз қавсайн тир => мегузорем 
    const double = (n) => {
  return n * 2;
};
  3. Агар дар бадан танҳо return бошад — қавсайни фигурӣ ва худи калимаи return-ро мебарорем. Қимат худкор бармегардад. 
    const double = (n) => n * 2;
  4. Агар параметр маҳз як бошад — қавсайни доираро ҳам бардоштан мумкин аст 
    const double = n => n * 2;

Ҳар чор вариант як корро мекунанд. Санҷед:

const double = n => n * 2;

console.log(double(5));   // → 10
console.log(double(21));  // → 42

Қоидаҳои навишт

ҲолатЧӣ тавр менависем
Параметр нестconst hi = () => "Салом!"; — қавсайн ҳатмист
Як параметрconst double = n => n * 2; — қавсайнро партофтан мумкин аст
Якчанд параметрconst sum = (a, b) => a + b; — қавсайн ҳатмист
Як ифодаБе { } — натиҷа худкор бармегардад
Якчанд сатрБо { } — ва он гоҳ return-ро худамон менависем
 
const sayHi = () => "Салом!";
const sum = (a, b) => a + b;
const isEven = n => n % 2 === 0;

// якчанд сатр — қавсайни фигурӣ ва return лозиманд
const getBill = (price, people) => {
  const tip = price * 0.1;
  return (price + tip) / people;
};

console.log(sayHi());          // → Салом!
console.log(sum(7, 8));        // → 15
console.log(isEven(10));       // → true
console.log(getBill(200, 4));  // → 55
Хатои маъмул

Қавсайни фигурӣ гузоштан ва return-ро фаромӯш кардан. Ҳамин ки { } пайдо шуд, бозгашти худкор нест мешавад — функсия undefined бармегардонад.

Хато 
const triple = n => { n * 3 };
console.log(triple(4)); // → undefined
Дуруст 
const triple = n => n * 3;
console.log(triple(4)); // → 12

Кай кадом функсияро истифода бурдан

  • Тирдор — барои функсияҳои кӯтоҳ ва махсусан вақте ки функсияро ба функсияи дигар медиҳанд. Дар дарси оянда мебинед, ки онҳо дар методҳои массив чӣ қадар зебо менамоянд: prices.map(p => p * 2).
  • Declaration — барои функсияҳои калон, «асосӣ»-и барнома, ки номи муҳим доранд.
  • Функсияҳои тирдор як хусусияте доранд, ки ба калимаи this вобаста аст. Онро мо дар дарс дар бораи объектҳо ҷудо мекунем, ҳоло танҳо дар хотир нигоҳ доред, ки он вуҷуд дорад.
Ишораи ЗС

ЗС қариб ҳамеша кодро бо функсияҳои тирдор менависад. Агар тири нофаҳмо бинед, хоҳиш кунед: «Ин функсияи тирдорро ба Function Declaration-и оддӣ аз нав навис ва фарқро шарҳ деҳ». Ду вариантро паҳлӯ ба паҳлӯ муқоиса кардан — беҳтарин роҳи фаҳмидани навишт аст.

Амалия: мустаҳкам мекунем

Дар дохили сатри қолабии tripInfo travelTime(distance, speed)-ро даъват кунед. Агар speed дода нашавад, ба он ҷо undefined меравад — ва дар travelTime қимати пешфарз кор мекунад.

06 Доираи намоёнӣ

Доираи намоёнӣ (scope) ба ин савол ҷавоб медиҳад: тағйирёбанда дар кадом ҷои код «намоён» аст ва онро истифода бурдан мумкин аст. Аз ин вобаста аст, ки чаро баъзан код хатои is not defined медиҳад, ҳарчанд тағйирёбанда «ана, навишта шудааст».

Монандӣ аз ҳаёт

Хонаи бисёрошёнаро тасаввур кунед. Ҳавлӣ — умумӣ: майдончаи бачагонаро ҳамаи сокинон мебинанд. Хонавор — шахсӣ: дар хонавор будан, шумо ҳам чизҳои худро мебинед, ҳам (аз тиреза) ҳавлиро. Аммо ҳамсояҳо аз ҳавлӣ намебинанд, ки дар сари мизи шумо чӣ ҳаст. Дар код ҳам ҳамин тавр: аз дарун ба берун намоён аст, аммо аз берун ба дарун — не.

1. Доираи глобалӣ

Тағйирёбандаҳое, ки берун аз ҳамаи функсияҳо ва блокҳо эълон шудаанд. Дар ҳама ҷо дар барнома намоёнанд.

const academy = "MakeFirstStep";

function showAcademy() {
  console.log(`Учимся в ${academy}`); // функсия тағйирёбандаи глобалиро мебинад
}

showAcademy();         // → Учимся в MakeFirstStep
console.log(academy);  // → MakeFirstStep

2. Доираи функсия (маҳаллӣ)

Тағйирёбандаҳое, ки дар дохили функсия эълон шудаанд, танҳо дар дохили он вуҷуд доранд. Параметрҳои функсия низ тағйирёбандаҳои маҳаллӣ мебошанд. Аз берун онҳо намоён нестанд.

function makeOrder() {
  const dish = "оши палав";
  console.log(`Заказ: ${dish}`);
}

makeOrder();       // → Заказ: оши палав
console.log(dish); // ✖ ReferenceError: dish is not defined

Ин хато нест, балки хусусияти хеле фоиданок аст. Ҳар функсия мисли хонаваре ҷудогона аст: дар дохил тағйирёбандаҳоро бо оромӣ ном гузоштан мумкин аст, бидуни тарс аз он ки онҳо бо тағйирёбандаҳои функсияи дигар «омехта мешаванд».

function morning() {
  const message = "Субх ба хайр!";
  console.log(message);
}

function evening() {
  const message = "Шаб ба хайр!"; // ҳамон ном — ҳеҷ ихтилоф нест
  console.log(message);
}

morning(); // → Субх ба хайр!
evening(); // → Шаб ба хайр!

3. Доираи блокӣ

Ҳар қавсайни фигурии { } — дар if, for, while — низ доираи худро месозад. Тағйирёбандаҳои let ва const, ки дар блок эълон шудаанд, танҳо дар дохили ҳамин блок намоёнанд.

const score = 92;

if (score >= 86) {
  const grade = 5;
  console.log("Оценка внутри блока:", grade); // → Оценка внутри блока: 5
}

console.log(typeof grade); // → undefined — берун аз блок grade вуҷуд надорад

Пӯшонидан: номҳои якхела

Агар дар дохили функсия тағйирёбандаро бо ҳамон номе эълон кунед, ки дар берун ҳаст, тағйирёбандаи дарунӣ беруниро мепӯшонад («сояафкан мешавад»). Тағйирёбандаи берунӣ дар ин вақт тағйир намеёбад.

const weather = "солнечно";

function showMountainWeather() {
  const weather = "снег"; // тағйирёбандаи худӣ, маҳаллӣ
  console.log("В Варзобе:", weather);
}

showMountainWeather();             // → В Варзобе: снег
console.log("В Душанбе:", weather); // → В Душанбе: солнечно

JavaScript тағйирёбандаро аз дарун ба берун меҷӯяд: аввал дар доираи ҷорӣ, баъд дар доираи берунӣ, ва ҳамин тавр то глобалӣ. Аввалинеро, ки ёфт, мегирад. Агар дар ҳеҷ ҷо наёфт — хатои is not defined.

Чӣ тавр қиматро аз функсия ба берун баровардан

Роҳи дуруст — return. Функсия қиматро бармегардонад, ва мо онро дар берун ба тағйирёбанда нигоҳ медорем.

function getDish() {
  const dish = "оши палав";
  return dish;
}

const myDish = getDish();
console.log(myDish); // → оши палав
Муҳим: пас var чӣ мешавад?

Дар коди кӯҳна (ва баъзан дар ҷавобҳои ЗС) var вомехӯрад. Он ба доираи блокӣ итоат намекунад — аз қавсайни фигурии if ва for «мегузарад». Аз ин сабаб хатогиҳои душворёфт ба вуҷуд меоянд. Дар коди муосир танҳо const (аз рӯи пешфарз) ва let (агар қимат тағйир ёбад) менависем.

if (true) {
  var oldStyle = "я протёк наружу";
  let newStyle = "я остался внутри";
}

console.log(oldStyle);        // → я протёк наружу
console.log(typeof newStyle); // → undefined
Маслиҳат

Тағйирёбандаро дар хурдтарин доирае эълон кунед, ки ба он лозим аст. Тағйирёбандаҳои глобалиро ҳар функсияи барнома тасодуфан тағйир дода метавонад — ва баъд ёфтани он ки ин корро кӣ кард, хеле душвор аст. Тағйирёбандаҳои глобалӣ чӣ қадар кам бошанд, зиндагӣ ҳамон қадар ором аст.

Амалия: мустаҳкам мекунем

Дар ин ҷо на танҳо навиштани код, балки пешбинӣ кардани рафтори он низ муҳим аст.

ВАЗИФАИ 6.1

Кӣ чиро мебинад

осон

Бе иҷрои код, дар дафтар нависед, ки ҳар кадом аз се сатри console.log чиро мебарорад. Сипас иҷро кунед ва бо натиҷа муқоиса намоед. Барои ҳар сатр шарҳ диҳед, ки JavaScript кадом тағйирёбандаи name-ро ёфт ва чаро.

const name = "MakeFirstStep";

function first() {
  const name = "Фарход";
  console.log("1:", name);
}

function second() {
  console.log("2:", name);
}

first();
second();
console.log("3:", name);
Натиҷаи интизоршаванда
Сначала ваш прогноз — потом кнопка «Запустить»
Ишора 1

Қоидаи ҷустуҷӯро ба ёд оред: JavaScript тағйирёбандаро аввал дар доираи ҷорӣ меҷӯяд, баъд ба берун мебарояд.

Ишора 2

Функсияи first name-и худӣ дорад. Ва second худӣ надорад — ба куҷо «нигоҳ кардан» лозим меояд?

ВАЗИФАИ 6.2

Кодро таъмир кунед

миёна

Коди зер бо хато меафтад. Сабабро ёбед ва онро ислоҳ кунед, то ҷамъи ниҳоӣ дар дохили функсия ҳисоб шавад, ва дар берун бароварда шавад. Дар дохили функсия тағйирёбандаҳои глобалӣ эҷод кардан мумкин нест — return-ро истифода баред.

function calcCart(price, count) {
  const total = price * count;
}

calcCart(15, 4);
console.log(`Сумма корзины: ${total} сомони`);
Натиҷаи интизоршаванда
Сумма корзины: 60 сомони
Ишора 1

Матни хаторо дар консол хонед. total дар дохили функсия эълон шудааст — дар кадом доира намоён аст?

Ишора 2

Функсия бояд total-ро баргардонад, ва дар берун натиҷаи даъватро ба тағйирёбанда нигоҳ доштан лозим аст: const total = calcCart(...).

ВАЗИФАИ 6.3

Ҳисобкунаки меҳмонон

душвор

Дар даромадгоҳи китобхона ҳисобкунак гузошта шудааст. Функсияи addVisitor(name)-ро нависед, ки ҳангоми ҳар даъват шумораи умумии меҳмононро ба 1 зиёд мекунад ва сатрро чун дар мисол мебарорад. Онро барои се меҳмон даъват кунед. Сипас хаттӣ ҷавоб диҳед: чаро тағйирёбандаи ҳисобкунакро дар дохили функсия эълон кардан мумкин нест? Ҷавоби худро санҷед — онро ба дохил гузаронед ва иҷро кунед.

// ҳисобкунакро дар куҷо эълон кунем?

// function addVisitor(name) { ... }

addVisitor("Сабрина");
addVisitor("Далер");
addVisitor("Манижа");
Натиҷаи интизоршаванда
Добро пожаловать, Сабрина! Посетителей сегодня: 1
Добро пожаловать, Далер! Посетителей сегодня: 2
Добро пожаловать, Манижа! Посетителей сегодня: 3
Ишора 1

Ҳисобкунак бояд байни даъватҳои функсия «зинда» монад. Тағйирёбандаҳои дохили функсия ҳар дафъаи даъват аз нав эҷод мешаванд — ва ҳар дафъа аз сифр оғоз мегарданд.

Ишора 2

let visitors = 0;-ро дар берун аз функсия эълон кунед, ва дар дохил зиёд кунед: visitors++.

07 Амалияи ниҳоӣ

Акнун ҳамаро якҷоя ҷамъ мекунем. Дар ин вазифаҳо ҳамаи мавзӯъҳои дарс муфид мешаванд: эълони функсияҳо, параметрҳои пешфарз, return, функсияҳои тирдор ва доираи намоёнӣ. Бо тартиб ҳал кунед — ҳар кадоми баъдӣ каме мушкилтар аст.

Вазифаи калонро чӣ тавр ҳал кардан

1) Шартро ду бор хонед. 2) Нависед, ки функсия чиро мегирад (параметрҳо) ва чиро бармегардонад. 3) Дар мисоли мушаххас дар зеҳн ё дар коғаз ҳал кунед. 4) Танҳо баъд код нависед — ва онро пас аз ҳар қадам бо тугмаи «Иҷро» санҷед.

Амалия: ҳамаро якҷоя ҷамъ мекунем

Се вазифа — се барномаи хурд.

ВАЗИФАИ 7.1

Ҳисоб дар чойхона

миёна

Гурӯҳи дӯстон дар чойхона шом хӯрданд. Функсияи splitBill(total, people, tipPercent)-ро нависед, ки бармегардонад, ҳар кас бо назардошти чойпулӣ чӣ қадар бояд пардозад. Чойпулии пешфарз — 10%. Натиҷаро бо Math.round() то адади бутун мудаввар кунед.

// function splitBill(...) { ... }

console.log(splitBill(360, 4));
console.log(splitBill(250, 3, 15));
console.log(splitBill(500, 5, 0));
Натиҷаи интизоршаванда
99
96
100
Ишора 1

Тартиби амалҳо: чойпулиро ҳисоб кардан → ба маблағ илова намудан → ба шумораи одамон тақсим кардан → мудаввар кардан.

Ишора 2

Маблағ бо чойпулӣ: total + total * tipPercent / 100. Ба даъвати сеюм диққат диҳед: 0 — қимати ҳақиқӣ аст, қимати пешфарз дар ин ҷо кор намекунад (ва набояд кунад).

ВАЗИФАИ 7.2

Обуҳаво дар Душанбе

миёна

Ду функсия нависед. Функсияи тирдори toFahrenheit(c) дараҷаҳои Селсияро аз рӯи формулаи c × 9 / 5 + 32 ба Фаренгейт табдил медиҳад. Функсияи describeWeather(c) аввалиро истифода мебарад ва сатрро бармегардонад: аз 30 °C ва боло — жарко, аз 15 — тепло, пасттар — прохладно. return-и барвақтро истифода баред.

// const toFahrenheit = ...
// function describeWeather(c) { ... }

console.log(describeWeather(38));
console.log(describeWeather(22));
console.log(describeWeather(5));
Натиҷаи интизоршаванда
38°C (100.4°F) — жарко
22°C (71.6°F) — тепло
5°C (41°F) — прохладно
Ишора 1

Аввал Фаренгейтро ба тағйирёбанда дар дохили describeWeather ҳисоб кунед, то функсияро якчанд бор даъват накунед.

Ишора 2

Санҷишҳо аз ҳарорати баландтар ба пасттар мераванд: if (c >= 30) return ...; баъд if (c >= 15) return ...;, ва return-и охирин — барои ҳамаи ҳолатҳои боқимонда.

ВАЗИФАИ 7.3

Варақаи имтиҳон

душвор

Муаллим балҳоро (аз 0 то 100) ба баҳо табдил медиҳад: 86 ва боло — 5, аз 71 — 4, аз 56 — 3, пасттар — 2. Нависед:

  • getGrade(score) — баҳоро ҳамчун адад бармегардонад;
  • isPassed(score) — тирдор, агар баҳо 3 ва боло бошад, true бармегардонад (дар дохил getGrade-ро истифода баред);
  • report(name, score) — сатрро барои варақа бармегардонад, ҳарду функсияро истифода бурда.
// function getGrade(score) { ... }
// const isPassed = ...
// function report(name, score) { ... }

console.log(report("Рустам", 87));
console.log(report("Зарина", 72));
console.log(report("Шахром", 56));
console.log(report("Далер", 50));
Натиҷаи интизоршаванда
Рустам: 87 баллов, оценка 5 — сдал
Зарина: 72 баллов, оценка 4 — сдал
Шахром: 56 баллов, оценка 3 — сдал
Далер: 50 баллов, оценка 2 — пересдача
Ишора 1

Аз getGrade оғоз кунед ва онро алоҳида санҷед: console.log(getGrade(90)). Танҳо вақте ки кор мекунад — ба функсияи навбатӣ гузаред. Барномаҳоро ҳамин тавр аз хиштҳои хурди боэътимод месозанд.

Ишора 2

isPassed дар як сатр: score => getGrade(score) >= 3. Дар report калимаи «супорид» ё «бозтопшӣ»-ро бо оператори сегона интихоб кардан қулай аст: isPassed(score) ? "сдал" : "пересдача".

✓ Хулосаи дарс

  • Функсия — пораи кодест бо ном. Як бор эълон кардем — ҳар қадар хоҳем даъват мекунем: greet().
  • Declaration: function greet() {} — пеш аз эълон низ даъват кардан мумкин аст (hoisting).
  • Expression: const greet = function () {}; — функсия ҳамчун қимат дар тағйирёбанда, танҳо пас аз эълон дастрас аст.
  • Тирдор: const double = n => n * 2; — бе { } натиҷа худкор бармегардад; бо { } return лозим аст.
  • Параметрҳо — номҳо ҳангоми эълон, аргументҳо — қиматҳо ҳангоми даъват. Бо тартиб дода мешаванд. Дода нашаванд — undefined.
  • Пешфарз: function f(x = 10) — танҳо барои undefined кор мекунад.
  • return натиҷаро медиҳад ва функсияро фавран анҷом медиҳад. Бе он функсия undefined бармегардонад. Ҳисоб мекунем — бармегардонем, на мебарорем.
  • Доираи намоёнӣ: аз дарун ба берун намоён аст, аз берун ба дарун — не. let/const дар { }-и худ зиндагӣ мекунанд. var-ро истифода намебарем.
