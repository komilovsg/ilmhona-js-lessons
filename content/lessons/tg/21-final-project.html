Лоиҳаи ниҳоӣ: ҳимоя ва қадамҳои аввал дар касб

Имрӯз Шумо ҳамаи он чиро, ки дар ду моҳ омӯхтед, нишон медиҳед: лоиҳаи шахсии худро ҳимоя мекунед, курси пурраро такрор мекунед, резюме ва профили GitHub-ро тайёр мекунед ва шпаргалкаи шахсии промптҳоро бо худ мебаред. Ин поён нест, балки витрина аст: корфармо ё фармоишгар маҳз аз рӯи он қарор медиҳад, ки бо Шумо гуфтугӯ кардан меарзад ё не.

  • Талаботҳо ба лоиҳаи ниҳоӣ ва меъёрҳои баҳогузории 0–100-ро фаҳмидан
  • Мавзӯъҳои асосии ҳамаи модулҳоро такрор кардан ва худро дар 16 вазифаи худозмоии ниҳоӣ санҷидан
  • Ҳимояро дар 5 дақиқа гузаронидан: демо, шарҳи код, ҷавоб ба саволҳо
  • Ба ҳалли дигарон шарҳи судманд додан ва шарҳро ба ҳалли худ оромона қабул кардан
  • Профили GitHub, README ва резюмеи ҳалолонаро барои вазифаи junior frontend омода кардан
  • Шпаргалкаи шахсиро аз 10 промпти корӣ аз рӯи формулаи курс ҷамъ кардан
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Ин дарси ниҳоӣ аст, бинобар ин дар он матни зиёд барои хондан ва омодагӣ ҳаст: талаботҳо, меъёрҳо, нақшаи ҳимоя, блоки касбӣ. Аммо амалиёт ҳам ҳаст. Бахши 04 худозмоии ниҳоӣ аз 16 вазифа аз рӯи тамоми курс аст (функсияҳо, массивҳо, объектҳо, DOM, ҳодисаҳо, шаклҳо, async). Дар бахшҳои дигар ҳам вазифаҳои хурд ҳастанд ва ҳар кадоме мисли дарсҳои гузашта худкор тафтиш мешавад. Вазифаҳои DOM дар қуттии регӣ бо пешнамоиш ҳал карда мешаванд. Худи лоиҳаро Шумо дар VS Code-и худ месозед, ва инҷо муқоиса мекунед ва машқ менамоед.

01 Лоиҳаи ниҳоӣ: чиро бояд супорид

Дар мини-лоиҳаҳо ғояро ба Шумо медоданд. Дар лоиҳаи ниҳоӣ ғоя аз они Шумост: Шумо худатон қарор медиҳед, ки барнома кадом вазифаро ҳал мекунад, аммо ҳатман онро пеш аз оғози кор бо омӯзгор мувофиқа мекунед. Ин муҳофизат аз ду ифрот аст: ғояи хеле оддӣ («тугма рангро иваз мекунад») ва хеле азим («Instagram-и худам»). Лоиҳае лозим аст, ки Шумо воқеан онро то охир расонида ва шарҳ дода тавонед.

Мувофиқ аст

  • Ҳисобкунаки хароҷоти оила бо сомонӣ бо категорияҳо ва нигоҳдорӣ
  • Ҷадвали машғулот бо филтр аз рӯи рӯзҳо ва «дарси наздиктарин»

  • Луғати «русӣ — тоҷикӣ» бо кортҳо барои такрор
  • Викторина аз JavaScript бо ҳисоби натиҷа ва рекорд

Мувофиқ нест

  • Як экран бе мантиқ («лендинги зебо»)
  • Нусхаи мини-лоиҳаи 1 ё 2 бо номи дигар
  • Ғояе, ки сервер, базаи маълумот ва вуруд бо парол талаб мекунад (ин маводи курси «React Pro + Next.js» аст)
  • Лоиҳа аз туториали бегона бе тағйироти худӣ
  • Чизе хеле бузург: «шабакаи иҷтимоӣ», «бонки онлайн», «бозӣ мисли GTA»
Қоидаҳои курс инҷо ҳам амал мекунанд

ЗС иҷозат аст, аммо бо қоида: аввал 15 дақиқа худатон, ягон коде, ки онро сатр ба сатр шарҳ дода наметавонед, нест, ва дар ҳимоя омӯзгор ҳақ дорад дар бораи ҳар як сатр бипурсад. Шарҳ дода натавонистед, холҳо барои ин қисм кам карда мешаванд. «Тамоми лоиҳаро барои ман бинавис» — роҳи кафолатноки гирифтани 0 дар ҳимоя аст.

03 Такрори курс: панҷ модул дар як саҳифа

Пеш аз ҳимоя муфид аст тамоми роҳро бо як нигоҳ аз назар гузаронед. Дар поён — барои ҳар модул як блоки фишурда: Шумо чӣ карда метавонед ва чиро ба ёд овардан лозим аст. Агар ягон банд нигаронкунанда бошад — дарсро аз рӯи истинод кушоед ва аз нав хонед. Баъд худро дар бахши 04 санҷед.

Монанд аз ҳаёт

Пеш аз имтиҳони рондан инструктор аз нав намеомӯзонад, балки иҷозат медиҳад маршрутро тай кунед: таваққуфгоҳ, гардиш, бозгашт. Такрори курс ҳамон маршрут аст: аз ҳамаи «истгоҳҳо» гузаред ва қайд кунед, ки дар куҷо боэътимод меравед ва дар куҷо суръатро паст мекунед.

Модули 1 · Пойдевори JS (дарсҳои 1–6)

  • Дарси 1. Оғоз: JS дар браузер чӣ тавр зиндагӣ мекунад, script, консол, DevTools.
  • Дарси 2. Тағйирёбандаҳо: let / const, намудҳо, typeof, табдили намудҳо ("5" + 3 ва "5" - 3).
  • Дарси 3. Шартҳо: if / else, ===, &&, ||, ??, truthy ва falsy.
  • Дарси 4. Давраҳо: for, while, for...of, break / continue.
  • Дарси 5. Функсияҳо: параметрҳо ва return, функсияҳои тирчадор, соҳаи эътибор, closure-ҳо.
  • Дарси 6. Массивҳо: map, filter, reduce, find, sort, spread.

Модули 2 · DOM ва интерфейс (дарсҳои 7–12)

  • Дарси 7. Объектҳо: хосиятҳо, деструктуризатсия, Object.entries, нусхабардорӣ тавассути spread, JSON.
  • Дарси 8. DOM: querySelector, createElement, textContent, classList.
  • Дарси 9. Ҳодисаҳо: addEventListener, event.target, делегатсия тавассути closest.
  • Дарси 10. Шаклҳо: submit ва preventDefault, санҷиш (валидатсия), хабарҳои хато.
  • Дарси 11. Ҳолат: як объекти state, функсияи render, localStorage + JSON.
  • Дарси 12. Мини-лоиҳаи 1: таҷзияи вазифа, MVP, баррасӣ ва ҳимояи аввал.

Модули 3 · Async ва API (дарсҳои 13–18)

  • Дарси 13. Ғайримутобиқӣ: event loop, setTimeout, колбэкҳо, Promise.
  • Дарси 14. fetch: дархост, response.ok, json(), async / await, try / catch.
  • Дарси 15. Кор бо API: ҳуҷҷатгузорӣ, параметрҳои дархост, печонандаҳои худӣ болои fetch.
  • Дарси 16. Ҳолатҳои боршавӣ: боршавӣ, хато, холӣ, муваффақият; Promise.all.
  • Дарси 17. Модулҳо ва Vite: import / export, npm, сохтори лоиҳа.

Тартиби иҷро: event loop-ро пешбинӣ кунед

душвор

Дар массиви prediction тартиберо нависед, ки шаш нишона бо он иҷро мешаванд. Код худаш барномаро оғоз мекунад, тартиби воқеиро ҷамъ мекунад ва бо тартиби Шумо муқоиса менамояд. Аввал дар бораи ҷавоб фикр кунед, баъд оғоз намоед: коди синхронӣ аввал меояд, баъд микровазифаҳо (then, идома пас аз await), ва танҳо баъд таймерҳо.

const log = (s) => out.push(s);

  log("A");
  await null;
  log("B");

log("start");
setTimeout(() => log("timeout"), 0);

Promise.resolve().then(() => log("promise"));
log("end");

// пешгӯии Шумо — нишонаҳо бо тартиби иҷро
const prediction = [];

setTimeout(() => {
  console.log(out.join(" → "));
  console.log("Прогноз верный: " + (prediction.join(" → ") === out.join(" → ") ? "да" : "нет"));

Ишора 1

Ба таври синхронӣ иҷро мешаванд: start, баъд бадани f() то await-и аввал (яъне A), баъд end. Ҳама чизи дигар интизор аст.

Ишора 2

Ба навбати микровазифаҳо аввал идомаи f() (B), дуюм — then (promise) афтод. Дар охир, ҳамчун макровазифа, timeout меояд.

Сенарияи демо: аз пеш омода мекунем

Демо аксар вақт на аз сабаби код, балки аз сабаби омодагии нокифоя вайрон мешавад. Сенарияро дар коғаз нависед ва онро ҳадди аққал як маротиба бо овоз бо секундомер гузаронед.

  1. Ҷадвалҳои лозимиро аз пеш кушоед: сайти деплойшуда, репозиторий дар GitHub, муҳаррир бо файлҳо. Ҳарфро дар муҳаррир ва миқёси саҳифаро калон кунед (Ctrl +).
  2. Сенарияи асосӣ — се-чор амал, ки арзиши асосиро нишон медиҳанд: масалан «шаҳрро ворид кард → обу ҳаворо дид → ба интихобшудаҳо илова кард».
  3. Нишон диҳед, ки барнома намеафтад: воридоти холӣ, интернети ғайрифаъол (дар ҷадвали Network-и DevTools Offline-ро интихоб кардан мумкин аст) ё дархости нодуруст.
  4. Саҳифаро нав кунед (F5) ва нишон диҳед, ки маълумот барқарор шуд.
  5. Нақшаи эҳтиётӣ: аз пеш скриншот ё сабти кӯтоҳи экранро созед. Агар интернет дар аудитория шикаст бихӯрад, Шумо саргум намешавед.
  6. Бо ибораи пул хотима диҳед: «Акнун нишон медиҳам, ки ин дар код чӣ тавр сохта шудааст».

12 саволи маъмул ва дар бораи чӣ бояд ҷавоб дод

1. Чаро ту ин ғоярро интихоб кардӣ ва он барои кист?
Як истифодабарандаи воқеӣ (худатон, оила, ҳамгурӯҳон) ва як мушкилӣ. На «ба ҳама лозим аст», балки «ба ман лозим аст, зеро…».
2. Лоиҳа чӣ тавр сохта шудааст: кадом файлҳо ва барои чӣ масъуланд?
Нақшҳоро ном баред: маълумот ва дархостҳо, ҳолат, тасвир, коркардкунандаҳои ҳодисаҳо. Агар модулҳо бошанд — кадом файл чиро содир (export) мекунад.
3. state чист ва он дар лоиҳаи ту дар куҷост?
Як объект бо ҳамаи маълумоти барнома, саҳифа аз рӯи он кашида мешавад. Онро дар код нишон диҳед ва бигӯед, ки дар он чӣ ҳаст.
4. Аз клик ба тугма то тағйирот дар экран чӣ рӯй медиҳад?
Ҳодиса → коркардкунанда → тағйири ҳолат → render → нигоҳдорӣ. Занҷираро дар коди худ тарсим кунед.
5. Маълумот аз куҷо меояд ва хаторо чӣ тавр коркард мекунӣ?
fetch, санҷиши response.ok, try / catch ва чор ҳолати экранро нишон диҳед: боршавӣ, хато, холӣ, муваффақият.
6. async / await-ро дар мисоли худат шарҳ деҳ.
await Promise-ро интизор мешавад ва саҳифаро масдуд намекунад; функсияи дорои await ҳатман async бошад; хатоҳоро try / catch мегирад. Агар дархостҳои мувозӣ бошанд — Promise.all.
7. Дар localStorage чӣ ҳаст ва агар он ҷо ахлот бошад чӣ?
Сатри JSON бо калиди лоиҳа. Захира танҳо сатрҳоро мефаҳмад: ҳангоми сабт JSON.stringify, ҳангоми хондан JSON.parse дар try / catch, ҳангоми хато аз ҳолати холӣ оғоз мекунем.
8. Бо Git чӣ тавр кор кардӣ: шохаҳо, коммитҳо, хаторо чӣ тавр бозпас мегардонӣ?
Таърихро нишон диҳед: паёмҳои пурмазмун, шоха барои функсияи нав. Бозгашт: git revert (бехатар) ё бозгашт ба коммит; бо шохаи умумӣ чиро кардан мумкин нест — таърихро аз нав навиштан.
9. Лоиҳа чӣ тавр ҷойгир шудааст ва агар барпоӣ (build) афтад чӣ мешавад?
Дар куҷо деплой шудааст (Vercel ё GitHub Pages), чӣ тавр нав мешавад (push ба шоха), логи барпоиро дар куҷо дидан лозим аст. Ҳалолона: «хаторо дар лог аз боло мехонам, сатри аввали сурхро меҷӯям».
10. Кадом хато аз ҳама мушкилтар буд ва онро чӣ тавр пайдо кардӣ?
Мушаххасот: чиро интизор будед, чиро гирифтед, кадом фарзияҳоро санҷидед, DevTools ва console.log чӣ кӯмак карданд. Таърихи ҷустуҷӯ аз «ман хато надоштам» бештар қадр мешавад.
11. Ту ЗС-ро дар куҷо истифода бурдӣ? Ин сатрро шарҳ деҳ.
Ҳақиқатро бигӯед: чӣ пурсидед (нақша, шарҳи хато, санҷиш), чиро худатон тағйир додед. Ҳар як сатри нишондодашударо бо суханони худ шарҳ додан лозим аст. Наметавонед — ҳалолона бигӯед ва бо овоз таҳлил кунед.
12. Агар як ҳафтаи дигар медоштӣ, чиро беҳтар мекардӣ?
Як-ду банди мушаххас: тестҳо, таҳрир, мутобиқшавӣ ба экранҳо, гузариш ба React. Ин нишон медиҳад, ки Шумо ҳудуди лоиҳаи худро мебинед.
Чӣ ҳимояро вайрон мекунад

Код хондан бо овоз сатр ба сатр, баҳона овардан («натавонистам»), ва ҷавоб ихтироъ кардан ҳангоме ки намедонед. Беҳтар: «ин нест, зеро… инак ман онро чӣ тавр илова мекардам» ва «ба ёд надорам, аммо дар ҳуҷҷатҳо меёбам ва нишон медиҳам». Омӯзгор фаҳмишро баҳо медиҳад, на комилиро.

Ҳалли дигаронро чӣ тавр муҳокима кардан лозим аст

Ҳангоми ҳимояҳо дигарон истироҳат намекунанд: гӯш диҳед, бинед ва қайд кунед. Пас аз ҳар баромад як дақиқа барои вокуниши гурӯҳ ҳаст. Қоидаҳо оддӣ: дар бораи лоиҳа гап мезанем, на дар бораи шахс, ва ҳар як эзоҳ чор қисм дорад.

Вокуниши судманд

  • «Ба ман маъқул шуд, ки ҳангоми хатои шабака тугмаи „Такрор“ нишон дода мешавад»
  • «Дар функсияи render шартҳо зиёданд; як қисмашро ба функсияи алоҳида баровардан мумкин аст, он гоҳ хондани он осонтар мешавад»
  • «Агар API массиви холӣ баргардонад, чӣ мешавад?»
  • «Агар маълумот даҳ маротиба зиёд мебуд, ту инро чӣ тавр дигар мекардӣ?»

Вокуниши бефоида

  • «Хуб» ва «даҳшат», бе тавзеҳ
  • «Аз они ман беҳтар аст» ё «ман ин тавр намекардам»
  • Муҳокимаи муаллиф («ту ҳамеша дер мекунӣ»)
  • Ишора, ки чӣ тавр «дуруст» аст, бе савол дар бораи сабабҳои қарор
  1. Чӣ шуд: ду-се афзалияти мушаххас.
  2. Хатарро дар куҷо мебинам: ҷойе, ки барнома метавонад вайрон шавад, ва Шумо инро чӣ тавр санҷидед.
  3. Савол: «чаро ин тавр?» ба ҷои «ин нодуруст аст».
  4. Пешниҳод: як беҳбудии мушаххас. Муаллиф худаш қарор медиҳад, ки онро қабул кунад ё не.

Шарҳро қабул карданро ҳам бояд омӯхт: фавран баҳс накунед, эзоҳро сабт кунед, ташаккур гӯед ва пас аз ҳимоя дар бораи он фикр кунед. Муаллиф ҳақ дорад розӣ нашавад, аммо бояд шарҳ диҳад, ки чаро.

Антипаттернҳо

  • Пурсидан: «ин ҳал чӣ камбудиҳо дорад?»

08 Амалиёт дар дарс: ҳимояҳо ва алоқаи баръакс

Вақти асосии машғулот — ҳимояи лоиҳаҳои ниҳоӣ. Агар гурӯҳ калон бошад, онҳо тамоми дарсро мегиранд: он гоҳ блоки касбӣ ва шпаргалкаи промптҳо дар хона анҷом дода мешаванд (ва ба ВХ дохил мешаванд).

  1. 0–5 дақ · Ташкил. Омӯзгор тартиби ҳимояҳоро эълон мекунад. Лоиҳаи худро бо истиноди оммавӣ кушоед ва боварӣ ҳосил кунед, ки он бор мешавад.
  2. 5–70 дақ · Ҳимояҳо. Барои ҳар лоиҳа 5 дақиқа ва як дақиқа барои иваз шудани баромадкунанда. Дигарон гӯш медиҳанд ва варақ пур мекунанд: ду афзалият, як хатар, як савол барои ҳар лоиҳа.
  3. 70–85 дақ · Таҳлил. Омӯзгор ёфтаҳои умумӣ ва хатоҳои пешоянда ном мебарад: чӣ барои бисёриҳо баромад, чӣ аксар вайрон мешавад. Ҳар кас алоқаи баръаксро оид ба лоиҳаи худ мегирад.
  4. 85–90 дақ · Хулосаҳо. Минбаъд чӣ: курси «React Pro + Next.js» ба хоҳиш, мӯҳлатҳои супоридани шпаргалка ва истинодҳо.
Агар навбати худро интизоред

Телефонро варақ назанед: ба саволҳои таҳлил, ки ба ҳамсояи Шумо дода мешаванд, ба худ ҷавоб диҳед ва ғояҳоро барои лоиҳаи худ қайд кунед. Беҳтарин роҳи омодагӣ ба ҳимоя — гӯш додан ба се ҳимояи бегона аст.

ЗС дар дарс

Ҳангоми ҳимояҳо ЗС истифода намешавад. Пас аз машғулот метавонед аз он бипурсед, ки қайдҳои алоқаи баръаксатонро аз нав бихонад ва нақшаи беҳбудиҳоро тартиб диҳад (аз рӯи қоидаҳои курс: ғояҳоро худатон қабул мекунед ё рад менамоед).
