Props, рӯйхатҳо ва keys, useState

Шумо аллакай компонентҳо эҷод карда, аз онҳо саҳифа ҷамъ карда метавонед. Аммо саҳифае, ки тағйир намеёбад, — танҳо тасвири зебост. Имрӯз мо ба компонентҳо меомӯзонем, ки маълумотро қабул кунанд (props), рӯйхатҳоро аз массив намоиш диҳанд, ҳолатро ба ёд доранд (useState) ва ба истифодабаранда вокуниш нишон диҳанд. Маҳз ба ин чор чиз интерфейси ҳар як сайти React истодааст — аз сабади мағозаи интернетӣ то чат.

  • Маълумотро ба компонент тавассути props додан, children, деструктуризатсия ва қиматҳои пешфарзро истифода бурдан
  • Рӯйхатро аз массив тавассути .map() намоиш додан ва шарҳ додан, ки key барои чӣ лозим аст ва чаро индекс дар нақши калид рӯйхатро вайрон мекунад
  • Маълумоти тағйирёбандаро дар useState нигоҳ доштан ва онро тавассути setter нав кардан, аз ҷумла бо усули функсионалӣ
  • Ҳолатро ҳеҷ гоҳ «дар ҷояш» тағйир надодан: унсурҳои массивҳо ва объектҳоро тавассути spread, filter ва map илова кардан, нест кардан ва нав кардан
  • Ҳодисаҳоро коркард кардан (onClick, onChange, onSubmit) ва майдонҳои воридоти идорашаванда сохтан
  • Қисмҳои интерфейсро нишон додан ва пинҳон кардан: &&, оператори сегона, return-и барвақт
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Блокҳои код бо ҷадвалҳои App.jsx ва style.css — ин мини-лоиҳаҳои React бевосита дар браузер ҳастанд: дар чап код, дар рост натиҷа, дар поён консол. Кодро тағйир диҳед ва ▶ Иҷро кардан-ро пахш кунед. Ба онҳо интернет лозим аст — React аз шабака бор мешавад. Дар вазифаҳо дар зери код сатри // ---- санҷиш (тағйир надиҳед) ---- ҳаст: ин «роботи озмоишгар»-и хурд аст, ки пас аз оғоз худаш тугмаҳоро пахш мекунад ва матн ворид менамояд, баъд натиҷаро ба консол менависад — вазифа аз рӯи он худкор санҷида мешавад. Дар лоиҳаи воқеӣ чунин блок лозим нест, ва ба он даст задан лозим нест. Ишораҳо дар зери қулф 🔒 пинҳонанд: аввал худатон кӯшиш кунед.

Ва боз як чизи муҳим. Дар лоиҳаи воқеии Vite React дар консоли браузер дар бораи хатоҳо шикоят мекунад, масалан «Each child in a list should have a unique key». Инҷо, дар қуттии регии таълимӣ, барпоии «ҷангӣ» (production)-и React кор мекунад, ва ин огоҳиҳо нестанд. Бинобар ин хатоҳои калидҳо ва ҳолатро мо аз рӯи натиҷа мегирем, на аз рӯи сатрҳои сурх. Ин ҳатто муфидтар аст: ин тавр Шумо меомӯзед, ки хаторо бо чашм бинед.

01 Props: маълумот ба компонент

Компонент — функсияест, ки порчаи интерфейсро бармегардонад (дар дарси гузашта Шумо онҳоро дар Vite эҷод кардед). Як функсияи ҳамон бояд кортҳои гуногунро кашида тавонад: дар бораи самбӯса, қурутоб, шакароб. Барои ин ба он маълумоти воридотӣ лозим аст. Дар React онҳо props номида мешаванд — аз калимаи «properties», хосиятҳо.

Монанд аз ҳаёт

Менюи чойхона. Чорчӯба, ҳарф ва ҷойгиршавии сатр — ин компонент аст: онҳо барои ҳамаи таомҳо якхелаанд. Ва «Самбӯса — 5 сомонӣ» ва «Қурутоб — 35 сомонӣ» — ин props аст: ҳар таом аз они худро дорад. Чопхона бояд барои ҳар таом бланки нав чоп накунад — танҳо он чизе, ки ба сатрҳо навишта шудааст, тағйир меёбад.

Props-ро мисли атрибутҳо дар HTML мегузаронанд. Дар дохили компонент онҳо бо як объект дар аргументи аввали функсия меоянд:

function DishCard(props) {
  return <div>{props.name} — {props.price} сомони</div>;
}

// props = { name: "Самбуса", price: 5 }
<DishCard name="Самбуса" price={5} />

Props
Объекти маълумот, ки волид ба фарзанд мегузаронад. Волид онҳоро мисли атрибутҳо менависад, фарзанд ҳамчун аргументи функсия мегирад.
Ҷараёни яктарафа
Маълумот танҳо аз боло ба поён меравад: аз волид ба фарзанд. Фарзанд props-и волидашро аз нав навишта наметавонад.
children
Props-и махсус: ҳар чизе, ки дар байни тегҳои кушодан ва пӯшидани компонент навишта шудааст.

Props-ро тағйир додан мумкин нест

Props барои компонент танҳо барои хондан дастрасанд. Компонент бояд мисли функсияи тоза рафтор кунад: маълумотро гирифт — аз рӯи он интерфейсро кашид, аммо худи маълумотро даст намезанад. Агар компонентро чизеро тағйир додан лозим бошад — ин аллакай на props, балки ҳолат аст (useState, бахши 04).

Хатои маъмул

Кӯшиши «ислоҳ кардан»-и props дар дохили компонент: props.price = props.price * 2. Дар реҷаи таҳия React фавран хато медиҳад, ва дар барпоии ҷангӣ тағйирот метавонад «хомӯшона» ҷойҳои дигарро вайрон кунад. Қиматро дар тағйирёбандаи нав ҳисоб кардан лозим аст: const total = price * 2;

children — мундариҷаи дарунгузошта

Компонентҳоро мисли тегҳои оддии HTML дар якдигар гузоштан мумкин аст. Ҳар чизе, ки Шумо байни <Panel> ва </Panel> навиштаед, ба компонент дар prop-и children меояд. Шумо худатон қарор медиҳед, ки онро дар куҷо нишон диҳед.

// children — ҳар чизе, ки БАЙНИ тегҳои кушодан ва пӯшидан навишта шудааст

      <h3 style={{ margin: "0 0 6px" }}>{title}</h3>
      {children}
    </section>

Қутти тӯҳфа. Худи қутти (чорчӯба, бант, навишта) — ин компоненти Panel аст. Дар дохил чӣ ҳаст — children. Як қуттиро барои қанд, барои китоб, барои рӯймол истифода бурдан мумкин аст. Ба қутти муҳим нест, ки дар дохил чӣ ҳаст, — вазифаи он зебо печондани он аст.

02 Деструктуризатсия, қиматҳои пешфарз ва rest

Навиштани props.name, props.price, props.city дар ҳар сатр хастакунанда аст. Шумо аз дарси объектҳо медонед, ки чӣ тавр он кӯтоҳ мешавад: деструктуризатсия. Дар React онро қариб ҳама ҷо истифода мебаранд — бевосита дар қавсҳои параметрҳои функсия.

// чунин буд
function StudentCard(props) {
  return <p>{props.name}, {props.age} лет</p>;
}

// чунин шуд
function StudentCard({ name, age }) {
  return <p>{name}, {age} лет</p>;
}

Қиматҳои пешфарз

Агар волид prop-ро надода бошад, дар дохил undefined мешавад. Барои ҷойгир кардани қимати эҳтиётӣ аломати =-ро дар деструктуризатсия истифода баред — мисли дар параметрҳои функсияи оддӣ (дарси 5).

// Қиматҳои пешфарз — бевосита дар деструктуризатсияи props

Дом

Қимати пешфарз танҳо барои undefined кор мекунад. Агар null, 0 ё сатри холии "" дода шуда бошад, маҳз ҳамин қимат истифода мешавад. Барои null дар JavaScript оператори ?? ҳаст — Шумо бо он аз дарси шартҳо шиносед. Инро дар вазифаи 2.3 таҳлил мекунем.

Rest ва spread: «props-и боқимондаро тақсим кардан»

Мешавад, ки компонент худаш як-ду prop-ро истифода мебарад, ва ҳамаи дигарҳоро бояд ба тегҳои дарунгузошта диҳад — масалан, ба <input>. Инҷо се нуқтаи шинос кор мекунад:

  • { label, ...rest } дар параметрҳо — ҳамаи props-и боқимондаро дар объекти rest ҷамъ мекунад;
  • <input {...rest} /> дар JSX — ин объектро ҳамчун маҷмӯи атрибутҳо тақсим мекунад.
// ...rest «ҳамаи дигар» props-ро ҷамъ мекунад, ва {...rest} онҳоро минбаъд тақсим мекунад
function Field({ label, ...rest }) {
  return (
    <label style={{ display: "block", margin: "6px 0" }}>
      {label}: <input {...rest} />
    </label>
  );
}

export default function App() {
  return (
    <div>
      <Field label="Имя" placeholder="Мадина" />
      <Field label="Пароль" type="password" placeholder="не менее 8 знаков" />
      <Field label="Возраст" type="number" min="14" max="99" />
    </div>
  );
}

Монанд аз ҳаёт

Маршруткаи Душанбе. Ронанда пули роҳкиро мегирад (ин label аст — он чи ба ӯ лозим аст), ва хоҳиши Шумо «дар назди Бозори Сабз нигоҳ доред» ва борхалтаро (ин rest аст) ба худ намегирад, балки танҳо минбаъд мегузаронад. Компонент ҳам чунин аст: он чиро, ки ба ӯ лозим аст, мегирад, ва боқиро бе таҳқиқот минбаъд мефиристад.

Маслиҳат

{...rest}-ро бошуурона истифода баред. Агар «ҳамаро аз пай ҳам» тақсим кунед, ба таг метавонад prop-е афтад, ки онро намефаҳмад, ва ин ислоҳи хатоҳоро душвор мекунад. Барои компонентҳои оддӣ беҳтар аст props-и лозимиро ошкоро номбар кардан.

03 Рӯйхатҳо: .map() ва key

Маълумот дар сайт қариб ҳамеша бо рӯйхат меояд: молҳо дар феҳрист, паёмҳо дар чат, донишҷӯён дар гурӯҳ. <li>-ро барои ҳар унсур бо даст навиштан мумкин нест — дарозии рӯйхат аз пеш номаълум аст. Дар React рӯйхатро чунин мекашанд: массивро мегиранд ва ҳар унсури онро бо методи .map() ба порчаи JSX табдил медиҳанд. Бо map Шумо дар дарси массивҳо шинос шудед — он массиви нав бармегардонад, ва React массиви аз унсурҳои JSX-ро нишон дода метавонад.

// Рӯйхат аз массив: .map() ҳар унсурро ба <li> табдил медиҳад
const lessons = ["HTML и CSS", "JavaScript", "React Lite"];

export default function App() {
  return (
    <ul>
      {lessons.map((lesson) => (
        <li key={lesson}>{lesson}</li>
      ))}
    </ul>
  );
}

  1. Массиви маълумот. lessons — массиви оддии сатрҳо.
  2. map ҳар сатрро ба унсур табдил медиҳад. Барои "JavaScript" <li>JavaScript</li> ҳосил мешавад.
  3. Массиви аз се унсури JSX ҳосил шуд. React онҳоро яке аз паи дигаре ба саҳифа мебарорад.
  4. Ҳамаи ин дар қавсҳои фигурӣ навишта шудааст { ... } — дар дохили JSX ин «ворид кардани JavaScript» аст.

key барои чӣ лозим аст

Ба ҳар унсури рӯйхат prop-и махсуси key-ро додан лозим аст — «шиноснома»-и якто барои унсур. Аз рӯи калид React мефаҳмад, ки кадом унсур тағйир ёфт, илова шуд ё нопадид шуд, ва танҳо чизи лозимиро аз нав мекашад. Бе калидҳо он «унсури дуюмро нест карданд»-ро аз «мундариҷаи дуюм ва сеюмро тағйир доданд» фарқ карда наметавонад.

Монанд аз ҳаёт

Гардероб дар чойхона ё театр. Шумо курткаро месупоред ва рақам мегиред. Гардеробчӣ рӯи Шуморо ба ёд намегирад ва ба ранги куртка наменшигарад, балки аз рӯи рақам меҷӯяд. Агар рақамҳоро «аз рӯи тартиби навбат» (якум, дуюм, сеюм) диҳанд ва шахси якум равад, ҳамаи дигарон ногаҳон рақамҳои бегона мегиранд. Рақами хуб ба шахс тааллуқ дорад, на ба ҷой дар навбат. Калидҳо маҳз ҳамин тавр кор мекунанд.

Калид бояд чунин бошад:

  • дар байни ҳамсояҳо якто (дар як рӯйхат), аммо на ҳатман дар тамоми саҳифа;
  • устувор: барои як унсури ҳамон ҳангоми ҳар кашидани аз нав як калиди ҳамон;
  • аз маълумот гирифташуда: id аз база, артикули якто ё логин — на рақами тасодуфӣ.

Хатои маъмул

Ба ҷои функсияи тирчадор бо қавсҳои мудаввар (tag) => ( ... ) қавсҳои фигурии (tag) => { ... }-ро навиштан ва калимаи return-ро фаромӯш кардан. Функсия ҳалолона кор мекунад ва undefined-ро бармегардонад — ва ба ҷои рӯйхат дар саҳифа холигӣ мешавад. Ин ҳамон қоидаи дарси функсияҳост: дар функсияи тирчадор бо { } натиҷаро ошкоро баргардондан лозим аст. Маҳз ба чунин дом Шумо дар вазифаи 3.4 меафтед.

04 useState: компонент, ки ба ёд дорад

Props аз берун меоянд ва тағйир намеёбанд. Аммо дар саҳифа маълумоте ҳаст, ки аз амалҳои истифодабаранда тағйир меёбад: чанд маротиба «лайк» пахш карданд, дар майдон чӣ навишта шудааст, меню кушода аст ё не. Ин маълумот ҳолат (state) номида мешавад. Барои он дар React ҳук (hook)-и useState ҳаст.

Нави функсионалӣ

Вақте ки қимати нав аз қимати кӯҳна вобаста аст («1 илова кун»), ба сеттер функсия додан бехатар аст: setCount((c) => c + 1). React худаш ба c қимати аз ҳама тозаро мегузорад. Ин барои чӣ муҳим аст? Дар дохили як коркардкунанда тағйирёбандаи count — ин «акс»-и қимат дар лаҳзаи кашидани аз нав аст. Се даъвати пай дар пайи setCount(count + 1) ба се маротиба «0 + 1 гузоштан» табдил меёбанд — ва ҳисобкунак танҳо ба 1 меафзояд.

// count ҳоло 0

setCount(count + 1);  // 0 + 1 гузоштан  (count дар ин «акс» ҳанӯз 0 аст)
setCount(count + 1);  // 0 + 1 гузоштан  → натиҷа: 1

// навишти функсионалӣ
setCount((c) => c + 1);  // 0 → 1
setCount((c) => c + 1);  // 1 → 2
setCount((c) => c + 1);  // 2 → 3  → натиҷа: 3
Хатои маъмул

Интизор шудан, ки фавран пас аз setCount(5) тағйирёбандаи count ба 5 баробар мешавад. Он танҳо ҳангоми кашидани аз нави минбаъда тағйир меёбад. Агар «ҳамин ҳозир» бо қимати нав кор кардан лозим бошад, онро дар тағйирёбандаи алоҳида гузоред: const next = count + 1; setCount(next); console.log(next);

Ҳукҳоро танҳо дар сатҳи болои компонент даъват мекунанд — на дар дохили if, давраҳо ва функсияҳои дарунгузошта — ва танҳо дар компонентҳо (функсияҳо бо ном аз ҳарфи калон). Ин тавр React тартиби қиматҳои нигоҳдоштаро гум намекунад.

09 Блоки ЗС: ЗС хатоҳои React-ро шарҳ медиҳад — ва мо месанҷем

Ду хатои React-ро навомӯзон аз ҳама бештар мебинанд: «ман пахш мекунам, аммо экран тағйир намеёбад» ва «рӯйхат пас аз нест кардан ғайримуқаррарӣ рафтор мекунад». ЗС онҳоро зуд ва боэътимод шарҳ медиҳад. Аммо боэътимод — маънои дуруст нест. Вазифаи Шумо имрӯз — шарҳи ЗС-ро гирифтан ва онро дар коди худатон санҷидан: оғоз кардан, вайрон кардан, ислоҳ кардан ва боварӣ ҳосил намудан, ки сабаб дуруст номбар шудааст.

Қоидаҳои курс, ки дар ин ҷо махсусан муҳиманд

1. Аввал 15 дақиқа худатон кӯшиш мекунед: бахшҳои 04–06-и ин дарсро ба ёд оред. 2. Танҳо баъд ба ЗС мераведед. 3. Кодеро, ки сатр ба сатр шарҳ дода наметавонед, ба лоиҳа нагузоред — барои React ин маънои онро дорад: Шумо медонед, ки чаро ин ҷо массиви нав аст, на push, ва аз куҷо ҳар як key гирифта мешавад. 4. Ҷавоби ЗС-ро бо оғоз санҷед: шарҳе, ки онро дар код санҷидан мумкин нест, арзише надорад.

Чӣ тавр хостан: бад ва хуб

Формулаи промпти курс: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш. Ду промпти тайёр аз китобхонаи курс — барои «ҳолат нав намешавад» ва «key барои чӣ лозим» — аллакай аз рӯи он сохта шудаанд.

дар реакт тугмаи ман кор намекунад, ислоҳ кун
Ман React-ро дар сатҳи навомӯз меомӯзам: props, useState ва .map()-ро медонам. Инак компоненти ман: [код гузоред]. Ҳангоми пахши «Добавить» унсури нав дар экран пайдо намешавад, гарчанде ки дар консол он дар массив ҳаст. Шарҳ деҳ, чаро useState кор накард ва чӣ тавр ислоҳ кардан лозим. Маҳдудиятҳо: бе китобхонаҳои тарафи сеюм, бе useEffect, то ҳадди имкон камтар сатрро тағйир деҳ. Формати ҷавоб: 1) сабаб дар ду ҷумла бо калимаҳои оддӣ; 2) коди ислоҳшуда пурра; 3) чӣ маҳз тағйир ёфт. Санҷиш: дар охир бигӯ, ки оё ман ҳолатро бевосита мутатсия намекунам.
барои чӣ дар реакт key
Дар мисоли ман шарҳ деҳ, ки React барои чӣ key дар .map() лозим дорад ва бе он чӣ вайрон мешавад: [коди рӯйхатро гузоред]. Ман навомӯзам. Формат: шарҳи кӯтоҳ бо монанд, баъд нишон деҳ, ки агар index-ро ҳамчун key истифода баранд, рӯйхат чӣ тавр вайрон мешавад ва чӣ тавр ислоҳ кардан лозим. Санҷиш: пешниҳод кун, ки ман худам чӣ тавр дар хато ҳангоми нест кардани унсур аз миёнаи рӯйхат боварӣ ҳосил кунам (кадом майдонҳои воридот ва кадом амалҳо лозиманд).
Чек-лист: шарҳи ЗС-ро чӣ тавр санҷидан лозим

1) Ҳолат нав намешавад: оё ЗС мутатсияро ёфт (push, obj.x = …, sort бе нусха)? Агар вай «танҳо useEffect илова кун» ё «маҷбурӣ аз нав каш» пешниҳод кунад — ин қариб ҳамеша зиёдатӣ аст. 2) Калидҳо: кадом key-ро интихоб кард? Агар index «барои хориҷ кардани огоҳӣ» бошад — ин ҳамон хато-и бахши 06 аст. Калид бояд аз маълумот ояд. 3) Санҷиш бо оғоз: хаторо ҳангоми нест кардан аз миёна — бо майдони воридот дар ҳар сатр — пеш ва пас аз ислоҳ такрор кунед. 4) Оё Шумо бо суханони худ шарҳ дода метавонед, ки чаро ислоҳ кор мекунад?

Ёрирасони хуби ЗС шарҳ медиҳад, на танҳо ислоҳ мекунад. Агар дар ҷавоб ҳатто як калимаро нафаҳмида бошед, бипурсед: «соддатар шарҳ деҳ, дар мисоли чойхона». Ва аз баҳс ҳаросон нашавед: агар ЗС key={index} пешниҳод кард, ба ӯ бо мисоли бахши 06 эътироз кунед ва бинед, ки ӯ чӣ тавр мебарояд.

const courses = [

// onToggle — ин prop-ФУНКСИЯ аст: корт онро даъват мекунад, вақте ки ба дил пахш карданд
function CourseCard({ title, liked, onToggle }) {
  return (
    <div className="card">
      <b>{title}</b>{" "}
      <button onClick={onToggle}>{liked ? "♥ Нравится" : "♡ Лайк"}</button>
    </div>
  );
}

export default function App() {
  const [likedIds, setLikedIds] = useState([]);

  function toggle(id) {
    setLikedIds(likedIds.includes(id) ? likedIds.filter((x) => x !== id) : [...likedIds, id]);
  }

  return (
    <div>
      <h3>Понравилось: {likedIds.length} из {courses.length}</h3>
      {courses.map((course) => (
        <CourseCard
          key={course.id}
          title={course.title}
          liked={likedIds.includes(course.id)}
          onToggle={() => toggle(course.id)}
        />
      ))}
    </div>
  );
}

✓ Шпаргалкаи дарс

  • Props: маълумот аз волид ба фарзанд ҳамчун атрибутҳо меравад, бо объект меояд: function Card({ name, price }). Props танҳо барои хондан. Сатрҳо — дар зеркалимаҳо, боқӣ — дар { }.
  • children: ҳар чизе, ки байни тегҳои компонент аст. {children}-ро дар ҷое, ки лозим аст, нишон медиҳем: чорчӯбаҳо, панелҳо, печонандаҳо.
  • Пешфарз ва rest: { label = "Нажми" } танҳо барои undefined кор мекунад; барои null — ??. { a, ...rest } боқиро ҷамъ мекунад, <input {...rest} /> тақсим мекунад.
  • Рӯйхатҳо: items.map((x) => <Item key={x.id} … />). Бо { } пас аз тир return лозим аст. Филтр — filter пеш аз map.
  • key: якто ва устувор, аз маълумот (id). На index барои рӯйхатҳои тағйирёбанда (майдонҳои воридот ва ҳолати сатрҳо вайрон мешаванд) ва на Math.random().
  • useState: const [x, setX] = useState(аввалия). Қимати аввалия — танҳо ҳангоми намоиши аввал. Тағйирёбандаи оддӣ экранро нав намекунад. Ҳукҳо — танҳо дар сатҳи болои компонент.
  • Нави функсионалӣ: setX((x) => x + 1), вақте ки қимати нав аз кӯҳна вобаста аст. Ҳисобшавандаро дар ҳолат нигоҳ намедорем.
  • Мутатсия намекунем: илова кардан [...arr, x], нест кардан arr.filter(...), тағйир додан arr.map(...), объект { ...obj, k: v }. Мумкин нест: push, splice, obj.k = v, sort бе нусха.
  • Ҳодисаҳо: onClick={fn} — функсияро медиҳем, даъват намекунем: onClick={() => remove(id)}. Шакл: onSubmit + event.preventDefault().
  • Майдони идорашаванда: value={text} + onChange={(e) => setText(e.target.value)}; дар чекбокс — checked ва e.target.checked.
  • Рендери шартӣ: cond && <A /> («ё чизе не»), cond ? <A /> : <B /> («яке ё дигаре»), return-и барвақт барои ҳолатҳои махсус. 0 && … 0-ро мекашад — муқоиса кунед: n > 0 && ….
  • Боло бурдани ҳолат: ҳолати умумӣ дар наздиктарин волиди умумӣ зиндагӣ мекунад, ва ба фарзандон қимат ва функсияи коркардкунанда тавассути props медиҳем.
  • Бо ЗС: аввал худатон, баъд промпт аз рӯи формула. Шарҳи ЗС-ро бо оғоз месанҷем: оё мутатсия нест ва key аз куҷо гирифта шудааст.
