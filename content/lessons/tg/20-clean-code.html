Коди тоза, рефакторинг ва деплой

Кодро як бор менависанд, ва даҳҳо бор мехонанд. Пас аз як моҳ шумо худатон намефаҳмед, ки дар x2 чиро дар назар доштед, ва корфармо дар мусоҳиба репозиторийи шуморо дар 30 сония мекушояд. Имрӯз ёд мегирем, ки кодро ба тартиб оварем, то он вайрон нашавад, ва баъд лоиҳаҳоро ба интернет мегузорем — то тавассути истинод ҳар кас, аз модар то рекрутер, онҳоро кушода тавонад.

  • Ба тағйирёбандаҳо ва функсияҳо номҳое додан, ки шарҳ додани онҳо лозим нест
  • Функсияҳои калонро тақсим кардан, ҷойгиршавии дарунро бо return-и барвақтӣ бартараф намудан, такрор накардан (DRY)
  • «Рақамҳои ҷодуӣ»-ро ба собитҳо баровардан ва ҳисобҳоро аз намоиш ҷудо кардан
  • Кодро аз рӯи чек-лист санҷидан ва рефакторинг кардан, то рафтор тағйир наёбад
  • Лоиҳаро бо фармони npm run build ҷамъ кардан ва тағйирёбандаҳои муҳитро бе ошкор шудани сирҳо танзим намудан
  • Лоиҳаро дар Vercel ва GitHub Pages деплой кардан, ва маслиҳатҳои ревьюи ЗС-ро ба фоиданок ва зарарнок ҷудо намудан
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди бо тугмаи ▶ Иҷро кардан — зинда аст: онро тағйир диҳед ва натиҷаро дар консол бинед. Блокҳо бо имзои «Терминал» ва файлҳои танзимотиро иҷро кардан мумкин нест — онҳоро дар компютери худ такрор мекунед. Дар вазифаҳои рефакторинг рафтори код тағйир додан мумкин нест: санҷиш баромадро муқоиса мекунад, барои ҳамин дар ҳар чунин вазифа дар поён аллакай сатрҳои-тест ҳастанд. Ба онҳо даст назанед — онҳо суғуртаи шумоянд. Ишораҳо пинҳонанд: аввал худатон.

02 Функсияҳои хурд ва бозгашти барвақтӣ

Қоидаи рақами як барои функсияҳо: як функсия — як вазифа. Агар шумо онро бо калимаи «ва» тавсиф кунед («маблағро ҳисоб мекунад ва тахфиф татбиқ мекунад ва чек чоп мекунад»), ин се функсия аст. Функсияи кӯтоҳро хондан, ном додан, санҷидан ва дар ҷои дигар истифода бурдан осонтар аст.

  • Андоза. Нишондиҳанда — дар як экран ҷо мешавад, 10–20 сатр. На қонун, балки сигнал: агар варақ мезанед — вақти тақсим кардан расидааст.
  • Параметрҳо. Ду–се — муқаррарӣ. Панҷ ва зиёд — сабаби андеша, ки оё объект додан лозим нест.
  • Як сатҳи тафсилот. Функсияи боло нақл мекунад «чӣ рӯй дода истодааст» (validate → calc → render), ва тафсилот дар функсияҳои хурд пинҳонанд.
function processOrder(prices) {
  let sum = 0;
  for (const price of prices) {
    sum += price;
  }
  const discount = sum >= 100 ? sum / 10 : 0;
  console.log("К оплате: " + (sum - discount));
}

processOrder([40, 70, 20]);

Бозгашти барвақтӣ (guard clauses)

Вақте санҷишҳо ба дохили якдигар ҷойгир мешаванд, «тир»-и қавсҳо ҳосил мешавад: мантиқи асосӣ ба тарафи рост се сатҳ рафт, ва дар сар ҳамаи шартҳоро якбора нигоҳ доштан лозим меояд. Дору — бозгашти барвақтӣ: аввал ҳолатҳои бадро мебуранд ва фавран аз функсия мебароянд, ва мантиқи асосӣ дар як сатҳ мемонад.

Тир аз if-ҳои дарунҷойгир

    if (hasCard) {
      if (age < 7) {
        return 0;
      } else {
        return 3;
      }
    } else {
      return 5;
    }
  } else {
    return -1;
  }
}

function getFare(age, hasCard) {
  if (age < 0) return -1;
  if (!hasCard) return 5;

  return 3;

Монандӣ аз ҳаёт

Назоратчӣ дар даромадгоҳи метро чиптаро фавран дар турникет месанҷад ва бе он намегузорад. Тасаввур кунед, ки шуморо дохил карданд, то истгоҳи охир бурданд — ва танҳо дар он ҷо гуфтанд, ки чипта набуд. Бозгашти барвақтӣ — ин турникет дар аввали функсия аст.

DRY — Don't Repeat Yourself, «такрор накун». Порчаи кодро се бор нусха кардед — яъне ҳангоми ҳар ислоҳ бояд ҳар се нусхаро ёфта, ислоҳ кард. Агар функсияи «умумӣ» бо параметрҳо-парчамҳо (isStudent, isSenior, isSpecial…) пур шавад, шумо чизеро муттаҳид кардед, ки муттаҳид кардан намебоист.

Рақамҳои ҷодуӣ

Рақами ҷодуӣ — рақам (ё сатр) дар код, ки маънояш бе шарҳ нофаҳмо аст. * 11 чӣ маъно дорад? >= 300 чӣ? Пас аз як моҳ худатон ба ёд намеоред. Дору — собити номдор: қиматро ба боло аз файл баровардан ва ба он ном додан.

Дар ҳар барнома ду кори гуногун ҳаст: ҳисоб кардан (мантиқ: маҳсулотро филтр кардан, холи миёнаро ҳисоб кардан) ва нишон додан (намоиш: HTML ҷамъ кардан, ба консол баровардан). Монандӣ аз ҳаёт

05 Рефакторинг: шаклро тағйир медиҳем, на рафторро

Рефакторинг — ин беҳтар кардани сохти код бе тағйири он чизе, ки кор мекунад. Барои корбар чизе тағйир наёфт: ҳамон тугмаҳо, ҳамон рақамҳо.   1. Рафторро собит кунед. Пеш аз тағйир додани чизе, кодро иҷро кунед ва сабт кунед, ки барои якчанд вуруд чӣ чоп мекунад — аз ҷумла сарҳадӣ (0, холӣ, дақиқан остона). Инҳо «тестҳои» шумо ҳастанд.
  2. Як қадами хурд: иваз кардем → иҷро кардем → баромад ҳамон. Собитро баровардем → иҷро кардем → ҳамон. Даҳ ислоҳи пай дар пай накунед.
  3. Тартиби қадамҳо аз оддӣ ба мураккаб: номҳо → собитҳо → хориҷ кардани партов ва коди мурда → бозгашти барвақтӣ → ҷудо кардани функсияҳо → бартараф кардани такрорҳо → ҷудо кардани мантиқ ва баромад.
  4. Вайрон шуд — бозгашт кунед ба ҳолати охирини корӣ. Дар Git ин як фармон аст; барои ҳамин пас аз ҳар қадами муваффақ commit мекунем (дарси 19), масалан rename vars in cart.js.
  5. Ду кулоҳ. Ё шумо рефакторинг мекунед, ё хатоиро ислоҳ мекунед/функсия илова мекунед. Якбора — мумкин нест. Дар роҳ хаторо ёфтед — сабт кунед ва ба он бо commit-и алоҳида баргардед.

06 Ҷамъбасти лоиҳа: npm run build

Дар дарси 17 шумо лоиҳаро дар Vite эҷод кардед ва npm run dev-ро иҷро кардед. Ин реҷаи таҳия аст: Vite файлҳоро «чунон ки ҳастанд» медиҳад, саҳифаро фавран навсозӣ мекунад ва ишораҳо барои таҳиягарро илова менамояд. Барои сайти ҳақиқӣ чунин реҷа мувофиқ нест — код фишурда нашудааст, зиёдатӣ аст, ва сервер танҳо дар ноутбуки шумо кор мекунад. Барои нашр ҷамъбаст (build) лозим аст.

Монандӣ аз ҳаёт

Реҷаи таҳия — ошхона ҳангоми пухтан аст: дегҳо, корддонҳо, пӯстҳо дар сари миз. Ҷамъбаст — хӯроки тайёр, ки зебо дар контейнер барои бо худ бурдан печонда шудааст. Ба муштарӣ контейнер лозим аст, на тамоми ошхона. Папкаи dist — ҳамон «контейнер»-и печондашудаи сайти шумост.

Ҷамъбаст чӣ кор мекунад

  1. Ҷамъ мекунад ҳамаи модулҳои шуморо (import/export) ба якчанд файл.
  2. Минификатсия мекунад: фосилаҳо, шарҳҳоро хориҷ мекунад, номҳои тағйирёбандаҳоро кӯтоҳ мекунад. Файл якчанд маротиба хурдтар мешавад — саҳифа тезтар бор мешавад.
  3. Истифоданашударо мепартояд (tree shaking): агар китобхонаро пайваст карда бошед, аммо як функсияро истифода баред, зиёдатӣ ба сайт намеафтад.
  4. Ба номи файлҳо хеш илова мекунад (index-Ab12Cd34.js): код тағйир ёфт — ном иваз шуд, ва браузер версияи тозаро зеркашӣ мекунад, на кӯҳнаро аз кэш мегирад.
  5. Натиҷаро ба папкаи dist/ мегузорад — маҳз онро ба хостинг медиҳанд.

1. «Дар dev кор мекунад, аммо дар build — не». Ҷамъбаст сахттар аст: он import-ҳои вайрон ва хатоҳои имлоиро дар роҳҳо намебахшад. Ҳамеша npm run build-ро пеш аз деплой иҷро кунед.

Фармонҳои npm дар ҳама ҷо яксонанд. Дар Windows онҳоро дар PowerShell, «Терминал»-и VS Code ё Git Bash иҷро кунед; дар macOS — дар «Терминал» ё дар терминали дарунсохти VS Code (Ctrl + `). Нишонии API дар компютери шумо яктост, дар версияи «ҷангии» сайт — дигар. Андозаи саҳифа, номи барнома, калид ба хидмати обуҳаво — ҳамаи инҳо танзимот ҳастанд, ки онҳоро ба код дӯхтан лозим нест. Онҳоро ба тағйирёбандаҳои муҳит мебароранд — файли алоҳида, ки ҳангоми оғоз ва ҷамъбаст хонда мешавад.

Монандӣ аз ҳаёт

Дорупази палав як аст, аммо шумораи порсияҳо аз ҳолат вобаста аст: барои оила — як килограмм биринҷ, барои тӯй — даҳто. Шумо дорупазро аз нав намеменависед, балки «танзим»-ро дар коғазчаи дар ошхона иваз мекунед. Тағйирёбандаҳои муҳит — чунин коғазчаанд: код як аст, ва қиматҳо барои ҳар муҳит (ноутбуки шумо, сайт дар интернет) худӣ.

Дар Vite чӣ тавр кор мекунад

  • Қиматҳо — ҳамеша сатрҳо. VITE_PAGE_SIZE=12 "12"-ро медиҳад, VITE_DEBUG=false бошад — сатри "false"-ро, ки дар шарт ростӣ ҳисоб мешавад! Худатон табдил диҳед: Number(...), value === "true".

08 Деплой: Vercel ва GitHub Pages

Деплой — нашри сайт дар интернет, то ҳар кас онро аз рӯи истинод кушояд. То лоиҳа дар ноутбуки шумост, ин машқ аст. Вақте ки он истинод дорад — ин портфолио аст. Мо ду усули ройгонро барои сайтҳои статикӣ таҳлил мекунем (ва лоиҳаҳои шумо дар Vite — маҳз чунинанд).

Монандӣ аз ҳаёт

Шумо самбӯсаро дар хона пухтед — лазиз аст, аммо танҳо наздикон мечашанд. Деплой — кушодани сандуқ дар бозор: ҳамон маҳсулот, аммо акнун он нишонӣ дорад, ва ҳама ба назди он омада метавонанд. Хостинг — ҷой дар бозор аст, ва истинод — рақами сандуқи шумо.

Пеш аз деплой: чек-листи кӯтоҳ

  • npm run build бе хато мегузарад, npm run preview сайти корӣ нишон медиҳад.
  • Лоиҳа дар репозиторий дар GitHub меистад (дарси 19), шохаи бо коди корӣ фиристода шудааст: git push.
  • Дар репозиторий .env.local ва сирҳо нестанд; .env.example ҳаст.
  • Ҳарфи калон ва хурди номҳои файлҳо ва import-ҳо мувофиқат мекунад.

Усули 1. Vercel

Vercel худаш Vite-ро меёбад, худаш лоиҳаро ҷамъ мекунад ва пас аз ҳар git push сайтро навсозӣ мекунад. Барои навомӯз — кӯтоҳтарин роҳ.

  1. vercel.com-ро кушоед ва бо тугмаи Continue with GitHub ворид шавед (тарифи Hobby барои лоиҳаҳои шахсӣ ройгон аст).
  2. Add New… → Project-ро пахш кунед. Vercel репозиторийҳои шуморо нишон медиҳад: даркориро ёбед ва Import-ро пахш кунед (бори аввал дастрасӣ ба репозиторийҳоро иҷозат диҳед).
  3. Дар экрани танзим санҷед: Framework Preset — Vite (худаш муайян мешавад), Build Command — npm run build, Output Directory — dist.
  4. Environment Variables-ро кушоед ва тағйирёбандаҳоро аз .env-и худ илова кунед (масалан, VITE_API_URL) — яктоӣ: ном ва қимат. Файли .env-ро Vercel аз репозиторий намехонад.
  5. Deploy-ро пахш кунед. Пас аз як дақиқа нишонии намуди номи-лоиҳа.vercel.app пайдо мешавад. Ин истиноди зиндаи шумост.

Қисми A. Ревьюи лоиҳаи ҳамсоя (дар ҷуфтҳо)

  1. Истиноди репозиторийҳоро мубодила кунед. Лоиҳаи ҳамсояро clone кунед: git clone истинод, баъд npm install ва npm run dev. Боварӣ ҳосил кунед, ки он оғоз мешавад.
  2. Чек-листи чопӣ-ро (қисми 11) кушоед. Аз рӯи 12 банд гузаред ва дар сутуни «То» нишон гузоред.
  3. 5–8 мулоҳиза-ро бо як формат сабт кунед: файл:сатр — банди № — чӣ нодуруст аст ва барои чӣ — чӣ тавр ислоҳ кардан. Мисол: src/cart.js:14 — банди 5 — рақами 300 бе ном, нофаҳмо аст, ки ин остонаи интиқол аст — ба FREE_DELIVERY_FROM баровардан.
  4. Мулоҳизаҳо бояд хушмуомила ва мушаххас бошанд: «функсияи calc нофаҳмо номгузорӣ шудааст» — бад; «дар calc t-ро ба total иваз кунед, то намоён шавад, ки ҷамъ мекунем» — хуб. Кодро интиқод мекунем, на одамро.
  5. Мулоҳизаҳоро бо овоз муҳокима кунед: муаллиф ҳақ дорад розӣ нашавад, агар фаҳмонад, ки барои чӣ.

Қисми B. Рефакторинг аз рӯи мулоҳизаҳо

  1. Муаллиф шоха эҷод мекунад: git switch -c refactor/clean-code.
  2. Аз рӯи мулоҳизаҳо яктоӣ мегузарад. Пас аз ҳар кадом: иҷро → ҳама мисли пештара кор мекунад → git commit -m "extract delivery constants" (паём — аз рӯи қоидаҳои дарси 19).
  3. Санҷиши рафтор: барномаро кушоед ва ҳамон сенарияҳоро, ки пеш аз таҳрирҳо, гузаред (ҷустуҷӯ, саҳифабандӣ, хатои шабака). Чизе тағйир ёфт — бозгашт: git restore ..
  4. Дар охир: npm run build бе хато. Баъд git push-и шоха.
  5. Чек-листро такроран гузаред, сутуни «Пас»-ро пур кунед. Ҳадаф — на камтар аз 10 аз 12.

Қисми C. Деплойи ҳамаи лоиҳаҳои гурӯҳ

  1. Лоиҳаи 1 → Vercel аз рӯи қадамҳои қисми 08. Вақти ҳадаф — 10 дақиқа. Нашуд? Логи ҷамъбастро хонед: хато қариб ҳамеша дар сатрҳои охирин нишон дода шудааст.
  2. Лоиҳаи 2 → GitHub Pages: base, workflow, Settings → Pages. Онҳое, ки зудтар тамом карданд, ба ҳамсояҳо навбатӣ кумак мекунанд — шарҳ додан, на ба ҷои дигаре пахш кардан.
  3. Санҷиши истинод: дар реҷаи инкогнито ва дар телефон кушоед, дар DevTools → Console хатои сурх набояд бошад, дар Network — ягон 404 нест.
  4. Ҳамаи истинодҳо ба ҷадвали умумии гурӯҳ ворид мешаванд (формат: ном, лоиҳа, истинод ба сайт, истинод ба репозиторий).

Қисми D. README бо ЗС

  1. Далелҳо-ро дар бораи лоиҳа омода кунед: чӣ кор мекунад, стек, фармонҳои оғоз, истинод ба демо.
  2. Аз ЗС хоҳиш кунед, ки README-ро аз рӯи промпти қисми 09 ҷамъ кунад.
  3. Аз рӯи рӯйхати «Чиро санҷидан» санҷед: андешаҳоро хат занед, фармонҳоро иҷро кунед, скриншот ва истинод илова кунед, ибораҳои қолабиро бознависед.
  4. README.md-ро ба реша commit кунед ва фиристед.
Тайёр аст, вақте ки

Лоиҳа дорад: чек-лист ≥ 10/12, истиноди зинда, README бо скриншот, .env.example ва дар таърих сирр нест. Натиҷаро ба ҳамсоя ва муаллим нишон диҳед.

12 Вазифаи хонагӣ

Вазифа: лоиҳаи хурди 2-ро рефакторинг кунед, ду лоиҳаро деплой кунед, README-ро ороиш диҳед ва истинодҳоро фиристед. Натиҷаи дарс — чек-листи пуршудаи сифати код ва истинодҳои зинда ба лоиҳаҳо.

  1. То-ро баҳо диҳед. Лоиҳаи хурди 2-ро аз рӯи чек-листи қисми 11 пеш аз ҳар таҳрир гузаред. Натиҷаро (X аз 12) ва рӯйхати вайронкуниҳоро сабт кунед.
  2. Рефакторинг кунед. Шохаи refactor/clean-code-ро эҷод кунед. На камтар аз панҷ commit-и бомаъно — ҳар кадом дар бораи як таҳрир («rename cart variables», «extract delivery constants», «split render from calc»). Рафтори барнома тағйир намеёбад.
  3. Пас-ро баҳо диҳед. Чек-листро такрор кунед. Ҳадаф — на камтар аз 10 аз 12. Шохаро бо усули оддӣ ба асосӣ ҷамъ кунед (тавассути PR, мисли дарси 19).
  4. Ду лоиҳаро деплой кунед. Лоиҳаи хурди 2 — дар Vercel; як лоиҳаи дигар (лоиҳаи хурди 1 ё ҳар кадом дигар) — дар GitHub Pages. Ҳарду истинод бояд бе хато дар консол кушода шаванд.
  5. Сирҳо ва муҳит. Дар ҳарду репозиторий .env.example ҳаст, калидҳои воқеӣ нестанд, тағйирёбандаҳо (агар бошанд) дар хостинг муайян шудаанд.
  6. README. Дар ҳар репозиторий: ин чист, стек, чӣ тавр оғоз кардан, скриншот, истинод ба демо, «минбаъд чӣ». Нусхаи пешакиро бо ЗС кардан мумкин аст, вале бо суханони худатон бознависед ва ҳамаи фармонҳоро санҷед.
  7. Матн барои портфолио. 3–4 ҷумла дар бораи лоиҳаи хурди 2: вазифа, худатон чӣ кардед, стек, истинод.

Чӣ супурдан лозим

  • Истинодҳо ба ду репозиторий ва ду истиноди зинда ба сайтҳо.
  • Чек-листи пуршуда (сутунҳои «То» ва «Пас») бо ҳисоб.
  • Дафтари рефакторинг: ҷадвал ҳадди аққал аз панҷ сатр — «банди чек-лист → чӣ тағйир додем → номи commit».
  • Матн барои портфолио (дар README ё дар файли алоҳида).

✓ Варақаи кӯмакии дарс

  • Номҳо: тағйирёбанда — исм, функсия — феъл, булӣ — is/has/can, собит — UPPER_SNAKE. Бе data, temp, x1.
  • Функсия як чизро мекунад. «Ва» дар тавсиф — сабаби тақсим кардан. Нишондиҳанда — як экран.
  • Бозгашти барвақтӣ: аввал ҳолатҳои бадро мебуранд if (...) return ...;, мантиқи асосӣ ҳамвор мемонад, else пас аз return лозим нест.
  • DRY: бори сеюм такрор шуд — ба функсия ё маълумот бароред. Он чиро, ки тасодуфан монанд аст, муттаҳид накунед.
  • Рақамҳои ҷодуӣ → собитҳои номдор дар боло аз файл, воҳидҳои ченак дар ном.
  • Мантиқ ≠ намоиш: ҳисоб додаҳоро бармегардонад, render нишон медиҳад, коркунанда мечаспонад.
  • Шарҳ ба «барои чӣ» ҷавоб медиҳад, на «чӣ». Коди шарҳшударо — хориҷ кардан (Git ба ёд дорад).
  • Рефакторинг шаклро тағйир медиҳад, на рафторро: тест → қадами хурд → иҷро → commit. Ё рефакторинг мекунем, ё хато ислоҳ мекунем — на якбора.
  • Ҷамъбаст: npm run build → dist/, санҷиш — npm run preview. dist-ро ба Git намегузорем. Ҳарфи калон ва хурди номҳои файлҳо бояд мувофиқат кунад.
  • Тағйирёбандаҳои муҳит: import.meta.env.VITE_*, қиматҳо — сатрҳо, пас аз таҳрири .env аз нав оғоз. .env.local — дар .gitignore, .env.example — ба репозиторий. Дар браузер сирр нест.
  • Vercel: Import-и репозиторий → preset Vite → тағйирёбандаҳо → Deploy; пас аз иваз кардани тағйирёбандаҳо — Redeploy. GitHub Pages: base: "/репозиторий/" + Settings → Pages → GitHub Actions + workflow.
  • Ревьюи ЗС: мулоҳизаҳоро аз рӯи чек-лист мепурсем, на «беҳтар кун». Маслиҳатро дар сурате қабул мекунем, ки онро мефаҳмем, рафтор ҳамон аст, мушкил воқеӣ аст, метод вуҷуд дорад ва код соддатар аст. README — танҳо аз рӯи далелҳо, бо суханони худатон бознависед.
