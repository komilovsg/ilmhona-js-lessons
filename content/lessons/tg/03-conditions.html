Шартҳо ва мантиқ

То ҳол барнома сатр ба сатр иҷро мешуд, мисли дастури пухтан бе вариантҳо. Аммо сайти воқеӣ доимо қарор қабул мекунад: корбарро ба дарун роҳ диҳад ё не, пул дар тавозун кифоя аст ё не, кадом тахфифро диҳад, кадом саҳифаро нишон диҳад. Имрӯз шумо ба барнома саволҳои «ҳа ё не» додан ва интихоб кардани корҳои минбаъдаро меомӯзед.

  • Қиматҳоро бо операторҳои >, <, >=, <= муқоиса кунед ва фарқи == ва ===-ро бифаҳмед
  • Муайян кунед, ки JavaScript кадом қиматҳоро «дурӯғ» (falsy) ва кадомро «рост» (truthy) мешуморад
  • Шартҳоро аз &&, ||, ! ҷамъ кунед ва бидонед, ки онҳо воқеан чиро бозпас мегардонанд
  • Шохаҳои if / else if / else, оператори сегона ва switch-ро нависед
  • GitHub Copilot-ро ҳамчун ёрдамчӣ истифода баред ва ба «мусофир»-и он табдил наёбед
  • Аввалин ҳисобкунаки консолии худро созед
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Тамоми код дар заминаи торик бо тугмаи ▶ Иҷро кардан — зинда аст. Онро бевосита дар ин ҷо тағйир додан ва натиҷаро дарҳол дар консоли поёни он дидан мумкин аст. Вайрон кардед — ↺ Аз нав-ро пахш кунед. Ишораҳои вазифаҳо пинҳон шудаанд: аввал худатон кӯшиш кунед, ишораро танҳо вақте кушоед, ки монд шудед. Дар ин дарс мо ҳанӯз функсияҳо ва давраҳо наменависем — танҳо тағйирёбандаҳо ва шартҳо. Маълумоти барномаҳоро бо тағйирёбандаҳо дар аввали код медиҳем: қиматҳоро тағйир диҳед ва бубинед, ки барнома чӣ тавр вокуниш нишон медиҳад.

01 Операторҳои муқоиса

Ҳар қарор дар барнома бо савол оғоз мешавад: «ин синну сол аз ҳаждаҳ калон аст?», «парол мувофиқат кард?», «пул кифоя аст?». Савол дар JavaScript бо оператори муқоиса дода мешавад, ҷавоб бошад ҳамеша яке аз ду: true («ҳа») ё false («не»). Ин навъи boolean аст, ки шумо аз дарси навъҳои маълумот аллакай медонед.

ОператорМаъноМисолНатиҷа
>калонтар5 > 3true
<хурдтар5 < 3false
>=калонтар ё баробар5 >= 5true
<=хурдтар ё баробар4 <= 3false
===қатъиян баробар5 === 5true
!==қатъиян баробар не5 !== 6true
 
const age = 17;
const price = 35;
const balance = 120;

console.log(age >= 18);          // → false: то синни баркамолӣ як сол мондааст
console.log(balance >= price);   // → true: пул кифоя аст
console.log(balance - price);    // → 85: арифметика низ кор мекунад
console.log(age !== 17);         // → false
Хатои маъмул: як аломати «=»

Як аломати = — ин таъинот («қиматро дар тағйирёбанда гузор») аст, на муқоиса. Саволи «баробар аст?»-ро === медиҳад. Онҳоро омехта кардан хеле осон аст, бинобар ин бо овоз бихонед: = — «мешавад», === — «баробар аст?».

let score = 5;
console.log(score === 7);  // → false: танҳо савол, score тағйир намеёбад
score = 7;                  // таъинот: акнун дар score 7 аст
console.log(score === 7);  // → true

Муқоисаи сатрҳо: аз рӯи алифбо, вале бо истиснохо

Сатрҳо «аз рӯи луғат», ҳарф ба ҳарф муқоиса мешаванд. Аммо компютер на ҳарфҳоро, балки рақамҳои дохилии онҳоро (кодҳоро) дар ҷадвали Unicode муқоиса мекунад. Бинобар ин ду дом ҳаст: ҳарфҳои калон аз хурдҳо «хурдтар»-анд, рақам-сатрҳо бошанд мисли матн муқоиса мешаванд, на мисли рақам.

console.log("Аня" < "Бахтиёр");  // → true: «А» дар алифбо пештар аз «Б» меистад
console.log("а" < "Б");          // → false: «а»-и хурд дар ҷадвал пас аз «Б»-и калон меояд
console.log("Z" < "a");          // → true: ҳамаи калонҳо пештар аз хурдҳо меоянд
console.log("10" < "9");         // → true: мисли матн «1» пештар аз «9», мисли луғат
console.log(10 < 9);             // → false: аммо мисли рақам
Ташбеҳ аз зиндагӣ

Рақамҳои маршруткаҳо дар истгоҳи Душанбе. Агар онҳоро мисли рақам хонем, «9» пештар аз «10» меояд. Аммо агар лавҳаҳоро аз рӯи алифбо, мисли ҷузвдонҳо дар ҷевон гузорем, «10» пеш аз «9» меафтад: рақами аввал муқоиса мешавад, ва он дар «1» хурдтар аст. Сатрҳо дар JavaScript маҳз мисли лавҳаҳо дар ҷевон муқоиса мешаванд, рақамҳо — мисли рақамҳо.

Муқоисаи навъҳои гуногун

Вақте ки дар як тарафи > ё < сатр, дар тарафи дигар рақам аст, JavaScript сатрро ба рақам табдил медиҳад (шумо инро дар дарси табдили навъҳо дидед) ва танҳо баъд муқоиса мекунад.

console.log("10" > 9);        // → true: сатри "10" рақами 10 шуд
console.log("abc" > 1);       // → false: "abc" NaN шуд, ҳар муқоиса бо NaN false медиҳад
console.log(NaN === NaN);      // → false: NaN ҳатто ба худаш баробар нест
console.log(null > 0);        // → false
console.log(null === 0);       // → false
console.log(null >= 0);       // → true — ғаройиби забон, ба он дар бахши оянда бармегардем

02 Баробарии қатъӣ ва ғайриқатъӣ

Дар JavaScript ду навъи «баробар» ҳаст. Онҳо ба ҳам монанд менамоянд, вале комилан гуногун рафтор мекунанд.

  • === — баробарии қатъӣ. Ҳам қимат ва ҳам навъро муқоиса мекунад. Агар навъҳо гуногун бошанд — фавран false, бе кӯшиши чизеро табдил додан.
  • == — баробарии ғайриқатъӣ. Агар навъҳо гуногун бошанд, аввал қиматҳоро ба навъи умумӣ меорад ва танҳо баъд муқоиса мекунад.
console.log(5 === 5);     // → true: рақам ва рақам
console.log(5 === "5");   // → false: рақам ва сатр, навъҳо гуногунанд
console.log(5 == "5");    // → true: == сатри "5"-ро ба рақам табдил дод ва муқоиса кард
Ташбеҳ аз зиндагӣ

===-и қатъӣ — посбон дар даромадгоҳи донишгоҳ аст: шиносномаро пурра месанҷад — ҳам ном ва ҳам ҳуҷҷат. ==-и ғайриқатъӣ — шиноси меҳрубон аст: «Хуб, шумо ба Фарход монанд ҳастед, гузаред». Баъзан тахмин мекунад, вале баъзан нодурустро мегузаронад. Дар код мо пешбинишавандагиро мехоҳем, бинобар ин посбон беҳтар аст.

Ҷадвал: бо == чӣ мешавад

Муқоисаи ғайриқатъӣ ба рӯйхати дарози қоидаҳо итоат мекунад. Ҳамаи онҳоро дар хотир доштан лозим нест, вале як бор дидан муфид аст, ки онҳо ба чӣ меоранд:

Қоидаи курс

Ҳамеша === ва !== менависем. Ягона чизе, ки дар бораи == дар хотир доштан меарзад: хондани он дар коди дигарон ва фаҳмидани он ки чаро хатарнок аст. Агар рақамро аз шакл бо сатр муқоиса кардан лозим бошад — ошкоро табдил диҳед: Number(input) === 5. Ошкоро беҳтар аз ниҳонӣ: код якмаъно хонда мешавад.

Ин бад аст

«Тасодуфан» кор мекунад ва вақте ки корбар сатри холӣ ворид кунад, вайрон мешавад.

const answer = "";
if (answer == 0) {
  console.log("Ответ — ноль!");  // бароварда мешавад, ҳарчанд корбар чизе ворид накардааст
}
Ин хуб аст

Навъ ошкоро табдил дода мешавад, сатри холӣ нашуда ба сифр табдил намеёбад.

const answer = "";
if (answer !== "" && Number(answer) === 0) {
  console.log("Ответ — ноль!");  // бароварда намешавад
}

ВАЗИФАИ 2.1

Баромадро пешбинӣ кунед: == ва ===

осон

Барои ҳар кадоме аз шаш муқоиса пешбиниро ("true" ё "false") дар prediction нависед ва танҳо баъд иҷро кунед. Сатрҳоеро, ки дар онҳо хато кардед, бо сабаб дар конспект сабт кунед.

// Пешбиниро ворид кунед: true ё false барои ҳар муқоиса (ҳар қимат — бо матн, чунон ки консол нишон медиҳад)
const prediction = ["", "", "", "", "", ""];
const actual = [
  5 == "5",
  5 === "5",
  0 == false,
  null == undefined,
  null === undefined,
  NaN == NaN,
].map(String);
console.log(actual.join("|") === prediction.join("|") ? "Верно!" : "Не угадали, подумайте ещё");

Верно!
Ишора 1

Аз худ бипурсед: оё навъи қиматҳо яксон аст? Агар ҳа — муқоисаи ғайриқатъӣ ва қатъӣ як натиҷа медиҳанд.

Ишора 2

Бо ҷадвали боло муқоиса кунед. Алоҳида ду ҳолати «махсус»-ро дар хотир доред: null == undefined ва NaN.

Ишора 2

Сатри чорум >=-ро истифода мебарад, на ==-ро. Операторҳои <, >, <=, >= null-ро ба 0 меоранд, бинобар ин 0 >= 0 true медиҳад.

03 Қиматҳои рост ва дурӯғ (truthy / falsy)

Шарт ҳатман муқоиса будан лозим нест. Ба if ҳар қиматро гузоштан мумкин аст ва JavaScript худаш онро ба true ё false табдил медиҳад. Ин ҳамон табдили ниҳонӣ ба boolean аст, ки дар дарси навъҳо сухан рафт.

Дар ҳамагӣ ҳашт қимати «дурӯғ», боқӣ — рост

Қиматҳоеро, ки ба false табдил меёбанд, falsy («дурӯғнамо») меноманд. Панҷтои асосиро дар хотир доред — онҳо ҳар рӯз вомехӯранд:

Қимати falsyИн чист
falseхуди қимати дурӯғ
0 (инчунин -0, 0n)рақами сифр
""сатри холӣ
null«қасдан холӣ»
undefined«қимат таъин нашудааст»
NaN«рақам не»

Боқӣ ҳама — truthy («рост»): ҳар рақами ғайрисифр (аз ҷумла манфӣ), ҳар сатри ғайриҳолӣ, аз ҷумла "0" ва "false". Ҳар қиматро тавассути Boolean(...) ё инкори дукаратаи !! санҷидан мумкин аст:

console.log(Boolean(0));         // → false
console.log(Boolean(""));        // → false
console.log(Boolean(null));      // → false
console.log(Boolean(NaN));       // → false

Стакани холӣ, ҳамёни холӣ, ҷойи холӣ дар истгоҳ — ин «не» аст. Аммо ҳамёне, ки дар он як танга ҳаст, — аллакай «ҳаст», ҳарчанд ночиз. Вале ба як ғаройиб диққат диҳед: 0 — ин «холӣ» аст, сатри "0" — «ҳаст», зеро дар он аломат-рақам ҷойгир аст.

Ин чӣ тавр истифода мешавад

Сабаби аз ҳама маъмули нигоҳ кардан ба truthy/falsy — санҷиши «оё корбар умуман қимат додааст»:

}

04 Операторҳои мантиқӣ: &&, ||, !

Як савол аксар вақт кам аст. «Ба клуб рафтан мумкин аст, агар шумо 18 ё бештар доред ва шиноснома доред». Барои муттаҳид кардани саволҳо се оператори мантиқӣ истифода мешавад:

&& — «ва»
Рост аст, танҳо агар ҳар ду шарт рост бошанд.
|| — «ё»
Рост аст, агар ақаллан як аз шартҳо рост бошад.
! — «не»
Қиматро баръакс мекунад: !true — ин false аст ва баръакс.

const age = 20;
const hasTicket = true;

console.log(age >= 18 && !hasTicket);  // → false
Ташбеҳ аз зиндагӣ

Барои баромадан ба роҳи ресмонӣ билет ва обу ҳавои хуб лозим аст (&&). Ба чойхона даромадан мумкин аст ё аз даромадгоҳи асосӣ, ё аз ҳавлӣ (||). Аломати «не» — лавҳаи «Кор намекунад» аст: ҷавобро баръакс мекунад.

Афзалият ва қавсҳо

Тартиби иҷро мисли риёзиёт аст: аввал !, баъд &&, сонитар ||. Чунон ки зарб пештар аз ҷамъ меояд, «ва» низ пештар аз «ё» меояд. Барои тахмин накардан ва хонандаро саргардон накардан, дар шартҳои мураккаб қавсҳо гузоред.

const isStudent = true;
const hasCard = false;
const isWeekend = false;

// бе қавсҳо: аввал &&, баъд ||
console.log(isStudent || hasCard && isWeekend);     // → true
// бо қавсҳо: тартиб тағйир меёбад
console.log((isStudent || hasCard) && isWeekend);   // → false

Қонуни «не» (қонунҳои де Морган)

Шарти «не (А ё Б)» ҳамон маъноро дорад, ки «не А ва не Б». Ва баръакс: «не (А ва Б)» — ин «не А ё не Б» аст. Ин ба соддасозии шартҳои печида кумак мекунад.

const isClosed = false;
const isFull = true;

// «Даромадан мумкин аст, агар на (баста ё ҷой нест)»
console.log(!(isClosed || isFull));     // → false
// ҳамон: «на баста ВА на пур»
console.log(!isClosed && !isFull);     // → false

Қатъи кӯтоҳ ва қиматҳои бозпасгардонидашаванда

Ҳамин ҷо ҷолибтарин қисм оғоз мешавад. Операторҳои && ва || дар асл на true / false, балки яке аз қиматҳоеро, ки муқоиса мекунанд, бозпас мегардонанд. Ва онро «танбалона», аз чап ба рост мекунанд, баробари он ки ҷавоб равшан шуд, қатъ мешаванд. Инро қатъи кӯтоҳ (short-circuit) меноманд.

  • a || b — аввалин қимати ростро мегирад. Агар ростҳо набошанд — охиринро бозпас мегардонад.
  • a && b — аввалин қимати дурӯғро мегирад. Агар дурӯғҳо набошанд — охиринро бозпас мегардонад.
console.log(0 || 10);                  // → 10: 0 дурӯғ аст, ба пеш меравем
console.log("Алиша" || "гость");       // → Алиша: қимати аввал аллакай рост аст, минбаъд намебинем
console.log(null || undefined || "запасной"); // → захира

console.log(1 && 2 && 3);                // → 3: ҳама рост, охиринро бозпас гардонд
console.log(1 && 0 && 3);                // → 0: дар аввалин дурӯғ истод
console.log(null && "не дойдём");        // → null
Ташбеҳ аз зиндагӣ

|| — санҷиши вариантҳои эҳтиётӣ аст: «ба чойхонаи назди хона меравем, агар баста бошад — ба ҳамсоя, агар он ҳам баста бошад — ба хона». Аввалин варианти кордорро мегирем. && — занҷири санҷишҳо дар фурудгоҳ аст: шиноснома, билет, бор. Баробари он ки як санҷиш нагузашт — дигар намегузоранд ва мо медонем, ки дар чӣ истодем.

Инро дар амал истифода мебаранд. Қимати пешфарз:

const nickname = "";                          // корбар чизе ворид накард
const shown = nickname || "Гость";            // агар холӣ бошад — «Гость»-ро ҷойгузин мекунем
console.log("Привет,", shown);                // → Привет, Гость

Ва «танҳо агар»-и бехатар: қисми рости && танҳо вақте ҳисоб карда мешавад, ки чап рост бошад.

const isAdmin = true;
isAdmin && console.log("Открываем панель администратора");  // иҷро мешавад
const isGuest = false;
isGuest && console.log("Это сообщение не появится");        // қисми рост ҳатто ҳисоб карда нашуд

Оператори ?? — «агар холӣ» танҳо барои null ва undefined

|| камбудие дорад, ки шумо аллакай дидед: 0 ва сатри холиро дурӯғ мешуморад. Барои қиматҳои пешфарз ин аксар вақт нофорам аст: овози 0 — танзими софдилона аст, на «қимат таъин нашудааст». Оператори ?? («якҷоякунии тиҳӣ») қимати эҳтиётиро танҳо вақте ҷойгузин мекунад, ки дар чап null ё undefined бошад.

const volume = 0;                 // корбар садоро хомӯш кард

console.log(volume || 50);        // → 50 ✖ садои хомӯшшуда худ аз худ фаъол шуд
console.log(volume ?? 50);        // → 0  ✔ сифр нигоҳ дошта шуд

let theme;                        // танзим таъин нашудааст (undefined)
console.log(theme ?? "светлая");  // → светлая

05 Оператори шартӣ if / else if / else

Акнун, ки саволҳо доданро медонем, ба барнома интихоби роҳ-ро меомӯзонем. Барои ин оператори if («агар») хизмат мекунад.

const temperature = 35;

if (temperature > 30) {
  console.log("Жарко, берите воду");
}
console.log("Программа продолжается");

Код дар қавсҳои фигурӣ танҳо вақте иҷро мешавад, ки шарт дар қавсҳои мудаввар рост бошад. Агар дурӯғ бошад — блок танҳо гузаронида мешавад ва барнома пеш меравад.

else — «дар ҳолатҳои дигар»

const balance = 8;
const fare = 3;   // роҳкиро дар маршрутка

if (balance >= fare) {
  console.log("Проезд оплачен");
} else {
  console.log("Недостаточно средств");
}

else if — якчанд вариант

Агар вариантҳо аз ду зиёд бошанд, байни if ва else ҳар қадар else if илова мекунанд. Шартҳо аз боло ба поён, то аввалин рост санҷида мешаванд; боқӣ дигар санҷида намешаванд.

const score = 72;

if (score >= 86) {
  console.log("Оценка: 5");
} else if (score >= 71) {
  console.log("Оценка: 4");
} else if (score >= 56) {
  console.log("Оценка: 3");
} else {
  console.log("Оценка: 2");
}
Ташбеҳ аз зиндагӣ

Чароғаки роҳнамо дар хиёбони Рӯдакӣ. Ронанда бо тартиб месанҷад: сурх? — меистем. Не? Зард? — омода мешавем. Не? Пас, сабз — меравем. Баробари он ки як банд мувофиқ омад, ронанда боқиро дигар ба назар намегирад. Занҷири if / else if / else ҳамин тавр кор мекунад.

Тартиби шартҳо муҳим аст

Азбаски танҳо аввалин шохаи мувофиқ иҷро мешавад, шартҳоро аз сахттаринҳо ба нармтаринҳо гузоштан лозим аст. Агар score >= 56-ро аввал гузоред, 90 балл ҳам баҳои «3» мегирад — зеро 90 низ аз 56 калон аст.

const score = 90;

if (score >= 56) {
  console.log("Оценка: 3");     // аллакай дар ин ҷо кор мекунад
} else if (score >= 71) {
  console.log("Оценка: 4");     // ҳеҷ гоҳ нахоҳем расид
} else if (score >= 86) {
  console.log("Оценка: 5");     // ва ба ин ҷо ҳам
}

Шартҳои таркибӣ ва дарунҷоӣ

06 Оператори сегона ? :

Вақте ки танҳо яке аз ду қиматро интихоб кардан лозим аст, сохтори if / else хеле ҷой мегирад. Барои чунин ҳолатҳо навишти кӯтоҳ ҳаст — оператори сегона (тернарӣ). Он дар JavaScript ягонаест, ки се қисм дорад («тернарӣ» маънои «се»-ро дорад).

const age = 20;

// навишти дароз
let status1;
if (age >= 18) {
  status1 = "взрослый";
} else {
  status1 = "ребёнок";
}

// навишти кӯтоҳ: шарт ? қимат_агар_ҳа : қимат_агар_не
const status2 = age >= 18 ? "взрослый" : "ребёнок";

console.log(status1);   // → взрослый
console.log(status2);   // → взрослый
Ташбеҳ аз зиндагӣ

Лавҳа дар дари чойхона: «Кушода / Баста». Соҳиб бо як нигоҳ ба соат интихоб мекунад, ки лавҳаро бо кадом тараф овезон кунад. Оператори сегона маҳз ҳамин корро мекунад: аз рӯи шарт яке аз ду қимати тайёрро интихоб мекунад.

Дар куҷо қулай аст

Натиҷаи оператори сегона — қимат аст, бинобар ин онро бевосита ба сатри қолабӣ ё ба аргументи console.log гузоштан мумкин аст:

const items = 0;
console.log(`В корзине: ${items === 0 ? "пусто" : items + " шт."}`);

const hour = 7;
console.log("Чойхона:", hour >= 9 && hour < 22 ? "открыта" : "закрыта");

Занҷири операторҳои сегона

Операторҳои сегонаро ба ҳам пайваст кардан мумкин аст, ин else if-ро иваз мекунад. Кор мекунад, вале бо ду сатҳ хондан аллакай душвор аст.

const temp = 22;
const feel = temp >= 30 ? "жарко"
           : temp >= 15 ? "тепло"
           : "прохладно";
console.log(feel);   // → тепло
Аз ҳад зиёд

Операторҳои сегонаи дарунҷоӣ дар як сатр — дарди сар барои хонанда.

const x = a ? b ? 1 : 2 : c ? 3 : d ? 4 : 5;
if / else-и софдилона

Агар вариантҳо аз ду зиёд ё шартҳо мураккаб бошанд — if / else if ё switch-ро гиред.

let label;
if (temp >= 30) {
  label = "жарко";
} else if (temp >= 15) {
  label = "тепло";
} else {
  label = "прохладно";
}
На барои амалҳо, балки барои қиматҳо

Оператори сегона барои гирифтани қимат лозим аст. Агар шумо бояд амалҳои гуногун иҷро кунед (яке барорад, дигареро захира кунад), if-и оддиро истифода баред. Ифодае чун cond ? console.log("a") : console.log("b") кор мекунад, вале бад хонда мешавад.

07 Сохтори switch

Агар як тағйирёбандаро бо қиматҳои мушаххаси зиёд муқоиса кардан лозим бошад, занҷири даҳ else if печида мешавад. Барои ин switch («гузаронанда») ихтироъ шудааст.

const day = 3;

switch (day) {
  case 1:
    console.log("Понедельник");
    break;
  case 2:
    console.log("Вторник");
    break;
  case 3:
    console.log("Среда");
    break;
  default:
    console.log("Другой день");
}
  1. Ифода ҳисоб мекунад дар қавсҳо пас аз switch — дар ин ҷо day.
  2. Қимат қатъиян муқоиса мешавад (мисли ===) бо ҳар case аз боло ба поён.
  3. Аввалин мувофиқат ёфта мешавад — ва код аз ҳамин ҷо ба поён иҷро мешавад.
  4. break аз switch мебарояд. Агар break набошад — иҷро идома меёбад.
  5. default — «ҳеҷ чиз мувофиқ наомад», ҳамонанди else. Онро дар охир менависанд.
Ташбеҳ аз зиндагӣ

Меню дар чойхона: официант «курутоб»-ро мешунавад ва бевосита ба сатри лозимаи меню меравад, на ҳамаи хӯрокҳоро бо тартиб мехонад. default — ин «чунин хӯрок дар мо нест». Ва агар break-ро фаромӯш кунед, официант ҳам курутоб ва ҳам ҳар он чиро, ки дар поёни меню навишта шудааст, меорад.

break-ро фаромӯш кардем: «афтидан» (fall-through)

Маъруфтарин дом дар switch. Бе break JavaScript case-и лозимаро меёбад ва ҳар он чи дар поён аст иҷро мекунад, то даме ки ба break ё охири switch бирасад.

const n = 2;

switch (n) {
  case 1:
    console.log("Один");
  case 2:
    console.log("Два");
  case 3:
    console.log("Три");
  default:
    console.log("Неизвестно");
}
// мебарорад: Два, Три, Неизвестно — ҳар он чи дар поёни case-и мувофиқ аст

Афтидани муфид: якчанд case — як амал

Тарафи муфид ҳам ҳаст. Агар барои якчанд қимат амал яксон бошад, онҳоро пай дар пай навиштан мумкин аст, break-ро бошад танҳо пас аз коди умумӣ гузоштан:

const month = 4;

  case 12:
  case 1:
  case 2:
    console.log("Зима");
    break;
  case 3:
  case 4:
  case 5:
    console.log("Весна");
    break;
  case 6:
  case 7:
  case 8:
    console.log("Лето");
    break;
  case 9:
  case 10:
  case 11:
    console.log("Осень");
    break;
  default:
    console.log("Такого месяца нет");
}

switch қиматҳоро мисли ===, бе табдили навъҳо муқоиса мекунад. Бинобар ин рақами 1 ва сатри "1" — қиматҳои гуногунанд:

switch (choice) {
  case 1:
    console.log("Число один");
    break;
  case "1":
    console.log("Строка «1»");
    break;
  default:
    console.log("Не нашли");
}

09 Амалия дар дарс: ҳисобкунаки консолӣ

Аввалин барномаи воқеиро месозем. Ин ҳисобкунак аст: ду рақам ва аломати амалро мегирад, ҳисоб мекунад ва ҷавобро ба консол мебарорад. Воридкунии интерактивӣ (тавассути prompt) дар ин саҳифа нест, бинобар ин маълумотро бо тағйирёбандаҳо дар боло медиҳем: a, b ва operation. Нақшаи дарс ва ҳолатҳои Copilot
  • Вазифаҳои 9.1–9.2 — ҳисобкунак. Copilot фаъол аст: аз ишораҳо истифода баред, вале ҳар сатри пазируфтаро ба ҳамнишин шарҳ диҳед.

Қолаби ҳисобкунак

  1. Маълумот: ду рақами a, b ва сатри operation бо аломат.
  2. Интихоби амал: switch (operation) бо вариантҳои "+", "-", "*", "/".
  3. Натиҷа: сатри намуди 12 * 4 = 48-ро бароред.
  4. Ҳимоя: тақсим ба сифр — хатои алоҳида; амали номаълум — шохаи default.
const a = 12;
const b = 4;
const operation = "+";

Шарти аз ҳама сахтро (ҳар ду тақсимкунанда) аввал мегузорем, баъд «танҳо 3», баъд «танҳо 5», дар охир else бо console.log(n).

★ Вазифаи хонагӣ: се барномаи консолӣ

Се барнома, ҳар кадом дар файли худ. Онҳоро дар консоли браузер (DevTools аз дарси аввал) ё дар ин саҳифа иҷро кардан мумкин аст. Маълумотро бо тағйирёбандаҳо дар аввали файл диҳед. Бе функсияҳо ва давраҳо: танҳо тағйирёбандаҳо, if / else, оператори сегона ва switch.

Барномаи 1. Ҳисобкунак

Рушди кори синфӣ: a, b, operation.

  • ☐ Амалҳои +, -, *, /, %, ** тавассути switch.
  • ☐ Тақсим ва бақия ба сифр — паёми хато ба ҷои натиҷа.
  • ☐ Амали номаълум — паёми хато (default).
  • ☐ Санҷиши навъҳо: агар a ё b рақам набошанд (typeof a !== "number"), Ошибка: нужны числа-ро бароред ва ҳисоб накунед.
  • ☐ Баромад дар намуди 12 * 4 = 48.

Барномаи 3. Табдилдиҳандаи асъор

Қурбҳо дар барнома собит карда шудаанд: 1 USD = 10.5 сомонӣ, 1 RUB = 0.12 сомонӣ. Маблағи amount, асъори аслӣ from ва мақсадӣ to (сатрҳои "TJS", "USD", "RUB") дода шудаанд. Ғоя: аввал маблағро ба сомонӣ гузаронед («махраҷи умумӣ»), баъд аз сомонӣ ба асъори лозимӣ.

const amount = 100;
const from = "USD";
const to = "TJS";

const USD_RATE = 10.5;   // 1 доллар чанд сомонӣ меарзад
const RUB_RATE = 0.12;   // 1 рубл чанд сомонӣ меарзад

let inSomoni;

switch (from) {
  case "TJS":
    inSomoni = amount;
    break;
  case "USD":
    inSomoni = amount * USD_RATE;
    break;
  // дар ин ҷо "RUB" мешавад
  default:
    console.log("Неизвестная исходная валюта");
}

console.log(inSomoni);   // → 1050
// баъд: switch (to)-и дуюм натиҷаро аз inSomoni ҳисоб мекунад

✓ Варақаи хулосаи дарс

  • Муқоиса: > < >= <= true / false бозпас мегардонанд. Як = — таъинот, на муқоиса. Сатрҳо аз рӯи ҷадвали Unicode муқоиса мешаванд: «Z» аз «a» хурдтар аст, "10" < "9" бошад.
  • === ва !== — муқоисаи қатъӣ (қимат ва навъ). == навъҳоро ба ҳам меорад ва ба ғайричашмдошт меоварад (0 == "", null == undefined). Дар код танҳо === менависем; NaN ба ҳеҷ кас баробар нест.
  • Falsy: false, 0, "", null, undefined, NaN. Боқӣ ҳама — truthy, аз ҷумла "0", " ", "false". Сифр — қимати воқеӣ аст: !== undefined-ро санҷед, вақте ки сифр мумкин аст.
  • Мантиқ: && — ва, || — ё, ! — не. Афзалият: !, баъд &&, баъд ||; шубҳа дошта бошед — қавс гузоред.
  • Қатъи кӯтоҳ: || аввалин ростро бозпас мегардонад, && — аввалин дурӯғро (ё қимати охирини занҷирро). nick || "Гость" — қимати пешфарз. ?? танҳо null ва undefined-ро иваз мекунад: 0 ?? 50 0 медиҳад.
  • if / else if / else: шартҳо аз боло ба поён то аввалин рост санҷида мешаванд, аз сахт ба нарм. Ҳамеша бо қавсҳои фигурӣ.
  • Оператори сегона: шарт ? агар_ҳа : агар_не — барои интихоби яке аз ду қимат. Занҷирҳои аз ду сатҳ ва бештарро тавассути if навиштан беҳтар аст.
  • switch: муқоисаи қатъӣ бо case, break ҳатмӣ (вагарна «афтидан» ба поён), default — барои ҳама чизи дигар. case-ҳои пай дар пай бе break — як амал барои якчанд қимат.
  • Copilot: Tab — қабул кардан, Esc — рад кардан, Ctrl/Cmd + I — inline chat. Ба корҳои мунтазам ва шарҳ кумак мекунад, агар ишораҳоро бе фикр қабул кунед, ба омӯзиш халал мерасонад. Аввал худатон бо Copilot-и хомӯш, баъд он ҳамчун тақризнависанда. Сарҳадҳо (> ва >=), сифр ва break-ҳои фаромӯшшударо санҷед.
