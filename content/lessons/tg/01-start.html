То ҳол саҳифаҳои шумо ба «расм» монанд буданд: зебо, вале бе ҷон. Тугма коре намекунад, шакл чизеро тафтиш намекунад. Имрӯз шумо ҷои корро омода мекунед, аввалин скриптро ба кор медароред ва асбоби асосии барномасозро — консолро меомӯзед.

Бо ин саҳифа чӣ тавр кор кардан лозим аст

Тамоми код дар заминаи торик бо тугмаи ▶ Иҷро кардан — зинда аст. Онро ҳамин ҷо тағйир додан ва натиҷаро дарҳол дар консоли поёни он дидан мумкин аст. Вайрон кардед — ↺ Аз нав-ро пахш кунед. Равзанаҳои бо ҷадвалҳои index.html / script.js саҳифаҳои хурданд: боло код, поён пешнамоиш. Ишораҳои вазифаҳо пинҳон шудаанд: аввал худатон кӯшиш кунед. Блокҳои бо навиштаи «Терминал» ё «Танҳо хондан» иҷро намешаванд — ин дастурҳо барои компютери шумоанд.

Муҳим: равзанаҳои alert, prompt ва confirm дар ин саҳифа аз ҷониби «қуттии рег»-и браузер, ки код дар он кор мекунад, баста шудаанд. Бинобар ин мо онҳоро дар мисолҳои хониш шарҳ медиҳем, вале шумо онҳоро дар саҳифаи худ дар VS Code иҷро мекунед.

JavaScript кодро чӣ тавр мехонад

  • Аз боло ба поён, сатр ба сатр. Мисли хондани дастури пухтан: аввал қадами якум, баъд дуюм.
  • Як фармон — як амал. Фармонҳоро (онҳоро «дастур» меноманд) одатан бо нуқтаву вергул ; анҷом медиҳанд.
  • Регистр муҳим аст. console ва Console барои JavaScript ду калимаи гуногунанд.
  • Агар дар ягон сатр хато рӯй диҳад, коди поёнтар иҷро намешавад. Браузер қатъ мешавад ва дар консол паём менависад.

Аввалин фармоне, ки меомӯзед — console.log аст. Он қимати додашударо дар консол «чоп мекунад». Кӯшиш кунед: «Иҷро кардан»-ро пахш кунед, баъд матнро тағйир диҳед ва аз нав иҷро намоед.

Дар амал санҷед, ки тартиб муҳим аст. Сатрҳо аз боло ба поён иҷро мешаванд ва натиҷа дар консол бо ҳамон тартиб меояд:

console.log("Первый шаг");

console.log("Шаг 2: всё хорошо");

Хатои маъмул

Гумон кардан, ки JavaScript «мефаҳмад, ки шумо чиро дар назар доштед». Не: он айнан он чизеро иҷро мекунад, ки навишта шудааст, ҳарф ба ҳарф. Фосилаи зиёдатӣ дар нохунакҳо, ҳарфи калон ба ҷои хурд, қавси фаромӯшшуда — ва ба ҷои натиҷа паёми сурх мегиред. Ин муқаррарӣ аст: хато бо ҳар барномасоз ҳар рӯз рӯй медиҳад ва хондани онҳо малакаи алоҳидаест, ки имрӯз тамринашро оғоз мекунем.

02 Скриптро пайваст мекунем: inline, файли беруна, defer

Барои он ки браузер JavaScript-ро иҷро кунад, кодро бо ёрии теги <script> ба саҳифа «гузоштан» лозим аст. Ду роҳ ҳаст.

Роҳи 1. Код бевосита дар HTML (inline)

<body>
  <h1>Моя страница</h1>

  <script>
    console.log("Салом из inline-скрипта!");
  </script>
</body>

Барои санҷиши кӯтоҳ қулай аст, вале дар лоиҳаҳои воқеӣ ин тавр намекунанд: HTML ба омехтаи бесарусомон табдил меёбад, коди онро бошад, дар саҳифаи дигар истифода бурдан мумкин нест.

Роҳи 2. Файли алоҳида (скрипти беруна)

Ин роҳи асосӣ аст. Код дар файли script.js дар паҳлӯи index.html ҷойгир аст, дар HTML бошад, шумо танҳо тавассути атрибути src ба он ишора мекунед — айнан мисли он ки <link href="style.css"> CSS-ро пайваст мекунад.

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Первый скрипт</title>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Салом, JavaScript!</h1>
</body>
</html>

console.log("Салом из script.js!");
Ташбеҳ аз зиндагӣ

Inline-скрипт — ин қайдест, ки бевосита ба девор часпонида шудааст. Файли беруна — ин қафасаест бо ҷузвдонҳо: дар девор танҳо барчасп овезон аст «ҷузвдони script.js-ро бинед», ҳамаи ҳуҷҷатҳо бошад дар ҷузвдон ҳастанд ва онҳоро аз ҳар хона (аз ҳар саҳифа) кушодан мумкин аст.

src
Нишонии файли дорои скрипт. script.js — дар паҳлӯи HTML, js/script.js — дар ҷузвдони дохилии js, ../script.js — як зина боло.
Теги пӯшанда
Ҳамеша лозим аст: <script src="..."></script>. Онро ҳамчун <script src="..." /> навиштан мумкин нест — саҳифа вайрон мешавад.
defer
Атрибути «интизор шав». Браузер файлро баробари хондани саҳифа боргирӣ мекунад, вале онро танҳо пас аз хондани тамоми HTML иҷро мекунад.

Теги script-ро дар куҷо нигоҳ доштан лозим аст

Нақшаи бахши гузаштаро ба ёд оред: браузер HTML-ро аз боло ба поён мехонад. Агар скрипт аз унсуре, ки ба он муроҷиат мекунад, боло истода бошад, дар лаҳзаи оғози кор чунин унсур ҳанӯз вуҷуд надорад. Дар мисоли зинда бубинед. Дар се ҷой мо аз саҳифа сарлавҳаи h1-ро металабем (ин чӣ тавр кор мекунад, дар дарси 8 шарҳ медиҳем — ҳоло фақат калимаи null — «чизе нест» муҳим аст).

<script>
  console.log("скрипт ВЫШЕ заголовка:", document.getElementById("title"));
</script>

<h1 id="title">Салом, MakeFirstStep!</h1>

<script>
  console.log("скрипт НИЖЕ заголовка:", document.getElementById("title"));
</script>

// файли script.js дар ин қуттии рег пас аз тамоми саҳифа иҷро мешавад, мисли defer
console.log("script.js (как defer):", document.getElementById("title"));

Скрипти аввал null-ро дид: сарлавҳа дар саҳифа ҳанӯз набуд. Дуюм ва сеюм — <h1#title>-ро ёфтанд. Аз ин ҷо се қоидаи корӣ мебарояд:

ВариантЧӣ тавр менамоядКай истифода бурдан лозим аст
defer дар <head><script src="script.js" defer></script>Интихоби мо дар курс. Пайвастшавӣ дарҳол дар болои файл намоён аст, иҷро бошад — пас аз боргирии саҳифа.
Дар охири <body><script src="script.js"></script> пеш аз </body>Роҳи кӯҳна, вале корӣ. Дар коди дигарон зуд вомехӯрад.
Дар <head> бе defer<script src="script.js"></script>Одатан хато аст: скрипт замоне иҷро мешавад, ки саҳифа ҳанӯз нест, ва унсурҳоро намеёбад.

Боз атрибути async ҳаст: он скриптро баробари боргирӣ фавран иҷро мекунад, саҳифа ва скриптҳои дигарро интизор намешавад. Ҳисобкунакҳои аналитикаро ҳамин тавр пайваст мекунанд. Барои барномаҳои мо он мувофиқ нест: тартиби оғоз кафолат дода намешавад. Аммо type="module" (дарсҳои 17–18) худкор мисли defer рафтор мекунад.

Хатоҳои маъмул ҳангоми пайваст кардан
  • Скрипт «кор намекунад», дар консол холӣ аст. Роҳро дар src санҷед: skript.js ва script.js — файлҳои гуногунанд. Дар сервер низ регистр муҳим аст: Script.js ≠ script.js.
  • Дар консол сатри сурх «Failed to load resource: 404». Браузер файлро наёфт: он дар ҷузвдони дигар аст ё номаш дигар аст.
  • Файл script.js.txt ном дорад. Дар Windows васеъшавиҳо бо пешфарз пинҳонанд — онҳоро фаъол кунед (Проводник → Вид → Показать → Расширения имён файлов).
  • Кодро тағйир додам, вале дар браузер ҳама чиз ба ҳолати пештара аст. Файл захира нашудааст (нуқтаи сафед дар назди ҷадвал дар VS Code) ё браузер нусхаи кӯҳнаро нишон медиҳад: саҳифаро бо тозакунии кэш нав кунед — Ctrl + Shift + R (Windows) ё Cmd + Shift + R (macOS).
  • Агар тег src дошта бошад, коди дохили он нодида гирифта мешавад. Яке аз ду лозим аст: ё src, ё код дар дохил.

03 Консол: log, warn, error, table

Консол — ин равзанаи «чат» байни шумо ва браузер аст. Дар он ҷо барнома паёмҳо менависад, шумо бошед мехонед. Барномасозони JavaScript нисфи вақти корро дар консол мегузаронанд: қиматҳоро месанҷанд, хатоҳоро меҷӯянд, фармонҳоро месанҷанд.

Ташбеҳ аз зиндагӣ

Консол мисли тирезаи ошхонаи чойхона аст, ки ошпаз тавассути он ба толор паём мефиристад. «Фармоиш тайёр аст» (log), «биринҷ тамом шуда истодааст» (warn), «қазон шикаст, палав намешавад» (error). Меҳмон ин тирезаро намебинад — танҳо шумо, таҳиягар.

console.log — қимат чоп мекунем

Дар қавсҳо матн, рақамҳо ва ҳатто ҳисобҳо навиштан мумкин аст. Матн ҳамеша дар нохунак гирифта мешавад: дукарата "..." ё яккарата '...' — фарқ надорад, муҳим он аст, ки кушода ва пӯшанда яксон бошанд.

console.log("Это текст");          // сатр — дар нохунакҳо
console.log('Одинарные тоже можно');
console.log(2026);                 // рақам — бе нохунакҳо
console.log(7 * 8);                // JavaScript худаш ҳисоб мекунад: 56
console.log(100 - 35);             // 65

"5" аз 5 чӣ фарқ дорад? Дар нохунакҳо — матн (сатр), бе нохунакҳо — рақам. Барои одам яксон аст, барои барнома не. Муфассал дар дарси оянда шарҳ медиҳем, ҳоло дар хотир доштан кифоя аст: нохунакҳо = матн.

Якчанд қимат дар як log

Бо вергул дар console.log ҳар қадар қимат додан мумкин аст: консол онҳоро дар як сатр бо фосила мебарорад. Ин хеле қулай аст: тавзеҳ дар чап, қимат дар рост.

console.log("Урок " + 1 + ": старт курса");
console.log("MakeFirstStep" + " " + "2026");

Маслиҳат

Дар матни оддӣ баъзан худи нохунакҳо лозиманд. Агар дар дохили калима апостроф ё нохунак бошад, нохунаки навъи дигарро гиред: "It's a plov" ё 'Он сказал "Салом"'. Барои гузаштан ба сатри нав дар дохили матн аломати \n ҳаст. Боқиро баъдтар меомӯзем.

warn, error, info, table

Консол «овозҳои» гуногун дорад. Дар консоли воқеии браузер онҳо гуногун менамоянд: warn — сатри зард, error — сурх, info — оддӣ бо нишона, table бошад ҷадвал мекашад.

console.log("Обычное сообщение");
console.info("Информация: курс начался");
console.warn("Предупреждение: осталось мало риса");
console.error("Ошибка: казан сломан");
console.table(["самбуса", "курутоб", "чой"]);
Дар браузери шумо ин чӣ тавр менамояд

Дар равзанаи иҷрои ин саҳифа ҳама чиз бо сатрҳои оддӣ бароварда мешавад, то шумо натиҷаро бо намуна муқоиса карда тавонед. Дар консоли воқеӣ warn зард, error бошад сурх бо тугмаи кушодан хоҳад буд, ки аз куҷо даъват шудани паёмро нишон медиҳад. console.table ҷадвали воқеиро бо сутунҳои «index» ва «Value» мекашад — консолро дар саҳифаи худ кушоед ва бубинед. Ҷадвалҳо махсусан он гоҳ муфиданд, ки маълумоти зиёди яксонро мебароред (бо массивҳо ва объектҳо дар дарсҳои 6 ва 7 шинос мешавем).

Консол ҳамчун ҳисобкунак

Дар DevTools консолро бевосита низ истифода бурдан мумкин аст: ифодаро чоп кардед, Enter-ро пахш кардед — натиҷа гирифтед, бе console.log. Тири ↑ фармони қаблиро меорад, Shift + Enter сатрро бе иҷрои фармон мегузаронад. Санҷидани чизҳои хурд қулай аст: 2 ** 10, 17 % 5, "a" + "b".

Паёми хаторо мехонем

Сатри сурх ҳукм нест, балки ишорат аст. Дар он ҳамеша се қисм ҳаст:

  1. Навъи хато — SyntaxError (қоидаҳои навишт вайрон шудаанд: қавс ё нохунак намерасад), ReferenceError (калимаеро истифода мебаред, ки JavaScript намешиносад).
  2. Тавсиф — масалан, Console is not defined («Console муайян нашудааст») ё missing ) after argument list («пас аз аргументҳо ) намерасад»).
  3. Ҷой — номи файл ва рақами сатр, масалан script.js:3. Дар консоли воқеӣ ин истинод аст: пахш кардан маҳз ҳамин сатрро мекушояд.

Хондани ин се қисмро ёд гиред — ва нисфи хатоҳо дар як дақиқа ҳал мешаванд. Равзанаи иҷрои ин саҳифа низ ишора медиҳад: дар зери сатри сурх сатри шарҳдиҳанда бо забони русӣ пайдо мешавад.

console.log("Открываем чойхону");
console.log("Добавьте закрывающую кавычку);
console.log("Закрываем чойхону");
Хатоҳои имлоии маъмули навомӯзон
  • consol.log, console.lg, console.Log — хатои имло дар калима.
  • Нохунак ё қавси фаромӯшшуда: console.log("Салом).
  • Нохунакҳои гуногун дар аввал ва охир: "Салом'.
  • Матн бе нохунак: console.log(Салом) — JavaScript мепиндорад, ки Салом фармон аст.
  • Ҳарфҳои русӣ ба ҷои лотинӣ дар калимаи console (зоҳиран ҳамон с ва о, вале барои барнома дигаранд). Агар «ҳама чиз дуруст аст, вале кор намекунад» — калимаро аз нав нависед.
  • Вергули фаромӯшшуда байни қиматҳо ё нуқтаи зиёдатӣ.

Вақте ки JavaScript саҳифаро тағйир медиҳад, тағйиротро маҳз дар ин ҷо мебинед.

Ҷадвали Sources: файлҳо ва нуқтаҳои таваққуф

05 Равзанаҳо: alert, prompt, confirm

Консолро танҳо таҳиягар мебинад. Аммо баъзан лозим меояд, ки бо корбар сӯҳбат кард: паём нишон дод, ном пурсид, ҷавоби «ҳа» ё «не» гирифт. Браузер барои ин се равзанаи дарунсохт дорад. Онҳо «модалӣ» мебошанд: то даме ки равзана кушода аст, саҳифа яхбастааст ва чизи дигар пахш кардан мумкин нест.

Ин мисолҳоро дар компютери худ иҷро кардан лозим мешавад

Коди ин саҳифа дар дохили «қуттии рег»-и ҷудошудаи браузер кор мекунад ва он равзанаҳои модалиро манъ мекунад: alert, prompt ва confirm дар ин ҷо танҳо нодида гирифта мешаванд. Бинобар ин блокҳои зерин — танҳо барои хондан. Онҳоро ба script.js-и худ нусха бардоред (пас аз танзими муҳит дар бахши 6) ва дар саҳифаи худ санҷед.

alert — паём нишон медиҳем

alert("Салом, MakeFirstStep!");

Равзана бо матн ва як тугмаи «OK». Чизе бозпас намегардонад: танҳо нишон медиҳад ва интизор мешавад.

prompt — аз корбар мепурсем

prompt("Как вас зовут?");                // равзана бо майдони воридкунӣ
prompt("В каком вы городе?", "Душанбе"); // аргументи дуюм — қимати пешфарз

Равзанаро бо майдони воридкунӣ ва тугмаҳои «OK» ва «Отмена» (Бекор кардан) нишон медиҳад. prompt чиро бозпас мегардонад:

  • агар OK пахш шуда бошад — он чизе, ки ворид шуд, ҳамеша ҳамчун сатр (ҳатто агар рақам чоп карда бошед);
  • агар «Отмена» ё Esc пахш шуда бошад — қимати махсуси null («ҳеҷ чиз»).

confirm — мепурсем «ҳа ё не»

confirm("Вы точно хотите удалить заказ?");

Равзана бо савол ва тугмаҳои «OK» ва «Отмена». Агар OK пахш шавад, true («ҳа»), агар «Отмена» бошад, false («не») бозпас мегардонад. Бо ин ҷавоб чӣ кор кардан — вақте интихоб мекунем, ки шартҳоро биомӯзем (дарси 3).

Ҷавобро фавран, бе тағйирёбанда истифода мебарем

Тағйирёбандаҳоро ҳоло намедонем (ин дарси 2 аст), аммо ҷавоби prompt-ро аллакай истифода бурдан мумкин аст — як даъватро ба дохили дигаре гузошта. Аввал JavaScript он чиро иҷро мекунад, ки дар дохили қавсҳо аст, баъд натиҷаро истифода мебарад.

alert("Салом, " + prompt("Как вас зовут?") + "!");
  1. Даъвати дохилӣ иҷро мешавад: равзанаи «Как вас зовут?» (Номатон чист?) кушода мешавад, шумо «Мадина»-ро ворид мекунед.
  2. prompt сатри "Мадина"-ро бозпас мегардонад.
  3. "Салом, " + "Мадина" + "!" часпонида мешавад.
  4. alert-и беруна Салом, Мадина!-ро нишон медиҳад.

Дом: prompt сатр бозпас мегардонад

Агар аз корбар ду рақам пурсида, ҷавобҳоро бо аломати + ҷамъ кунед, часпонидан ҳосил мешавад, на маблағ: "7" + "5" натиҷаи "75" медиҳад. Барои табдил додани сатр ба рақам функсияи Number(...)-ро истифода баред. Ин «дом»-ро ҳатто дар ин ҷо, бе равзанаҳо санҷидан мумкин аст — ба ҷои ҷавобҳои корбар сатрҳои тайёрро мегузорем:

console.log("7" + "5");                    // часпонидани сатрҳо
console.log(Number("7") + Number("5"));    // ба рақамҳо табдил додем ва ҷамъ кардем

alert(Number(prompt("Первое число")) + Number(prompt("Второе число")));
Ташбеҳ аз зиндагӣ

Ин мисли анкета дар бонк аст: шумо рақамҳоро бо дасти худ менависед, оператор бошад онҳоро ба компютер ворид мекунад. То даме ки рақамҳо танҳо дар коғазанд (дар сатр), бо онҳо ҳисоб кардан мумкин нест. Аввал бояд «ворид кард» (Number(...)), баъд ҷамъ кард.

Чаро дар лоиҳаҳои воқеӣ ин қариб истифода намешавад
  • Равзанаҳо тамоми саҳифаро басташуда мекунанд, дар ҳамаи сайтҳо яксон менамоянд ва корбарро метарсонанд.
  • Онҳоро бо услубҳои сайт ороиш додан мумкин нест: ранг кардан, ҷонбахшӣ, кашола кардан.
  • Браузер ба корбар имкон медиҳад «Дигар диалогҳоро нишон надиҳед»-ро фаъол кунад, пас аз он код хомӯшона кор карданро бас мекунад.
  • Ба ҷои онҳо дар сайтҳо шаклҳо, равзанаҳои модалии аз HTML сохташуда ва огоҳиҳо истифода мешаванд — инро мо дар модулҳои 2 ва 3 меомӯзем.

Аммо барои омӯзиш ва санҷиши зуди ғояҳо alert ва prompt беҳтаринанд: чизеро тарроҳӣ кардан лозим нест.

Шарт ва маҳдудиятҳо давра ба давра тағйир меёбанд — навҳояшро дар сайт бинед.

Дар JavaScript ЗС аксар вақт дар куҷо хато мекунад

  • Фармонҳоро меандешад. Усул ё функсияеро пешниҳод мекунад, ки дар JavaScript нест (масалан, console.print), — боварибахш садо медиҳад, дар консол бошад хатои сурх.
  • Забонҳоро омехта мекунад. Сохторҳоро аз Python ё забони дигар меорад, зеро «монанд аст».
  • Баромадро нодуруст пешбинӣ мекунад. Бо боварӣ менависад «ин код 4-ро мебарорад», ҳол он ки 22 мебарорад. ЗС коди шуморо иҷро намекунад — тахмин мекунад.
  • Вазифаи нодурустро ҳал мекунад. Шумо як чизро хоста будед, ӯ монандашро ҳал кард, боз чизи зиёдатӣ илова кард.
  • Усулҳои кӯҳна ё ҳалҳои хеле мураккабро истифода мебарад, ки шарҳ дода наметавонед.

Худатон санҷед: ёрдамчии ЗС метавонист бигӯяд «"2" + 2 4 медиҳад». Иҷро кунед ва бовар кунед, ки кӣ дуруст аст — консол ё ЗС:

Танзими муҳитро анҷом диҳед, тасдиқро фиристед ва панҷ вазифаи хурдро бо console.log, alert ва prompt ҳал кунед. Қисми 1. Муҳити корӣ (скриншотҳо)

  • ☐ VS Code насб шудааст, ҷузвдони mfs-js кушода аст, lesson-01/index.html ва script.js намоёнанд.
  • ☐ Live Server, Prettier ва GitHub Copilot насб шудаанд, Auto Save ва Format On Save фаъоланд.
  • ☐ Вуруд ба GitHub аз VS Code анҷом дода шудааст, Copilot ишораҳо нишон медиҳад.
  • ☐ Live Server саҳифаро мекушояд, дар ҷадвали Console паёмҳои шумо намоёнанд.
  • ☐ Дархост ба GitHub Student Pack фиристода шудааст (скриншоти мактуб ё саҳифаи ҳолат) — ё шумо шарҳ додаед, ки чаро мувофиқ нестед.

Як скриншот бояд ҳама чизро якбора нишон диҳад: равзанаи VS Code бо script.js-и кушода ва панели паҳлӯӣ, дар паҳлӯяш — браузер бо саҳифа ва консоли кушода бо паёмҳои шумо. Беҳтар аст ду скриншот бошад: алоҳида VS Code (бо нишонаи Copilot) ва алоҳида браузер.

Қисми 2. Панҷ вазифа

  1. Корти зиёратӣ (console.log). Панҷ сатр бароред: ном, шаҳр, соли таваллуд, курс, хӯроки дӯстдошта. Дар сатри синну сол синну солро бо ифода ҳисоб кунед: 2026 - соли_таваллуди_шумо (рақамро худатон гузоред).
  2. Ҳисоб дар мағоза (console.log бо якчанд қимат). Се мол бо нарх ва миқдор. Дар ҳар сатр: ном, миқдор, аломати = ва маблағи бо ифода ҳисобшуда. Дар охир — натиҷа, он низ ҳисобшуда. Як сатр — як console.log бо якчанд қимат бо вергул.
  3. Салом (alert). alert-ро бо салом ба гурӯҳ нишон диҳед, баъд alert-и дуюмро бо матни ду сатр (гузаштан ба сатри нав — аломати \n дар дохили матн).
  4. Шиносоӣ (prompt + alert). Ном ва шаҳрро бо ду prompt бипурсед ва бо як alert нишон диҳед: Салом, Ном аз Шаҳр!. Ишора: ду prompt-ро дар як часпонидани сатрҳо гузоштан мумкин аст.
  5. Масоҳат (prompt + Number + confirm). Дарозӣ ва бари росткунҷаро бо ду prompt бипурсед, ҷавобҳоро тавассути Number ба рақам табдил диҳед ва масоҳатро тавассути alert нишон диҳед. Баъд confirm("Показать периметр?")-ро бипурсед ва ҷавобро (true ё false) тавассути console.log бароред. Периметрро нишон додан лозим нест, шартҳоро ҳанӯз наомӯхтаем.

Бонус (ихтиёрӣ, бе балл): ягон сатрро бо се роҳ бароред — console.log, console.warn, console.error — ва скриншоти намуди онҳоро дар консоли воқеӣ гиред. Ва боз кӯшиш кунед console.table(["самбуса", "курутоб", "чой"])-ро бароред.

✓ Варақаи хулосаи дарс

  • Нақшҳо: HTML — дар саҳифа чӣ ҳаст, CSS — чӣ тавр менамояд, JavaScript — чӣ рӯй медиҳад. JS аллакай дар браузер дарунсохт аст (муҳаррики V8 дар Chrome ва Edge).
  • Код чӣ тавр хонда мешавад: аз боло ба поён, сатр ба сатр. Регистр муҳим аст. Хато дар сатр — боқӣ иҷро намешавад.
  • Пайвастшавӣ: <script src="script.js" defer></script> дар <head> — стандарти мо. Теги пӯшанда ҳатмист. Бе defer скрипт дар <head> пештар аз саҳифа иҷро мешавад. Inline — танҳо барои санҷишҳо. Агар src бошад, коди дохили тег нодида гирифта мешавад.
  • Консоли холӣ? Роҳро дар src, регистри ҳарфҳо, васеъшавии файл (.js, на .js.txt), захира шудани файл, ҷадвали Network (200 ё 404), нав кардан бе кэш: Ctrl/Cmd + Shift + R-ро санҷед.
  • Консол: console.log(...) — якчанд қимат бо вергул бо фосила бароварда мешаванд; warn — огоҳӣ, error — хато, table — ҷадвал. Матн дар нохунакҳо, рақамҳо бе нохунак. Арифметика: + - * / % **, қавсҳо, қисми касрӣ — бо нуқта.
  • Хатоҳо: навъ (SyntaxError, ReferenceError) + тавсиф + файл ва сатр. Паёми сурхро бихонед, тахмин накунед. Сабабҳои маъмул: хатои имлоӣ дар console/log, регистр, нохунак ё қавси фаромӯшшуда, матн бе нохунак.
