Ҳолати барнома ва localStorage

Шумо рӯйхати корҳо навиштед, ҷадвали браузерро бастед — ва ҳама чиз гум шуд. Барои корбар ин фалокат аст: ӯ даҳ дақиқа сарф кард, аммо сайт ҳама чизро фаромӯш кард. Дар барномаҳои воқеӣ сабади мағозаи интернетӣ, мавзӯи торик ва дарси нохондашуда аз нав бор шудани саҳифа мегузаранд. Имрӯз шумо ҳамаи маълумоти барномаро дар як ҷо нигоҳ доштан, экранро аз рӯи ин маълумот кашидан ва онро дар браузер захира кардан меомӯзед.

  • Ҳолати барномаро бо як объект тавсиф кардан ва аз маълумоти «ҳосилшуда» фарқ кардан
  • Функсияи render(state)-ро навиштан, ки экранро танҳо аз рӯи ҳолат мекашад
  • Ҳолатро тавассути функсияҳои хурди амал тағйир додан: илова кардан, қайд кардан, нест кардан
  • Маълумотро тавассути localStorage якҷоя бо JSON.stringify ва JSON.parse захира кардан ва хондан
  • Вақте маълумот нест, вайрон ё кӯҳна аст, афтода намондан
  • Аз ЗС хоҳиш кардан, ки сохтори ҳолатро пешниҳод кунад ва онро бо сохтори худ муқоиса кардан
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди дар заминаи торик бо тугмаи ▶ Запустить — зинда аст: тағйир диҳед ва иҷро кунед. Блокҳои «Амалиёт» худкор аз рӯи матн дар консол санҷида мешаванд. Дар якчанд вазифа саҳифаи хурд бо пешнамоиш ҳаст: дар чап код (ҷадвалҳои index.html, style.css, script.js), дар рост натиҷа. Ишораҳо пинҳон шудаанд — аввал худатон кӯшиш кунед.

Муҳим дар бораи localStorage. Коди ин саҳифа дар «қуттии санҷиш»-и ҷудо кор мекунад, ки дар он localStorage-и воқеӣ нест. Мо инро дар бахши 04 муфассал таҳлил мекунем ва ба шумо ивазкунаки дақиқро бо ҳамон API медиҳем. Дар компютери шумо (дар вазифаи хонагӣ) шумо воқеиро истифода мебаред.

01 Ҳолати барнома чист

Ҳолат (state) — ин ҳамаи маълумотест, ки барномаро ҳамин ҳозир тавсиф мекунанд ва метавонанд тағйир ёбанд: рӯйхати вазифаҳо, кадомашон иҷро шудаанд, филтри интихобшуда, мавзӯи тарҳ, маҳсулот дар сабад. Агар аз ҳолат «акс» гиред, аз рӯи он он чиро, ки корбар мебинад, пурра барқарор кардан мумкин аст.

Муқоиса аз ҳаёт

Лавҳа дар истгоҳи автобус дар Душанбе. Худи лавҳа чизеро «дар хотир надорад»: он танҳо ҷадвалеро нишон медиҳад, ки дар системаи диспетчер аст. Рейси Хуҷандро бекор карданд — диспетчер сабтро иваз кард, ва лавҳа аз нав кашида шуд. Ҷадвал дар система — ин ҳолат аст. Лавҳа — экран. Агар касе навиштаи лавҳаро дастӣ, системаро нарасонда, ислоҳ мекард, ҳангоми навсозии навбатӣ ислоҳ нест мешуд, ва дар толор бетартибӣ оғоз мегардид.

Навомӯзон чӣ тавр мекунанд: маълумот «пароканда» аст

Аввалин чизе, ки ба хотир меояд — барои ҳар хурдакорӣ тағйирёбандаи алоҳида сохтан, ва қисми маълумотро умуман он чизе ҳисоб кардан, ки дар саҳифа навишта шудааст. Чунин код зуд ба бесаранҷомӣ табдил меёбад:

let ownerName = "Мадина";
let balance = 150;
let operations = 2;
let lastOperation = "пополнение";

function showWallet() {
  console.log(`${ownerName}: ${balance} сомони, операций: ${operations}, последняя — ${lastOperation}`);
}

showWallet();

То даме ки тағйирёбандаҳо чортоянд, ин тоқатпазир аст. Аммо вақте бист шуданд, ба саволҳои оддӣ ҷавоб додан мумкин нест: маҳз чиро захира кардан лозим? Чиро ба функсия додан? Ҳангоми баромадани корбар чиро тоза кардан?

Дар лоиҳаҳои воқеӣ чӣ тавр мекунанд: як объект

Ҳамаи маълумоти тағйирёбандаи барномаро дар як объект мегузоранд — одатан онро state меноманд.

const state = {
  ownerName: "Мадина",
  balance: 150,
  history: ["пополнение", "покупка"],
};

function showWallet(state) {
  const last = state.history[state.history.length - 1];
  console.log(`${state.ownerName}: ${state.balance} сомони, последняя операция — ${last}`);
}

showWallet(state);
console.log(JSON.stringify(state)); // тамоми барнома — бо як нигоҳ

Фоидаҳо фавран намоёнанд: функсияҳо state-ро мегиранд ва дигар чизеро намеҷӯянд; «чиро захира кардан» — ин танҳо state аст; ислоҳ осонтар аст — кифоя аст як объектро чоп кунед ва тамоми барномаро бубинед.

Чиро ба ҳолат гузоштан лозим, чиро не

Дар ҳолат далелҳои аслӣ-ро нигоҳ медоранд, ки онҳоро аз маълумоти дигар баровардан мумкин нест. Ҳар чизеро, ки аз ҳолат ҳисоб кардан мумкин аст, дар он нигоҳ доштан лозим нест — ин маълумоти ҳосилшуда аст.

Зиёдатӣ дар ҳолат

Ҷамъ ва ҳисобкунак аз рӯйхат «алоҳида зиндагӣ мекунанд» — яктоашро нав кардан осон фаромӯш мешавад, ва онҳо ихтилоф мекунанд.

const state = {
  items: [{ title: "Самбуса", price: 5, qty: 3 }],
  total: 15,        // ҳисоб кардан мумкин аст
  itemsCount: 1,    // ҳисоб кардан мумкин аст
};
Танҳо далелҳо

Дар ҳолат — маҳсулот. Ҷамъро функсия ҳисоб мекунад, ва он ҳамеша ба рӯз аст.

const state = {
  items: [{ title: "Самбуса", price: 5, qty: 3 }],
};
const getTotal = (state) =>
  state.items.reduce((sum, i) => sum + i.price * i.qty, 0);
Ба ҳолат
Рӯйхати вазифаҳо, филтри интихобшуда, мавзӯъ, маҳсулот дар сабад, номи корбар, рақами қадами ҷорӣ.
На ба ҳолат
Ҷамъи сабад, шумораи вазифаҳои иҷрошуда, сатрҳои тайёри HTML — ҳар чизе ки аз ҳолат ҳисоб кардан мумкин аст.
Бошуурона қарор медиҳем
Чизҳои муваққатӣ мисли матни дар майдон чопшаванда. Онҳоро дар ҳолат нигоҳ доштан мумкин аст, ё захира накардан — дар ин бора боз дар бахши ЗС сухан меронем.
Хатои маъмул

Нусха кардани адад аз ҳолат ба тағйирёбандаи маҳаллӣ ва тағйир додани нусха. Адад ва сатрҳо бо қимат нусха мешаванд: нусхаро тағйир додем — ҳолат бетағйир монд.

const state = { visitors: 10 };

let visitors = state.visitors; // ададро нусха кардем
visitors = visitors + 1;       // нусхаро тағйир додем

console.log(visitors);         // → 11
console.log(state.visitors);   // → 10 — дар ҳолат чизе тағйир наёфт

миёна

const state = { visitors: 0 };

function addVisitor(state) {

Ишора 2

02 Рендер аз ҳолат: render(state)

Ғояи навбатӣ — аз ҳама муҳим дар дарс. Экран зиндагии худро намекунад: он ҳар дафъа аз нав аз рӯи ҳолат кашида мешавад. Барои ин функсияи render-ро менависанд. Он ҳолатро мегирад ва нишон медиҳад. Дигар чизе намекунад: чизеро тағйир намедиҳад ва чизеро ҳал намекунад.

Барои он ки ҳоло ба HTML парешон нашавем, «экран» дар мисоли аввал консол мешавад:

const state = {
  todos: [
    { id: 1, text: "Купить нон", done: true },
    { id: 2, text: "Сделать домашку по JS", done: false },
  ],
};

function render(state) {
  console.log("--- Список дел ---");
  state.todos.forEach((todo) => {
    const mark = todo.done ? "[x]" : "[ ]";
    console.log(`${mark} ${todo.text}`);
  });
}

render(state);

Акнун ҳамин чиз дар саҳифаи воқеӣ. Ба сохтори скрипт диққат диҳед: дар боло ҳолат, баъд render, баъд амал ва коркардкунандаи клик. «Добавить блюдо»-ро пахш кунед ва бубинед, ки рӯйхат чӣ тавр тағйир меёбад:

<button id="add">Добавить блюдо</button>
<ul id="menu"></ul>
<p id="info"></p>

ul { padding-left: 20px; }
li { margin: 4px 0; }
#info { color: #6b7280; }

const menu = document.querySelector("#menu");
const info = document.querySelector("#info");
const addBtn = document.querySelector("#add");

// 1. Ҳолат
const state = {
  dishes: ["Оши палав", "Самбуса"],
};
const NEXT = ["Курутоб", "Шакароб", "Манту", "Чакка"];

// 2. Рендер: экранро аз рӯи ҳолат мекашад
function render() {
  menu.textContent = ""; // рӯйхатро пок кардем
  state.dishes.forEach((name) => {
    const li = document.createElement("li");
    li.textContent = name;
    menu.append(li);
  });
  info.textContent = `Блюд в меню: ${state.dishes.length}`;
}

// 3. Амал: ҳолатро тағйир медиҳад ва аз нав кашиданро талаб мекунад
addBtn.addEventListener("click", () => {
  const next = NEXT[state.dishes.length - 2];
  if (next) state.dishes.push(next);
  render();
});

render();
console.log("блюд в состоянии:", state.dishes.length);

Қоидаҳои render-и хуб

  1. Танҳо ҳолатро мехонад. Маълумотро барои экран аз state мегирем, на аз DOM. Не list.children.length, балки state.todos.length.
  2. Чизеро тағйир намедиҳад. Дар дохили render push, state.x = … ва дигар тағйироти маълумот нест.
  3. Ҳамаро пурра мекашад. Контейнерро пок кардем ва аз нав сохтем. Барои рӯйхатҳо аз даҳҳо элемент ин фаврист, ва хатоҳо камтар: фикр кардан лозим нест, «маҳз чӣ тағйир ёфт».
  4. Баъди ҳар амал даъват мешавад. Ҳолатро тағйир додем — render()-ро даъват кардем. Фаромӯш кардем — экран «дурӯғ мегӯяд».
  5. Ҳолати холиро кашида метавонад. Агар вазифаҳо набошанд, «Список пуст»-ро нишон медиҳем, на холигии сафед.
Муқоиса аз ҳаёт

Ошпаз дар чойхона фармоишро аз рӯи чек ҷамъ мекунад, на аз рӯи хотира. Фармоиш тағйир ёфт — ба чек нигоҳ кард ва аз нав тайёр кард. Чек — ин ҳолат аст. Таом дар миз — экран. Бо чек баҳс кардан беҳуда аст: агар дар чек «бе пиёз» бошад, пиёз намешавад.

Ду сарчашмаи ҳақиқат

Шумораи вазифаҳо ҳам дар массив ва ҳам «дар саҳифа» нигоҳ дошта мешавад. Яктоашро нав кардан фаромӯш шуд — онҳо ихтилоф мекунанд.

// ❌ маълумотро аз DOM мегирем
const count = list.children.length;
if (count >= 5) {
  alert("Слишком много задач");
}
Як сарчашмаи ҳақиқат

Ҳақиқат — дар state. DOM — танҳо инъикоси он.

// ✓ маълумотро аз ҳолат мегирем
if (state.todos.length >= 5) {
  alert("Слишком много задач");
}
Хатои маъмул

Маълумотро тағйир додан ва фавран экранро дастӣ «ислоҳ кардан» (li.textContent = …, li.remove()) дар ҳар коркардкунанда. То даме ки элемент як аст — кор мекунад. Вақте филтрҳо, ҳисобкунакҳо ва захиракунӣ пайдо мешаванд, шумо гоҳ яктояшро, гоҳ дигаронро нав кардан фаромӯш мекунед. state-ро тағйир медиҳем, render()-ро даъват мекунем — ва тамом.

ВАЗИФАИ 2.3

Хаторо ёб: аз нав кашиданро фаромӯш кардем

миёна

Баъди илова кардани вазифаҳо экран кӯҳна мемонад. Кодро чунон ислоҳ кунед, ки render баъди ҳар амал даъват шавад — аммо даъватро як маротиба, дар дохили addTodo навиштан лозим, на баъди ҳар даъвати беруна.

const state = { todos: [{ id: 1, text: "Хлеб", done: false }] };

function render(state) {
  console.log("--- Экран ---");
  state.todos.forEach((todo) => console.log(`${todo.done ? "[x]" : "[ ]"} ${todo.text}`));
}

function addTodo(text) {
  state.todos.push({ id: state.todos.length + 1, text, done: false });
}

render(state);
addTodo("Молоко");
addTodo("Чой");

03 Амалҳо: ҳолатро чӣ тавр дуруст тағйир додан

Ҳолатро функсияҳои хурди амал (actions) тағйир медиҳанд: addTodo, toggleTodo, removeTodo. Коркардкунандаҳои ҳодисаҳо худашон ба маълумот намедароянд — онҳо танҳо амали лозимиро даъват мекунанд. 04 localStorage: хотираи браузер

Ҳоло тамоми ҳолат дар тағйирёбанда зиндагӣ мекунад. Саҳифаро нав кардед — тағйирёбандаҳо аз нав сохта мешаванд, ва ҳолат сифр мешавад. Барои он ки маълумот аз нав бор шудан гузарад, онро ба ҷое гузоштан лозим аст, ки бо саҳифа гум намешавад. Барои ин браузер localStorage дорад — анбори хурди «калид → сатр», ки ба сайт вобаста аст.

Муқоиса аз ҳаёт

Анбори ашё дар вокзал. Шумо ҷомадонро месупоред ва рақамча мегиред. Меравед, дар шаҳр сайр мекунед, рӯзи дигар бармегардед — ҷомадон ба ҷояш. Рақамча — ин калид, ҷомадон — қимат. Аммо ба ин анбор танҳо ашёи бастабандишударо гузоштан мумкин аст: localStorage танҳо сатрҳоро мегирад. Ҳама чизи дигарро бояд бастабандӣ кард — дар ин бора дар зер.

Дар бораи localStorage чиро бояд донист

  • Ҷуфтҳои «калид — сатр»-ро нигоҳ медорад. Калидҳо низ сатранд.
  • Маълумот ҳангоми аз нав бор шудани саҳифа, бастани ҷадвал ва ҳатто аз нав оғоз кардани браузер нест намешавад.
  • Ҳар сайт анбори худро дорад: makefirststep.tj маълумоти example.com-ро намебинад.
  • Ҳаҷм — тақрибан 5 МБ барои як сайт: барои рӯйхати корҳо ё танзимот ин бо захира кифоя аст.
  • Корбар метавонад онро дар танзимот пок кунад ё дастӣ дар DevTools тағйир диҳад. Ба маълумоти аз он гирифташуда бовар кардан мумкин нест, ҳамон тавр ки ба воридот дар шакл.
  • Дар он ҷо паролҳо ва асрорро нигоҳ надоред: ҳар скрипт дар саҳифа метавонад онҳоро бихонад.

Тамоми коди ин саҳифа дар тирезаи ҷудогона-«қуттии санҷиш» иҷро мешавад — мо ҳамин тавр компютери шуморо аз коди тасодуфии зараровар муҳофизат мекунем. Чунин тиреза «сайти худро» надорад, бинобар ин браузер дастрасии онро ба localStorage манъ мекунад. Худатон санҷед:

localStorage.setItem("theme", "dark");
console.log(localStorage.getItem("theme"));

Хатои дастрасӣ — гуноҳи шумо нест ва хатои дарс нест. То шумо ҳамоно машқ карда тавонед, мо ивазкунак медиҳем: объекти storage бо ҳамон усулҳои setItem, getItem, removeItem, clear. Он маълумотро дар хотира то даме ки коди шумо кор мекунад, нигоҳ медорад. Ва барои он ки «аз нав бор кардани саҳифа»-ро дар қуттии санҷиш ҳам нишон додан мумкин бошад, мо функсияи оғози барномаро якчанд маротиба пай дар пай дар як скрипт даъват мекунем: анбор мемонад, аммо тағйирёбандаҳои барнома не.

// ── ивазкунаки localStorage ─────────────────────────────────────
// Дар қуттии санҷиш localStorage-и воқеӣ дастнорас аст — дар компютери шумо
// window.localStorage-ро истифода баред. Боқимонда код тағйир намеёбад.
function createStorage() {
  let data = {};
  return {
    getItem(key) {
      return Object.hasOwn(data, key) ? data[key] : null;
    },
    setItem(key, value) {
      data[key] = String(value); // мисли воқеӣ: ҳама чиз ба сатр табдил меёбад
    },
    removeItem(key) {
      delete data[key];
    },
    clear() {
      data = {};
    },
  };
}
const storage = createStorage();

Тамоми кодро дар дарс тавассути тағйирёбандаи storage нависед. Дар компютери шумо, дар файли оддии HTML, кифоя аст ивазкунакро бо як сатр иваз кунед — боқимонда бе тағйирот кор мекунад:

Ҳама чиз ба сатр табдил меёбад

Ин тузоқи асосӣ аст. Адад гузоштем — сатр гирифтем. Объект гузоштем — матни "[object Object]" гирифтем.

function createStorage() {

05 JSON: ҳолатро ба сатр бастабандӣ мекунем

Бо JSON шумо дар дарси 7 шинос шудед. Дар ин ҷо он вазифаи мушаххасро ҳал мекунад: localStorage танҳо сатрҳоро мегирад, ва ҳолати мо — объект бо массивҳост. Бинобар ин пеш аз навиштан мо объектро ба сатр бастабандӣ мекунем (JSON.stringify), ва баъди хондан — боз мекунем (JSON.parse).

const state = {
  filter: "all",
  todos: [{ id: 1, text: "Купить нон", done: false }],
};

const raw = JSON.stringify(state);    // объект → сатр
console.log(raw);
console.log(typeof raw);              // → string

Муқоиса аз ҳаёт

Кӯч. Диванро якбора ба мошин ҷо намекунанд, бинобар ин онро ҷудо мекунанд, ба қуттиҳо мепечонанд ва мебаранд. Дар хонаи нав мувофиқи дастур боз ҷамъ мекунанд. stringify — «ҷудо кардан ва печонидан», parse — «ҷамъ кардан». Диван ҳамон аст, аммо ин аллакай нусхаи нави ҷамъшуда аст, на ҳамон худаш.

Ҷуфти функсияҳои saveState / loadState

То ки JSON.stringify ва setItem-ро дар даҳ ҷо нанависем, онҳоро дар ду функсия пинҳон мекунем. Тамоми барнома ба анбор танҳо тавассути онҳо муроҷиат мекунад:

const KEY = "todo-app:v1";   // калид: номи барнома + версияи формат

function saveState(state) {
  storage.setItem(KEY, JSON.stringify(state));
}

function loadState() {
  const raw = storage.getItem(KEY);
  return raw === null ? null : JSON.parse(raw);
}

Калид бо префикси todo-app: аз низоъ бо барномаҳои дигар дар ҳамон сайт муҳофизат мекунад, ва :v1 вақте лозим мешавад, ки шумо формати ҳолатро тағйир диҳед: версияи нав калиди навро хонда метавонад ва ба маълумоти кӯҳна пешпо нахӯрад.

Хатоҳои JSON

Қоидаҳои формат сахтанд: калидҳо ва сатрҳо танҳо дар нохунакҳои дугона, бе вергул баъди элементи охирин, бе шарҳҳо. Вайрон кардед — JSON.parse истиснои SyntaxError-ро мепартояд, ва барнома меафтад. Мо муқобилат кардани инро дар бахши навбатӣ меомӯзем.

06 Маълумоти холӣ, вайроншуда ва кӯҳнашуда

Коде, ки «вақте ҳама чиз хуб аст» кор мекунад, нисфи кор аст. Нисфи дигар — вақте маълумот нест, вайрон шудааст ё бо версияи кӯҳнаи барнома навишта шуда буд, чӣ мешавад. Бо localStorage чунин чиз пайваста рух медиҳад:

  • Оғози аввал. Корбар бори аввал омад — дар анбор холист, getItem null бармегардонад.
  • Хасу хошок. Касе сабтро дар DevTools ислоҳ кард, сабт қатъ шуд, барномаи дигар таҳти ҳамон калид чизи худро навишт.
  • Формати кӯҳна. Дирӯз дар ҳолат майдони filter набуд, имрӯз шумо онро илова кардед, ва дар браузери корбар акси дирӯза мемонад.
Муқоиса аз ҳаёт

Анбор дар курс пеш аз оғози машғулот. Маъмур ҷевонро барои маркерҳо мекушояд: мабодо ҷевон холӣ бошад (рӯзи аввал), маркерҳо хушк шуда бошанд (маълумоти вайроншуда) ё ба ҷои онҳо стикерҳо аз семестри гузашта бошанд (формати кӯҳна)? Маъмури хуб воҳима намекунад: вай маҷмӯаи эҳтиётӣ дорад. Маҷмӯаи эҳтиётӣ дар код — ин ҳолати пешфарз аст.

Анбори холӣ

Агар калид набошад, getItem null бармегардонад. Инро ошкоро санҷед ва ҳолати пешфарзро баргардонед:

function createStorage() {
  let data = {};
  return {
    getItem: (key) => (Object.hasOwn(data, key) ? data[key] : null),
    setItem: (key, value) => { data[key] = String(value); },
    removeItem: (key) => { delete data[key]; },
    clear: () => { data = {}; },
  };
}
const storage = createStorage();

const KEY = "todo-app:v1";
const DEFAULT_STATE = { nextId: 1, todos: [] };

function loadState() {
  const raw = storage.getItem(KEY);
  if (raw === null) return { ...DEFAULT_STATE, todos: [] }; // оғози аввал
  return JSON.parse(raw);
}

console.log(JSON.stringify(loadState())); // анбор холӣ аст

Ба { ...DEFAULT_STATE, todos: [] } диққат диҳед: мо нусхаи пешфарзро бармегардонем, на худи объектро. Вагарна ҳамаи тағйирот ба «маҷмӯаи эҳтиётӣ» меафтад, ва ҳангоми барқароркунии навбатӣ он аллакай холӣ нахоҳад буд.

JSON-и вайроншуда: try / catch

Агар дар анбор сатре бошад, ки JSON-и дуруст нест, JSON.parse истисно мепартояд. Онро тавассути try / catch мегиранд (шумо инро дар дарси 7 дидед) ва ба ҳолати пешфарз бармегарданд:

function safeParse(raw) {
  try {
    return JSON.parse(raw);
  } catch (error) {
    console.log("Данные повреждены:", error.name);
    return null;
  }
}

console.log(safeParse('{"ok":true}'));  // → { ok: true }
console.log(safeParse("{oops"));        // → Данные повреждены: SyntaxError, потом null

Шакли нодуруст: месанҷем, ки дар дохил чӣ ҳаст

Сатр метавонад JSON-и дуруст бошад, аммо тамоман на он чизе, ки мо интизор будем: адади 42, сатр, null, объект ба ҷои массив. Бинобар ин баъди parse шакли маълумотро месанҷем:

function isValidTodos(value) {
  return Array.isArray(value);
}

console.log(isValidTodos([]));            // → true
console.log(isValidTodos({ a: 1 }));      // → false — объект, на массив
console.log(isValidTodos(JSON.parse("42"))); // → false — адад
console.log(isValidTodos(JSON.parse("null"))); // → false
Тузоқи ҷолиб

JSON.parse(null) намеафтад, балки null бармегардонад — зеро null аввал ба сатри "null" табдил меёбад, ва ин JSON-и дуруст аст. Дар натиҷа JSON.parse(storage.getItem(key)) ҳангоми анбори холӣ «кор мекунад», аммо null бармегардонад, ва аллакай сатри навбатии state.todos бо TypeError меафтад. Бинобар ин санҷиши raw === null ҳамеша лозим аст.

Ҳолат кӯҳна шуд: қиматҳои пешфарзро омехта мекунем

Вақте дар ҳолат майдонҳои нав пайдо мешаванд, аксҳои кӯҳна онҳоро надоранд. Ҳал — аз ҳолати пешфарз оғоз кардан ва он чиро, ки дар анбор ёфтем, болои он «гузоштан»:

// → майдонҳои filter ва theme бо пешфарз гирифта шуданд, todos — аз захирашуда

Ҳама чиз якҷоя: loadState-и боэътимод

  1. Сатрро баровардем тавассути getItem. Агар null — ҳолати пешфарзро баргардонем.
  2. Кушодем дар дохили try / catch. Хато — ҳолати пешфарзро баргардонем.
  3. Шаклро санҷидем: ин умуман объект аст (на адад, сатр, null, массив)? Не — ҳолати пешфарз.
  4. Омехтем қиматҳои пешфарзро барои майдонҳои намерасида ва майдонҳои муҳимро санҷидем: масалан, todos бояд массив бошад.
function loadState() {
  const raw = storage.getItem(KEY);
  if (raw === null) return createDefaultState();     // 1. холӣ

  let saved;
  try {
    saved = JSON.parse(raw);                         // 2. JSON-и вайроншуда
  } catch {
    return createDefaultState();
  }

  if (typeof saved !== "object" || saved === null || Array.isArray(saved)) {
    return createDefaultState();                     // 3. ин объекти ҳолат нест
  }

  const state = { ...createDefaultState(), ...saved }; // 4. намерасидаро илова кардем
  if (!Array.isArray(state.todos)) state.todos = [];   //    ва майдони муҳимро таъмир кардем
  return state;
}

07 Блоки ЗС: талаб мекунем, ки сохтори ҳолатро пешниҳод кунад

Муҳимтарин лаҳза дар ҳар барнома — кадом маълумотро ва бо кадом намуд нигоҳ медоред. Хато дар ин ҷо гарон меояд: сохтори ҳолатро аз нав сохтан, вақте ки render, амалҳо ва захиракунӣ аллакай навишта шудаанд, — ҳамон аст, ки пойдевори хонаи тайёрро аз нав созем. Бинобар ин маҳз ба ин ҷо ЗС-ро ҷалб кардан мувофиқ аст — аммо ҳамчун андешаи дуюм, на ҳамчун муаллиф.

Қоидаҳои курс, ки дар ин ҷо махсусан муҳиманд

1) Аввал 15 дақиқа худатон: state-и худро дар коғаз ё дар код кашед. 2) Танҳо баъд промпт. 3) Коде, ки сатр ба сатр шарҳ дода наметавонед, ба лоиҳа ворид накунед. 4) Қарорро шумо қабул мекунед: ЗС пешниҳод мекунад, шумо муқоиса мекунед ва интихоб мекунед.

Тартиби кор

  1. Версияи худӣ. Барномаро бо як ҷумла тавсиф кунед ва объекти state-ро тарҳрезӣ кунед. Қайд кунед, ки аз он чиро дар localStorage захира мекунед.
  2. Промпт аз рӯи формула: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш.
  3. Муқоиса. Тафовутҳоро ба ҷадвал нависед: майдон — дар ман — дар ЗС — чӣ ҳал кардам ва чаро.
  4. Санҷиш. Барои ҳар ҷои баҳсбарангез аз худ бипурсед: «агар дар ин ҷо холӣ бошад ё хасу хошок бошад, чӣ мешавад?».

Промпти бад ва хуб

Фикр кун, ки маълумотро барои барномаи ман чӣ тавр нигоҳ дорам

Чаро бад аст: ЗС на барномаро медонад, на сатҳи шуморо, на ин ки маълумот дар куҷо нигоҳ дошта мешавад. Вай ё маслиҳати умумӣ медиҳад, ё фавран меъмории азимро дар фреймворке, ки шумо надоред.

Контекст: ман навомӯз ҳастам, бо JavaScript-и холис бе китобхонаҳо менависам, лоиҳаи таълимӣ — ҳисобкунаки одатҳо. Корбар метавонад одат илова кунад, онро имрӯз иҷрошуда қайд кунад, нест кунад ва филтри «ҳама / иҷронашуда»-ро иваз кунад. Маълумот бояд аз нав бор шудани саҳифа гузарад. Вазифа: сохтори объекти ҳолатро пешниҳод кун ва шарҳ деҳ, ки аз он чиро ба localStorage гузоштан лозим. Маҳдудиятҳо: танҳо сатрҳо, адад, қиматҳои булӣ, массивҳо ва объектҳо (он чи аз JSON мегузарад); он чиро, ки ҳисоб кардан мумкин аст, нигоҳ надор; ҳар одат id-и ягона дорад. Формати ҷавоб: аввал намунаи объекти state ҳамчун коди JS; баъд рӯйхати майдонҳо — ба ҳар сатр «майдон — чаро лозим»; баъд чиро захира мекунем ва чиро не. Санҷиш: 2 ҳолатро ном бар, ки дар онҳо маълумоти захирашуда метавонад нодуруст бошад, ва чӣ тавр бо онҳо мубориза бурдан.

Ин варианти густурдаи қолаби ёддошти курс аст: «Сохтори объекти ҳолатро барои барномаи [тавсиф] пешниҳод кун. Шарҳ деҳ, чаро чунин майдонҳо ва чиро ба localStorage гузорам». Мо контекст, маҳдудиятҳо ва санҷишро илова кардем — ва ҷавобе гирифтем, ки онро муқоиса кардан мумкин аст.

Чек-лист: ҷавоби ЗС-ро чӣ тавр санҷидан

  • Оё маълумоти ҳосилшуда нест. Агар дар ҳолат total, doneCount ё HTML-и тайёр бошад — онҳоро ҳисоб кардан мумкин аст, пас зиёдатианд.
  • id-ҳои ягона. Онҳо аз куҷо мегиранд? nextId ҳаст, ё ЗС length + 1-ро пешниҳод мекунад (мо дидем, ки он чӣ анҷом меёбад)?
  • Навъҳои оддӣ. Оё санаҳо, функсияҳо, undefined нестанд, ки аз JSON намегузаранд?
  • Чиро захира кардан. Оё муваққатиро захира кардан лозим — масалан, матни дар майдон ҳамин ҳозир чопшаванда? Аксар вақт не: баъди аз нав бор шудан он лозим нест.
  • Версияи формат. Оё ЗС калиди намуди app:v1-ро пешниҳод кард? Ҳангоми тағйири сохтор чӣ мешавад?
  • Маълумоти холӣ ва вайроншуда. ЗС аксар вақт оғози аввал ва маълумоти вайроншударо «фаромӯш мекунад» — инро худатон илова кунед.

08 Амалиёт дар дарс: рӯйхати корҳо, ки ҳамаро дар хотир дорад

Ҳамаро якҷоя ҷамъ мекунем: рӯйхати корҳо бо ҳолат, рендер, амалҳо ва захиракунӣ. Дар се марҳила мекунем, ва ҳар кадом бо санҷиш дар консол анҷом меёбад. Дар боло болои код — ҷадвалҳои index.html, style.css, script.js. Дар script.js ҳал мекунем: шарҳҳои TODO-ро ҷӯед.

Дар бораи «аз нав бор кардан» дар қуттии санҷиш

Аз нав бор кардани воқеии саҳифаро дар ин ҷо иҷро кардан мумкин нест: он ивазкунаки storage-ро низ нест мекунад. Бинобар ин сатрҳои поёни скрипт онро худашон тақлид мекунанд: экранро пок мекунанд, тағйирёбандаи state-ро фаромӯш мекунанд ва боз boot()-ро даъват мекунанд. Баъд аз ин танҳо он чизе зинда монда метавонад, ки дар storage аст — мисли браузери воқеӣ. Санҷиши худкори поёнро нарасонед.

Марҳилаи 1. Ҳолат, render ва амалҳо

Аввал бе захиракунӣ: як ҳолат, як функсияи render, амалҳои addTodo ва toggleTodo ва ду коркардкунанда. Шакл вазифа илова мекунад, клик ба вазифа «иҷро шуд»-ро иваз мекунад (вакилкунӣ аз дарси 9).

09 Вазифаи хонагӣ: ба лоиҳаи дарси 9 захиракуниро илова кунед

Лоиҳаи худро аз дарси 9 (саҳифаи интерактивӣ бо ҳодисаҳо ва вакилкунӣ) гиред ва ба он дар хотир доштани маълумот-ро омӯзонед. Дар ин ҷо шумо дар компютери худатон кор мекунед — яъне воқеии localStorage-ро истифода мебаред: const storage = window.localStorage;.

Чӣ бояд кард

  • Дар лоиҳа як ҳолат — объекти state ҳаст. Дар ҳеҷ ҷо маълумоте нест, ки танҳо дар DOM «зиндагӣ» мекунад.
  • Экранро функсияи render() мекашад. Коркардкунандаҳои ҳодисаҳо амалҳоро даъват мекунанд, ва онҳо — render()-ро.
  • saveState() ва loadState() ҳастанд; калид бо префикси лоиҳа ва версия, масалан myproject:v1.
  • Ҳолат баъди ҳар амал захира мешавад ва ҳангоми кушодани саҳифа барқарор мешавад: ҷадвалро бастем, дубора кушодем — ҳама чиз ба ҷояш.
  • loadState() аз инҳо мегузарад: анбори холӣ, JSON-и вайроншуда, шакли нодурусти маълумот ва майдонҳои нави намерасида.
  • Тугмаи «Сбросить» ҳаст, ки маълумоти барномаро пок мекунад (removeItem аз рӯи калиди шумо) ва ҳолати оғозиро бармегардонад.
  • Дар ҳолат маълумоти ҳосилшуда, функсияҳо ва объектҳои сана нестанд.

Кори худро чӣ тавр санҷидан

  1. Якчанд элемент илова кунед, саҳифаро нав кунед (F5) — ҳама чиз ба ҷояш?
  2. DevTools (F12) → Application → Local Storage-ро кушоед. Калиди худро ёбед, нигоҳ кунед, қимат чӣ гуна менамояд.
  3. Қиматро дастӣ вайрон кунед: қавси охиринро нест кунед. Саҳифаро нав кунед — барнома бояд бо ҳолати оғозӣ оғоз шавад, на бо хато дар консол биафтад.
  4. Калидро нест кунед — саҳифа бояд «мисли бори аввал» кушода шавад.
  5. «Сбросить»-ро пахш кунед — маълумот ҳам аз экран, ҳам аз анбор нест шуд?

✓ Ёддошти дарс

  • Ҳолат — ҳамаи маълумоти тағйирёбандаи барнома дар як объекти state. Танҳо далелҳои аслиро нигоҳ доштан; он чи ҳисоб кардан мумкин аст (ҷамъ, ҳисобкунак), бо функсия ҳисоб мекунем.
  • render(state) экранро пурра ва танҳо аз рӯи ҳолат мекашад: чизеро тағйир намедиҳад, маълумотро аз DOM намехонад, рӯйхати холиро кашида метавонад.
  • Давра: ҳодиса → амал (addTodo, toggleTodo, removeTodo) → state-ро тағйир додем → render() → saveState().
  • Массивҳо дар ҳолат: илова кардан — [...arr, item], тағйир додан — map, нест кардан — filter. Натиҷаро дубора ба state таъин мекунем. Id-ро аз nextId мегирем, на аз length + 1.
  • localStorage: setItem(k, v), getItem(k) (калид нест — null), removeItem(k), clear(). Танҳо сатрҳоро нигоҳ медорад, баъди аз нав бор шудан зинда мемонад, тақрибан 5 МБ, барои ҳар сайт худӣ. Асрорро нигоҳ надоред.
  • Дар қуттии санҷиши курс localStorage-и воқеӣ дастнорас аст — ивазкунаки storage-ро бо ҳамон API истифода мебарем. Дар компютери худатон: const storage = window.localStorage;. Воқеиро дар DevTools → Application → Local Storage санҷидан мумкин аст.
  • JSON: JSON.stringify(state) пеш аз навиштан, JSON.parse(raw) баъди хондан. Намегузаранд: undefined, функсияҳо, санаҳо (сатр мешаванд).
  • loadState-и боэътимод: null → ҳолати пешфарз; JSON.parse дар try / catch; санҷиши шакл; { ...defaults, ...saved } барои майдонҳои нав. Калид бо префикс ва версия: app:v1.
