Қариб ҳар барномаи воқеӣ чизеро бор мекунад: рӯйхати молҳо, ҷадвал, профил. Имрӯз мо меомӯзем, ки инро дуруст кунем, барномаро бо API ба React интиқол медиҳем ва нақша тартиб медиҳем, ки минбаъд ба куҷо рушд кунем, агар хоҳед React ва Next.js-ро амиқтар омӯзед.

01 useEffect: кай кор мекунад

Компоненти React — функсияи тоза аст: маълумотро (props ва state) гирифт, тавсифи экранро (JSX) баргардонд. Тамом. Рендер набояд дар ҷаҳони беруна чизеро «кунад»: дархост фиристад, таймер оғоз кунад, сарлавҳаи ҷадвалро тағйир диҳад. Чунин амалҳо таъсироти ҷонибӣ номида мешаванд, ва барои онҳо дар React ҷои алоҳида ҳаст — ҳуки useEffect.

Монанд аз ҳаёт

Дар чойхона пешхизмат аввал дастархон мепӯшад — ин рендер аст: дастархон, пиёлаҳо, нон. Танҳо вақте ки миз тайёр аст, ӯ барои чойник ба ошхона меравад — ин эффект аст. Дар миёнаи тайёр кардани миз ба ошхона рафтан мумкин нест: меҳмон аллакай менишинад ва ба мизи холӣ менигарад. React ҳамин тавр мекунад: аввал экранро нишон медиҳад, ва танҳо баъд аз он эффекти Шуморо оғоз мекунад.

Тартиб: рендер → экран → эффект

«Иҷро кардан»-ро пахш кунед, баъд якчанд маротиба ба тугма дар пешнамоиш — ва аз паси консол равед.

import { useEffect, useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);

  // Ин бадани компонент — РЕНДЕР: React ҳисоб мекунад, ки экран чӣ тавр бояд намояд
  console.log("1. рендер: считаем JSX, count =", count);

  // Ва ин ЭФФЕКТ аст: React онро танҳо БАЪД аз нав шудани экран даъват мекунад
  useEffect(() => {
    console.log("2. эффект: экран обновлён, count =", count);
  });

  return <button onClick={() => setCount(count + 1)}>Нажато: {count}</button>;
}
  1. Рендер. React функсияи компонентро даъват мекунад ва JSX мегирад. Ҳар як console.log дар бадани компонент дар ҳамин қадам иҷро мешавад.
  2. Коммит. React DOM-и воқеиро нав мекунад — истифодабаранда экрани навро мебинад.
  3. Эффект. React функсияҳоро аз useEffect даъват мекунад. Инҷо ба шабака баромадан, таймер гузоштан ва ба document даст задан бехатар аст.

Массиви вобастагиҳо: эффект кай такрор мешавад

Ҳамчун аргументи дуюм useEffect массиви вобастагиҳоро қабул мекунад. Он ба саволи «пас аз кадом рендерҳо эффектро аз нав оғоз кардан?» ҷавоб медиҳад.

НавиштКай кор мекунадИстифодаи маъмулӣ
useEffect(fn)пас аз ҳар рендерқариб ҳеҷ гоҳ; аксар вақт ин хато аст
useEffect(fn, [])як маротиба, пас аз рендери аввалборкунии маълумот ҳангоми кушодан, обуна
useEffect(fn, [a, b])пас аз рендери аввал ва ҳар вақте ки a ё b тағйир ёфтанддархост аз рӯи id ё сатри ҷустуҷӯ

Кӯшиш кунед: тугмаҳои a ва b-ро пахш кунед ва бинед, ки аз се эффект кадомаш вокуниш нишон медиҳад.

import { useEffect, useState } from "react";

export default function App() {
  const [a, setA] = useState(0);
  const [b, setB] = useState(0);

  useEffect(() => {
    console.log("A (без массива): после КАЖДОГО рендера");
  });

  useEffect(() => {
    console.log("B ([]): один раз, после первого рендера");
  }, []);

  useEffect(() => {
    console.log("C ([a]): изменился a, теперь a =", a);
  }, [a]);

  return (
    <div style={{ display: "flex", gap: 8 }}>
      <button onClick={() => setA(a + 1)}>a = {a}</button>
      <button onClick={() => setB(b + 1)}>b = {b}</button>
    </div>
  );
}
Қоидаи вобастагиҳо

Дар массив ҳамаи қиматҳоро аз компонент (props, state, функсияҳо), ки эффект мехонад, навиштан лозим аст. Агар эффект id-ро истифода барад, ва дар массив он набошад, эффект бо id-и «кӯҳна» кор мекунад — сарчашмаи аз ҳама маъмули хатоҳо. Муҳаррири хуб (ва ЗС) инро бо қоидаи react-hooks/exhaustive-deps мегӯяд; онро хомӯш накунед, балки кодро ислоҳ намоед.

Хатои маъмул: давраи беохир

Эффект бе массив, ки ҳолатро тағйир медиҳад, рендери навро оғоз мекунад, он — эффекти навро, ва ҳамин тавр то беохир. Браузер овезон мешавад ё React хатои «Too many re-renders»-ро мепартояд. Ин кодро дар лоиҳаи кории худ оғоз накунед.

function Counter() {
  const [n, setN] = useState(0);

  useEffect(() => {
    setN(n + 1); // ✖ массиви вобастагиҳо нест: рендер → эффект → setN → рендер → ...
  });

  return <p>{n}</p>;
}

миёна

Стенд ҳисобро, баъд мавзӯъро, боз ҳисобро тағйир медиҳад. Эффектеро нависед, ки сохраняем счёт: N-ро ҳангоми ҳар тағйири ҳисоб (аз ҷумла намоиши аввал) чоп мекунад, аммо ба иваз шудани мавзӯъ вокуниш нишон намедиҳад.

import { useEffect, useState } from "react";

// стенд: «истифодабарандаи виртуалӣ» қадамҳоро аз рӯи таймер иҷро мекунад
function useScript(steps) {
  useEffect(() => {
    const ids = steps.map(([ms, fn]) => setTimeout(fn, ms));
    return () => ids.forEach(clearTimeout);
  }, []);
}

export default function App() {

  useScript([

  return <p className={theme}>Счёт: {count}</p>;

02 Cleanup: ба паси худ тозакорӣ кардан лозим аст

Эффект метавонад функсияро баргардонад — онро cleanup («тозакорӣ») меноманд. React онро дар ду ҳолат даъват мекунад: пеш аз он ки эффектро аз нав оғоз кунад (ҳангоми иваз шудани вобастагиҳо) ва вақте ки компонент аз экран нопадид мешавад.

useEffect(() => {
  // 1) «фаъол мекунем»: таймер, обуна, дархост
  const id = setInterval(tick, 1000);

  // 2) «хомӯшкунанда»-ро бармегардонем
  return () => clearInterval(id);
}, []);
Монанд аз ҳаёт

Шумо бо маршрутка омадед ва дар он радиоро бо садои пурра фаъол кардед. Агар бе хомӯш кардан фуромада равед, радио барои салони холӣ садо медиҳад ва ба мусофирони навбатӣ халал мерасонад. Cleanup — ин «радиоро хомӯш кардан ҳангоми баромадан» аст. Таймер бе cleanup ҳамин тавр дар компонент, ки аллакай нест, тиқ-тиқ карданро давом медиҳад.

Тартиб ҳангоми иваз шудани вобастагиҳо

  1. Эффект бо room = "Общий" оғоз шуд: пайваст шудем.
  2. room ба "Группа JS" иваз шуд: React аввал cleanup-и эффекти кӯҳна-ро даъват мекунад (аз «Общий» ҷудо шудем)…
  3. …ва танҳо баъд эффектро бо қимати нав оғоз мекунад (ба «Группа JS» пайваст шудем).
  4. Компонентро аз экран бардоштанд: cleanup-и охирин — ҷудо шудем.

StrictMode: барои чӣ React эффектро ду маротиба оғоз мекунад

Вақте ки Шумо лоиҳаро дар Vite ё Next.js эҷод мекунед, компонентҳо одатан дар <StrictMode> печонида шудаанд. Дар реҷаи таҳия он қасдан «репетитсия» мекунад: эффектро оғоз мекунад, фавран cleanup-ро даъват мекунад ва эффектро боз як маротиба оғоз мекунад. Ин тавр React месанҷад, ки эффекти Шумо «хомӯш шуданро» медонад ва ахлот намегузорад. Дар барпоии тайёр (production) ин такрор нест.

function Clock() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    console.log("эффект: запускаем таймер");
    const id = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => {
      console.log("cleanup: останавливаем таймер");
      clearInterval(id);
    };
  }, []);

  return <p>Прошло секунд: {seconds}</p>;
}

Ба «оғози дукарата» чӣ тавр муносибат кардан лозим аст

Ин хато нест ва «React вайрон нашудааст». Агар пас аз оғози дукарата барнома чунон ки лозим аст, кор кунад — cleanup дуруст навишта шудааст. Агар дархост ду маротиба меравад ё таймерҳо тез мешаванд — Шумо cleanup-ро фаромӯш кардед. Равзанаҳои таълимии ин саҳифа дар реҷаи production кор мекунанд, бинобар ин такрор дар онҳо намоён нест; худатон санҷед, вақте ки лоиҳаро дар Vite эҷод мекунед.

Хатои маъмул: тоза кардани таймерро фаромӯш кардед

Бе cleanup интервал пас аз рафтани компонент зинда мемонад: рехтани хотира ва навкунии ҳолати компоненти ғайримавҷуд.

04 Мусобиқаи дархостҳо ва AbortController

Экрани профилро бо тугмаҳои «Мадина» ва «Фарход» тасаввур кунед. Шумо «Мадина»-ро пахш кардед — дархост рафт, ва он суст аст. Ин мусобиқаи дархостҳо (race condition) номида мешавад, ва он дар сайтҳои воқеӣ пайваста рух медиҳад.

Монанд аз ҳаёт

Шумо дар як чойхона палав фармудед, аммо фавран фикратонро иваз карда, дар дигаре қурутоб фармудед. Қурутобро зуд оварданд, шумо хӯрданро сар кардед — ва ногаҳон курйер палавро меорад, ки Шумо онро бекор карда будед. Рафтори дуруст — ба чойхонаи аввал занг задан ва фармоишро бекор кардан аст. Барои дархостҳо бекоркунӣ — ин AbortController аст.

AbortController дар ду сатр

Шумо контроллер эҷод мекунед, signal-и онро ба fetch медиҳед, ва вақте ки дархост дигар лозим нест, controller.abort()-ро даъват мекунед. Promise-и fetch он гоҳ бо хатои AbortError рад карда мешавад.

const controller = new AbortController();

fetch("https://jsonplaceholder.typicode.com/users/1", { signal: controller.signal })
  .then((r) => r.json())
  .then((user) => console.log("получили", user.name))
  .catch((err) => console.log("ошибка:", err.name));

controller.abort(); // фавран фикр иваз кардем
console.log("aborted:", controller.signal.aborted);

Дар эффект чӣ тавр менамояд

Cleanup-и эффект — ҷои беҳтарин барои abort() аст: React онро пеш аз такрори оғози эффект ва ҳангоми рафтани компонент даъват мекунад.

Варианти эҳтиётӣ: парчами ignore

Агар бекор кардан чизе нест (масалан, китобхона signal-ро қабул намекунад), парчамро истифода баред: let ignore = false; дар эффект, if (!ignore) setUser(user) дар коркардкунанда ва return () => { ignore = true; } дар cleanup. Дархост бекор намешавад, аммо натиҷаи он нодида гирифта мешавад. Бекоркунӣ беҳтар аст: он боз траффикро ҳам сарфа мекунад.

Хатои маъмул: AbortError-ро ба истифодабаранда нишон медиҳем

Агар дар .catch танҳо setError(err.message) кунед, ҳангоми ҳар иваз шудан истифодабаранда барои як лаҳза «The user aborted a request»-ро мебинад. err.name === "AbortError"-ро санҷед ва хомӯшона бароед.

05 Ҷустуҷӯ, debounce ва филтркунӣ

Филтркунӣ: на ҳолат лозим аст ва на эффект

Фарз кунед, ки Шумо рӯйхат ва сатри ҷустуҷӯ доред. Навомӯзон аксар вақт барои «рӯйхати филтршуда» useState-и дуюмро ташкил медиҳанд ва онро дар эффект нав мекунанд. Монанд аз ҳаёт

Менюи рӯи девори чойхона як аст. Вақте ки меҳмон мегӯяд «ба ман чизе бе гӯшт», пешхизмат менюро аз нав наменависад ва дуюмро овезон намекунад — ӯ танҳо дар зеҳн таомҳои гӯштиро мегузаронад. Рӯйхати филтршуда — «нигоҳ ба меню» аст, на менюи нав.

Ҷустуҷӯ тавассути сервер ва debounce барои чӣ лозим аст

Агар дар рӯйхати ҳазорон сабт ҷустуҷӯ кунед, филтр кардан дар клиент аллакай мумкин нест — дархост ба сервер лозим аст: /users/search?q=плов. Аммо агар барои ҳар клавишаи пахшшуда дархост фиристед, то даме ки истифодабаранда «плов»-ро чоп мекунад, чор дархост меравад: п, пл, пло, плов. Се тоаш ба ҳеҷ кас лозим нестанд, ва онҳо метавонанд бо тартиби омехта баргарданд.

Debounce («ларзиш») — усул аст: 300–500 мс интизор шудан, то истифодабаранда чоп карданро бас кунад, ва танҳо баъд ҷустуҷӯ кардан. Ҳар пахши нав таймерро аз нав мегузорад.

Аввал худи ядрои ғоя дар JS-и тоза — функсияи debounce, ки ҳама ҷо истифода мешавад, на танҳо дар React. Ва дар React ҳамин чиз ҳамчун ҳуки худӣ ташкил карда мешавад:

function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id); // пахши нав таймери кӯҳнаро бекор мекунад
  }, [value, delay]);

  return debounced;
}

Ин мисоли зебои cleanup аст: ҳар тағйири value таймери тағйири гузаштаро мебардорад, ва то охир танҳо охиринаш зинда мемонад. Истифода: эффекти дархост на аз query (дар ҳар ҳарф тағйир меёбад), балки аз debounced вобаста аст.

Мисоли зинда: ҷустуҷӯ бо API-и воқеӣ

Номҳои англисиро чоп кунед (ma, ol, ja) ва аз паси ҳисобкунаки дархостҳо равед: то даме ки пай дар пай чоп мекунед, он намеафзояд. Дархости гузашта тавассути AbortController бекор мешавад.

import { useEffect, useState } from "react";

function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

06 Блоки ЗС: промпт барои компоненти React дар муқобили кори дастӣ

Компонентҳои React-ро ЗС бисёр боэътимод менависад — ин яке аз маъмултарин дархостҳо дар ҷаҳон аст. Аммо маҳз дар ин ҷо ӯ «кунҷҳоро буридан»-ро дӯст медорад: response.ok-ро мегузарад, cleanup-ро фаромӯш мекунад, ҳолати «холӣ»-ро намекашад ё мусобиқаи дархостҳоро мегузорад. Код дар ин ҳол озода менамояд ва дар «роҳи хушбахт» кор мекунад. Бинобар ин маҳорати имрӯза — на «гирифтани компонент», балки ҳолатҳои ҳадди охирро дар промпт пешбинӣ кардан ва натиҷаро аз рӯи рӯйхат санҷидан аст.

Қоидаҳои курс, ки дар ин ҷо махсусан муҳиманд

1. Аввал 15 дақиқа худатон кӯшиш мекунед — Шумо аллакай қолабҳо аз бахшҳои 03–04 доред. 2. Баъд бо промпт аз рӯи формула ба ЗС мераведед. 3. Компонентеро, ки сатр ба сатр шарҳ дода наметавонед, ба лоиҳа нагузоред: Шумо бояд бидонед, ки ҳар вобастагӣ дар массив ва ҳар сатри cleanup барои чӣ аст. 4. Не дар «роҳи хушбахт», балки дар вайроншавиҳо санҷед: ҷавоби 404/500, рӯйхати холӣ, иваз шудани зуд, рафтан аз саҳифа.

Чӣ тавр хостан: бад ва хуб

Формулаи промпти курс: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш. Барои компоненти React се чизи ҳатмиро илова мекунем: props (аз берун чӣ меояд), ҳолат (компонент чӣ нигоҳ медорад) ва ҳолатҳои ҳадди охир (чӣ метавонад хато равад).

барои ман компоненти React бо рӯйхати истифодабарандагон бинавис
Ман React меомӯзам, сатҳ — навомӯз: useState, props, key, useEffect-ро медонам. Компоненти функсионалии UserList-ро бо React-и тоза бе китобхонаҳо бинавис. Props: apiUrl (сатр). Пеш аз супоридан

Интернетро хомӯш кунед (ё дар DevTools дар ҷадвали Network реҷаи Offline-ро гузоред) ва барномаро аз нав бор кунед. Ба ҷои экрани холӣ паёми фаҳмо бо тугмаи «Такрор» бояд пайдо шавад. Баъд дар ҷустуҷӯ зуд якчанд ҳарфро пай дар пай чоп кунед ва ба ҷадвали Network нигаред: дархост бояд як маротиба равад, на барои ҳар ҳарф.

✓ Шпаргалкаи дарс

  • Рендер бояд тоза бошад. Дархостҳо, таймерҳо, document.title, обунаҳо — таъсироти ҷонибӣ ҳастанд, ҷояшон дар useEffect аст.
  • Тартиб: рендер → навкунии DOM → эффект.
  • Вобастагиҳо: бе массив — пас аз ҳар рендер; [] — як маротиба; [a, b] — ҳангоми тағйири a ё b. Дар массив ҳар чизе, ки эффект мехонад.
  • Cleanup: return () => ... дар эффект. Пеш аз оғози такрорӣ ва ҳангоми рафтани компонент даъват мешавад. StrictMode дар таҳия қасдан «эффект → cleanup → эффект»-ро оғоз мекунад.
  • Чор ҳолат: loading, error, empty, success. «Холӣ» — ин муваффақият бо массиви холӣ аст.
  • Қолаб: fetch → if (!response.ok) throw new Error(...) → json() → setState; дар .catch — хато, аммо AbortError-ро нодида мегирем.
  • Мумкин нест useEffect(async () => ...): функсияи async-ро дар дохил эълон мекунем.
  • Мусобиқаи дархостҳо: cleanup бо controller.abort() (ё парчами ignore), то ҷавоби кӯҳна навро напӯшонад.
  • Маълумоти ҳосилавӣ (рӯйхати филтршуда) ҳангоми рендер ҳисоб мекунем, ва дар ҳолат нигоҳ намедорем.
  • Debounce: useDebounce(value, delay) — setTimeout дар эффект ва clearTimeout дар cleanup; дархост аз debounced вобаста аст.
  • Next.js: масирҳо аз рӯи папкаҳо, компонентҳои серверӣ (маълумот дар сервер, бе useEffect), "use client" барои интерактив.
  • Бо ЗС: дар промпт барои компонент — props, ҳолат, ҳолатҳои ҳадди охир; санҷиш аз рӯи чек-лист аз 8 банд.
  • Минбаъд: 8 ҳафтаи нақша, лоиҳа як маротиба дар ду ҳафта, коммит дар як рӯз.
