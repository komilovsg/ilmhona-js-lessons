Модулҳо, npm ва build бо Vite

То даме ки барномаи шумо дар як файли 300-сатра ҷой мегирад, ҳама чиз хуб аст. Аммо сайти ҳақиқӣ — ин даҳҳо файл, китобхонаҳои бегона ва ҷамъбаст пеш аз нашр аст. Имрӯз шумо ёд мегиред, ки кодро ба модулҳо тақсим кунед, бастаҳоро тавассути npm пайваст кунед, лоиҳаро бо Vite оғоз намоед — ва барномаи дарси 16-ро ба он мегузаронед.

  • export ва import навиштан: номдор, пешфарз, бо тағйири ном ва файли «витринагӣ»-и index.js
  • Роҳҳои модулҳоро дуруст нишон додан ва лоиҳаро ба папкаҳо тақсим кардан
  • package.json-ро хондан ва таҳрир кардан: майдонҳо, dependencies ва devDependencies, версияҳои ^ ва ~
  • Фармонҳоро тавассути скриптҳои npm иҷро кардан: npm run dev, npm run build
  • Лоиҳаро бо фармони npm create vite@latest эҷод кардан ва фарқи сервери dev аз build-ро фаҳмондан
  • Барномаро ба Vite гузаронидан, ба модулҳо тақсим кардан ва ба репозиторий бор кардан
Бо ин саҳифа чӣ тавр кор кардан лозим

Ин дарс дар бораи абзорҳост, бинобар ин як қисми мисолҳо — терминал ва файлҳои лоиҳа мебошанд: онҳо дар заминаи торик ҳастанд, вале бе тугмаи «Иҷро кардан». Фармонҳоро шумо дар компютери худ такрор мекунед (сарлавҳаи блок ишора мекунад: «Терминал» ё номи файл). Ҳар чизе, ки дар браузер ба таври ҳақиқӣ санҷидан мумкин аст, зинда аст: модулҳо, import-ҳо ва таҳлили package.json бо тугмаи ▶ Иҷро кардан оғоз мешаванд. Дар браузер файлҳо нестанд, барои ҳамин «файл»-и модулро дар сатр нигоҳ медорем ва бо import()-и ҳақиқӣ бор мекунем — ин ҳамон механизмест, ки браузер барои файлҳо истифода мебарад. Сатри setTimeout(() => {}, 300) дар ин мисолҳо ёрирасон аст: он аз майдончаи озмоишӣ хоҳиш мекунад, ки каме интизор шавад, то модул бор шавад. Дар лоиҳаи ҳақиқӣ он лозим нест.

01 Модулҳо барои чӣ лозиманд. export ва import

Ҳар лоиҳаи ҷиддиро кушоед — шумо дар он як script.js-и азим наменамоед. Код ба файлҳо тақсим шудааст: яке барои дархостҳо ба API масъул аст, дигаре — барои тасвир, сеюм — барои функсияҳои ёрирасон. Чунин файл модул номида мешавад.

Чаро як файл — бад аст? Аввалан, дар он ҳидоят кардан душвор аст. Дуюм, агар якчанд скрипти оддиро пай дар пай пайваст кунем, ҳамаи тағйирёбандаҳои онҳо ба як фазои умумӣ меафтанд: ду функсия бо номи format якдигарро пок мекунанд. Модул ҳарду мушкилро ҳал мекунад: он соҳаи намоии худро дорад ва ба берун танҳо он чизе мебарояд, ки шумо возеҳан иҷозат додаед.

Монандӣ аз ҳаёт

Ошхонаи чойхонаи калон. Як ошпаз палав мепазад, дигаре — кабоб, сеюм — нон. Ҳар кас мизи худ ва маҳсулоти худро дорад — ин модул бо соҳаи намоии худ аст. Аммо таоми тайёрро ошпаз тавассути тирезаи расонидан медиҳад — ин export аст. Пешхизмате, ки таомро мегирад ва ба толор мебарад, — ин import аст. Ҳар чизе ки дар сари миз монд, «корҳои шахсии» ошпаз аст, ба толор намеравад.

Экспорти номдор

Барои он ки чизеро ба берун кушоед, пеш аз эълон калимаи export-ро менависанд. Барои гирифтани онро дар файли дигар — import бо номҳо дар қавсҳои фигурӣ:

const RATE = 11; // бе export — танҳо дар дохили ҳамин файл намоён аст

export function toSomoni(usd) {
  return usd * RATE;
}

export function toUsd(somoni) {
  return somoni / RATE;
}

import { toSomoni, toUsd } from "./currency.js";

console.log(toSomoni(100)); // → 1100
console.log(toUsd(550));    // → 50

Номҳо дар қавсҳои фигурӣ бояд бо номҳои экспортшуда айнан мувофиқ бошанд, аз ҷумла ҳарфи калон ва хурд. Тартиб муҳим нест. Агар чизеро import кунед, ки вуҷуд надорад — хато ҳанӯз пеш аз иҷрои код пайдо мешавад.

Import-и ҳақиқиро худи ҳамин ҷо иҷро мекунем

Дар ин саҳифа файлҳо дар диск нестанд, вале функсияи import() ҳаст, ки модулро аз рӯи нишонӣ бор карда метавонад. Мо «файл»-ро ба сатр печонида, ба нишонӣ табдил медиҳем (Blob ва URL.createObjectURL) ва бор мекунем. Барои шумо ин танҳо сатр дар нохунакҳои баръакс аст — тасаввур кунед, ки ин мазмуни файл аст.

// «файл» → нишонӣ → модул
const load = (code) => {
  setTimeout(() => {}, 300); // танҳо ин саҳифа ба он ниёз дорад: майдончаи озмоишӣ интизор мешавад, то модул бор шавад
  return import(URL.createObjectURL(new Blob([code], { type: "text/javascript" })));
};

const currency = await load(`
  const RATE = 11;
  export function toSomoni(usd) { return usd * RATE; }
  export function toUsd(somoni) { return somoni / RATE; }
`);

console.log(currency.toSomoni(100)); // 1100
console.log(currency.toUsd(550));    // 50
console.log(currency.RATE);          // undefined — бе export аз берун намоён нест

Натиҷаи боркунӣ — объект бо ҳар он чизе, ки модул экспорт кардааст. Собити RATE экспорт нашудааст — аз берун он нест. Ин ҳамон «махфияти» модул аст.

Модуле, ки модули дигарро import мекунад

Акнун ду «файл»: дуюмӣ якумиро бо сатри оддии import ... from пайваст мекунад. Ба ҷои роҳи "./currency.js" мо нишонии модули якумро мегузорем — дар диски ҳақиқӣ ҷои он роҳ меистод.

const url = (code) => {
  setTimeout(() => {}, 300); // танҳо ин саҳифа ба он ниёз дорад: майдончаи озмоишӣ интизор мешавад, то модул бор шавад
  return URL.createObjectURL(new Blob([code], { type: "text/javascript" }));
};

// файли currency.js
const currencyUrl = url(`
  const RATE = 11;
  export const toSomoni = (usd) => usd * RATE;
  export const toUsd = (somoni) => somoni / RATE;
`);

// файли main.js (дар диск: import { toSomoni } from "./currency.js")
await import(url(`
  import { toSomoni, toUsd } from "${currencyUrl}";
  console.log("100 USD =", toSomoni(100), "сомони");
  console.log("550 сомони =", toUsd(550), "USD");
`));

Import боз чӣ кор карда метавонад

Тағйири ном: as
Агар номҳо зиддият кунанд: import { format as formatDate } from "./dates.js". Акнун дар дохили файл функсия formatDate ном дорад.
Ҳамаро якбора: * as
import * as currency from "./currency.js" — як объект, ба функсияҳо тавассути нуқта муроҷиат мекунем: currency.toSomoni(5). Вақте қулай аст, ки бисёр чиз лозим аст ва мехоҳем бубинем, ки кадом чиз аз куҷост.
Экспорт бо рӯйхат
Ҳатмӣ нест, ки пеш аз ҳар сатр export гузорем — ҳамаро дар поёни файл ҷамъ кардан мумкин аст: export { toSomoni, toUsd };
Танҳо иҷро
import "./style.css" — бе ном: файл танҳо пайваст мешавад. Дар Vite услубҳоро ҳамин тавр пайваст мекунанд.

02 Экспорти пешфарз, реэкспорт, роҳҳо ва папкаҳо

export default

Модул метавонад як экспорти «асосӣ» дошта бошад — export default. Ҳангоми import он бе қавсҳои фигурӣ ва бо ҳар номе, ки худатон меандешед, гирифта мешавад:

export default function greet(name) {
  return `Салом, ${name}!`;
}

export const LANG = "tg"; // экспорти номдорро ҳам дар паҳлӯ нигоҳ доштан мумкин аст

import greet, { LANG } from "./ui/greet.js";   // default — бе қавс, боқӣ — дар қавс
import hello from "./ui/greet.js";              // айнан ҳамон, ном худамон интихоб мекунем

console.log(greet("Мадина"), LANG);

Реэкспорт: файли витринагии index.js

Вақте дар папка бисёр модул ҳаст, навиштани панҷ сатри import аз панҷ файли гуногун нокулай аст. Одат шудааст, ки дар папка файли index.js мегузоранд, ки ҳар чизи лозимаро ҷамъ мекунад ва тавассути як тиреза медиҳад — мисли витрина дар мағоза. Барои ин экспорти «интиқолдиҳанда» ҳаст:

export { getUsers, getPosts } from "./users.js";   // номҳои алоҳида
export * from "./products.js";                      // ҳамаи номдорҳо якбора
export { default as http } from "./http.js";        // default → номдор

// аз берун муҳим нест, ки дар кадом файл чӣ ҳаст: роҳ ба папка мебарад
import { getUsers, searchProducts, http } from "./api/index.js";
Монандӣ аз ҳаёт

Бозори Корвон. Шумо ба ҳар анбор намеравед — ба қатори даркорӣ меравед, ки дар он фурӯшанда фармоишро мегирад ва худаш аз анборҳои гуногун мол мебарорад. index.js — ҳамон фурӯшанда аст: харидор (модули дигар) танҳо қаторро медонад, на анборҳоро.

Қоидаҳое, ки донистанашон лозим аст

  1. Модул як бор иҷро мешавад. Ҳар қадар файл онро import кунад ҳам, код дар дохили он як бор оғоз мешавад, ва ҳама як ҳолати ягона (ҳисобкунак, кэш, танзимот)-ро мегиранд.
  2. Соҳаи намоии худ. Тағйирёбандаҳои модул ба window намеафтанд. Барои ҳамин дар лоиҳаи Vite шумо тасодуфан тағйирёбандаи бегонаро аз нав навишта наметавонед.
  3. Реҷаи қатъӣ худ аз худ фаъол аст. Навиштани "use strict" лозим нест.
  4. import — танҳо дар боло аз файл ва на дар дохили if ё функсия. Барои боркунӣ «ҳангоми ниёз» import() ҳаст — маҳз онро мо дар ин саҳифа истифода мебарем.
  5. Давраҳоро манъ кардан лозим нест, вале аз онҳо худдорӣ кардан даркор. Агар a.js файли b.js-ро import кунад, b.js бошад — a.js-ро, дар тартиби иҷро ошуфтагӣ пайдо мешавад. Ҳал: чизи умумиро ба файли сеюм баровардан.

  • utils дар бораи барнома намедонанд. debounce ба ҳар лоиҳа мувофиқ аст — яъне ҷояш дар utils аст.

03 Node.js, npm ва package.json

Node.js — ин JavaScript берун аз браузер аст: он кодатонро бевосита дар компютер иҷро мекунад. Мо онро на барои сайтҳо, балки барои абзорҳо лозим дорем: Vite, форматкунандаҳо ва санҷиши код худашон бо JavaScript навишта шудаанд ва дар Node кор мекунанд. Бо Node якҷоя npm насб мешавад — мудири бастаҳо: барномае, ки коди бегонаро (бастаҳоро) аз феҳристи азими npmjs.com зеркашӣ мекунад ва ба лоиҳаи шумо пайваст менамояд.

Монандӣ аз ҳаёт

Бозори масолеҳи сохтмон. Шумо хона месозед ва хиштро худатон намерезед — тайёрашро мегиред. npm — ин ҳам бозор, ҳам расонидан аст: мегӯед «фалон баста лозим», ва онро ба папкаи node_modules меоранд. package.json бошад — рӯйхати харидҳои лоиҳа: дақиқ чӣ ва кадом версия ба шумо лозим аст. Ин рӯйхатро ба таҳиягари дигар диҳед — ва ӯ бо як фармон айнан ҳамон масолеҳро дар назди худ ҷамъ мекунад.

Насб ва санҷиш (Windows ва macOS)

  1. Node.js LTS-ро зеркашӣ кунед аз nodejs.org (тугмаи «LTS» — версия бо дастгирии дароз). Windows — насбкунандаи .msi, macOS — насбкунандаи .pkg. Ҳама ҷо бо танзимоти пешфарз розӣ шавед.
  2. Терминалро пӯшед ва аз нав кушоед. Ин муҳим аст: тирезаҳои кӯҳна барномаҳои навро намебинанд. Осонтар аз ҳама — терминал бевосита дар VS Code: меню Terminal → New Terminal (дар клавиатура Ctrl+`).
  3. Версияҳоро санҷед. Барои Vite-и муосир Node.js 20.19+ ё 22.12+ лозим аст.

Маслиҳат

Дар лоиҳаи Vite ҳар чизе ки import мекунед, ҳангоми build ба файлҳои ниҳоӣ печонида мешавад, барои ҳамин дар сайт сарҳади байни ду рӯйхат намоён нест. Вале одат лозим аст: вақте лоиҳаи бегонаро кушоед, аз рӯи ин рӯйхатҳо фавран мефаҳмед, ки «барнома ба чӣ ниёз дорад» ва «бо чӣ сохта мешавад». Қоида оддӣ аст: дар import дар дохили src/ лозим бошад — ин dependencies аст (npm install ном), танҳо барои кор бо лоиҳа лозим бошад — devDependencies (npm install -D ном).

console.log(parse("1.10.0")[1] > parse("1.9.0")[1]); // true — 10 аз 9 калонтар аст

Скриптҳои npm: фармонҳои худии лоиҳа

Дар блоки scripts шумо ба фармонҳои дароз номҳои кӯтоҳ медиҳед. Ба ҷои он ки ба ёд гиред, ҷамъкунанда чӣ тавр оғоз мешавад, ҳама як чизро менависанд: npm run dev. Ҳар кӣ лоиҳаро кушояд — як сол баъд ё таҳиягари дигар — дар package.json мебинад, ки кадом фармонҳо дастрасанд.

"scripts": {

Шарҳҳои //-ро дар JSON-и ҳақиқӣ навиштан мумкин нест — дар ин ҷо онҳо танҳо барои тавзеҳанд.

  • Барои калимаҳои start ва test калимаи run-ро нанависед ҳам мешавад: npm start, npm test. Барои боқӣ (dev, build) — ҳатмист: npm run dev.
  • Фармонҳоро тавассути && якҷоя кардан мумкин аст: "check": "npm run build && npm run preview" — дуюмӣ танҳо дар сурате оғоз мешавад, ки якум бо муваффақият анҷом ёбад.
  • Скриптҳо дар ҳамаи системаҳо кор мекунанд, ба шарте ки барномаҳои байнисистемавӣ истифода баред. Фармонҳое мисли rm -rf dist дар Windows-и оддӣ кор намекунанд — барои чунин ҳолатҳо бастаҳо мегиранд (масалан, rimraf).
  • npx ном — як бор зеркашӣ ва иҷро кардани барнома, бе насб кардан ба лоиҳа. Маҳз ҳамин тавр npm create vite@latest кор мекунад (дар асл ин npx create-vite@latest аст).
Бастаҳоро бодиққат насб кунед

Насби баста — ин иҷрои коди бегона дар компютери шумост. Пеш аз он ки бо маслиҳати интернет ё зеҳни сунъӣ npm install иҷро кунед, дар npmjs.com санҷед: оё ном дуруст навишта шудааст, баста дар як ҳафта чанд маротиба зеркашӣ шудааст, муаллиф кист, навсозии охирин кай буд. Зеҳни сунъӣ гоҳо бастаҳоеро меандешад, ки вуҷуд надоранд, ва қаллобон бастаҳо бо номҳои монанд қайд мекунанд (reacct ба ҷои react). Агар ном ба шумо ношинос бошад — аз муаллим пурсед.

миёна

Функсияи compareVersions(a, b)-ро нависед: агар версияи a аз b кӯҳнатар бошад, -1, агар навтар бошад 1 ва агар баробар бошанд 0 бармегардонад. Версияҳо — сатрҳои намуди "1.10.0"; бояд рақамҳо муқоиса шаванд, на сатрҳо.

Ишора 2

Дар давра: агар pa[i] < pb[i] бошад — фавран return -1; агар калонтар бошад — return 1; агар баробар бошанд — ба рақами навбатӣ мегузарем. Пас аз давра — return 0.

ВАЗИФАИ 3.4

Оё версия мувофиқ аст

душвор

satisfies(version, range)-ро нависед. Диапазон метавонад чунин бошад: версияи дақиқ "1.2.3"; "^1.2.3" — ҳамон версияи major ва на пасттар аз нишондодашуда; "~1.2.3" — ҳамон major ва minor ва на пасттар аз нишондодашуда. Функсияи compareVersions аз вазифаи гузашта аллакай омода аст. Ҳисоб мекунем, ки major на камтар аз 1 аст.

function compareVersions(a, b) {
  const pa = a.split(".").map(Number);
  const pb = b.split(".").map(Number);
  for (let i = 0; i < 3; i++) {
    if (pa[i] !== pb[i]) return pa[i] < pb[i] ? -1 : 1;
  }
  return 0;
}

function satisfies(version, range) {
  // 1) навъи диапазонро аз рӯи аломати аввал муайян кунед
  // 2) аломати ^ ё ~-ро бурида, муқоиса кунед
}

const checks = [
  ["1.5.0", "^1.2.3"],
  ["2.0.0", "^1.2.3"],
  ["1.2.2", "^1.2.3"],
  ["1.2.9", "~1.2.3"],
  ["1.3.0", "~1.2.3"],
  ["1.2.3", "1.2.3"],
  ["1.2.4", "1.2.3"],
];
for (const [v, r] of checks) console.log(v, r, satisfies(v, r));
Натиҷаи интизоршаванда

1.2.2 ^1.2.3 false

1.3.0 ~1.2.3 false
1.2.3 1.2.3 true
1.2.4 1.2.3 false
Ишора 1

Се ҳолат: диапазон бо ^, бо ~ ё бе аломат оғоз мешавад (версияи дақиқ — compareVersions(...) === 0 кифоя аст). Барои ду ҳолати аввал қисмҳои версия ҳамчун рақам лозиманд.

Ишора 2

Барои ^: major-и версия бо major-и диапазон баробар аст ва compareVersions(version, base) >= 0, ки дар он base = range.slice(1). Барои ~ — ҳамон, илова бар ин minor ҳам баробар аст.

04 Vite: сервери таҳия ва build

Vite (ба забони фаронсавӣ «зуд» маъно дорад, «вит» хонда мешавад) — абзоре, ки ду вазифаро ҳал мекунад. Аввалан, сервери маҳаллиро оғоз мекунад, то модулҳо ҳангоми таҳия кор кунанд ва саҳифа фавран пас аз нигоҳ доштани файл навсозӣ шавад. Дуюм, лоиҳаро ҷамъ мекунад ба сайти тайёр: бисёр модулҳоро ба якчанд файл часпонда, фишурда ба папкаи dist мегузорад.

Монандӣ аз ҳаёт

Ошхона ва расонидан. То даме ки шумо мепазед (таҳия мекунед), ҳама маҳсулот дар сари миз дар қуттиҳои қулай меистанд: гирифтӣ, чашидӣ, ислоҳ кардӣ — ин dev-сервер аст. Аммо ба муштарӣ шумо миз бо қуттиҳоро намефиристед, балки фармоиши ботартиб бастабандишударо: ҳама дар як баста, бе чизи зиёдатӣ — ин build (build) аст. Бастаро ба ҳар хостинг гузоштан мумкин аст.

  3. Ба папкаи лоиҳа гузаред ва вобастагиҳоро насб кунед.
  4. Сервери таҳияро оғоз кунед ва нишонии аз терминалро дар браузер кушоед.
  5. Серверро қатъ кунед — Ctrl+C дар терминал (ҳам дар Windows, ҳам дар macOS).

05 Амал дар дарс: барномаро ба Vite мегузаронем

Барномаи дарси 16-ро мегирем — ҷустуҷӯ аз рӯи API бо ҳолатҳои боркунӣ, натиҷаи холӣ ва хато ва бо debounce — ва ба Vite мегузарем. Дар поён — намунаи меъёрӣ дар феҳристи маҳсулоти dummyjson.com. Дар назди шумо номи функсияҳо ва файлҳо метавонанд фарқ кунанд — ин муқаррарист: ғоя-и ҷудокунӣ муҳим аст, на ҳарф ба ҳарф.

Нақшаи гузариш

1) Версияи кӯҳнаро дар Git нигоҳ медорем. 2) Лоиҳаро дар Vite эҷод мекунем. 3) Нишонгузорӣ (разметка)-ро ба index.html, услубҳоро — ба src/styles/ мегузаронем. 4) JS-ро ба модулҳо тақсим мекунем: api, ui, utils, main. 5) npm run dev-ро оғоз мекунем ва месанҷем, ки ҳама мисли пештара кор мекунад. 6) npm run build-ро иҷро мекунем. 7) Commit ва push ба GitHub. Қоидаи гузариш: рафтори барнома тағйир намеёбад — танҳо сохтори код.

Қадами 1. Лоиҳаи нав

Ҳар файл — як масъулият. Аввал api: танҳо дархост ва санҷиши ҷавоб, ҳеҷ DOM нест.

const API_URL = "https://dummyjson.com";

export async function searchProducts(query, signal) {
  const url = `${API_URL}/products/search?q=${encodeURIComponent(query)}&limit=10`;
  const response = await fetch(url, { signal });

  if (!response.ok) {
    throw new Error(`Ошибка сервера: ${response.status}`);
  }

  const data = await response.json();
  return data.products;
}

Баъд utils: debounce дар бораи барномаи мо чизе намедонад, бинобар ин дар ҳар лоиҳа зиндагӣ карда метавонад.

export function debounce(fn, delay = 300) {
  let timerId;
  return (...args) => {
    clearTimeout(timerId);
    timerId = setTimeout(() => fn(...args), delay);
  };
}

ui танҳо барои он чизе масъул аст, ки корбар мебинад: ҳолатро нишон медиҳад ва рӯйхатро тасвир мекунад.

const statusEl = document.querySelector("#status");
const listEl = document.querySelector("#list");

export function showStatus(text) {
  statusEl.textContent = text;
}

export function renderProducts(products) {
  const items = products.map((product) => {
    const li = document.createElement("li");
    li.textContent = `${product.title} — ${product.price} $`;
    return li;
  });
  listEl.replaceChildren(...items);
}

let controller;

async function search(query) {
  controller?.abort();                 // дархости пештараро бекор мекунем
  controller = new AbortController();

  if (!query.trim()) {
    showStatus("Введите запрос");
    renderProducts([]);
    return;

}

06 Блоки ЗС: аз ӯ мепурсем, ки кодро ба модулҳо тақсим кунад

Тақсим кардани файл ба модулҳо — вазифаи маъмули ЗС аст: он механикӣ аст ва натиҷаро бо иҷро санҷидан мумкин аст. Аммо маҳз дар ин ҷо ЗС бештар чизҳои хурдро «вайрон мекунад»: default ва экспорти номдорро омехта мекунад, .js-ро дар роҳ фаромӯш мекунад, бастаҳоеро меандешад, ки дар лоиҳа нестанд. Барои ҳамин имрӯз маҳоратро машқ мекунем: дақиқ пурсидан ва то сатри охир санҷидан.

Қоидаҳои курс, ки дар ин ҷо махсусан муҳиманд

1. Аввал 15 дақиқа худатон кӯшиш мекунед: дар коғаз нақша кашед, ки кадом файлҳо ва папкаҳо ба шумо лозиманд ва дар ҳар кадом чӣ меистад. 2. Фақат баъд ба ЗС муроҷиат мекунед ва бо варианти худатон муқоиса менамоед. 3. 07 Муаллим чӣ нишон медиҳад: Claude Code

Claude Code — ёрдамчии ЗС, ки дар терминал, бевосита дар папкаи лоиҳаи шумо кор мекунад. Вай, бар хилофи чат, файлҳои лоиҳаро мебинад, метавонад таҳрирро фавран дар якчанд файл пешниҳод кунад ва фармонҳоро иҷро намояд (npm run build, git diff). Аммо ҳар амал — таҳрири файл ё фармон — ро танҳо пас аз иҷозати шумо мекунад. Муаллим кори онро дар лоиҳаи ҳамин дарс нишон медиҳад; насб кардани Claude Code ба шумо имрӯз лозим нест. Вазифаи шумо — тамошо кардан ва сабт кардан, ки вазифа чӣ тавр гузошта мешавад ва натиҷа чӣ тавр санҷида мешавад.

Монандӣ аз ҳаёт

Ин ёрдамчии ошхонаи чойхона аст: вай зуд буридан ва тайёр карданро медонад, вале таомро барои ӯ шумо «мечашед». Гуфтед «пиёзро ҳалқа-ҳалқа бур» — ҳалқаҳо гирифтед. Гуфтед «чизе тайёр кун» — ногаҳонӣ гирифтед. Супориш ҳар қадар дақиқтар ва санҷиш пеш аз пешниҳод ҳар қадар диққатнокона бошад, натиҷа ҳамон қадар беҳтар мешавад.

Рафти намоиш

  1. Нуқтаи бозгашт. Пеш аз оғоз лоиҳа commit шудааст: git status «тоза»-ро нишон медиҳад. Агар ЗС кодро вайрон кунад — бо як фармон бармегардем.
  2. Оғоз дар папкаи лоиҳа. Муаллим терминалро дар решаи лоиҳа мекушояд ва claude-ро оғоз мекунад.
  3. Гузоштани вазифа. Вазифа аз рӯи формулаи курс навишта мешавад: контекст, вазифа, маҳдудиятҳо, формат, санҷиш (мисол дар поён).
  4. Нақша пеш аз таҳрирҳо. Аввал мепурсем, ки нақшаро нишон диҳад: кадом файлҳо эҷод ва тағйир дода мешаванд. Нақшаро тағйир додан осонтар аз ислоҳи таҳрирҳои тайёр аст. Дар Claude Code барои ин реҷаи нақша ҳаст (бо Shift+Tab иваз мешавад).
  5. Иҷозатҳо. Барои ҳар таҳрир ва фармон Claude Code мепурсад «мешавад?». Мо мехонем, ки дақиқан чӣ кор карданӣ аст ва танҳо баъд розӣ мешавем.
  6. Таҳлили натиҷа. git status, git diff-ро мебинем, npm run dev ва npm run build-ро иҷро мекунем. Аз рӯи чек-листи поён месанҷем.
  7. Қарор. Хубро — бо паёми фаҳмо commit мекунем. Бадро — бозгашт мекунем ва вазифаро дақиқ менамоем.

Вазифа чӣ тавр таҳия мешавад

Ин лоиҳаи таълимӣ дар Vite (vanilla JS) аст: ҷустуҷӯи маҳсулот аз рӯи dummyjson.com. Ҳоло тамоми код дар src/main.js аст. Онро ба модулҳо тақсим кун: src/api/products.js (дархостҳо), src/ui/render.js (тасвир), src/utils/debounce.js; main.js танҳо пайваст ва банд мекунад. Маҳдудиятҳо: рафтор тағйир наёбад, ба index.html ва package.json даст назан, бастаҳои нав насб накун, экспортҳои номдор, васеъкунии .js дар роҳҳо. Аввал нақшаро аз рӯи файлҳо нишон деҳ, тасдиқи маро интизор шав, баъд таҳрир ворид кун. Дар охир npm run build-ро иҷро кун ва натиҷаро хабар деҳ.

Ба се усул диққат диҳед: ба чӣ даст задан мумкин нест (index.html, package.json, бастаҳо), «аввал нақша, баъд таҳрирҳо» ва санҷиш дар охир (npm run build).

Функсияи reviewDiff(lines)-ро нависед, ки diff-ро аз назар мегузаронад ва огоҳиҳо чоп мекунад. Сатрҳои бо + — иловашуда, бо - — хориҷшуда, боқиро намегирем. Рақами сатр — рақами он дар массив, аз 1 оғоз мешавад. Қоидаҳо (бо тартиб санҷида мешаванд, барои як сатр на зиёда аз як огоҳӣ):

✓ Варақаи кӯмакии дарс

  • Модул — файл бо соҳаи намоии худ. Ба берун танҳо он чиз мебарояд, ки бо export қайд шудааст.
  • Экспорти номдор: export function f() {} → import { f } from "./a.js". Номҳо мувофиқ мешаванд; тағйири ном: { f as g }; ҳамаро якбора: import * as a.

  • Витрина: export { f } from "./a.js", export * from "./b.js" дар index.js — як тиреза барои папка.
  • Роҳҳо: ./ — ҳамсоя, ../ — боло, ном бе нуқта — баста аз npm. Васеъкунии .js-ро менависем, хати моил ҳамеша рост аст, ҳарфи калон ва хурд муҳим аст.

  • Сохтор: src/api, src/ui, src/utils, src/main.js. Як модул — як вазифа, main.js — роҳбари оркестр.
  • package.json: scripts, dependencies (ба коди барнома лозиманд), devDependencies (абзорҳо). node_modules-ро ба Git намегузорем, package-lock.json-ро — мегузорем.
  • semver: MAJOR.MINOR.PATCH. ^1.4.2 — то 2.0.0, ~1.4.2 — то 1.5.0. Рақамҳоро ҳамчун рақам муқоиса мекунем.
