Дарси 15 · Async ва API

Кор бо API-и воқеӣ

Дӯкони интернетӣ ҳазорон молро дар HTML нигоҳ намедорад — вай онҳоро аз сервер мепурсад: «шаш молро нишон деҳ, дувоздаҳи аввалро гузарон, танҳо аз категорияи «телефонҳо»». Имрӯз шумо меомӯзед, ки чунин саволҳоро тавассути параметрҳои дархост диҳед ва ҷавобро ба рӯйхати зинда бо ҷустуҷӯ, филтрҳо ва саҳифаҳо табдил диҳед — каталогҳо, лентаҳо ва ҷустуҷӯ дар сайтҳои воқеӣ маҳз ҳамин тавр сохта шудаанд.

  • Суроғаи дархостро тавассути URLSearchParams ҷамъ кардан, бе андеша дар бораи фосилаҳо ва кириллитса
  • Ҳуҷҷатгузории API-ро хондан ва дар ҷавоб майдонҳои лозимаро ёфтан
  • Аз ҷавоби сервер рӯйхат кашидан, бе такрори кортҳо
  • Ҷустуҷӯро бе дархостҳои зиёдатӣ анҷом додан: debounce ва ҳимоя аз «мусобиқаи» дархостҳо
  • Филтр ва мураттаб кардан — дар сервер ва дар клиент
  • Саҳифаҳоро аз рӯи limit / skip ҳисоб кардан ва тугмаҳои «Ба қафо» / «Ба пеш»-ро идора кардан
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди дар заминаи торик бо тугмаи ▶ Иҷро кардан зинда аст: тағйир диҳед ва иҷро кунед. Мисолҳо бо fetch ба API-ҳои оммавии воқеӣ мераванд, барои ҳамин интернет лозим аст. Блокҳо бо ҷадвалҳои index.html / style.css / script.js — ин саҳифаи хурд аст: дар тарафи чап код, дар зери он пешнамоиш ва консол. Вазифаҳо худашон аз рӯи он ки шумо ба консол чоп мекунед, санҷида мешаванд. Агар ба сервер «бад» бошад (ҳолати нодир), хатои шабакаро мебинед — оддӣ боз як бор иҷро кунед. Ишораҳо зери қулфак 🔒: аввал худатон, баъд ишора.

Дар дарс се API-и оммавӣ бе калид ҳаст: DummyJSON (мол), Rick and Morty API (персонажҳо) ва андаке Open-Meteo (обу ҳаво) дар вазифаи хонагӣ.

01 Параметрҳои дархост: URL ва URLSearchParams

Ҳар дархост ба API — ин суроға аст. Аммо суроға на танҳо «ба куҷо рафтан»-ро, балки «чиро дақиқан овардан»-ро ҳам медонад. Барои ин баъд аз аломати ? параметрҳои дархост (query string) дар намуди ҷуфтҳои калид=қимат, ки бо & ҷудо шудаанд, илова мекунанд.

Қиёс аз ҳаёт

Фармоиш дар чойхона. «Курутоб» — ин роҳ аст: шумо чиро фармоиш медиҳед. «Бе piyoz, ҳиссаи калонтар, ду коса чой» — ин параметрҳо аст: возеҳкунӣ ба ҳамон хӯрок. Хӯрок як аст, фармоишҳо гуногунанд. Бо API ҳам чунин аст: роҳи /products як аст, параметрҳои limit, skip, q бошанд тағйир медиҳанд, ки ба шумо дақиқан чӣ меоранд.

Чаро сатрҳоро бо даст часпондан мумкин нест

Навомӯзон суроғаро ҳамин тавр ҷамъ мекунанд: "…?q=" + text + "&limit=" + limit. То даме ки дар text як калима бо лотинӣ бошад, ҳама чиз кор мекунад. Аммо ҳамин ки корбар фосила, &, # ё ҳарфи русӣ ворид кунад — суроға вайрон мешавад. URL қоидаҳои сахт дорад: чунин аломатҳоро бояд рамзгузорӣ кард (фосила → + ё %20, & → %26, кириллитса → %D0…).

Худамон рамзгузорӣ кардан — мушкил аст ва хато кардан осон. Барои ин дар браузер (ва дар Node.js) синфи тайёри URLSearchParams ҳаст.

const params = new URLSearchParams();
params.set("q", "плов & чай");   // фосилаҳо, &, кириллитса — ташвиши мо нест
params.set("limit", 5);          // рақам худаш ба сатр табдил меёбад
params.set("skip", 10);

console.log(params.toString());
// q=%D0%BF%D0%BB%D0%BE%D0%B2+%26+%D1%87%D0%B0%D0%B9&limit=5&skip=10

const url = "https://dummyjson.com/products/search?" + params;
console.log(url);   // объект худкор ба сатр табдил меёбад

URLSearchParams-ро фавран аз объект ё аз сатри тайёр сохтан мумкин аст — барои таҷзияи суроғаи бегона қулай аст:

const fromObject = new URLSearchParams({ q: "phone", limit: 5 });
console.log(fromObject.toString());

const fromString = new URLSearchParams("q=plov&limit=10&page=3");
console.log(fromString.get("q"));        // plov
console.log(fromString.get("limit"));    // "10" — сатр аст, на рақам!
console.log(fromString.get("sort"));     // null — чунин параметр нест
console.log(fromString.has("page"));     // true

Суроғаи пурра: URL

Барои таҷзияи суроғаи пурра синфи URL ҳаст: он searchParams дорад — ҳамон URLSearchParams, ки аллакай ба суроға пайваст шудааст.

02 Ҳуҷҷатгузорӣ ва ҷавоби API-ро мехонем

Ҳар API қоидаҳои худро дорад: параметрҳо чӣ ном доранд, ҷавоб чӣ тавр сохта шудааст, агар ҳеҷ чиз ёфт нашавад чӣ мешавад. Инро танҳо аз ҳуҷҷатгузорӣ ва аз худи ҷавоб фаҳмидан мумкин аст. Одати №1-и барномасоз: аввал бубинед, ки воқеан чӣ меояд ва танҳо баъд код нависед.

Аз дарси 14 шумо печонандаи болои fetch-ро дар хотир доред. Вай дар ҳар мисол лозим мешавад, барои ҳамин версияи кӯтоҳи вай инҷост — дар дарс вай дар аввали ҳар блок меистад:

async function getJson(url) {
  const response = await fetch(url);
  if (!response.ok) throw new Error("HTTP " + response.status);
  return response.json();
}

async function main() {
  const data = await getJson("https://dummyjson.com/products?limit=2&select=title,price");
  console.log(Object.keys(data));
  console.log(data.products);
  console.log("всего товаров на сервере больше, чем пришло:", data.total > data.products.length);
}
main();

Қиёс аз ҳаёт

Ҳуҷҷатгузории API — ин менюи чойхона аст. Шумо тахмин намекунед, ки дар ошхона чӣ ҳаст: менюро мекушоед ва хӯроку (эндпойнтҳо), ҳиссаҳо ва иловаҳоро (параметрҳо) мебинед. Ҷавоби сервер бошад — худи хӯрок дар табақ: пеш аз хӯрдан бояд бингаред, ки дар он чӣ ҳаст.

Ҳуҷҷатгузориро дар 2 дақиқа чӣ тавр хондан

  1. Эндпойнти лозимаро ёбед. «Ба ман ҷустуҷӯи мол лозим» → GET /products/search.
  2. Параметрҳоро нависед: кадомаш ҳатмӣ, кадомаш не, кадом қиматҳо иҷозат дода мешаванд (limit, skip, select, sortBy, order).
  3. Намунаи ҷавобро кушоед ва ёбед, ки рӯйхат дар куҷо ва майдонҳои хидматӣ дар куҷо ҳастанд.
  4. Бо даст санҷед: суроғаро ба браузер ё ба console.log гузоред ва боварӣ ҳосил кунед, ки ҷавоб чунон аст, ки дар ҳуҷҷатгузорӣ.
  5. Дар бораи «холӣ» ва «хато» бидонед: агар ҳеҷ чиз набошад, кадом статус ва кадом бадан меояд.

Як усули дигар: параметри select дар DummyJSON дар ҷавоб танҳо майдонҳои лозимаро мегузорад. Дархост сабуктар ва тезтар мешавад — барои чӣ тавсиф ва шарҳҳоро зеркашӣ кардан, агар ном ва нарх лозим бошад?

03 Рендери рӯйхат аз API

Маълумот омад — акнун онро дар саҳифа нишон медиҳем. Схема ҳамеша як аст: fetch → массив → барои ҳар унсур гиреҳ сохтан → ба саҳифа гузоштан. Ин ҳамон чизест, ки шумо дар дарсҳои 8 ва 11 мекардед, фақат массив акнун на аз тағйирёбанда, балки аз интернет меояд.

Debounce: интизор мешавем, то одам гапашро тамом кунад

Debounce («зидди ларзиш») амалро ба таъхир мегузорад ва ҳар даъвати нав интизориро аз сар оғоз мекунад. Амал танҳо дар сурате кор мекунад, ки корбар барои вақти додашуда хомӯш шуд — одатан 300–500 мс. Ин ҳамон setTimeout ва clearTimeout аз дарси 13 аст.

Қиёс аз ҳаёт

Пешхизмат дар чойхона баъд аз ҳар калимаи меҳмон ба ошхона намедавад. Вай интизор мешавад, то меҳмон гапашро тамом кунад: «курутоб… ва самбуса… ва чой… тамом». Танҳо баъд аз танаффус назди ошпаз меравад. Debounce — ин пешхизмати сабур аст: як танаффус дар сӯҳбат — як рафтан ба ошхона.

function debounce(fn, ms) {
  let timer;                       // таймер байни даъватҳо зинда мемонад
  return (...args) => {
    clearTimeout(timer);           // даъвати нав қаблиро бекор мекунад
    timer = setTimeout(() => fn(...args), ms);
  };
}

const find = debounce((text) => console.log("ищем:", text), 300);

find("п");
find("пл");
find("пло");
find("плов");      // танҳо даъвати охирин кор мекунад — баъд аз 300 мс

Функсия функсияи нав бармегардонад, ки дар дохили он таймер «пинҳон» аст (closure — шумо онро дар дарси 5 дидаед). Обуна дар барнома чунин менамояд:

  state.q = input.value.trim();
  state.page = 1;          // ҷустуҷӯи нав — ҳамеша аз саҳифаи аввал!
  load();
}, 400));

«Мусобиқа»-и дархостҳо: вақте ҷавоби кӯҳна баъд аз нав меояд

Ҳатто бо debounce чунин мешавад: шумо дархостро барои «ph» фиристодед, фикратон гашт ва «phone»-ро фиристодед. Сервер ба дархости дуюм тезтар, ба якум — дертар ҷавоб дод. Агар ҷавобҳоро ҳангоми омадан нишон диҳем, кӯҳна навро бознависӣ мекунад ва дар майдон «phone», дар рӯйхат — натиҷаҳо барои «ph» мешавад. Ин мусобиқаи дархостҳо (race condition) номида мешавад.

Қиёс аз ҳаёт

Шумо палав фармоиш додед, баъд аз як дақиқа фикратон гашт ва самбуса фармоиш додед. Агар ошпазон хӯрокҳоро аз рӯи омодагӣ биёранд, самбуса аввал меояд, баъд палави нолозимро «мерасонанд» — ва шумо чизи нодурустро мехӯред. Дуруст: ба ҳар фармоиш рақам додан ва танҳо хӯроки бо рақами охирин-ро қабул кардан.

const delays = { ph: 300, phone: 100 };   // ба «ph» сервер дертар ҷавоб медиҳад
const fakeFetch = (q) => new Promise((resolve) =>
  setTimeout(() => resolve("результаты для " + q), delays[q]));

async function search(q) {
  const result = await fakeFetch(q);
  console.log("показано:", result);
}

setTimeout(() => search("phone"), 50);
// дар экран «ph»-и кӯҳна мемонад — корбар на он чиро, ки ҷустуҷӯ кард, мебинад

Дору оддӣ аст: ҳар дархост рақами худро дорад, танҳо ҷавобро ба дархости аз ҳама наве нишон медиҳем:

const delays = { ph: 300, phone: 100 };
const fakeFetch = (q) => new Promise((resolve) =>
  setTimeout(() => resolve("результаты для " + q), delays[q]));

let lastRequest = 0;                    // рақами дархости охирин

async function search(q) {
  const id = ++lastRequest;             // рақами худро мегирем
  const result = await fakeFetch(q);
  if (id !== lastRequest) return;       // дар ин миён дархости нав рафт — партофта мешавад
  console.log("показано:", result);
}

search("ph");
setTimeout(() => search("phone"), 50);

05 Филтркунӣ ва мураттабкунӣ

Филтр кардан дар ду ҷой мумкин аст — ва аз интихоб суръат ва қулайӣ вобаста аст:

Филтр дар сервер

Шумо аз API танҳо лозимаро металабед: /products/category/smartphones. Маълумоти камтар меояд, дар каталогҳои калон (ҳазорон сабт) кор мекунад, бо пагинатсия мувофиқ аст. Аммо ҳар филтри нав — дархости нав.

Филтр дар клиент

Маълумот аллакай бор шудааст, шумо оддӣ болои массив filter мекунед. Фавран, бе шабака. Аммо танҳо дар сурате кор мекунад, ки маҷмӯи пурра дар даст бошад — барои каталогҳои азим ва боркунии саҳифавӣ мувофиқ нест.

Қиёс аз ҳаёт

Сервер — ин анбор дар «Корвон»: шумо занг мезанед ва мегӯед «танҳо қолинҳои сурхро фиристед» — лозимаро меоранд. Клиент — ин пештахтаи шумо: қолинҳо аллакай оварда шудаанд, шумо оддӣ сурхҳоро ба чап, боқиро ба рост мемонед. Анбор роҳро сарфа мекунад, пештахта — вақти интизориро.

Филтр дар клиент: filter + includes

Вақте шартҳоро омехта кардан лозим аст ва маълумот кам аст, массивро дар ҷояш филтр мекунем. Як шарт — як «элак»:

  { title: "Курутоб", category: "горячее", price: 35 },
  { title: "Шакароб", category: "салаты", price: 15 },
  { title: "Оши палав", category: "горячее", price: 40 },

function applyFilters(items, { q = "", category = "", maxPrice = Infinity }) {
  const text = q.trim().toLowerCase();
  return items.filter((item) => {
    if (text && !item.title.toLowerCase().includes(text)) return false;  // ҷустуҷӯ бе назардошти ҳарфи калон/хурд
    if (category && item.category !== category) return false;
    return item.price <= maxPrice;
  });
}

06 Пагинатсия: саҳифаҳо аз рӯи limit ва skip

Дар каталог 194 мол ҳаст — ҳамаро якбора бор кардан нодонист: дароз, вазнин ва касе он қадар намегардонад. Барои ҳамин сервер маълумотро ҳисса-ҳисса медиҳад, шумо бошед ҳиссаи лозимаро металабед. Ин аст пагинатсия (боркунии саҳифавӣ).

Қиёс аз ҳаёт

Палавро дар тӯй на бо тамоми дег, балки бо ҳисса дар лаганҳо медиҳанд: дар ҳар кадом — даҳ ҳисса. Иловаи дигар мехоҳед — лагани навбатӣ металабед. Параметри limit — дар як лаган чанд ҳисса, skip — чанд ҳиссаро шумо аллакай хӯрдед ва мегузаронед.

Тугмаҳои «Ба қафо» ва «Ба пеш»

Ҳолати пагинатсия — ҳамагӣ ду рақам аст: саҳифаи ҷорӣ ва шумораи умумии саҳифаҳо. Ҳама чизи дигар аз онҳо кашида мешавад:

  • «Ба қафо» дар саҳифаи аввал хомӯш мешавад: prev.disabled = page === 1.
  • «Ба пеш» дар охирин хомӯш мешавад: next.disabled = page === pages.
  • Ёддошти «Саҳифаи 3 аз 5» аз ҳамин рақамҳо ҷамъ мешавад.
  • Баъд аз ҷустуҷӯи нав ё иваз шудани категория саҳифа ба аввал барқарор мешавад — вагарна дар саҳифаи 7-уми натиҷаҳо мондан мумкин аст, ки ҳамагӣ се то аст.
Хатоҳои маъмул

1. skip = page * limit бе «−1» — як саҳифаи пурра гузаронда мешавад, ҳиссаи аввали мол ҳеҷ гоҳ намоён нест. 2. Саҳифаҳоро тавассути Math.floor ё Math.round ҳисоб мекунанд — саҳифаи охирин гум мешавад. 3. page = 1-ро ҳангоми ҷустуҷӯи нав барқарор карданро фаромӯш мекунанд. 4. Ҷустуҷӯи холӣ дар DummyJSON total: 0 бармегардонад — ба нул тақсим кардан тарсовар нест, аммо «саҳифаи 1 аз 0» аҷиб менамояд: ҳадди ақал як саҳифаро нишон диҳед (Math.max(1, …)).

07 Блоки ЗС: ҳуҷҷатгузории API-ро бо ЗС якҷоя мехонем

Ҳуҷҷатгузориҳо дароз, бо забони англисӣ ва чунон навишта шудаанд, ки параметри лозимаро ёфтан душвор аст. ЗС аъло кумак мекунад, ки зуд эндпойнт ва параметрҳоро ёбед — агар худи матни ҳуҷҷатгузориро ба он диҳед. Аммо вай нуқсон дорад: вақте ҳуҷҷатгузорӣ дар даст нест, вай параметрҳоеро ихтироъ мекунад, ки ба ҳақиқат монанданд, аммо дар API-и шумо вуҷуд надоранд.

Қоидаҳои курс, ки дар ин ҷо махсусан муҳиманд

1. Аввал 15 дақиқа худатон кӯшиш мекунед: ҳуҷҷатгузориро мекушоед, эндпойнтро меҷӯед, суроғаро дастӣ менависед. 2. Баъд назди ЗС меравед. 3. Ба лоиҳа коде гузоред, ки онро сатр ба сатр шарҳ дода наметавонед. 4. Ҳар чизе, ки ЗС дар бораи параметрҳои API гуфт, бо ҷавоби воқеии сервер муқоиса кунед — бо дархост дар консол.

Чӣ тавр пурсидан: бад ва хуб

Формулаи промпти курс: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш. Барои ҳуҷҷатгузорӣ муҳимтаринаш — матни онро гузоштан (ё порчаи лозимаро), на хоҳиш кардани «ба ёд овардан».

дар dummyjson молро аз рӯи категория ва ном якбора чӣ тавр ҷустуҷӯ кунам
Ман JavaScript меомӯзам, каталоги молро бо JS-и пок бе китобхонаҳо менависам. Инак порчаи ҳуҷҷатгузории DummyJSON: [матнро аз саҳифаи https://dummyjson.com/docs/products гузоред]. Ба ман лозим: саҳифаи 6 молро нишон додан, аз рӯи ном ҷустуҷӯ кардан ва аз рӯи категория филтр кардан. Бигӯ: кадом эндпойнт барои ҷустуҷӯ, кадом барои категория, онҳо кадом параметрҳо доранд (limit, skip, select, sortBy, order) ва оё онҳоро омехта кардан мумкин аст. Бо ҷадвали «вазифа → эндпойнт → параметрҳо» ва як мисоли дархост бо fetch ва URLSearchParams ҷавоб деҳ. Агар дар ҳуҷҷатгузорӣ чизе набошад, ҳамин тавр бигӯ, чизеро ихтироъ накун. Дар охир бинвис, ки ман дар консол чиро дастӣ санҷам.

Промпти хубро нусха кунед, матни воқеии ҳуҷҷатгузориро гузоред — ва ҷавоб гиред. Ва акнун доми асосиро месанҷем: агар ба параметри ихтироъшуда бовар кунем чӣ мешавад. Фарз кунем, ЗС бо боварӣ ?category=smartphones-ро ба ҷустуҷӯ маслиҳат дод:

function buildProductsUrl(page, limit, q) {
  const skip = page * limit;
  let url = "https://dummyjson.com/products?limit=" + limit + "&skip=" + skip;
  if (q) url += "&q=" + q;
  return url;
}

function debounce(fn, ms) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

let lastRequest = 0;
async function load() {

  statusEl.textContent = "Загрузка…";

    const response = await fetch(buildUrl());
    if (!response.ok) throw new Error("HTTP " + response.status);

}

  • Филтр ва мураттабкунӣ: дар сервер (/category/…, sortBy, order) — барои маълумоти калон; дар клиент (filter, includes) — барои аллакай боршуда. На ҳамаи параметрҳои API бо ҳам мувофиқанд — ҳуҷҷатгузориро бихонед.
  • Пагинатсия: skip = (page − 1) × limit; саҳифаҳо Math.ceil(total / limit); «Ба қафо» дар саҳифаи 1 хомӯш аст, «Ба пеш» — дар охирин; дар Rick and Morty — page ва info.pages / info.next.
  • Сохтори барнома: state → buildUrl() → load() → render() + updatePager(). Ҳодисаҳо танҳо ҳолатро тағйир медиҳанд ва load()-ро даъват мекунанд.
