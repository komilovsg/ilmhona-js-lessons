Дарси 12 · 🏁 Лоиҳаи хурди №1

Лоиҳаи хурд: трекери вазифаҳо ё одатҳо

Аввалин лоиҳаи воқеӣ барои портфолио: барнома бо JavaScript-и холис, ки маълумоти шуморо ҳатто баъди аз нав бор шудани саҳифа дар хотир медорад. Чунин трекерҳо паси Todoist, Notion ва даҳҳо барномаҳои телефон истодаанд, ва имрӯз шумо трекери худро месозед, онро дар назди гурӯҳ ҳимоя мекунед ва ба GitHub бор мекунед.

  • Варианти лоиҳаро интихоб кардан ва онро ба 10–15 зервазифа бо баҳои вақт тақсим кардан
  • Барномаро гирди як объекти ҳолат ва функсияи render ҷамъ кардан
  • Шакл, вакилкунии ҳодисаҳо, филтрҳо ва захираро дар localStorage пайваст кардан
  • Code review-ро дар ҷуфт аз рӯи чек-лист гузаронидан ва эродҳоро ислоҳ кардан
  • Лоиҳаро дар 5 дақиқа ҳимоя кардан: нишон додан, кодро шарҳ додан, ба саволҳо ҷавоб додан
  • Лоиҳаро ба GitHub бор кардан ва чунон оро додан, ки нишон додан шармовар набошад
Бо ин саҳифа чӣ тавр кор кардан лозим

Имрӯз дарси-лоиҳа аст. Қисми болоии саҳифа — супориш, меъёрҳои баҳогузорӣ ва нақша. Дар миёна — гармкунӣ: вазифаҳои кӯтоҳ, ки аз онҳо трекер ҷамъ мешавад (ҳолат, кашидан, ҳодисаҳо, филтрҳо, захира). Ҳар кадом худкор санҷида мешавад, мисли дарсҳои гузашта. Минбаъд — қолаби оғозӣ дар қуттии санҷиш, чек-лист барои санҷиш дар ҷуфт, нақшаи ҳимоя ва бор кардан ба GitHub. Лоиҳаро шумо дар VS Code-и худ ҷамъ мекунед, ва дар ин ҷо машқ мекунед ва муқоиса мекунед.

01 Супориш: вариантро интихоб кунед

Лоиҳа аз он чи шумо дар дарсҳои 8–11 кардаед, ҷамъ мешавад: рӯйхат дар DOM, ҳодисаҳо, шакл, ҳолат дар як объект ва захира. Имрӯз мо ҳама чизро то барномаи корӣ мерасонем, якдигарро месанҷем ва ҳимоя мекунем. Яке аз ду вариантро интихоб кунед — мувофиқи ҳамон меъёрҳо баҳо медиҳем.

Варианти А. Трекери вазифаҳо

Рӯйхати корҳо: вазифа менависед, илова мекунед, иҷрошуда қайд мекунед, нест мекунед. Филтрҳои «Все / Активные / Готовые» ва ҳисобкунаки «Осталось: 3 из 5» ҳастанд.

Ниҳод: { id, title, done }

Варианти Б. Трекери одатҳо

Рӯйхати одатҳо («Читать 20 минут», «Тренировка»). Ҳар рӯз «анҷом шуд»-ро қайд кардан мумкин аст, барнома силсилаи рӯзҳои пай дар пай ва чанд одат имрӯз иҷро шудааст, нишон медиҳад.

Ниҳод: { id, name, days: ["2026-10-14", …] }

Вариантҳо аз рӯи мураккабӣ қариб баробаранд: дар одатҳо мантиқ мураккабтар (санаҳо ва силсила), дар вазифаҳо — ҳолатҳои намоиши бештар (филтрҳо). Агар шумо танҳо навакак бо эътимод код навиштан оғоз карда бошед — вазифаҳоро гиред. Мехоҳед чолиш — одатҳо. Ғояи худро пешниҳод кардан мумкин аст, аммо танҳо дар сурате ки аз рӯи ҳаҷм ҳамон қадар бошад ва шумо онро бо омӯзгор пеш аз оғози кор мувофиқа карда бошед.

Муқоиса аз ҳаёт

Дафтарчаеро тасаввур кунед, ки модар дар он менависад, ки дар бозор чӣ харидан лозим. Харидашударо хат зад — сабт монд, аммо дигар менамояд. Дафтарро баст, фардо кушод — сабтҳо ба ҷояш. Трекери шумо — ҳамин гуна дафтар аст: ҳолат — ин сабтҳост, render — онҳо дар саҳифа чӣ гуна менамоянд, localStorage — худи дафтар, ки ҳангоми бастан гум намешавад.

Шумо дар охир чиро нишон медиҳед

  1. Барномаи кор — дар браузер бе хато дар консол кушода мешавад.
  2. Репозиторий дар GitHub бо код ва README (ин чист, чӣ тавр оғоз кардан, скриншот).
  3. Ҳимоя дар 5 дақиқа — намоиш, шарҳи код ва ҷавоб ба саволҳо.
Қоидаҳои курс дар ин ҷо ҳам амал мекунанд

ЗС-ро истифода бурдан мумкин аст (мо ҳатто дар поён омӯхтани онро мекунем), аммо мувофиқи қоидаҳои курс: аввал 15 дақиқа худатон кӯшиш мекунед, коде, ки сатр ба сатр шарҳ дода наметавонед, ворид намекунед, ва дар ҳимоя омӯзгор ҳақ дорад хоҳиш кунад, ки ҳар сатрро шарҳ диҳед. Натавонистед — холҳо барои ин қисм кам карда мешаванд.

02 Талабот: MVP ва бонусҳо

MVP (minimum viable product) — версияи ҳадди ақал, ки аллакай муфид аст ва аз аввал то охир кор мекунад. Аввал онро пурра месозем, ва танҳо баъд вақтро ба оро сарф мекунем. Лоиҳа бе MVP баҳои баланд намегирад, ҳар қадар бонус дошта бошад.

Бонусҳо — баъди MVP

  • Таҳрир: клики дучанда ба матн онро ба майдони воридкунӣ табдил медиҳад (Enter — захира, Esc — бекор).
  • Тугмаи «Очистить выполненные» бо тасдиқ.
  • Ҷустуҷӯ дар рӯйхат дар вақти воқеӣ (ҳодисаи input).
  • Афзалиятҳо ё категорияҳо бо нишонаҳои рангин.
  • Мавзӯи торик бо захираи интихоб.
  • Мураттабсозӣ: аз рӯи алифбо, аз рӯи санаи илова.
  • Барои одатҳо: ҳафта дар шакли 7 нуқта бо қайдҳо аз рӯи рӯзҳо ва «беҳтарин силсила».
Маслиҳат

Бонусҳоеро интихоб кунед, ки шумо метавонед дар ҳимоя шарҳ диҳед. Як бонуси оддӣ, ки шумо ҳар сатри онро мефаҳмед, аз се пораи «сеҳрнок»-и код аз чат бо ЗС қиматтар аст.

Чӣ холҳоро кам мекунад

  • Кодро шарҳ дода наметавонед — дар меъёре, ки қисми нофаҳмо ба он тааллуқ дорад, холҳо гум мекунед (қоидаи курс №2 ва №3).
  • Ба мӯҳлат супорида нашуд — то −10 хол, бо мувофиқа бо омӯзгор.
  • Код пурра аз донишҷӯи дигар ё аз чат бе фаҳмиш нусха шудааст — 0 барои лоиҳа. Ба якдигар кӯмак кардан мумкин ва лозим аст, аммо ҳар кас аз они худро менависад ва мефаҳмад.

04 Декомпозитсия: лоиҳаро якҷоя бо ЗС тақсим мекунем

Хатои асосии навомӯз пеш аз лоиҳаи калон — нишаста «ҳама чизро якбора» навиштан оғоз кардан. Баъди як соат код ба бесаранҷомӣ табдил меёбад, нофаҳмо аст, ки чӣ аллакай кор мекунад, ва мехоҳӣ ҳамаро партоӣ. Касбиён дигар хел мекунанд: аввал вазифаро ба қадамҳои хурд тақсим мекунанд, вақти ҳар кадомро баҳо медиҳанд ва пай дар пай мераванд. Ин декомпозитсия номида мешавад.

Муқоиса аз ҳаёт

Палави тӯйро барои 200 нафар «ягон тавр» намепазанд. Аввал рӯйхат: гӯшт ва биринҷ харидан, сабзиро буридан, оташ афрӯхтан, зирвакро андохтан, биринҷро резондан, ба дам гузоштан. Барои ҳар қадам — вақт ва масъул. Лоиҳа — ҳамон палав: мақсади калон, аз қадамҳои хурд.

Блоки ЗС-и дарс: вазифаи калон — нофаҳмо, аз куҷо оғоз кардан

Ин вазъияти №10 аз китобхонаи промптҳои курс аст. ЗС рӯйхати қадамҳоро олӣ пешниҳод мекунад, аммо тартиб, зиёдатӣ ва баҳои вақтро шумо месанҷед. Аз версияи бе қоида оғоз кунед, баъд — бо формулаи курс: контекст → вазифа → маҳдудиятҳо → формат → санҷиш.

трекери вазифаҳоро чӣ тавр сохтан
Контекст: ман донишҷӯи курси JavaScript ҳастам, лоиҳаи таълимии «трекери вазифаҳо»-ро бо JS-и холис бе китобхонаҳо ва фреймворкҳо менависам. Аллакай медонам: DOM, ҳодисаҳо, шаклҳо, localStorage, объектҳо ва массивҳо. Вазифа: лоиҳаро ба 10–15 зервазифаи 20–40 дақиқагӣ ба тартиби иҷро тақсим кун. Маҳдудиятҳо: дар MVP танҳо илова, қайд, нест кардан, филтрҳо, ҳисобкунак ва захира. Ягон китобхона. Бонусҳоро бо рӯйхати алоҳида дар охир баровар. Формати ҷавоб: рӯйхати рақамдор. Дар ҳар банд: ном, баъди он чӣ бояд кор кунад, баҳо бо дақиқа. Санҷиш: баъди рӯйхат 3 ҷойро ном бар, ки навомӯз дар ин лоиҳа бештар хато мекунад.

Промпти аввал суханони умумӣ медиҳад ва шояд фавран тамоми кодро, ки шумо шарҳ дода наметавонед. Дуюм нақшае медиҳад, ки бо он кор кардан мумкин аст. Аммо ин танҳо чернавик аст. Ба намунаи натиҷа баъди ислоҳи шумо нигоҳ кунед:

Бо ҷавоби ЗС чӣ мекунед — қадам ба қадам

  1. Зиёдатиро хат занед. Агар ЗС «Webpack-ро танзим кун» ё «React-ро пайваст кун»-ро пешниҳод кард — ин дар бораи лоиҳаи мо нест. Мо бо JS-и холис.
  2. Тартибро санҷед. «Захира»-ро пеш аз «ҳолат» кардан мумкин нест: аввал бояд донист, чиро захира кардан. Ҳар қадам бояд ба қадамҳои тайёри пешина такя кунад.
  3. Вақтро худатон баҳо диҳед. ЗС намедонад, ки барои шумо чӣ қадар вақт меравад. То ҳол таҷриба нест, баҳои ӯро ба 1.5 зарб кунед. Ҳар қадаме, ки аз 40 дақиқа дарозтар аст — боз тақсим кунед.
  4. Ҳар қадам бояд натиҷаи намоён диҳад. «Дар бораи меъморӣ фикр кардан» — қадам нест. «Функсияи addTask санҷишро дар консол мегузарад» — қадам аст.
  5. MVP-ро аз бонусҳо ҷудо кунед. Бонусҳоро танҳо вақте иҷро мекунем, ки ҳама чизи MVP кор мекунад.
  6. Нақшаро нависед дар файли PLAN.md ё шарҳ — ва иҷрошударо қайд кунед. Ҳар нишона — пешрафти намоён, ва он ангезаро нигоҳ медорад.

function createTaskItem(task) {
  const li = document.createElement("li");
  li.textContent = task.title;
  if (task.done) li.classList.add("done");

}

function render(state, list) {

Ҳолат ҳаст, кашидан ҳаст. Боқӣ мондааст, ки интерфейсро зинда кунем: ирсоли шакл ва кликҳо ба вазифаҳоро бигирем. Дар лоиҳа айнан ду коркардкунандаи муҳим хоҳад буд: submit дар шакл ва click дар рӯйхат.

09 Гармкунии 5. Захира: localStorage ва JSON

Хишти охирини MVP — то маълумот баъди бастани ҷадвал гум нашавад. localStorage — ин анбори хурд бевосита дар браузер аст: ҷуфтҳои «калид — қимат». Се усул, ки қариб ҳамеша лозиманд: setItem(key, value), getItem(key) ва removeItem(key).

Маҳдудияти асосӣ: танҳо сатрҳо нигоҳ дошта мешаванд. Адад ба сатри "10" табдил меёбад, ва объект ба "[object Object]"-и бефоида. Бинобар ин ҳолатро пеш аз навиштан ба сатри JSON табдил медиҳем (JSON.stringify), ва баъди хондан — боз ба объект (JSON.parse).

Эзоҳ дар бораи қуттии санҷиши ин саҳифа

Коди ин саҳифа дар «қуттии санҷиш»-и ҷудогонаи браузер иҷро мешавад — ин ҳимоя аст, то коди бегона ба маълумоти шумо нарасад. Дар он localStorage-и воқеӣ банд аст. Бинобар ин дар машқҳо мо ивазкунак-ро истифода мебарем — объекти storage бо ҳамон API (getItem, setItem, removeItem), ки маълумотро дар хотира нигоҳ медорад. Мантиқи код дар ин ҳол як ва ҳамон аст. Дар лоиҳаи худи шумо дар VS Code тамоми блокро бо як сатр иваз мекунед: const storage = localStorage;.

try {
  localStorage.setItem("test", "1");
  console.log("localStorage работает");
} catch (error) {
  console.log("localStorage недоступен:", error.name);
}

Одатан шумо SecurityError-ро мебинед. Ин муқаррарӣ аст: маҳз бинобар ин мо дар зер тавассути ивазкунак кор мекунем. Онро нусха кунед — он дар ҳар машқи ин бахш лозим аст:

const storage = {
  data: {},
  getItem(key) { return key in this.data ? this.data[key] : null; },
  setItem(key, value) { this.data[key] = String(value); },   // мисли воқеӣ: ҳама чиз ба сатр
  removeItem(key) { delete this.data[key]; },
};

Ҳангоми фиристодани бастаи аз Душанбе ба Хуҷанд шумо ҷевонро пурра намебаред: ҷудо мекунед, ба қуттиҳо мепечонед (JSON.stringify), ва гиранда боз ҷамъ мекунад (JSON.parse). Анбор танҳо «қуттиҳо»-ро мефаҳмад — яъне сатрҳоро.

Маълумотро бехатар мехонем

Маълумот дар localStorage метавонад вайрон шуда бошад, онро корбар метавонист дастӣ ислоҳ кунад, ва ҳангоми оғози аввал он танҳо нест. Агар бешубҳа JSON.parse-ро даъват кунед, барнома ҳанӯз пеш аз кадри аввал меафтад. Бинобар ин чунин мехонем: try/catch + санҷиши шакл + варианти эҳтиётӣ.

12 Code review: якдигарро месанҷем

Code review — вақте ки як барномасоз коди дигарро пеш аз он ки он «ба олам биравад», мехонад. Ин имтиҳон нест ва ҷустуҷӯи гунаҳкор нест: назари тоза онро мебинад, ки муаллиф кайҳо мушоҳида карданро бас кардааст. Дар дастаҳои воқеӣ бе ревью код умуман қабул намешавад.

Муқоиса аз ҳаёт

Пеш аз тӯй палавро на танҳо ошпаз, балки боз ду-се нафар чашида мебинанд: ошпаз ба маза одат кардааст ва метавонад нафаҳмад, ки намак кам аст. Ревью — ҳамон «чашидани аз берун» аст.

Ревью чӣ тавр мегузарад (10 дақиқа барои лоиҳа)

  1. 2 дақ — оғоз. Муаллиф барномаро нишон медиҳад, баррасикунанда худаш онро вайрон кардан мехоҳад.
  2. 5 дақ — хондани код. Баррасикунанда аз рӯи чек-листи зер мегузарад ва эродҳоро менависад.
  3. 3 дақ — гуфтугӯ. Се банди «чӣ хуб аст», се — «чиро беҳтар кардан». Муаллиф саволҳои равшанкунанда медиҳад ва қарор медиҳад, чиро қабул кунад.

Чек-листи баррасикунанда

Вайрон кардан мехоҳем (оғоз)

  • ☐ Сатри холӣ ва танҳо фосилаҳо илова намешаванд
  • ☐ Enter дар майдон мисли тугма кор мекунад
  • ☐ Номи хеле дароз тарҳро вайрон намекунад
  • ☐ Номи <b>test</b> ҳамчун матн нишон дода мешавад
  • ☐ Миёнаи рӯйхатро нест кардем, навро илова кардем — ҳама чиз кор мекунад
  • ☐ F5 — маълумот ба ҷояш
  • ☐ Ба localStorage дастӣ хасу хошок навиштан, F5 — барнома зинда аст
  • ☐ Дар консол хатои сурх нест
  • ☐ Дар паҳноии 360 px ҳама чиз хонданӣ аст

Код мехонем

  • ☐ Як объекти ҳолат, на тағйирёбандаҳои пароканда
  • ☐ render интерфейсро аз ҳолат месозад ва рӯйхатро пок мекунад
  • ☐ Функсияҳо болои ҳолат ҳолати кӯҳнаро тағйир намедиҳанд
  • ☐ preventDefault ва санҷиш ҳаст
  • ☐ Ҳодисаҳои рӯйхат — тавассути вакилкунӣ, на дар ҳар элемент
  • ☐ Матни корбар тавассути textContent
  • ☐ Хондан аз localStorage бо try/catch муҳофизат шудааст
  • ☐ Номҳои фаҳмо, a, x, data2 нест
  • ☐ Нусхабардорӣ, коди шарҳшуда ва console.log-и зиёдатӣ нест
  • ☐ Сатрҳои «ҷодугарӣ» ("done", калиди анбор) ба константаҳо баровардаанд

function addTask(state, title) {

function getVisible(tasks, filter) {
  if (filter === "activ") return tasks.filter((t) => !t.done);
  if (filter === "done") return tasks.filter((t) => t.done);
  return tasks;

Саволҳои маъмул ва дар бораи чӣ бояд гуфт

state чист ва дар ту дар куҷост?
Як объект бо ҳамаи маълумоти барнома: рӯйхат, филтр, id-и навбатӣ. Саҳифа аз он кашида мешавад. Онро дар код нишон диҳед.
Чаро render ҳар дафъа рӯйхатро аз нав месозад?
Осонтар ва боэътимодтар: ҷустан лозим нест, ки кадом элемент тағйир ёфт. Саҳифа ҳамеша ба ҳолат мувофиқ аст. Барои рӯйхати хурд ин зуд аст.
Вакилкунӣ чист ва чаро дар ин ҷо лозим аст?
Як коркардкунанда дар рӯйхат ба ҷои коркардкунанда дар ҳар тугма. Баъди render элементҳо аз нав сохта мешаванд, аммо коркардкунанда дар падар мемонад ва барои элементҳои нав кор мекунад.
Чаро дар submit preventDefault лозим аст?
Бе он браузер шаклро мефиристад ва саҳифаро аз нав бор мекунад — ҳолат дар хотира гум мешавад.
Дар localStorage чӣ ва бо кадом намуд мемонад?
Сатри JSON бо ҳолат таҳти калиди лоиҳа. Анбор танҳо сатрҳоро мефаҳмад, бинобар ин JSON.stringify ҳангоми навиштан ва JSON.parse ҳангоми хондан.
Агар дар анбор хасу хошок бошад, чӣ мешавад?
try/catch дар атрофи JSON.parse ва санҷиши шакл: ҳангоми мушкилот барнома бо ҳолати холӣ оғоз мешавад ва намеафтад.
Id дар ту чӣ тавр ҳисоб мешавад? Баъди нест кардан чӣ?
Тавассути ҳисобкунаки алоҳидаи nextId, ки танҳо меафзояд. length + 1 такрор медод.
Чаро textContent, на innerHTML?
Матни корбарро ҳамчун аломатгузорӣ қабул кардан мумкин нест: вагарна ба барнома HTML ва скриптҳои бегонаро андохтан мумкин аст.
ЗС-ро дар куҷо истифода кардӣ? Ин сатрро шарҳ деҳ.
Ростқавлона бигӯед, барои чӣ: декомпозитсия, шарҳи хато, санҷиш. Ҳар сатре, ки омӯзгор нишон дод, бояд бо суханони худ шарҳ дода шавад.
Агар боз як рӯз медоштӣ, чиро беҳтар мекардӣ?
1–2 чизи мушаххасро ном баред: таҳрир, ҷустуҷӯ, санҷишҳо. Ин нишон медиҳад, ки шумо маҳдудиятҳои лоиҳаро мебинед.

Маслиҳатҳо барои омодагӣ

  • Сенарияи намоишро бо овози баланд бо секундомер ақаллан як маротиба гузаред.
  • Файлҳои лозимиро пешакӣ кушоед ва ҳарфро дар муҳаррир калон кунед: гурӯҳ бояд кодро бубинад.

Лоиҳае, ки танҳо дар ноутбуки шумост, барои корфармо вуҷуд надорад. GitHub — портфолиои шумост. Git-и асосӣ (init, commit, push)-ро шумо аз талаботи воридшавии курс медонед; мунтазам онро дар дарси 19 таҳлил мекунем, ва имрӯз — роҳи ҳадди ақали «папка → репозиторий».

  2. Git-ро дар папкаи лоиҳа ибтидо кунед ва коммити аввалро созед: 
    git init
git add .
git commit -m "add tracker app"
  3. Репозиторийро пайваст кунед ва кодро фиристед. Суроғаро аз саҳифаи репозиторийи нав нусха кунед (ба ҷои ВАШ_ЛОГИН номи худро дар GitHub гузоред): 
    git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/task-tracker.git
git push -u origin main
  4. Натиҷаро санҷед. Саҳифаи репозиторийро нав кунед: файлҳо ба ҷояшон, дар реша index.html намоён аст. Репозиторийро дар тирезаи хусусии браузер ё аз телефон кушоед — истинод бояд бе вуруд ба ҳисоб кушода шавад.
  5. README.md-ро аз рӯи қолаби зер илова кунед, скриншоти барномаро гиред ва ба репозиторий гузоред.
  6. Ислоҳотро аз рӯи ревью бо коммитҳои алоҳида бор кунед — ҳамин тавр дар таърих намоён аст, ки шумо чиро такмил додед:

git push
