Давраҳо (цикл)

Дар саҳифа 100 молро нишон додан, аз ҳамаи ҳарфҳои парол гузаштан, даромади моҳро ҳисоб кардан, ҷадвал кашидан — ҳамааш «як корро бисёр маротиба кун» аст. Як сатри яксонро сад маротиба навиштан касе нахоҳад кард: барои ин давраҳо (цикл) ҳастанд. Имрӯз шумо навиштани онҳо, қатъ кардани онҳо ва — ки камтар муҳим нест — роҳ надодан ба он ки онҳо ҳеҷ гоҳ қатъ нашаванд, меомӯзед.

  • Амалро тавассути while, for ва do..while такрор кунед ва шарҳ диҳед, ки давра қадам ба қадам чӣ тавр мегузарад
  • Давраи мувофиқи вазифаро интихоб кунед
  • Ҷараёни давраро тавассути break ва continue идора кунед
  • Сатрро ҳарф ба ҳарф бо ёрии for..of аз назар гузаронед
  • Натиҷаро дар тағйирёбанда ҷамъ кунед: маблағ, ҳисобкунак, ҳадди аксар, сатр
  • Бо давраҳои дарунҷоӣ ҷадвал ва шаклҳо кашед ва давраи беохирро бишносед
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Тамоми код дар заминаи торик бо тугмаи ▶ Иҷро кардан — зинда аст. Онро бевосита дар ин ҷо тағйир диҳед ва натиҷаро дарҳол дар консоли поёни он бинед. Вайрон кардед — ↺ Аз нав-ро пахш кунед. Ишораҳои вазифаҳо пинҳон шудаанд: аввал худатон кӯшиш кунед, ишораро танҳо вақте кушоед, ки монд шудед. Имрӯз мо танҳо аз он чи аллакай медонем, истифода мебарем: тағйирёбандаҳо, навъҳо ва шартҳо. Функсияҳо ва массивҳо ҳоло нестанд — онҳо дар дарсҳои 5 ва 6 мебошанд.

01 Давраҳо барои чӣ лозиманд. Давраи while

Тасаввур кунед, ки шумо дар остонаи MakeFirstStep панҷ меҳмонро пешвоз мегиред. Бе давраҳо код чунин менамояд:

console.log("Гость №1, добро пожаловать!");
console.log("Гость №2, добро пожаловать!");
console.log("Гость №3, добро пожаловать!");
console.log("Гость №4, добро пожаловать!");
console.log("Гость №5, добро пожаловать!");

Панҷ сатр — ҳанӯз тоқатфарсо нест. Аммо агар меҳмонон 500 бошанд? Ва агар шумораи онҳо пешакӣ маълум набошад? Дар ин ҷо давра ба кумак меояд — сохторе, ки блоки кодро то даме ки шарт иҷро мешавад, такрор мекунад. Соддатарин давра — while («то даме ки»):

let i = 1;                 // 1. оғоз: ҳисобкунак аз 1 сар мешавад
while (i <= 5) {           // 2. шарт: то даме ки true аст, такрор мекунем
  console.log(`Гость №${i}, добро пожаловать!`);
  i++;                     // 3. қадам: ҳисобкунакро иваз мекунем
}
console.log("Все гости встречены");
Ташбеҳ аз зиндагӣ

Шумо дар тӯй ошӣ палав тақсим мекунед. Қоида содда: то даме ки дар қазон палав ҳаст — боз як табақ мекашем. Пеш аз ҳар табақ ба қазон менигаред (шартро месанҷед). Палав ҳаст — мекашед (бадани давраро иҷро мекунед). Қазон холӣ — тамом. Чанд табақ мешавад, пешакӣ намедонед: ин аз қазон вобаста аст.

while қадам ба қадам чӣ тавр кор мекунад

  1. Санҷиши шарт. JavaScript ифодаро дар қавсҳо пас аз while ҳисоб мекунад. Ин ҳамон ифодаест, ки дар if: true ё false.
  2. Агар true — ҳар он чи дар қавсҳои фигурӣ аст, иҷро мешавад. Ин бадани давра аст.
  3. Бозгашт ба қадами 1. Ба қавси пӯшанда расидем — боз шартро месанҷем.
  4. Агар false — давра тамом мешавад, барнома ба пеш, ба сатри пас аз } меравад.

Ёдоварӣ: навиштҳои кӯтоҳ

i++ — ҳамон чизест, ки i = i + 1. i-- — ба 1 кам кардан. i += 2 — 2 илова кардан, money -= 6 — 6 тарҳ кардан. Ин навиштҳоро мо дар ҳар давра вомехӯрем.

while, вақте ки шумораи давр пешакӣ маълум нест

Қуввати асосии while — ҳолатҳои «кун, то даме ки чизе рух диҳад». Масалан, то даме ки пул барои чой кифоя аст:

let money = 20;          // сомонӣ дар ҳамён
const teaPrice = 6;      // нархи як чойник чой

while (money >= teaPrice) {
  money -= teaPrice;
  console.log(`Выпили чай. Осталось: ${money} сомони`);
}
console.log("Денег на чай больше нет");

Чанд чойник мешавад, пешакӣ намоён нест, давра худаш ҳисоб кард. Агар шумораи такрор фавран маълум бошад («маҳз 5 меҳмон»), навишти дигар — for — қулайтар аст, дар бораи он дар бахши оянда.

Хатоҳои маъмул

1. Агар шарт аз худи аввал дурӯғ бошад, бадан ягон маротиба иҷро намешавад — ва ин муқаррарӣ аст, танҳо чизе бароварда намешавад. 2. Агар тағйир додани ҳисобкунакро (i++) фаромӯш кунед, шарт то абад рост мемонад ва давра абадӣ давр мезанад — ин давраи беохир аст. Мо онро дар бахши 08 алоҳида таҳлил мекунем, наметарсед.

let n = 10;
while (n < 5) {
  console.log("Сюда мы не попадём");
  n++;
}
console.log("Конец, n =", n);   // → Конец, n = 10

02 Давраи for

Дар давраи while се қисми муҳим — оғоз, шарт ва қадам — дар код пароканда шудаанд: оғоз болотар аз давра, қадам дар охири бадан. Чизеро фаромӯш кардан осон аст. Давраи for ҳамаи инро дар як сатр ҷамъ мекунад:

for (let i = 1; i <= 5; i++) {
  console.log(`Гость №${i}, добро пожаловать!`);
}

Натиҷа ҳамон аст, ки дар while-и бахши гузашта, вале код камтар аст ва ҳар се қисм фавран намоён мебошад.

Ташбеҳ аз зиндагӣ

Маршруткаи №8 аз болои истгоҳҳо мегузарад. Сарлавҳаи for — ҷавоб ба се савол аст: дар кадом истгоҳ нишастӣ (let i = 1), то кадом истгоҳ меравӣ (i <= 5) ва чӣ тавр меравӣ — яктогӣ ё як истгоҳ гузашта (i++). Бадани давра — ин он аст, ки дар ҳар истгоҳ мекунӣ: ба тиреза менигарӣ, мебароӣ, пул медиҳӣ.

Ҳама чиз бо кадом тартиб иҷро мешавад

  1. Оғоз let i = 1 як бор, аз ҳама аввал иҷро мешавад.
  2. Шарт i <= 5 пеш аз ҳар давр санҷида мешавад. false — баромадан аз давра.
  3. Бадан пурра иҷро мешавад.
  4. Қадам i++ пас аз бадан иҷро мешавад. Баъд боз қадами 2.

Вариантҳои гуногуни сарлавҳа

Се қисмро тағйир дода, ҳар тавр ҳисоб кардан мумкин аст: аз сифр, бо қадам, ба қафо.

Маслиҳат: while ё for?

Пешакӣ медонед, ки чанд давр аст («5 меҳмон», «аз 1 то 100») — for-ро гиред. Давр задан лозим аст «то даме ки чизе рух диҳад» (пул кифоя аст, воридкунӣ тамом нашудааст) — while-ро гиред. Ҳар for-ро ба while аз нав навиштан мумкин аст ва баръакс: ин масъалаи қулайӣ аст.

Дом: ба як хато кардан

Маъмултарин хато дар давраҳо — «хато ба як» (off-by-one). Фарқи байни i < 5 ва i <= 5 — як даври пурраи зиёдатӣ аст. Агар аз сифр ҳисоб кунед, < нависед; агар аз як — <=. Ва ҳамеша қимати якум ва охирин-ро санҷед.

for (let i = 1; i < 5; i++) {
  console.log(`Урок ${i}`);   // дарси 5-ум гум шуд!
}

Тағйирёбандаи давра танҳо дар дохил зинда аст

for (let i = 1; i <= 3; i++) {
  console.log(i);
}
console.log(i);   // ✖ i берун аз давра вуҷуд надорад

Ин муқаррарӣ аст ва ҳатто қулай: ҳар давра i-и худро дорад ва давраҳо ба ҳамдигар халал намерасонанд. Агар қимат пас аз давра лозим бошад, тағйирёбандаро то он эълон кунед. Чаро ин тавр сохта шудааст — дар дарс дар бораи функсияҳо мегӯем.

03 Давраи do..while

while бародари дугоник дорад: do..while («кун, то даме ки»). Фарқ ягона, вале муҳим аст: шарт пас аз бадан санҷида мешавад, бинобар ин бадан ҳадди аққал як бор иҷро мешавад, ҳатто агар шарт аз аввал дурӯғ бошад.

let attempt = 0;

do {
  attempt++;
  console.log(`Попытка входа №${attempt}`);
} while (attempt < 3);

Ба нуқтаву вергул пас аз while (…) диққат диҳед — дар do..while он лозим аст. Акнун ҳар ду давраро муқоиса кунед, вақте ки шарт фавран дурӯғ аст:

let cups = 0;

while (cups > 0) {
  console.log("while: тело выполнилось");
}

do {
  console.log("do..while: тело выполнилось");
} while (cups > 0);
Ташбеҳ аз зиндагӣ

Дар чойхона чойникро бо чой фавран, напурсида меоваранд, баъд мепурсанд: «Боз?». Ин do..while аст: аввал амал, баъд савол. Дар муассисаи дигар аввал мепурсанд: «Чой биёрам?» — ва танҳо пас аз «ҳа» меоваранд. Ин while аст: аввал санҷиш, баъд амал.

04 break ва continue

Баъзан давраро пеш аз мӯҳлат қатъ кардан ё як давраро гузаронидан лозим аст. Барои ин ду калима ҳаст.

  • break — тамоман аз давра баромадан. Барнома аз сатри пас аз давра идома меёбад.
  • continue — бақияи давраи ҷориро гузаронидан ва ба оянда гузаштан.
for (let i = 1; i <= 10; i++) {
  if (i === 4) {
    console.log("Нашли нужную остановку! Выходим");
    break;
  }
  console.log(`Проезжаем остановку №${i}`);
}
console.log("Цикл закончился");
Ташбеҳ аз зиндагӣ

Шумо дар чойхона мизи холиро меҷӯед ва аз канори сафҳо мегузаред. Ёфтед — break: дигар намеҷӯед, менишинед. Ва continue — ин «ин миз банд аст, намеистам, ба оянда меравам». Ҷустуҷӯ идома меёбад, вале як мизро шумо танҳо гузаронидед.

Бақияи тақсим: оператори %

console.log(8 % 2);    // → 0   (ҷуфт)

05 Аз назар гузаронидани сатр: for..of

Давраро на танҳо аз болои рақамҳо, балки аз болои ҳарфҳои сатр низ иҷро кардан мумкин аст. Барои ин шакли қулайи for..of («барои ҳар … аз …») ҳаст:

for (const letter of "Душанбе") {
  console.log(letter);
}

Дар ҳар давр ба тағйирёбандаи letter ҳарфи оянда меафтад. На ҳисобкунак, на шарт, на қадам лозим аст — JavaScript худаш ба охири сатр мерасад. const-ро менависем, зеро дар ҳар давр тағйирёбандаи нав сохта мешавад, дар дохили давр бошад мо онро тағйир намедиҳем.

Ташбеҳ аз зиндагӣ

Тасбеҳ: шумо донаҳоро яккайякӣ, аз аввалин то охирин мегузаронед. for..of — «барои ҳар дона фалон корро кун». Ба шумо муҳим нест, ки он аз рӯи рақам кадом аст, шумо танҳо донаи оянда мегиред, то ресмон тамом шавад.

Ҳамон аз назар гузаронӣ тавассути for-и оддӣ

Ҳар ҳарф дар сатр рақам — индекс дорад. Ададшуморӣ аз сифр оғоз мешавад. Ҳарфро аз рӯи рақам тавассути қавсҳои мураббаъ гирифтан мумкин аст: city[0]. Шумораи ҳарфҳо дар city.length нигоҳ дошта мешавад. Бинобар ин индекси охирин — length - 1 аст.

const city = "Хорог";
console.log(city.length);   // → 5
console.log(city[0]);       // → Х
console.log(city[4]);       // → г

for (let i = 0; i < city.length; i++) {
  console.log(`${i}: ${city[i]}`);
}

Вақте ки танҳо худи аломат лозим аст — for..of-ро мегирем, ин содда аст. Вақте ки боз рақам низ лозим аст (масалан, ҳарфи аввал ва охиринро муқоиса кардан) — for-и оддиро бо индекс мегирем.

Вазифаҳои маъмул оид ба сатрҳо

Ҳисоб кардан, ки ҳарф чанд маротиба вомехӯрад:

  if (ch === "с") {
    count++;
  }
}
console.log(`Букв «с»: ${count}`);   // → Букв «с»: 2

Сатри нав ҷамъ кардан — масалан, калимаро баръакс кардан. Ҳар ҳарфи навро ба чап ба сатри аллакай ҷамъшуда мечаспонем:

let reversed = "";

  console.log(`взяли «${ch}» → ${reversed}`);
}
console.log(reversed);   // → ишо

Соат. Ақрабаки соатӣ як қадам мегузорад, ақрабаки дақиқагӣ дар ин вақт тамоми сафҳаро — 60 қадамро мегардад. Давраи беруна — ақрабаки соатӣ, дохилӣ — дақиқагӣ. То даме ки беруна як давр мезанад, дохилӣ ҳамаи даврҳои худро аз аввал то охир мегузарад.

08 Давраи беохир: чӣ тавр овезон нашудан

Давра танҳо вақте қатъ мешавад, ки шарти он ягон вақт false шавад. Агар шарт ҳамеша рост бошад, давра ҳеҷ гоҳ тамом намешавад. Ин давраи беохир аст ва ин маъруфтарин хатои барномасозони навкор (ва на танҳо онҳо) мебошад. Саҳифа бо чунин давра «овезон мешавад»: тугмаҳо пахш намешаванд, ҷадвал ҷавоб намедиҳад.

Ташбеҳ аз зиндагӣ

Таксирон ҳисобкунакро фаъол кард ва хомӯш кардани онро фаромӯш намуд. Мусофир кайҳо баромадааст, рақамҳо бошанд меафзоянд — ва то даме ки касе мошинро қатъ накунад, ҳамин тавр аст. Давра бе ҳисобкунаки тағйирёбанда — ҳамон таксии «фаромӯшшуда» аст.

Ин дар саҳифаи мо чӣ тавр менамояд

Иҷрокунандаи ин саҳифа муҳофизат шудааст: агар код аз чанд сония зиёд «хомӯш» бошад, он маҷбуран қатъ мешавад ва паёми сурх менависад. ▶ Иҷро кардан-ро пахш кунед ва тақрибан се сония интизор шавед:

}
console.log("Эта строка никогда не выполнится");

    isPrime = false;
    break;
  }
}

  • do..while: do { … } while (шарт); — бадан ҳадди ақал як бор иҷро мешавад, шарт пас аз он санҷида мешавад.
  • break тамоман аз давра мебарояд, continue бақияи давраро мегузаронад. Дар дохили давраҳои дарунҷоӣ break танҳо аз дохилӣ мебарояд.
  • for..of аз болои сатр: for (const ch of "текст"). Рақами ҳарф лозим аст — for бо text[i] ва text.length. Индексҳо аз сифр, охирин — length - 1. Сатрро «дар ҷояш» тағйир додан мумкин нест — нав ҷамъ мекунем.
  • Ҷамъкунандаҳо: маблағ — оғоз 0, ҳосили зарб — оғоз 1, ҳисобкунак — count++ аз рӯи шарт, ҳадди аксар — if (x > best), сатр — line += …. То давра эълон мекунем.
  • Давраҳои дарунҷоӣ: бадани дохилӣ «даврҳои беруна × даврҳои дохилӣ» маротиба иҷро мешавад. Сатри расмро бо давраи дохилӣ ҷамъ мекунем ва пас аз он мебарорем. Ҷамъкунандаи сатр — дар дохили давраи беруна.
  • Бақияи тақсим %: x % 2 === 0 — ҷуфт, x % 3 === 0 — чандкарата ба 3.
  • Давраи беохир: шарт ҳамеша true аст. Сабабҳо — тағйир додани ҳисобкунакро фаромӯш кардем, ба самти нодуруст тағйир медиҳем, continue пеш аз қадам, break дар while (true) нест. Се савол пеш аз оғоз: чӣ тағйир меёбад, ба кадом самт, оё шарт false шуда метавонад. Муҳофиз кумак мекунад — ҳисобкунаки даврҳо бо break.
