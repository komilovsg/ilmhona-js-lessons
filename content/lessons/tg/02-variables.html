Тағйирёбандаҳо, навъҳои маълумот, табдили навъҳо

Ҳар барнома чизеро дар хотир нигоҳ медорад: нархи мол, номи корбар, шумораи ашё дар сабад. Барои ин тағйирёбандаҳо лозиманд, ҳар қимат бошад навъ дорад — ва аз он вобаста аст, ки JavaScript бо он чӣ тавр муносибат мекунад. Имрӯз шумо нигоҳ доштани маълумот, донистани навъи он ва дар дом наафтодан ба ғалатҳои классикӣ, монанди "5" + 3-ро меомӯзед. Дар охири дарс — аввалин кор бо ЗС: промптро чӣ тавр тартиб додан ва ЗС-ро дар хато чӣ тавр доштан.

  • Тағйирёбандаҳоро тавассути let ва const эълон кунед ва шарҳ диҳед, ки чаро var-ро истифода намебарем
  • Ба тағйирёбандаҳо номҳои дуруст диҳед
  • Навъҳои string, number, boolean, null, undefined-ро фарқ кунед ва онҳоро тавассути typeof муайян намоед
  • Сатрҳоро бо литералҳои қолабӣ ҷамъ кунед ва бо арифметика ҳисоб намоед
  • Қиматҳоро аз як навъ ба навъи дигар ошкоро табдил диҳед — ва табдили ниҳонро пешбинӣ кунед
  • Промптро аз рӯи формулаи «контекст → вазифа → маҳдудиятҳо → формат» нависед ва ҷавоби ЗС-ро санҷед
Бо ин саҳифа чӣ тавр кор кардан лозим аст

Тамоми код дар заминаи торик бо тугмаи ▶ Иҷро кардан — зинда аст. Онро тағйир додан ва натиҷаро дарҳол дар консоли поёни он дидан мумкин аст. Вайрон кардед — ↺ Аз нав-ро пахш кунед. Ин дарс дар бораи пешбинӣ аст: пеш аз иҷрои код аз худ бипурсед «чӣ бароварда мешавад?», ҷавобро нависед — ва танҳо баъд тугмаро пахш кунед. Ишораҳои вазифаҳо пинҳон шудаанд: аввал худатон кӯшиш кунед. Аз дарси 1 ба шумо танҳо console.log, теги script ва DevTools лозим аст — ҳама чизи дигарро дар ин ҷо шарҳ медиҳем.

01 Тағйирёбандаҳо: let, const ва чаро не var

Тағйирёбанда — ин ҷои номдор дар хотира аст, ки барнома қиматро дар он мегузорад, то баъд онро бо ном берун орад. Ба ҷои он ки рақами 25-ро дар даҳ ҷо нависед, онро як бор сабт мекунед ва минбаъд аз ном истифода мебаред.

let price = 25;
console.log(price);        // → 25

price = 30;                // қимати нав
console.log(price);        // → 30
console.log(price * 2);    // → 60
Ташбеҳ аз зиндагӣ

Хонаи амонат дар истгоҳи автобуси Душанбе. Ҳар ҳуҷайра рақам дорад — ин номи тағйирёбанда аст. Дар дохил ашё мехобад — ин қимат аст. Шумо метавонед ҳуҷайраро кушоед ва ашёи дигареро гузоред (let), ё онро чунон қулф кунед, ки мундариҷаро тағйир додан мумкин набошад (const).

Тағйирёбандаро чӣ тавр эълон кардан

let
Тағйирёбандае, ки қимати он тағйир дода мешавад: тавозун, ҳисобкунак, номи корбар.
const
Тағйирёбандае, ки онро аз нав таъин кардан мумкин нест: нархи асъор, номи академия, нишонии сайт. Ин варианти пешфарз аст.
var
Роҳи кӯҳна аз давраи то соли 2015. Кор мекунад, вале ғайричашмдошт рафтор мекунад. Дар коди нав истифода намебарем.
Қоидаи курс

Аз const оғоз кунед. Агар баъдтар маълум шавад, ки қимат бояд тағйир ёбад, — ба let иваз кунед. Ин тавр аз рӯи код фавран намоён аст, ки чӣ метавонад тағйир ёбад ва чӣ не.

const academy = "MakeFirstStep";   // тағйир намеёбад
let students = 12;            // тағйир меёбад

students = 13;                // донишҷӯи нав омад
console.log(academy, students);   // → MakeFirstStep 13

Агар const-ро тағйир диҳем, чӣ мешавад

JavaScript барномаро қатъ мекунад ва хато нишон медиҳад. Ин вайроншавӣ не, ҳимоя аст: худатон гуфтед, ки қимат набояд тағйир ёбад.

const rate = 10.95;
console.log("Курс:", rate);

rate = 11;   // ✖ TypeError: Assignment to constant variable.
console.log("Новый курс:", rate);

Диққат диҳед: сатри бо "Новый курс" иҷро нашуд. Пас аз хато барнома қатъ мешавад. Хондани матни хато — яке аз малакаҳои асосии барномасоз аст: TypeError — «навъи хато», пас аз ду нуқта — тавсифи фаҳмо.

Эълон кардан ва таъин кардан — чизҳои гуногунанд

  • Эълон — калимаи let ё const ва ном. Як бор анҷом дода мешавад.
  • Таъинот — аломати =. Бисёр маротиба анҷом додан мумкин аст (барои let).
  • Барои const қиматро фавран ҳангоми эълон додан лозим аст: const x; — хато.
  • Барои let бе қимат эълон кардан мумкин аст: let result; — дар дохил undefined («муайян нашудааст») мешавад. Дар бораи он дар бахши навъҳо сӯҳбат мекунем.
let result;                 // эълон кардем, қимат ҳоло нест
console.log(result);        // → undefined

result = 100;               // таъин кардем
console.log(result);        // → 100

Чаро не var

var се хусусияти нохуш дорад. Шумо онро дар китобҳои дарсии кӯҳна ва дар ҷавобҳои ЗС вомехӯред, бинобар ин фаҳмидани мушкил муҳим аст.

1. Аз қавсҳои фигурӣ «мерезад». Код дар { } — блок аст. Тағйирёбандаи let дар дохили блок мемонад, var бошад ба берун мебарояд:

{
  var oldWay = "var видно снаружи";
  let newWay = "let живёт только внутри";
  console.log(newWay);        // → let танҳо дар дохил зинда аст
}

console.log(oldWay);          // → var аз берун намоён аст

{
  let newWay = "let живёт только внутри";
}

console.log(newWay);   // ✖ ReferenceError: newWay is not defined

2. Ҳамон номро ду бор эълон кардан имкон медиҳад — ва шумо метавонед тағйирёбандаи дигарро тасодуфан ба ҷои он нависед, ҳатто пай набарда:

var city = "Душанбе";
var city = "Худжанд";      // JavaScript хомӯш аст, ҳарчанд ном аллакай банд аст
console.log(city);         // → Худжанд

let city = "Душанбе";
let city = "Худжанд";      // ✖ SyntaxError: Identifier 'city' has already been declared
console.log(city);

3. «Боло мебарояд»: var-ро то сатри эълон истифода бурдан мумкин аст — ба ҷои хатои фаҳмо undefined мегиред. Бо let ва const JavaScript софдилона мегӯяд, ки шумо шитоб кардед.

console.log(a);   // → undefined (аҷиб, вале бе хато)
var a = 5;
console.log(a);   // → 5

console.log(b);   // ✖ ReferenceError: Cannot access 'b' before initialization
let b = 5;
Хулоса

Хатое, ки JavaScript фавран нишон медиҳад — ин хуб аст: ёфтани он осон аст. var хатоҳоро пинҳон мекунад, let ва const онҳоро нишон медиҳанд. Бинобар ин: танҳо const ва let.

02 Навъҳои маълумот ва typeof

Қиматҳо навъҳои гуногун доранд. Рақами 25 ва матни "25" ба ҳам монанд менамоянд, вале барои JavaScript инҳо чизҳои комилан гуногунанд: рақамҳоро зарб кардан мумкин аст, матнро бошад — часпондан ва нишон додан. Навъ муайян мекунад, ки бо қимат чӣ кор кардан мумкин аст.

Ташбеҳ аз зиндагӣ

Дар бозор қатори гӯшт, қатори мева ва қатори зарфҳо ҳаст. Нонро дар тарозуи чой баркашидан ва дар пиёла рехтан мумкин нест. Ҳар мол «қатор»-и худро дорад — навъи худро, ва аз он вобаста аст, ки бо он чӣ мекунанд.

Панҷ навъи асосӣ

НавъИн чистМисолҳо
stringМатн — ҳамеша дар нохунакҳо"Салом", 'MakeFirstStep', "25"
numberРақам — бутун ё касрӣ, як навъ25, 3.14, -7
booleanМантиқии «ҳа/не»: танҳо ду қиматtrue, false
null«Холӣ» — набудани қимат, ки қасдан сабт шудаастnull
undefined«Муайян нашудааст» — қимат ҳанӯз таъин нашудаастundefined

Донистани навъи қимат ба оператори typeof кумак мекунад. Он сатр-ро бо номи навъ бозпас мегардонад:

console.log(typeof "Салом");     // → string
console.log(typeof 25);          // → number
console.log(typeof 3.14);        // → number  (касрӣ низ number аст)
console.log(typeof true);        // → boolean
console.log(typeof undefined);   // → undefined

typeof бо тағйирёбандаҳо низ кор мекунад — он ба қимати дохил менигарад:

const dish = "курутоб";
const price = 35;
const isSpicy = false;

console.log(dish, typeof dish);       // → курутоб string
console.log(price, typeof price);     // → 35 number
console.log(isSpicy, typeof isSpicy); // → false boolean
Нохунакҳо навъро иваз мекунанд

25 — рақам, "25" бошад — сатр аз ду аломат. Агар рақам дар нохунакҳо омада бошад, бо он мисли рақам ҳисоб кардан ҳоло мумкин нест (дар ин бора — дар бахшҳои 5 ва 6).

console.log(typeof 25);     // → number
console.log(typeof "25");   // → string
console.log(typeof true);   // → boolean
console.log(typeof "true"); // → string — ин танҳо матн аз чор ҳарф аст

null ва undefined: фарқ дар чист

Ташбеҳ аз зиндагӣ

Шумо ба хонаи амонат омадед. undefined — ҳуҷайра ҳаст, вале дар он ҳанӯз чизе нагузоштаанд («муайян нашудааст»). null — дар ҳуҷайра қайде ҳаст «ин ҷо қасдан холӣ» («қимат таъин шудааст: ҳеҷ чиз»).

let phone;                 // эълон кардем, вале таъин накардем
console.log(phone);        // → undefined

let nickname = null;       // худамон қарор додем: ном нест
console.log(nickname);     // → null

Одатан undefined «худаш» пайдо мешавад (JavaScript мегӯяд: «ин ҷо холӣ аст, чунки шумо чизе нагузоштед»), null-ро бошад барномасоз бошуурона менависад: «ҳоло қимат нест».

Ғаройиби typeof null

typeof null "object"-ро бозпас мегардонад, ҳарчанд null навъи алоҳида аст. Ин хатои маъруфест, ки соли 1995 дар JavaScript пайдо шуд ва абадӣ монд: ислоҳ кардан миллионҳо сайти кӯҳнаро вайрон мекард. Ҳамчун далел дар хотир доред ва ҳайрон нашавед — ЗС дар ҷавобҳо аксар вақт маҳз ҳамин ҷойро омехта мекунад.

console.log(typeof null);       // → object  (!)
console.log(typeof undefined);  // → undefined
console.log(null === undefined);// → false — «қатъиян баробар»: ин қиматҳои гуногунанд (муфассалтар дар бахши 6)

Навъи тағйирёбанда собит нест

Дар JavaScript тағйирёбанда метавонад қимати ҳар навъро нигоҳ дорад ва онро тағйир диҳад. Инро типизатсияи динамикӣ меноманд. Қулай аст, вале диққатро талаб мекунад: тағйирёбандае, ки дар он рақам буд, ногаҳон сатр мебарояд — ва ҳисоб кардан дигар намешавад.

let value = 100;
console.log(typeof value);   // → number

value = "сто";
console.log(typeof value);   // → string

value = true;
console.log(typeof value);   // → boolean

Боз ду навъ — танҳо шиносоӣ

  • bigint — рақамҳои бутуни хеле калон, дар охир бо ҳарфи n навишта мешаванд: 12345678901234567890n. number-и оддӣ танҳо то 9 007 199 254 740 991 дақиқ аст. Ба шумо ин кам лозим мешавад.
  • symbol — «шиносгар»-и беназир, бо фармони Symbol("id") сохта мешавад. Дар ин курс лозим намешавад.
console.log(typeof 123n);             // → bigint
console.log(typeof Symbol("id"));     // → symbol

Боз навъи «таркибӣ» — object ҳаст — барои рӯйхатҳо ва объектҳо. Онро дар дарсҳои 6 ва 7 шарҳ медиҳем, ҳоло бошад дар рӯйхати мо танҳо панҷ навъи асосии примитивӣ ҳаст.

03 Сатрҳо ва литералҳои қолабӣ

Сатр — ин матн аст. Онро дар нохунакҳо менависанд ва нохунакҳо се навъ доранд:

const a = "двойные кавычки";
const b = 'одинарные кавычки';
const c = `обратные кавычки — шаблонная строка`;

console.log(a);
console.log(b);
console.log(c);

Сатр дар нохунакҳои баръакс `…` имкон медиҳад, ки қиматҳо бевосита ба матн тавассути ${ } дароварда шаванд. Дар дохили қавсҳо ҳар ифодаро навиштан мумкин аст.

Боз як қулайӣ: сатри қолабӣ метавонад якчанд сатр-ро ишғол кунад — гузаришҳо ҳамон тавр боқӣ мемонанд.

Оператори % — «бақия» — онро дар мисоли манту осонтар фаҳмидан мумкин аст. 17 мантуро ба 5 дона дар як табақ ҷобаҷо кардем: 3 табақи пурра шуд (ин Math.floor(17 / 5) аст), 2 манту монд — ин ҳамон 17 % 5 аст. const manti = 17;

Мудаввар кардан: Math.round, floor, ceil

console.log(Math.round(2.5));  // → 3 — то наздиктарин бутун

console.log(Math.floor(2.9));  // → 2 — ҳамеша ба поён

Навишти кӯтоҳ: +=, ++ ва ҳамсафон

Қимати тағйирёбандаро доимо тағйир додан лозим аст: ба тавозун илова кардан, ҳисобкунакро зиёд кардан. Барои ин шаклҳои кӯтоҳ ҳаст:

let balance = 100;

balance *= 2;             // balance = balance * 2
console.log(balance);     // → 200

let visitors = 0;

visitors++;
console.log(visitors);    // → 2
visitors--;               // ба 1 кам кардан
console.log(visitors);    // → 1

Аломатҳои ++ ва ---ро пеш аз тағйирёбанда ва пас аз он навиштан мумкин аст. Агар шумо рақамро танҳо дар сатри алоҳида зиёд кунед, фарқ нест. Аммо агар қимат дар ҳамон сатр истифода шавад — фарқ ҳаст:

let a = 5;
console.log(a++);   // → 5  — аввал қимати кӯҳна дода шуд, баъд зиёд шуд
console.log(a);     // → 6

console.log(++b);   // → 6  — аввал зиёд шуд, баъд дода шуд
console.log(b);     // → 6

Муқоисаҳо boolean медиҳанд

Аломатҳои >, <, >=, <=, === (баробар) ва !== (баробар не) қиматҳоро муқоиса мекунанд ва true ё false бозпас мегардонанд. Шартҳои if, ки бар ин асос сохта мешаванд, дар дарси 3 меомӯзем.

console.log(5 > 3);        // → true
console.log(5 < 3);        // → false
console.log(10 >= 10);     // → true
console.log(7 === 7);       // → true
console.log(7 !== 7);       // → false

Infinity ва NaN

Дар риёзиёт ба сифр тақсим кардан мумкин нест. JavaScript намеафтад, балки қимати махсусро бозпас мегардонад:

console.log(1 / 0);     // → Infinity — «беинтиҳо»
console.log(-1 / 0);    // → -Infinity
console.log(0 / 0);     // → NaN — «рақам не» (Not a Number)

NaN вақте пайдо мешавад, ки арифметика барнаомад: масалан, матнро ба рақам зарб кардем. Се хосияти NaN-ро дар хотир доред:

  • аз рӯи навъ ҳамоно number аст: typeof NaN → "number";
  • он «сироятӣ» аст: ҳар амал бо NaN низ NaN медиҳад;
  • NaN ҳатто ба худаш баробар нест. Санҷидан бояд бо фармони Number.isNaN(x) бошад.
console.log("abc" * 2);              // → NaN
console.log(NaN + 5);                // → NaN — сироят кард
console.log(NaN === NaN);            // → false (!)
console.log(Number.isNaN(NaN));      // → true
console.log(Number.isNaN("abc"));    // → false — ин сатр аст, на NaN
Рақамҳои касрӣ ва пул

Компютер касрҳоро дар шакли дуӣ нигоҳ медорад ва баъзе касрҳои даҳӣ дақиқ навишта намешаванд. Ин хатои JavaScript нест — қариб ҳамаи забонҳо ҳамин тавр кор мекунанд.

console.log(0.1 + 0.2);            // → 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);    // → false

Бо пул чӣ кор кардан лозим аст: бо хурдтарин воҳидҳо — бо дирам (1 сомонӣ = 100 дирам), яъне бо рақамҳои бутун ҳисоб кунед ва танҳо ҳангоми намоиш ба 100 тақсим намоед. Баровардани зебо бо ду рақами пас аз нуқта бошад .toFixed(2) медиҳад — вале дар хотир доред: он сатр бозпас мегардонад, на рақам.

const total = 0.1 + 0.2;
console.log(total.toFixed(2));          // → 0.30
console.log(typeof total.toFixed(2));   // → string — ин аллакай матн аст!

console.log((10 + 20) / 100);           // → 0.3 — бо дирам ҳисоб кардем (10 ва 20), баъд тақсим кардем

05 Табдили ошкори навъҳо

Табдили навъҳо — ин табдил додани қимат аз як навъ ба навъи дигар аст. Он ошкоро (худатон мехоҳед: «аз ин рақам кун») ва ниҳонӣ (JavaScript инро худаш, напурсида мекунад — дар бахши оянда шарҳ медиҳем) мешавад. Аввал онро бошуурона анҷом доданро меомӯзем.

Ташбеҳ аз зиндагӣ

Нуқтаи мубодилаи асъор. Шумо бо доллар меоед, вале сомонӣ лозим аст: маблағ «аслан» ҳамон, вале шакл дигар. Барои ҳар ҷуфти асъор кассаи худ ҳаст: String() — «матн кун», Number() — «рақам кун», Boolean() — «ҳа/не кун». Аммо мубодила баъзан номуваффақ мешавад: «абракадабра»-ро ба рақам иваз намекунед — NaN мегиред.

Ба сатр: String()

console.log(String(123));         // → "123"
console.log(String(true));        // → "true"
console.log(String(null));        // → "null"
console.log(String(undefined));   // → "undefined"
console.log(typeof String(123));  // → string

Ба рақам: Number()

Муҳимтарин табдил. Дар кори воқеӣ рақамҳо аксар вақт ҳамчун матн меоянд: аз майдони воридкунӣ, аз ҷавоби сервер. Фосилаҳои канориро Number() мегирад, вале матни зиёдатиро дар дохил не.

console.log(Number("42"));        // → 42
console.log(Number("3.14"));      // → 3.14
console.log(Number("  7  "));     // → 7    — фосилаҳои канорӣ партофта мешаванд

console.log(Number("abc"));       // → NaN
console.log(Number(""));          // → 0    — сатри холӣ сифр медиҳад (!)
console.log(Number(true));        // → 1
console.log(Number(false));       // → 0
console.log(Number(null));        // → 0
console.log(Number(undefined));   // → NaN

Ба қимати мантиқӣ: Boolean()

Ҳар қиматро ба true ё false табдил додан мумкин аст. Қоида содда: қиматҳои «холӣ» false медиҳанд, боқӣ ҳама — true. «Холӣ»-ҳо (онҳоро falsy меноманд) дар ҳамагӣ шашто асосӣ мебошанд:

  • false — худаш;
  • 0 (ва -0);
  • "" — сатри холӣ;
  • null;
  • undefined;
  • NaN.
console.log(Boolean(0));            // → false
console.log(Boolean(""));           // → false
console.log(Boolean(null));         // → false
console.log(Boolean(undefined));    // → false
console.log(Boolean(NaN));          // → false

console.log(Boolean(1));            // → true
console.log(Boolean(-5));           // → true  — ҳар рақам, ба ҷуз сифр
console.log(Boolean("Салом"));      // → true
console.log(Boolean(" "));          // → true  — фосила аллакай аломат аст!
console.log(Boolean("0"));          // → true  — сатри "0" холӣ нест
console.log(Boolean("false"));      // → true  — ва ин низ танҳо матн аст
Домҳои Boolean

"0" ва "false" — сатрҳои ғайриҳолӣ, бинобар ин true. Сатри холии "" ва рақами 0 бошад — false. Ин ҷоест, ки ҳам навомӯзон ва ҳам ЗС хато мекунанд.

06 Табдили ниҳонӣ: домҳои асосӣ

Агар дар ифода қиматҳои навъҳои гуногун вомехӯранд, JavaScript худаш онҳоро ба шакли умумӣ меорад — ва огоҳ намекунад. Баъзан ин қулай аст, вале бештар манбаи хатоҳои аҷиб мешавад. Вазифаи шумо — фаҳмидани қоидаҳо ва пешбинӣ карда тавонистани натиҷа.

Қоидаи 1: «+» бо матн — ин часпонидан аст

Агар ақаллан як тарафи + сатр бошад, JavaScript дуюмро ба сатр табдил медиҳад ва мечаспонад.

console.log("5" + 3);        // → 53   — на 8!
console.log(3 + "5");        // → 35
console.log("Итого: " + 100);// → Итого: 100
console.log("5" + true);     // → 5true
console.log("5" + null);     // → 5null
Ташбеҳ аз зиндагӣ

Аломати + ҳамчун ширеш кор мекунад. Дар паҳлӯи ҳам ду рақам — ҷамъ мекунад. Дар паҳлӯи ҳадди аққал як матн — мечаспонад: «5» ва «3» ба «53» табдил меёбанд, мисли рақамҳо дар барчаспҳо. Аломатҳои дигар (-, *, /) часпонда наметавонанд — онҳо танҳо ҳисоб мекунанд.

Қоидаи 2: аломатҳои арифметикии дигар ба рақам табдил медиҳанд

console.log("5" - 3);        // → 2
console.log("5" * "2");      // → 10
console.log("10" / "2");     // → 5
console.log("abc" * 2);      // → NaN — ба рақам табдил додан нашуд

Қоидаи 3: boolean, null ва undefined дар ҳисобҳо

console.log(true + 1);       // → 2    — true ба 1 табдил меёбад
console.log(false + 1);      // → 1    — false ба 0 табдил меёбад
console.log(null + 1);       // → 1    — null ба 0 табдил меёбад
console.log(undefined + 1);  // → NaN  — undefined ба NaN табдил меёбад

Тартиб аз чап ба рост

Ифода қадам ба қадам аз чап ба рост ҳисоб карда мешавад. То даме ки дар чап рақамҳо ҳастанд — онҳо ҷамъ карда мешаванд, вале баробари он ки дар занҷир сатр пайдо шуд — минбаъд часпонидан меравад:

console.log(1 + 2 + "3");    // → 33   — аввал 1 + 2 = 3, баъд "3" + "3"
console.log("1" + 2 + 3);    // → 123  — аввал "1" + 2 = "12", баъд "12" + 3
console.log(1 + 2 + 3);      // → 6

Плюси якоя: навишти кӯтоҳи Number()

Плюс пеш аз қимат бе қисми чап онро ба рақам табдил медиҳад — ҳамон тавр, ки Number(). Инро дар коди дигарон дидан мумкин аст, вале дар коди худ беҳтар аст ошкоро нависед.

console.log(+"7");           // → 7
console.log(+"");            // → 0
console.log(+"abc");         // → NaN
console.log(typeof +"7");    // → number
console.log("b" + "a" + +"a" + "a");   // → baNaNa  — шӯхии маъруф дар бораи NaN

Муқоисаҳо: == ва ===

Барои санҷидани баробарӣ ду роҳ ҳаст. ==-и дукарата «ғайриқатъӣ» аст — навъҳоро ба ҳам меорад ва барои ҳамин аҷиб рафтор мекунад. ===-и сеқарата «қатъӣ» аст — бе табдил муқоиса мекунад: қиматҳо танҳо вақте баробаранд, ки ҳам қимат ва ҳам навъ мувофиқат кунанд.

console.log(5 == "5");        // → true   — сатрро ба рақам овард
console.log(5 === "5");       // → false  — навъҳои гуногун
console.log(0 == "");         // → true   (!)
console.log(0 == false);      // → true   (!)
console.log("0" == false);    // → true   (!)
console.log(null == undefined);   // → true
console.log(null === undefined);  // → false
console.log(null == 0);       // → false  — чунин номувофиқатӣ
Қоидаи курс

Ҳамеша === ва !== нависед. ==-и ғайриқатъиро истифода намебарем — он арзиши дар хотир доштани ҳамаи аҷоибиҳояшро надорад.

Муқоисаи сатрҳо — аз рӯи ҳарфҳо

Ду сатр аломат ба аломат муқоиса мешаванд, мисли калимаҳо дар луғат, на мисли рақамҳо. Бинобар ин «10» «хурдтар» аз «9» мебарояд: рақами аввали 1 аз 9 хурдтар аст.

console.log("10" > "9");     // → false (!)  — сатрҳо аз рӯи аломатҳо муқоиса мешаванд
console.log("10" > 9);       // → true       — яке аз қиматҳо рақам аст, пас мисли рақамҳо муқоиса мекунад
console.log(Number("10") > Number("9"));  // → true — роҳи боэътимод
Чӣ тавр худро муҳофизат кардан

Ба «бошад, ки»-и табдили ниҳонӣ умед набастан. Маълумотро аз берун гирифтед (майдони шакл, prompt, ҷавоби сервер) — фавран онро тавассути Number() ба навъи лозимӣ табдил диҳед ва минбаъд бо рақамҳо кор кунед. Ошкоро беҳтар аз ниҳонӣ: он дар код намоён аст ва пешбинишаванда аст.

07 Блоки ЗС: анатомияи промпт ва «ЗС-ро дар хато доштан»

Ёрдамчии ЗС маҳз ба он саволе ҷавоб медиҳад, ки шумо додед. Саволи норавшан — ҷавоби норавшан, ки ба ғайр аз ин метавонад хато дошта бошад. Бинобар ин дар ин курс мо ду малака дорем: дуруст пурсидан (промпт) ва ҷавобро санҷидан (иҷро кардан ва муқоиса намудан).

Қоидаҳои кор бо ЗС дар курси мо

1. Аввал 15 дақиқа худатон кӯшиш мекунед — ва танҳо баъд ба назди ЗС мераванд. 2. Коде, ки сатр ба сатр шарҳ дода наметавонед, ба кор намегузоред. 3. Ҳамеша шарҳ талаб кунед, на танҳо код. 4. Номҳои тағйирёбандаҳо, ҳолатҳои канорӣ ва мантиқро бо даст — дар консол месанҷед. 5. Дар кори назоратӣ (дарсҳои 6 ва 18) ЗС пурра хомӯш аст.

Анатомияи промпт: чор қисми ҳатмӣ

Промпти хуб — матни дароз не, балки сохтор аст. Тартибро дар хотир доред: контекст → вазифа → маҳдудиятҳо → формати ҷавоб. Банди панҷум — санҷиш — мо вақте илова мекунем, ки ҷавобе лозим аст, ки ба он кӯркӯрона бовар кардан мумкин нест (яъне қариб ҳамеша).

Ҳар қадар фармоиш дақиқтар бошад, ҳамон қадар имкони ба ҷои нодуруст расидан камтар аст. ЗС ҳамон ронанда аст: ӯ фикрҳоро намехонад.

Ҷавоби ЗС-ро чӣ тавр хондан: месанҷем, бовар намекунем

ЗС бо боварӣ менависад — ҳатто вақте ки хато мекунад. Дар мавзӯи навъҳо ин махсусан намоён аст: табдили ниҳонӣ ва аҷоибиҳое монанди typeof null-ро он аксар вақт нодуруст нақл мекунад. Бинобар ин шумо алгоритми содда доред:

  1. Пешбинӣ кунед. Шарҳи ЗС-ро хондед — нависед, ки кадом натиҷа бояд ҳосил шавад.
  2. Иҷро кунед. Мисолро ба консол нусха бардоред ва бубинед, ки дар асл чӣ бароварда мешавад.
  3. Муқоиса кунед. Мувофиқат кард — олӣ. Мувофиқат накард — ё ЗС хато кард, ё шумо. Фаҳмед, ки маҳз кӣ: омӯзиш ҳамин аст.

  4. 8 ифодаро пешбинӣ кунед. Худатон 8 ифодаи бо табдили ниҳонӣ (+, -, *, true, null, undefined) тартиб диҳед. Пешбиниро нависед, баъд иҷро кунед ва муқоиса намоед.
  5. Соат ва дақиқа. Аз рӯи миқдори сонияҳо (масалан, 10000) вақтро дар шакли «соат : дақиқа : сония» бароред. Math.floor ва %-ро истифода баред.
  6. Ислоҳи се порча. Се порчаи кӯтоҳро бо хатои табдили навъ нависед (часпонидан ба ҷои ҷамъ; NaN аз сабаби undefined; муқоисаи ғайриқатъӣ), дар поён бошад — варианти ислоҳшудаи ҳар кадомро.
  7. Ошкорсози Falsy. Boolean(...)-ро барои 12 қимати гуногун бароред (0, "", " ", "0", null, undefined, NaN, -1 ва ғ.). Дар паҳлӯ бо шарҳ — пешбинии шумо.
  8. Шикори NaN ва Infinity. Се роҳи гуногуни гирифтани NaN ва ду роҳи Infinity-ро ёбед. NaN-ро тавассути Number.isNaN санҷед.
  9. Пул бе хато. Сабад: се мол бо нархҳо бо сомонӣ ва дирам (масалан, 12.40, 7.35, 0.10). Натиҷаро тавассути дирам (бо рақамҳои бутун) ҳисоб кунед ва бо сомонӣ бароред.
  10. Як промпти хуб. Промптро аз рӯи формулаи «контекст → вазифа → маҳдудиятҳо → формат» барои ҳар вазифаи ин дарс тартиб диҳед. Онро дар конспект сабт кунед (поёнтар бинед).

Кор бо ЗС ва конспект оид ба промптҳо

Супориш оид ба «доштани хато»

Ҳар 3 вазифаро аз 10 интихоб кунед. Барои ҳар кадом ба ЗС промптро аз рӯи қолаби худ фиристед: «шарҳ деҳ, ин чӣ тавр ҳал мешавад ва консол чиро мебарорад». Баъд кодро аз ҷавоб иҷро кунед ва бо натиҷаи худ муқоиса намоед. Дар конспект барои ҳар кадоми се вазифа нависед:

  • кадом промптро фиристодед (бо матн);
  • мазмуни мухтасари ҷавоби ЗС (2–3 ҷумла);
  • ЗС дар куҷо хато кард — ё агар хато накарда бошад, маҳз чиро санҷидед, то боварӣ ҳосил кунед;
  • бо промпти дуюм чиро ислоҳ ё возеҳ кардед.

Агар ЗС ягон бор хато накарда бошад — ин муқаррарӣ аст, вале он гоҳ далелҳо лозиманд: маҳз чиро иҷро ва муқоиса кардед. Ҷавоби «ЗС дуруст буд, зеро ЗС ҳамин тавр гуфт» ҳисоб карда намешавад.

✓ Варақаи хулосаи дарс

  • Тағйирёбанда — ҳуҷайраи номдор бо қимат. const — бо пешфарз, let — агар қимат тағйир ёбад, var — истифода намебарем (аз блок мерезад, дар бораи эълони такрорӣ хомӯш аст, «боло мебарояд»).
  • Номҳо: лотинӣ, camelCase, на аз рақам, регистр муҳим аст; собитҳои танзимот — UPPER_CASE.
  • Навъҳо: string, number, boolean, null, undefined (+ bigint, symbol). typeof сатр бозпас мегардонад. typeof null → "object" — ғаройиби таърихӣ; typeof NaN → "number".
  • undefined — «қимат ҳанӯз нест», null — «қимат қасдан нест».
  • Сатрҳо: литералҳои қолабӣ `Салом, ${name}`; .length, .trim(), .toUpperCase(), s[0]. Ҷойгузорӣ танҳо дар нохунакҳои баръакс кор мекунад.
  • Операторҳо: + - * / % **; кӯтоҳкуниҳо +=, -=, ++, --; Math.round/floor/ceil барои мудаввар кардан.
  • NaN — «рақам не», сироятӣ, NaN !== NaN, санҷиш — Number.isNaN(). Infinity — натиҷаи тақсим ба сифр.
  • Пулро бо дирамҳои бутун ҳисоб мекунем; 0.1 + 0.2 !== 0.3; toFixed() сатр бозпас мегардонад.
  • Табдили ошкоро: String(), Number() ("" → 0, матни зиёдатӣ → NaN), parseInt/parseFloat рақамро аз аввали сатр мехонанд, Boolean().
  • Falsy: false, 0, "", null, undefined, NaN. Боқӣ ҳама — true, аз ҷумла "0" ва "false".
  • Табдили ниҳонӣ: "5" + 3 → "53" (сатр бо + — часпонидан); "5" - 3 → 2; true + 1 → 2; null + 1 → 1; undefined + 1 → NaN; 1 + 2 + "3" → "33".
  • Муқоиса: ҳамеша === ва !==. Сатрҳо аз рӯи аломатҳо муқоиса мешаванд: "10" > "9" → false.
  • Промпт: контекст → вазифа → маҳдудиятҳо → формати ҷавоб (+ санҷиш). Ҷавоби ЗС — фарзия аст: пешбинӣ кунед, иҷро кунед, муқоиса кунед, аз нав бипурсед. Консол — довари асосӣ.
