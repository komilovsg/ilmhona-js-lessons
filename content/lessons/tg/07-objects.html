Дарси 7 · JavaScript

Объектҳо

Дар дарси гузашта мо фаро гирифтем, ки рӯйхатҳоро нигоҳ дорем: харидҳо, баҳоҳо, шаҳрҳо. Массив вақте комилан мувофиқ аст, ки чизҳо бисёранд ва якнамуданд. Аммо чӣ тавр як чизро, ки хосиятҳои гуногуни бисёр дорад, тавсиф кардан мумкин — донишҷӯ, мол, фармоиши таксӣ? Барои ин дар JavaScript объектҳо ҳастанд. Қариб ҳар чизе, ки аз сервер меояд ва дар сайт нишон дода мешавад, — объектҳо ва массивҳои объектҳо мебошанд. Имрӯз ҳамаро якҷоя ҷамъ мекунем: функсияҳо, массивҳо ва объектҳо — ва меомӯзем, ки ба ЗС вазифаҳои дақиқро бо ин забон гузорем.

  • Объектҳо эҷод кардан, хосиятҳои онҳоро хондан, тағйир додан, илова ва нест кардан
  • Бо додаҳои дарунравӣ ва массивҳои объектҳо кор кардан — мисли ҷавобҳои воқеии сервер
  • Методҳои объектро навиштан ва фаҳмидан, ки this ба чӣ ишора мекунад
  • Додаҳоро зуд бо деструктуризатсия гирифтан ва нусхаҳоро тавассути ... сохтан
  • Объектҳоро ба JSON ва баръакс табдил додан, додаҳои серверро бехатар хондан
  • Барои ЗС промптҳои дақиқро бо забони JS навиштан ва ҷавобҳои онро санҷидан

01 Объект чист ва он барои чӣ лозим аст

Массивро ба ёд меорем: ["нон", "чой", "самбуса"]. Ин рӯйхати чизҳои якнамуд аст, ва ба ҳар кадом мо бо рақам — индекс муроҷиат мекунем. Акнун кӯшиш мекунем як донишҷӯро тавсиф кунем: ном, синну сол, шаҳр, курс. Бо массив ҳам мешавад:

Бо массив — нокулай

Дар student[2] чӣ ҳаст? Тартибро дар хотир доштан лозим аст. Ҷойҳоро омехтед — хатое мегиред, ки пай бурдани он душвор аст.

const student = ["Фарход", 20, "Душанбе", "Frontend"];
console.log(student[2]); // ва ин чист? шаҳр? курс?
Бо объект — фаҳмо

Ҳар қимат ном дорад. Код мехонед — ва фавран мефаҳмед, ки чӣ дар куҷост.

const student = { name: "Фарход", age: 20, city: "Душанбе", course: "Frontend" };
console.log(student.city); // фавран маълум аст: шаҳр
Монандӣ аз ҳаёт

Шиноснома ё анкетаро ҳангоми ворид шудан ба MakeFirstStep ба ёд оред. Дар он «сатри рақами 3» нест — дар он майдонҳо бо номҳо ҳастанд: «Насаб», «Санаи таваллуд», «Шаҳр». Ҳар майдон ном ва мундариҷа дорад. Объект айнан ҳамин тавр сохта шудааст: ин маҷмӯаи ҷуфтҳои «ном → қимат» аст.

Объект
Маҷмӯаи ҷуфтҳои «калид: қимат» дар қавсайни фигурӣ { }. Як чизро бо хосиятҳои бисёр тавсиф мекунад.
Хосият
Як ҷуфт дар дохили объект, масалан city: "Душанбе". Мисли як майдон дар анкета.

Он чи дар зери калид нигоҳ дошта мешавад ("Душанбе"). Метавонад ҳар чиз бошад: адад, сатр, массив, объекти дигар, функсия.

Объектро чӣ тавр эҷод кардан

Объектро дар қавсайни фигурӣ менависанд. Дар дохил — хосиятҳо бо вергул. Ҳар хосият: калид, ду нуқта, қимат. Чунин навишт литерали объект номида мешавад.

const student = {
  name: "Фарход",
  age: 20,
  city: "Душанбе",
  isStudent: true
};

console.log(student);        // → { name: "Фарход", age: 20, city: "Душанбе", isStudent: true }
console.log(typeof student); // → object

const empty = {};            // объекти холӣ — низ объект аст
console.log(empty);          // → {}

Хосиятро чӣ тавр хондан: нуқта ва қавсайни мураббаъ

Ду усул ҳаст. Тавассути нуқта — student.name — аз ҳама маъмул ва кӯтоҳ. Тавассути қавсайни мураббаъ — student["name"] — дар ду ҳолат лозим аст:

  • дар калид фосила ё тире ҳаст: product["старая цена"], product["made-in"];
  • номи калид дар тағйирёбанда ҳаст: product[field].
const product = {
  title: "Казан",
  price: 250,
  "made-in": "Таджикистан",
  "старая цена": 300
};

console.log(product.title);          // → Казан
console.log(product["price"]);       // → 250
console.log(product["made-in"]);     // → Таджикистан
console.log(product["старая цена"]); // → 300

// калид дар тағйирёбанда ҳаст
const field = "title";
console.log(product[field]);  // → Казан
console.log(product.field);   // → undefined (калидро бо номи "field" меҷӯяд)

Сатри охирин — хатои маъмул аст. product.field хосиятеро меҷӯяд, ки айнан field ном дорад. Ва product[field] аввал қимати тағйирёбандаро ("title") мегирад ва танҳо баъд чунин калидро меҷӯяд.

Чунин хосият нест — undefined мегирем

const user = { name: "Мадина" };

console.log(user.age);    // → undefined
console.log(user.length); // → undefined (объект length надорад, мисли массив)

Хато нест: JavaScript оддӣ мегӯяд «дар ин ҷо чизе нест». Хато мешавад, агар хосиятро аз худи undefined гирифтан хоҳем, масалан user.address.city. Чӣ тавр муҳофизат кардан — дар мавзӯи 02 ҷудо мекунем.

Тағйир додан, илова кардан, нест кардан

Объектро баъд аз эҷод тағйир додан мумкин аст. Ба калиди мавҷуда қимат таъин кардем — тағйир додем. Ба калиди нав — илова кардем. Оператори delete хосиятро нест мекунад. Ва оператори in месанҷад, ки калид ҳаст ё не.

const order = { dish: "Оши палав", price: 30 };

order.price = 35;      // тағйир додан: калиди price аллакай буд
order.drink = "Чой";   // илова кардан: калиди drink набуд
console.log(order);    // → { dish: "Оши палав", price: 35, drink: "Чой" }

delete order.drink;    // нест кардан
console.log(order);    // → { dish: "Оши палав", price: 35 }

console.log("price" in order); // → true
console.log("drink" in order); // → false
Муҳим: const ва объектҳо

const аз нав таъин кардан-и тағйирёбандаро — гузоштани объекти дигарро ба он — манъ мекунад. Аммо мазмун-и объектро тағйир додан мумкин аст. Тасаввур кунед: ба қуттӣ ёрлиқи «card» часпонда шудааст. Ёрлиқро ба қуттии дигар ҷобаҷо кардан мумкин нест, аммо чизҳои дохили қуттиро тағйир додан мумкин аст.

const card = { owner: "Зарина", balance: 100 };

card.balance = 150;          // мумкин аст: мазмунро тағйир медиҳем
console.log(card.balance);   // → 150

// card = { owner: "Зарина", balance: 0 };  // мумкин нест: TypeError, const аз нав таъин намешавад

Навишти кӯтоҳи хосиятҳо

Аксар вақт қиматҳо аллакай дар тағйирёбандаҳо бо ҳамон номҳо ҳастанд. Он гоҳ ба ҷои { name: name, age: age } танҳо { name, age } навиштан мумкин аст. Ин як чиз аст.

const name = "Нилуфар";
const age = 18;
const city = "Бохтар";

const student = { name, age, city };
console.log(student); // → { name: "Нилуфар", age: 18, city: "Бохтар" }

// функсияи «фабрика»: додаҳоро мегирад, объект бармегардонад
const makeStudent = (name, city) => ({ name, city, course: "Frontend + ИИ" });
console.log(makeStudent("Далер", "Куляб")); // → { name: "Далер", city: "Куляб", course: "Frontend + ИИ" }
Қапқон: функсияи тирдор объект бармегардонад

Ба қавсайни доира диққат диҳед: () => ({ ... }). Бе онҳо JavaScript мешуморад, ки { — оғози бадани функсия аст, на объект, ва функсия undefined бармегардонад.

Ҳамаи хосиятҳоро чӣ тавр гузаштан

Массив for...of ва методҳо дорад. Объектро мустақиман ин тавр гузаштан мумкин нест, аммо се ёвар ҳаст, ки объектро ба массив табдил медиҳанд:

  • Object.keys(obj) — массиви калидҳо;
  • Object.values(obj) — массиви қиматҳо;
  • Object.entries(obj) — массиви ҷуфтҳои [калид, қимат].
const grades = { html: 5, css: 4, js: 5 };

console.log(Object.keys(grades));    // → ["html", "css", "js"]
console.log(Object.values(grades));  // → [5, 4, 5]
console.log(Object.entries(grades)); // → [["html", 5], ["css", 4], ["js", 5]]

// дар объект чанд хосият ҳаст
console.log(Object.keys(grades).length); // → 3

// баҳои миёна: values + reduce аз дарси гузашта
const sum = Object.values(grades).reduce((total, g) => total + g, 0);
console.log(sum / Object.keys(grades).length); // → 4.666666666666667

Бештар ҷуфтҳоро тавассути for...of бар Object.entries мегузаранд. Навишти const [subject, grade] ҷуфтро ба ду тағйирёбанда ҷудо мекунад — муфассал инро дар мавзӯи 05 мефаҳмем, ҳоло танҳо шаклро дар хотир доред.

const grades = { html: 5, css: 4, js: 5 };

for (const [subject, grade] of Object.entries(grades)) {
  console.log(`${subject}: ${grade}`);
}
// → html: 5
// → css: 4
// → js: 5

Усули кӯҳна ҳам ҳаст — давраи for...in. Он калидҳо-ро мегузарад, ва қиматро тавассути қавсайни мураббаъ мегирем:

const grades = { html: 5, css: 4, js: 5 };

for (const key in grades) {
  console.log(key, grades[key]);
}
// → html 5
// → css 4
// → js 5
Хатогиҳои маъмул

1) grades.key дар дохили for...in — калиди «key»-ро меҷӯяд. grades[key] лозим аст.
2) obj.length — объект дарозӣ надорад. Object.keys(obj).length-ро истифода баред.
3) { name = "Фарход" } — дар дохили литерал ду нуқта мегузоранд, на =.
4) Вергулро байни хосиятҳо фаромӯш карданд — SyntaxError.

Ишораи ЗС

Агар боварӣ надоред, ки объект лозим аст ё массив, додаҳоро ба ЗС бо калимаҳо тавсиф кунед: «ман 30 донишҷӯро нигоҳ медорам, ҳар кадом ном, шаҳр ва баҳоҳо дорад — додаҳоро дар JS чӣ тавр беҳтар ташкил кардан мумкин?». Ҷавоби хуб — массиви объектҳо. Аммо қарорро худатон қабул кунед: шумо акнун қоидаро медонед.

Амалия: мустаҳкам мекунем

Аз анкета оғоз мекунем, баъд бо кортии мол кор мекунем, ва дар охир овозҳоро ҳисоб мекунем — объект ҳамчун «ҳисобкунак».

02 Дарунравӣ: объектҳо дар объектҳо, массивҳои объектҳо

Қимати хосият метавонад ҳар чиз бошад — аз ҷумла объекти дигар ё массив. Додаҳои воқеӣ ҳамин тавр менамоянд: корбар суроға (объект), рӯйхати малакаҳо (массив) дорад, ва гурӯҳ — массиви донишҷӯён дорад, ки ҳар кадом — объект аст.

Монандӣ аз ҳаёт

Ҷузвдони «Гурӯҳи FE-07» дар ҷевон. Дар он варақа бо номи ментор ва боз як ҷузвдон «Донишҷӯён» мебошад. Дар ҷузвдони «Донишҷӯён» — анкетаҳо, ҳар кадом дар варақаи худ. Барои ёфтани шаҳри донишҷӯи дуюм шумо мекушоед: гурӯҳ → ҷузвдони донишҷӯён → анкетаи дуюм → майдони «Шаҳр». Дар код роҳ айнан ҳамин тавр навишта мешавад: group.students[1].city.

const user = {
  name: "Шахром",
  age: 22,
  address: {               // объект дар дохили объект
    city: "Худжанд",
    street: "ул. Камоли Худжанди"
  },
  skills: ["HTML", "CSS"]  // массив дар дохили объект
};

console.log(user.address.city);   // → Худжанд
console.log(user.skills[0]);      // → HTML
console.log(user.skills.length);  // → 2

user.address.zip = "735700";      // ба объекти дарунравӣ хосият илова кардем
user.skills.push("JavaScript");   // методҳои массив ба тартиби муқаррарӣ кор мекунанд
console.log(user.skills);         // → ["HTML", "CSS", "JavaScript"]

Массиви объектҳо — шакли аз ҳама маъмули додаҳо

Вақте сайт аз сервер рӯйхати молҳо, донишҷӯён ё фармоишҳоро пурсон мешавад, қариб ҳамеша массиви объектҳо меояд. Гурӯҳи донишҷӯён чунин менамояд:

const group = {
  name: "FE-07",
  mentor: { name: "Далер" },
  students: [
    { name: "Фарход", city: "Душанбе" },
    { name: "Мадина", city: "Худжанд" }
  ]
};

console.log(group.mentor.name);       // → Далер
console.log(group.students[1].name);  // → Мадина
console.log(group.students.length);   // → 2

Роҳи дарозро чӣ тавр хондан

  1. group — тамоми объекти гурӯҳро мегирем.

Методҳои массивҳо + объектҳо

Ҳар чизе, ки шумо дар дарси гузашта омӯхтед, бо массиви объектҳо комилан кор мекунад. Ба callback объекти пурра меояд, ва мо аз он хосияти лозимиро мегирем.

Агар он чиро, ки find баргардонд, тағйир диҳед, объекти дохили массив низ тағйир меёбад. Ин нусха нест, балки як «истинод»-и дигар ба ҳамон объект аст.

Дастрасии бехатар: ?.

Додаҳои сервер на ҳамеша пурра мебошанд. Дар як корбар суроға ҳаст, дар дигаре — не. Агар хосиятро аз undefined гирем, барнома бо хатои TypeError меафтад, ва тамоми коди поёнтар иҷро намешавад:

console.log(users[1].address.city); // TypeError: суроға undefined аст, city надорад
console.log("Эта строка уже не выполнится");

Оператори занҷири ихтиёрӣ ?. мегӯяд: «агар дар чап undefined ё null бошад — минбаъд нарав, оддӣ undefined баргардон». Ва оператори ?? имкон медиҳад, ки қимати пешфарз гузорем, агар дар чап undefined ё null бошад. Онҳоро аксар вақт якҷоя истифода мебаранд.

  { name: "Далер", address: { city: "Куляб" } },
  { name: "Сабрина" }
];

console.log(users[1].address?.city ?? "город не указан"); // → шаҳр нишон дода нашудааст

for (const u of users) {
  console.log(`${u.name}: ${u.address?.city ?? "—"}`);
}
// → Далер: Куляб
// → Сабрина: —

// ?. бо массивҳо низ кор мекунад
const empty = [];

?.-ро ҳама ҷо паси ҳам нагузоред

?. дар он ҷо лозим аст, ки додаҳо дар ҳақиқат метавонанд набошанд (майдони ихтиёрӣ, ҷавоби холӣ). Агар хосият ҳатман бояд бошад, ва вай нест — беҳтар аст хато гирифта, хатоиро ёфт, на ин ки хомӯшона холигиро нишон диҳем.

03 Методҳои объект

Қимати хосият метавонад функсия низ бошад. Чунин функсия дар дохили объект метод номида мешавад. Хосиятҳо тавсиф мекунанд, ки объект чӣ гуна аст (ном, нарх, шаҳр), ва методҳо — вай чӣ кор карда метавонад (салом додан, ҷамъро ҳисоб кардан, тахфиф татбиқ намудан).

Монандӣ аз ҳаёт

Чойник: вай хосиятҳо дорад — ранг, ҳаҷм, чанд об рехта шудааст. Ва тугмаи «ҷӯшон» ҳаст — ин амал аст. Дар объект хосиятҳо — додаҳоянд, ва методҳо — тугмаҳоянд, ки чизеро иҷро мекунанд.

Метод
Функсияе, ки дар хосияти объект ҷойгир аст.
Даъвати метод
Навишти объект.метод() — бо қавсайн! Бе қавсайн шумо танҳо худи функсияро мегиред, аммо онро ба кор намеандозед.
const chaikhana = {
  name: "Рохат",
  city: "Душанбе",
  greet: function () {
    console.log("Хуш омадед в чайхану!");
  }
};

chaikhana.greet();                  // → Хуш омадед в чайхану!
console.log(typeof chaikhana.greet); // → function

Навишти кӯтоҳи метод

Калимаи function ва ду нуқтаро партофтан мумкин аст: greet() { ... }. Ин навишти муосир аст, онро шумо аксар вақт мебинед. Методҳо, мисли функсияҳои оддӣ, параметр мегиранд ва тавассути return қиматҳо бармегардонанд.

const calc = {
  add(a, b) {
    return a + b;
  },
  multiply(a, b) {
    return a * b;
  },
  percent(sum, p) {
    return sum * p / 100;
  }
};

console.log(calc.add(25, 17));      // → 42
console.log(calc.multiply(4, 12));  // → 48
console.log(calc.percent(300, 15)); // → 45

Шумо аз қадим методҳоро истифода мебаред

Ҳар дафъае, ки шумо нуқта ва қавсайн гузоштед, шумо методи объекти дарунсохтро даъват мекардед. console — объект аст, ва log — методи он! Math — объект бо методҳои риёзӣ. Сатрҳо ва массивҳо низ методҳо доранд.

console.log(typeof console);     // → object
console.log(typeof console.log); // → function

console.log(Math.round(4.6));    // → 5
console.log(Math.max(3, 9, 4));  // → 9

const city = "хорог";
console.log(city.toUpperCase()); // → ХОРОГ

const cart = ["нон"];
cart.push("чой");                // push — методи массив
console.log(cart);               // → ["нон", "чой"]

Пас arr.push(...) ва calc.add(...) — як ғоя аст: объект хосияти-функсия дорад, ва мо онро тавассути нуқта даъват мекунем.

Қавсайнро фаромӯш карданд

Метод оғоз нашуд — худи функсия баромад.

console.log(calc.add);   // ƒ add() — ин функсия аст, на натиҷа
chaikhana.greet;         // ҳеҷ чиз рӯй надод
Бо қавсайн

Метод иҷро шуд ва натиҷа баргардонд.

console.log(calc.add(2, 3)); // 5
chaikhana.greet();           // Хуш омадед в чайхану!

Методе, ки ба додаҳои объект ниёз дорад

Аксар вақт ба метод хосиятҳои дигари ҳамон объект лозиманд. Ҳоло ба онҳо бо номи тағйирёбанда муроҷиат кардан мумкин аст:

const chaikhana = {
  name: "Рохат",
  open: "07:00",
  info() {
    return `Чайхана «${chaikhana.name}», открыта с ${chaikhana.open}`;
  }
};

console.log(chaikhana.info()); // → Чайхана «Рохат», открыта с 07:00

Ин кор мекунад, аммо нокулай аст: агар тағйирёбандаро иваз кунед ё хоҳед, ки чунин метод дар объекти дигар бошад — ҳама чиз вайрон мешавад. Барои ин калимаи махсуси this ҳаст — мавзӯи оянда.

Хатогиҳои маъмул

1) Даъват бе қавсайн: obj.method ба ҷойи obj.method().
2) Хатои имлоӣ дар ном: calc.Add() → TypeError: calc.Add is not a function. Ҳарфҳои калон ва хурд муҳиманд.
3) return-ро фаромӯш карданд — метод undefined бармегардонад, ҳарчанд дар дохил ҳама чизро ҳисоб кардааст.

04 this — «ин объект»

Дар дохили метод аксар вақт гуфтан лозим аст: «номи ин объектро гир». Барои ин калимаи this ҳаст. Қоидае, ки дар хотир нигоҳ доштан лозим аст:

Қоидаи асосӣ

this — объекте аст, ки дар лаҳзаи даъвати метод пеш аз нуқта меистад. student.introduce()-ро даъват кардем — яъне дар дохил this ба student баробар аст.

Монандӣ аз ҳаёт

Калимаи «ман». Вақте Фарход мегӯяд «ман аз Душанбе», «ман» — Фарход аст. Вақте ҳамин ибораро Мадина мегӯяд, «ман» — Мадина аст. Ибора як аст, аммо маъно вобаста аст, ки кӣ мегӯяд. this — «ман» барои метод аст: вобаста аст, ки метод аз кадом объект даъват шудааст.

const student = {
  name: "Манижа",
  city: "Истаравшан",
  introduce() {
    console.log(`Салом! Я ${this.name} из города ${this.city}`);
  }
};

student.introduce(); // → Салом! Я Манижа из города Истаравшан

student.city = "Душанбе"; // кӯчид
student.introduce(); // → Салом! Я Манижа из города Душанбе
  1. Даъвати student.introduce(). JavaScript мебинад, ки дар чапи нуқта чӣ меистад, — ин student аст.
  2. this = student. Дар муддати ин даъват this ба объекти student ишора мекунад.
  3. this.name — ин ҳамон student.name аст, яъне "Манижа".
  4. Метод ҳамеша додаҳои тоза мегирад. city-ро тағйир додед — даъвати оянда аллакай шаҳри навро нишон медиҳад.

Методҳо объектро тавассути this тағйир медиҳанд

const counter = {
  count: 0,
  increment() {
    this.count++;
  },
  reset() {
    this.count = 0;
  },
  show() {
    console.log(`Счётчик: ${this.count}`);
  }
};

counter.increment();
counter.increment();
counter.increment();
counter.show();  // → Счётчик: 3
counter.reset();
counter.show();  // → Счётчик: 0

Як функсия — объектҳои гуногун

Дар ин ҷо this дар ҳақиқат муфид аст. Як функсияро ба якчанд объект гузоштан мумкин аст — ва ҳар дафъа this ҳамон объекте мешавад, ки функсия аз он даъват шудааст.

function sayHi() {
  console.log(`Ассалому алейкум, я ${this.name}`);
}

const farhod = { name: "Фарход", sayHi };
const zarina = { name: "Зарина", sayHi };

farhod.sayHi(); // → Ассалому алейкум, я Фарход
zarina.sayHi(); // → Ассалому алейкум, я Зарина

Қапқони 1: функсияи тирдор ҳамчун метод

Функсияи тирдор худи this надорад. Вай this-ро аз берун мегирад — аз ҷое, ки навишта шудааст, на аз объекти пеш аз нуқта. Бинобар ин ҳамчун метод бо this кор намекунад:

const user = {
  name: "Рустам",
  hello: () => {
    console.log(this === user); // тирдор: this аз берун аз объект гирифта шуд
  },
  hi() {
    console.log(this === user); // методи оддӣ: this — объекти пеш аз нуқта
  }
};

user.hello(); // → false
user.hi();    // → true

Агар дар дохили hello this.name мебуд, шумо на «Рустам», балки холигӣ ё undefined-ро мегирифтед. Аммо функсияи тирдор дар дохили метод ғайриҳамсол аст — масалан, ҳамчун callback барои map: вай this-ро аз метод мегирад, яъне аз объект.

const shop = {
  discount: 10,
  prices: [100, 250, 40],
  withDiscount() {
    // callback-и тирдор this-ро аз методи withDiscount мегирад, яъне shop
    return this.prices.map(p => p - p * this.discount / 100);
  }
};

console.log(shop.withDiscount()); // → [90, 225, 36]
Қоидаи ҳарруза

Методи объектро бо навишти кӯтоҳи method() { } менависем. Callback-ҳои дохили метод (map, filter, reduce) — тирдор. Он гоҳ this ҳамеша ҳамон чизе мешавад, ки лозим аст.

Қапқони 2: методро аз объект «канданд»

Агар методро ба тағйирёбандаи алоҳида нигоҳ дошта, онро даъват кунед, пеш аз нуқта аллакай чизе нест. Дар реҷаи қатъӣ ("use strict" — он дар иҷрои кодамон ва дар ҳамаи лоиҳаҳои муосир фаъол аст) this undefined мешавад, ва муроҷиати this.name меафтад:

const user = {
  name: "Рустам",
  introduce() {
    console.log(`Я ${this.name}`);
  }
};

user.introduce();          // → Я Рустам
const f = user.introduce;  // функсияро бе объект гирифтем
f();                       // TypeError: this — undefined, name надорад

Чӣ тавр ислоҳ кардан: тавассути объект даъват кардан — user.introduce(), ё ба функсияи тирдор печондан: const f = () => user.introduce();. Ин аксар вақт рӯй медиҳад, вақте ки методро ба функсияи дигар медиҳанд, масалан setTimeout(user.introduce, 1000) — дар он ҷо низ this гум мешавад.

const user = {
  name: "Рустам",
  introduce() {
    console.log(`Я ${this.name}`);
  }
};

const f = () => user.introduce(); // печонак: дар дохил даъват боз тавассути нуқта
f(); // → Я Рустам

Барои идоракунии this боз методҳои bind, call ва apply ҳастанд — масалан, user.introduce.bind(user) объектро абадӣ «мебандад». Мо онҳоро баъдтар ҷудо мекунем, ҳоло қоидаи «объект пеш аз нуқта» кифоя аст.

Ишораи ЗС

ЗС баъзан методҳоро бо функсияҳои тирдор «барои кӯтоҳӣ» менависад — ва this вайрон мешавад. Дар ҷавоби ЗС method: () => { ... this ... }-ро диданд — фавран хоҳиш кунед, ки ба method() { } аз нав нависад.

Амалия: мустаҳкам мекунем

05 Деструктуризатсия

Деструктуризатсия — усули кӯтоҳи «ҷудо кардан»-и объект ё массив ба тағйирёбандаҳои алоҳида. Ба ҷойи се сатри const name = user.name; const age = user.age; ... — як сатр.

Монандӣ аз ҳаёт

Шумо аз бозор бо халта омадед: харбуза, нон, анор. Ҳар дафъа ба халта даст дароз кардан мумкин аст — «халта, харбузаро деҳ». Ва мумкин аст фавран ҷобаҷо кард: харбузаро ба рӯи миз, нонро ба нонхона, анорро ба гулдон. Деструктуризатсия — маҳз «мазмунро ба ҷояш ҷобаҷо кардан» аст, то минбаъд фавран гирем.

Аз объект: аз рӯи номи калидҳо

const user = { name: "Зарина", age: 21, city: "Пенджикент" };

// ба тарзи кӯҳна
const userCity = user.city;

// деструктуризатсия: калидҳои name ва age-ро ба тағйирёбандаҳои ҳамном мегирем
const { name, age } = user;

console.log(name, age);  // → Зарина 21
console.log(userCity);   // → Пенджикент

Дар чапи = қавсайни фигурӣ на «объект эҷод кардан», балки «аз объект гирифтан»-ро ифода мекунад. Номҳои тағйирёбандаҳо бояд бо калидҳо мувофиқ бошанд, тартиб муҳим нест.

Ном иваз кардан ва қиматҳои пешфарз

const user = { name: "Зарина", age: 21, city: "Пенджикент" };

// name: userName — «калиди name-ро гир, аммо тағйирёбандаро userName ном бигузор»
const { name: userName } = user;
console.log(userName); // → Зарина

// қимати пешфарз — агар калид нест (undefined)
const { country = "Таджикистан", city = "Душанбе" } = user;
console.log(country); // → Таджикистан (калид набуд)
console.log(city);    // → Пенджикент (калид буд — default лозим нест)
Ду нуқтаро чӣ тавр дар хотир нигоҳ доштан

Дар деструктуризатсияи { аз_куҷо: ба_куҷо }: дар чапи ду нуқта — калиди объект, дар рост — номи тағйирёбандаи нав. Ва = — қимати пешфарз.

Деструктуризатсияи дарунравӣ

const order = {
  id: 77,
  customer: { name: "Фарход", phone: "+992 90 111 22 33" },
  address: { city: "Душанбе", street: "проспект Рудаки, 45" }
};

const { id, customer: { name }, address: { street } } = order;
console.log(id, name, street); // → 77 Фарход проспект Рудаки, 45

// customer ва address дар ин ҷо — танҳо «роҳ» аст, тағйирёбандаҳо бо чунин ном нестанд

Аз массив: аз рӯи мавқеъ

Барои массив қавсайни мураббаъ истифода мешавад, ва тағйирёбандаҳо бо тартиб гирифта мешаванд, на бо ном.

const route = ["Душанбе", "Варзоб", "Искандеркуль"];

const [start, stop, finish] = route;
console.log(start);  // → Душанбе
console.log(finish); // → Искандеркуль

// унсурро гузаштан — танҳо вергул
const [, , lake] = route;
console.log(lake);   // → Искандеркуль

// ду тағйирёбандаро ҷой иваз кардан
let first = "чой";
let second = "шакароб";
[first, second] = [second, first];
console.log(first, second); // → шакароб чой

Дар параметрҳои функсия

Истифодаи аз ҳама маъмул: функсия объектро мегирад ва фавран онро ҷудо мекунад. Маълум мешавад, ки кадом майдонҳо ба вай лозиманд, ва қиматҳои пешфарзро додан мумкин аст.

function showProduct({ title, price, currency = "сомони" }) {
  console.log(`${title}: ${price} ${currency}`);
}

showProduct({ title: "Гранат", price: 15 });   // → Гранат: 15 сомони
showProduct({ title: "Черешня", price: 3, currency: "$" }); // → Черешня: 3 $

// дар callback-ҳои массивҳо
const fruits = [{ title: "Дыня", price: 12 }, { title: "Виноград", price: 18 }];
console.log(fruits.map(({ title }) => title)); // → ["Дыня", "Виноград"]

// ва дар гузариш аз ҷуфтҳои объект — акнун фаҳмо аст, ки дар ин ҷо чӣ рӯй медиҳад
for (const [fruit, kg] of Object.entries({ зардолу: 3, гранат: 2 })) {
  console.log(`${fruit} — ${kg} кг`);
}
// → зардолу — 3 кг
// → гранат — 2 кг
Чаро ин дар React ҳама ҷо ҳаст

Дар фреймворки фронтенди React, ки шумо меомӯзед, компонент додаҳоро ҳамчун объект мегирад — ва қариб ҳамеша онро фавран деструктуризатсия мекунанд. Ва ҳуки useState массиви ду унсурро бармегардонад, ки аз рӯи мавқеъ ҷудо карда мешавад. Ҳоло танҳо шакли шиносро шиносед:

function ProductCard({ title, price }) {          // деструктуризатсияи объект
  const [count, setCount] = useState(0);          // деструктуризатсияи массив
  // ...
}
Хатогиҳои маъмул

1) Хатои имлоӣ дар ном: const { nmae } = user — undefined мегиред, хато намешавад.
2) Деструктуризатсия аз undefined: const { name } = undefined → TypeError.
3) Тағйирёбанда аллакай эълон шудааст: const { name } = user, вақте ки name дар боло аллакай ҳаст → SyntaxError: ... has already been declared. Ном иваз карданро истифода баред.
4) Қимати пешфарз танҳо барои undefined кор мекунад, на барои null ё 0.

ВАЗИФАИ 5.3

Ҷавоби сервер бо брон

06 Spread ва rest: се нуқта ...

Се нуқтаи ... дар JavaScript ду нақш дорад. Spread («кушодан») массив ё объектро ба унсурҳои алоҳида паҳн мекунад. Rest («боқимонда») баръакс унсурҳои алоҳидаро ба массив ё объект ҷамъ мекунад. Навишт як аст, аммо маъно аз ҷой вобаста аст.

Spread барои массивҳо

const fruits = ["зардолу", "гранат"];
const more = ["дыня", "виноград"];

// муттаҳид кардан
const all = [...fruits, ...more];
console.log(all); // → ["зардолу", "гранат", "дыня", "виноград"]

// унсурро ба оғоз ё охир илова кардан, бе тағйири массиви аслӣ
const withCherry = ["черешня", ...fruits];
console.log(withCherry); // → ["черешня", "зардолу", "гранат"]

// массивро ба аргументҳои функсия паҳн кардан
const prices = [12, 45, 7];
console.log(Math.max(...prices)); // → 45

Нусха ё истинод?

Чизи хеле муҳим. Аломати = массив ё объектро нусха намекунад — он ба ҳамон чиз ном дуюм медиҳад. Нусхаи воқеӣ — тавассути spread.

Монандӣ аз ҳаёт

const b = a — ин калиди дуюми ҳамон хона аст: диванро ҷой иваз кардед — ҳардуи соҳибон мебинанд. const b = [...a] — ин хонаи нав бо ҳамон мебел аст: дар яке ҳар чӣ хоҳед тағйир медиҳед, дигаре мисли пештара мемонад.

const fruits = ["зардолу", "гранат"];

const same = fruits;      // нусха НЕСТ — ҳамон аст
same.push("дыня");
console.log(fruits);      // → ["зардолу", "гранат", "дыня"] (вайрон шуд!)

const copy = [...fruits]; // нусхаи воқеӣ
copy.push("виноград");
console.log(fruits);      // → ["зардолу", "гранат", "дыня"] (тағйир наёфт)
console.log(copy);        // → ["зардолу", "гранат", "дыня", "виноград"]

Spread барои объектҳо

Бо объектҳо — ҳамин тавр: нусха бардоштан, муттаҳид кардан ва «як майдонро тағйир додан» дар нусха. Агар калид ду бор вомехӯрад, охирин ғолиб меояд.

const user = { name: "Далер", age: 20, city: "Куляб" };

// нусха бо майдони тағйирёфта
const older = { ...user, age: 21 };
console.log(user.age, older.age); // → 20 21

// ду объектро муттаҳид кардан

const full = { ...user, ...contacts };
console.log(Object.keys(full)); // → ["name", "age", "city", "phone", "telegram"]

// тартиб муҳим аст: охирин ғолиб меояд
const wrong = { age: 21, ...user };
console.log(wrong.age); // → 20 (age аз user 21-ро аз нав навишт)

Чаро фронтенд нусхаҳои навро дӯст медорад

Дар фронтенд (ва махсусан дар React) одат шудааст, ки додаҳои кӯҳнаро тағйир надиҳанд, балки нусхаҳои навро бо тағйирот эҷод кунанд. Ин тағйирнопазирӣ (immutability) номида мешавад. Барои чӣ? Барнома додаҳои кӯҳна ва навро муқоиса мекунад: агар объект ҳамон бошад (шумо онро оддӣ ислоҳ кардед), вай қарор медиҳад, ки чизе тағйир наёфтааст, ва экранро навсозӣ намекунад. Нусхаи нав — сигнали равшан: «додаҳо тағйир ёфтанд, аз нав бикаш».

const addToCart = (cart, item) => [...cart, item];
const updateQty = (item, qty) => ({ ...item, qty });

const cart = [{ title: "Нон", qty: 2 }];
const newCart = addToCart(cart, { title: "Чой", qty: 1 });

console.log(cart.length, newCart.length); // → 1 2
console.log(updateQty(cart[0], 5));       // → { title: "Нон", qty: 5 }
console.log(cart[0]);                     // → { title: "Нон", qty: 2 }
Қапқон: нусха сатҳӣ аст

Spread танҳо сатҳи аввал-ро нусха мекунад. Объектҳо ва массивҳои дарунравӣ нусха намешаванд — нусха ва асл онҳоро якҷоя истифода бурданро давом медиҳанд.

const student = { name: "Абдулло", address: { city: "Турсунзаде" } };

const copy = { ...student };
copy.name = "Абдулло К.";          // сатҳи аввал — нусха, асл бутун аст
copy.address.city = "Душанбе";     // объекти дарунравӣ — умумӣ!

console.log(student.name);         // → Абдулло
console.log(student.address.city); // → Душанбе (хато!)

// дуруст: сатҳи дарунравиро низ нусха мекунем
const student2 = { name: "Мадина", address: { city: "Худжанд" } };
const moved = { ...student2, address: { ...student2.address, city: "Душанбе" } };
console.log(student2.address.city, moved.address.city); // → Худжанд Душанбе

Нусхаи пурра (амиқ)-ро тавассути structuredClone сохтан мумкин аст — дар мавзӯи 07 ҷудо мекунем.

Rest: «ҳама чизи боқимонда»-ро ҷамъ кардан

Дар параметрҳои функсия ... ҳамаи аргументҳои додашударо ба массив ҷамъ мекунад. Ҳамин тавр функсияеро навиштан мумкин аст, ки ҳар қадар адад мегирад.

function sum(...nums) {
  console.log(nums); // ин массиви оддӣ аст
  return nums.reduce((total, n) => total + n, 0);
}

console.log(sum(10, 20, 5)); // → [10, 20, 5]
                             // → 35
console.log(sum());          // → []
                             // → 0

// rest пас аз параметрҳои оддӣ: якум — алоҳида, боқимонда — ба массив
function order(customer, ...dishes) {
  console.log(`${customer} заказал(а): ${dishes.length} блюда`);
}
order("Зарина", "курутоб", "самбуса", "чой"); // → Зарина заказал(а): 3 блюда

Дар деструктуризатсия rest «боқимонда»-и объект ё массивро ҷамъ мекунад. Хеле қулай аст, то майдонҳои изофиро бардорем — масалан, паролро пеш аз додани додаҳо ба экран.

console.log(others); // → ["Зарина", "Рустам"]

07 JSON: додаҳо чӣ тавр сафар мекунанд

Сервер ва браузер — барномаҳои гуногунанд, аксар вақт дар компютерҳои гуногун. Объекти JavaScript-ро «аз роҳи сим» чун ҳаст фиристодан мумкин нест: дар шабака матн интиқол дода мешавад. Бинобар ин JSON (JavaScript Object Notation) ихтироъ шуд — формати матнӣ барои мубодилаи додаҳо. Вай қариб мисли объекти JS менамояд, аммо ин сатр аст.

Монандӣ аз ҳаёт

Шумо аз Хуҷанд ба Душанбе кӯч мекунед. Ҷевон дар мошин пурра ҷо намешавад — шумо онро ҷудо мекунед, дар қуттиҳо бо дастур бастабандӣ мекунед, ва дар ҷойи нав баръакс ҷамъ мекунед. JSON.stringify — «ҷудо ва бастабандӣ кардан»-и объект ба сатр. JSON.parse — «баръакс ҷамъ кардан»-и объект аз сатр.

JSON-ро дар куҷо вомехӯред:

  • Ҷавобҳои сервер. Обуҳаво, рӯйхати молҳо, фармоишҳо — ҳама бо сатри JSON меояд, ки онро ба объект табдил додан лозим аст.
  • localStorage — захира дар браузер. Он танҳо сатрҳоро нигоҳ дошта метавонад, бинобар ин объектҳоро ба он ҷо дар шакли JSON мегузоранд.
  • Файлҳои танзими лоиҳаҳо, масалан package.json.

Хатогиҳои таҳлил ва try/catch

Агар сатр — JSON-и дуруст набошад (нохунаки ягона, вергули изофӣ, ҷавоби бурида), JSON.parse хатои SyntaxError-ро мепартояд, ва барнома меистад. Барои ин нашавад, сохтори try...catch-ро истифода мебаранд:

  1. try { ... } — «кӯшиш кун иҷро кунӣ». Агар ҳама чиз хуб бошад, блоки catch гузаронида мешавад.
  2. catch (error) { ... } — «агар дар дохили try чизе афтод, ба ин ҷо биё». Дар error объекти хато мемонад, вай name ва message дорад.
  3. Барнома кор карданро давом медиҳад аз сатри баъд аз catch.
const bad = "{'city': 'Хорог'}"; // нохунаки ягона — ин JSON нест

try {
  const data = JSON.parse(bad);
  console.log(data.city);
} catch (error) {
  console.log("Не удалось прочитать данные");  // → Не удалось прочитать данные
  console.log(error.name);                      // → SyntaxError
}

console.log("Программа работает дальше");       // → Барнома минбаъд кор мекунад

Дар се дарс шумо луғатеро омӯхтед, ки фронтенд бо он сухан мегӯяд: функсияҳо, массивҳо, методҳо, объектҳо. Вақтро ба навиштани 15 моли дастӣ сарф накунед. ЗС додаҳоро хеле хуб эҷод мекунад — махсусан агар фавран майдонҳо, навъҳо ва заминаи маҳаллиро нишон диҳед.

9. Қоидаи асосӣ

Кодеро, ки шарҳ дода наметавонед, ҷойгир накунед

Агар шумо гуфта наметавонед, ки ҳар сатр чӣ мекунад, — вақте вайрон шавад, онро ислоҳ карда наметавонед. Бо қадамҳои хурд пеш равед: як функсия дар як вақт. Хоҳиш кардед — хондед — иҷро кардед — фаҳмидед — танҳо баъд навбатӣ.

Қолаби универсалии промпт

Нусха кунед ва барои вазифаи худ пур кунед. Панҷ блок қариб ҳамаи сабабҳои ҷавобҳои бадро мепӯшонад.

Замина: ман JavaScript меомӯзам (функсияҳо, массивҳо, объектҳо). [лоиҳа чӣ аст: мағоза / рӯзномаи баҳоҳо / ...]-ро менависам. Додаҳо (мисол): [2–3 объект ё порчаи JSON-ро гузоред] Вазифа: функсияи [ном]([параметрҳо])-ро нависед, ки [қадам ба қадам чӣ мекунад]. Натиҷаи интизоршаванда барои мисоли боло: [баромади дақиқ]. Маҳдудиятҳо: танҳо const/let, функсияҳои тирдор, методҳои массив (filter/map/find/reduce), деструктуризатсия дар ҷое ки мувофиқ аст. Додаҳои аслиро тағйир надеҳ. Бе китобхонаҳо. Ҳолатҳои канориро ба назар гир: массиви холӣ, майдони набуда. Формати ҷавоб: аввал код, баъд шарҳ қадам ба қадам бо забони тоҷикӣ, баъд 3 мисоли даъват бо баромади интизоршаванда.

Амалия бо ЗС

Дар ин вазифаҳо асосӣ — на гирифтани код, балки санҷидани он аст. Натиҷаро бо тугмаи «Иҷро» муқоиса кунед.

ВАЗИФАИ 9.2

ЗС хатоҳоро меёбад, шумо — месанҷед

миёна

Дар ин код се хато ҳаст — ҳама аз ҷадвали «Хатогиҳои маъмули ЗС». Аввал кӯшиш кунед, ки онҳоро худатон ёбед. const shop = {

  cheapestFirst: () => {
    return this.products.sort((a, b) => a.price - b.price);
  },
  total() {
    return this.products.reduce((sum, p) => sum + p.price);
  }
};

Хулосаи дарс

  • Объект — як чиз бо хосиятҳои номдор: { name: "Фарход", age: 20 }. Массив — рӯйхати чизҳои якнамуд. Массиви объектҳо — шакли аз ҳама маъмули додаҳо.
  • Хондан: obj.key ё obj["key"] (калид бо фосила ё дар тағйирёбанда: obj[field]). Хосият нест → undefined.
  • Тағйир додан/илова кардан: obj.key = value. Нест кардан: delete obj.key. Санҷидан: "key" in obj. Объектро дар const тағйир додан мумкин аст, аз нав таъин кардан не.
  • Навишти кӯтоҳ: { name, age }. Функсияи тирдор объектро дар қавсайн бармегардонад: () => ({ ... }).
  • Гузариш: Object.keys / values / entries + for (const [key, value] of Object.entries(obj)). Шумораи хосиятҳо: Object.keys(obj).length.
  • Дарунравӣ: group.students[1].name. Додаҳои ихтиёрӣ: user.address?.city ?? "—".
  • Метод — функсия дар объект: greet() { }, даъват бо қавсайн obj.greet().
  • this — объекти пеш аз нуқта ҳангоми даъват. Методҳо бо this — тирдор нестанд; callback-ҳои дохили метод — тирдор. Методи аз объект кандашуда this-ро гум мекунад.
  • Деструктуризатсия: const { name: userName, city = "Душанбе" } = user, const [first, , third] = arr, function f({ title, price }).
  • Spread кушода мегирад: [...a, ...b], { ...user, age: 21 } — нусхаи нав (сатҳӣ!). Rest ҷамъ мекунад: function sum(...nums), const { password, ...safe } = user.
  • JSON — матн барои мубодилаи додаҳо: JSON.stringify(obj, null, 2) ва JSON.parse(str) дар дохили try...catch. localStorage танҳо сатрҳоро нигоҳ медорад. Нусхаи амиқ — structuredClone(obj).
  • Бо ЗС: методҳо ва сохторҳоро ном баред, мисоли додаҳо ва баромади дақиқ диҳед, ҳолатҳои канориро хоҳиш кунед, бо иҷро санҷед. Кодеро, ки шарҳ дода наметавонед, ҷойгир накунед.
