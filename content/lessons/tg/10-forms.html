Шаклҳо ва санҷиш (валидатсия)

Сабти ном, вуруд, фармоиши палав бо расонидан, номнависӣ ба курс — қариб ҳар чизе, ки корбар ба сайт «медиҳад», тавассути шакл ворид мекунад. Ва корбарон хато мекунанд: майдонҳоро холӣ мегузоранд, телефонро бе рамзи кишвар менависанд, дар охири email фосила мегузоранд. Имрӯз шумо хондани маълумот аз шакл ва бо мулоимат фаҳмондани он ки чиро бояд ислоҳ кард — ҳанӯз пеш аз ирсол — меомӯзед.

  • value ва checked-ро дар майдонҳои гуногун хондан: матн, адад, тугмаҳои радио, чекбоксҳо, рӯйхат
  • Ирсоли шаклро бо ҳодисаи submit гирифтан ва маълумотро тавассути FormData ҷамъ кардан
  • Санҷиши дарунсохти браузерро истифода бурдан ва фаҳмидан, ки чӣ камбуд дорад
  • Ибораҳои муқаррарии оддӣ навиштан ва дар санҷишҳо татбиқ кардан
  • Функсияҳои санҷиши худиро навиштан ва матнҳои фаҳмои хатоҳоро бевосита дар зери майдонҳо нишон додан
  • Санҷиши «зинда»-ро анҷом додан: майдонро ҳангоми воридкунии маълумот санҷидан
Бо ин саҳифа чӣ тавр кор кардан лозим

Коди дар заминаи торик бо тугмаи ▶ Запустить — зинда аст: онро тағйир диҳед ва натиҷаро бубинед. Дар блокҳои консолӣ шакл бевосита аз сатри HTML сохта мешавад — ба ин восита мо метавонем кодро бе воридкунии дастӣ санҷем. Тирезаҳо бо ҷадвалҳои index.html / style.css / script.js — саҳифаҳои хурданд: дар боло код, дар поён пешнамоиш, ки дар он воқеан клик кардан ва чоп кардан мумкин аст. Оғоз — Ctrl + Enter. 01 Шакл ва майдонҳои он: value ва checked

Шакл дар HTML — ин теги <form> аст, ки дар дохили он майдонҳои воридкунӣ ҷойгиранд: <input>, <select>, <textarea> ва тугмаи ирсол. Аломатгузориро шумо аллакай медонед — имрӯз ба мо муҳим аст, ки чӣ тавр маълумотро аз ин майдонҳо баровардан бо ёрии JavaScript.

Муқоиса аз ҳаёт

Анкета дар бонк ё бланки фармоиш дар чойхона: дар ҳар сатр ном («Ном», «Телефон») ва он чизе, ки шумо навиштаед, ҳаст. Дар шакл ном — атрибути name аст, ва он чизе, ки навишта шудааст, — хосияти value. Оператор бланки пуркардашударо мегирад ва сатр ба сатр мехонад — скрипти шумо айнан ҳамин тавр кор мекунад.

Майдонро чӣ тавр ёфтан

Ҳар майдонро тавассути querySelector ёфтан мумкин аст, аммо шакл роҳи қулай дорад — маҷмӯаи form.elements. Дар он майдонҳо аз рӯи атрибути name дастрасанд:

<form id="reg">
  <label>Имя <input name="fullName" value="Мадина"></label>
  <label>Возраст <input name="age" type="number" value="19"></label>
  <label>Город
    <select name="city">
      <option value="dushanbe">Душанбе</option>
      <option value="khujand">Худжанд</option>
    </select>
  </label>
  <label><input type="checkbox" name="agree"> Согласен с правилами</label>
  <button type="button" id="show">Показать значения</button>

Тузоқи асосӣ: value — ҳамеша сатр

Ҳатто дар type="number" қимат ҳамчун сатр меояд. Ин ҳамон ҳикояи табдили навъҳо аз дарси 2 аст:

document.body.innerHTML = `
  <input name="plov" type="number" value="40">
  <input name="tea" type="number" value="10">`;

const plov = document.querySelector("[name=plov]").value;
const tea = document.querySelector("[name=tea]").value;

console.log(plov + tea);                   // "4010" — ҳамчун сатр часпиданд!
console.log(Number(plov) + Number(tea));   // 50 — аввал ба адад табдил медиҳем
console.log(document.querySelector("[name=plov]").valueAsNumber); // 40 — фавран адад
Хатоҳои маъмул

1) Дар чекбокс .value-ро ба ҷои .checked хондан — шумо ҳамеша сатри "on"-ро мегиред, ҳатто агар нишона набошад. 2) .value-ро фаромӯш кардан ва худи элементро чоп кардан: console.log(form.elements.fullName) тегро нишон медиҳад, на матнро. 3) Ду майдони ададиро тавассути + ҷамъ кардан — часпидани сатрҳо мешавад.

Атрибутҳои name, label ва type

  • name — «номи майдон». Тавассути он мо майдонро дар form.elements меёбем, ва маҳз аз рӯи он маълумот ба FormData меафтад (бахши 3). Бе name майдон барои шакл «ноаён» аст.
  • <label> — тавзеҳ. Майдонро дар он печонед ё тавассути for ва id пайваст кунед: он гоҳ клик ба матн курсорро ба майдон мегузорад, ва хонандаҳои экранӣ мефаҳманд, ки пеши онҳо кадом майдон аст.
  • type — ба браузер ишора мекунад, ки дар телефон кадом клавиатураро нишон диҳад (tel — рақамӣ, email — бо «@») ва кадом санҷишҳоро фаъол кунад.

02 Ирсоли шакл: ҳодисаи submit

Вақте одам тугмаи «Отправить»-ро пахш мекунад ё дар майдони матнӣ Enter-ро мезанад, шакл ҳодисаи submit-ро ба вуҷуд меоварад. Агар чизе накунед, браузер маълумотро ба сервер мефиристад ва саҳифаро аз нав бор мекунад — тамоми маълумоти воридшуда ва тамоми мантиқи JS-и шумо нест мешавад. Бинобар ин сатри аввали ҳар коркардкунандаи ирсол — event.preventDefault() (шумо инро аз дарси 9 медонед).

document.body.innerHTML = `
  <form id="order">
    <input name="dish" value="Оши палав">
    <input name="qty" type="number" value="2">
    <button>Заказать</button>
  </form>`;

const form = document.querySelector("#order");

form.addEventListener("submit", (event) => {
  event.preventDefault();                       // намегузорем, ки саҳифа аз нав бор шавад
  const dish = form.elements.dish.value;        // қиматҳоро ДАР ДОХИЛИ коркардкунанда мехонем
  const qty = Number(form.elements.qty.value);
  console.log(`Заказ принят: ${dish} × ${qty}`);
});

form.dispatchEvent(new Event("submit", { cancelable: true }));   // пахши тугмаи «Заказать»-ро тақлид мекунем

submit-ро мешунавем, на click-ро

Бад: click дар тугма

Агар одам шаклро бо клавишаи Enter фиристад, тугмаро касе пахш накардааст — коди шумо кор намекунад.

button.addEventListener("click", () => {
  // Enter дар майдон ба ин ҷо намеояд
});
Хуб: submit дар шакл

Дар ҳар роҳи ирсол кор мекунад: муш, Enter, тугма дар телефон.

form.addEventListener("submit", (event) => {
  event.preventDefault();
  // ...
});

Тафсилоти муфид

event.target
Дар ҳодисаи submit ин худи шакл аст. Пас майдонҳоро чун event.target.elements.email гирифтан мумкин аст — коркардкунанда аз тағйирёбандаи берунӣ вобаста нест.
form.reset()
Ҳамаи майдонҳоро ба қиматҳои аввала бармегардонад (ҳамонҳое, ки дар атрибутҳои value / checked навишта шудаанд, ё холӣ). Баъди ирсоли бомуваффақият даъват мекунем.
form.dispatchEvent(new Event("submit", { cancelable: true }))
Ҳодисаи submit-ро дастӣ «мепаронад». Бо ин усул мо дар мисолҳо ва вазифаҳо пахши «Отправить»-ро тақлид мекунем: қуттии таълимии санҷиш ирсоли воқеии шаклҳоро манъ мекунад, бинобар ин одатии form.requestSubmit() (он тугмаро худаш пахш мекунад) дар ин ҷо кор намекунад. Дар сайти оддӣ шумо ба тугма клик мекунед ё маҳз requestSubmit()-ро даъват мекунед.
<button type="button">
Тугма дар дохили шакл ба таври пешфарз онро мефиристад. Агар тугма барои чизи дигар лозим бошад (масалан, «нишон додани парол»), type="button" нависед.
novalidate
Атрибути шакл: санҷиши дарунсохти браузерро хомӯш мекунад, то санҷиши худии шумо кор кунад (бахши 4).
Хатои маъмул: қиматро хеле барвақт мехонем

Қимати майдон ҳангоми чоп кардани одам тағйир меёбад. Бинобар ин онро дар лаҳзаи ҳодиса, дар дохили коркардкунанда хондан лозим аст. Агар як маротиба дар оғози скрипт хонед, шумо он чизро мегиред, ки ҳангоми бор шудани саҳифа дар майдон буд (аксар вақт — сатри холӣ).

const form = document.querySelector("form");

const email = form.elements.email.value;   // ✖ фавран хондем — ҳанӯз холист

form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("email:", "[" + email + "]");
});

form.elements.email.value = "madina@mail.tj";  // «корбар» суроғаро навишт
form.dispatchEvent(new Event("submit", { cancelable: true }));                          // → email: []
Муқоиса аз ҳаёт

Пешхизмат дар чойхона фармоишро на он вақт сабт мекунад, ки шумо танҳо ба сари миз нишастед, балки он вақт, ки шумо гуфтед «метавон фармоиш дод». Қиматҳои шаклро низ ҳамин тавр мехонем — дар лаҳзаи ирсол, на пешакӣ.

ВАЗИФАИ 2.3

миёна

Коркардкунандаи шакли вурудро нависед. Логинро аз фосилаҳои канорӣ тоза кардан лозим аст (trim()). Агар логин ё парол холӣ бошад — Ошибка: заполните все поля-ро чоп кунед. Вагарна Вход выполнен: логин-ро чоп кунед, шаклро барқарор кунед ва хабар диҳед, ки майдони логин баъд аз он холист ё не.

document.body.innerHTML = `
  <form>
    <input name="login">
    <input name="password" type="password">
  </form>`;

const form = document.querySelector("form");

// коркардкунандаи submit


function submitWith(login, password) {
  form.elements.login.value = login;
  form.elements.password.value = password;
  form.dispatchEvent(new Event("submit", { cancelable: true }));
}

03 FormData: ҳамаи майдонҳоро якбора ҷамъ мекунем

Агар дар шакл 10 майдон бошад, онҳоро якто-якто тавассути .value хондан — дилгиркунанда аст ва чизеро фаромӯш кардан осон аст. Барои ин дар браузер объекти дарунсохти FormData ҳаст: шумо шаклро ба он медиҳед, ва он худаш ҳамаи майдонҳоро бо атрибути name гашта, «ном → қимат»-и онҳоро ҷамъ мекунад.

document.body.innerHTML = `
  <form>
    <input name="fullName" value="Мадина">
    <select name="city">
      <option value="dushanbe" selected>Душанбе</option>
      <option value="khujand">Худжанд</option>
    </select>
    <input type="checkbox" name="skills" value="css" checked>
    <input type="checkbox" name="skills" value="js" checked>
    <input type="checkbox" name="skills" value="git">
    <input type="checkbox" name="agree" checked>
    <input type="checkbox" name="news">
  </form>`;

const data = new FormData(form);

console.log(data.get("fullName"));    // Мадина — як қимат аз рӯи ном
console.log(data.getAll("skills"));   // ["css", "js"] — ҳамаи қиматҳои як ном
console.log(data.has("news"));        // false — чекбокси бе нишона ба FormData намеафтад
console.log(data.get("agree"));       // "on" — дар чекбокси бе атрибути value қимат "on" аст

for (const [key, value] of data) {    // FormData-ро ҳамчун ҷуфтҳои «калид, қимат» гузаштан мумкин аст
  console.log(key, "=", value);
}

Аз FormData объекти маъмулиро ба осонӣ гирифтан мумкин аст — он лозим мешавад, то маълумотро захира кунед ё ба корбар нишон диҳед (дар шакли JSON, мисли дарси 7):

document.body.innerHTML = `
  <form>
    <input name="fullName" value="Мадина">
    <input name="age" type="number" value="19">
  </form>`;

const data = new FormData(document.querySelector("form"));
const obj = Object.fromEntries(data);   // { fullName: "Мадина", age: "19" }

console.log(JSON.stringify(obj));
console.log(typeof obj.age);   // string — ҳамаи қиматҳо ҳанӯз ҳам сатранд!
Муқоиса аз ҳаёт

Ин мисли курьери почта аст, ки аз идора ҳамаи бланкҳои пуркардашударо дар як баста мегирад. Аммо ба баста вай танҳо бланкҳоро бо имзо (name) ва танҳо онҳое, ки пур шудаанд, мегирад. Майдон бе name — бланки беном аст, курьер онро намегирад.

Чӣ ба FormData намеафтад
  • майдонҳо бе атрибути name;
  • майдонҳо бо атрибути disabled (барои «танҳо хондан» readonly-ро истифода баред);
  • чекбоксҳо ва тугмаҳои радио бе нишона — калиди онҳо дар маълумот танҳо нест. Агар false лозим бошад, checked-ро бевосита гиред: form.elements.news.checked.

Ва боз Object.fromEntries барои номҳои такроршаванда (skills) танҳо қимати охирин-ро мегузорад, бинобар ин барои гурӯҳҳои чекбокс data.getAll("skills")-ро истифода баред.

Баъдтар, вақте ба кор бо сервер мерасем, ҳамин объекти FormData-ро ҳамон тавр ба сервер фиристодан мумкин мешавад. Ҳоло мақсади мо — ҷамъ кардани маълумот ва боварӣ ҳосил кардан аст, ки он дуруст аст.

Муқоиса аз ҳаёт

Санҷиши дарунсохт мисли посбон дар даромадгоҳи маркази савдо аст: вай чизи равшанро мебинад (чипта ҳаст ё не, пропуск холӣ нест), аммо қоидаҳои мағозаи шуморо намедонад. Вай нахоҳад гуфт «Ба шумо маҳз рақами тоҷикӣ бо рамзи +992 лозим аст» ва сабаби радро бо забони барои шумо фаҳмо ва дар ҷои дурусти саҳифа шарҳ намедиҳад. Барои ин санҷиши худӣ лозим аст.

Санҷиши дарунсохт чӣ камбуд дорад

  • Матнҳои хато — бо забон ва услуби браузер, онҳоро мувофиқи тарҳи сайт тарроҳӣ кардан мумкин нест.
  • Як ҳубобча дар як вақт — одам танҳо хатои аввалро мебинад, на ҳамаро якбора.
  • Қоидаҳои мураккаб — «паролҳо мувофиқанд», «телефон танҳо тоҷикӣ» коди худиро талаб мекунанд.
  • Санҷиши зинда ҳангоми воридкунӣ — бе JavaScript-и худӣ «зебо» намешавад.
Нозукиҳо

1) minlength ва maxlength танҳо вақте месанҷанд, ки қиматро одам ворид мекунад. Агар аз JavaScript input.value = "a" нависед, парчами tooShort кор намекунад. 2) Ҳамаи санҷишҳои браузер ва JS-и шумо дар саҳифа ба осонӣ гузашта мешаванд (кифоя аст DevTools-ро кушоед), бинобар ин дар сайти воқеӣ маълумотро ба таври иловагӣ дар сервер ҳам месанҷанд. Санҷиш дар браузер — ин қулайӣ барои одам аст, на ҳимоя.

Аз ин рӯ дар амал чунин мекунанд: атрибутҳои асосӣ (required, type)-ро барои ишораҳои клавиатураи мобилӣ мегузоранд, ва худи санҷиш ва матнҳои хатоҳоро дар JavaScript менависанд ва ҳубобчаҳои браузериро бо атрибути novalidate дар шакл хомӯш мекунанд:

</form>

05 Ибораҳои муқаррарӣ барои навомӯзон

Ибораи муқаррарӣ (regex, «регэксп») — ин қолаби кӯтоҳест, ки тавсиф мекунад, сатр чӣ гуна бояд бошад. «Танҳо рақамҳо», «бо +992 оғоз мешавад ва баъд нӯҳ рақам», «ҳарфҳои лотинӣ ва зерхат» — ҳамаи инро бо як сатр навиштан мумкин аст. Барои санҷиши шаклҳо ин абзори ивазнашаванда аст.

Муқоиса аз ҳаёт

Дӯзанда андоза мегирад ва матоъро аз рӯи қолаб мебурад: қисм ё дақиқ ба қолаб мемонад, ё не. Ибораи муқаррарӣ — қолаб барои матн. Шумо шаклро як маротиба тавсиф мекунед, ва компютер ҳар сатрро ба он мемонад ва ҷавоб медиҳад «мувофиқ аст» ё «мувофиқ нест».

const onlyDigits = /^\d+$/;          // байни слэшҳо — қолаб

console.log(onlyDigits.test("12345"));  // true  — мувофиқ аст
console.log(onlyDigits.test("12a45"));  // false — ҳарф ҳаст
console.log(onlyDigits.test(""));       // false — холӣ (ақаллан як рақам лозим аст)

Ибораи муқаррарӣ байни ду слэш навишта мешавад /.../. Усули .test(сатр) true бармегардонад, агар сатр ба қолаб мувофиқ бошад, вагарна — false. Акнун «ҳарфҳои» ин забонро шарҳ медиҳем.

Парчамҳо ва иваз: воридотро тоза мекунем

Баъди слэши пӯшанда парчамҳо мегузоштан мумкин аст: i — ҳарфҳои калон ва хурдро фарқ накардан, g — ҳамаи мувофиқатҳоро ҷустан, на танҳо аввалинро. Бо усули replace ин роҳи қулай барои аз фосила ва дефисҳо тоза кардани телефон аст:

06 Санҷиши худӣ: функсияҳои санҷанда ва матнҳои хатоҳо

Акнун мо ҳама чизро дорем, то санҷиши худиро нависем. Дастур оддӣ аст ва барои ҳар шакл кор мекунад:

  1. Як санҷанда барои як майдон. Ин функсияест, ки қиматро мегирад ва матни хато-ро бармегардонад — ё сатри холии "", агар ҳама чиз хуб бошад.
  2. Дар объект ҷамъ мекунем. { fullName: validateName, email: validateEmail, ... } — аз рӯи калид намоён аст, ки кадом санҷанда ба кадом майдон тааллуқ дорад.
  3. Хатоҳоро нишон медиҳем. Матн — дар <span> дар зери майдон, ва худи майдонро бо чаҳорчӯбаи сурх ва атрибути aria-invalid қайд мекунем.
  4. Намефиристем, то даме ки ақаллан як хато ҳаст.

Қадами 1: санҷанда — функсияи «қимат → матни хато» аст

function validateEmail(value) {
  const email = value.trim();                       // фосилаҳои канориро мебарорем
  if (email === "") return "Введите email";
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    return "Похоже, в адресе ошибка. Пример: madina@mail.tj";
  }
  return "";                                        // сатри холӣ = хато нест
}

console.log("[" + validateEmail("") + "]");
console.log("[" + validateEmail("madina@") + "]");
console.log("[" + validateEmail("  madina@mail.tj ") + "]");

Функсия танҳо месанҷад ва дар бораи саҳифа чизе намедонад. Бинобар ин санҷидани он осон аст (мо ҳоло онро бо се мисол даъват кардем) ва истифодаи такрории он осон — дар ҳар саҳифа ва бо ҳар тарҳ. Қоидаи «як функсия ҳисоб мекунад, дигар нишон медиҳад»-ро шумо дар дарси 5 дидаед.

Муқоиса аз ҳаёт

Назоратчӣ дар даромадгоҳи метро. Вай аз пасатон намедавад — дар назди турникет меистад ва ба чипта менигарад. Агар чизе нодуруст бошад, вай сабабро ном мегирад («корт гузоред», «пул намерасад»). Санҷанда — ҳамон назоратчӣ: дар баромад ё «гузаред» (""), ё сабаби фаҳмои радкунӣ.

Кадом матнҳои хато навиштан лозим

Бад

«Ошибка!», «Неверное значение», «Invalid input», «Поле заполнено неверно». Одам намефаҳмад, чӣ нодуруст аст ва чӣ тавр ислоҳ кардан лозим.

Хуб

«Введите номер в формате +992 и 9 цифр», «Пароль — минимум 8 символов», «Пароли не совпадают». Гуфта шудааст, ки чиро интизорем, ва фавран намуна намоён аст.

  • Бо «Шумо» ва оромона сухан гӯед: на «Ту нодуруст ворид кардӣ», балки «Лутфан, email-ро санҷед».
  • Қоида-ро ном гиред, на танҳо далели хаторо: «ақаллан 2 ҳарф» муфидтар аз «хеле кӯтоҳ» аст.
  • Хаторо дар паҳлӯи майдон нишон диҳед, на бо як тирезаи alert дар болои саҳифа.
  • Майдони ҳатмии холӣ ва формати нодуруст — паёмҳои гуногун-анд: «Введите email» ва «Неверный формат email».

Қадами 2: ҳамаи майдонҳоро якбора месанҷем

Вақте санҷандаҳо якчанд бошанд, онҳоро дар объект нигоҳ доштан ва бо давра гузаштан қулай аст. Дар баромад — объекти хатоҳо: дар он калидҳо танҳо барои майдонҳои нодуруст ҳастанд. Объекти холӣ — ҳама чиз хуб.

const validators = {
  fullName: (v) => (v.trim().length < 2 ? "Введите имя (минимум 2 буквы)" : ""),
  age: (v) => (Number(v) >= 16 ? "" : "Курс с 16 лет"),
};

function validateAll(data) {
  const errors = {};
  for (const field in validators) {
    const message = validators[field](data[field]);
    if (message) errors[field] = message;
  }
  return errors;
}

console.log(JSON.stringify(validateAll({ fullName: "Мадина", age: "19" })));   // {}
console.log(JSON.stringify(validateAll({ fullName: "М", age: "15" })));

Ҳар майдон «ҷой барои хато» мегирад — <span>-и холӣ дар паҳлӯ. Ҳангоми хато мо матнро ба он менависем, ҳангоми набудани он — пок мекунем. Ҳамеша textContent-ро истифода баред, на innerHTML: воридоти корбарро ҳамчун HTML ба саҳифа гузоштан мумкин нест.

const validators = {
  fullName: (v) => (v.trim().length < 2 ? "Введите имя (минимум 2 буквы)" : ""),
  age: (v) => (Number(v) >= 16 ? "" : "Возраст — число от 16"),

function showError(name, message) {
  const input = form.elements[name];
  const box = form.querySelector(`[data-error="${name}"]`);
  box.textContent = message;                               // сатри холӣ хаторо пок мекунад
  input.classList.toggle("invalid", message !== "");       // чаҳорчӯбаи сурх
  input.setAttribute("aria-invalid", message ? "true" : "false");  // барои хонандаҳои экран
}

form.addEventListener("submit", (event) => {
  event.preventDefault();
  let firstBad = null;
  for (const name in validators) {
    const message = validators[name](form.elements[name].value);
    showError(name, message);
    if (message && !firstBad) firstBad = form.elements[name];
  }
  if (firstBad) {
    firstBad.focus();                 // курсорро ба аввалин майдони хатодор мегузорем
    return;                           // минбаъд намеравем — шакл фиристода намешавад
  }
  console.log("Отправлено:", JSON.stringify(Object.fromEntries(new FormData(form))));
});

  event.preventDefault();

});

Иҷро кунед, «Отправить»-ро бо майдонҳои холӣ пахш кунед, баъд ислоҳ кунед ва боз фиристед. Ба се ҷузъ диққат диҳед: хатоҳо фавран дар ҳамаи майдонҳо нишон дода мешаванд, курсор дар аввалин майдони «бад» меистад, ва дар майдони ислоҳшуда хато нест мешавад.

Хатоҳои маъмул
  • Фаромӯш кардани trim() — « » (фосилаҳо) ҳамчун ном ғайрихолӣ ҳисоб мешавад.
  • Сатрро ҳамчун адад муқоиса мекунем — "5" < "16" сатрҳоро аз рӯи аломатҳо муқоиса мекунад. Аввал Number(...).
  • Хатои кӯҳнаро пок намекунем — одам майдонро ислоҳ кард, аммо матни сурх монд. Бинобар ин showError ҳамеша, ҳатто барои майдонҳои дуруст — бо сатри холӣ даъват мешавад.
  • Воридотро тавассути innerHTML нишон медиҳем — барои XSS роҳ мекушояд. Танҳо textContent.
  • Санҷиш танҳо дар браузер — барои сайти воқеӣ боз санҷиши сервер низ лозим аст.

07 Санҷиши зинда: ҳангоми чоп кардани одам месанҷем

Санҷиш танҳо ҳангоми пахши «Отправить» кор мекунад, аммо нокулай аст: одам даҳ майдонро пур кард ва дар бораи хато дар аввалин майдон мефаҳмад. Санҷиши зинда фавран ишора мекунад. Барои он се ҳодиса лозим аст:

input
Дар ҳар тағйири қимат кор мекунад: клавиша заданд, матн гузоштанд, аломатро пок карданд.
change
Вақте кор мекунад, ки қимат тағйир ёфт ва майдон фокусро аз даст дод (барои чекбокс ва рӯйхат — фавран ҳангоми интихоб).
blur
Майдон фокусро аз даст дод — одам ба майдони дигар рафт. Боло намеравад (баръакси focusout).
Муқоиса аз ҳаёт

Пешхизмати хуб дар чойхона шуморо дар нисфи сухан намебурад: «Не, палав аллакай нест!» Вай интизор мешавад, то шумо гуфтанро тамом кунед, ва танҳо баъд ислоҳ мекунад. Шакл низ ҳамин тавр: то даме ки одам воридкунии майдонро тамом накардааст, ба майдон хафа нашавед, вагарна аввалин ҳарфи email «Неверный email»-и сурхро ба вуҷуд меорад.

Қоидаи «ламс шуд / ламс нашуд» (touched)

  1. То даме ки одам майдонро тарк накардааст — хаторо нишон намедиҳем, ҳатто агар қимат ҳоло нодуруст бошад.
  2. Вақте blur кор кард — майдон «ламсшуда» ҳисоб мешавад: месанҷем ва хаторо нишон медиҳем.
  3. Аз ҳамин лаҳза дар ҳар input аз нав месанҷем: ҳамин ки одам ислоҳ кард, хато фавран нест мешавад.
  4. Ҳангоми пахши «Отправить» ҳамаи майдонҳоро якбора «ламс мекунем» ва ҳамаи хатоҳоро нишон медиҳем.

08 Блоки ЗС: қоидаҳои санҷиш ва регэкспҳо

Ишораи ЗС

Ибораҳои муқаррарӣ — яке аз беҳтарин вазифаҳо барои ЗС: навиштани онҳо бо даст вақтро мегирад, ва бо калимаҳо шарҳ додани «чӣ мехоҳам» осон аст. Аммо маҳз дар ин ҷо ЗС бештар бо эътимод хато мекунад. Бинобар ин нақша ҳамеша як аст: ЗС пешниҳод мекунад — шумо бо мисолҳои худ месанҷед.

Қоидаҳои курсро ёдрас мекунем: аввал 15 дақиқа худатон кӯшиш кунед, ва ҳеҷ гоҳ коде, ки сатр ба сатр шарҳ дода наметавонед, ворид накунед. Имрӯз шумо аллакай регэкспҳоро хонда метавонед, бинобар ин ҷавоби ЗС-ро қисм ба қисм таҳлил кардан мумкин аст.

1. Қоидаҳои санҷишро талаб мекунем

Формулаи промптро истифода мебарем: контекст → вазифа → маҳдудиятҳо → формати ҷавоб → санҷиш.

санҷиши шакли сабти номро соз
Контекст: ман бо JavaScript-и холис бе китобхонаҳо менависам, сатҳ — навомӯз. Шакли сабти номро барои курсҳо дар Душанбе месозам. Вазифа: барои майдонҳо қоидаҳои санҷиш тартиб деҳ: ном, телефон (Тоҷикистон, +992), email, парол, такрори парол. Барои ҳар кадом — шарт, паёми хато бо забони тоҷикӣ ва ибораи муқаррарӣ, агар лозим бошад. Маҳдудиятҳо: регэкспҳои оддӣ, ки навомӯз хонда тавонад; бе китобхонаҳои беруна; паёмҳо — мулоим, бо намунаи воридкунии дуруст. Формати ҷавоб: ҷадвали «майдон | қоида | паёми хато | регэксп». Санҷиш: барои ҳар регэксп 3 сатрро, ки мувофиқанд, ва 3-тоеро, ки мувофиқ нестанд, биёр ва регэкспро қисм ба қисм шарҳ деҳ.

2. Регэкспи ЗС-ро бо ҳолатҳои худамон месанҷем

Ҳатто ба ҷавоби аз ҳама боэътимод бовар накунед. Одат кунед — ҷадвали санҷишҳо:

  1. 3–5 сатри мувофиқ, аз ҷумла «ифлос» (бо фосилаҳо дар канор, бо регистри гуногун).
  2. Сатри холӣ — бояд рад карда шавад (агар майдон ҳатмӣ бошад).
  3. Ҳудуди дарозӣ: як кам аз ҳадди ақал, айнан ҳадди ақал, айнан ҳадди аксар, як зиёд аз ҳадди аксар.
  4. «Хасу хошок» дар атроф: abc1234xyz дар ҷое, ки танҳо рақамҳо лозиманд. Ҳамин тавр шумо набудани ^ ва $-ро мегиред.
  5. Маълумоти воқеии шумо: телефонҳо аз китобчаи ёддошти шумо, номҳои дӯстон бо кириллӣ, email-и воқеии шумо.

Регэкспи ЗС-ро қисм ба қисм бихонед, чунон ки мо дар бахши 5 кардем. Агар ягон қисмро шарҳ дода наметавонед — аз ЗС шарҳ пурсед ва онро бо санҷишҳо тасдиқ кунед, ё ибораро соддатар кунед. Кодеро, ки намефаҳмед, ҳангоми вайрон шудан дар маълумоти воқеӣ ислоҳ карда наметавонед.

09 Амалиёт дар дарс: шакли сабти ном бо санҷиши зинда

Ҳамаро дар як шакл ҷамъ мекунем — чунон, ки шумо дар ҳар сайт мебинед. Мо номнависӣ ба курсро месозем: ном, email, парол ва такрори парол.

Қоидаҳои шакли мо
  • Ном — ҳадди ақал 2 аломат бе фосилаҳо дар канор. Хато: «Имя — минимум 2 буквы».
  • Email — формати оддӣ чизе@чизе.чизе. Хато: «Введите email в формате name@mail.tj».
  • Парол — ҳадди ақал 8 аломат, баъд ҳадди ақал як рақам. Хатоҳо: «Пароль — минимум 8 символов» ва «Добавьте хотя бы одну цифру».
  • Такрори парол — бо парол мувофиқ аст. Хато: «Пароли не совпадают».
  • Хатоҳо баъди баромадан аз майдон пайдо мешаванд (blur), баъд барои ҳар воридкунӣ нав мешаванд (input).
  • Ҳангоми ирсол ҳамаи майдонҳо якбора санҷида мешаванд, курсор ба аввалин хатодор меравад, ва ҳангоми муваффақият «Регистрация: имя, email» чоп мешавад (паролро дар логҳо намегузорем — ҳеҷ гоҳ!).

Нақшаи кор

  1. Аломатгузорӣ. Шакл бо novalidate, дар ҳар майдон — label, name ва span.error-и холӣ дар зери он (data-error="номи майдон").
  2. Санҷандаҳо. Функсияҳои «қимат → матни хато», ки дар объекти validators ҷамъ шудаанд (бахши 6).
  3. Нишон додани хатоҳо. showError — матн, чаҳорчӯбаи сурх, aria-invalid.
  4. Санҷиши зинда. Луғати touched, коркардкунандаҳои blur ва input (бахши 7).
  5. Ирсол. Коркардкунандаи submit: ҳамаи майдонҳоро «ламс мекунем», месанҷем, фокус ба аввалин хатодор ё муваффақият (бахши 2).

Аломатгузорӣ, услубҳо ва «скелет»-и умумӣ (қадамҳои 1, 3)-ро мо тайёр медиҳем. Кори шумо — ду марҳила.
